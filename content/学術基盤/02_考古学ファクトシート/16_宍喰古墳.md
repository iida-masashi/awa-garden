# 宍喰古墳 ファクトシート

## 基礎情報
- **所在地**: 徳島県海部郡海陽町宍喰（宍喰中学校横・県民運動場脇）
- **種別**: 円墳（地山を掘り込んで石室を築き盛土した円墳。横穴式石室を埋葬施設とする）
- **時代**: 古墳時代後期（**報告上は築造年代不明**。約7km北東の大里古墳〔6世紀後半〜7世紀〕との比較から同時期と**推定**）
- **位置**: 阿波最南端、太平洋に面する宍喰川河口域。本県最南の古墳
- **規模**: 原石室は全長約12mの横穴式石室と伝える。大里古墳より少し大きい規模をもっていたと考えられる（海陽町教育委員会）

## 概要
阿波国最南端に位置する古墳。紀伊水道と太平洋を結ぶ海上交通の要衝にあり、海人族の影響圏に属する。宍喰川流域を治めた豪族の首長墓とみられる。大正10年頃、運動場予定地の尾根上で赤土採取中に発見され、運動場造成時に現在地へ**移築**された。

## 主な出土品・遺構
- **横穴式石室**（移築現存するのは玄室部分で、長さ約5m・幅約1.5m程度。奥壁に大岩、側壁は頭大の石を積む。原位置では既に天井石を欠き、奥壁・側壁のみ残存していたと伝える）
- **出土遺物（海陽町教育委員会の説明板）**: 石室内調査で **折れた刀** と **土器** を検出
- **海陽町文化財一覧（町指定・㉗）の記述**（OCR取込。[kaiyou_bunkazai](https://www.town.kaiyo.lg.jp/_files/00580649/kaiyou_bunkazai.pdf)）: 「6世紀頃の古墳で、現在地に移設」「横穴式石室の玄室一面が残り、石室の石は砂岩で、長さ約7ｍ、幅2.6ｍの長方形に配置し、奥壁に2枚の砂岩を用いる。直刀、須恵器、土師器が出土したという」。副葬品は直刀・須恵器・土師器で、玉類と阿波青石の記載はない。石室の寸法は上記の説明板由来の記述（長さ約5m・幅約1.5m）と食い違うため、実測値は海陽町史・県報告書での確認が必要（〔要確認〕）

## 阿波説における重要性

### 1. 黒潮ルートと海人族
宍喰は黒潮が四国沖を流れる海上交通の重要ポイント。古代において紀州・伊勢・尾張・東国への海上交通の発着地。
→ 阿波忌部の東遷ルート（阿波 → 紀伊 → 東国）の出発点候補の一つ。

### 2. 海部郡の祭祀ネットワーク
宍喰は古代海部郡に属し、和奈佐意富曾神社・八鉾神社など海神系の祭祀圏に位置する。

### 3. 被葬者＝鷲住王の子孫・阿波脚咋別一族説
宍喰川上流の **大山神社**（鷲住王を祀り、宍喰開拓の祖神とする）の存在から、被葬者を **鷲住王（わしずみのおおきみ）** を祖とする **阿波脚咋別（あしくいわけ）一族** の首長とみる説がある。鷲住王は『日本書紀』に景行天皇の曾孫・履中天皇の后妃の兄として現れ、讃岐国造・阿波脚咋別の始祖とされる人物。「脚咋（あしくい）」が「**宍喰**（ししくい）」の地名になったとする伝承がある。北東7kmの大里古墳と被葬者像が重なり、ともに南阿波の海洋豪族（後の海部氏）の墓とみる議論につながる。
→ 詳細は専門ノート [[鷲住王と阿波君：南阿波の独立勢力と大里古墳の被葬者]] に委ねる（鷲住王・脚咋別・海部氏の系譜論はそちらが扱う）。

### 4. 関東・房総との地名対応
宍喰・宍倉系の地名が房総（千葉県）にも分布。阿波忌部の東遷との関連が指摘される（要・実証）。
