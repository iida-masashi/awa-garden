# 御祖略系：天之御中主神から天午刀男神への父神縦系譜

> [!summary] 要旨
> **「御祖略系（みおやりゃくけい）」** は、**『粟国造粟凡直粟飯原氏系図』（1876年）** の中段に挿入される **大宜都比売命と粟国造の父神系譜** を整理した独立系図部分。神世七代を経ずに直接 **「天之御中主神 → 皇産霊二大神 → 角凝魂命 → 天午刀男神」** という **4世代縦系譜** で天津神最高位から **阿波忌部・粟国造の祖父神** へ連結する。**天午刀男神（あまのてかしお／天手力男命の異表記）** が **大阿波女神（大宜都比賣命）・天日鷲神・天鈴杵命系・許登能麻遅比賣命の4系統の御子** を持つ **氏族横展開の結節祖神** として位置付けられる。本系譜は **[[安房齋部本系帳：洲宮神社小野家伝承と天背男命の系譜]] の縦系譜（神魂命→天背男命→天日鷲翔矢命）と並行する第二の父神系譜** であり、**「天午刀男神＝天手力男命＝天背男命＝天石門別命」** の **一神異名説**（平田篤胤）の系図的物証となる。

## 2. 御祖略系の原文翻刻

『粟国造粟凡直粟飯原氏系図』中段に挿入される **「御祖略系」** の完全翻刻：

```
御祖略系

天之御中主神
   ↓
皇産霊二大神
   ↓
角凝魂命
   ↓
天午刀男神
   ├→ 天日鷲神（粟忌部之祖、式内麻植郡忌部神社）
   │      ├→ 大麻比古神（式内板野郡大麻比古神社）
   │      ├→ 長白羽神
   │      └→ 天羽槌雉神
   ├→ 天鈴杵命
   │      ↓
   │     天御雲命
   │      ↓
   │     天村雲命（式内麻植郡天村雲伊自波庭比賣神社二座）
   │      ↓
   │     天波與命
   ├→ 許登能麻遅比賣命
   └→ 大阿波女神（大宜都比賣命）
```

#### 「天午刀男」表記の解読

「**午（うま）**」と「**刀（とう）**」の文字解釈：

| 字 | 一般的読み | 解読 |
|---|---|---|
| **午** | うま | **「手」の異表記**（または草書体の誤写） |
| **刀** | とう | **「力」の異表記**（または字形類似） |

→ **「天午刀男」＝「天手力男（あまのたぢからお）」** の異表記とする読みが有力。

#### 平田篤胤「一神異名」説との接続

天午刀男神は、平田篤胤の「一神異名」説における：

**天背男命 ＝ 天石門別命 ＝ 天石門別安国玉主命 ＝ 天手力男神**

の **同一神**。御祖略系の **天午刀男神** ＝ 安房齋部本系帳の **天背男命** ＝ 一神異名群の中核神。

→ 詳細：[[天背男命：阿波忌部の祖父神と「一神異名」群]]

## 5. 御祖略系の構造的特徴

### 5-1. 「4世代縦」+「4系統横」の組み合わせ

```
天之御中主神
   ↓
皇産霊二大神         ← 縦：天津神最高位の4世代
   ↓
角凝魂命
   ↓
天午刀男神           ← 結節祖神
   ↓
   ├─ 天日鷲神 → 3御子    ← 横：4系統の御子展開
   ├─ 天鈴杵命 → 4世代縦系譜
   ├─ 許登能麻遅比賣命
   └─ 大阿波女神（大宜都比賣命）
```

→ **「4×4」の二軸構造**。天津神最高位から阿波の主要祭祀神まで **わずか4世代** で接続する **極めて短縮された系譜**。

### 5-2. 神世七代を経ない直系

通常の記紀系図では：

```
天之御中主神 → 神世七代（伊邪那岐含む）→ 各神
```

という長大な系譜を経るが、御祖略系は **神世七代を完全に省略**：

```
天之御中主神 → 皇産霊 → 角凝魂 → 天午刀男 → 各神
```

→ **「神世七代以前の超古層」** に阿波忌部・粟国造の祖父神を位置付ける戦略的系譜。

### 5-3. 安房齋部本系帳との対応関係

| 御祖略系 | 安房齋部本系帳 |
|---|---|
| 天之御中主神 | – |
| 皇産霊二大神 | 神魂命 |
| 角凝魂命 | 角己利命・天底立命 |
| – | 五十狭布魂・伊加志保魂命 |
| **天午刀男神** | **天背男命** |
| → 天日鷲神 → 大宜都比賣 等 | → 天日鷲翔矢命 → 6御子 |

→ **両系図は「同じ神々を異なる名前で記述している」** と読める。御祖略系は **「天午刀男神」表記** で、安房齋部本系帳は **「天背男命」表記** だが、両者は **一神異名** とする解釈が成立する。

## 7. 阿波説における意義

### 7-1. 「天津神最高位 → 阿波の祖父神」の超短縮系譜

御祖略系の最大の特徴は、**わずか4世代** で天津神最高位（天之御中主神）から阿波の祖父神（天午刀男神）に到達すること：

| 観点 | 内容 |
|---|---|
| **戦略的意義** | 阿波忌部・粟国造を **天津神直系** に位置付ける |
| **記紀との対比** | 記紀の神世七代を **省略・無視** する |
| **古層の主張** | 「神世七代以前の超古層」の祭祀権を阿波が保持 |

### 7-2. 「天午刀男神」結節構造

天午刀男神を中心に **4系統が放射状に展開** することは、阿波忌部・粟国造祭祀の **氏族横断的統合** を示す：

| 系統 | 後裔氏族 |
|---|---|
| 天日鷲神系 | 阿波忌部・大麻比古祭祀・倭文連・伊勢麻続連 |
| 天鈴杵命系 | 大田田根子・高倉下・天村雲命系（神武東征助力神族） |
| 許登能麻遅比賣命系 | 中臣氏（天児屋根命の母として） |
| 大阿波女神系 | 粟国造・粟凡直・粟飯原氏 |

→ **天午刀男神が阿波忌部・中臣氏・粟国造・神武東征助力神族の共通祖神** という位置付け。

### 7-3. 大宜都比売命の父神問題の決着

[[大宜都比売命の父神論：天手力男・天背男・八倉比賣との交差]] で論じた **「大宜都比売命の父神は誰か？」** という核心問題に、御祖略系は明確な答えを与える：

```
天午刀男神（＝天手力男命）
   ↓
大阿波女神（＝大宜都比賣命）
```

→ **「父神＝天手力男命（天午刀男神）」** とする阿波説の最も決定的な系図的物証。

### 7-4. 天村雲命系と神武東征の連動

天鈴杵命系の **天御雲命（＝高倉下）・天村雲命** は **神武東征の助力神**：

| 神 | 神武東征での役割 |
|---|---|
| **天香山 ＝ 高倉下** | 神武に布都御魂剣を献上、熊野での危機を救う |
| **天村雲命** | 神武東征の剣（草薙剣に関連）の神格 |

→ 御祖略系は **「天午刀男神 → 天鈴杵命 → 天香山（高倉下）→ 天村雲命」** という系譜を介して、**阿波の祖父神が神武東征に直接関与** したことを示す。

### 7-5. 一神異名説の系図的物証

御祖略系の **「天午刀男神」** という独特な表記は：

- **「天手力男命」** の異表記
- **「天背男命」** との同一神（一神異名）
- 平田篤胤説の **系図的物証**

→ 中世以前の系図類が **同一神を異なる名前で記録** していたことを示す重要事例。

## 10. 留保（中立的併記）

> [!warning] 注意
> - 「**天午刀男 ＝ 天手力男**」とする読みは**字形類似による推定**で、原本の意図は確定していない。「午」「刀」が誤写の可能性も含めて検討が必要
> - **御祖略系自体が『粟飯原氏系図』内の挿入部分** であり、本系図全体の編纂年代（1876年）から原典の年代は遡及困難
> - 「**4世代で天津神最高位から阿波祖父神に到達**」とする超短縮系譜は、忌部側の戦略的系譜の可能性。記紀の神世七代との整合性は問題が残る
> - 「**天午刀男神 ＝ 天背男命 ＝ 天手力男神**」の一神異名説は平田篤胤の解釈で、現代学術では検証は限定的
> - **fusa の百嶋神社考古学ベース比定**（天鈴杵命＝大田田根子、天御雲命＝高倉下など）は独自解釈で、文献的確証はない
> - **皇産霊二大神を一括** する記述は本御祖略系の特徴だが、神産巣日と高皇産霊を別系統と見る通説とは異なる
> - 「**角凝魂命**」は記紀には登場せず、本系譜での位置付けは『斎部宿祢本系帳』の角己利命との対応関係から推定される
