# 大宜都比売命の父神論：天手力男・天背男・八倉比賣との交差

> [!summary] 要旨
> 阿波の国魂神・大宜都比売命（大粟姫）の系譜上の位置は、阿波説の論理構造を成立させるか否かを決する核心問題である。本ノートは、通説（『古事記』では伊邪那岐・伊邪那美の御子）に対し、阿波内部の系図資料（『上一宮大粟神社古傳書及御神号改正願稿』『粟国造粟飯原家系図』『斎部宿祢本系帳』ほか）に基づく「父神＝天手力男命（＝天石門別神）」論、八倉比賣命との同一神論、配偶神・御子神の系譜を整理する。阿波説は天背男命＝天手力男命を介して阿波忌部（天日鷲）と阿波国魂（大宜都比売）を「兄弟関係」とみる系譜論を根幹に置く。

阿波の国魂神・**大宜都比売命**（おおげつひめのみこと／大粟姫）の系譜上の位置は、阿波説の論理構造を成立させるか否かを決する核心問題である。本ノートは、

1. 通説（『古事記』）における系譜
2. 阿波説における **「父神＝天手力男命」** 論
3. **八倉比賣命との同一神論** との接続
4. 配偶神・御子神の系譜

を整理し、阿波内部の系図資料（『上一宮大粟神社古傳書及御神号改正願稿』『粟国造粟飯原家系図』『斎部宿祢本系帳』『古屋家家譜』『阿波国風土記編輯雜纂』）を相互参照する。

これらは矛盾するように見えるが、阿波説の立場では **「同一神を異なる系譜文脈で語っている」** と読まれる。

## 2. 通説：『古事記』における大宜都比売命の系譜

『古事記』上巻・国生み段：

> 次に粟国を生みき、亦の名は **大宜都比売**（おほげつひめ）と謂ふ

→ 伊邪那岐・伊邪那美の **国生み** の所産。「国（粟国＝阿波）の別名」として直接登場する。父神は **伊邪那岐**、母神は **伊邪那美**。

さらに別段で：

> 神産巣日御祖命に **大宜都比売神** を保食神として食物を供する

→ 五穀の起源神（須佐之男命に殺されて五穀を生じる）。

→ 通説では、大宜都比売命は **「阿波国そのものの神格」** であり、伊邪那岐系の高天原神の一柱として位置づけられる。

## 3. 阿波説①：『古傳書改正願稿』が伝える父神

明治期、政府が「大粟大明神（現・上一宮大粟神社）」を「**埴生屋神社**」に、「杉尾大明神」を「**天石門別八倉比賣神社**」に **改名しようとした政府方針** に対し、阿波の識者たちが古傳・古文書を確認調査して作成した **抗議文書**：

> **『上一宮大粟神社古傳書及御神号改正願稿』**

これが阿波の父神論の最重要根拠である。

### 3-1. 引用核心部

> 然レハ天石門別八倉比賣神ト申ス **天石門別ノ四字ハ御父ノ御名ヲ冠ラセ給ヘル也**

→ 「天石門別八倉比賣」の **「天石門別」の四字は父神の名を冠したもの**。

> **栲幡千千姫命 佐那神社ニ坐テ天手力男神ト共ニ御戸開之神テフ御称ヲ頁ヒ坐ルハ 天手力男神 亦名 天石門別神 ニテ 御父也**

→ 栲幡千千姫命は **佐那神社（佐那河内）** で天手力男神と共に祀られる。それは **天手力男神（亦名 天石門別神）が父神** だからである。

### 3-2. 結論

```
天手力男神（＝天石門別神）
   ┃
   ┗━━ 御子：栲幡千千姫命（＝大宜都比売命の異名）
                  ┃
                  ┗━━ 配偶神：積羽八重事代主神
```

→ **大宜都比売命（栲幡千千姫命）の父は天手力男命（＝天石門別神）**。

### 3-3. 父神冠詞論の系譜的補強

「天石門別」の冠詞を父神の名と読む論理は、

- **天石門別八倉比賣神社**（国府町矢野）：父・天石門別神＋娘・八倉比賣神
- **天石門別豊玉比賣神社**（『阿波国風土記編輯雜纂』）：父・天石門別神＋后神・天石門別八倉姫＝豊玉姫
- **天石門別安國玉主天神社**（土佐国）：天石門別＋安国玉主

の **三社すべて** に適用される。延喜式神名帳の全国2861社中、「天石門別＋神名」となっているのはこの3社のみで、阿波・土佐に固有の **父娘 or 夫婦祭祀** の様式と読める。

→ 出典：awa-otoko（2016-01-14）大宜都比売命の父は天手力男命 （[出典](https://awa-otoko.hatenablog.com/entry/2016/01/14/003629)）

## 4. 阿波説②：『粟国造粟飯原家系図』が示す異名群

一宮神社所蔵の「**阿波女社宮主祖系**」を取り入れた『粟国造粟飯原家系図』には、「**粟国魂 大宜都比売命**」の異名として以下が列挙される：

| 異名 | 意味・解釈 |
|---|---|
| 大阿波女神（おおあわめ） | 阿波の大女神 |
| 阿波女神（あわめ） | 阿波女神（同上の短縮形） |
| 阿波波神（あわわのかみ） | 阿波の波（海神性） |
| 阿波神 | 阿波そのもの |
| **天津羽羽神**（あまつはは） | 天の母神／天背男命の娘（『斎部宿祢本系帳』） |
| **天石門別八倉比賣神** | 父神冠詞＋娘 |
| **天石門別豊玉比賣神** | 父神冠詞＋娘 |

→ これらすべてが **同一神＝大宜都比売命** の異名であるとされる。

### 4-1. 異名チェーンの統合

大宜都比売命 ＝ 大粟姫 ＝ 大阿波女神 ＝ 阿波咩命 ＝ 天津羽羽神 ＝ **八倉比賣命** ＝ **栲幡千千姫命** ＝ 豊玉比賣命 ＝ 大日孁命（音韻置換）

これは阿波説における **「神名の重層性」** の典型例で、

- 単一の神格が
- 異なる地域・時代・氏族・側面によって
- 多数の名で呼ばれた

ことを示す。記紀の整理過程でこれらが別神格として記述されたために混乱が生じた、と阿波説は主張する。

## 5. 八倉比賣命との同一神論

八倉比賣命と大宜都比売命を同一神とする論理は、四層の根拠の重なりで成立する：

### 5-1. 第1層：系図的根拠

『粟国造粟飯原家系図』が両神を **明示的に同一神と記載**（前述）。

### 5-2. 第2層：音韻置換の根拠

```
大粟姫（おおあわひめ） ← 本来の名
       ↓
大日孁（おおひるめ）    ← 音相似による置換
```

awa-otoko 氏が『改正願稿』から引用：

> もともとの祭神 **大粟姫（おおあわひめ）に聞こえがちかい大日孁神（おおひるめ）に置き換え**、冠に天石門別を付けた、天石門別八倉比賣神社として、天石門別豊玉比賣神社の存在を消してしまった。

→ **意図的なすり替えによって、大粟姫の名が大日孁（天照大神）に置き換えられた**。

### 5-3. 第3層：父神の一致

両神とも父神は **天手力男命（＝天石門別神）**（『改正願稿』）。同じ父神を共有する以上、両神は同一またはきわめて近縁である。

### 5-4. 第4層：祭祀地の連続性

```
上一宮大粟神社（神山町神領） ── 大宜都比売命
        ↓ 鮎喰川流域
鬼籠野（中一宮）           ── 大宜都比売命
        ↓
一宮神社（一宮町）         ── 大宜都比売命 ＋ 天石門別八倉比賣命（並祀）
        ↓ 鮎喰川を挟んで対岸
天石門別八倉比賣神社（国府町矢野） ── 大日孁命（＝大粟姫の置換）
```

→ 上流から下流へ、神名を変えながら **同じ大宜都比売命** が祭祀されている。一宮神社の **拝礼順序** には「**上一宮大粟神社の方向へ拝礼**」が古来組み込まれており、両神同一の暗号的記憶として機能している。

## 6. 系譜の三層モデル

阿波説における大宜都比売命の系譜は、三層構造で理解できる：

### 6-1. 第1層：祖父神（『斎部宿祢本系帳』）

```
神魂命 ‐ 角己利命 ‐ 天底立命 ‐ 五十狭布魂 ‐ 伊加志保魂命 ‐ 天背男命 × 八倉比賣命
```

→ 神魂命の五世孫・天背男命（亦名 天石門別命）が祖父神。

### 6-2. 第2層：父神（『改正願稿』）

```
天手力男命（＝天石門別神＝天背男命：平田篤胤の「一神異名」説で同一）
   ┃
   ┗━━ 御子：大宜都比売命（＝栲幡千千姫＝八倉比賣＝大日孁＝大粟姫）
```

→ 阿波説では、**「祖父神」と「父神」は同一**（天背男命＝天手力男命）。世代論的には父神として位置づけられる。

### 6-3. 第3層：配偶神と御子神（『粟国造粟飯原家系図』『斎部宿祢本系帳』）

```
大宜都比売命（＝天津羽羽神）
   ┃
   ┣━━ 夫：積羽八重事代主神
   ┃
   ┗━━ 御子：御間都比古色止命（長国造の祖）／天香山命（？）など
```

→ 海人族の祖・事代主と婚姻し、長国・海人系・出雲系の祖神を産む。

### 6-4. 三層モデルの統合系図

```
           神魂命
              ↓
        （五世）
              ↓
天背男命＝天石門別命＝天手力男命  ×  八倉比賣命
                      ↓
        ┌─────────────┴─────────────┐
        ↓                                ↓
   天日鷲翔矢命                  栲幡千千姫＝大宜都比売命
   （阿波忌部祖）                  （阿波国魂神＝八倉比賣）
                                        ↓
                                積羽八重事代主神 ×
                                        ↓
                                  御間都比古色止命
                                    （長国造祖）
```

→ **阿波忌部（天日鷲）と阿波国魂（大宜都比売）が、同じ父神・天手力男命のもとで「兄弟関係」となる**。これが阿波説の根幹の系譜論である。

## 7. 別伝：高皇産霊尊（高木神）の御子としての位置

『古事記』および『日本書紀』の一書には、栲幡千千姫命を **高皇産霊尊（高木神）の娘** とする伝がある。

> 高皇産霊尊の女、栲幡千千姫を以て、天忍穂耳尊に配せて妃と為す（『日本書紀』神代下・一書）

阿波説では、栲幡千千姫＝大宜都比売命と同一視するため、この別伝は **「大宜都比売命＝高皇産霊尊の御子」** という系譜論を派生させる。すなわち：

- 通説（『古事記』本文）：伊邪那岐・伊邪那美の御子
- 阿波説（『改正願稿』）：天手力男命（＝天石門別神）の御子
- **別伝（『書紀』一書）：高皇産霊尊の御子**

の三系譜が併存することになる。

阿波説の立場では、高皇産霊尊は **天背男命＝天手力男命と同一の祖父神階の神格** として読み替えられる場合があり、この別伝も「父神＝天手力男命」論と矛盾せず、**世代差を生んだ系図的圧縮の結果** として位置づけられる。すなわち、

```
高皇産霊尊（＝祖父神格） → 栲幡千千姫＝大宜都比売命
天手力男命（＝父神格）   → 栲幡千千姫＝大宜都比売命
```

の両系譜は、阿波説では **同一の神統譜が編纂段階で世代を圧縮・分割された痕跡** とみなされる。詳細は本ノート §三層モデルを参照。

## 8. 通説との関係――「異伝」の意味

通説（『古事記』）では、

- 大宜都比売命 ＝ 伊邪那岐・伊邪那美の子
- 栲幡千千姫命 ＝ 高皇産霊神の娘
- 八倉比賣命 ＝ 大日孁命（天照大神）

として、三神は **完全に別神格** である。阿波説は通説と矛盾するように見えるが、

### 8-1. 阿波説の論理

1. **記紀は中央朝廷の編纂** であり、阿波（粟国・忌部の本拠地）の独自伝承は **削除・改竄** された
2. 阿波内部の系図文献（『改正願稿』『粟国造粟飯原家系図』『斎部宿祢本系帳』）は、**抹消された伝承を断片的に保存** している
3. 『古事記』の「大宜都比売命＝阿波国」は、**阿波の国魂神の重要性を一行に圧縮した結果** に過ぎない

### 8-2. 通説側の根拠

- 『古事記』は8世紀初頭の編纂で、阿波内部の系図文献は江戸〜明治期の写本・編纂であり、**史料的に新しい**
- 平田篤胤の「一神異名」説は学説であって史実ではない
- 神名の異名関係は **後世の解釈** であり、本来の神格は記紀記述通り

### 8-3. 阿波説の反論

- 『阿波国風土記編輯雜纂』『斎部宿祢本系帳』『古屋家家譜』『新撰姓氏録』など、**9〜10世紀の古層史料** にも、阿波説の系譜の片鱗が確認できる
- 延喜式神名帳の「天石門別」を冠する3社が阿波・土佐に集中する事実は、**この地域に固有の祭祀構造があった** ことの物的証拠
- 太政官符（1070年）の「**邦国之大典**」は、八倉比賣神が **国家祭祀レベル** で重要視されていた歴史的事実

→ 通説と阿波説は、**「史料の新旧」と「祭祀の集中」のどちらに重みを置くか** の問題に収束する。阿波説は **後者** を重視する立場である。

## 9. 補論：「大粟姫の父は天手力男命」という主張の意味

この一見奇異な主張が、阿波説の中で持つ理論的位置を整理する：

### 9-1. 意味1：阿波説の中心的系譜構造の確立

- **佐那河内（佐那縣）** = 天手力男命の本拠
- **国府町矢野（天石門別八倉比賣神社）** = 娘・大宜都比売命の祭祀地
- **神山町神領（上一宮大粟神社）** = 大宜都比売命の元宮

の **三角祭祀構造** が、父娘関係によって統合される。

### 9-2. 意味2：阿波忌部と粟国造の血縁的接続

- 天日鷲命（阿波忌部の祖） ＝ 天背男命の子
- 大宜都比売命（阿波国魂） ＝ 天手力男命の子
- **天背男命＝天手力男命** であれば、両者は **兄妹関係**

→ 阿波忌部氏（祭祀氏族）と粟国造（土着王権）の **血縁的接続** が成立し、阿波の祭政両権が単一の祖父神に由来することになる。

### 9-3. 意味3：伊勢神宮内宮の同殿坐神との接続

伊勢神宮内宮は天照大神と **天手力男神**（左方・神体は弓）・**万幡豊秋津姫命**（右方・神体は剣＝栲幡千千姫の亦名）を同殿で祀る。これは：

- 天照大神（栲幡千千姫の子・天忍穂耳の子＝瓊瓊杵尊系）
- 天手力男神（父）
- 栲幡千千姫命＝大宜都比売命（母）

という **三世代血縁関係** を皇祖祭祀に組み込んだ結果と読める。**伊勢神宮内宮の同殿祭祀は、阿波の父娘祭祀（佐那河内＋気延山）を継承したもの** という解釈が成立する。

## 10. まとめ：父神論が指し示す阿波説の構造
