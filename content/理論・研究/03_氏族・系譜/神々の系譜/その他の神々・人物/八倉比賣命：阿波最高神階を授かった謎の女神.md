# 八倉比賣命：阿波最高神階を授かった謎の女神

八倉比賣命（やくらひめのみこと）は、徳島市国府町矢野・気延山に鎮座する **延喜式内 名神大社「天石門別八倉比賣神社」** の祭神。承和8年（841）に従五位下、元暦2年（1185）に **正一位** を授かり、**阿波国で最高位の神階** を持つ女神となった――にもかかわらず、「八倉比賣神」が一体誰であるかは記紀のどこにも記されておらず、現在に至るも **完全には解明されていない** 古代史最大の謎の一つである。

本ノートは、八倉比賣命の比定論争（大日孁尊／大宜都比売命／第三の神）と、その **父神**・**配偶神**・**御子神** をめぐる諸系図の交差を整理し、特に **「大宜都比売命との同一神論」** を中心に位置づける。

## 📜 神階昇叙の履歴――阿波最高位への道

『続日本後紀』『日本三代実録』『中右記』所引『阿波国徴古雑抄』『太政官符』により、八倉比賣神の神階昇叙は次の通り：

| 年 | 西暦 | 神階 | 典拠 |
|---|---|---|---|
| 承和8年 | 841 | 正八位 → **従五位下** | 『続日本後紀』 |
| 仁明朝 | 841 | （正五位下に再叙） | 当社略記 |
| 貞観13年 | 871 | **従四位上** | 『日本三代実録』 |
| 元暦2年 | 1185 | **正一位** | 当社略記（後鳥羽天皇） |

延喜式神名帳（927年）編纂時点の **阿波国全式内社の神階序列**：

```
正四位上：天石門別八倉比賣神           ← 阿波最高位
従四位上：葦稲葉神／大麻比古神
従四位下：天日鷲神                    ← 阿波忌部祖
従五位上：鹿江比賣神／埴生女屋神／白鳥神
従五位下：伊射奈美神／伊比良咩神／船尽比賣神
```

→ **阿波忌部の祖神・天日鷲神（従四位下）よりも、阿波の総鎮守・大麻比古神（従四位上）よりも上位** ――この事実は決定的に重要である。

> 平安時代における国家の安寧や存続に直結する力、霊験を持っていると信じられていた神でなければ、これほどの神階は授からない。（kohun-jinjya blog）

## 🏛 邦国之大典――太政官符が証言する国家祭祀

延久2年（1070年）6月28日の **太政官符**（『阿波国徴古雑抄』所収、関白内大臣師通の記）：

> 八倉比賣神の **祈年月次祭は邦国之大典也** として、奉幣を怠った阿波国司をきびしく叱っている

太政官符は **天皇の裁可もしくは太政官会議の決定** を受けて発給される **律令制下の最高公文書**。地方の式内社の祭祀を「邦国（日本国）の大典」と公的に位置づけ、現地国司を叱責した記録は極めて異例である。

→ 11世紀の時点で **阿波の現地は神の正体を忘れていた** が、**中央朝廷はその重要性を認識し続けていた**。この非対称性こそ、八倉比賣神が「**抹消された記憶の上に成立する神格**」であることを示唆する。

→ 出典：goutara-blog（2013-07-07）天石門別八倉比賣略記 （[出典](https://goutara.blogspot.com/2013/07/blog-post.html)）

## 🔀 比定論争――八倉比賣神は誰か

延喜式神名帳「阿波国 名方郡 天石門別八倉比賣神社」の論社は3社あり、それぞれ祭神が異なる：

| 論社 | 所在地 | 祭神 | 阿波説的解釈 |
|---|---|---|---|
| 天石門別八倉比賣神社 | 徳島市国府町矢野 | **大日孁命**（＝天照大神） | 神社最有力候補。御本記は天照葬儀記録 |
| 上一宮大粟神社 | 名西郡神山町神領 | **大宜都比売命** | 阿波の国魂神。元社可能性 |
| 一宮神社 | 徳島市一宮町 | **大宜都比売命 ＋ 天石門別八倉比賣命** | 両神並祀 |

### 説1：八倉比賣＝大日孁尊（天照大神）

#### 根拠

- 国府町矢野の天石門別八倉比賣神社の **境内由緒書** が明記
- 当社所蔵『**天石門別八倉比賣大神御本記**』は **天照大神の葬儀執行の詳細な記録** として読まれる
  - 道案内：伊魔離神
  - 葬儀委員長：大地主神
  - 木股神／松熊二神
  - 神衣を縫った広浜神
  - 八百萬神のカグラを「**嘘楽（うそらく）**」と表記＝葬儀の意
- 折口信夫は天照大神を三種に分類し、「**阿波における天照大神は水の女神に属する、もっとも威力ある神霊**」と論じた
- 銅板葺以前の大屋根棟瓦の **一対の龍の浮彫** ＝水の女神との習合
- 御神符に「**火付せ八倉比賣神宮**」と明記＝火事から守る神＝水神性

#### 反論

> 大日孁女命が天石門別八倉比賣神だとすれば、皇祖神で最高神の天照大神に神階が授けられるのっておかしくないか？（kohun-jinjya blog）

阿波国学者の **城福勇** は『わが残照：阿波郷土史研究』で、また明治政府の **教部省『特選神名牒』**（1876年）も、『天石門別八倉比賣神社本記』を **偽書** と断じる。『特選神名牒』には阿波出身の国学者 **小杉榲邨** が編者として加わっており、この判定は重い。

### 説2：八倉比賣＝大宜都比売命（大粟姫＝大阿波女神）

#### 根拠

「阿波女社宮主祖系」を取り入れた **『粟国造粟飯原家系図』**（一宮神社所蔵）に、積羽八重事代主神の后神「**粟国魂 大宜都比売命**」の **別名群** として次の異名が列挙される：

> 大阿波女神（おおあわめ）／阿波女神（あわめ）／阿波波神（あわわのかみ）／阿波神／**天津羽羽神**（あまつはは）／**天石門別八倉比賣神**／**天石門別豊玉比賣神**

→ つまり、大宜都比売命と八倉比賣神は **同一神** であることが系図で明示される。

さらに **音韻置換論**：

```
大粟姫（おおあわひめ）  ⇒  大日孁（おおひるめ）
```

awa-otoko氏（『上一宮大粟神社古傳書及御神号改正願稿』に基づく）：

> もともとの祭神 大粟姫（おおあわひめ）に聞こえがちかい大日孁神（おおひるめ）に置き換え、冠に天石門別を付けた、天石門別八倉比賣神社として、天石門別豊玉比賣神社の存在を消してしまった。

→ **大粟姫 → 大日孁** という意図的な祭神名のすり替え。明治期、政府が「大粟大明神（現・上一宮大粟神社）」を「埴生屋神社」に、「杉尾大明神」を「天石門別八倉比賣神社」に改名しようとしたとき、当時の阿波の識者たちが『改正願稿』を作成して抗議した。この抗議文書がこの音韻置換論の核心的根拠である。

→ 出典：awa-otoko（2016-01-11）八倉比賣神社は天石門別豊玉比賣神社だった （[出典](https://awa-otoko.hatenablog.com/entry/2016/01/11/232255)） ／ awa-otoko（2016-01-14）大宜都比売命の父は天手力男命 （[出典](https://awa-otoko.hatenablog.com/entry/2016/01/14/003629)）

#### 補強根拠

- 神階の高さ：「阿波で最高の神階を授かった女神」は **阿波の国魂神＝大宜都比売命** が最も自然
- 国家祭祀の対象：「邦国之大典」と称されるのは **五穀豊穣の神格**＝大宜都比売命と整合
- 一宮神社の祭神並祀：「大宜都比売命 ＋ 天石門別八倉比賣命」と並べることは **両神同一の記憶を分割して保存** したと読める
- kohun-jinjya 氏の総括：「やはり『天石門別八倉比賣神 ＝ 大宜都比売命』に分があるように思う」

### 説3：第三の神（独立した阿波固有の最高女神）

#### 根拠

- 『古事記』『日本書紀』にも一切登場しない神名「八倉比賣」が、平安朝廷の最高神階を獲得している事実
- 大日孁が天照大神ならば臣下の神階を授ける対象として不適切（皇祖神を超越的に扱う制度上の不整合）
- 大宜都比売命は『古事記』に登場するが、八倉比賣としての異名は阿波内部の伝承のみで、外部典拠なし
- kohun-jinjya 氏：「天石門別八倉比賣神は、**卑弥呼でもなく天照大神でもない阿波固有の最高神** として祀られていたことは確か」

→ つまり、八倉比賣命は **阿波の独自固有神** として存在し、後世に大日孁・大宜都比売命と習合・置換されていった、という見方。

## 👨‍👩‍👧 父神論――八倉比賣命の系譜

八倉比賣命の **父神**（または **配偶神**）として、複数の系図文献が並存する：

### 系図1：『斎部宿祢本系帳』（洲宮神社祠官・小野家所蔵）

> 神魂命 ‐ 角己利命 ‐ 天底立命 ‐ 五十狭布魂 ‐ 伊加志保魂命 ‐ **天背男命** ‐ 天日鷲翔矢命
>
> 天背男命の **后神は八倉比賣命**

→ **八倉比賣命は天背男命の后神**、その子が阿波忌部の祖・天日鷲翔矢命。
→ つまり八倉比賣命は **阿波忌部の祖母神**。

### 系図2：『古屋家家譜』（大伴連系図）

> 高皇産霊尊 ‐ 安牟須比命 ‐ 香都知命 ‐ 天雷命 ‐ **天石門別安国玉主命** ‐ 天押日命
>
> 天石門別安国玉主命の注記：「一名 大国栖玉命、一名 大刀辛雄命（たちからおのみこと）、**妻神 八倉比売命**」

→ 八倉比賣命は天石門別安国玉主命（一名 大刀辛雄命＝**天手力男命**音通）の妻。

### 系図3：『阿波国風土記編輯雜纂』

> 天津國玉神ノ御子 天日鷲命ハ 即日向皇子ニテ 是天石門別神 其御霊ヲ倭大國玉神トイフ
> **天石門別神 櫛磐竃神ノ后神ヲ 天石門別八倉姫トイフ**
> 次妃豊玉姫ハ 椎根津彦ノ祖ナリ

→ 天石門別神（櫛磐竃神）の后神が「**天石門別八倉姫**」。これは『斎部宿祢本系帳』の天背男命（亦名 天石門別命）と八倉比賣命の夫婦関係と一致する。

### 系図4：『上一宮大粟神社古傳書及御神号改正願稿』

> 然レハ天石門別八倉比賣神ト申ス **天石門別ノ四字ハ御父ノ御名ヲ冠ラセ給ヘル也**
>
> 栲幡千千姫命 佐那神社ニ坐テ天手力男神ト共ニ御戸開之神テフ御称ヲ頁ヒ坐ルハ **天手力男神 亦名 天石門別神 ニテ 御父也**

→ 八倉比賣神社の **「天石門別」の四字は父神の名を冠したもの**。栲幡千千姫命の父も天手力男神＝天石門別神。

### 父神論の収束点

四つの系図はそれぞれ細部は異なるが、共通する論理構造を持つ：

```
天石門別神（＝天背男命＝天石門別安国玉主命＝天手力男命）
   ┃
   ┣━━ 妻 ＝ 八倉比賣命 ━━━━━━━━━━┓
   ┃                                    ┃
   ┗━ または ━ 父 → 八倉比賣命（御子）  ┛

御子神：
   ・天日鷲翔矢命（阿波忌部の祖：『斎部宿祢本系帳』）
   ・栲幡千千姫命＝大宜都比売命（『改正願稿』）
   ・天津羽羽命（事代主の妻：『斎部宿祢本系帳』『土佐風土記』）
```

→ つまり、八倉比賣命は **「天石門別神系の中心女神」** として、阿波の主要神格群（忌部祖神・国魂神・海人族妃神）の **母 or 妻** として位置づけられる。父神論争は、結局のところ **同一神を異なる系図文脈で語っている** に過ぎない可能性が高い。

## 🌸 「大宜都比売命との同一神論」の論理構造

八倉比賣命と大宜都比売命を同一神とする最大の論証は次の連鎖：

### ① 異名のチェーン

**大宜都比売命** ＝ 大粟姫 ＝ 大阿波女神 ＝ 阿波女神 ＝ 阿波咩命 ＝ 阿波波神 ＝ **天津羽羽神** ＝ **天石門別八倉比賣神** ＝ **天石門別豊玉比賣神** ＝ 栲幡千千姫命

これらは『粟国造粟飯原家系図』『改正願稿』その他により系図的に裏付けられる。

### ② 父神の一致

天手力男神（＝天石門別神）が、

- 八倉比賣命の **父** とする系図（『改正願稿』）
- 栲幡千千姫命の **父** とする系図（『改正願稿』）
- 大宜都比売命の **父** とする系図（『改正願稿』、awa-otoko 解釈）

→ **三神は同じ父神を共有** することにより、結局 **同一神** とされる。

### ③ 配偶神の一致

- 大宜都比売命の夫 ＝ 積羽八重事代主神（『粟国造粟飯原家系図』）
- 天津羽羽命の夫 ＝ 八重事代主命（『斎部宿祢本系帳』）
- → 同じ配偶神を持つ＝同一神

### ④ 祭祀地の親近性

- **上一宮大粟神社**（神山町神領）：大宜都比売命の本宮
- **天石門別八倉比賣神社**（国府町矢野）：気延山西麓
- **一宮神社**（一宮町）：両神並祀＝両神同一の証

→ 鮎喰川沿いに上流から下流へ「神領（上一宮）→ 鬼籠野 → 一宮 → 矢野（杉尾山）」と展開し、**大宜都比売命の祭祀は段階的に下流に分祀されていった**（awa-otoko 説）。

### ⑤ 「大粟姫 → 大日孁」音韻置換

```
おおあわひめ
  ↓
おお（あ→ひる）め    ※「あわ」を「ひる」に置換
  ↓
おおひるめ（大日孁）
```

『改正願稿』はこの置換を **意図的な計画** として告発する：

> [大日孁の] 訓相近ク似タルヨリ大日孁命ト誤リシモノ也、其ハ儒證ニ考ヘ合シテ知ルベキ㕝アリ

（※ 文中の「㕝（こと）」には「嘘」の意が含まれると awa-otoko は解釈）

### ⑥ 卑弥呼との関係

奥の院・五角形祭壇（青石木口積、鶴石・亀石の「つるぎ石」）は **卑弥呼の墓** と一説に言われる。一帯から江戸時代まで大量の **丹（朱）** がしみ出していた（→ 阿南市・若杉山辰砂採掘遺跡が時代と一致する唯一の水銀朱鉱山）。

『魏志倭人伝』の「朱を用いる習憤」と整合し、**阿波＝邪馬台国** の物証として位置づけられる。

## 🪶 「天石門別」の冠詞をめぐる二解釈

延喜式の「天石門別八倉比賣神社」の社名構造には二つの解釈がある：

### 解釈A：形容辞説（天石門を開いた神＝天照系）

「天石門別」を「**天石門を別（わ）けて出てきた神**」の意とし、天岩戸開きで現れた天照大神＝大日孁＝八倉比賣に冠した形容辞とする。

#### 弱点

- 延喜式は **二柱を祀る場合は「二座」と明記** する。「天石門別八倉比賣神社」は **一座** なので、形容辞説の方が文献的に整合
- ただし、八倉比賣が天照ではなく大宜都比売命とすれば、形容辞としての適合性に疑問

### 解釈B：父神冠詞説（天石門別神＋八倉比賣＝父娘）

『改正願稿』が明言する通り、**「天石門別」の四字は父神の名** を冠した。社名は「**父神・天石門別神の娘である八倉比賣神を祀る社**」の意。

#### 補強

- 天石門別八倉比賣神社の **境内末社・箭執神社** の祭神は **櫛石窓神・豊石窓神**（『古事記』天石戸別神の亦名）。これは **父神の祠を末社として配置** したものと読める。
- 摂社・松熊神社の祭神は **天手力男命・天宇受売命**（後者は佐那河内村大宮神社からの分祀）。**天石門別神＝天手力男神** が摂社で祀られる構造と整合。
- 父神は **佐那河内（佐那縣）** に本拠を持つ天手力男命であり、娘の八倉比賣は **国府町矢野** に祀られた――**夫婦・父娘の二極祭祀構造**。

### 解釈Cの可能性：天石門別神（父）と八倉比賣（娘）の同体祭祀

両神を同体（神格的に同一）として祀ったがゆえに、「二座」とせず「天石門別八倉比賣神」一柱として表記した、という第三解釈。

延喜式神名帳全国2861社の中で「**天石門別＋神名**」となっている神社は、

- 阿波国：**天石門別八倉比賣神社**
- 阿波国：**天石門別豊玉比賣神社**
- 土佐国：**天石門別安国玉主天神社**

の **3社のみ**。「天石門別」の冠詞は、阿波・土佐の **海洋連環地域に固有の祭祀形態** を示すと推定される。

## 🏛 杉尾山と気延山――神社の遷座

『天石門別八倉比賣大神御本記』には、八倉比賣神の **遷座** が記される：

> 而後経二千百五年而到小治田御宇元年龝八月 太神毛原美曽持爾託曰久：
> 吾宮地遙爾高峻志此 故爾神主祝部巫乃百乃蒼生爾到萬天参詣拝趨爾倦労奈牟
> 杉乃小山者不高不低不遠不近直善地也 彼嶺爾欲遷座止

→ **当初の鎮座地は気延山頂上**、後に **杉尾山に遷座**。

気延山に降臨し、五百箇野薦・八十玉籤を採取（伊魔離神）、大地主神・木股神に道案内され、広浜神に時節の御衣を奉られ、最終的に気延嶺の下津磐根に鎮座――この一連の地名群は、現在も気延山周辺に **早渕（鮎喰川）／五十串野／美阿閇野／髪狭野／矢倉郷／屋度利／御衣足** として残存している。

> 「気延山々頂より移遷、杉尾山に鎮座してより二千百五年を経ぬ」（安永2年＝1773年の古文書）

逆算すると **西暦338年**（4世紀初・古墳発生期）。ただし御本記原文は「小治田御宇元年（推古元年＝593年）から2105年さかのぼる」とも読め、**紀元前1512年** まで遡る可能性もある。

#### 奉納古歌

## 🧿 御陵と神葬祭――『天石門別八倉比賣大神御本記』の異常な記録

奥の院・**五角形祭壇** が天照大神（または八倉比賣命）の **陵墓** とされる根拠は、御本記が **神葬祭（神の葬儀）** の詳細を記している点にある：

| 役割 | 神名 |
|---|---|
| 道案内（先導） | **伊魔離神** |
| 葬儀委員長 | **大地主神** |
| 葬地確保 | 木股神 |
| 棺護衛 | 松熊二神 |
| 神衣（経帷子）縫製 | **広浜神** |
| 葬列の演奏 | 八百萬神（「**嘘楽**」と表記） |

「嘘楽（うそらく）」――一般の神楽（かぐら）が祝祭であるのに対し、「嘘楽」は **葬儀の楽** を意味する造語。「嘘」字を用いる点は、後世の編纂者が「これは普通の神楽ではない」と明示する意図と読める。

→ 八倉比賣神社は **神の葬儀地** であり、奥の院の五角形祭壇は **その陵墓**――この解釈に立てば、八倉比賣神＝天照大神は **阿波で葬られた歴史的人物（卑弥呼？）** ということになる。
