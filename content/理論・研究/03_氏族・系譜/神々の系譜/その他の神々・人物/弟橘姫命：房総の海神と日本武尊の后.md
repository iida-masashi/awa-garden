# 弟橘姫命：房総の海神と日本武尊の后

> [!summary] 要旨
> 弟橘姫命（おとたちばなひめのみこと）は、記紀において日本武尊（ヤマトタケル）の后として、走水（東京湾）にて海神の怒りを鎮めるために入水したと伝えられる女性。しかし房総半島側の伝承群は、彼女の入水後の運命について記紀とは大きく異なる物語を残している――姫は死なずに千葉の浜辺に流れ着き、里人に介抱されて蘇生した、というのである。本ノートは、阿波説の文脈で弟橘姫の系譜（百嶋神社考古学では物部宗家の娘）を整理し、房総各地の「弟橘姫蘇生伝承」「弟橘姫陵伝承」を一覧する。彼女は阿波物部氏の血脈と房総（安房・上総）を結ぶ重要な接点とされる。

## 2. 系譜論――物部氏のハイブリッド血統

百嶋神社考古学による弟橘姫の系譜：

```
                   天兒屋根 ─┐
                              ├─ 息長水依姫 ─┐
                   豊受大神 ─┘                ├─ 師長姫（母）
                                              │     │
              支那津姫（豊受大神）─┐         │     │
                                    ├─ ウマシマジ（父）
                       長髄彦 ──────┘
                          ├─ ヒミコ宗女イヨ（孝霊天皇妃）
```

- **父系**：長髄彦の血を引く物部宗家（ウマシマジ＝忍山宿禰）の娘。
- **母系**：豊受大神のDNA。
- **両系**で豊受大神の血を継ぐ「ハイブリッド」。妹イヨが孝霊天皇妃であるため**天皇家にも極めて近い**。
- この血統を**隠したい誰か**の存在が、各神社の御祭神を「不詳」とする伝承操作の動機とされる。

→ 物部氏系譜の詳細は [[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配|阿波物部氏ノート]] を参照。

## 3. 記紀と『常陸国風土記』の相違

- **『古事記』『日本書紀』**：走水で入水して亡くなり、数日後に櫛や袖など遺物が浜辺に流れ着いた。
- **『常陸国風土記』行方郡条・多珂郡条**：
    > 「倭武天皇の后、大橘比売命、倭より降り来て、この地に参り遇ひたまひき」
    
    日本武尊と弟橘姫が常陸の安布賀の邑（潮来・行方）で**再会**し、共に狩りを楽しんだとする。**姫は生きていた**。

`房総側で姫が蘇生 → 体力回復後に常陸で再合流`、というシナリオが地理的に整合する。

## 4. fusa資料（房総側の検証）

「未知の駅 總フサ」ブログ（fusa）の現地調査による、千葉市中央区・旧蘇我町を中心とした弟橘姫蘇生伝承の追跡記録。

### 1. 蘇我比咩神社（千葉市中央区蘇我町2-2-7）――「我れ蘇れり」の起源
- 📍 ①蘇我比咩神社：県内で唯一「弟橘姫復活伝承」を持つ式内社。社伝では入水した姫が浜辺に流れ着き里人に蘇生され「我れ蘇れり」と宣り給うたことから「蘇我の里」と称した。男千木・五七桐紋（男神の紋）から、長らく主祭神は「不詳」とされてきた（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633771550.html)）
- 同社の御祭神構成（伊勢大神・蘇我比咩・春日・経津主・武甕槌・天兒屋根・応神・千代春稲荷・御霊）は、弟橘姫の血族を覆い隠す**カモフラージュ**との解釈。
- 「**スカ → スガ → ソガ**」の音韻転訛論。蘇我比咩神社の前身は**須賀（スガ）神社**で、姫を助けた人々がスサノオ系の氏族であった可能性。後に蘇我氏が当地を統治して「蘇我」の字に転換されたとする説。
- 蘇我氏側の解釈は [[阿波蘇我氏：石井町・曽我氏神社を源流とする中央進出の軌跡|阿波蘇我氏ノート]] と相互参照。

### 2. 大巌寺町・浅間神社／鷲宮神社――製鉄地と原氏（千葉氏四天王）
- 📍 ②大巌寺の開基・原胤栄は千葉氏四天王で粟飯原氏と同祖。境内「龍が沢」は古代の野たたら（製鉄）地候補。浅間神社は古墳の可能性。鷲宮神社の真の御祭神は天日鷲命または日本武尊（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633772926.html)）
- 原氏（千葉氏配下）と粟飯原氏が「妙見社神前の元服式で御供を務める家柄」であった点は、[[粟飯原氏：千葉氏との繋がりと妙見・月信仰の系譜|粟飯原氏ノート]] と接続。

### 3. 赤井稲荷神社・赤井薬師堂――産鉄地の痕跡
- 📍 ③稲荷社なのに男千木・狛狐なしの赤井稲荷神社は、大巌寺四社の「愛宕社」（カグツチ＝金山彦）であった可能性。地名「赤井」は地下水の鉄分酸化に由来。古代千葉県は豊富な鉄資源に恵まれていた（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633790539.html)）

### 4. 花輪町・子安社／大森町・神明神社
- 📍 ④旧蘇我町の御祭神「不詳」が連続する謎。住んでいた人々がそっくり移動したか、秘密にしすぎたかのいずれか（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633791207.html)）

### 5. 宮崎神社・慈眼寺――旧大宮神社
- 📍 ⑤旧称「大宮神社」で御祭神は天宇受賣命（＝豊受姫）。男千木。境内に神武天皇の石宮あり。慈眼寺は産鉄民との関連が示唆される（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633791606.html)）

### 6. 千葉寺町・瀧蔵神社――姫が療養した最有力地
- 📍 ⑥行基開山（和同2年・709）の千葉寺境内に鎮座。御祭神は海津見神（豊玉彦＝天太玉）、境内社に青龍神社（豊玉姫）。縄文海進時も陸地で、姫の療養地として最有力。「星の民」（海人族・忌部・白族・出雲系・物部の融合）の痕跡（fusa/房総側） （[出典](https://ameblo.jp/books-fu-sa/entry-12633792532.html)）

## 5. 房総各地の弟橘姫伝承スポット

fusa「房総ヤマトタケル伝説」シリーズに記録された、弟橘姫関連の主要神社・地名：

### 入水・漂着・運搬の道筋
- **走水（東京湾）** で入水
- **袖ヶ浦市・吾妻神社**（三黒字西大縄）：丸山古墳。姫の遺骸を本納に運ぶ途上で動かなくなり当地に葬ったとする伝承。臂松（ひじまつ）の標識。
- **袖ヶ浦市・吾妻神社**（吉野田）：姫の御袖が漂着し「袖ヶ浦」の地名由来となる。
- **袖ヶ浦市・三黒（みくろ）**：御骸（ミムクロ）の転訛。
- **富津市・貴布禰神社**：入水時の白布が漂着、「布流津（ふるつ）→富津」。
- **富津市・吾妻神社**（西大和田）：「ああ吾が妻よ」の地名由来。
- **茂原市・橘神社**（本納町御船形）：式内社。姫を葬ったとする古墳と「吾妻ヶ池」。
- **茂原市・橘神社**（長尾）：流れ着いた姫の衣を神璽とする。
- **市原市・弟橘媛神社**（皆吉字橘山）：橘禅寺後方の山中。
- **長南町・野見金山の鏡塚**：姫の遺鏡を埋めたとされる場所。

### 「姫は生きていた」系（蘇生・常陸合流説）
- 千葉市中央区・旧蘇我町（蘇我比咩神社シリーズ⑥か所、上述）

これらの伝承が**並立的に存在する**事実は、「**入水後に複数の姫が漂着し、本物の弟橘姫と他の姫の遺体が混同された**」という蘇我比咩神社シリーズ①の推論を補強する。

## 6. 関連する論点

### 「アヅマハヤ」の再解釈
- 古代朝鮮語で「**田舎を伐る**」の意とする説（fusa「⑥小鷹神社」記事より）。日本武尊が姫を慕って嘆いた言葉とされてきた「アヅマハヤ」は、後世の創作であり、東国制圧の意図を覆い隠す装飾であった可能性。
- 詳細は 📍 小鷹神社（市原市）の物部蝦夷虐殺伝承 （[出典](https://ameblo.jp/books-fu-sa/entry-12635360594.html)） を参照。

### 阿波物部氏との接続
- 弟橘姫の父・忍山宿禰＝物部宗家ウマシマジは、阿波・天村雲命系物部氏の祖（饒速日命）の子。同氏は剣山・吉野川流域で鉄・植林・治水を掌握した。
  → [[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配|阿波物部氏ノート]]
- 房総の山座王（長柄町・武峯神社）もウマシマジの孫であり、**阿波物部 → 房総物部** のラインが、弟橘姫の婚姻と山座王の道案内によって**ヤマト王権と接合**された構図が浮かぶ。

### 玉前神社・香取神宮の女神祭祀との関連
- 上総一宮・玉前神社の御祭神「玉依姫」と、弟橘姫の母系（豊受大神 → 師長姫）の海神系祭祀は同一の海人族文化圏に属する。
