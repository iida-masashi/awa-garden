# 葦稲葉神：天日鷲命の御子神と板野郡の稲祭祀

> [!summary] 要旨
> 葦稲葉神（あしいなばのかみ）は、延喜式神名帳に「阿波国 板野郡 葦稲葉神社」として記された式内社の主祭神。『粟飯原家略傳』に「大宜都比売命の御子神」と明記される板野郡の祖神で、天日鷲命の御子神として『古語拾遺』『安房斎部系図』の系譜と接続し、積羽八重事代主神と大宜都比売命の若室神（皇子神）とする伝承を持つ、忌部祭祀と粟国造祭祀の交差点に位置する神。本ノートは、「葦田野→板野」の地名連続性、神宅地区の三層祭祀構造、稲の神への神格の重層、大山住大明神＝葦稲葉神＝大山祇とコノハナサクヤヒメの祭祀、稲荷信仰の本源論、承和9年（842）の神階授与などを統合し、葦稲葉神を神武天皇の母方系譜の本拠・阿波忌部祭祀権の結節点として位置づける。

**葦稲葉神（あしいなばのかみ）** は、延喜式神名帳に「**阿波国 板野郡 葦稲葉神社**」として記された式内社の主祭神。『粟飯原家略傳』に **「大宜都比売命の御子神」** と明記される、**板野郡の祖神**。

葦稲葉神は **天日鷲命の御子神** として『古語拾遺』『安房斎部系図』の系譜と接続し、また **積羽八重事代主神と大宜都比売命の若室神（皇子神）** とする伝承を持つ、**忌部祭祀と粟国造祭祀の交差点** に位置する重要神。

## 2. 板野郡の地名由来――葦田野（イタノ）から板野（イタノ）へ

awa-otoko 氏が紹介する古文書：

> **板野郡と云うは葦田野（イタノ）郡なり**
> 根元である **神宅村** に **吾田鹿葦津姫（イ（ア）タカシツヒメ）の神が坐す** 郡を以ってして郡の号となりしなり。

→ 板野郡（イタノ）の名は、**「葦田野（イタノ）」** に由来する。「葦」「田」「野」――葦稲葉神社の祭神「**葦稲葉**」の名と深く呼応する。

**吾田鹿葦津姫（あたかしつひめ）** は、別名群を持つ：

- 木花開耶姫／木華開耶姫／木花之開耶姫
- 木花之佐久夜毘売／神阿多都比売／神吾田津姫
- 鹿葦津姫／豊吾田津媛／桜大刀自神

通説では「コノハナサクヤヒメ」＝**ニニギノミコトの妻、山幸彦・海幸彦の母**。

### 2-1. 葦稲葉神社と吾田鹿葦津姫の関係

awa-otoko 氏の解釈：

> 板野郡（もちろん上板町も含む）は古代より **積羽八重事代主神と大宜都比売命の領域** であり、そしてこの **二柱の皇子である若室神が葦稲葉神** として神宅村に鎮座している。

→ 葦稲葉神 ＝ **積羽八重事代主神 × 大宜都比売命の御子神** ＝ **若室神**。

awa-otoko 氏は次のような系譜的解釈を示す：

```
天石門別神（＝天手力男）
   ┃
大宜都比売命  ×  積羽八重事代主神
   ┃
   ┣━━ 若室神 ＝ 葦稲葉神
   ┃     （板野郡の御子神 ＝ 「葦田野＝板野」の祖神）
   ┃
   ┗━━ 夏之姫（？）
         ＝ 吾田鹿葦津姫（コノハナサクヤヒメ？）
```

→ **大宜都比売命の娘が吾田鹿葦津姫** ＝ コノハナサクヤヒメ。これが正しければ、コノハナサクヤヒメは **板野郡の神宅村に鎮座した阿波の女神** であり、ニニギの妻も阿波の女神となる。

### 2-2. 鹿江比賣との関係

葦稲葉神社には **鹿江比賣神社** が合祀されている。鹿江比賣 ＝ **吾田鹿葦津姫** ではなく、

> 鹿江比賣は **大宜都比売命**、吾田鹿葦津姫は **大宜都比売命の娘・夏之姫** にあたるのではないか（awa-otoko 説）

→ **二段階の女神祭祀**：

- 母神：**大宜都比売命**（＝鹿江比賣）
- 娘神：**夏之姫**（＝吾田鹿葦津姫＝コノハナサクヤヒメ）

## 3. 神宅地区の三層祭祀構造

葦稲葉神社の元社地・**神宅（かんやけ）地区** は、神宅 = 「**神の宅（館）**」の意。古代から神聖な祭祀地として三層の祭祀構造を持っていた：

### 3-1. 三層の古代祭祀

```
山際（畑地区）           ── 奥宮  ＝ 芽野原（葦稲葉神社・元地）
   ↓
山麓                     ── 里宮  ＝ 神宮寺付近（鹿江姫神社）
   ↓
田地                     ── 田宮  ＝ 殿宮（"たのみや"の転訛）
```

- **奥宮**：山際の畑地区「芽野原」――神体山「**大山**」の **男神「葦稲葉神」** を祀る
- **里宮**：山麓の「神宮寺」付近――**産土女神「鹿江比賣神」** を祀る
- **田宮**：殿宮（現・殿宮神社）――稲作の守護神 **倉稲魂命**（＝大宜都比売命＝御食津神）

### 3-2. 遷座の歴史

| 時代 | 出来事 |
|---|---|
| 古代 | 大山畑 芽野原（扇状地の頂点）に葦稲葉神社が鎮座 |
| ある時 | **山崩れで社殿倒壊** |
| → | 扇状地下端の宮ヶ谷川河畔の **鹿江姫神社** に遷座 |
| → | 鹿江姫神社も **失火で社殿焼失** |
| 現在 | 現在地の **殿宮神社** に移される（葦稲葉・鹿江姫合祀） |

→ つまり、現在の「殿宮神社」は **三層祭祀の最下層（田宮）の地** であり、上層の奥宮（葦稲葉神）と里宮（鹿江姫）の祭祀を **災害に伴って下に集約** した結果である。

→ 出典：awa-otoko（2015-08-29）葦稲葉神社は本来どこに鎮座していたのか （[出典](https://awa-otoko.hatenablog.com/entry/2015/08/29/205442)）

## 4. 葦稲葉神の神格――稲の神への重層

### 4-1. 「葦稲葉」の語義

- **葦（あし）**：水辺に生える草本（葦原中つ国の「葦」）
- **稲葉（いなば）**：稲の葉、または **因幡（いなば）**＝山陰の地名
- 全体：「**葦の生い茂る水辺で、稲を育てる神**」＝ **湿地から稲作への変化を象徴**

### 4-2. 神格の重層性

| 神格 | 内容 |
|---|---|
| **草の神** | 鹿江比賣＝野槌神（原野の女神） |
| **稲の神** | 葦稲葉翁（湿地稲作の男神） |
| **穀霊神** | 倉稲魂命＝大宜都比売命（稲荷神の本源） |
| **山住神** | 大山住（祇）大明神（神体山「大山」の主神） |
| **皇子神** | 若室神（大宜都比売・事代主の御子） |

→ **湿地→水田→山地** という地理的階梯と、**草→稲→穀霊→山住** という神格階梯が、葦稲葉神社の周辺で **一つに統合** されている。これは古代の稲作伝来期の祭祀的記憶を、地名・神社構造として保存しているとも読める。

### 4-3. 大山住大明神＝葦稲葉神

awa-otoko 氏：

> 葦稲葉神とは **大山住（祇）大明神そのもの**。本来、大山住大明神を祭祀していた **大山寺 奥の院 黒岩大明神** が大山祇大明神発祥の地であり、後年便宜上麓に降ろされたのが葦稲葉神社である。

→ つまり、葦稲葉神＝大山祇神の阿波における顕現。大山祇神は **コノハナサクヤヒメの父神** であるから、

```
大山祇神（葦稲葉神）
   ┃
   ┗━━ 鹿江比賣（妃神 ＝ 野槌神）
              ┃
              ┗━ 木花咲耶姫（吾田鹿葦津姫 ＝ 板野郡の祖神）
```

という親子三代の祭祀構造が、神宅地区に重層して残されている。

## 5. 木花咲耶姫の移動――阿波内部の遷座史

『阿波国風土記編輯雜纂』および awa-otoko 氏の調査によれば、**大山祇神と鹿江姫の娘である木花咲耶姫** は、上板町椎本野神の **椎宮神社** が元社：

```
椎宮神社（上板町 椎本野神）― 元社
   ↓ 大水で社殿流失
桜間神社（石井町）
   ↓ 再度流失
椎宮神社（名東町）
   ↓
椎宮神社（佐古）
```

→ 木花咲耶姫の祭祀は、**上板町の山麓** から **吉野川流域** に沿って下流に展開した。これは大宜都比売命系の祭祀展開（神領→鬼籠野→一宮→矢野）と地理的に並行する。

### 5-1. 石井町 曽我氏神社

石井町の **曽我氏神社** でも木花咲耶姫が祭神として祀られ、**彦火々出見尊（山幸彦）と夫婦神** とされる。これは：

- 木花咲耶姫の夫＝ニニギノミコト → 子＝山幸彦
- だが阿波の祭祀では **木花咲耶姫＝山幸彦の妻**

という、通説とは1世代ずれた系譜が伝わる。

## 6. 倉稲魂命と稲荷信仰の本源

葦稲葉神社の祭神「**倉稲魂命（うかのみたまのみこと）**」は、**御食津神（みけつのかみ）＝御狐神（みけつのかみ）** とも呼ばれ、**稲荷神の本源**。

awa-otoko 氏：

> 稲作の守護神である倉稲魂命、すなわち大宜都比売命。「**御食津（みけつ）＝御狐神**」である。**稲荷の総本山 伏見稲荷大社は、神山町神領 上一宮大粟神社の大宜都比売命と葦稲葉神社の大宜都比売命** である。

→ つまり、

```
伏見稲荷大社（京都）
   ↑
   ↑（東遷）
   ↑
上一宮大粟神社（神山町神領）― 大宜都比売命の本宮
   ↑（移動）
葦稲葉神社（板野郡神宅）   ― 大宜都比売命の御子神（若室神）と御食津神の祭祀
```

という構造で、**稲荷信仰の本源は阿波の大宜都比売命** とする。

## 7. 承和9年（842）の神階授与

『続日本後紀』承和9年（842）10月壬戌（2日）条：

> 奉授：
> 安房国 従五位下 安房大神 正五位下、無位第一后神 天比理刀咩命神
> 信濃国 無位 健御名方富命前 八坂刀売神
> **阿波国 無位 葦稲葉神**
> 越後国 無位 伊夜比古神
> 常陸国 無位 筑波女大神 並 従五位下

→ 同日に **葦稲葉神に従五位下** が授与された。同時に神階を授かった神々を見ると：

- **天比理刀咩命神**：安房大神（天太玉命）の后神＝阿波忌部の東遷地・安房
- **八坂刀売神**：建御名方命の后神＝諏訪
- **伊夜比古神**：越後の祖神
- **筑波女大神**：常陸の祖神

→ **東国の主要祭神とともに葦稲葉神が朝廷から神階を授与された** ことは、葦稲葉神が **国家祭祀の対象** として認識されていたことを意味する。阿波忌部の東遷ルート上の祭神群と同時授与されていることは、葦稲葉神＝阿波忌部の祭神という位置づけを補強する。

## 8. 「天日鷲命の御子神」としての葦稲葉神

『粟飯原家略傳』（明治10年・粟凡直粲胤）：

> 御子神 **葦稲葉ノ神ノ㘴ス地ハ板野郡** ト云フ

→ **大宜都比売命の御子神＝葦稲葉神の鎮座地が板野郡**。

『古語拾遺』『安房斎部系図』『阿波国風土記編輯雜纂』を統合した阿波説の系譜では、

```
天背男命（＝天石門別＝天手力男命）
   ┃
   ┣━━ 天日鷲翔矢命（阿波忌部祖）  ━━ 妹 天津羽羽命
   ┃        ┃                              ┃
   ┃        ┃                              ┗━ 配偶神：事代主神
   ┃        ┃                                       ┃
   ┃        ┗━ 御子：長白羽命（神麻績連祖）       ┃
   ┃                                                 ┃
   ┗━━ 大宜都比売命（大粟姫）  ───────────────────┘
              （事代主の后神）
                      ┃
                      ┗━ **若室神 ＝ 葦稲葉神**
                              （板野郡の御子神）
```

つまり、葦稲葉神は：

1. **天日鷲命の妹（天津羽羽命＝大宜都比売命）の子**
2. **事代主神の子**
3. **天日鷲命の甥**（事代主神の血を引く）

『先代旧事本紀』『古語拾遺』の系譜で **天日鷲命の御子神** として位置づけられる場合と、**事代主神の御子神** として位置づけられる場合とで、見解が分かれるが、いずれの場合も **阿波忌部・粟国造の祭祀圏の御子神** として葦稲葉神社に祀られた。

## 9. 天日鷲命の伝播と葦稲葉神の二重祭祀

awa-otoko 氏（『麻植郡からみる大宜都比売命・葦稲葉神の手掛かり』）：

> 神山神領から忌部山を越えて伝わった「**大宜都比売命・葦稲葉神**」が美郷村の一部の地域に根付いて祭祀が継承された。それが後に **麻植郡平野部に降りて、さらには吉野川を下り、上板町の「葦稲葉神」として祭祀された** のではないか。

→ つまり、**阿波内部での葦稲葉神祭祀の移動ルート**：

```
神山神領（上一宮大粟神社・大宜都比売命の本宮）
       ↓ 忌部山越え
美郷村種野（種野稲荷神社）
       ↓
麻植郡平野部
       ↓ 吉野川を下る
上板町神宅（葦稲葉神社）
```

### 9-1. 美郷村種野稲荷神社の「四方至（しほうづめ）」

種野稲荷神社には「**四方至（しほうづめ）の石**」があり、神社を中心におよそ四丁（約120m×4）の場所に立てられていた：

- 南東：楢の木の四ツ辻
- 南西：大畑の西、川田への旧道上
- 北東：種野八幡神社の上方、一本松の祠前
- 北西：宮田にあった古い祠の付近

→ 「四方至＝四至（しいし）」は、**忌部祭祀の「神の領域を示したもの」**。葦稲葉神祭祀地が **忌部の四至石** で囲まれているのは、葦稲葉神＝忌部の祭神という構造を示している。

### 9-2. 種野稲荷神社の「樫の葉」伝承

> 美郷村種野の稲荷は、遥かな昔に **樫の葉に乗って天降ってこられた** そうで、そのため川向こうを「樫の葉」と呼び、神様が降りた石を「**影向石（ようごういし）**」と呼んでいた。

## 12. 「コノハナサクヤヒメ＝板野郡の祖神」説の意味
