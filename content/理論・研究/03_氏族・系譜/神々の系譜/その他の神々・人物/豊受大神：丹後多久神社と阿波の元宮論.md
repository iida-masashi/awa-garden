# 豊受大神：丹後・多久神社と阿波の元宮論

伊勢神宮外宮の祭神 **豊受大神（とようけのおおかみ）** ――丹後の **多久神社** で「**豊宇賀能咩命（とようかのみのみこと）**」として祀られ、丹後国風土記の **羽衣伝説の天女** と同一神。阿波説では本源を **海陽町・和奈佐** に求める。本ノートは多久神社の伝承と阿波・元宮論を統合する。

> 📚 関連: 羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群, [[岡上の聖域と吉野川北岸の祭祀]], [[元宮ハブ_MOC]]

## 🎯 核心命題

豊受大神は単独の女神ではなく、**多層的同体神**：

```
阿波（海陽町・和奈佐）の天女 ＝ 原初の祭神
    ↓ 遷座
丹後（多久神社・比治山・籠神社）の豊宇賀能咩命（天酒大明神）
    ↓ 遷座
伊勢神宮外宮の豊受大神
```

## 🏔 多久神社（丹後）の概要

| 項目 | 内容 |
|---|---|
| 所在地 | 京都府京丹後市（旧 丹後国） |
| 主祭神 | **豊宇賀能咩命**（とようかのみのみこと） |
| 同体神 | **豊受大神**（伊勢外宮）／**天酒大明神** |
| 関連伝承 | 丹後国風土記逸文「奈具の社」の天女 |
| 関連遺跡 | **涌田山1号墳**ほか古墳群（古墳時代前期） |

### 「天酒大明神」――万病を治す酒の女神

丹後国風土記逸文：
> **天女よく酒を噛み造り、その酒を一杯飲めばすべての病が治る**

→ 天女（豊宇賀能咩命）は **酒造の祖神** で、その酒は霊薬。
→ 「天酒大明神」の称号の根拠。

### 涌田山1号墳と古墳時代の祭祀

多久神社の **本殿背後** には：
- **涌田山1号墳**（古墳時代前期）
- 関連古墳群

→ 弥生末〜古墳前期の **祭祀＋首長埋葬** が一体化した聖地。
→ 羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群 の **寺山古墳群（3世紀初頭）** と類似構造。

## 📜 丹後国風土記「奈具の社」の阿波対応

『丹後国風土記』逸文：
> 比治山の頂きに井があり、その名を間奈井という。
> 天女が八人降って来て水浴。
> **和奈佐老父・和奈佐老女** が衣装を隠した。
> （中略）
> 『これは、いわゆる竹野の郡の **奈具の社** においでになる **豐宇賀能賣命** なり。』

### 地名対応

| 丹後国風土記の地名 | 阿波の地名 |
|---|---|
| **和奈佐**（老父・老女の名） | **海陽町鞆浦字那佐（旧 和奈佐）** |
| 比治の里 | （阿波の対応未確定） |
| **奈具の社** | 多久神社（丹後） |

→ 「和奈佐」を冠する老夫婦の名 → **阿波の地名がそのまま物語化** された伝承の可能性。

→ 詳細：羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

## 🌐 多段階遷座論：和奈佐 → 多久神社 → 籠神社 → 伊勢外宮

```
【阿波・海陽町・和奈佐】（最古層）
  寺山古墳群（3世紀初頭）＝ 天女（豊受大神）の墓
  芝遺跡 ＝ 多地域交易の中心
  内行花文鏡 ＝ 大陸交易の物証
        ↓
【阿波・板野郡・岡上神社】（北阿波拠点）
  豊受姫命 ＝ ウカノミタマ ＝ 大宜都比売命
        ↓
【丹後・多久神社】（伝承継承）
  豊宇賀能咩命 = 天酒大明神
  涌田山1号墳ほか古墳群
        ↓
【丹後・比沼麻奈為神社】
        ↓
【丹後・籠神社】
  海部氏伝世鏡（内行花文長宜子孫八葉鏡）
        ↓
【伊勢・外宮】（最終遷座）
  豊受大神
```

→ 阿波説における **豊受大神の遷座 5段階**。

## 🌟 「丹後は出雲とは対等」――丹後王国論

note.com 記事著者（やんまあ）の見解：
> 丹後は出雲を裏切ったor出雲とは対等な力を持ち、大和朝廷についた

→ 丹後地域における豊受大神系統の信仰は、**地域的アイデンティティ** として独立した政治史的位置を持つ。

阿波説の視点では：
- 丹後は **阿波からの遷座先** であり、独自の地域王国を形成
- **海部氏ネットワーク**（阿波 ⇔ 丹後）が古代の海洋連絡軸を構成
- 多久神社・籠神社・比沼麻奈為神社 → **海部氏祭祀の3拠点**
