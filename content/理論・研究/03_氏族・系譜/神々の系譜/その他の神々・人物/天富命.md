# 天富命（あめのとみのみこと）

← ポータルへ戻る

> [!summary] 要旨
> **天富命（あめのとみのみこと）** は **天太玉命の孫** にあたる忌部の祖神格にして、**神武朝に阿波忌部を率いて東国へ渡った東遷の主導者**。『古語拾遺』（807年、斎部広成）に最も詳細な事績が伝わり、**麻・穀（かじ）の栽培伝播**、**東国総国（ふさのくに）の開拓**、**安房神社の創建**、**橿原宮の造営（天富命の率いる手置帆負・彦狭知らの後裔）** という、阿波忌部の四大事跡すべてに関わる中心人物。本ノートは天富命を **阿波忌部の東遷を体現する祖神** として総合する。

## 2. 『古語拾遺』に見える事跡

天富命の事績は **『古語拾遺』** が最重要の一次文献。神武朝の段に集中して記される。

### 2-1. 橿原宮の造営

神武天皇の即位に先立ち、天富命は祖神 **天太玉命** の命に従い、**手置帆負命（たおきほおいのみこと）・彦狭知命（ひこさしりのみこと）の裔孫**（讃岐・紀伊忌部）を率いて、**斎斧・斎鉏（いみおの・いみすき）** を用いて山材を伐り出し、**橿原宮（橿原神宮の原型）** を造営した。

> 仍りて天富命をして、手置帆負・彦狭知二神の孫をして、斎斧斎鉏を以て、始めて山材を採りて、瑞殿を構造らしむ。

→ **天富命＝神武朝の宮殿造営の現場指揮官**。中央忌部の **斎部広成自身が「祖」と仰ぐ** 神格であり、『古語拾遺』が天富命を皇統祭祀の中軸に据える理由がここにある。

### 2-2. 阿波忌部を率いた東遷

橿原宮造営後、天富命は **天日鷲命の孫（阿波忌部の本部隊）** を率い、**「肥饒の地」を求めて** 阿波国を経由し、東国へ向かう。

> 天富命をして、手置帆負・彦狭知二神の孫をして、矛・楯を造らしむ。又、**天日鷲命の孫をして、阿波国に率て往きて、麻・穀を植えしむ**。其の裔、今、彼の国に在り。**大嘗の年に、木綿・麻布を貢る**。所謂、阿波忌部の祖なり。

→ 阿波忌部の本貫地確立を **天富命の指導下** で行ったと記す。**麻・穀（かじ／こうぞ）** の栽培、**木綿・麻布の貢進**、**大嘗祭の阿波忌部由縁** がすべてこの段に集約されている。

### 2-3. 東国（房総）の開拓と安房神社創建

阿波の麻穀栽培が定着した後、天富命は **「東国の肥沃地」を求めて** 阿波忌部の **分流** を率い、**黒潮ルートで太平洋を北上**、房総半島南端に上陸。

> 又、**阿波忌部の能き地を求めて、東国に分かち遣はす**。便ち、麻・穀を植う。好麻の生ふる所、故、**総国と謂ふ**。穀木の生ふる所、故、**結城郡と謂ふ**。古語に、麻を呼びて、総と為す。今、上総・下総、二国と為すは是なり。阿波忌部の住む所、便ち、**安房郡と名づく**。今、**安房国** と謂ふ、是なり。**天富命、初め、太玉命の社を此の地に立つ、今、安房社と謂ふ、是なり**。

→ **総国・上総・下総・結城郡・安房郡・安房国** という関東地名群が、すべて **阿波忌部の植えた麻穀** に由来すると明記される。**安房神社の創建者** が天富命本人であることも、ここで宣言される。

→ 詳細：[[天富命の上陸と安房神社の創建]]、[[安房国の建国と地名の移植]]、[[北上と「総（ふさ）の国」の誕生]]、[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

## 3. 系譜上の位置

### 3-1. 中央忌部系譜（『古語拾遺』『斎部宿禰本系帳』）

```
高皇産霊尊
   │
   ├─ 天太玉命（中央忌部総祖神）
   │      │
   │      └─ ……（数代）……
   │              │
   │              └─ 天富命（神武朝の忌部族長）
   │
   └─ 天日鷲命系（阿波忌部祖、別系統）
```

→ 中央忌部の系譜では、天富命は **天太玉命の孫** と位置づけられ、神武朝の祭祀現場を主導する世代に位置する。

### 3-2. 阿波独自伝承との交差

阿波忌部の独自系譜（[[👥 阿波忌部の神系譜]]）では、**由布津主命（阿八別彦命）** が東遷を主導するとされる。天富命と由布津主命の関係には三説がある：

| 説 | 内容 |
|---|---|
| 同一神異名説 | 天富命＝由布津主命。中央伝承（古語拾遺）と阿波伝承で名が異なるが実体は同一 |
| 共同指導説 | 天富命（中央派遣の指揮官）と由布津主命（阿波本部隊の族長）が **連携して東遷** を主導 |
| 別人別代説 | 別世代の東遷主導者が複数いた（時間差での移住） |

→ 阿波説の通常採用は **共同指導説**（[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] を参照）。

## 4-bis. 「富む（とむ）」の語源と天富命

千葉まほろば神社（chiba_jinja）の調査と土橋幸一『小櫃川流域のかたりべ』の決定的記述：

> 忌部氏祖神の一柱「**天富命**」は穀物の神とされ、**穀物が豊かに実ることを、命にちなみ「富む」というようになった** そうです。

→ 日本語「**富む（とむ）**」「**富（とみ）**」の語源が **天富命** にあるとする伝承。穀物豊穣の神格名が日本語の根幹に組み込まれた稀有な事例。

→ 関連地名：
- **冨崎神社（富崎神社）**（君津市戸崎）：「とみさき → とさき」転訛
- **富山**（南房総市合戸）：**天富命終焉の地** とされる山
- **冨田**（君津市戸崎周辺）：豊かな水稲の実った土地
- **岩出**（同）：天富命の磐座を切り出した場所

### 4-quater-3. 『日本地理志料』所載の核心伝承

> **冨山は天富命の墓地** で、**成務天皇の時に子孫の久豆美（くずみ）が神霊を [[安房神社]] に遷した** とある。

これは極めて重要な伝承：

| 段階 | 場所 | 内容 |
|---|---|---|
| **神武朝** | 阿波→安房 | 天富命が阿波忌部を率いて東遷、安房神社創建 |
| **天富命没後** | **冨山** | 冨山に埋葬、清澄妙見山に廟所設立 |
| **成務天皇朝** | **冨山 → 安房神社** | **子孫・久豆美が天富命の神霊を安房神社へ遷座** |
| **以後** | 安房神社 | 天富命を相殿に祀る（[[安房神社]] 主祭神 天太玉命の相殿として現在に至る） |

→ **[[安房神社]] が現在も天富命を相殿に祀る根源** は、成務朝の **冨山からの神霊遷座** にある。

### 4-quater-4. 『安房志』所載の補足伝承

> 国史を按ずるに、弘仁二年紀、安房の人 **大伴直勝麻呂、姓を大伴登美宿弥（とみのすくね）を賜る** と載す。富山と謂ふも彼の **登美宿弥** に因めるならんか。

→ 弘仁2年（811年）に **大伴直勝麻呂が「大伴登美宿弥」の姓を賜った** ことが『日本後紀』等に記載される。「**登美宿弥（とみのすくね）**」の氏族名と「冨山」の地名の関連が指摘されている。

→ 阿波説的読み：「**登美**」氏 ＝ **天富命の子孫氏族**。冨山周辺に天富命の血統氏族が中世まで存続していた可能性。

### 4-quater-5. 「子孫・久豆美（くずみ）」について

## 6. 阿波説における意義

天富命の存在は、阿波説の **以下の論点を中核で支える**：

### 6-1. 阿波忌部の東遷を「皇命」として正統化

天富命の東遷は **神武天皇の勅命** に基づく公式行動として『古語拾遺』に記される。これにより：

- 阿波忌部の房総開拓は **私的移民ではなく公的事業**
- 安房神社は **皇命に基づく国家祭祀地**
- 麁服貢進・由加物貢進は **天富命の起点伝承に裏付けられた特権**

→ [[大嘗祭と麁服：阿波忌部の特権と幕府の契約]]、[[大嘗祭と麁服（あらたえ）_天皇即位に必須の阿波の神布]]

### 6-2. 地名移植法則の根拠

『古語拾遺』本文が **「阿波忌部の住む所、便ち、安房郡と名づく」** と明記。地名「安房・総・結城」がすべて阿波忌部由来と一次史料に記録される、阿波説の **「地名と氏族の東遷法則」（四大柱の④）の最強の物証**。

→ [[阿波・畿内地名ペア検証：東遷（ひがしうつり）の法則]]、[[上総・下総・安房の古郡名と阿波接続論：總フサ国の地名学的痕跡]]

### 6-3. 五忌部統括の主導者

讃岐忌部（手置帆負）・紀伊忌部（彦狭知）・阿波忌部（天日鷲）・安房忌部（天富自身）・出雲忌部を **統括して指揮** したのが天富命。**忌部全体の中央祭祀** が中央朝廷ではなく **天富命を介して阿波・安房軸** で機能していたとする読みが可能。

### 6-4. 古語拾遺が伝える「消された阿波」

『古語拾遺』は中央忌部の斎部広成が **中臣氏に祭祀権を奪われた不満** から編纂した史書。**記紀には殆ど記されない阿波忌部の事績** を意図的に復元している。天富命の阿波経由東遷は、**記紀から「消された阿波」を補完する貴重な記録**。

→ [[15_忌部氏系図・氏文]]、[[阿波説の根幹]]

### 6-5. 黒潮海洋ネットワークの祭祀的証言

天富命の **海路東遷** は、阿波の海人族（海部氏・安曇氏）の **黒潮航路** を経由して行われた。**鳴門→紀伊水道→太平洋→房総** という航路は、考古学的にも黒曜石・土器の流通で確認される交易路と整合する。

→ [[阿波海人族：海洋王権を支えた安曇・海部・那賀のネットワーク]]、[[阿波忌部の東国痕跡：千葉・上総・安房の祭祀地名]]

## 7. 天富命と「総（ふさ）の国」

『古語拾遺』が示す **「総国」誕生の論理構造**：

```
阿波の麻（あさ）
   │
   │  天富命が東国へ移植
   ↓
房総半島で「好麻（よきあさ）」生育
   │
   │  古語で「麻＝総（ふさ）」
   ↓
「総国」誕生 → 後に「上総・下総」に分割
   │
   │  阿波忌部の居住地
   ↓
「安房郡」誕生 → 「安房国」へ昇格
```

→ **阿波（あわ）→ 安房（あわ）** の地名同音、**麻（あさ）→ 総（ふさ）** の語源対応、**穀木（かじ）→ 結城** の植物地名対応――『古語拾遺』本文に明記される **三重の地名根拠** が、天富命東遷伝承の信頼性を一次史料レベルで支える。

## 11. 留保（中立的併記）

> [!warning] 注意
> - **天富命の東遷伝承は『古語拾遺』（807年）に依拠** する。記紀本文には明確な記載がなく、**中央忌部の家伝史料** に由来する点に留意。
> - 『古語拾遺』は斎部広成が **中臣氏との祭祀権闘争** の中で編纂した史書で、忌部の権威を強調する目的が含まれる。**価値ある一次資料だが、客観中立な編纂物ではない**。
> - 「**阿波→安房**」の地名移植説は『古語拾遺』本文に明記されるが、**逆方向（安房→阿波）の地名移植** を主張する反論もある。本ノートは前者を採用するが、地名学的には開かれた論点。
> - **天富命と由布津主命（阿八別彦命）の同一神異名説** は阿波の伝承に依拠し、文献的に確定したものではない。
> - **「総（ふさ）＝麻」の語源** は『古語拾遺』が伝える説で、現代の歴史言語学では別解釈もある。
> - 神武朝の年代設定そのものが学術的に確定しておらず、天富命の活動年代を **古墳時代初期〜中期** に比定するのは阿波説の解釈モデルの一つである。
