# 天村雲神（あまむらくものかみ）

← ポータルへ戻る

> [!summary] 要旨
> **天村雲神（あまむらくものかみ）** は、阿波麻殖郡の式内社 [[天村雲神伊自波夜比売神社]] の主座に祀られる神。配偶神 **伊自波夜比売神（いじはやひめのかみ）** と対をなす **二座社の主神** である。『先代旧事本紀』では天忍人命の御子で、海人系・天孫系の祖神。阿波説では **五十猛命（いそたける）との同体説** を軸に、新羅から木種を持ち帰った樹木の祖神＝植林・林業の神とされ、阿波忌部および阿波物部氏の祖神として麻殖郡の山林祭祀の古層に位置づけられる。

## 3. 祭神と社伝

『先代旧事本紀』天孫本紀では、天村雲命は **天忍人命の御子** で、天香語山命を経て尾張連・海部氏へと連なる海人系の祖神とされる。「村雲」は **神域を覆う神聖な雲** を象徴する名で、阿波では忌部山下の「叢雲（むらくも）」の地に鎮座したと伝える。

阿波説の核心は、天村雲命を **五十猛命（いそたけるのみこと）と同神視** する点にある。五十猛命はスサノオの御子で、新羅から木種を持ち帰り日本の山々に植えた **樹木・植林の祖神** である。『海部氏勘注系図』では「五十猛命＝天村雲命」と接続され、スサノオ→五十猛命（天村雲命）→天香語山命→天五十楯→建諸隅命→大倭姫（卑弥呼比定）に至る阿波の重要系譜の結節点に置かれる。

## 4. 阿波説における位置づけ

### 4-1. 麻殖郡＝阿波忌部本貫地の山林祭祀

鎮座地の麻殖郡は阿波忌部の本貫地であり、[[忌部神社]] をはじめとする忌部系式内社群を形成する。天村雲命を樹木・植林神とみることは、剣山山麓から吉野川流域にかけての **林業・木材祭祀の古層** が当地に存在したことを示すと解される。

→ [[阿波忌部氏伝承詳細]]、[[種穂山降臨：天磐船と五穀の種蒔き]]

### 4-2. 阿波物部氏の祖神として

阿波物部氏は **天村雲命（五十猛命）を祖** とする武人集団とされ、美馬郡・麻殖郡の製鉄・鍛冶の遺構と結びつけられる。植林（木炭）と製鉄が一体の技術祭祀をなしたとみる立場から、天村雲命は産業神系譜の起点に置かれる。

→ [[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配]]

### 4-3. 二座社の対偶構造

阿波の二座社は主祭神と配偶神を併せ祀る形式で、天村雲神・伊自波夜比売神もその一例である。男神（天・山・木）と女神（[[伊自波夜比売神]]）の対祭祀をなすと解される。

→ [[阿波国の二座社一覧]]
