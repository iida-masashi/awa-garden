# 御刀媛と室比賣神社：景行天皇妃の水難伝承と阿波の海人族祭祀

『日本書紀』景行天皇条に登場する妃 **御刀媛（みはかしひめ）** ――豊国別皇子の母とされ、肥後・名石神社（熊本県長洲町）と阿波・室比賣神社（阿南市新野町）の双方で、**「天皇を慕って海を渡って追いかけて来た妃が水難事故により亡くなる」** という同一の伝承を伝える。本ノートは marine816ブログ「御刀媛から考察 ①〜⑤」を中心に、御刀媛と複数の女神（石長比売・木花咲耶姫・イザナミ）の多層的同体論を整理する。

> 📚 親ハブ: [[元宮ハブ_MOC]]
> 関連: [[賀志波比売神社]], [[峰神社・龍宮総宮社：浅間神社の本宮と木花咲耶姫]], 天岩屋の阿波比定論：太龍寺の鍾乳洞と石長比売＝天照大神説

## 🎯 核心命題

御刀媛は単独の女神ではなく、**石長比売・木花咲耶姫・賀志波比売・神夏磯媛・弟媛・阿津姫・イザナミ** といった複数の女神格と **同一神の異なる呼称** である可能性が高い。その本拠地は **阿波・海部郡**。

## 📜 御刀媛の出典

### 『日本書紀』景行天皇条
> 景行天皇は日向国の高屋宮に6年在住中、美人が居ることを聞き及んで呼び寄せた妃。
> その名は **御刀媛（みはかしひめ）**、豊国別皇子の母。

### 『古事記』
> **日向之美波迦斯毘賣（ひむかのみはかしびめ）**

→ 表記は異なるが同一人物。

### 古語分析
| 字 | 訓み | 意味 |
|---|---|---|
| 御刀 | **みと** | （古語）女性器を表す「ほと」と関連 |
| 刀 | **はかし** | 古語の訓 |

→ 「ミハカシ」は身体的・霊的な意味を含む古語。

## 🏯 名石神社（熊本県長洲町）

| 項目 | 内容 |
|---|---|
| 所在地 | 熊本県玉名郡長洲町 |
| 祭神 | **景行天皇・御刀媛尊・豊国別尊** |
| 由緒 | 「日向御刀媛が景行天皇のあとを追って長洲に来たものの、既に天皇は発った後で、悲しみのあまり女官と共に海に入水して身を投げ石になった」 |

### 原文引用
> **日向御刀媛(ひむかのみはかしびめ)が景行天皇のあとを追って、長洲に来たものの既に天皇は発った後で、悲しみのあまり女官と共に海に入じ身を投げて石になったと伝えられる。**

## 🌊 室比賣神社（阿南市新野町）――阿波の対応

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県阿南市新野町入田 |
| 延喜式表記 | 室比賣神社（小社） |
| 御祭神 | **木花開耶姫命**（＝御刀媛と同一神） |
| 別社 | 海部郡海陽町相川の **阿津神社** |

### 室比賣神社の由緒
> **当社の御祭神は淳仁天皇の御内室「室妃」で奈良時代の末期に、姫が天皇を慕って小舟で淡路へ向かう途中、荒天の為阿波の東岸に漂着。**

→ 名石神社と **同一の母題**：「妃が天皇を追って海を渡る → 漂着 → 水難で亡くなる」

### 海陽町相川の伝承
- **阿津姫の昔話**：追われる姫が最終的に池に身を投げる
- **高橋長者伝説**：海陽町に伝わる関連伝承

### 阿波説の再地理化（marine816）

|---|---|
| 美濃（みの） | 阿南市 **見能林町**（旧名・見能） |

→ 景行天皇即位4年の美濃行幸で **弟媛を娶ろうとして失敗** した説話は、すべて阿波内部で起きた可能性。

## 🔄 多重同一性論

marine816 が示す **女神の多重同一性**：

| 女神名 | 出典 | 役割 |
|---|---|---|
| **御刀媛** | 景行紀 | 景行天皇妃 |
| **日向之美波迦斯毘賣** | 古事記 | 同上（別表記） |
| **弟媛** | 景行紀（4年） | 景行天皇に妃に推挙されたが姉八坂入媛を立てた |
| **神夏磯媛** | 景行紀（熊襲平定） | 神鏡を持って天皇に帰順 |
| **石長比売** | 古事記（瓊瓊杵尊段） | 木花咲耶姫の姉 |
| **賀志波比売** | 阿府志 | 津峯神社の祭神 |

## 👯 石長比売＝木花咲耶姫 同一神論

『古事記』邇邇芸命段では石長比売と木花咲耶姫は **姉妹** とされるが、marine816 は **両者を同一神** と解釈：

| 視点 | 石長比売 | 木花咲耶姫 |
|---|---|---|
| 性格 | 永遠（岩のように堅固） | 儚い（花のように咲き散る） |
| 結末 | 瓊瓊杵尊に返される | 妻として留まる |
| 阿波の祭祀地 | 津峯神社・賀志波比売神社 | 峯神社・室比賣神社 |
| 阿波説の解釈 | **同一神の二面性**を分離した記紀の文学的脚色 |

→ 「**岩**」と「**花**」は、同じ女神の **永遠性と短命性** の対立的側面。
