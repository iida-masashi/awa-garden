# 御刀媛（みはかしひめ）と室比賣神社

> [!summary] 要旨
> 御刀媛は『日本書紀』景行13年条に現れる景行天皇の妃で、豊国別皇子（日向国造の始祖）の母。『古事記』では日向之美波迦斯毘賣と表記される。熊本・名石神社には「天皇を追って来た妃が入水して石になった」という伝承があり、阿波・室比賣神社（式内小社、祭神は室比賣命）には淳仁天皇の室妃が漂着したという同型の「海を渡る妃」の社伝がある。marine816ブログ「御刀媛から考察 ①〜⑤」は、御刀媛＝石長比売＝木花咲耶姫＝賀志波比売＝神夏磯媛＝イザナミという多重同一性論を展開し、その本拠地を阿波・海部郡に置く。本ノートはその同体論を阿波説の解釈として整理するもので、記紀・社伝の事実と解釈を分離して記述する。

## 3. 祭神と社伝

### 3-1. 記紀における御刀媛

『日本書紀』景行天皇13年夏5月条：

> 十三年夏五月、悉平襲国。因以居於高屋宮已六年也、於是其国有佳人、曰御刀媛（御刀、此云彌波迦志）、則召爲妃。生豊国別皇子、是日向国造之始祖也。

すなわち、襲国を平定して高屋宮に6年滞在した景行天皇が、その国の佳人・御刀媛を召して妃とし、豊国別皇子を生んだ。豊国別皇子は日向国造の始祖とされる。『古事記』では同じ妃を「日向之美波迦斯毘賣」と記し、子を豊国別王とする。両者は同一人物とみてよい（コトバンク『日本人名大辞典+Plus』も同旨）。

### 3-2. 同一神異名群

文献上確実な異名は **御刀媛（書紀）＝日向之美波迦斯毘賣（古事記）** のみである。これ以外の同一視（石長比売・木花咲耶姫・賀志波比売・神夏磯媛・弟媛・阿津姫・イザナミ）は marine816 の同体論であり、5節で解釈として分離して扱う。

### 3-3. 名石神社の社伝（熊本県長洲町）

名石神社（めいしじんじゃ、別名・女石宮）の由緒：

> 日向御刀媛が景行天皇のあとを追って長洲に来たものの、既に天皇は発った後で、悲しみのあまり女官と共に海に身を投げて石になったと伝えられる。

祭神は景行天皇（大足彦忍代別天皇）・日向御刀媛・豊国別皇子。記紀にはこの伝承自体は記されておらず、長洲の地に伝わる社伝である。

### 3-4. 室比賣神社の社伝（阿波）

> 当社の御祭神は淳仁天皇の御内室「室妃」で、奈良時代の末期に、姫が天皇を慕って小舟で淡路へ向かう途中、荒天の為阿波の東岸に漂着。ここに安住の地を求めていたが、ついに黄泉の客となった。身重であった姫は安産を願う遺言を残したという。

祭神は室比賣命で、安産の神として崇敬される。境内は中世の岡山城址。

**循環参照への注意**：室比賣神社の室妃は奈良時代（淳仁天皇）の人物とされる社伝であり、景行紀の御刀媛とは本来別人である。両社伝の「同一母題」をもって御刀媛と室比賣命の同一性を論証することはできない（母題の類似は解釈の出発点にとどまる）。本ノートではこの点を踏まえ、同一性は阿波説の仮説としてのみ扱う。

## 4. 歴史

- 古代：『日本書紀』（720年）景行13年条に御刀媛・豊国別皇子。『古事記』（712年）の景行天皇系譜に日向之美波迦斯毘賣。
- 延長5年（927年）：『延喜式』神名帳に「阿波国 那賀郡 室比賣神社」（小社）。
- 中世：室比賣神社は岡山城に鎮座したとされる。
- 江戸期：『阿府志』が室比賣神社の祭神を吾田鹿葦津姫（木花咲耶姫の別名）とし、『阿波志』も鹿葦津姫命（コノハナサクヤ）に比定。祭神同定の解釈はこの時期の地誌に始まる。
- 明治7年（1874年）：室比賣神社は室姫神社と改称（現在は徳島県神社庁の表記で室比賣神社）。
- 現在：室比賣神社の式内社比定には論社（海陽町相川の阿津神社）があり、確定していない。

## 5. 「海を渡る妃」母題と多重同一性論（核心論点）

### 5-1. 両社伝の母題比較

| 室比賣神社（阿波） | 名石神社（熊本） |
|---|---|
| 室妃（淳仁天皇内室） | 御刀媛（景行天皇妃） |
| 天皇を慕って小舟で渡る | 景行天皇を追って長洲に来る |
| 荒天で阿波東岸に漂着 | 天皇は既に発った後で悲嘆 |
| 黄泉の客となる（安産の遺言） | 海に身を投げて石となる |

→ 「妃が天皇を追って海を渡る → 漂着・行き違い → 水難で亡くなる」という同一の母題を共有する。ただし両社伝の主人公は本来別人であり、母題の同一性自体は事実として、そこから先の同体論は解釈である。

### 5-2. 多重同一性論（marine816）

| 女神名 | 出典 | 役割 |
|---|---|---|
| **御刀媛** | 景行紀 | 景行天皇妃 |
| **日向之美波迦斯毘賣** | 古事記 | 同上（別表記。文献的に同一） |
| **弟媛** | 景行紀（4年） | 妃に推挙されたが姉・八坂入媛が立てられた |
| **神夏磯媛** | 景行紀（熊襲平定） | 神鏡を持って天皇に帰順 |
| **石長比売** | 古事記（瓊瓊杵尊段） | 木花咲耶姫の姉 |
| **賀志波比売** | 『阿府志』 | 津峯神社の祭神 |
| **木花咲耶姫** | 『阿府志』室比賣神社条 | 室比賣神社の祭神比定 |
| **吾田鹿葦津姫** | 『阿府志』室比賣神社条 | 木花咲耶姫の別名 |
| **阿津姫** | 海陽町伝承 | 海陽町相川・阿津神社 |
| **イザナミ** | 古事記（黄泉国訪問） | 究極的同体（記事⑤） |

→ marine816 は、これらがすべて「海を渡る／追われる／水難で亡くなる／神となる」という共通モチーフを持つ同一神の異名だとする。また神夏磯媛については、『阿府志』で羽山戸神×大気都比売神の娘とされる夏之売命＝賀志波比売と同一視する（神夏磯媛＝夏之売命論）。いずれも文献的裏付けは未確定（12. 留保参照）。

### 5-3. 石長比売＝木花咲耶姫 同一神論

『古事記』邇邇芸命段では石長比売と木花咲耶姫は姉妹とされるが、marine816 は両者を同一神と解釈する：

| 視点 | 石長比売 | 木花咲耶姫 |
|---|---|---|
| 性格 | 永遠（岩のように堅固） | 儚い（花のように咲き散る） |
| 結末 | 瓊瓊杵尊に返される | 妻として留まる |
| 阿波の祭祀地 | 津峯神社・賀志波比売神社 | 峯神社・室比賣神社 |
| 阿波説の解釈 | **同一神の二面性**を分離した記紀の文学的脚色 | |

→ 「岩」と「花」は、同じ女神の永遠性と短命性の対立的側面だという読みである。

### 5-4. 白蛇と蛇信仰

[[峰神社・龍宮総宮社：浅間神社の本宮と木花咲耶姫]] の平成7年由緒書き：

> 木花開耶姫命白蛇トナリテ屡々現ハルヲ以ツテ正ニ霊験顕カナリト

→ 木花咲耶姫の白蛇化は、女神の永遠性と再生のシンボルとされる。蛇信仰との接続として、龍宮総宮社の「龍」、阿津神社の海神性、イザナミ＝大蛇化伝承（記紀）が挙げられる（いずれも解釈）。

## 6. 阿波説における意義

### 6-1. 景行天皇条の阿波内再解釈

通説の景行天皇九州行幸ルート（紀伊 → 美濃 → 筑紫豊前 → 碩田国 → 日向）に対し、marine816 は説話の舞台を阿波内部に再地理化する：

| 通説 | 阿波説の比定 |
|---|---|
| 美濃（みの） | 阿南市 **見能林町**（旧名・見能） |
| 高屋宮 | 阿波の高屋神社（海部郡美波町近辺） |
| 弟媛が隠れた竹林 | 舎心山常住院 **太龍寺** |
| 泳宮（ククリのみや） | 同上 |
| 美濃国造の屋敷 | 海部郡 |

→ 景行天皇即位4年の美濃行幸で弟媛を娶ろうとして失敗した説話は、すべて阿波内部で起きた可能性がある、という読みである。

### 6-2. 阿波・九州・関東の祭祀ネットワーク

「海を渡る妃」モチーフは、阿波・海部郡を中心とした古代海人族の祭祀ネットワークを示す痕跡だと阿波説はみる：

```

┣ 室比賣神社（阿南市新野町、論社：海陽町相川・阿津神社）
┣ 賀志波比売神社（阿南市）
┣ 峯神社・龍宮総宮社（阿南市椿町）
▼ 海路で展開

┗ 名石神社（熊本県長洲町）――同一の母題

┗ [[弟橘姫命：房総の海神と日本武尊の后]]――海を渡る妃の別系統
```
