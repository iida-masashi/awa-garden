# 阿波比売命（あわひめのみこと）

> [!summary] 要旨
> 阿波比売命は、遠江国佐野郡の式内小社 [[阿波々神社]]（静岡県掛川市、粟ヶ岳山頂付近）の主祭神として現行祀られる女神である。ただし『延喜式』神名帳に記録されたのは社名「阿波々神社」までであり、祭神名が式内社名として記録されたわけではない（[[阿波々神社]]ノートで原文照合済み）。記紀に「阿波比売命」の名は確認できず、阿波国の国魂神・大宜都比売命や [[阿波命]] と同体とする三女神同体論、父神・配偶・御子の系譜はいずれも阿波説および系図伝承に基づく解釈で、一次史料の裏付けは確認できていない。本ノートは確認できる事実と阿波説の解釈を分離して記述する。

## 3. 神格と社伝

### 3-1. 阿波々神社の祭神として

阿波比売命の祭祀が具体的に確認できるのは、粟ヶ岳（標高532m）山頂付近に鎮座する [[阿波々神社]] である。同社の現行主祭神は阿波比売命で、創建は736年と伝えられる（神社由緒に基づき、Wikipediaもこの年を採る）。境内には素戔嗚命と櫛稲田姫を祀る八重垣神社が併設されている。なお旧稿が挙げた配祀「大宜都比売命・天津羽羽命」は、照合した資料（Wikipedia・移行済み [[阿波々神社]] ノート）では確認できなかった（12.留保）。

### 3-2. 記紀における不在

『古事記』『日本書紀』に「阿波比売命」の名は確認できない。一方、『古事記』国産み段では四国・阿波国の別名として「大宜都比売」の名が現れる（Wikipedia「オオゲツヒメ」）。これは地名としての阿波と女神名の結びつきを示す古典的な用例ではあるが、阿波比売命その人の記事ではなく、両神の同一視を直接裏付けるものでもない。

### 3-3. 同一視の循環参照への注意

阿波説では本神を大宜都比売命と同一視し、その同一視を根拠に阿波々神社の東遷創祀を権威づけ、一方で同社の存在を東遷の論拠とする構造がある。これは循環参照になり得るため、本ノートでは同一視と東遷創祀をそれぞれ独立した仮説として扱う（[[阿波々神社]] ノートの処理と整合）。

## 5. 系譜伝承と同一視の検討

### 5-1. 阿波の三女神同体論

阿波説では阿波の女神は三相一体の構造で語られる：

| 神格 | 性格（阿波説の整理） |
|---|---|
| 大宜都比売命 | 食物・穀霊・粟祭祀の女神。『古事記』では阿波国の別名としても現れる |
| **阿波比売命** | 阿波国の女神化（地名神格化）とされる |
| [[阿波命]] | 阿波国の包括的国魂とされる |

→ いずれも阿波国の最古層の女神を表現する異名と読むのが阿波説の解釈である。記紀がこの三神の同一を明示した箇所は確認できていない。

### 5-2. 系譜伝承（粟飯原家系図系）

旧稿の親族関係は以下のとおりだが、いずれも系図伝承・阿波説資料に基づき、記紀等の一次史料では確認できていない：

- 父神：天背男命（[[天背男命：阿波忌部の祖父神と「一神異名」群]]）とする伝承（粟飯原家伝に基づくと旧稿は記す）
- 配偶：天日鷲命系の阿波忌部祖神とされる
- 御子：八前の随神（北斗七星）に擬される（大宜都比売命の降臨伝承における八神構成との対応づけ。→ [[八前の随神と北斗七星：大宜都比売命の降臨を支えた天文学的配置]]）

### 5-3. 神津島・阿波咩命との関係

伊豆国・神津島の [[阿波命神社]]（式内名神大社）の祭神は **阿波咩命**（あわのめのみこと、別名に阿波命／阿波比咩命）である。『続日本後紀』承和7年（840年）条によれば三嶋神の本后とされ、物忌奈命はその御子神という（Wikipedia「阿波命神社」）。平田篤胤は『古史伝』で阿波咩命を天津羽羽神（天石門別神の娘神）に比定した。また「阿波」の神名から、忌部氏が阿波国から安房国へ東遷する際に当地に逗留したことに由来するという伝承もある。

神名の類似（比売／比咩）から本神との同一視が連想されるが、神津島の伝承は三嶋神の后という独自の系譜を持ち、阿波比売命との同一を裏付ける史料は確認できていない。両者は分離して扱う。

## 6. 阿波説における意義

### 6-1. 阿波忌部東遷の物的証拠とする説

阿波比売命を主祭神とする遠江・[[阿波々神社]]の存在は、阿波説では阿波忌部の東遷経路上の重要拠点を示すとされる：

```
阿波（粟国） → 黒潮ルート → 紀伊水道 → 駿河湾 → 遠江・粟ヶ岳
   ┃                                              ┃
   ┗ 上一宮大粟神社                              ┗ 阿波々神社（東遷の中継地とされる）
```

ただし同社の創祀の担い手は史料上不明であり、東遷創祀は仮説である。

### 6-2. 事任八幡宮との対構造

- [[事任八幡宮]]（延喜式名「己等乃麻知神社」、主祭神・己等乃麻知比売命）は同じ佐野郡の式内社で、社伝（公式サイト）では玉主命の娘とされる
- 阿波説では、言葉（事任）の女神と粟の女神（阿波比売）＝玉主命の二人の娘による対構造と読む
- 詳細：[[祭神・阿波比売命と事任八幡宮との対構造]]

なお旧稿の「事任八幡宮の旧名『己等乃麻知比売命神社』」は誤りで、神名帳の表記は「己等乃麻知神社」である（[[事任八幡宮]] ノート・Wikipediaで確認し、本節および留保4で訂正）。

### 6-3. 古代地名「あは」の語源論

- 粟・阿波・安房（あは）── すべて同系の地名とする阿波説の主張
- 阿波比売命＝「あは」を冠する女神＝阿波国そのものの神格化と読む
- 詳細：[[阿波・安房ペア：黒潮が繋ぐ同一地名群]]

### 6-4. 山岳祭祀の同型性とする説

- 阿波：神山・剣山系の山岳祭祀
- 遠江：粟ヶ岳山頂祭祀
- 山名・神格・配祀の三位一体の同型性が阿波忌部の祭祀文化の標準パターンとする阿波説の解釈（配祀の同一性自体は未確認。12.留保）
