# 国生み神話の阿波本舞台論：水蛭子・淡島・淡道之穂之狭別嶋

> **要旨**：『古事記』国生み神話における **水蛭子（ヒルコ）** と **淡島（アハシマ）** の正体、そして大八嶋の最初の子 **「淡道之穂之狭別嶋」** が通説の淡路島ではなく阿波・徳島の地名（海陽町那佐）であるとする論考の統合。仁徳天皇歌「おしてるや 難波の崎よ…」の島々（淡島・自凝島・檳榔の島・さけつ島）を阿波の地形に当て嵌めると、Flood Mapsで再現される往古の海岸線にぴったり対応する。また国生みの島々を移動経路（海路）として読み解くと、佐渡島＝韓国沙島、大島＝南淡福良、知訶嶋＝竹ヶ島、両児嶋＝那佐二子島となり、出発地と帰着地はいずれも海陽町那佐となる。

---

## 1. 水蛭子と淡島——子に数えられなかった最初の二子

### 記紀の記述
- 古：「久美度邇此四字以音興而生子、水蛭子、此子者入葦船而流去。次生淡嶋、是亦不入子之例。」
- 紀：イザナミがイザナギに声をかけ、最初に淡路洲、次に蛭児（三歳になっても脚立たず磐櫲樟船に乗せ流す）。

### 「水蛭子」の解釈
- 通説：水蛭（ヒル）のように手足が異形の不具の子。
- 阿波説：**「日る子」＝太陽の御子＝エビス**——尊い「日の御子」だからこそ流された貴種流離譚。
- 室町時代以降の **ヒルコ＝エビス信仰** との結合は新説ではなく古来の伝承の復活と捉える。

### 「淡島」の解釈
- 通説：和歌山県加太の **淡嶋神社**（祭神：少彦名命・大己貴命・神功皇后）→ 神功皇后が三韓征伐凱旋時に祠を移した友ヶ島の神島。
- しかしこれは『古事記』の淡島とは別物。

### 阿波・阿南の淡島神社
- **淡島神社**（徳島県阿南市畭町三田8）。
- 『阿波志』：「粟島祠 中林海中に在り」——淡島神社は昔は阿南市沖の**青島**にあった。
- 往古より青島の神社は「沖の淡島」と呼ばれる。
- Flood Mapsで縄文晩期・弥生時代を再現すると、現在の淡島神社の地も「島」だった。
- **「アハシマ」＝「阿波の島」**（阿波の原読みは「アハ」）。

### エビス信仰の阿波集中
- 阿南市は **蛭子（ひるこ・えびす）神社の密集地**。
- 全国の蛭子神社：ほぼ各都道府県1社程度（鹿児島・福岡・兵庫・愛媛・和歌山など）。
- 徳島県には少なくとも27社、うち阿南市だけで15社。和歌山市は「蛭子若宮神社」1社のみ——紀伊水道対岸の格差。
- **蛭子姓・戎姓・夷姓・戎田姓・戎居姓・戎谷姓** の氏姓ルーツが徳島の海部・長国に集中。
- 蛭子能収氏のルーツも徳島県美波町（旧日和佐町）——「えびす」「戎」地名が残る漁村。

### 関連祭祀
- 八神殿（宮中神祇官）の最後二神は **御食津神（大宜津比売神）** と **事代主神（えびす）**——いずれも阿波由来。
- 全国唯一、式内社で事代主命を祀るのは阿波国に2座のみ。
- 阿波国一宮 **天石門別八倉比売神社**（徳島市国府町西矢野）：祭神 **大日孁女命（オオヒルメ）**＝アマテラスの元社。
  - ヒルコ＝日の御子＝エビス
  - ヒルメ＝日の巫女＝アマテラス
- 「女が先に言うのは良くない」とする男尊文脈は、**原日本が女性優位（卑弥呼／アマテラスの女王信仰）** だったことの暗示。

## 2. 仁徳天皇歌の島々——阿波の海岸線で解く

### 仁徳記の歌（淡路に坐し本国を望み詠む）
> 「おしてるや 難波の崎よ 出で立ちて 我国見れば 淡島 自凝島 檳榔の島見ゆ さけつ島見ゆ」
> 「乃自其嶋傳而幸行吉備國」

### 通説の矛盾
- 「難波」を摂津国難波、「吉備」を岡山県、「淡島」を友ヶ島の神島とすると、淡路から東を見ている歌になるが、その後吉備へは西方向に行くため辻褄が合わない。
- 沖ノ島・友ヶ島・地島など南淡から東を見て本州（北側）に戻る奇妙なU字経路となる。

### 阿波説解釈
- 黒日売を下船させた「大浦」＝**徳島県鳴門市北灘町大浦**。
- 近接して **葛城神社**3社が天円山周辺に鎮座——皇后 **葛城磐之媛** との対応。
- 天円山＝ホケノ山古墳の原型と説のある **萩原墳墓群**。
- 「吉備」＝阿南市牛岐＝「岐比津」（→ 孝安天皇から考察の港町論）。
- 仁徳が歌を詠んだ場所は淡路島南部（三原郡——応神妃の娘・淡路御原皇女ゆかり）。
- そこから **南方の阿波の海岸線** を望んだ。

### 島々の阿波比定
| 歌の島 | 阿波比定地 | 現状 |
|--------|-----------|------|
| 淡島 | 阿南市沖の青島・畭町淡島神社一帯 | 弥生期は島 |
| 自凝島 | **日峰山**（小松島市中田町） | 現在は陸続き |
| 檳榔の島 | **津田山**（徳島市津田町） | 現在は半民家化、檳榔の実形状 |
| さけつ島 | **大毛島・島田島**（鳴門市） | 真ん中から裂けた形状 |

Flood Mapsで往古を再現すると、これらの島々が淡路島南部から一直線に見える島並として浮かび上がる。

### 淤能碁呂島＝日峰山
- 「天の沼矛を降して掻きまわした…潮水が積もって島となった」＝水に棒を入れて掻き混ぜると中央に渦が立ち、その底に堆積する——**日峰山（ひのみね）** の地形と読みの一致。
- **国生みの建国出発点は日峰山周辺**。

## 3. 新・国生み——大八嶋を海路として読む

### 通説比定の不可能経路
通説では大八嶋を次の順で生成：

| 順 | 古事記名 | 通説比定 |
|----|---------|---------|
| ① | 淡道之穂之狭別嶋 | 淡路島 |
| ② | 伊予之二名嶋 | 四国 |
| ③ | 隠岐之三子嶋 | 隠岐島 |
| ④ | 筑紫島 | 九州 |
| ⑤ | 伊岐嶋 | 壱岐 |
| ⑥ | 津嶋 | 対馬 |
| ⑦ | 佐度嶋 | 佐渡 |
| ⑧ | 大倭豊秋津嶋 | 本州 |
| ⑨ | 吉備児嶋 | 児島半島 |
| ⑩ | 小豆嶋 | 小豆島 |
| ⑪ | 大嶋 | 周防大島 |
| ⑫ | 女嶋 | 国東姫島 |
| ⑬ | 知訶嶋 | 五島列島 |
| ⑭ | 両児嶋 | 男女群島 |

『古事記』には「**然後、還坐之時**、生吉備兒嶋…」とあり、⑨以降は **「還ってくる時に」生まれた島々**。通説で結ぶと淡路→四国→**隠岐**→九州→壱岐→対馬→**佐渡**→本州…と右往左往し、最終の女嶋・知訶嶋・両児嶋に至っては大分・五島・男女群島へと遠ざかる、起点に戻らない奇怪な航路。

### 隠岐之三子嶋＝高知県沖の島
- 通説の隠岐諸島は四島あり、「三子嶋」の名と合わない。
- 高知県宿毛湾沖の **沖の島**（旧称「妹兄島（いもせじま）」）が候補。
- 七島構成のうち実質3島（沖の島・鵜来島・姫島）。
- 『今昔物語集』巻26第10「土佐國の妹兄、知らぬ島に行て住む語」——イザナギ・イザナミ神話と酷似した妹兄婚漂着伝承。
- 天気のよい日は九州が見えるという立地——次行程の筑紫嶋へ自然接続。

### 佐度嶋＝大韓民国チョルラ南道ヨス市 沙島（さど）
- 「水行航路」で対馬の次に来る島→朝鮮半島南部。
- 倭の北岸 **狗邪韓国**（『後漢書』『三国志』）。
- 『魏志韓伝』辰韓条「**國出鐵**、韓濊**倭皆従取之**」——鉄を採取し積み込む経済的動機。

### 大嶋＝淡路島（南淡福良）
- 万葉集15・3638「**過大嶋鳴門而**經再宿之後追作歌」「これやこの名に負ふ鳴門の渦潮に玉藻刈るとふ海人娘子ども」。
- 「鳴門」を持つ大嶋は徳島県側の鳴門と接する島——**現在の淡路島**。
- 大多麻流別＝「大溜る」＝船舶が集まり停泊する港湾の意。
- 万葉集15・3634「筑紫道の可太の大島」の「可太」は別の大島と区別するための限定語（井上『新考』「可太は方なり」）。
- 現南淡町福良港が第一候補。
- → **『古事記』の「淡道之穂之狭別嶋」と「淡路島」は別物**。淡路島は「大嶋」。

### 女嶋＝日峰山（または小松島の島嶼）
- 通説の国東姫島ではない。
- 日峰神社（小松島市中田町、阿波三峰の一）祭神：**大日霊貴神・少彦名神・市杵島比女神**——二人の女神が鎮座。
- 大神子・小神子の地名が周辺に残る → 大日霊貴神・市杵島比女神に対応。

### 知訶嶋＝竹ヶ島・志式島＝宍喰
- 『肥前国風土記』小城郡：景行天皇が **志式島（ししきのしま）** の仮宮から西海を見て、土蜘蛛の大耳・垂耳がいる小近・大近（値嘉島）を確認。
- 阿波置換：志式島＝**徳島県海部郡海陽町宍喰（ししくい）**、近くの島＝**竹ヶ島**。
- 五島列島の小値賀・大値賀は時代が下る景行天皇命名譚で、神代の知訶嶋とは別物。

### 両児嶋＝海陽町那佐の二子島
- 徳島県海陽町と高知県東洋町境界の無人島。
- 約1200年前、**紀州熊野神社のご神体が12に分かれ、うち一つが金の鳥になりこの島の松に止まった**伝承。
- 海陽町那佐湾内にも同名「二子島」（旧「三島」、三島神社旧鎮座地）が存在。
- 三島神社祭神 **溝咋耳命**＝八咫烏鴨武角身命＝**金鵄**——「金の鳥」伝承の本来地。

## 4. 「淡道之穂之狭別嶋」の意味——岸根敏行論文と阿波説結論

### 岸根敏行氏（福岡大学）の語義分析
- 「淡道之」＝淡路に至る道、必ずしも粟と直結しない。
- 「穂」＝稲の穂（本居宣長説に同意）。
- 「之」は主語・述語をつなぐ格助詞→「穂が早い／穂が稲をつけた」。
- 「狭」＝「早苗」「早乙女」の「さ」＝稲。
- 「別」＝皇族男子の姓（比古・男に同じ）。
- 結論：**「淡道という、（稲）穂が早くついた男子という嶋」**／**「淡道という、穂をつけた稲の男子という嶋」**。

### 阿波説結論
- 阿波の道 ＝ 阿波（粟）への道。
- 稲 ＋ 早 ＋ 別（男子）＝**阿波-枳閇（来経＝道）-委奈佐-比古命**。
- 出雲国風土記の **「阿波枳閇委奈佐比古命」**（船岡山の段：船岡山は彼が引き来居えた船）と完全一致。
- → 「淡道之穂之狭別嶋」は現在の淡路島ではなく、**式内社 和奈佐意富曾神社が御鎮座する徳島県海陽町那佐（往古の和奈佐）** のこと。
- 出発地と帰着地が同地（両児嶋もこの海陽町）——円環的な国生み行程。

### 出雲国風土記 船岡山の段
> 「船岡山。郡家の東北一里一百歩。**阿波枳閉委奈佐比古命**、曳き来居ゑし船、則ち此の山、是矣。故、船岡と云ふ。」

→ 佐度嶋（韓国沙島）から鉄を積んで船岡山周辺で製鉄加工、次の地へ海路移動——出雲・島根の製鉄文化との接続。
- 海部刀は島根県の良質な鉄を使用。
- 阿波枳閉委奈佐比古命の正体はイザナギか、子のスサノオか——いずれにせよ阿波と山陰を繋ぐ海人神。

## 5. 神名併記の有無の意味

『古事記』国生みの島には神名併記の有無パターンがある：

| 島 | 神名併記 | 解釈 |
|----|----------|------|
| ①淡道之穂之狭別嶋 | なし | イザナギ自身の投影／次代の別神格化（水蛭子へ） |
| ②伊予之二名嶋 | 愛比売・飯依比古・大宜都比売・建依別 | 四国の四面 |
| ⑦佐度嶋 | なし | イザナミ自身の投影／次代の別神格化（淡嶋へ） |
| その他 | あり | 通常の子としての存在 |

→ ①と⑦が「子として認められなかった」水蛭子・淡嶋に対応する自身の投影。これらは次代の別神名（スサノオ・天照大御神など）として再出する。

## 8. 留保（中立的併記）

- 「アハシマ」＝「阿波の島」の解釈は音韻的には自然だが、淡島が阿波と無関係に「泡」（不安定な意）を指す可能性も否定できない。
- Flood Maps による海面変動再現は標高ベースで概算であり、考古学的海退期との厳密照合は別途必要。
- 佐度嶋＝韓国沙島説は地名音通のみが根拠で、文献的裏付けは弱い。狗邪韓国＝倭領説は中国側史料に依拠する。
- 岸根論文の語義分析を阿波の那佐に直結させるのは私説解釈であり、論者自身は阿波説をとっていない。
- 大杉博系の「四国＝邪馬台国」説は主流学界では受け入れられていない。
