# 三嶋大明神と阿波：伊豆一宮の元宮としての事代主祭祀

静岡県三島市に鎮座する **三嶋大社（みしまたいしゃ）** は伊豆国一宮、名神大社。主祭神は **大山祇命** と **積羽八重事代主神（つみはやえことしろぬしのかみ）** の二柱（合わせて「**三嶋大明神**」と総称）。

阿波説では、この三嶋大社（特に事代主祭祀）の本源を **阿波国に2社存在する事代主神社**（阿波郡・勝浦郡）と、阿波忌部・海人族による伊豆諸島進出に求める。本ノートはその系譜的接続を整理する。

| 項目 | 内容 |
|---|---|
| 鎮座地 | 静岡県三島市大宮町 |
| 社格 | 伊豆国一宮、名神大社、官幣大社 |

| 創建 | 不詳（古代から） |
| 由緒 | 古くは伊豆諸島に鎮座、伊豆半島に遷座した経緯あり |

## 🏝 伊豆諸島と阿波の海洋ネットワーク

### 三嶋大社の本源は伊豆諸島

通説でも三嶋大社は、**もとは伊豆諸島（神津島・伊豆大島）に鎮座** し、後に伊豆半島の現在地に遷座したと考えられている。
神津島には現在も **物忌奈命神社（ものいみなのみことじんじゃ）** が鎮座し、ここに **伊古奈比咩命（いこなひめのみこと）** が祀られる。

### 伊古奈比咩命と阿波咩命

伊豆諸島の祭神 **伊古奈比咩命** と、阿波説で注目される **阿波咩命（あわめのみこと）** は、いずれも伊豆諸島と阿波の祭祀接続を示す女神格である。

| 神 | 鎮座地 | 関連 |
|---|---|---|
| 伊古奈比咩命 | 神津島・三嶋大社境内 | 事代主神の妃神とも、独立した女神格とも |
| 阿波咩命 | 神津島・長浜神社、奈良率川阿波神社 | 阿波由来の女神 |

→ noraneko-blog では、これらを **天日鷲命の血統の女神** として整理する。

## 🐉 事代主神の阿波本貫

延喜式神名帳では、**事代主神社** という社名は阿波国に **2社** 存在する：

| 神社 | 郡 | 比定論社 |
|---|---|---|
| 事代主神社 | 阿波郡 | 阿波市市場町伊月（事代主神社） |
| 事代主神社 | 勝浦郡 | 生夷神社（勝浦郡勝浦町沼江田中71） |

→ 1国に2社の事代主神社というのは全国でも極めて稀。これは事代主祭祀の **本貫地が阿波** であった証拠と解される。

## 🌟 事代主神＝大宜都比売命の配偶神という阿波説

阿波の式内社研究では、**事代主神（積羽八重事代主神）** を **大宜都比売命の配偶神** として位置づける論がある。

```
大宜都比売命（阿波国魂、上一宮大粟神社）
   ┃
   ┃（配偶）
   ┃
積羽八重事代主神（事代主神社×2）
   │
   ├ 海洋王権の象徴
   ├ 国譲りでの服属者
   └ 三嶋大明神として伊豆へ
```

## 🏯 中臣氏との関係：天日鷲命系譜

三嶋大社祭祀には **中臣氏（後の藤原氏）** の影響があるとされる。阿波説では、中臣氏も **天日鷲命の系譜** に連なるとする論が存在する。

→ 参考：awanonoraneko_03_氏族_忌部海人#2011-09-01-天日鷲命　は、中臣の神　１ （[出典](https://awanonoraneko.hatenadiary.com/entry/52323472)）

これが正しければ、**三嶋大社の中臣系祭祀も、根本的には阿波忌部祖の祭祀** ということになる。

## 🌐 大山祇命の元宮論との接続

三嶋大社の主祭神の一柱 **大山祇命** は、伊予国一宮 **大山祇神社（大三島）** と同神。
[[元宮ハブ_MOC]] でも記載のとおり、大山祇神社の元宮は **阿讃山脈の「大山」** とされる。

→ つまり、三嶋大社の二柱（大山祇命＋事代主神）は **両方とも阿波が元宮** という主張が成立する。
