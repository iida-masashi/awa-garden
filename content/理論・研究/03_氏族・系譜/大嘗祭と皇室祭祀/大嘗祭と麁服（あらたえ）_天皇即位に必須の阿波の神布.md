# 🎓 大嘗祭と麁服（あらたえ）：天皇即位に必須の阿波の神布

> [!summary] 概要
> **大嘗祭（だいじょうさい）** は新天皇が即位後に初めて行う **「真の天皇となるための極秘儀式」**。この儀式の中心に供えられる **麁服（あらたえ／麻織物）** は、**古来から阿波国の忌部氏（現代の徳島県美馬市木屋平・三木家）が栽培・製織し、調進（献上）する** ことが絶対の掟とされてきた。**大正・昭和・平成・令和**の四代続く即位儀式でも、三木家が麁服を調進している。
>
> 阿波説では、これを **「天皇家のルーツが阿波であることの動かぬ物証」** と位置づける。中臣氏（藤原氏）の台頭で1000年以上前に表舞台から消えた阿波忌部が、**唯一現代に継承する皇室祭祀の特権** であり、阿波と皇室を結ぶ最大の生きた証拠である。

---

## 🎌 大嘗祭の儀式構造

### 概要

大嘗祭は新天皇が即位後の **一世一代** の儀式：
- 新嘗祭（毎年11月の収穫祭）を、**即位後の初回に限り特別に大規模化** したもの
- **悠紀殿（ゆきでん）・主基殿（すきでん）** の二殿が大嘗宮として臨時造営される
- 天皇は天照大神をはじめとする **天神地祇に新穀を供え、自らも食す**
- これにより **神の霊力を身に宿し、真の天皇となる**

### 大嘗宮の構造

```
[大嘗宮]
   ├ 悠紀殿（東日本産の新穀・神饌を供える）
   └ 主基殿（西日本産の新穀・神饌を供える）

各殿に供えられる三神器的供物：
   ├ 神鏡（依代）
   ├ 和服（にぎたえ）＝絹織物
   └ 麁服（あらたえ）＝麻織物 ★阿波忌部の調進
```

### 供物の意味

| 供物 | 素材 | 担当 | 阿波説での意味 |
|---|---|---|---|
| **和服（にぎたえ）** | 絹 | 三河国（旧鴨田・赤引糸） | 通常の絹織物 |
| **麁服（あらたえ）** | 麻 | **阿波国・三木家** | **天皇即位の核心。阿波本貫論の最重要物証** |

→ 「**麁（あら）**」は素朴・粗野・原初の意。**最も原始的で神聖な素材** として麻布が選ばれる。
→ 阿波の麻は記紀における **天日鷲命の播殖** に起源を持つ（[[天日鷲命：天岩戸の功績と「鷲」の由来]]）。

## 🌾 麁服調進の系譜：阿波忌部・三木家

### 阿波忌部氏の特権

『古語拾遺』（807年・斎部広成）：
> 天日鷲命の孫・**天富命** は阿波忌部を率いて麻と穀（かじ）を植え、麁妙（あらたえ）・繊維製品を朝廷に献上した。

→ 阿波忌部は **古代から朝廷の神事用麻布を独占供給** する氏族として確立されていた。

### 三木家（みきけ）の世襲

| 項目 | 内容 |
|---|---|
| 本貫 | **徳島県美馬市木屋平（こやだいら）** |
| 氏族 | 阿波忌部の直系子孫 |
| 役職 | **麁服調進の世襲祭祀権** |
| 屋敷 | 国指定史跡「**三木家住宅**」（江戸期建立、阿波忌部祭祀の中心地） |
| 関連史料 | **三木家文書**（中世〜近世の調進記録、※[[三木家文書の偽書論争：阿波忌部研究の史料批判|偽書論争]] あり） |

詳細：[[阿波忌部の考古学的物証：忌部山古墳群と三木家屋敷]]、[[阿波忌部氏伝承詳細]]

### 麁服調進の現代の流れ

近代以降（大正大嘗祭以後）の調進プロセス：

1. **麻畑の御祓い**（即位前年）：三木家敷地内の麻畑で神事
2. **麻の播種・栽培**（即位の年・春）：木屋平の麻畑で阿波在来種を栽培
3. **収穫・繊維化**（夏〜秋）：阿波忌部の伝統技法で麻を加工
4. **織機奉納と織始め式**（10月頃）：忌部神社で奉告祭
5. **織り上げ・調進**（11月の大嘗祭直前）：完成した麁服を東京の宮中に運ぶ
6. **大嘗宮の悠紀殿・主基殿に供える**

## 🌟 阿波説における核心命題

### 1. なぜ「阿波の麻」でなければならないのか

通説的説明：
- 麻は古代から神聖視されていた
- 阿波忌部が古代から麻栽培を担当していた歴史的経緯

**阿波説の核心命題**：
> 天皇家の **本当のルーツ（祖神の地）が阿波** だからだ。自分たちの祖先の地で作られた神聖な麻布に包まれることで初めて、皇祖神からの **正当な霊力が継承** される。

### 2. 1000年以上の特権継承の意味

中臣氏（藤原氏）の台頭により、忌部氏が政治的に **完全に排除** された後も、麁服調進権だけは：
- **奪うに奪えなかった**
- **代替不可能** な祭祀権として、阿波忌部に残された
- → **皇室の本貫地に対する物的承認** の継続

### 3. 公認史としての阿波忌部

[[幕府・政府による公認と極秘調査の歴史]]：
- 江戸幕府も明治政府も、**麁服調進の世襲は公的に認めざるを得なかった**
- これは **「阿波の特権」が単なる地方伝承ではなく、公認された皇室祭祀の制度** であることの証明

### 4. 文書群の重み

| 文書名 | 内容 |
|---|---|
| **三木家文書**（中世〜近世） | 調進記録の連続性 |
| **粟飯原家文書** | 粟国造系の祭祀継承記録 |
| **古語拾遺**（807年） | 阿波忌部の祖先・天日鷲命の麻播殖 |
| **延喜式**（927年） | 大嘗祭の制度的位置づけ |

- 楮繊維から作られる

## 🌟 阿波説における意義（5層構造）

### 第1層：現代も続く特権
大正・昭和・平成・令和の四代続く三木家の麁服調進。**現代に動いている儀式** であり、伝説や古文書だけでなく **生きた物的証拠** として機能する。

### 第2層：制度的公認
古代律令から江戸幕府、明治政府、現代に至るまで、麁服調進の世襲権が **公的に承認** されてきた事実。

### 第3層：文献的根拠
『古語拾遺』『延喜式』『三木家文書』『粟飯原家文書』が一貫して **阿波忌部の特権** を記録。

### 第4層：物産的根拠
麻・穀・紙・絹・塩・水銀朱の **阿波本貫性**。大嘗祭に必要な物産がすべて阿波に集中。

### 第5層：阿波説への帰結
天皇家の本貫地が阿波であるからこそ、**祖先の地で作られた麁服でなければ霊力が継承されない** という核心命題。
