# 国造家の広域接続：伊賀・紀伊・伊豆・関東と四国

> [!summary] 要旨
> 『先代旧事本紀』巻十「国造本紀」の系譜記述をもとに、伊賀・紀伊・伊豆・関東の主要国造家を確定し、四国の国造家10家（[[四国の国造家：四国の国造の系譜と裏付け]]）との間に本紀上で確認できる接続（同祖・同系の明記）を整理する。確認できた接続は、伊余国造（伊予）―印幡国造（下総）、仲国造（常陸）―伊予国造、意岐国造（隠岐）―長国造（阿波）、都佐国造（土佐）―長国造、石見国造―紀伊国造、そして国造本紀・神武東征段が天日鷲命（同段で「粟忌部首祖」と明記）を伊賀・伊勢国造の祖とする記述である。一方、房総の「阿波国造」は天穂日命系の膳大伴氏で四国阿波とは系譜上無関係であり、伊豆国造は本紀では物部系で四国の三嶋溝杭命系とは本紀上で接続しない。本紀の「同祖」は系譜上の主張であって、実際の血縁・移動の証明ではない点に留意する。

## 1. 命題の構造

| 観点 | 史料上の整理 | 阿波説における扱い |
|---|---|---|
| 接続の根拠 | 国造本紀の「同祖」「○○国造祖」等の明記があるものに限る | 明記なき接続（音の一致・地名対応等）は仮説として分離する |
| 房総「阿波国造」 | 天穂日命系・膳大伴氏。四国阿波の粟・長両国造とは別系譜 | 同名であることをもって四国阿波と結ぶことはできない（四国ノートで確定済み） |
| 伊豆と三嶋 | 伊豆国造は本紀では物部系。三嶋溝杭命系（長・都佐）との接続は本紀にない | 社伝層（三島溝橛耳神）の接続は別層として併記する |
| 名方国造 | 国造本紀に条が存在しない（両転写で確認） | 伊賀―名方の接続主張は前提自体が成立しない |

## 3. 伊賀国造

国造本紀における伊賀の記述は三箇所に分かれ、祖が一本化されない（詳細は [[伊賀国造の二層構造_天日別命系と敢氏系]] で原文照合済み）。

| 記述箇所 | 原文（要部） | 祖・初代 |
|---|---|---|
| 神武東征段 | 「以天日鷲命為伊勢國造、即伊賀伊勢國造祖」 | 天日鷲命（同段で「粟忌部首祖天日鷲命」と明記） |
| 伊勢国造条 | 「橿原朝、以天降天牟久怒命孫天日鷲命、勑定賜國造」 | 天日鷲命（天牟久怒命の孫） |
| 伊賀国造条 | 「志賀髙穴穂朝御世、皇子意知別命三世孫武伊賀都別命、定賜國造。難波朝御世、隸伊勢國。飛鳥朝代割置如故」 | 武伊賀都別命（意知別命＝垂仁天皇皇子の三世孫、成務朝） |

- 伊賀国造の氏族は阿保氏（君）で、本拠は伊賀郡阿保村。在地の阿閇氏（敢氏）は『新撰姓氏録』で大彦命（孝元天皇皇子）の後裔とされ、国造の系統とは祖を異にする別系譜である（[[伊賀国造の二層構造_天日別命系と敢氏系]]）。
- **名方国造・アメノサヅチとの関係**：天日別命系（伊勢国造の別伝）と阿波の名方国造・天佐自能和氣命を結ぶ主張は、Vault内ノートにも今回の照合範囲にも確認できなかった。そもそも「名方国造」は国造本紀の両転写に条が存在せず（阿波関係は粟・長のみ）、本体ノート [[天佐自能和氣神社]]・[[国造設置の時代別推移：神武朝から各天皇代の国造任命]] の照合でも一次史料で未確認と確定している。したがって伊賀―名方の接続は、接続以前に前提（名方国造の実在）が史料で裏付けられていない。
- 伊賀と阿波の間に本紀上で実在する接続は、東征段が天日鷲命を「粟忌部首祖」と明記したうえで伊賀・伊勢国造の祖とする点に限る。ただし伊賀国造条の任命（武伊賀都別命）とは層が異なり、本紀内部で食い違う。

## 4. 紀伊国造・紀氏

| 項目 | 内容 |
|---|---|
| **国造本紀条** | 「橿原朝御世、神皇産霊命五世孫天道根命、定賜國造」。東征段は「以天道根命為紀伊國造、即紀河瀬直祖」 |
| **姓氏録** | 神魂命（カミムスビ）の五世孫とする点で本紀と一致（校訂注もこの一致を指摘する）。紀直等の祖 |
| **裏付け** | 『日本書紀』敏達12年条に紀忍勝（6世紀の実在国造）。『貞観儀式』巻10に国造任命の儀式を収録。律令制後も日前・國懸両宮の宮司として「国造」を称して存続した代表的な存続国造家（詳細は [[紀伊国造・紀氏（天道根命系）]]） |
| **本紀上の接続** | 石見国造条「瑞籬朝御世、紀伊國造同祖蔭佐奈朝命児大屋古命、定賜國造」― 紀伊国造と同祖の家が石見に置かれたとする明記がある |

- **紀伊忌部との関係**：紀伊国造家（天道根命系）と紀伊忌部（手置帆負命・彦狭知命系）は別系譜で、ともに名草郡に重なって所在する（[[紀伊忌部：手置帆負・彦狭知から天道根命・紀氏への系譜]]）。国造本紀に両者を系譜で結ぶ記述はない。
- 手置帆負命の帰属は史料間で揺れる。『古語拾遺』は「手置帆負命（讃岐國忌部祖也）」とし、彦狭知命を紀伊忌部の祖とする整理が一般的だが、『日本書紀』神代巻第九段の一書には手置帆負神を紀国忌部の遠祖とする異伝がある（讃岐深掘りで確認）。紀伊の忌部は国造家とは別の祭祀技術品部の層として扱う。

## 5. 伊豆国造

| 項目 | 内容 |
|---|---|
| **国造本紀条** | 「神功皇后御代、物部連祖天蕤杵命八世孫若建命、定賜國造。難波朝御世、隸駿河國。飛鳥朝御世、分置如故」（校訂系は「天蕤桙命」とし、注に姓氏録の服部連＝天御梓命の後を引く） |
| **系統** | 物部系。四国の小市国造・風速国造と同じ物部連祖の系譜網に属する |
| **後裔・奉斎** | 伊豆国一宮・三嶋大社の社家は国造の後裔とされる矢田部氏が務めた（Wikipedia「伊豆国造」） |

- **三嶋溝杭命系との関係**：国造本紀の伊豆国造条に三嶋溝杭命への言及はなく、本紀の系譜上、伊豆国造と四国の長国造・都佐国造（三嶋溝杭命系）は接続しない。
- 社伝の層では、比波預天神社の社伝が伊豆国造の遠祖・加理波夜須多祁比波預命を「三島溝橛耳神の長子」と伝える（Wikipedia「伊豆国造」）。これは社伝に基づく接続であり、本紀の物部系譜とは別層の所伝として区別する（社伝現物の照合は未取得 → 留保）。
- なお都佐国造条の校訂注は、三嶋溝杭命系について『続日本後紀』の摂津国人・長我孫（葛城事代主命八世孫）と神名帳・摂津国島下郡の溝咋神社を引く。三嶋溝杭命の本貫が摂津三島方面を示唆する注記であり、伊豆の三嶋との関係はこの注記からは導けない（未検証）。

### 6-2. 関東の系統クラスタ

1. **天穂日命系**：上海上・房総阿波・高国造（彌都侶岐命孫・弥佐比命）が天穂日命八世孫の同系として房総南部に並ぶ。出雲国造も同祖（天穂日命十一世孫）で、山陰にまで連なる大きな系譜網である
2. **神八井耳命系（多氏系）**：印波国造・仲国造が同系。伊余国造（伊予）への同祖接続を持つ（→ §8）
3. **兄多毛比命系（无耶志国造祖）**：菊麻・波伯・大嶋・胸刺（无邪志）の同族群が房総〜山陽に分布する
4. **茨城国造祖系**：師長・須志・馬來田・道口岐閇・周防の分家群（→ 6-1）
5. **大彦命系**：那須国造の建沼河命は大彦命（孝元天皇皇子）の子とされる（Wikipedia「那須国造」の系譜整理）。伊賀の阿閇氏（敢氏）・阿倍氏と祖神を共有する皇別ラインである。ただし国造本紀の那須条自体は「建沼河命孫大臣命」と記すのみで、大彦命の名は条文に現れない

### 6-3. 房総の阿波国造と忌部の関係

- 国造本紀の「阿波国造」が房総（後の安房国）を指すことは四国調査で確定済みであり、校訂注も「今安房國」と明記する。四国阿波の粟・長両国造とは系譜が異なる（粟＝高皇産霊系、長＝観松彦系／房総阿波＝天穂日命系・膳大伴氏）。
- 安房国造家と忌部の関係について史料が示すのは、系譜上の同祖ではなく**祭祀上の結節**である。安房神社（安房国一宮）は忌部氏の祖神・天太玉命を主祭神とし忌部氏による創建と伝わるが、その祭祀は安房国造（膳大伴氏）一族が担ったと見られている（Wikipedia「阿波国造」）。
- 伊甚国造条は「安房國造祖伊許保止命孫伊己侶止直」を伊甚国造とする（「安房」は写本により「安度」とも）。房総内部の分家関係であり、忌部との接続は記されない。
- 『古語拾遺』の天富命東遷と安房の斎部（忌部）の伝承は、国造家（大伴直系）とは別系統の記述であり、両者を系譜で結ぶ史料は確認できない。
- **混同への注意**：「阿波国造墓碑」（徳島県石井町・中王子神社蔵、養老7年＝723年、粟凡直弟臣・名方郡大領）は四国阿波の粟国造の金石文であり、房総の阿波国造の物証ではない。同名の「阿波国造」が併存するため、出典の帰属を常に確認する必要がある。

## 8. 広域接続図（国造本紀の系譜上で確認できるもの）

| 接続 | 本紀の根拠（原文要部） | 性格 |
|---|---|---|
| 伊余国造（伊予）― 印幡国造（下総） | 伊余条「印幡國造同祖敷桁波命児速後上命、定賜國造」（校訂系は「敷衍彥命」） | 同祖の明記。ただし『愛媛県史』は『古事記』系譜（速後上命＝神八井耳命の後裔）との矛盾を指摘する（[[四国の国造家：四国の国造の系譜と裏付け]]） |
| 仲国造（常陸）― 伊予国造 | 仲条「伊豫國造同祖建借馬命、定賜國造」 | 同祖の明記。「伊豫國造」が伊余を指すかは条文上特定できない。仲・印波とも神八井耳命系で、関東の同系が伊予に接続する形になる |
| 意岐国造（隠岐）― 長国造（阿波） | 意岐条「觀松彦伊呂止命五世孫十挨彦命」、長条「觀松彦色止命九世孫韓背足尼」 | 同一祖神（観松彦命）の系譜を共有 |
| 都佐国造（土佐）― 長国造（阿波） | 都佐条「長阿比古同祖三嶋溝杭命九世孫小立足尼」 | 同祖の明記。阿波南部〜土佐東部の同系配置 |
| 石見国造 ― 紀伊国造 | 石見条「紀伊國造同祖蔭佐奈朝命児大屋古命」 | 同祖の明記 |
| 天日鷲命 ― 伊賀・伊勢国造 | 東征段「以天日鷲命為伊勢國造、即伊賀伊勢國造祖」。同段は天日鷲命を「粟忌部首祖」と明記 | 本紀内部で阿波忌部の祖と伊賀・伊勢国造の祖を結ぶ唯一の直接記述。ただし個別条の任命（伊賀＝武伊賀都別命、伊勢＝天日鷲命）とは層が異なる |
| 那須国造 ― 伊賀・阿閇氏 | 那須条は「建沼河命孫大臣命」。建沼河命を大彦命の子とするのはWikipediaの系譜整理 | 祖神（大彦命）の共有。本紀条文自体に大彦命は現れないため、接続の強さは一段落ちる |
| 阿閉臣祖・屋主思（男心）命 ― 高志国造 | 高志条「阿閉臣祖屋主思命三世孫市入命、定賜國造」（校訂系は「屋主男心命」「世入命」） | 本紀で屋主思命系の就任地は高志（越）であり四国阿波ではない。[[阿閇氏：阿波国造・屋主思命系の祭祀氏族とその展開]] の阿波国造説は『阿波志』由来として分離済み |
| 周防国造 ― 茨城国造 | 周防条「茨城國造同祖加米乃意美」 | 同祖の明記。関東の系譜が山陽に及ぶ例 |

**接続として成立しなかったもの**：
- 伊久国造・怒麻国造の「阿波国造同祖」：seisaku転写は両条とも「阿波國造同祖」とするが、校訂系（Wikisource）は両条とも「阿岐國造同祖」と読む（伊久条「阿岐國造同祖十世孫豐島命」、怒麻条「阿岐國造同祖飽速玉命三世孫」）。飽速玉命は安芸・速谷神社の祭神で阿岐国造の祖とされ、校訂系に従えば四国阿波への接続は消える。読みが転写間で割れる以上、阿波説の根拠には使えない（[[四国の国造家：四国の国造の系譜と裏付け]] 留保2と整合。本ノートで伊久条にも同型の異同があることを新たに確認した）
- 伊豆国造 ― 三嶋溝杭命系：本紀に明記なし（社伝層のみ → §5）
- 新治国造の祖「美都呂岐命」と房総阿波国造の「彌都侶岐命」は音が一致するが、同祖の明記はなく系譜接続は未検証（seisaku転写では新治条は「吴都呂岐命」で音も分かれる）

## 9. 阿波説における意義

- 本紀の系譜網のうち、四国と他地域を結ぶ明記のある接続は、伊余―印幡、仲―伊予、意岐―長、都佐―長、東征段の天日鷲命の5件である。いずれも「同祖」という系譜上の主張であり、それ自体は氏族の移動や血縁の実証ではない。
- 房総の阿波国造と安房の忌部伝承は、安房神社の祭祀という一点で接するが、系譜は別系統である。「阿波」の同名性と忌部東遷伝承を重ねて国造家まで忌部系とみなすことは、史料の層を超えた読みになる。
- 伊豆については、本紀の物部系譜と社伝の三島系譜が別層に併存する。四国の三嶋溝杭命系との接続を主張するには社伝層の検証が前提であり、本紀を根拠にはできない。
- 伊賀については、本紀東征段が「粟忌部首祖」天日鷲命を伊賀・伊勢国造の祖とする点が阿波接続の唯一の直接記述である。一方で伊賀国造条の武伊賀都別命系とは食い違い、天日別命＝天日鷲命の同一視も阿波説仮説のままである（[[伊賀国造の二層構造_天日別命系と敢氏系]]）。

## 13. 留保（中立的併記）

> [!warning] 注意
> 1. **国造本紀の性格**：『先代旧事本紀』は後世（10世紀初頭頃）の編纂物で、国造本紀の任命記事は各国造家の家譜類に由来するとされる。本ノートの「本紀の記事」はすべて「国造本紀がそう記す」層の情報であり、正史・金石文による裏付けは §7 のとおり家ごとに分けて評価した
> 2. **転写間の異同**：seisaku転写とWikisource校訂系の間で、「阿波／阿岐」（伊久・怒麻条）、「印岐／印波」、「敷桁波／敷衍彥」、「連沼河／建沼河」、「吴都呂岐／美都呂岐」等の異同がある。本ノートは両転写を併記したが、校訂本（国史大系等）現物による確定は未取得である
> 3. **「同祖」の意味**：本紀の同祖・同系の記述は系譜上の主張であり、実際の血縁関係や氏族の移動を証明するものではない。接続図（§8）は「本紀がどう系譜づけているか」の整理である
> 4. **那須国造と大彦命**：建沼河命を大彦命の子とするのはWikipedia「那須国造」の系譜整理に依り、国造本紀の那須条の文面には大彦命は現れない。那須国造碑が裏付けるのは7世紀末の那須直の存在であり、系譜そのものではない
> 5. **伊豆と三嶋の社伝接続**：比波預天神社の社伝（三島溝橛耳神の長子）はWikipedia「伊豆国造」経由の確認で、社伝現物の照合は未取得。三嶋大社の社家・矢田部氏を国造後裔とする点も同記事の整理に依る
> 6. **安房神社の祭祀担当**：膳大伴氏が安房神社の祭祀を担ったとするのはWikipedia「阿波国造」の整理（「見られている」という推定表現）に基づく。安房国造と忌部の「祭祀上の結節」はこの推定の範囲を超えない
> 7. **紀伊忌部の帰属異伝**：手置帆負命を紀国忌部の遠祖とする書紀一書の異伝は、讃岐深掘り時の照合（粟井神社・大麻神社ノート）に基づく。本調査での書紀原文の直接照合は未了（未取得）
> 8. **未取得**：国史大系等の校訂本現物による各条の確定、『常陸国風土記』那珂国造記事の原文、比波預天神社の社伝現物
> 9. 本ノートの evidence_type は primary_source_based（国造本紀の原文照合に基づく整理のため）、confidence は 3（本紀自体の史料的限界と転写異同のため）
