# 安房国忌部家系：高山家伝承と由布津主命の系譜

> [!summary] 要旨
> **『安房国忌部家系』** は **上総忌部・高山家** に伝承されていた忌部の系図写本。**明治4年（1871）、国学者・小杉椙邨（こすぎ・すぎむら）** が高山家戸主・高山義行のもとで発見し世に出した。**「天日鷲命を初代とする安房忌部の5世代系譜」** を伝え、**「由布津主命（ゆふつぬしのみこと）＝阿八別彦命（アワワケヒコ）＝天富命（あめのとみのみこと）」** という同一神異名説、および **訶多々主命を安房忌部首の元始** とする系譜情報を含む。**[[👥 阿波忌部の神系譜]] が「阿波側」の系譜を扱うのに対し、本ノートは「安房側」の系譜** を扱う。阿波忌部の東遷を **血統的に裏付ける** 第一級の物的史料。

## 1. 命題の構造

| 通説 | 阿波説 |
|---|---|
| 安房忌部は中央忌部（斎部氏）の地方分流 | **天日鷲命を始祖とする独自系譜**、阿波忌部と直結 |
| 由布津主命は記紀に登場しない後代の創作 | **由布津主命＝阿八別彦命＝天富命**、東遷の主導者 |
| 高山家系図は近世の偽書 | **明治4年に小杉椙邨が発見した実在の系図写本**、原本は中世以前の系図に遡る |

## 2. 史料概観

|---|---|

| **発見者** | **小杉椙邨（こすぎ・すぎむら）** — 国学者 |
| **所蔵家** | **上総忌部・高山家**（戸主：高山義行） |

## 3. 系図の構造：5世代の安房忌部系譜

### 3-1. 神話的背景（系図冒頭）

系図は **天岩戸神話** から始まる：

> 八百万の神は天安川の河原に集まり、天照大神を天岩戸から出す方法を議論する。それぞれの神達が役割を担って天照大神を誘い出すことになり、**八尺瓊勾玉や八咫鏡などを用意し、阿波忌部の遠祖 天日鷲命は青和幣・白和幣を、天太玉命は太御幣を持って祈祷を行なった**。

→ 安房忌部の系譜は **天岩戸神話の祭祀貢献者** から始まる。

### 3-2. 第1代：天日鷲命（あめのひわしのみこと）

| 項目 | 内容 |
|---|---|
| **位置** | 系図初代、安房忌部の祖 |
| **職能** | 青和幣・白和幣を奉献、岩戸開きの祭祀神 |
| **背景** | **神産巣日御祖大神の孫**（系図記載） |

→ awa-otoko の重要な指摘：「**天日鷲命と天太玉命は同一人物**」とする見解もある。

→ 関連：[[天日鷲命：天岩戸の功績と「鷲」の由来]]

### 3-3. 第2代：天日鷲命の三柱の子

天日鷲命と **言苫比賣命（ことつめひめ）** との間に生まれた三柱：

| 子 | 異名 | 後裔氏族 |
|---|---|---|
| **大麻比古命** | 亦名・**津咋見命**、**津杭耳命** | **阿波忌部の祖**（[[大麻比古神社]] 主祭神） |
| **天白羽鳥命** | 亦名・**長白羽命** | **伊勢国 麻績連（おみのむらじ）の祖**、神風と共に伊勢に入り **五十鈴宮に奉仕** |
| **天羽雷雄命** | 亦名・**武羽槌命** | **倭文連（しとりのむらじ）の祖** |

→ 第2代で **阿波忌部・伊勢麻績連・倭文連** の三系統に分岐。

→ 関連：[[大麻比古神社]]、[[阿波忌部氏伝承詳細]]

### 3-4. 第3代：大麻比古命の二柱の子

大麻比古命と **磯根御氣比賣命（いそねみけひめ）** との間に生まれた二柱：

| 子 | 異名・職掌 |
|---|---|
| **千鹿江比賣命** | 「**今 千貝大明神 是也**」と記載（千葉県内の千貝大明神と同定） |
| **由布津主命** | 亦名・**阿八別彦命（アワワケヒコ）** ／ **天止美命（＝天富命）** |

### 3-5. 第4代：由布津主命＝天富命

**最重要記述**（系図中段）：

> **由布津主命は天止美命（天富命）と定め**、さらに由布津主命は **青和幣・白和幣を使用して荒妙を調達**、これは **阿波国から麻、木綿、和幣の織物を用意させたもの** であると記録している。
>
> また、由布津主命は其の地（阿波国を指す）に天日鷲命を祭祀する **忌部神社**、父・大麻比古命を祭祀する社（**大麻比古神社**）を建てて崇拝した。
>
> その後「**天止美命亦科由布津主命而更覚美土而可…**（天富命と由布津主命はさらなる良き場所を見つけるため…） 」とあり、**太占の結果から阿波忌部族を率いて東土に移動を決定** したことが記載されている。

→ 系図上で **「由布津主命＝天止美命＝天富命」** という **同一神異名説** が文献的に確定。

→ 関連：[[天富命]]、[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

### 3-6. 第5代：訶多々主命（かたたぬしのみこと）— 安房忌部首の元始

> 天止美命（天富命）はその創祀の際、天太玉命が天上から持ち来たった神宝を納め、その神宝を娘である **飯長姫命（いいながひめ）** に奉仕させる。
>
> **飯長姫命は由布都主命と結婚**し、これが安房忌部氏の祖としている。
>
> 「**阿八別彦命御合天止美命之子飯長姫命而所生子名訶多々主命是之安房忌部首之元始也**」
>
> （**阿波別け彦と飯長姫が夫婦となり訶多々主命が生まれた。是、安房忌部党首の元始なり**。）

→ 系図はここで安房忌部の **第5代・訶多々主命** に至り、**安房忌部首（あわのいんべのおびと）の元始** と定める。

### 3-7. 5世代系譜の総覧

```
第1代  天日鷲命 ─── 言苫比賣命
         │
         ├─── 大麻比古命（=津咋見命）── 阿波忌部の祖
         │
第2代    ├─── 天白羽鳥命 ── 伊勢麻績連の祖
         │
         └─── 天羽雷雄命 ── 倭文連の祖

第2代  大麻比古命 ─── 磯根御氣比賣命
         │
         ├─── 千鹿江比賣命（千貝大明神）
         │
第3代    └─── 由布津主命（=阿八別彦命=天富命）
                   │
第4代              由布津主命 ─── 飯長姫命（天富命の娘）
                                ＊由布津主＝天富命と娘が結婚という入れ子構造
                   │
第5代              訶多々主命 ── 安房忌部首の元始
```

## 4. 「由布津主命＝天富命」同一神異名説

### 4-1. 系図の決定的記述

> **由布津主命は天止美命（天富命）と定め**

→ 系図そのものが両者を **同一視** している。これは [[👥 阿波忌部の神系譜]] §2-7 の **「天富命と由布津主命の関係3説」**（同一神異名／共同指導／別人別代）のうち、**同一神異名説の最強の文献的根拠**。

### 4-2. 「阿八別彦命（アワワケヒコ）」の意味

「**阿八別彦命**」 = 「**阿波を別けた彦**」：

| 語素 | 意味 |
|---|---|
| **阿八** | **阿波（あわ）** の異表記 |
| **別（わけ）** | **分かれる・別離する** |
| **彦** | 男性の尊称 |

→ **「阿波から東国へ別れて移住した彦（指導者）」** の意。系図にも：

> 阿波から東国に移動した由布津主命は **天桅弓・天羽羽矢を用いて諸国の神達を平定** していく。手中に入れた領土を整備し、五穀豊穣も得られたことから土着の百姓も歓喜し、由布津主命の領土は拡大していった。**この業績からの由布津主命の美称として「阿八別彦命（アワワケヒコ）」と云う御名が生まれた**。

→ 「**阿八別彦**」は **東遷後の業績による美称**。元の名は「由布津主命」または「天止美命（天富命）」。

### 4-3. 大麻比古神社・忌部神社の創建者

系図によれば、**由布津主命（＝天富命）が阿波で：

- **忌部神社**（天日鷲命祭祀） — [[忌部神社]]
- **大麻比古神社**（父・大麻比古命祭祀） — [[大麻比古神社]]

を創建したと記される。

→ 阿波忌部の核心二社（[[忌部神社]]・[[大麻比古神社]]）が **由布津主命＝天富命の創建** とする系図伝承は、阿波説の最重要論点の一つ。

## 5. 阿波忌部と安房忌部の連続性

### 5-1. 「阿波の祭祀 → 安房の祭祀」の連続

系図が示す祭祀の連続性：

| 阿波 | 安房 | 神 |
|---|---|---|
| **忌部神社** | **下立松原神社** | **天日鷲命** |
| **大麻比古神社** | （関連社） | **大麻比古命** |
| （由布津主の祭祀） | **安房神社** | **天太玉命** |
| – | **莫越山神社** | **手置帆負命・彦狭知命**（讃岐・紀伊忌部祖） |

→ **由布津主命（＝天富命）は阿波・安房両国で同じ祖神を祭祀** している。

→ awa-otoko の指摘：

> 由布津主命は阿波でも天日鷲命と大麻比古命を祭祀しているように **関東でも天日鷲命と大麻比古命を祭祀していることはまず間違いない**。今に至っては天日鷲命がメジャーになり過ぎて、殆んどが天日鷲命に侵食されているようにも感じ取れる。

### 5-2. 訶多々主命と安房忌部首

第5代 **訶多々主命** が **「安房忌部首の元始」** と定められることは：

| 観点 | 内容 |
|---|---|
| **「首（おびと）」の称号** | 律令制以前の地方支配層の称号。**安房忌部首** は安房国の祭祀権を統括する氏族長 |
| **天富命の孫** | 訶多々主命は天富命の孫（天富命の娘・飯長姫と由布津主命の子） |
| **由布津主命との同一視** | 由布津主命＝天富命とすれば、訶多々主命は **天富命と自分の娘の子** という入れ子構造 |

→ この **入れ子構造**は、系図解釈の難点。**同一神異名説の限界** を示す可能性もある。

## 7. 阿波説における意義

### 7-1. 安房忌部の独自系譜の確立

『安房国忌部家系』は **中央忌部（斎部氏）の系譜とは独立した安房忌部独自の系譜** を伝える：

- **天日鷲命を初代** とする独自体系
- **由布津主命＝天富命** の同一神異名説
- **5世代の系譜情報** が具体的に記される

→ これは **『古語拾遺』（中央忌部の家伝）と並ぶ第二の忌部系譜**。

### 7-2. 阿波忌部と安房忌部の血統的連続

系図は **由布津主命（＝天富命）** を介して：

- 阿波忌部の祭祀（忌部神社・大麻比古神社）
- 安房忌部の祭祀（安房神社・下立松原神社）

の **血統的連続性** を明示する。これは **「阿波→安房」の東遷を血統で裏付ける** 第一級の物的史料。

→ 詳細：[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

### 7-3. 由布津主命の業績の具体化

系図は由布津主命の業績を具体的に記す：

| 業績 | 内容 |
|---|---|
| **阿波での祭祀** | 忌部神社・大麻比古神社の創建 |
| **太占による東遷決定** | 良き地を見つけるため太占を行い東遷を決定 |
| **東国平定** | 天桅弓・天羽羽矢で諸国の神達を平定 |
| **領土拡大** | 土着の百姓を歓喜させ領土を拡大 |
| **美称獲得** | 業績により「阿八別彦命」の美称を得る |
| **安房郡命名** | 阿波忌部の居住地を安房郡と命名 |
| **安房神社創建** | 祖父・天太玉命を祀る社（安房神社）を建てる |
| **神宝伝承** | 天太玉命が天上から持ち来たった神宝を娘・飯長姫に奉仕させる |

→ 『古語拾遺』が **大綱のみ記す** 東遷史を、本系図は **具体的事件・人物関係で詳述** する。

### 7-4. 千鹿江比賣命と千貝大明神

第3代の **千鹿江比賣命** が **「今 千貝大明神 是也」** とされることは：

- **千葉県内に千貝大明神が現存する** 可能性
- 阿波の **千鹿江比賣** ([[葦稲葉神：天日鷲命の御子神と板野郡の稲祭祀]]関連神格) との関連
- **千葉氏との接続**（粟飯原氏遠縁論）

→ 関連：[[粟飯原氏：千葉氏との繋がりと妙見・月信仰の系譜]]

### 7-5. 系図の中世以前への遡及可能性

小杉椙邨の所見：

> 全編尤疑ワシキモノナレド **何カ種トスル残嗣（残された系譜）ナドアリテ此成文セシナラン** ト

→ 写本そのものは江戸末期だが、**「種となる残された系譜」** が存在した可能性が示唆される。**原本は中世以前** の系図に遡る可能性。

## 11. 留保（中立的併記）

> [!warning] 注意
> - 『安房国忌部家系』の **写本は江戸末期** で、原本の年代は未確定。小杉椙邨自身も「全編疑わしい」と評価しているが、**「種となる残された系譜が存在した可能性」** も指摘
> - 「**由布津主命＝天富命**」とする同一神異名説は系図に明記されるが、**他史料（『古語拾遺』等）では両者は別人として記される** 場合もある。本ノートは系図記述を中心に整理するが、**他説との比較は別途必要**
> - 「**訶多々主命＝安房忌部首の元始**」とする系譜情報は、他史料による裏付けが限定的
> - 「**千鹿江比賣命＝千貝大明神**」の同定は系図記述に依拠する
> - **「由布津主命と飯長姫（天富命の娘）の結婚」** は、由布津主命＝天富命と同一神とすると **「自分の娘と結婚」** という入れ子矛盾が生じる。この点は系図解釈の重要論点
> - 高山家本は **中央忌部（斎部氏）の系譜と独立** した別系統。記紀・古語拾遺・本系図の **三層比較** が史料批判的に必要
> - 本ノートのevidence_typeは "primary_source_based"、confidence は4（高位）— 系図写本という具体的物的史料が存在するため
