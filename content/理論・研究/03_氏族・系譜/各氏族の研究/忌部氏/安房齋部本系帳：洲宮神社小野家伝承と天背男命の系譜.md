# 安房齋部本系帳：洲宮神社小野家伝承と天背男命の系譜

> [!summary] 要旨
> **『安房齋部本系帳』＝『斎部宿祢本系帳』** は、安房国洲宮神社（千葉県館山市洲宮）の祠官・小野家が所蔵してきたとされる安房忌部の系譜文献である。神魂命を始祖とし、**天背男命** を中軸に、天日鷲翔矢命・天比理刀咩命・天津羽羽命・天萬栲幡千幡比賣命・櫛明玉命など6御子を横展開する系譜を伝える点に特徴がある。ただし **原本は現存せず**、内容の確認は写本の伝承と阿波説系ブログ・『洲宮神社縁起』の翻訳に依存する。天背男命という神格自体は『新撰姓氏録』『先代旧事本紀』にも見えるが、本系帳の系譜全体が古代史料で裏付くわけではない。本ノートは、確認できる事実（洲宮神社の公的情報・姓氏録の記載）と、本系帳の伝える系譜情報（未検証を含む）を分離して併記する。

## 3. 祭神と社伝

### 3-1. 天背男命という神格

天背男命（あめのせおのみこと）は、記紀の本文には系譜の中軸としては現れないが、以下の古代史料に名が見える。

- 『先代旧事本紀』天神本紀：饒速日命の天降りに随行した32神の一とされ、山背久我直の祖とされる（二次資料による確認）
- 『新撰姓氏録』：左京神別・宮部造の条に「天壁立命 男 天背男命 之後」とあり、天背男命は天壁立命の子で宮部造の祖とされる。また山城国神別・今木連の条は「神魂命 五世孫 阿麻乃西乎乃命 之後」とし、「阿麻乃西乎乃」は天背男命の音写と解される（§7参照）

→ 詳細：[[天背男命：阿波忌部の祖父神と「一神異名」群]]

### 3-2. 后神・八倉比賣命

本系帳は天背男命の項に「亦名を天石門別命、明日名門命、后神が八倉比賣命」と注記するとされる。八倉比賣命は阿波国の式内社・天石門別八倉比売神社の祭神である。この「天背男命＝天石門別命」等の同一視は、平田篤胤の「一神異名」説に連なる解釈であり、古代史料で確定した同一視ではない（留保参照）。

→ 関連：[[八倉比賣命：阿波最高神階を授かった謎の女神]]

### 3-3. 洲宮神社の社伝

洲宮神社の社伝では、神武天皇元年に天富命が魚尾山に神社を創建し、当時海辺にあったことから「洲神」「洲宮」と呼ばれたと伝える（Wikipedia「洲宮神社」）。『古語拾遺』（807年）は、天富命が阿波国を開拓した後、阿波忌部氏の一部を率いて房総半島に上陸したとする大綱を記すが、天背男命・本系帳の系譜情報は記さない。

## 4. 歴史

### 4-1. 后神天比理乃咩命神社をめぐる経緯

- 「天比理刀咩神」は六国史に度々登場し、神階の陞叙を受けている（神階の詳細は洲崎神社側の記事にまとめられる）
- 延長5年（927年）の『延喜式』神名帳に「后神天比理乃咩命神社 大 元名洲神」と記載され、大社に列格
- 江戸時代から、洲宮神社と洲崎神社の間でどちらが式内社か争われた。明治5年（1872年）に教部省は洲宮神社を式内社と定めたが、翌明治6年（1873年）に決定を覆して洲崎神社を式内社とした。洲宮神社では文永10年（1273年）の火災で古記録を失ったことが指定変更の原因の一つと主張しているという
- 『洲崎神社伝記』によれば、洲宮神社は始め明神山の洲の辺に鎮座し、後に魚尾山へ遷座、文永10年の火災で社殿を焼失して仮宮にあり、永享11年（1439年）10月に現在地へ遷座したという。現在地からも祭祀に使われた鏡や土器が出土している

### 4-2. 本系帳の伝来について

本系帳が小野家にいつから伝来したか、写本がいつ作られたかは、今回の照合範囲では公的資料で確認できなかった。本系帳の内容を知る経路は、阿波説系ブログ（kohun-jinjya）による紹介と、『洲宮神社縁起』の翻訳（千葉まほろば神社）等に依存する（留保参照）。

## 5. 系図の構造と6御子

### 5-1. 縦系譜：神魂命から天日鷲翔矢命まで

本系帳は、神魂命（かみむすひ）を始祖として天日鷲翔矢命に至る7世代の縦系譜を記すとされる：

```
第1代 神魂命（かみむすひ）
│
第2代 角己利命（つぬこりのみこと）
│
第3代 天底立命（あめのそこたちのみこと）= 亦名 天壁立命（あめのかべたちのみこと）
│
第4代 五十狭布魂（いさふたま）
│
第5代 伊加志保魂命（いかしほたまのみこと）
│
第6代 天背男命（あめのせおのみこと）= 中軸祖父神
│
第7代 天日鷲翔矢命（あめのひわしかけるやのみこと）= 阿波忌部の祖
```

この配置では天背男命は神魂命の五世孫に当たり、『新撰姓氏録』今木連条の「神魂命 五世孫」と世代数が一致する。一方、姓氏録・宮部造条は天背男命を天壁立命の「男（子）」とし、本系帳で天壁立命（天底立命の亦名）と天背男命の間に2世代を挟む配置とは世代数が整合しない（留保参照）。

### 5-2. 神魂命系という出自

神魂命は出雲系の祖神で、高皇産霊尊（タカミムスヒ）と対をなす造化三神の一柱。本系帳の系譜は、阿波忌部が高天原系（タカミムスヒ）ではなく出雲系（カミムスヒ）の出自を主張する形になる。「阿波における出雲勢力の痕跡と整合する」とする読みは阿波説の解釈であり、史料上の裏付けは本系帳自体に依存する。

→ 関連：[[積羽八重事代主神と阿波：大宜都比売命の配偶神としての海洋王権]]、[[大国主命と天日鷲命：阿波忌部の祖神との同一視説]]

### 5-3. 天背男命の6御子

本系帳は、天背男命の御子として6柱の神を挙げるとされる（出典欄は旧稿の整理に基づく。各出典の個別照合は未了。留保参照）：

| 御子の名 | 配偶／後嗣 | 出典（旧稿の整理） |
|---|---|---|
| **天日鷲翔矢命** | 阿波忌部の祖 | 『斎部宿祢本系帳』 |
| **許登能麻遅命**（ことのまじ） | 天児屋根命の母／父は玉主命 | 『藤原氏本系帳』 |
| **天比理刀咩命** | 天太玉命の后神（Wikipedia「天比理刀咩命」でも天太玉命の后神・忌部氏の祖神の一柱とされる） | 『延喜式神名帳』『続日本後紀』 |
| **天津羽羽命** | 八重事代主命の妻／父神は天石門別神 | 『土佐風土記』『土佐國式社考』 |
| **天萬栲幡千幡比賣命** | 天児屋根命の妻／亦名 天棚機比賣命 | 『斎部宿祢本系帳』 |
| **櫛明玉命** | 出雲国玉作の祖（『古語拾遺』が「出雲国玉作の祖」と位置付ける。記紀では玉祖命等の名で現れる） | 『古語拾遺』 |

### 5-4. 中臣氏の「二重の外祖父」構造とその読み

本系帳の整理では、許登能麻遅命が天児屋根命（中臣氏祖）の母、天萬栲幡千幡比賣命が天児屋根命の妻とされ、天背男命は中臣氏祖の母と妻の双方の父に当たる。この構造を「忌部側が中臣氏を血統的下位に置く戦略系譜」と読むのは阿波説の解釈であり、本系帳が中立的歴史記録か戦略的家伝かは議論の余地がある（留保参照）。

### 5-5. 『洲宮神社縁起』所載の安房開拓譚

『洲宮神社縁起』は系譜情報を物語化した資料で、千葉まほろば神社に翻訳が伝わる。縁起そのものの分析は [[洲宮神社縁起：安房開拓神話を伝える式内社の根本史料]] に分離されており、本節は要点のみを引く。なお縁起の成立年代は不明（平安時代以降とされる）であり、以下の物語は縁起の伝承として扱う。

- **序文**：天比理刀咩命は天背男命と八倉比売命の御子で天布止玉命（天太玉命）の妃神。天止美命（天富命）は天布止玉命と久志備の御子とされる
- **安房開拓譚**：神武天皇の時代、天止美命が天日鷲命の孫・由布津主命に麻と穀の殖産を命じ、阿波国の忌部諸氏を率いて東国へ向かった。天梔弓・天羽々矢で害獣を狩り払い、獲物を積み上げた場所を鹿倉山と名づけた。由布津主命は阿八和気毘古命とも称えられたとされる。※『古語拾遺』は天富命が「日鷲命之孫」を率いたと記すが孫の名は記さず、「由布津主命」の名は記紀・『古語拾遺』・『先代旧事本紀』・風土記には確認できない（[[由布津主命]]ノートの照合結果）
- **地名語源**：穀木・長麻・狭布佐の名が起こり、「布佐（ふさ）は阿波の古い言葉に由来し国名を総（ふさ）とした」「阿波国忌部が住んだ地は安房（あわ）」とする。『古語拾遺』の「麻＝総」とは異なる縁起独自の説である
- **安房神社の創建**：天止美命が宮地を定めて正殿を営み、天布止玉命が持ち降した八坂の珠を御霊代として安房大神を鎮め、娘の飯長姫命を御手代として仕えさせたとされる
- **洲宮神社の創建**：大刀自・天比理刀咩命が飯長姫命に着いて「白波の寄せる、うまし小浜こそ、我が宮地にふさわしい」と神託し、天止美命は真経津鏡を御神体として鎮座させた。これが洲宮の名の由来とされる
- **天日鷲翔矢神の出現**：金色の羽の鳥が現れ神が人に着いて「我は天日鷲翔矢神である」と告げ、由布津主命は新宮を造って祀り松原神社と称えたとされる（[[下立松原神社]]の創建譚）

### 5-6. 下立松原神社について

下立松原神社は南房総市に同名社が2社（旧白浜町・旧千倉町）あり、いずれも天日鷲命を主祭神とし、式内社「安房国朝夷郡 下立松原神社」の後裔社を称している。どちらが後裔社かは決め手がなく未確定である（Wikipedia「下立松原神社」）。両社の社伝とも、天富命とともに安房に渡った由布津主命が神武天皇元年に天日鷲命を祀ったのに始まると伝える。旧稿が言及した「壁画殿」（由布津主命・飯長姫命・天日鷲翔矢神の絵画）の存在は、今回の照合範囲では公的資料で確認できなかった（留保参照）。

## 6. 阿波説における意義

### 6-1. 「阿波・安房・畿内」の祭祀統合論

阿波説では、本系帳が天背男命の御子6柱を介して阿波・安房・出雲・尾張・伊勢・畿内を統合する祭祀ネットワークを記述すると読み、阿波忌部が古代日本の祭祀氏族のネットワーク中枢に位置する物的証拠と位置付ける。ただしこの読みは本系帳の系譜情報の真実性を前提としており、その前提自体は未検証である。

| 祭祀地 | 関連神 |
|---|---|
| **阿波** | 天日鷲翔矢命（[[忌部神社]]）、八倉比賣（[[天石門別八倉比売神社]]） |
| **安房** | 天比理刀咩命（[[安房神社]] 后神、[[后神天比理乃咩命神社]]）、天日鷲翔矢命（[[下立松原神社]]） |
| **出雲** | 櫛明玉命（玉作の祖） |
| **土佐** | 天津羽羽命（事代主の妻） |
| **畿内（中臣）** | 許登能麻遅命（天児屋根命の母）、天萬栲幡千幡比賣命（天児屋根命の妻） |

### 6-2. 安房・阿波二系譜の補完関係（阿波説の整理）

| 系譜資料 | 中軸 | 強調 |
|---|---|---|

### 6-3. 平田篤胤「一神異名」説の根拠とされる点

本系帳の「天背男命＝亦名 天石門別命・明日名門命・后神 八倉比賣命」という注記は、平田篤胤の「一神異名」説（天石門別命・明日名門命・天背男命・天石門別安国玉主命等は一神の異名で、実は天手力男神とする）の根拠の一つとされる。これが正しければ阿波忌部の祖父神＝天手力男神となり、『古事記』「手力雄命は佐那那縣に坐す」の佐那那縣を佐那河内とする阿波説の読みと接続する。ただし「一神異名」説自体は江戸期国学者の解釈であり、現代学術での検証は限定的である。

→ 関連：[[佐那河内：佐那縣と天岩戸神話の地]]、[[王ケ原神宮]]、[[佐那河内村大川原高原]]

### 6-4. 中臣氏との祭祀権闘争の系譜的論拠とする読み

本系帳が「天背男命が中臣氏祖・天児屋根命の母と妻の双方の父」と記す構造を、延暦22年（803年）の斎部広成の権利復権運動や『古語拾遺』（807年）と並行する系譜的論拠と読むのは阿波説の解釈である。

→ 関連：[[阿波忌部氏伝承詳細]]、[[15_忌部氏系図・氏文]]
