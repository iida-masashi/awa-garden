# 三系譜比較：安房忌部伝承・御祖略系・粟飯原家系図の差分検証

> [!summary] 要旨
> 阿波忌部・安房忌部の系譜を伝える三系統の文献——**①安房忌部の伝承**（[[安房国忌部家系：高山家伝承と由布津主命の系譜]] / [[安房齋部本系帳：洲宮神社小野家伝承と天背男命の系譜]]）、**②御祖略系**（[[御祖略系：天之御中主神から天午刀男神への父神縦系譜]]）、**③粟国造粟飯原家系図 神代本系**（[[大宜都比売命家系図：粟国造粟飯原家系図と神系譜の総合]]）——を構造的に比較・検証する。**起点神・中軸神・後裔氏族・地理的焦点・編纂目的** の5観点で差分を整理し、**「同一神を異名で記録する三系図の補完関係」** か、**「異なる祭祀権主張の競合系譜」** かを判別する。結論：**三系図は同一の神話的母胎から派生した「祭祀権主張の三角構造」** を形成し、**安房側・阿波側・粟国造側がそれぞれ異なる中軸神を立てて自家の正統性を主張** していると読む。各系図は **「自家の祖神を最高位に置く戦略的構造」** を持つが、**核心の神格群（天日鷲・大宜都比売・天背男／天午刀男・八倉比賣・天太玉）は共通** している点で、**根本的な歴史的母胎の存在** を裏付ける。

## 3. 各系図の中軸神比較

### 3-1. 中軸神の置換構造

各系図は **同じ「祖神域」の異なる神を中軸** に据える：

```
        ┌─ ①-A：由布津主命＝天富命  ← 「東遷指導者」中心
        │
祖神域 ─┼─ ①-B：天背男命           ← 「祖父神」中心
        │
        ├─ ②：天午刀男神            ← 「祖父神」中心（天背男命と同一視可能）
        │
        └─ ③：積羽八重言代主神＋大宜都比賣神 ← 「祭神夫婦」中心
```

→ **①-Bと②は同一神を異なる名前で中軸化** している可能性が高い：

| 系図 | 中軸神 | 后神 |
|---|---|---|
| ①-B 小野家本 | **天背男命** | **八倉比賣命** |
| ② 御祖略系 | **天午刀男神** | （明示なし、ただし大阿波女神の母として暗示） |
| 平田篤胤「一神異名」説 | **天背男命＝天午刀男（天手力男）＝天石門別命** | 八倉比賣命 |

→ **「天背男命＝天午刀男神」** とすれば、①-Bと②は **同一の祖父神を中軸とする補完系図**。

### 3-2. 高山家本と粟飯原家系図の中軸の差

| 系図 | 中軸 | 強調点 |
|---|---|---|
| ①-A 高山家本 | **由布津主命＝天富命** | **東遷指導者・安房開拓** |
| ③ 粟飯原家系図 | **積羽八重言代主神＋大宜都比賣神** | **阿波での祭神夫婦** |

→ **中軸は地理的焦点を反映** している。高山家本（安房側）は **東遷主導者**、粟飯原家系図（阿波側）は **阿波本貫の祭神夫婦**。

## 9. 矛盾点の検証

### 9-1. 由布津主命と天富命の関係

| 系図 | 由布津主命と天富命 |
|---|---|
| ①-A 高山家本 | **同一神異名**（由布津主命＝天止美命＝天富命） |
| ①-B 小野家本 | 言及なし |
| ② 御祖略系 | 言及なし |
| ③ 粟飯原家系図 | 言及なし |

→ ①-A 独自の同一神論。**②・③の阿波側系図は由布津主命を扱わない**。

→ これは **「安房側系図」の特徴**：阿波→安房の東遷指導者として**両神名を統合**する必要があった。

### 9-2. 大宜都比賣命の父神の差

| 系図 | 大宜都比賣命の父神 |
|---|---|
| ①-A 高山家本 | 言及なし |
| ①-B 小野家本 | **天背男命**（天背男命の后神＝八倉比賣命） |
| ② 御祖略系 | **天午刀男神**（4御子の一） |
| ③ 粟飯原家系図 | **天午刀男神**（同一文書の御祖略系を参照） |

→ ②と③は **「天午刀男神＝大宜都比賣命の父神」** で一致。

## 11. 阿波説における意義

### 11-1. 「祭祀権主張の三角構造」

三系図は **異なる氏族が同一神話的母胎から自家系譜を構築** した三角構造：

| 系図 | 主張する祭祀権 |
|---|---|
| ①-A 高山家本 | **安房忌部首** の祭祀権 |
| ①-B 小野家本 | **洲宮神社祠官家**（中臣氏より上位の血統） |
| ② 御祖略系 | **粟国造**の天津神直系性 |
| ③ 粟飯原家系図 | **粟飯原氏**（粟国造末裔）の現代までの祭祀権 |

→ **各系図は自家の祖神を最高位に置く戦略** を取りつつ、**核心の神格群は共通** している。

→ これは **「同一の歴史的母胎から派生した複数の家伝の競合構造」** であり、**逆説的に歴史的母胎の実在を裏付ける**。

### 11-2. 「異名重層構造」の理解

三系図に共通する **「異名重層構造」**：

| 異名関係 | 系図 |
|---|---|
| 天背男命＝天午刀男神＝天手力男命 | ①-B、②、平田篤胤 |
| 大宜都比賣命＝八倉比賣命＝大粟比売命 | ③ |
| 大宜都比賣命≠八倉比賣命（母娘） | ①-B（母）と③（同一神） |
| 由布津主命＝天富命＝阿八別彦命 | ①-A |

→ **異名解釈の差** が三系図の最大の **史料批判上の論点**。

### 11-3. 史料批判の三段階

三系図を史料批判する際の段階：

| 段階 | 内容 |
|---|---|
| **第1段階** | **「核心神格群の一致」** を確認（天日鷲・大宜都比売・天背男／天午刀男・天太玉） |
| **第2段階** | **「異名と中軸神の差」** を整理（各系図がどの神を中軸に置くか） |
| **第3段階** | **「編纂目的と政治的動機」** を分析（誰の祭祀権主張か） |

→ 三段階の史料批判により、**「神話的母胎の歴史的実在性」と「各家の戦略的編纂」を分離** することが可能。

### 11-4. 統合的歴史像

三系図を統合すると：

1. **阿波の神代祭祀** ＝ 天午刀男神（＝天背男命）と大宜都比賣神を中心とする父神・娘神祭祀（②③）
2. **天日鷲命を祖とする阿波忌部** が成立（②③）
3. **由布津主命（＝天富命）が東遷** し、安房を開拓（①-A）
4. **訶多々主命が安房忌部首** となる（①-A）
5. **洲宮神社祠官家・小野家** が中央祭祀権を主張（①-B）
6. **粟国造・粟飯原氏** が阿波で34代継承（③）
7. **1341年に祭官職簒奪**（③）
8. **明治期の家名復活運動**（②③編纂）

→ **三系図の統合により、阿波忌部・安房忌部・粟国造の3000年に及ぶ歴史像** が再構築可能。
