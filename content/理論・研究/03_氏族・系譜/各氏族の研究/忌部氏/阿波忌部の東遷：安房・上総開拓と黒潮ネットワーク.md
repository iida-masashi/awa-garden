# 阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク

> [!summary] 要旨
> 阿波忌部の東遷の動機・経路・主要人物を扱う専門ノート。『古語拾遺』（807年・斎部広成）を根本史料とし、天富命率いる組織的東遷プロジェクト、黒潮ネットワーク（阿波→紀伊→伊豆→房総）、阿久留王伝承を統合的に整理する。地名「安房（あわ）＝阿波由来」「総（ふさ）＝麻の豊穣地」は音韻だけでなく『古語拾遺』に明文化された制度的命名とみる。さらに小櫃川を遡る内陸忌部、印旛沼の忌部・宗像・物部の三系統祭祀、中央斎部氏との関係までを扱う。東遷先の物的痕跡は別ノートに分離。

## 2. 『古語拾遺』の東遷記事

斎部広成（忌部広成）が807年（大同2年）に平城天皇へ撰上した『古語拾遺』は、阿波忌部の東遷を伝える根本史料である。ただし同書は斎部氏が中臣氏との職掌争いの中で自氏の伝承・主張を記した書であり、中立的な「公式記録」ではない。東遷記事の評価にはこの氏族側の視点を含む点に留意が必要である。

原文（東遷にかかわる部分）:

> 天富命更求沃壌、分阿波齋部率往東土、播殖麻穀。好麻所生、故謂之總國。穀木所生、故謂之結城郡（古語、麻謂之總。今爲上總下總二國是也）。阿波忌部所居、便名安房郡（今安房國是也）。天富命即於其地立太玉命社、今謂之安房社。故其神戸有齋部氏。

- **天富命**：『古語拾遺』本文の注記に「天富命（太玉命之孫）」とあり、太玉命（天太玉命）の孫とされる
- **「肥饒地」を求めて**：麻・穀（カジノキ）の栽培適地（産業的動機）
- **「総（ふさ）」と「安房（あわ）」の命名**：『古語拾遺』は地名の由来を阿波斎部の移住に求める。あわせて、穀木の生えた地を **結城郡** と名づけたとも記す（旧稿の引用はこの一節を欠いていた）
- **安房社**：天富命がその地に太玉命の社を立てたのが安房社（現・安房神社）で、その神戸に斎部氏がいる、と記す

→ 『古語拾遺』の叙述の範囲では、東遷は神武天皇の命を受けた天富命が忌部諸氏を率いる事業として描かれる。これを「国家的・組織的プロジェクト」と評価するのは同書の叙述に基づく阿波説の読みであり、同時代の他史料による裏付けはない。

## 4. 阿久留王伝承（房総先住勢力との対峙）

阿波説では、天富命率いる阿波忌部の上陸は無人地への開拓ではなく **先住勢力との対峙** を伴ったと読み、房総半島の伝承に残る **阿久留王（あくるおう）** を、忌部が直面した先住勢力の象徴と位置づける。

ただし、伝承そのものの内容はこの読みと異なる（2026-11-15照合）:

- 阿久留王は **上総国鹿野山（現・君津市）を拠点とした蝦夷の首長、もしくは鬼** とされ、『房総志料』『南総郡郷考』『上総町村誌』等の地誌では **ヤマトタケルによって討たれた** と伝わる（Wikipedia「阿久留王」）。その名は正史には見られない
- 阿久留王が天富命・忌部氏と争ったとする文献・伝承は確認できない。「忌部の対峙相手」と読むのは阿波説の解釈である
- 阿久留王伝承地は鹿野山周辺（鬼泪山・阿久留王塚など）に伝わるが、これが「阿波忌部の進出経路と対応する」という整理も阿波説側のものである

→ この対峙構造は、神武東征における先住勢力との対峙構造（[[神武東征阿波ルート説]]）と類似する。**祭祀氏族の東進と先住勢力の服属** が古代日本の国家形成のひとつの型であった可能性。

## 5. 中央忌部との関係

阿波説では、阿波忌部の東遷は **中央忌部（斎部氏）の指揮系統下** で行われたと考える。

- 中央の斎部（忌部）氏は、地方忌部氏を **部民として従え**、朝廷儀式の祭礼具準備を統括したとする
- 阿波忌部はその有力地方氏族として、麻・穀の供給と東国開拓の実働を担当したとする
- 東遷後の安房忌部も、中央斎部氏との文書のやりとり（公文書・神社認定）で繋がり続けたとする

→ ただし本節の出典は阿波説ブログ（下記リンク）のみで、いずれの主張も一次史料・公的資料では未検証である（§9留保4）。詳細は [🔍 阿波忌部氏NO2：中央斎部氏と地方忌部氏の関係](https://tono202.livedoor.blog/archives/30148963.html) 参照。

## 6. 阿波説における位置づけ

阿波忌部の東遷は、阿波説の **三大命題の一つ**（始祖伝承・産業祭祀・東遷）として位置づけられる。

- 地名「安房・総」の阿波由来は **音韻一致だけでなく、『古語拾遺』に明文化された制度的命名**
- 東遷は **個別の漂着** ではなく **組織的開拓プロジェクト**（天富命指揮、麻・穀の播殖）
- 黒潮ネットワークを介した広域展開（紀伊・伊豆・茨城へも痕跡）

→ ただし、近代以降に流布した「阿波忌部が全国を開拓した」式の拡大解釈には批判的距離が必要。**『古語拾遺』記載の範囲（安房・上総中心）**と、**後世の付加伝承**は分けて評価する。

→ 中世以降の阿波忌部の連続性（麁服貢進の継続）と、近代の言説構築は別問題（[[近代の忌部強調史観の形成：大正大嘗祭以後の阿波説的言説の構築]] 参照）。

### 7-2. 富崎神社：天富命の磐座祭祀

**富崎神社（君津市戸崎）** は阿波忌部上総拠点の最重要社と阿波説では位置づけられる。以下はいずれも地誌『小櫃川流域のかたりべ』の伝える創建譚・地名解釈であり、公的資料による裏付けはない（祭神自体も資料により異なる。§7-1参照）:

- 当地に進んだ水稲耕作技術をもたらした忌部氏が **「天富命」の磐座** を祀り、新穂を供える新嘗祭を行ったと伝える
- その磐座の上に富崎神社が建立されたと伝える
- **「とみさき → とさき（戸崎）」** の地名転訛（同地誌の説）
- 周辺地名：**「梶開」「梶畑」**（カジノキ＝穀木由来）、**「岩出」**（磐座切り出し地）、**「富田」**（豊かな水稲の地）とする解釈（同地誌の説）

→ **磐座祭祀＋地名＋稲作伝承** の三点セットが揃う例として同地誌は紹介するが、創建譚の史料的裏付けは未検証である。

### 7-3. 「富む」の語源と天富命

『小櫃川流域のかたりべ』の決定的記述：

> 忌部氏祖神の一柱「**天富命**」は穀物の神とされ、**穀物が豊かに実ることを、命にちなみ「富む」というようになった** そうです。

→ 日本語「富む（とむ）」の語源が **天富命** にあるとする伝承。阿波忌部の **穀物豊穣神格** が日本語の根幹に組み込まれている。
