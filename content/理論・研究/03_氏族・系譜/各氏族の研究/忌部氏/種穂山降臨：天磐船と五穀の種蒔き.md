# 種穂山降臨：天磐船と五穀の種蒔き

← ポータルへ戻る

> [!summary] 要旨
> 阿波忌部の祖神 **天日鷲命（あめのひわしのみこと）** が「**天磐船（あめのいわふね）**」に乗って阿波の **種穂山（吉野川市山川町）** に降臨し、麻・五穀の種を蒔いて開拓を始めたとする伝承。地名「**麻殖（おえ）郡**」および国名「**阿波（粟）**」の起源とされ、阿波忌部の **始祖神話の中核** をなす。本ノートは降臨神話の構造と、阿波説における意義を整理する。

---

## 1. 神話の概要

### 1-1. 降臨の構造

| 要素 | 内容 |
|---|---|
| 降臨神 | 天日鷲命 |
| 降臨手段 | 天磐船 |
| 降臨地 | 種穂山（吉野川市山川町、種穂忌部神社所在地） |
| 行為 | 麻・五穀の種を山頂で蒔き、開拓を主導 |
| 結果 | 地名「麻殖（おえ）郡」「粟（あわ）国」が生まれる |

### 1-2. 種穂山と関連神社

- **種穂忌部神社**：吉野川市山川町の山頂付近に鎮座。「種穂」の社名がそのまま神話の核を保持している。
- **木綿麻山（高越山）**：種穂山と隣接する忌部の聖域。修験道とも結びついた阿波忌部の信仰中枢。
- **忌部神社**：麻殖郡の中央忌部祭祀の本拠（後代の遷座論争あり）。

→ 詳細：[[阿波忌部の始祖伝承：天日鷲命と種穂山降臨]]、[[木綿麻山（高越山）：忌部の聖域と修験の源流]]

## 2. 神話の地名学的読解

### 2-1. 「麻殖（おえ）郡」の地名起源

「**麻殖**」は文字通り **「麻を植える」** を意味する。種穂山で天日鷲命が麻を植えたという神話が、そのまま地名として固定化された。麻殖郡は阿波忌部の本拠地として『延喜式』にも記録される。

### 2-2. 「阿波（粟）」国名の起源

「**粟（あわ）**」は五穀の一種であり、天日鷲命が種穂山で種蒔きをしたという伝承が、国名「**粟国（あわのくに）→阿波国**」の起源となったと阿波忌部伝承は語る。これは「**国名そのものが忌部の事績に由来する**」という、極めて強い氏族的アイデンティティの主張である。

### 2-3. 「天磐船」の含意

「**天磐船**」は記紀神話で **饒速日命（ニギハヤヒ）** の河内降臨にも使用される神話的装置。種穂山降臨で同じモチーフが用いられることは、**阿波忌部祖神と饒速日命（物部祖神）との祭祀的近接性** を示唆する。

→ [[天火明命（アメノホアカリ）]]、天火明命_真の天孫降臨説

## 3. 種蒔き神事の歴史的位相

種穂山降臨神話は、単なる神話ではなく **古代農業・産業の定着プロセス** を神話化したものと解される。

| 要素 | 史実的読解 |
|---|---|
| 天日鷲命の降臨 | 阿波忌部氏族の阿波定着 |
| 五穀の種蒔き | 稲作以外の畑作技術（麻・粟・楮）の導入 |
| 天磐船 | 海路・河川による氏族移動の象徴 |
| 種穂山 | 山岳祭祀拠点としての聖域選定 |

阿波忌部が **麻・穀（こうぞ）・楮の栽培技術** を持ち込んだ氏族であることは、後代の **大嘗祭麁服貢進** の連続性によっても傍証される。

→ [[阿波忌部の産業：麁服と麻・穀・紙の伝統]]、[[阿波忌部氏の歴史と産業_麻・穀・紙が支えた古代王権]]

## 4. 阿波説における意義

種穂山降臨神話は、阿波説の **以下の論点を同時に支える**：

1. **「阿波（粟）」国名そのものが忌部の事績** ──地名学的に阿波が忌部の本貫であることを主張可能。
2. **大嘗祭麁服貢進の根拠** ──天日鷲命が種を蒔いた土地で育った麻が、皇統儀礼に直結する。
3. **天磐船モチーフの共有** ──物部氏（饒速日命）との祭祀的接続を示唆。
4. **山岳信仰の起源** ──種穂山〜高越山の修験道伝統の起点。

## 7. 留保

> [!warning] 注意
> - 種穂山降臨神話は『古語拾遺』（807年、斎部広成）や中世以降の阿波の地誌・社伝に依拠する。**記紀本文には直接記載がない**。
> - 「**麻殖郡**」「**粟国**」の地名起源を全面的に種穂山降臨に求めるのは伝承的読解であり、別系統の語源説（地形語・他氏族祭祀）も存在する。
> - 種穂忌部神社と忌部神社（中央）の関係は、近代以降の **忌部神社遷座論争**（[[忌部神社の遷座論争：山崎から二軒屋まで]]）の文脈で再考が必要。
> - 天磐船モチーフの共有を以て **物部氏と忌部氏を同一系譜** とする論には飛躍がある。あくまで「祭祀的近接」の指摘に留めるべき。
