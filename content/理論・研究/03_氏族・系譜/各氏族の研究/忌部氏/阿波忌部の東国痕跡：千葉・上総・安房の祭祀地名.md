# 阿波忌部の東国痕跡：千葉・上総・安房の祭祀地名

> [!abstract] 本ノートの役割
> 阿波忌部の東遷先である **房総半島（千葉県）** に残る、**地名・神社・祭祀痕跡** を統合する専門ノート。東遷の「経路と動機」を扱う [[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] に対し、本ノートは **「東遷先で何が残っているか」（到着地の物的痕跡）** を集約する。

## 1. 核心命題

| 論点 | 内容 |
|---|---|
| **「安房（あわ）」の地名** | 『古語拾遺』は天富命が阿波斎部を率いて東上した記事の中で「阿波忌部の居る所、便ち安房郡と名づく（今の安房国是れなり）」と記す。安房の名が「阿波」に由来すると解するのはこの記事に基づく伝承的理解であり、『古語拾遺』自体は命名の理由を明示しない（10. 留保1） |
| **「総（ふさ）」の語源** | 『古語拾遺』は「好き麻の生ずる所なり。故に之を総の国と謂う」とし、古語で麻を「総」と謂った（今の上総・下総二国）と注する |
| **大原神社の分布** | 君津・流山・習志野の三社が阿波説ブログで検討対象とされてきたが、公的資料で天太玉命を祀るのは君津市平山社のみ。流山社は祓戸四神、習志野社（大原大宮神社）は伊奘諾尊・伊弉冉尊らを祀り、三社を一括して「天太玉命祭祀の物的痕跡」とする整理は成立しない（3節・10. 留保3） |
| **熊野祭祀との接続** | 上総袖ヶ浦の熊野神社伝承に「忌の語源＝熊」とする説（fusaブログの仮説）。公的資料では未確認（4節・10. 留保4） |

## 3. 大原神社群と大原足尼祭祀

千葉県内の大原神社三社（君津市平山・流山市平和台・習志野市実籾）は、阿波説ブログ（fusa「未知の駅 總フサ」）で体系的に検討されてきた。しかし公的資料で確認できる各社の祭神は次のとおりで、**三社とも天太玉命を祀るわけではない**。

| 神社 | 所在地 | 公的資料で確認できる祭神・由緒 |
|---|---|---|
| 大原神社 | 君津市平山 | 天児屋根命・天太玉命の二柱（神社庁系資料）。式外社・旧郷社。由緒は「古昔大和国奈良に鎮座する春日神社を勧請」したとする |
| 大原神社 | 流山市平和台 | 瀬織津比咩命・速開津比咩命・気吹戸主命・速佐須良比咩命（祓戸四神）。延宝元年（1673年）創建と伝えられ、社号は旧地名「西平井の字大原」に因むという |
| 大原神社（大原大宮神社） | 習志野市実籾 | 伊奘諾尊・伊弉冉尊・猿田彦命ほか（公式サイト）。天治元年（1124年）実籾本郷に伊弉冉尊を祀って創建と伝える |

- ① 君津編：フルール・ド・リス・五三桐紋、隠された女神論（fusaブログの現地調査に基づく仮説）
- ② 流山編：北拝の特異形態、Flood Maps による岬地形（同上）
- ③ 習志野編：七年祭り「叔母」、イザナギ・イザナミ親神社（同上。なお習志野社の祭神が伊奘諾・伊弉冉両尊である点自体は公式サイトで確認できる）

→ 詳細統合ノート: [[大原神社と大原足尼：千葉に残された忌部祖神祭祀の物的痕跡]]

『古語拾遺』の東遷記事の原文は次のとおりである（Vault保存の原文転写による）。

> 天富命更に沃壌を求め、阿波斎部を分かち率いて東土に往き、麻穀を播殖す。好き麻の生ずる所、故に之を総の国と謂う。……阿波忌部の居る所、便ち安房郡と名づく（今の安房国是れなり）。天富命即ち其の地に太玉命の社を立つ。今之を安房社と謂う。故に其の神戸に斎部氏有り。

→ すなわち『古語拾遺』が直接裏づけるのは、阿波斎部の東上・総国の命名・安房郡の命名・太玉命社（安房社）の建立までであり、大原神社群との接続は後世の伝承とブログ研究による解釈である。

## 4. 「忌」字の語源と熊野信仰（fusa資料）

## 7. 阿波説における位置づけ

**公的資料で確認できる事実** は次の範囲である。

1. 『古語拾遺』に、天富命が阿波斎部を率いて東上し、総国の命名・安房郡の命名・太玉命社（安房社）の建立に至る記事がある
2. 安房神社（天太玉命）・洲崎神社（天比理乃咩命）・下立松原神社（天日鷲命）の祭神と、忌部氏による開拓伝承が公的資料で確認できる
3. 君津市平山の大原神社は天太玉命を天児屋根命とともに祀る（ただし由緒は春日神社勧請とする）

**阿波説の解釈** は次の範囲であり、事実とは分けて評価すべきである。

1. 上記の分布を「組織的・計画的な東遷プロジェクト」の物的痕跡と読み、「移民の偶然では説明不能」とする主張
2. 大原神社群・熊野神社・「八神郡」を重層的な傍証とみる整理（大原神社については流山・習志野の両社が天太玉命を祀らないため、三社一括の根拠は成立しない）
3. なお根拠史料の『古語拾遺』自体が斎部広成の奏上による忌部氏側の史料である点にも留意が必要である

→ 近世以降の伝承付加（「忌部直系」言説の派生）と古代の物的痕跡は **時代層を分けて評価** すべきである。

> [!warning] 注意
> - 「阿波（あわ）→安房（あわ）」の音韻一致や、千葉県内の天太玉命・天日鷲命祭祀の分布を「組織的・計画的な東遷の物的痕跡」とみるのは阿波説の解釈であり、公的資料で確認できるのは『古語拾遺』の天富命東遷記事と、安房三社の祭神・開拓伝承の範囲までである。

### 未検証として残した主張
1. **安房の地名が「阿波」に由来するという命名説そのもの**：『古語拾遺』は「阿波忌部の居る所、便ち安房郡と名づく」と記すのみで、命名理由（阿波の転訛等）を明示しない。Wikipedia「安房神社」も「阿波忌部の移住・開拓から起こったといわれる」と伝承として記す範囲にとどまる
2. **洲崎神社の「海上交通の守護神」という性格づけ**：旧稿 §2 にあった表現だが、今回照合した公的資料（Wikipedia「洲崎神社」）では確認できなかった
3. **大原神社三社の個別論点**：君津編のフルール・ド・リス・五三桐紋と「隠された女神」論、流山編の北拝形態と岬地形の比定、習志野編の七年祭り「叔母」論はいずれも fusa ブログの現地調査に基づく仮説で、公的資料による裏づけはない
4. **「忌＝熊」音韻同源論と熊野祭祀の東遷説**：fusa ブログの仮説。袖ヶ浦市吉野田熊野神社の由緒・祭神自体も公的資料で未確認
5. **地名一致に基づく痕跡の拡大**：伊豆・茨城・讃岐・和歌山への広がりと「黒潮ネットワーク全域の現象」とする理解（awanonoraneko-blog）。地名一致のみでは移住・祭祀伝播の証拠にならない
6. **「八神郡」の枠組みと高山家安房国忌部家系の史料性**：「八神郡」は歴史的郡名ではなく note 記事の仮説的呼称。高山家系図は家系資料であり、一次史料としての検証は未実施
7. **安房神社を「忌部の総本山」とする位置づけと徳島の忌部神社・大麻比古神社との「直結」論**：旧稿 §2 の表現。公的な位置づけは式内社（名神大社）・安房国一宮であり、「総本山」「直結」は阿波説の解釈
