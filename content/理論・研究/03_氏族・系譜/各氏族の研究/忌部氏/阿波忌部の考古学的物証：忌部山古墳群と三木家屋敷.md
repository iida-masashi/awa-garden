# 阿波忌部の考古学的物証：忌部山古墳群と三木家屋敷

> [!summary] 本ノートの役割
> 阿波忌部の実在を **文献伝承ではなく物的証拠から論じる** 専門ノート。**忌部山古墳群・忌部山型古墳・三木家屋敷（徳島県最古の木造建築）** を中軸に、麻植郡〜美馬郡に集中する古墳・現存建築の考古学的データを整理する。文献偏重に陥りがちな阿波忌部研究を、**地上に残る物証**の側から補強する。

---

## 核心命題

| 論点 | 内容 |
|---|---|
| **忌部山型古墳の独自性** | ドーム型天井をもつ横穴式石室は阿波（吉野川市〜美馬市）に集中分布し、他地域には見られない地域型 |
| **分布域＝忌部本拠地** | 古墳群の分布が文献上の阿波忌部の本拠（麻殖郡・美馬郡）と一致 |
| **三木家屋敷の連続性** | 美馬市木屋平の三木家主屋は400年以上前の現存木造建築。中世以降の忌部後裔（御衣御殿人）の活動拠点 |
| **段の塚穴型石室との関係** | 段の塚穴型石室は阿波で発生し東進、北岡古墳・長峰古墳が東限。忌部山型と並ぶ阿波独自系譜 |

## 1. 忌部山古墳群（吉野川市山川町）

### 1-1. 概要

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県吉野川市山川町 |
| 時期 | 6世紀後半〜7世紀（古墳時代後期） |
| 構造 | 横穴式石室・**ドーム型天井**（忌部山型） |
| 被葬者 | 阿波忌部の有力者と推定 |

### 1-2. 「忌部山型古墳」という地域型

ドーム型天井をもつ横穴式石室は、**全国的に見ても阿波（吉野川市〜美馬市）に集中** し、考古学者によって「忌部山型」と命名されている。
- 西ノ原古墳・境谷古墳（吉野川市）
- 峯八古墳群（吉野川市川島町）
- 拝中・拝東・北原古墳（美馬市脇町）

→ 詳細は 忌部山古墳群（吉野川市） および 西ノ原古墳・境谷古墳 参照。

### 1-3. setonoshima資料による批判的視点

「瀬戸の島から」ブログは、忌部山古墳群の被葬者を **無条件で「阿波忌部」と同定すること自体に慎重さ** を求めている。
- 🔍 阿波忌部氏NO1：忌部山古墳群はドーム型天井を持つ特色ある古墳で、阿波忌部氏によって造られた？

→ 古墳の **構造的独自性（忌部山型）** は確実な物証だが、**被葬者の氏族同定** には複数の解釈余地がある。両者を分けて論じることが重要。

## 2. 三木家屋敷（美馬市木屋平）

### 2-1. 現存する徳島県最古の木造建築

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県美馬市木屋平 |
| 建築年代 | 400年以上前（江戸初期、現存） |
| 役割 | 旧山岳部統領の屋敷、現代も大嘗祭麁服貢進の拠点 |
| 現代 | 第28代当主が継承、隣接して資料館を設置 |

→ 詳細は [[忌部御殿人の正体：土佐野治茂説と大嘗祭の阿波貢進]] 参照。

### 2-2. 物証としての重要性

三木家屋敷は、**「阿波忌部の連続性」を地上に現存する形で示す唯一の建築物**。
- 古墳時代の物証（忌部山古墳群）
- 中世以降の物証（三木家屋敷）

この二つを結ぶことで、**6世紀〜現代まで1,400年以上にわたる阿波忌部の地理的連続性** が地上に可視化される。

### 2-3. 批判的視点：三木家文書の偽書部分

ただし三木家所蔵文書には近世作成の偽書が含まれており、屋敷の「物的連続性」と文書の「文書的連続性」は **分けて評価** する必要がある。
→ 詳細は [[三木家文書の偽書論争：阿波忌部研究の史料批判]] 参照。

## 3. 麻植郡〜美馬郡の古墳集中

### 3-1. 段の塚穴型石室の東限

| 古墳 | 所在地 | 特徴 |
|---|---|---|
| 北岡古墳 | 阿波市 | 段の塚穴型石室の東限 |
| 長峰古墳 | 阿波市 | 同上 |

段の塚穴型石室は **阿波で発生し東進** したと考えられ、北岡・長峰がその東限。忌部山型と並ぶ阿波独自の石室系譜。

→ 詳細は 北岡古墳＆長峰古墳 参照。

### 3-2. 天河別神社古墳群（鳴門市）

3世紀から5世紀にかけて造営された大型古墳群。鳴門市大麻町（[[大麻比古神社|大麻比古神社]]の地）に近接し、阿波忌部の祖神祭祀との関連が議論されている。

→ 詳細は 天河別神社古墳群 参照。

## 4. 阿波説における位置づけ

阿波忌部研究は伝承・文献史料に偏りがちだが、**地上に残る物証の側から見ると以下の三層が連続している**：

| 時代 | 物証 | 性格 |
|---|---|---|
| 古墳時代後期（6〜7C） | 忌部山型古墳群（吉野川市〜美馬市） | 阿波独自の石室構造 |
| 古墳時代前〜中期（3〜5C） | 天河別神社古墳群（鳴門市） | 大麻比古神社近接、祖神祭祀との関連 |
| 江戸初期〜現代 | 三木家屋敷（美馬市木屋平） | 県最古の木造建築、麁服貢進の現拠点 |

→ **物証の集中域（吉野川市〜美馬市）と、文献上の阿波忌部本拠（麻殖郡・美馬郡）が一致する**ことは、阿波説の核心的な傍証となる。

→ 一方で、**被葬者の氏族同定や文書の真贋判定** には批判的検討が必要。「物証＝阿波忌部」と短絡せず、構造的独自性と氏族比定を分けて議論することが、阿波説の学術的堅牢性を高める。
