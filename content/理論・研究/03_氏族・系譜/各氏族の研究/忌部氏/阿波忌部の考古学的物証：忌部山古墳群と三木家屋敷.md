# 阿波忌部の考古学的物証：忌部山古墳群と三木家屋敷

> [!summary] 本ノートの役割
> 阿波忌部の実在を **文献伝承ではなく物的証拠から論じる** 専門ノート。**忌部山古墳群・忌部山型古墳・三木家屋敷（徳島県最古の民家）** を中軸に、麻殖郡〜美馬郡に集中する古墳・現存建築の考古学的データを整理する。文献偏重に陥りがちな阿波忌部研究を、**地上に残る物証**の側から補強する。

---

## 核心命題

| 論点 | 内容 |
|---|---|
| **忌部山型古墳の独自性** | 玄室平面の胴張り・奥壁隅の隅丸・持ち送りの天井を特徴とする横穴式石室（天羽利夫の型式設定）。麻殖郡を中心に板野郡にも分布する阿波の地域型 |
| **分布域＝忌部本拠地** | 古墳群の分布が文献上の阿波忌部の本拠（麻殖郡・美馬郡）と重なる（阿波説の解釈。→留保） |
| **三木家屋敷の連続性** | 美馬市木屋平の三木家住宅は江戸時代前期（推定1615〜1660年）の現存民家で国の重要文化財。阿波忌部の後裔と伝える三木家（御衣御殿人）の活動拠点 |
| **段の塚穴型石室との関係** | 美馬市の段の塚穴古墳群を標式とする地域型。北岡古墳（阿波市）がその東限とされる（徳島県資料）。忌部山型と並ぶ阿波独自系譜 |

## 1. 忌部山古墳群（吉野川市山川町）

### 1-2. 「忌部山型古墳」という地域型

玄室の平面形が胴張りとなり、奥壁の隅が丸みを帯び、天井を持ち送り構造とする横穴式石室は、考古学者の天羽利夫によって「忌部山型石室」と命名された地域型である。分布は **麻殖郡（現・吉野川市一帯）を中心に板野郡にも及び**、名東郡の安喜古墳のように密接に関連する石室も知られる（『阿波学会紀要』第48号、2002年）。なお「ドーム型天井」という表現は、姉妹型である段の塚穴型石室の天井形状を指して使われることが多く、忌部山型の定義的特徴は胴張り平面・隅丸・持ち送りの組み合わせにある。
- 学術論文で忌部山型とされる例：忌部山1・2・5号墳、境谷古墳、金勝寺古墳（麻殖郡）、柿谷1・3・4・7号墳、山崎1号墳（板野郡）
- ブログ（kohun-jinjya）で忌部山型とされる例（学術論文・公的資料では未確認。→未検証2）：西ノ原古墳、峯八古墳群（吉野川市川島町）、拝中・拝東・北原古墳（美馬市脇町）

→ 詳細は 忌部山古墳群（吉野川市） および 西ノ原古墳・境谷古墳 参照。

### 1-3. setonoshima資料による批判的視点

「瀬戸の島から」ブログは、忌部山古墳群の被葬者を **無条件で「阿波忌部」と同定すること自体に慎重さ** を求めている。
- 🔍 阿波忌部氏NO1：忌部山古墳群はドーム型天井を持つ特色ある古墳で、阿波忌部氏によって造られた？

→ 古墳の **構造的独自性（忌部山型）** は確実な物証だが、**被葬者の氏族同定** には複数の解釈余地がある。両者を分けて論じることが重要。

#### 二次資料で確認できる報告書の内容（原典未照合・二次引用）

報告書本文そのものは未照合であるため、以下はすべて二次資料経由の情報として区別する。

- **発掘成果の骨格**：ブログ「瀬戸の島から」が、天羽利夫の講座テキスト（「古代阿波の忌部氏―考古学からのアプローチ」『講座 麻植を学ぶ』）と報告書の図版（測量図）をもとに要約する内容によれば、5基とも円墳（径約10m・高さ約2.5m、規模に大きな格差なし）、すべて横穴式石室で、1号墳には横穴式石室に隣接して竪穴式の小石室（追葬用）が付く。築造順序は1号墳→2・3号墳→4号墳→5号墳で、6世紀半ば前後に前後して造られたとされる（[[阿波忌部氏NO1 忌部山古墳群はドーム型天井を持つ特色ある古墳で、阿波忌部氏によって造られた？  瀬戸の島から]]）
- **被葬者比定の提示経緯**：『郷土研究発表会紀要』第30号（1984年）の「古代信仰と鴨島（麻植の古墳と忌部氏）」は、「徳島県考古学研究グループでは此の古墳の型式を忌部山型石室と名づけ、**古墳の主を『古事記』や『日本書紀』に見られる阿波忌部氏にあてはめている**」と明記する（[[古代信仰と鴨島]]）。天羽は忌部山古墳群を「里の阿波忌部の家族墓」として6世紀中頃に継続して造られたものと位置づけ、麻植郡の忌部山型石室墳の被葬者層が後の阿波忌部氏と系譜的につながる氏族であり、渡来系で鉄器生産に卓越した氏族であった可能性を指摘したとされる（天羽の講座テキストの二次紹介による）
- **評価**：「被葬者＝阿波忌部」という比定は、後世の阿波説支持者による付会ではなく、**発掘調査を担った側の研究者（徳島県考古学研究グループ／天羽利夫）が調査と同時期に提示した解釈**であることが、1984年の県の研究刊行物で確認できた。これは比定の出所を明確にする点で従来の記述を前進させる。ただし、それは考古学者の解釈（仮説）の提示であって、被葬者の氏族名を示す出土文字資料等による実証ではない。したがって未検証1の水準（被葬者同定は実証されていない）は変わらない

## 2. 三木家屋敷（美馬市木屋平）

### 2-1. 現存する徳島県最古の民家（国の重要文化財）

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県美馬市木屋平字貢 |
| 建築年代 | 江戸時代前期（推定1615〜1660年。棟札が腐食して読めず、建物の特徴からの推定）。1976年（昭和51年）2月3日に国の重要文化財に指定 |
| 役割 | 山岳武家（郷士）・阿波三木氏本家の屋敷。現代も大嘗祭麁服（あらたえ）調進の拠点 |
| 現代 | 第28代当主・三木信夫氏が継承（美馬市資料による）、隣接して三木家資料館を設置 |

→ 詳細は [[忌部御殿人の正体：土佐野治茂説と大嘗祭の阿波貢進]] 参照。

### 2-1b. 麁服調進の公的裏付け（2026-11-15補強調査）

令和の大嘗祭における麁服調進は、宮内庁の公式資料で直接確認できる。宮内庁「大嘗宮の儀関係資料」の「繪服，麁服（規格，数量，製作者）」には、麁服について規格「麻晒布」、数量「4反」、**納入者「三木家当主 三木信夫」**と明記されている（[[大嘗宮の儀関係資料（繪服・麁服）_宮内庁]]）。美馬市観光協会（三木家住宅の案内）も「令和元年に斎行された大嘗祭では、御殿人である三木家28代当主の三木信夫氏が宮内庁に麁服を届けました」「三木家は、大嘗祭において、阿波忌部氏が調整する『麁服』を歴代献上してまいりました」と記す（[[三木家住宅  美馬観光ビューロー]]）。すなわち「現代の三木家当主が大嘗祭の麁服納入者である」ことは公的資料で確定する。ただし、これは近現代の調進の継続を示すものであり、三木家の系譜が中世以前の阿波忌部に実証的に連なることとは別の問題である（→未検証7）。

### 2-1c. 系譜の接続状況（2026-11-15・系譜調査）

「古代阿波忌部→三木家」の接続を、時代ごとに文書でどこまで追えるかを公的資料・学術調査で確認した。結論を先に述べると、**文書で追えるのは中世（12世紀末〜14世紀前半）の麁服関係文書までであり、それ以前の古代忌部との系譜的接続、および中世〜近世の切れ目を埋める史料は、今回確認した範囲では存在しない**。時代ごとの状況は以下のとおり。

#### 三木家文書の公的位置づけ

- 三木家文書は徳島県指定有形文化財（書跡・典籍・古文書）。徳島県立博物館ニュース（No115）によれば、中世文書全47点のうち近代の写を除く45点が指定対象で、原本は徳島県立博物館に寄託・保管されている。美馬市の県指定文化財一覧では「三木家文書 45通、木屋平字貢143番地、昭和59年（1984）8月3日指定」（[[美馬市県指定文化財一覧]]、[[徳島県立博物館ニュースNo115（延喜式と三木家文書）]]）
- 中世文書43点は『徳島県文化財基礎調査報告 第5集 阿波の中世文書』（徳島県教育委員会、1982年）に写真とともに翻刻・紹介されている（『阿波学会紀要』第54号、2008年）

#### 「28代当主」の世代計算による検証

現当主・三木信夫氏が「第28代」であることは、美馬市観光協会等の公的・準公的資料が記す（§2-1の表）。ただし数え始めの人物を示す系図そのものは、今回の調査範囲では公表資料で確認できなかった（→未検証8）。仮定を置いた単純計算では次のようになる（28代まで代替わり27回、現当主の活動年を2019年とする）。

- 仮定A：初代を中世文書に現れる三木宗時（1260年、亀山天皇の大嘗祭に奉仕と年表が記す）とすると、759年÷27回≒**28.1年/代**。一般的な世代間隔（25〜30年）と整合する
- 仮定B：初代を三木家住宅の建築当主（1615〜1660年頃）とすると、約370年÷27回≒**13.7年/代**。短すぎて不自然であり、28代の起点は江戸前期ではありえない
- 仮定C：初代を古代の阿波忌部（807年の『古語拾遺』奏上期）とすると、1212年÷27回≒**44.9年/代**。長すぎて不自然であり、「古代から28代」という読みは計算と整合しない

すなわち「28代」という世代数は、**中世（13世紀前後）を起点とする家系とは整合するが、古代阿波忌部からの連続を示す数としては使えない**。これは計算上の整合性の話であり、系図の史実性の証明ではない。

三木家文書への学術的検討は段階的に進んでいる（以下は主に setonoshima ブログが紹介する丸山幸彦研究の二次情報であり、原論文そのものは未取得→未検証12）。

### 2-2. 物証としての重要性

阿波説では、三木家屋敷は **「阿波忌部の連続性」を地上に現存する形で示す建築物** と位置づけられる（「唯一の建築物」という表現は検証不能なため、事実としては断定しない）。
- 古墳時代の物証（忌部山古墳群）
- 中世以降の物証（三木家屋敷）

阿波説はこの二つを結ぶことで、**6世紀〜現代まで1,400年以上にわたる阿波忌部の地理的連続性** が地上に可視化されると主張する。ただしこれは、古墳の被葬者同定と三木家の系譜伝承の双方が成り立つ場合の解釈であり、事実として確定したものではない（→未検証5・7）。

### 2-3. 批判的視点：三木家文書の偽書部分

ただし三木家所蔵文書には近世作成の偽書が含まれており、屋敷の「物的連続性」と文書の「文書的連続性」は **分けて評価** する必要がある。

## 4. 阿波説における位置づけ

阿波忌部研究は伝承・文献史料に偏りがちだが、**地上に残る物証の側から見ると以下の三層が連続している**：

| 時代 | 物証 | 性格 |
|---|---|---|
| 古墳時代後期（6〜7C） | 忌部山型古墳群（吉野川市〜美馬市） | 阿波独自の石室構造 |
| 弥生時代終末期〜古墳時代前期 | 天河別神社古墳群（鳴門市、国史跡・鳴門板野古墳群の一部） | 大麻比古神社近接。祖神祭祀との関連は阿波説の解釈 |
| 江戸時代前期〜現代 | 三木家屋敷（美馬市木屋平） | 県最古の民家（国重要文化財）、麁服調進の現拠点 |

→ **物証の集中域（吉野川市〜美馬市）と、文献上の阿波忌部本拠（麻殖郡・美馬郡）が一致する**ことは、阿波説の核心的な傍証となる。

→ 一方で、**被葬者の氏族同定や文書の真贋判定** には批判的検討が必要。「物証＝阿波忌部」と短絡せず、構造的独自性と氏族比定を分けて議論することが、阿波説の学術的堅牢性を高める。
