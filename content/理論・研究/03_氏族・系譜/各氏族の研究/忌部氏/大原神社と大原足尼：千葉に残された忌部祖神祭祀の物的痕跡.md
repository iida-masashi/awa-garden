# 大原神社と大原足尼：千葉に残された忌部祖神祭祀の物的痕跡

> **要旨**：千葉県内の **君津市平山・流山市平和台・習志野市実籾** の三社をはじめとする「大原神社」群を、阿波忌部の東遷先（安房=阿波、天富命率いる「肥饒地を求む」東遷プロジェクト）に残る **天太玉命（忌部祖神）祭祀の物的痕跡** として整理する論考。社名の由来となる **「大原足尼（おおはらすくね）」** は「ひぼろぎ逍遥」古川氏が提示する **筑紫豊国国造** の系譜上の人物で、**「足尼（すくね）」表記から女性神** であることが判明。本ノートは fusa（未知の駅 總フサ）3シリーズの現地調査記録を起点に、忌部・筑紫豊国・千葉の祭祀ネットワークを統合的に再構成する。

## 🎯 核心命題

| 論点 | 通説 | 本ノートの統合的解釈 |
|---|---|---|
| **大原神社の主祭神** | 天兒屋根命・天太玉命の二柱（春日神社系勧請） | **隠された真の主神は女神**：①大原足尼（女神）②天比理刀咩命（天太玉命后神）③春日比賣神 のいずれか |
| **「大原」の語源** | 千葉県夷隅郡大原町の新田開発地（寛政2年=1790年「大原宿」） | **大原足尼の奉斎地名**。和名抄「廬道郷イオチゴウ」の遺称地として往古から「大原」の地名痕跡がある可能性 |
| **大原足尼の出自** | 不詳 | **筑紫豊国の国造**（古川氏「ひぼろぎ逍遥」説）。奉斎神社は全国に点在、千葉のほか九州にも複数 |
| **千葉県内の分布構造** | 個別の小社 | **君津・流山・習志野** の三地点はいずれも縄文海進時の岬・台地で、海上交通の目印となる古代開拓拠点。阿波忌部東遷の拠点配置と整合 |

## 📍 三社の現地調査記録（fusa「未知の駅 總フサ」）

### ① 大原神社（君津市平山字宮後823）

| 項目 | 内容 |
|---|---|
| **読み** | オオハラジンジャ |
| **表向き祭神** | 天兒屋根命・天太玉命 |
| **社伝** | 「往古、南都の春日神社を遷し祀る」 |
| **本殿装飾** | **フルール・ド・リス**（女神を示す）／五三桐紋（女神を示す） |
| **境内末社** | 熊野神社・須賀神社・佐田彦神社（道祖神）／白滝・阿夫利・浅間・秋葉・弁天 ほか |
| **特徴** | 「これぞ古社」の趣、田圃に囲まれた古社地、特徴的な中央が太い注連縄、拝殿上に鳥 |

→ **本殿に天兒屋根・天太玉の二柱（春日系）を祀るが、装飾は女神**。表向きの祭神と真の祭神に乖離があり、**隠された真の主神は女神**。

### ② 大原神社（流山市平和台4-1650-1）

| 項目 | 内容 |
|---|---|
| **読み** | ダイバラジンジャ（君津と発音が異なる！） |
| **表向き祭神** | 大原権現（江戸期社名）／瀬織津比咩命ほか3柱（合祀された七郎神社の祭神） |
| **明治15年神社明細帳** | **「不詳」** |
| **本殿装飾** | フルール・ド・リス（女神を示す） |
| **立地** | 旧西平井村字「大原」、急坂の途中に鎮座。**北拝**（妙見神を祀らないのに北を拝する特異形態） |
| **古地理** | Flood Maps 7m上昇時、平和台は岬になる。古代航海の陸路目印 |

→ **江戸初期創建を称するが字名「大原」は古い**。「不詳」とされた真の祭神が、後世「合祀した七郎神社の祭神」に置換された **千葉県内の典型的な祭神隠蔽パターン**。

## 👤 大原足尼とは何者か

### 古川氏（「ひぼろぎ逍遥」）の提示する論

- **筑紫豊国の国造**
- **奉斎神社が全国に点在**：千葉のほか、九州にも複数の大原神社・大原社あり
- **「足尼（すくね）」表記から女性**：男性は通常「宿禰」と表記

### 阿波説における位置付け

「**筑紫豊国の国造**」という出自と、**忌部祖神 天太玉命の祭祀** が共通することから：

1. **大原足尼＝忌部系の女性国造**（または巫女王）
2. 阿波忌部の東遷（天富命率いる「肥饒地を求む」プロジェクト）と並行する **西国→東国** の祭祀者移動
3. 大原足尼は **天富命の系譜・配偶神** の可能性

### 候補となる女神

| 候補 | 根拠 |
|---|---|
| **天比理刀咩命** | 天太玉命の后神。下立松原神社・洲崎神社（千葉）に祀られる。**大原足尼=天比理刀咩命** の可能性 |
| **大原足尼（独立した女神）** | 古川氏の提示通り。九州・千葉の同名社群が証言 |
| **春日比賣神** | 表向き祭神「天兒屋根命」の后神 |

## 🔗 阿波忌部の東遷論との接続

### 『古語拾遺』の証言

> 天富命率忌部諸氏、求肥饒地、遣阿波斎部、播殖穀麻。故、其地名為阿波。又分阿波斎部、率往東國、播殖穀麻、其地名為總國（即フサ国）。是即所謂房総是也。

→ 天富命が阿波忌部を率いて **「肥饒の地」** を求め、阿波で穀麻を播殖、さらに阿波斎部を東国（房総=フサ国）に分け遣わして同様に穀麻を播殖。**故地名を「總（フサ）」と為す**。

この東遷ルートに沿って：
- **安房**（南房総市）：忌部の総本社的役割 → [[千葉県の神社伝承(阿波説関連)]]：**安房神社（天太玉命）・洲崎神社（天比理刀咩命）・下立松原神社（天日鷲命）**
- **君津・流山・習志野**（本ノートの三社）：忌部祖神の二次的祭祀拠点
- **香取・側高**：香取神宮（経津主神=由布津主命）の忌部系武神

→ **大原神社三社は、安房から北上した忌部東遷の中継拠点** として位置付けられる。

## 📝 留保（中立的併記）

- 大原足尼の出自を「筑紫豊国国造」とする説は、HP「ひぼろぎ逍遥」古川氏の在野研究に依拠する。主流学界の検証を経たものではない。
- 千葉の大原神社三社が阿波忌部東遷の物的痕跡という解釈は、社伝の春日勧請説と対立し、決定的物証（系図・古文書）に欠ける。
- フルール・ド・リス装飾が女神を示すとする読解は、千葉県内の神社研究で広く採用されているが、近世建築装飾の地域的慣行として説明する立場もある。
- 「七年祭り」の起源伝承（馬加康胤・藤原時平諸常）は中世以降の習合伝承であり、古層の祭祀構造を直接示すものではない可能性がある。
- 大原町（旧夷隅郡）の地名由来「中魚落郷＝廬道郷遺称」と、大原神社群を直結させるには、より精密な地名学的検証が必要。
