# 明治期の社名改正運動と『改正願稿』の抵抗

> [!summary] 概要
> 明治期、政府教部省は阿波の式内社の社名統一・比定を進めた。**大宜都比売命の真名「大粟姫（オオアワヒメ）」を「大日孁神（オオヒルメ）」に置き換える** 改名運動に対して、阿波の識者たちは **『上一宮大粟神社古傳書及御神号改正願稿』** を編纂し、文書による抵抗を行った。粟飯原家10代当主 **粟凡直粲胤（あわのおおきみさんいん／粟飯原与一）** は明治10年（1877）に **『粟飯原家略傳』** を記し、古代姓「粟凡直」を再表明することで祭祀正統性を後世に宣言した。

---

## 🏛 明治政府の改名方針

明治政府教部省（後の内務省）は廃藩置県・神仏分離後、全国の式内社の比定統一を進めた。阿波では：

| 旧称 | 改名案 | 政治的意図 |
|---|---|---|
| **大粟大明神**（[[上一宮大粟神社]]） | → 埴生屋神社 | 大宜都比売命＝大粟姫の名を消去 |
| **杉尾大明神**（天石門別八倉比賣神社） | → 天石門別八倉比賣神社 | 祭神を **大日孁命＝天照大神** に置換 |

→ 意図：
1. 大宜都比売命＝大粟姫の名を消去
2. 大日孁命＝天照大神に祭神を置換
3. 阿波の独自祭祀を **中央祭祀（伊勢系）** に統合

## 📜 『上一宮大粟神社古傳書及御神号改正願稿』

阿波の識者たちは抗議文書を作成。`awa-otoko` 氏が読み解いた核心：

> 杉尾明神八倉比賣神社ニ非ルチ知ルヘシト思フニ
> **杉尾ハ極メテ天石門別豊玉比賣神社ナルヲ**
> 豊玉比賣神社ハ八倉比賣神社ト **同神ヲ祭リシ故㕝ヲ混シテ傳へ**
> 終ニ本ツ御名ヲ送失シテ古ク八倉比賣神社ト誤リ傳エシモノ也

### 改正願稿の主張

1. **杉尾＝天石門別豊玉比賣神社** が正しい（八倉比賣神社ではない）
2. **豊玉比賣神社と八倉比賣神社は同神**（大宜都比売命の異名）であるため混同された
3. 改名により本来の御名「**大粟姫**」が失われた

### 「大粟姫 → 大日孁」音韻置換の告発

> もともとの祭神 **大粟姫（おおあわひめ）** に聞こえがちかい **大日孁神（おおひるめ）** に置き換え、冠に天石門別を付けた、天石門別八倉比賣神社として、天石門別豊玉比賣神社の存在を消してしまった。
>
> それは考え合わした「**嘘**」で固められた古からの計画であった…

### 「㕝（こと）」字の暗号性

awa-otoko 説：

- 文書中の「**㕝（こと）**」字には **「嘘」の意** が含まれる
- 「**事を歪めて伝えた**」「**公文書として虚偽である**」という暗号的告発

→ 『改正願稿』は、明治期の阿波の識者たちが **「大宜都比売命の真名を守るための祭祀防衛戦」** を文書として残した、阿波説における最重要の **戦闘文書** である。

→ 出典：
- 2016-01-11-八倉比賣神社は天石門別豊玉比賣神社だった
- 2016-01-14-大宜都比売命の父は天手力男命

## 🌟 『粟飯原家略傳』（明治10年=1877年）の意義

awa-otoko の核心読解：

> 個人的には粟飯原与一氏が **粟凡直の姓** で記録しているのは、**自信と誇りをもって真実の表明を後世に伝えるため** は勿論のこと、「粟凡直」というワードを **アイキャッチ** として使用したかったのではないか。
>
> 粟凡直を調べれば大宜都比売命・千波足尼の繋がりが見出せる。また神山 神領地区の歴史も出てくる。
>
> **意図がなければ明治時代に古代の姓「粟凡直」は名乗れない**。

### 古代姓「粟凡直」再表明の意義

明治政府の社名改正運動・近代化政策の中で、粟凡直粲胤が古代の本姓「粟凡直」を再び名乗ったことは：

1. **粟国造家の正統性主張**
2. **大宜都比売命＝粟国魂神の祭祀権の継承宣言**
3. **後世の研究者への暗号メッセージ**

として機能する、**精神的な抵抗行動** であった。

→ 出典：2016-05-22-粟凡直粲胤_粟飯原家略傳

## 🔄 「阿波女社宮主祖系」と粟国造粟飯原家系図

一宮神社所蔵の「**阿波女社（あわめのやしろ）宮主祖系**」を取り入れた **『粟国造粟飯原家系図』** は、大宜都比売命の異名群を明示する：

| 異名 | 意味・典拠 |
|---|---|
| 大宜都比売命 | 阿波の国魂神（古事記） |
| 大粟姫（おおあわひめ） | 粟を蒔いた女神 |
| 大阿波女神（おおあわめ） | 阿波の大女神 |
| 阿波女神（あわめ） | 同上の短縮形 |
| 阿波咩命 | 伊豆神津島・阿波命神社の祭神 |
| 阿波波神 | 阿波の波（海神性） |
| **天津羽羽神**（あまつはは） | 事代主の妻（『斎部宿祢本系帳』） |
| **天石門別八倉比賣神** | 父神冠詞＋娘 |
| **天石門別豊玉比賣神** | 母を継ぐ娘神 |

→ 系図は **「これらすべてが同一神＝大宜都比売命の異名である」** ことを明示し、粟飯原氏が **これらの異名すべての祭祀系譜を正統に継承する家系** であることを宣言している。

詳細：[[大宜都比売命の父神論：天手力男・天背男・八倉比賣との交差]]

## 📍 fusa（房総側）からの補強：明治祭祀権回復運動

「未知の駅 總フサ」ブログによる **千葉側からの粟飯原氏研究**：

> 「平民苗字許可令」以降、粟飯原氏が「**千葉一族**」の仮装を捨て **本来の粟国造の系譜を再表明** した動機は、暦応4年（1341）に奪われた **御祭神への信仰を取り戻すため** であった、と房総側から論証。

→ 出典：粟飯原氏の謎② 阿波粟飯原氏と八倉比賣神社 後編 未知の駅 總フサ

### 「佐人＝千波足尼」口承継承の発掘

> 系図中、若室神から9代目「**佐人**」に「**千波足尼ハ佐人又ハ前後ニアル神人中ノ必別名也**」と添書きあり。藤原氏に祭祀権を奪われた忌部一族が **出自を偽り、口承で真実を伝えた** 痕跡。

→ 暦應4年以降の「千葉氏仮装」→明治期の「粟凡直再表明」という **600年の口承継承** が、千葉側資料からも裏付けられる。

## 🌟 明治期の祭祀防衛戦の総括

| 闘いの軸 | 内容 |
|---|---|
| **政治の闘い** | 政府改名運動 vs 阿波識者の抗議文書 |
| **真名の闘い** | 大日孁（中央祭祀化） vs 大粟姫（土着祭祀継承） |
| **系譜の闘い** | 「千葉氏仮装」放棄 → 「粟凡直」再表明 |
| **史料の闘い** | 公文書による消去 vs 家伝書・系図による保存 |
| **後世への遺産** | 散逸を免れた粟飯原家文書 → 県立文書館に保存 |

『粟飯原家略傳』の末尾：

> **此等ノ古傳アリト聞モ委細ニハ出ニ盡シ難シ 概略ヲ記ルス而シ**

――書ききれないほどの古伝がある、と粟凡直粲胤は明治10年に書き残した。彼の精神的抵抗が、**現代の阿波説の重要な根拠群** を残した。
