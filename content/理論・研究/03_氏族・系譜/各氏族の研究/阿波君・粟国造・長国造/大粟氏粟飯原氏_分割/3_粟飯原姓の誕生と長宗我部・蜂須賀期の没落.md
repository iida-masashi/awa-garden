# 粟飯原姓の誕生と長宗我部・蜂須賀期の没落

> [!summary] 概要
> [[2_暦應4年の祭祀権奪取：小笠原氏との闘い|暦應4年（1341）の祭祀権奪取]] 以降、粟国造家の子孫は神禄を失いつつも **「粟飯を炊いて神供」とする祭祀者** として生き残った。「粟飯原」という姓は **大宜都比売命に粟飯を捧げる祭祀の地** に由来する。やがて **千葉氏を称する仮装** を経て、**天正年間の長宗我部侵攻** により所領を完全に没収され、**蜂須賀家の阿波領有** によって民間身分へと落ちた。

---

## 🍚 「粟飯」を炊いて神供：粟飯原姓の誕生

『粟飯原家略傳』：

> 世時ニ至リテ終ニ相傳ノ職禄ヲ失フ
> 後子孫 **天正年中マテハ上山村ヲ領シ千葉氏ヲ称シセリ**
> 神勲ノ上寳ヲ傳へ **丗々 粟飯ヲ炊キテ神供** トナス
> **粟飯ヲ炊キシ地ヲ粟飯原ト云フ 故ニ粟飯原殿ト称ス**
> 後ニ千葉氏ヲ改メテ **粟飯原氏ヲ称スル** ハ之縁ルナリ

### 系譜上の決定的転換

| 時期 | 状態 |
|---|---|
| 暦應4年（1341）以降 | 神禄・祭官職を失う |
| 室町〜戦国 | **千葉氏** を称した（仮装） |
| 〜天正年中（1573-92） | **上山村**（神山町上山）を領した |
| 中世全般 | 神宝を伝え、**代々「粟飯」を炊いて神供** とした |
| 粟飯を炊いた地 | **「粟飯原（あわばら）」** と呼ばれる |
| → 後に | **「粟飯原氏」** を称するようになった |

## 🌸 「粟飯原」姓の祭祀的意義

「**粟飯原（あわばら）**」――この姓は **大宜都比売命に粟飯を捧げる祭祀の地** に由来する。武門の身分を失っても、**祭祀者としてのアイデンティティを姓に刻印** したことは、粟国造家の精神的継承の表明である。

### 「粟飯」の祭祀的意味

- **粟（あわ）**：阿波国の名の起源、大宜都比売命が蒔いた穀物
- **飯（いい）**：神供（神に捧げる食物）
- **粟飯**＝大宜都比売命の **国魂・粟祭祀の物的継承**

→ 武家の所領を失っても、**「粟飯を炊く」という祭祀行為そのもの** によって、粟国造家の正統性は継承された。

## 🌙 千葉氏との接続：妙見・月信仰

粟飯原氏が一時期「**千葉氏**」を称した背景には、**安房千葉氏との血縁・婚姻関係** がある。

### 阿波忌部の東遷と安房

『古語拾遺』（『日本書紀』神代上・第七段一書）：

> 天富命 更求沃壤、分阿波齋部、率往東上、播殖麻・穀
>
> 阿波忌部所居、便名 **安房郡**。

→ **阿波忌部** が安房（あわ＝千葉県南部）を開拓したことから、**阿波と安房の双方向の人的・血縁的往来** が古来続いた。

### 千葉氏（安房）と粟飯原氏（阿波）の妙見・月信仰

千葉氏（房総半島）は **妙見信仰**（北斗七星）を氏神とした。粟飯原氏も同じく妙見・月信仰を継承し、上一宮大粟神社の祭祀には：
- **八前の随神**（八柱の伴神）
- **柄杓の神宝**（北斗七星の依り代）

が秘儀として伝わる。

→ 阿波と安房は、阿波忌部・粟国造の祭祀系譜を通じて、**妙見・月信仰の双子の祭祀地** となった。

詳細：[[粟飯原氏：千葉氏との繋がりと妙見・月信仰の系譜]]
関連：[[八前の随神と北斗七星：大宜都比売命の降臨を支えた天文学的配置]]

### fusa（房総側）からの音韻論

「未知の駅 總フサ」ブログは『日本地理志料』（村岡良弼）に依拠し、次の音韻論を提示：

> **「千波チハ→千葉チバ」音韻論**：粟国造・千波足尼は元々「総（フサ）」に住んでおり、祖先の功労により粟国造に任じられた。「**千葉**」の地名そのものが粟凡直の領地名「**千波**」由来である可能性。

→ 出典：粟飯原氏の謎①千葉の地名の由来？粟国造・千波足尼 未知の駅 總フサ

## ⚔ 天正年間：長宗我部氏の阿波侵攻

『粟飯原家略傳』：

> 其後 **土佐国 長曾我部氏 當国へ乱入ノ際 麻植郡大浦村 木屋平ノ為ニ所領盡リ没収セラル**
>
> 尋テ蜂須賀家當国ヲ領シ後ハ民間へ遺テ入ニ今ノ如シ

### 長宗我部の阿波侵攻（天正5-13年、1577-85）

**長宗我部元親**（1539-99）は、土佐から四国統一を目指した戦国大名。阿波侵攻の過程で：

| 影響 | 内容 |
|---|---|
| **所領没収** | 麻植郡大浦村・木屋平により、粟飯原家の所領が **すべて没収** |
| **神社破壊** | 多くの阿波の神社・古文書を破壊 |
| **氏族系図散逸** | 系図・神宝が散逸 |
| **在地武家解体** | 在地武家の所領を没収 |

### 佐那河内・御間都比古神社の例

[[佐那河内：佐那縣と天岩戸神話の地]] でも、御間都比古神社が戦国時代に **社殿破壊** され、御神宝が散逸した記録が残る。

→ 阿波の **祭祀史の物的痕跡が中世末期に大きく失われた最大の原因** が、この長宗我部の乱入である。

### 「瀬戸の島から」資料の補強

「瀬戸の島から」ブログによる **長宗我部侵攻過程の一次史料検証**：

- 天正5年（1577）以降の阿波制圧過程
- 中富川合戦以前の阿波諸将の帰順
- 祖谷山衆の先陣としての協力
- 白地城・大西覚用の自立

## 🏯 蜂須賀家の阿波領有（1585-1868）

蜂須賀家は **天正13年（1585）** に豊臣秀吉から阿波を与えられ、明治維新まで領した武家。

### 阿波十郡の祭祀体系の再編

| 旧称 | 改名運動 |
|---|---|
| 大粟大明神 | → **埴生女屋神社** に改名 |
| 杉尾大明神 | → **天石門別八倉比賣神社** に改名 |

→ 粟飯原家にとっては、**土着祭祀権の完全な解体期** となった。

### 蜂須賀家の祭神政策

蜂須賀家は徳島藩主として神社の格付け・社領調整を主導：

- 大宜都比売命系の祭祀を弱化
- 中央祭祀（伊勢系）への統合志向
- 武家氏神祭祀の優位確立

→ 関連：2014-11-13-蜂須賀が動かした神々

## 📉 没落後の粟飯原家（江戸〜幕末）

『粟飯原家略傳』：

> 尋テ蜂須賀家當国ヲ領シ後ハ **民間へ遺テ入ニ今ノ如シ**

→ 武門の身分を完全に失い、民間へ。しかし上山村庄屋として **村落支配の中核** には残り、近世を通じて以下の伝統を保持：

1. **上山村庄屋として藩公認の地位**（蜂須賀家「卍」紋の御蔵が現存）
2. **粟飯（神供）の祭祀伝統**
3. **三日月紋**（千葉氏月星紋との接続）の家紋継承
4. **神領・粟飯原などの地名**を通じた祭祀地理の保持

→ この江戸期の地位保持があったからこそ、明治期に粟凡直粲胤（与一）による **古代姓再表明** が可能となった。
