# 粟飯原氏：千葉氏との繋がりと妙見・月信仰の系譜

> [!summary] 要旨
> 阿波の祭祀一族・粟飯原氏（あわばらし）と東国の雄・千葉氏の同族性・婚姻・系図的接続を、阿波→安房→千葉の「東遷軸」に焦点化して整理する補完論考。『古語拾遺』の安房開拓記事、『粟飯原家略傳』に記された「千葉氏を称した」一節、awa-otoko氏紹介の千葉家系図への組み込みを軸に、三日月紋／千葉氏月星紋の符合、安房千葉氏と阿波粟飯原氏に共通する天女伝説、妙見（北極星・北斗七星）信仰の東漸ルートを論じる。系譜全体・祭祀権闘争はメインノート（八倉比賣神社継承論）に委ね、本稿は東遷と妙見・月信仰の双子祭祀に集中する。

阿波国の祭祀一族 **粟飯原氏（あわばらし）** と、東国の雄 **千葉氏** の **同族性・婚姻・系図的接続** を整理する焦点化ノート。本ノートは、メインノート [[大粟氏・粟飯原氏：祭祀一族の系譜と八倉比賣神社継承の闘い]] の **§千葉氏との関係（妙見・月信仰）** を東遷軸で深掘りする補完論考。

> [!info] 本ノートのスコープ
> メインノートが扱う **粟飯原氏の系譜全体・祭祀権闘争・八倉比賣神社継承** とは独立に、本ノートは **阿波 → 安房 → 千葉** の東遷軸に焦点を当てる。系図・天女伝説・三日月紋・妙見信仰の伝播ルートを統合する。
> 系譜・社名奪取闘争の総合史 → メインノートを参照。

## 1. 阿波忌部の東遷と安房開拓

『古語拾遺』（斎部広成、807年）：

> 天富命 更求沃壤、分阿波齋部、率往東上、播殖麻・穀
> 阿波忌部所居、便名 **安房郡**

→ **阿波忌部** が房総半島（千葉県南部）を開拓し、地名「**安房（あわ）**」を持ち込んだ。この東遷ルートの上で、**粟飯原氏と千葉氏の接続** が成立する。

詳細：[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

## 2. 千葉氏との同族性：「千葉氏を称した」粟飯原氏

『**粟飯原家略傳**』（明治10年、粟凡直粲胤撰）：

> 後子孫 **天正年中マテハ上山村ヲ領シ千葉氏ヲ称シセリ**
> （...中略...）
> 後ニ **千葉氏ヲ改メテ粟飯原氏ヲ称スル** ハ之縁ルナリ

→ 粟飯原家は、神禄を失った中世以降の一時期、**千葉氏を称していた**（天正年中＝1573-92以前まで）。

### この事実の意味
- 粟飯原氏は、東国千葉氏との **婚姻または血縁による氏族的接続** を持つ
- 阿波 ↔ 安房双方向の人的往来の物的証拠
- 「粟（阿波）」と「千葉」の二重アイデンティティを保持

## 4. 三日月紋：千葉氏「月星紋」との符合

### 4-1. 粟飯原家住宅の三日月紋
神山町に現存する **粟飯原家住宅** には、家紋として **「三日月」** が見られる。これは：

- **千葉氏の家紋「月星紋」**（月＋北極星）と直系の同型
- **大宜都比売命** の「月」属性（[[月読尊と大宜都比売命：『月』の名を冠する女神と西阿波の月信仰|月読尊と大宜都比売命]]）と符合

→ 家紋・神格・信仰の **三重の符合** は偶然ではなく、阿波 → 安房 → 千葉の祭祀ネットワークの物的痕跡。

## 6. 妙見信仰（北極星・北斗七星）の東漸ルート

### 6-1. 千葉氏＝妙見信仰の旗手
千葉氏（房総半島）は、**妙見菩薩（北極星・北斗七星）信仰** を氏神とした最も有名な氏族。「**妙見＝千葉氏**」の図式は中世史の常識。

### 6-2. 阿波粟飯原氏の妙見要素
粟飯原氏は、上一宮大粟神社の祭祀において：
- **八前の随神**（八柱の伴神＝北斗七星＋輔星の8星の地上投影）
- **柄杓の神宝**（北斗七星の依り代）

を秘儀として伝える。

### 6-3. 東漸ルートの仮説
| 仮説A | 仮説B |
|---|---|
| 阿波 → 安房 → 千葉氏 | 千葉氏 → 安房 → 阿波 |
| 古代の阿波忌部・粟国造の妙見信仰が東国千葉氏に伝播 | 中世の千葉氏妙見信仰が安房経由で阿波に逆輸入 |
| 古代起源を支持 | 中世起源を支持 |

→ いずれの仮説も阿波・安房・千葉の **妙見信仰の同一ネットワーク** を前提とする。両地域の地理的隔絶を考えると、**双方向の人的・血縁的往来** こそが妙見信仰ネットワークを成立させた。

詳細：[[阿波の祭祀と天文配置]]

> 📝 fusa資料が補強する新情報：
> 1. **粟飯原氏は千葉神社（千葉妙見宮）の歴代神職を世襲**――和田茂右衛門『社寺よりみた千葉の歴史』によれば、寒川神社宮司の粟飯原氏は「良文の頃妙見尊に供奉した **粟飯原文次郎常時** の後裔、妙見社神職 **粟飯原右京の曽孫**」。延宝8年（1680）の縁起書『千葉妙見社元由』は粟飯原右京の署名入り。粟飯原氏は安房・阿波双方で **妙見祭祀の中核** であった物的証拠。
> 2. **千葉神社境内社「石神社」御祭神＝磐長姫＝大宜都比賣命**――百嶋神社考古学解釈で、千葉神社境内に **大宜都比賣命（粟飯原氏祖神）が秘儀的に祀られている** ことが明らかに。阿波の祭祀が房総の千葉氏宗家神社に組み込まれていた痕跡。
> 3. **千葉妙見神＝事代主・大国主の合体神説**――千葉神社分祀の櫻木妙見宮（千葉市若葉区）の御祭神が **大国主命・事代主** であることから、千葉の妙見神は事代主を含む合体神と推定される。粟飯原氏系図の「積羽八重事代主神」（粟国造の祖神）との接続を示唆。
> 4. **「千波チハ→千葉チバ」音韻論**――『日本地理志料』村岡良弼説。千葉氏遠祖・千葉国造大私部直善人の出自と粟国造・千波足尼を結ぶ可能性。
> 5. **天富命・布良崎上陸地（富崎村）**――安房郡富崎村の地名は「阿波の忌部を率いて布良崎に上陸した天富命にちなむ」と明記。阿波忌部東遷ルートの **館山市側終着点** が地名として現存。
