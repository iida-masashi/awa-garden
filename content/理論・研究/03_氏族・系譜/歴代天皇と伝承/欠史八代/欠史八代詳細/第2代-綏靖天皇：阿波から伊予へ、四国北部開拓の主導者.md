# 第2代 綏靖天皇（カムヌナカワミミ）：阿波から伊予へ、四国開拓の主導者

> [!summary] 要旨
> **綏靖天皇（神渟名川耳尊／神沼河耳命）** は神武天皇の皇子で第2代天皇。母は事代主神の娘 **媛蹈鞴五十鈴媛命**（記では富登多多良伊須須岐比売命）。記紀では事績がほとんど記されず「**欠史八代**」の筆頭に数えられるが、阿波説では阿波（粟国）の王権を徳島から伊予（愛媛）方面へ拡大させた実在の統治者とみる。母方が事代主＝海人族・出雲系の血を引く点を、阿波の海洋祭祀圏との接続として読む。

---

## 1. 命題の構造

| 観点 | 通説 | 阿波説 |
|---|---|---|
| 実在性 | 事績を欠き実在を疑問視（欠史八代） | 阿波・四国の神社伝承・地名に痕跡を残す実在の王 |
| 宮「葛城高丘宮」 | 大和国葛城（奈良県御所市） | 阿波（勝浦郡＝古「かつら」／鳴門市北灘町葛城神社周辺） |
| 王権の方向 | 大和盆地内の継承 | 阿波（イの国）→伊予（予の国）への四国北部開拓 |

## 2. 記紀の基本情報

| 項目 | 内容 |
|---|---|
| **和風諡号** | 神渟名川耳尊（書紀）／神沼河耳命（記） |
| **父** | 神武天皇 |
| **母** | 媛蹈鞴五十鈴媛命（事代主神の娘） |
| **兄** | 神八井耳命（多氏・意富氏の祖） |
| **皇后** | 五十鈴依媛命（事代主神の娘とも） |
| **皇子** | 磯城津彦玉手看尊（第3代安寧天皇） |
| **宮** | 葛城高丘宮 |
| **特記** | 兄 神八井耳命が皇位を弟に譲り、自らは祭祀（多氏祖）に退いたと伝わる |

『古事記』『日本書紀』とも在位・系譜のみで具体的事績に乏しく、いわゆる欠史八代の一柱。

日本書紀には唯一まとまった物語として「タギシミミの反逆」が伝わる。神武天皇崩御後、第一后妃 吾平津媛の子・手研耳命（タギシミミ）が、第二后妃 媛蹈鞴五十鈴媛命の子である神八井耳命・神渟名川耳尊（綏靖天皇）兄弟を害そうとした際、母の歌（「狭井川よ雲たち渡り畝傍山木の葉さやぎぬ風吹かむとす」）で危機を察知した兄弟が弓矢を用意し、片丘の大室で手研耳を討った。この時、兄・神八井耳命は手足が震えて矢を射ることができず、弟の神渟名川耳尊が代わって射殺したため、神八井耳命は皇位を弟に譲り自らは神祇を掌ることとなった。

## 3. 阿波・四国における足跡

- **葛城高丘宮の比定**: 記紀では大和国葛城（奈良県）に宮があったとされるが、阿波説では徳島県勝浦郡（古くは「かつら」と呼ばれた）や、鳴門市北灘町の「葛城神社」周辺に比定される。
- **若宮神社（徳島県三好郡東みよし町昼間）**: 祭神は神渟名川耳尊（綏靖天皇）単独。創立年代不詳。
- **井川神社（愛媛県伊予三島市豊岡町、現・四国中央市）**: 祭神は神八井耳尊・神渟名川耳尊（綏靖天皇）。白鳳3年（674年）に榧ヶ大岐から遷座と伝わり、大宝年間（701-704）に宇摩郡大領・越智玉澄が現在地に社殿を建立。三代実録（元慶8年・884年）に従五位下を授けられた記載がある国史見在社。記紀（712/720年）編纂以前から綏靖天皇を祀っていたことになる。
- **伊予国造の祖・神八井耳命を祀る神社（すべて愛媛県）**: 伊予国造の祖神とされる神八井耳命は、佐々久神社（延喜式内社、西条市、大鷦鷯尊＝仁徳天皇と合祀）／伊豫神社（延喜式内社論社、伊予市上野、月夜見命の配神として）／阿沼美神社（延喜式内社論社、松山市味酒町、天智3年・664年創建伝承）の3社に祀られる。愛媛県内に集中しており、綏靖天皇と兄・神八井耳命がほぼ同所（四国北部・愛媛県近辺）にいたことを示唆する。四国の他県には綏靖天皇の痕跡が見られない点も特徴とされる。

## 4. 阿波説における意義

阿波説において、四国の古名「伊予之二名島」の「伊（イ）」は「阿波（飯の国）」を指し、「予（ヨ）」が現在の愛媛を指すと読む。綏靖天皇とその兄の事績は、この「イの国（阿波）」から出発した王権が、隣国の「予の国（伊予）」を平定・開拓していくプロセスを反映していると解釈される。また、母が事代主神の娘であることから、出雲系・海人族系の血を引く王権であったとし、阿波の海洋祭祀圏（事代主祭祀＝[[事代主命（エビス）]]）との地理的整合を論じる。

→ 兄 神八井耳命を起点とする **多氏の東遷**（阿波→常陸・大生神社）とも並行して論じられる。

## 5. 留保

> [!warning] 注意
> - 綏靖天皇は記紀に系譜のみで具体的事績を欠く「欠史八代」の一柱であり、**実在性そのものが学術的に未確定**である。
> - 「葛城高丘宮＝阿波（勝浦・北灘）」「伊予之二名島の伊＝阿波」「四国北部開拓の主導者」はいずれも阿波説的解釈で、通説は宮を大和葛城に置く。
> - 若宮神社（東みよし町）・井川神社（四国中央市）の綏靖天皇祭祀は地域伝承・国史見在社としての記録であり、記紀の事績と直接結びつくものではない。
