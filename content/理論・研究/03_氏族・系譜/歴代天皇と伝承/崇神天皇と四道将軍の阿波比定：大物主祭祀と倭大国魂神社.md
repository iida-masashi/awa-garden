# 崇神天皇と四道将軍の阿波比定：大物主祭祀と倭大国魂神社

> [!summary] 要旨
> 『記紀』が「初めて国を治めた天皇（御肇國天皇／ハツクニシラススメラミコト）」と称える第10代崇神天皇の事績——疫病鎮静のための大物主祭祀、倭迹々日百襲姫の神託、大田田根子の探索、四道将軍派遣、倭大国魂神の遷座——を阿波（徳島県）の地名・式内社・遺跡から比定する。倭国大乱の時代と疫病記事が重なる時代観、田村遺跡（高知県南国市）衰退との同期、全国唯一「倭大国魂」を祀る式内社が美馬郡に鎮座する事実から、崇神朝の活動舞台を四国・阿波吉野川流域に置く論考の整理。

---

## 1. 崇神天皇の基礎情報と通説

| 項目 | 内容 |
|------|------|
| 諡号（古） | 御真木入日子印恵命／所知初國御真木天皇 |
| 諡号（紀） | 御間城入彦五十瓊殖天皇／御肇國天皇 |
| 風土記 | 美萬貴天皇（『常陸国風土記』に「初國所知美麻貴天皇」） |
| 在位（紀） | 紀元前97年〜紀元前30年（皇紀ベース、讖緯説による後付けの可能性） |
| 崩年干支 | 戊寅（古事記）→ 318年もしくは258年比定 |
| 通説の宮 | 磯城瑞籬宮／師木水垣宮（奈良県桜井市金屋・志貴御県坐神社伝承地） |
| 通説の陵 | 山邊道勾岡上陵＝行燈山古墳（奈良県天理市、墳丘長242m） |

- 神武の「始馭天下之天皇」と崇神の「御肇國天皇」がいずれも「ハツクニシラススメラミコト」と読める二重存在問題。
- 「ミマキイリヒコ」（崇神）と「イクメイリヒコ」（垂仁）に共通する「イリヒコ」呼称から、崇神を始祖とする「イリ王朝」「三輪王朝」説。
- 「ミマキ」は阿波の「美馬」と音通する重要な手掛かり（[[帥升ミマ説：元始ヤマト王権初代王と若杉山]] と接続）。

## 2. 疫病記事と倭国大乱の同時代性

### 記紀の疫病記事
- 古：「此天皇之御世、伇病多起、人民死爲盡」
- 紀：即位5年「國內多疾疫、民有死亡者、且大半矣」／即位6年「百姓流離、或有背叛」

### 中国史書との対応
- 『後漢書』東夷伝「桓霊間（146年〜189年）に倭国大いに乱れ、互いに争い合う」と重なる可能性。
- 詳細は 邪馬壹國・投馬國の阿波比定論、[[帥升ミマ説：元始ヤマト王権初代王と若杉山]] を参照。

### 田村遺跡（高知県南国市）の同期衰退
- 全国最大級の弥生時代集落遺跡（約450棟の竪穴住居・約400棟の掘立柱建物、計約850棟）。
- 三重環濠、大量土器、ガラス玉、銅鏡片、神殿らしき建物が描かれた土器、人面獣身の土偶を出土。
- 北部九州より古い弥生土器も確認。
- **倭国大乱期に衰退**——崇神紀の疫病記事と時代軸が一致。
- 大杉博氏「死国＝邪馬台国封印」説（四国が意図的に古代史から外されている）と整合。

### 天忍穂別神社（高知県香南市香我美町山川字スミガサコ）
- 田村遺跡近傍、式内社。
- 主祭神：哉吾勝勝速日天忍穂耳尊。相殿：饒速日尊。
- 「石舟さま」と呼ばれ、饒速日が石舟で天降ったと伝承。境内裏に巨大な舟形自然石。
- **航海安全神かつ疱瘡（天然痘）神**として祀られる——疫病平定との連関。
- 物部川流域に物部氏伝承が濃密。

## 3. 物部氏・阿波忌部の祖系

### 系譜
> アマテラス×スサノオ → 天忍穂耳命 → 饒速日命 → 宇摩志麻遲命 → 彦湯支命 → 出石心命 → 大矢口命 → 大麻綜杵命 → 伊加賀色許雄命 → 物部十千根（垂仁朝五大夫）→ 物部氏

### 阿波忌部との接続
- 「阿波風土記に曰く、大麻綜杵命の母は伊香色謎命なり按するに大麻綜杵命は阿波忌部族なるべし」
- 大麻綜杵命を祀るのは **御所神社（瑜伽神社）**（徳島県吉野川市鴨島町）。
- 孝元天皇妃・開化天皇の母 **伊香色謎命** を祀るのは **式内社 伊加加志神社**（徳島県吉野川市川島町）のみ。
- 旧麻植郡（阿波忌部の根拠地）に系譜の祭祀がすべて集約 → **物部氏は阿波忌部からの分派**。

## 4. 大物主祭祀と大田田根子の出自

### 託宣の経緯
1. 崇神は神床で大物主から「我が子・大田田根子に祀らせよ」との夢告。
2. 倭迹々日百襲姫命（孝霊天皇皇女）に大物主が憑依し神託を下す（紀）。
3. 紀7年8月：倭迹速神浅茅原目妙姫・大水口宿禰・伊勢麻績君の三人が同夢を見る。
4. 大田田根子に大物主を、市磯長尾市に倭大国魂神を祀らせ、疫病終息。

### 大田田根子の系譜
- 古：大物主大神 × 活玉依毘売（陶津耳命の娘）→ 櫛御方命 → 飯肩巣見命 → 建甕槌命 → **意富多々泥古**
- 紀：大物主 × 活玉依媛（陶津耳＝奇日方天日方武茅渟祇の娘）→ **大田々根子**

### 大田田根子の居所——阿波の地名対応
| 記紀の地名 | 阿波比定地 | 根拠 |
|-----------|-----------|------|
| 河内の美努村（古） | 徳島県三好市三野町 | 「ミノ」＝美馬郡から分かれた三好郡三野郷（和名類聚抄） |
| 茅渟縣（紀） | 三野町・三好周辺一帯 | 武茅渟祇＝チヌツミの「茅渟」由来 |
| 陶邑（紀） | 同上 | 陶津耳＝スエツミミの「陶」由来 |
| 三島溝杭姫の「三島」 | 徳島県美馬市穴吹町**三島** | 活玉依姫の別名 |
| 「大田」 | 徳島県美馬郡つるぎ町貞光**太田**（旧太田村） | 三島の隣接地 |

> 玉櫛媛＝溝咋姫神＝三島溝杭姫＝三嶋溝樴姫＝活玉依姫＝勢夜陀多良比売（『日本書紀』）

## 5. 倭大国魂神社：全国唯一の式内社

### 倭大國玉神社（徳島県美馬市美馬町重清字東宮上3）
- **全国で唯一「倭大国魂」を祀る式内社**。
- 「倭大國魂」とは「倭の産土神」。当然「倭」の地に祀られているはずで、その地が **阿波・美馬**。
- 詳細は [[倭大国玉神]] を参照。

### 市磯長尾市と椎根津彦
- 市磯長尾市は『紀』垂仁3年・7年で「倭直祖長尾市」。
- 椎根津彦（槁根津彦・珍彦）は神武東征の倭国造（倭直部）祖。
- 『三代実録』（901年）「阿波国名方郡海直豊宗、海直千常等同族七人に**大和連**の姓を賜う」。
- 『姓氏録』（815年）「大和連は椎根津彦の後裔」。
- → 阿波の海直は椎根津彦の後裔であり、**阿波と大和は同族**。

## 6. 天照大神の遷座と豐鍬入姬命

### 紀の記述
> 「先是、天照大神・倭大國魂二神、並祭於天皇大殿之內。然畏其神勢、共住不安。故、以天照大神、託豐鍬入姬命、祭於倭笠縫邑、仍立磯堅城神籬…日本大國魂神、託渟名城入姬命令祭、然渟名城入姬、髮落體痩而不能祭。」

### 「倭笠縫邑」＝阿波美馬郡比定
- **天都賀佐比古神社**（徳島県美馬市美馬町轟32、式内社）。
- 旧郡里村（こおざと）、美馬郡院があった大村郷。
- 古来「アマノカサツカ」と呼ばれ大社。「カサ」が笠縫邑に対応。
- 祭神は級長津彦命（風神）——倭国造（倭直部）の祖「シイネツヒコ」を祀っているのではないかとの仮説（「シナツヒコ」と「シイネツヒコ」の音通）。
- 段の塚穴古墳、白鳳期立光廃寺、土師器窯跡などから当地が県西の文化中心。
- 龍田大社（奈良）は崇神朝起源とされるが、当社の方が約1世紀古い可能性。

### 神浅茅原
- 「神淺茅原」＝天皇が八十萬神に占いを問い、倭迹々日百襲姬が神憑った場所。
- 「倭迹速-神淺茅原-目妙姬」と分解できる地名由来人名。
- 高天原・邪馬台国を想起させる祭祀の中心地——高天原阿波説：神山町の巨大湖と天つの民 と接続可能。
- 「目妙姫」＝黥面（魏志倭人伝の黥ける利目）の女性祭祀者の暗示。

## 7. 四道将軍と阿波・四国

崇神10年9月、四道将軍を派遣：
- 大彦命：北陸道
- 武渟川別：東海道
- 吉備津彦：西道
- 丹波道主命：丹波（山陰道）

途中、大彦命が和珥坂で異変を察知、倭迹々日百襲姫の予言により武埴安彦の謀反を知り、彦国葺（和珥氏祖）と共にこれを討伐。
四国（阿波）からみた派遣経路としては、吉野川流域を中心とする倭の中心から放射状に各方面へ向かう構図となる。

## 9. 「日本」と「倭」の表記改竄問題

- 紀の同じ段で「**倭**大國魂」と「**日本**大國魂神」が混在。
- 国号「日本」が定まるのは700年前後、奈良が「大和（おおやまと）」と定着するのも更に後。
- 崇神朝当時、「日本」「大和」は存在せず、**「倭（やまと）」＝徳島県**。
- 『日本書紀』完成（720年）時に意図的に「倭」→「日本」へ書き換えられたとみられる。
- 詳細は ヤマト 考察 系列（資料/01_ブログアーカイブ/koraku 内）。

## 13. 留保（中立的併記）

> [!warning] 注意
> - 阿波の地名「ミノ」「太田」「三島」「茅渟」が記紀の地名と一致する事実は確実だが、これは記紀の地名が後に阿波に持ち込まれた／逆に阿波から記紀地名が成立した、いずれの解釈も可能。
> - 田村遺跡の衰退は弥生後期気候変動や河川氾濫など複数要因あり、必ずしも倭国大乱だけが原因とは言えない。
> - 倭大國玉神社が全国唯一であることは式内社制定（10世紀）時点の話で、それ以前の祭祀分布までは保証されない。
> - 大杉博「死国＝邪馬台国封印」説は主流学界では受け入れられていない。
