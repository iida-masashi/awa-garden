# 崇神天皇

## 概要
- **読み**: スジンテンノウ
- **諡号（古）**: 御真木入日子印恵命／所知初國御真木天皇
- **諡号（紀）**: 御間城入彦五十瓊殖天皇／御肇國天皇（ハツクニシラススメラミコト）
- **代数**: 第10代
- **在位（紀）**: 紀元前97年〜紀元前30年（讖緯説による後付けの可能性）
- **崩年干支**: 戊寅（古事記）→ 318年もしくは258年比定
- **通説の宮**: 磯城瑞籬宮（奈良県桜井市金屋）
- **通説の陵**: 山邊道勾岡上陵＝行燈山古墳（奈良県天理市）
- **登場文献**: 『古事記』『日本書紀』『常陸国風土記』

## 阿波説における位置づけ
崇神天皇は **「ハツクニシラススメラミコト（御肇國天皇）」** と称えられる **実質的初代天皇** とされる。神武と崇神がともに「ハツクニシラス」と呼ばれる二重存在問題は、神武＝神話的始祖、崇神＝歴史的始祖の二段構造として理解される。

阿波説では、崇神朝の活動舞台を **四国・阿波吉野川流域** に置く。根拠：

| 論点 | 阿波での比定 |
|---|---|
| 諡号「ミマキ」 | 阿波の **美馬（みま）** と音通 |
| 倭大国魂神の遷座 | **全国唯一「倭大国魂」を祀る式内社＝美馬郡・倭大國魂神大國敷神社** |
| 大物主祭祀 | 大田田根子の系譜が **活玉依毘売（陶津耳の娘）** → 阿波海人族の女性 |
| 母・伊香色謎命 | **式内社 伊加加志神社（麻殖郡川島町）の主祭神**、全国唯一 |
| 父系祖父・大麻綜杵命 | **御所神社（瑜伽神社・吉野川市鴨島町）の祭神**、阿波忌部の流れ |
| 疫病鎮静 | 田村遺跡（高知県南国市）の倭国大乱期衰退と同期 |
| 四道将軍派遣 | 北陸・東海・西道・丹波の四方への派遣 → 阿波を中心とした四国・近畿圏の地理に整合 |

→ 崇神天皇は **阿波（美馬）に本拠を置き、阿波忌部・物部の祭祀基盤を背景に列島統合を進めた歴史的初代王** とする。

## 主要事績
1. **疫病鎮静と神祇再編**：天照大神と倭大国魂を宮中から外に出し、それぞれ豊鋤入姫・市磯長尾市に祭祀させる
2. **大物主祭祀**：夢告により大田田根子に大神神社を祀らせ疫病終息
3. **四道将軍派遣**：大彦命・武渟川別命・吉備津彦命・丹波道主命を四方に派遣
4. **戸籍と税制**：男弓弭の調・女手末の調を初めて制定
5. **任那遣使**：朝鮮半島との外交開始
