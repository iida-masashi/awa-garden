# 古代天皇の阿波在位説：初期天皇から持統天皇まで

← ポータルへ戻る

> [!summary] 要旨
> 「古代天皇の阿波在位説」とは、**神武天皇から持統天皇に至る歴代天皇のうち、その宮・陵・本貫の少なくとも一部が阿波（徳島県）にあった** とする阿波説の **核心命題** の一つである。本ノートは個別天皇ごとの比定論考（欠史八代・崇神朝・応神/履中/継体・安徳・天武持統など）を貫く **総論的フレーム** を提供し、各専門ノートへの動線を整理する。

---

## 1. 命題の構造

阿波説における「天皇阿波在位説」は、単一の主張ではなく **複数階層の命題** から構成される。

| 層位 | 命題 | 阿波説における強度 |
|---|---|---|
| ① 神話時代 | 天孫降臨・神武東征前の天皇家本貫が阿波 | 強（地名・神社・氏族の三重整合） |
| ② 欠史八代 | 第2代〜第9代の宮・陵が阿波に比定 | 強（御間都比古神社など単独祭祀の式内社が現存） |
| ③ 崇神〜仲哀 | 大和進出後も阿波が祭祀本貫として並行 | 中（崇神朝四道将軍と倭大国魂の阿波集中） |
| ④ 応神〜継体 | 八幡信仰と継体王朝の本貫が阿波 | 中（[[応神・履中・継体天皇の阿波本貫論：八幡信仰と継体王朝]]） |
| ⑤ 天智〜持統 | 大化以降も阿波との祭祀的紐帯が維持 | 弱（大嘗祭麁服貢進の連続性として表出） |
| ⑥ 中世 | 安徳天皇の阿波落ち延び | 別系統（[[安徳天皇の阿波落ち延び説：壇ノ浦替え玉と剣山頓宮]]） |

→ 本命題は [[阿波説の根幹]] の **「四大柱」のうち①記紀神話の舞台移動論** と **④地名と氏族の東遷法則** に直接対応する。

## 2. 阿波在位説の論拠類型

### 2-1. 単独祭祀の式内社

阿波には **特定の天皇のイミナを単独で祭神とする** 式内社が複数現存する。これは「単なる崇敬」ではなく **その地が天皇の宮・墓・祖廟であった** ことを示す祭祀パターンと解される。

| 天皇 | 単独祭祀の阿波の式内社 | 所在 |
|---|---|---|
| 第5代 孝昭天皇（観松彦色止命） | [[御間都比古神社]] | 名方郡 佐那河内村 |
| 第7代 孝霊天皇 | [[天佐自能和氣神社]] | 名方郡 徳島市 |
| 第9代 開化天皇 | [[伊加加志神社]] | 麻殖郡 |
| 第10代 崇神天皇 | 倭大國魂神を介し 倭大國魂神社 | 美馬郡 |

→ 詳細：[[欠史八代：阿波・四国に残る実在の足跡]]、[[崇神天皇と四道将軍の阿波比定：大物主祭祀と倭大国魂神社]]

### 2-2. 宮・陵の地名対応

記紀に記された宮・陵の名称が、阿波の微地名と一致する事例が体系的に蓄積されている。

- 葛城高丘宮／片塩浮孔宮など欠史八代の宮 → 阿波の郡郷の微地形に対応
- 履中陵「百舌鳥（毛受）耳原南陵」 → 眉山山頂「毛受ヶ原」（[[応神・履中・継体天皇の阿波本貫論：八幡信仰と継体王朝]]）
- 継体「弥乎国高嶋宮」 → 鳴門町高島

→ 一覧：[[欠史八代の阿波比定論：宮・陵・妃の地名対応一覧]]、[[阿波・畿内地名ペア検証：東遷（ひがしうつり）の法則]]

### 2-3. 大嘗祭による「本貫」の儀礼的証明

天皇即位儀式である **大嘗祭** において、阿波からのみ調進される **麁服（あらたえ）** は、阿波が天皇家の祭祀本貫地であることの儀礼的痕跡とされる。この連続性は神話時代から令和に至るまで断絶なく続いており、「在位説」を **儀礼の側から** 補強する。

→ [[大嘗祭と麁服：阿波忌部の特権と幕府の契約]]、[[大嘗祭・三種の御膳：天皇即位儀式が証明する阿波の本国性]]

### 2-4. 産業・祭祀氏族の阿波集中

歴代天皇に仕えた **忌部・物部・中臣・多氏・海部氏・鴨族** といった氏族の祖神祭祀地が、いずれも阿波に集中する点も「天皇本貫が阿波」とする傍証として挙げられる。

→ [[阿波忌部氏伝承詳細]]、[[👥 阿波忌部の神系譜]]

## 3. 持統天皇までを射程とする理由

本ノートが「持統天皇まで」を区切りとするのは、阿波説における **時代区分の意味的な節目** がここに置かれているためである。

1. **天武・持統朝の祭祀大改編**：天武朝に大嘗祭が制度として確立し（7C後半）、持統朝にかけて「藤原京遷都」と国史編纂が進行する。
2. **記紀編纂と舞台上書き**：8世紀初頭の『古事記』『日本書紀』編纂において、阿波で起きた事跡が **畿内の地名に上書きされた** と阿波説は解する。
3. **隠蔽の起点**：以後、天皇の本貫としての阿波は史書から消され、阿波忌部の麁服貢進という **儀礼の形** にのみ残存する。

→ [[舞台移動と隠蔽の歴史：なぜ阿波は消されたのか]]

## 5. 阿波説における意義

本命題は **「阿波が単なる神話の舞台」ではなく「歴代天皇の実在地」であった** ことを主張する点で、阿波説の最深部に位置する。

- 記紀の神話描写が阿波の地形と一致するだけでは「神話の上書き」までしか言えない。
- 歴代天皇の宮・陵・妃の地名対応が阿波で揃って初めて、阿波が **「歴史としての本貫」** であったと言える。
- この点で本命題は、阿波説を「神話論」から「**王権史論**」へと格上げする論拠となる。

## 7. 留保

> [!warning] 注意
> - 「歴代天皇の在位地がすべて阿波であった」とまで言える物証は揃っていない。**強い阿波説／弱い阿波説** の区分が必要であり、特に持統朝に近づくほど「阿波本貫」より「阿波との祭祀的紐帯」と解する方が史料整合的である。
> - 単独祭祀の式内社についても、後世の追祀・合祀の可能性を一律に排除できない。**個別天皇ごとの精査** は各専門ノートに譲る。
> - 本命題は通説（畿内本貫説）と真っ向から衝突するため、社伝・地名・氏族・考古の **四点同時整合** が確認できない限り「仮説」の域に留めるべきである。
