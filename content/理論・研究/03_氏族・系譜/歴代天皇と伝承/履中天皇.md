# 履中天皇

> [!summary] 要旨
> 履中天皇（大兄去来穂別尊）は仁徳天皇の子（第17代）。即位前に婚約者・黒媛を弟の住吉仲皇子に騙し取られる試練を経て即位したと伝わる。阿波説は、その陵「百舌鳥（毛受）耳原南陵」を眉山山頂「毛受ヶ原」に、逃避先「石上神宮」を箸蔵寺に、逃亡経路の「大坂越え」を鳴門・東かがわの大坂峠に比定し、「飛鳥」を吉野川中下流域とみて、履中朝の活動舞台を阿波（吉野川中下流域）とする。詳細は複合論考 [[応神・履中・継体天皇の阿波本貫論：八幡信仰と継体王朝]] の §3 にあり、本ノートは履中単独の人物像として再構成する。

## 1. 概要
- **読み**: リチュウテンノウ
- **諱（古）**: 大江之伊邪本和気命（オオエノイザホワケノミコト）
- **諱（紀）**: 大兄去来穂別尊（オオエノイザホワケノミコト）
- **代数**: 第17代
- **父**: 仁徳天皇
- **母**: 葛城磐之媛
- **通説の宮**: 磐余稚桜宮（奈良県桜井市）
- **通説の陵**: 百舌鳥耳原南陵＝上石津ミサンザイ古墳（大阪府堺市）
- **倭五王比定**: 「讃」（諸説）
- **登場文献**: 『古事記』『日本書紀』

## 2. 阿波説における位置づけ
履中天皇は仁徳天皇の子で、即位前に婚約者・黒媛を弟の住吉仲皇子に騙し取られる試練を経て即位したと伝わる。阿波説では、その陵「百舌鳥（毛受）耳原南陵」を **眉山山頂「毛受ヶ原」** に、逃亡経路の「大坂越え」を **鳴門・東かがわの大坂峠** に比定し、履中朝の活動舞台を阿波（吉野川中下流域）とみる。

詳細は複合論考 [[応神・履中・継体天皇の阿波本貫論：八幡信仰と継体王朝]] の §3 に展開されており、本ノートは履中天皇単独の人物像として再構成する。

| 論点 | 通説 | 阿波説の比定 |
|---|---|---|
| 陵「百舌鳥（毛受）耳原南陵」 | 上石津ミサンザイ古墳（堺市） | **眉山（以乃山）山頂「毛受ヶ原」** |
| 「飛鳥」（近飛鳥・遠飛鳥） | 河内・大和の飛鳥 | **吉野川中下流域**（近＝旧板野郡、遠＝美馬市） |
| 逃げ込んだ「石上神宮」 | 奈良県天理市 | **箸蔵寺**（三好市池田町州津、御詠歌「いその神」） |
| 「大坂越え」逃亡路 | 大阪府羽曳野→當麻 | **大坂峠**（鳴門市北灘町碁浦〜東かがわ市坂元） |
| 婚約者・黒媛のルーツ | 吉備海部直の娘 | **阿波の海部**（鳴門市北灘町大浦） |

## 3. 主要事績
1. **即位前の試練**：婚約者・黒媛を弟・住吉仲皇子に奪われる。難を逃れて即位。
2. **石上神宮への逃避**：反乱を避けて石上神宮（阿波説では箸蔵寺）へ逃れる。
3. **「大坂越え」**：大坂山口で乙女に道を問い、當岐麻道を回れと教えられる（阿波説では大坂峠）。
4. **国史編纂の初め**：諸国に国史（фумиひと）を置いたと伝わる。

## 4. 系譜（阿波説の整理）
```
仁徳天皇（難波高津宮＝東讃寒川郡難波郷）
   × 葛城磐之媛
        ↓
   履中天皇（大兄去来穂別尊）
   ├ 弟・住吉仲皇子（黒媛を奪う）
   ├ 弟・反正天皇（第18代）
   └ 弟・允恭天皇（第19代）
        ↓（皇子・市辺押磐皇子）→ 顕宗・仁賢天皇へ
```
- 父・仁徳の宮「難波高津宮」を阿波説は東讃寒川郡難波郷に比定（[[仁徳天皇]] 参照）。
- 婚約者・黒媛は阿波の海部（鳴門市北灘町大浦）に連なるとされ、王権と阿波海人族の通婚を示す。

## 5. 阿波比定の核心論点

### 5-1. 「百舌鳥（毛受）耳原南陵」＝眉山「毛受ヶ原」
『古事記』は陵を「毛受（もず）」とし、『日本書紀』は「百舌鳥耳原陵」と記す。岩利大閑『道は阿波より始まる』は「日孁命神陵・矢野神山の対岸の **以乃山（現眉山）山頂を毛受ヶ原** といい、その東西両端が **毛受の耳原** と呼ばれた古代の大聖地」とする。救世山峯薬師法谷寺「峯薬師如来縁起」にも同旨。**毛受＝百舌鳥（もず）** は表記違いの同義とし、モズの眉模様と眉山の地形を重ねる。

### 5-2. 「飛鳥」＝吉野川中下流域
『古事記』水歯別命条の「近飛鳥」「遠飛鳥」を、阿波説は **近飛鳥＝旧板野郡域（板野町〜鳴門市大麻町堀江）の港湾**、**遠飛鳥＝倭大國魂神社の鎮座する美馬市周辺** に比定。「飛鳥」全域を吉野川中下流域（美馬市〜鳴門市）とみる。

### 5-3. 「石上神宮」＝箸蔵寺
履中が逃れた石上神宮を、阿波説は **箸蔵寺**（三好市池田町州津、金毘羅大権現本尊）に比定する。御詠歌「**いその神** ふりにし世より…」、吉野川の古名「ふる川」と「布留」の音通を根拠とする。神仏習合・空海伝説により寺化＝古代史の封印とみる。

### 5-4. 「大坂越え」＝大坂峠
逃亡経路の「大坂山口」を、阿波説は **大坂峠**（鳴門市北灘町碁浦と東かがわ市坂元の県境、標高270m）に比定。古道「難波・奈良街道大坂峠越え」とし、「伊座（いざ）」「帰来」「迯田（にげた）」等の地名が東かがわ〜阿波市に残存するとする。

## 10. 留保（中立的併記）

> [!warning] 注意
> - 「毛受ヶ原＝以乃山（眉山）」は岩利大閑・髙木隆弘の指摘だが、眉山山頂に履中朝の墓所を特定する考古遺構は確認されていない。
> - 「石上神宮＝箸蔵寺」は御詠歌の語句と「布留／ふる川」音通に依拠し、本来の石上神宮（天理市）の歴史的継続と競合する。
> - 「大坂越え＝大坂峠」は地名対応に基づくが、通説経路（羽曳野→當麻）の矛盾を指摘する論法であり、積極的な物証ではない。
> - 倭五王「讃」の比定は応神・仁徳・履中・宇遲之和紀郎子など諸説あり確定しない。
