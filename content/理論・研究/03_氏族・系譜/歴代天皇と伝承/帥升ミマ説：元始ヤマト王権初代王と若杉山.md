# 帥升＝ミマ説：元始ヤマト王権の初代王と若杉山

『後漢書』東夷伝に記される **倭王帥升（すいしょう）** は、邪馬台国の卑弥呼に先立つ **元始ヤマト王権の初代王** であり、その名「**帥升**」は **「ミマ」または「いま」** と読まれる――これが ANYA(194) の核心命題。本ノートはこの説と、若杉山辰砂採掘遺跡・海人族祭祀との接続を整理する。

> 📚 関連: [[阿波の水銀朱（辰砂）：若杉山遺跡と権力の象徴]], [[阿波説タイムライン]]

## 🎯 核心命題

> **倭王帥升（成暦107年献上）＝「ミマ」または「いま」と読み、阿波（伊都・夷国）の王**

## 📜 倭王帥升の歴史的事実

### 『後漢書』東夷伝の記述
> 安帝の永初元年（**107年**）、倭国王 **帥升等** が **生口（せいこう）160人** を献じ、請見を願い出た。

| 項目 | 内容 |
|---|---|
| 年代 | **後漢 安帝 永初元年（107年）** |
| 倭王名 | **帥升** |
| 献上品 | **生口 160人** |
| 性格 | 倭国の最初の対中朝貢の明確な記録 |

### 「帥升」の従来読み・新読み

| 読み | 提唱者 | 解釈 |
|---|---|---|
| すいしょう | 通説 | 漢音による単純な音読み |
| **ミマ** | 阿波説（ANYA(194)） | **古代ヤマト王権の「ミマ」称号** |
| **いま** | 岡田秀博説（音韻学） | 古代日本語音による訓読 |

→ いずれにせよ、「帥升」は **個人名ではなく称号**（王号）の可能性が高い。

## 🔑 ミマ説の根拠

### 「ミマキ入彦命」（崇神天皇）との関係
- 第10代 **崇神天皇** の和風諡号は **「御真木入日子印恵命（ミマキイリヒコイニエノミコト）」**
- 「**ミマ**」を冠する初期天皇の称号
- 「ミマキ」＝「ミマ + 杵（き）」＝ミマの王

→ **「帥升」が「ミマ」と読めるなら、帥升は崇神天皇の系譜の祖** となる。

### 古代王権の「ミマ」称号
| 称号 | 関連天皇 |
|---|---|
| ミマキ入彦 | 崇神天皇 |
| ミマツ彦 | 孝昭天皇（第5代）の御間都比古色止命 |
| 帥升＝ミマ | 紀元107年の倭王 |

→ **「ミマ」は古代ヤマト王権の初代王朝の称号**であり、帥升はその初代候補。

### 御間都比古神社（阿波・名方郡）
- 阿波の式内社 [[御間都比古神社]] は **孝昭天皇＝御間都比古色止命** を祀る
- 「ミマツ彦」の祭祀地が **阿波の名方郡** にある
- 帥升=ミマ系統の祭祀地候補

## 🏝 「夷洲」「いのくに」と帥升の本拠

### 『後漢書』東夷伝の「夷洲」
> 會稽海外有東鯷人、分為二十餘國。又有 **夷洲** 及澶洲。

→ 「夷洲（いしゅう）」は会稽の海外、伝説の徐福が至った地。

### 阿波の「いのくに」
- 阿波は古名 **「夷国（いのくに）」**
- 眉山 = **以乃山（いのやま）**
- 麓 = 伊都・夷都・**渭津（いのつ）**

→ 「**いのつ＝帥升の都**」の可能性。

## 💎 若杉山辰砂採掘遺跡との接続

### 海人族のアイデンティティ
- 帥升一族は **海人族**（刻面分身を持つ＝『魏志倭人伝』の倭人描写と整合）
- 阿波の海部郡・那賀郡は海人族の本拠地
- **若杉山辰砂採掘遺跡**（阿南市）は帥升の時代に活発

### 生口160人の正体
ANYA(194) の重要指摘：
> 「生口」は通説では奴隷だが、実は **「成功（せいこう）」= 高度技術者集団** の可能性。

つまり：
- **生口160人 ≠ 奴隷160人**
- **成功160人 ＝ 中国漢から派遣された高度技術者160人**
- 採掘・冶金・農業の技術者の交換

→ これと **2024年確認の「火入れ法」**（若杉山で漢代中国と同じ採掘技術）が整合する。**帥升の時代に中国から鉄・水銀技術が阿波に持ち込まれた**。

詳細：[[火入れ法と国際技術交流：徐福伝説との接合]]

## 🌐 岡山県縦吊遺跡（32km の水銀種）

ANYA(194) で言及された **岡山県の遺跡**：
- 縦吊遺跡：32km の水銀種（朱）採掘の痕跡
- 阿波・若杉山と並ぶ古代の朱産業地

→ 帥升時代の **西日本広域の朱・鉄産業ネットワーク** が形成されつつあった可能性。

## 📜 帥升と邪馬台国の時間関係

| 年代 | 出来事 |
|---|---|
| **107年** | **倭王帥升** が後漢に160生口を献上 |
| 178-184年 | 倭国大乱 |
| 239年 | **卑弥呼** が魏に朝貢（『魏志倭人伝』） |

→ 帥升と卑弥呼の間は約130年。**帥升 = 元始ヤマト王権の初代**、**卑弥呼 = 邪馬台国の女王** で、両者は同じ王朝の異なる時代と解釈できる。

## 🔗 阿波説における5つの意義

### 1. 邪馬台国阿波説の前史
卑弥呼以前の **倭王帥升** も阿波の王であった可能性。**阿波王権の歴史が紀元前後まで遡る**。

### 2. ヤマト王権の「ミマ」始祖論
古代ヤマト王権の称号「ミマ」の発祥地が阿波。**崇神天皇は阿波の祖神を継ぐ系譜**。

### 3. 海人族アイデンティティ
帥升一族 = 海人族 ＝ 阿波・海部郡を本拠とする海洋勢力。**倭国王の本貫が阿波**。

### 4. 国際技術導入のタイミング
帥升の時代（107年）に **中国から高度技術者集団** が阿波に派遣された可能性。これが若杉山の火入れ法導入と整合。

### 5. 御間都比古神社の重要性
阿波・名方郡の **御間都比古神社**（[[御間都比古神社]]）は、帥升=ミマ系統の祭祀地として **元始ヤマト王権の原点** を示す式内社。
