# 1. 天富命の上陸と安房神社の創建

← ポータルへ戻る

> [!summary] 要旨
> **天富命（あめのとみのみこと）** は神武天皇の勅命を受け、阿波忌部の一族を率いて海路東へ向かい、房総半島の南端に上陸して **安房神社の地に本拠を定めた**。祖神 **天太玉命** を祀って東国における忌部氏の総本山とし、ここから上総・下総へと産業を広げた。本ノートは阿波忌部の **東遷の起点** をなす伝承を整理し、阿波説における意義を論じる。

---

## 1. 命題の構造

| 通説 | 阿波説 |
|---|---|
| 安房神社＝古代房総の地域祭祀 | 安房神社＝阿波忌部の東国総本山 |
| 天富命＝中央朝廷の使者 | 天富命＝阿波忌部の本部隊を率いる東遷主導者 |
| 天太玉命＝中央忌部の祖神 | 天太玉命＝阿波忌部の祖神（または天日鷲命と並ぶ） |

→ 本命題は [[阿波説の根幹]] の **「四大柱」のうち④地名と氏族の東遷法則** の **起点となる伝承** である。

---

## 2. 天富命（あめのとみのみこと）

### 2-1. 神武勅命と東遷

- 天富命は **神武天皇の勅命** を受け、阿波忌部の一族を率いて海路東へ向かった。
- 神武東征の後、東国（房総半島）の開拓を担う使命を負って派遣された。
- 阿波忌部の **本部隊** とも言える主要勢力を率いた。

### 2-2. 系譜上の位置

天富命は、阿波忌部の祖神系譜の中でも特別な位置を占める。

- **天太玉命** の御子神とも、近代の子孫ともされる。
- 阿波忌部の独自系譜では、**由布津主命（阿八別彦命）** と並ぶ東遷の祖。

→ [[👥 阿波忌部の神系譜]]、[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

## 3. 拠点の定立

### 3-1. 上陸と本拠地

| 項目 | 内容 |
|---|---|
| 上陸地 | 房総半島の南端 |
| 本拠地 | 現在の安房神社（千葉県館山市） |
| 祭祀 | 祖神 **天太玉命** を奉斎 |
| 位置づけ | 東国における忌部氏の総本山 |

### 3-2. 安房神社

- **安房神社**（千葉県館山市）：現在も鎮座する古社。
- 主祭神：**天太玉命**（中央忌部・阿波忌部の祖神）
- 後背に **吾谷山（あづちやま）** を控え、海に近い古代の聖域配置。
- 大嘗祭において **由加物（ゆかもの）の貢進** を行う特権社。

---

## 4. 忌部の本部としての位置

### 4-1. 阿波からの本部隊移動

ブログの考察によれば、**阿波にいた忌部族のうち、本部隊とも言える主要勢力がこの安房へ移住し、そこから上総・下総へと産業を広げていった** とされる。

| 段階 | 出来事 |
|---|---|
| ① 阿波本貫 | 麻殖郡を中心とした阿波忌部の祭祀・産業基盤 |
| ② 東遷決定 | 神武勅命による天富命の派遣 |
| ③ 海路移動 | 黒潮ルートで太平洋を北上 |
| ④ 安房上陸 | 房総半島南端に上陸、安房神社創建 |
| ⑤ 産業展開 | 上総・下総への北上と「総国」の形成 |

→ [[北上と「総（ふさ）の国」の誕生]]、[[産業と技術の足跡]]

### 4-2. 黒潮ネットワークの起点

天富命の海路移動は、阿波の海人族（海部氏・安曇氏）の **黒潮ネットワーク** を経由したとされる。鳴門→紀伊水道→太平洋→房総というルートは、古代から海人族によって維持されていた航海路と整合する。

→ [[阿波海人族：海洋王権を支えた安曇・海部・那賀のネットワーク]]、[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

## 5. 阿波説における意義

「天富命の上陸と安房神社の創建」は、阿波説の **以下の論点を支える**：

1. **東遷の起点伝承**：阿波忌部の房総開拓の **出発点** として位置づけられる。
2. **神武勅命との接続**：神武東征と並行する阿波忌部の東国展開を、皇統の意思に組み込んで語る。
3. **東国における祭祀本拠**：安房神社が阿波忌部の **東国総本山** として、阿波の忌部神社と対をなす二大拠点を形成する。
4. **大嘗祭の二重貢進構造**：阿波（麁服）と安房（由加物）の両方から大嘗祭への貢進があり、両国が **同一祭祀圏** であったことの儀礼的証明。

## 7. 留保

> [!warning] 注意
> - 「**天富命の東遷**」は『古語拾遺』（807年、斎部広成）に依拠する。**記紀本文には明確な記載がない** ため、史料的には中央忌部の伝承に依存している。
> - **神武勅命** との直接的接続は、阿波説の解釈モデルであり、『古語拾遺』本文にも具体的記述は限定的である。
> - 安房神社の祭神 **天太玉命** が **阿波忌部の祖神（天日鷲命と同一系統）** であるか、**中央忌部の独立祖神** であるかは、伝承的に二説あり、本ノートは阿波説寄りの整理を採用している。
> - 「**忌部の本部隊が阿波→安房に移住**」とする規模感の主張は、ブログ的解釈に近く、**考古学的物証**（同型墓制・同型遺物）による裏付けが今後の課題である。
