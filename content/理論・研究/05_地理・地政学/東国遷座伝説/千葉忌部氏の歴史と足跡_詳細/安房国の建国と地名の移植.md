# 2. 安房国の建国と地名の移植

← ポータルへ戻る

> [!summary] 要旨
> 神武天皇の勅命を受けた **天富命（あめのとみのみこと）** が阿波忌部を率いて房総半島南端に上陸し、**安房神社の地に本拠を構えて祖神を祀った**。この地は故郷への思いを込めて「**安房（あわ）**」と名付けられ、阿波の **勝浦・白浜・海部** といった地名が次々と房総の海岸線に再現された。これは単なる命名ではなく、**阿波の産業構造（漁業・航海）をそのまま移植** した文化的・経済的移動の証拠とされる。

---

## 1. 命題の構造

| 通説 | 阿波説 |
|---|---|
| 安房国＝古代房総南部の地域名（独自） | 安房国＝阿波忌部が「故郷の阿波」を移植 |
| 勝浦・白浜＝地形語（独自） | 阿波の勝浦・白浜の地名移植 |
| 安房神社の創建＝在地祭祀 | 阿波忌部祖神（天太玉命）の遷座 |

→ 本命題は [[阿波説の根幹]] の **「四大柱」のうち④地名と氏族の東遷法則** を、**阿波→房総** という太平洋ルートで実証する代表事例である。

---

## 2. 拠点の確立

### 2-1. 天富命の上陸と安房神社

天富命は、神武天皇の勅命を受けて阿波忌部の一族を率いて海路東へ向かい、**房総半島の南端に上陸**。現在の **安房神社**（千葉県館山市）の地に本拠を構え、**祖神（天太玉命）** を祀った。

| 項目 | 内容 |
|---|---|
| 主導者 | 天富命 |
| 一族 | 阿波忌部 |
| 上陸地 | 房総半島南端 |
| 創建神社 | 安房神社（東国における忌部氏の総本山） |
| 主祭神 | 天太玉命（阿波忌部祖神） |

→ 詳細：[[天富命の上陸と安房神社の創建]]

### 2-2. 「安房（あわ）」の命名

この地域は **故郷・阿波（あわ）への思いを込めて「安房（あわ）」と名付けられた**。これは阿波説における **東遷の確かな痕跡** とされる。

- 「**阿波（あわ）**」と「**安房（あわ）**」は同音であり、漢字表記が異なるだけで本来は同一の地名。
- 房総半島の **「安房国」** という古国名は、阿波忌部の故郷意識の直接的痕跡である。

## 3. 勝浦と白浜の地名移植

### 3-1. 阿波勝浦と房総勝浦

| 阿波 | 房総 |
|---|---|
| 徳島県勝浦郡（勝浦町・上勝町） | 千葉県勝浦市 |
| 紀伊水道に面した漁港 | 太平洋に面した漁港 |

阿波の勝浦郡は、海部郡と並ぶ阿波の海洋・漁業の拠点。同名の **千葉県勝浦市** が房総半島の太平洋岸に存在することは、地名移植の典型例とされる。

### 3-2. 阿波海部の白浜と房総の白浜

| 阿波 | 房総 |
|---|---|
| 徳島県海部郡海陽町（旧海部町）の白浜 | 千葉県南房総市白浜町 |
| 海人族（海部氏）の活動拠点 | 房総半島南端、安房神社の至近 |

阿波の海部（あま）の白浜と、房総南端の白浜が対応する。これは **海人族（海部氏）ぐるみで阿波→房総へ移動した** ことの傍証とされる。

## 4. 産業構造の移植

地名移動は単なる命名ではなく、**産業構造そのものの移植** を意味する。

| 産業 | 阿波 | 房総 |
|---|---|---|
| 漁業 | 海部・勝浦・宍喰の漁業集落 | 勝浦・白浜の漁業集落 |
| 航海 | 鳴門海峡・紀伊水道経由の海運 | 房総半島の太平洋海運 |
| 麻織物 | 麻殖郡の麻産業 | 上総・下総の麻・総（ふさ） |
| 神宝製作 | 阿波忌部の製織技術 | 安房・上総の倭文（しどり）氏 |

→ [[産業と技術の足跡]]

## 5. 阿波説における意義

「安房国の建国と地名の移植」は、阿波説の **以下の論点を支える**：

1. **東遷の実証**：神話的伝承ではなく、**地名・神社・産業の三点同時整合** で東遷を裏付ける。
2. **黒潮ネットワーク**：阿波→房総の海路移動は、黒潮を介した海人族のネットワークが古代に既に確立していたことを示す。
3. **大嘗祭の起源**：阿波と安房の両国から大嘗祭の貢進があった事実が、両国が **同一祭祀圏** であったことを傍証する（[[大嘗祭と麁服：阿波忌部の特権と幕府の契約]]）。
4. **「総（ふさ）国」の誕生**：安房から北上した忌部一族が「総国」を生み、後の上総・下総に分かれる流れ（[[北上と「総（ふさ）の国」の誕生]]）。

## 7. 留保

> [!warning] 注意
> - 「**安房＝阿波**」の同音対応は強い傍証だが、**漢字表記が古来異なる** ため、両者が完全に同一系統の地名であるかは厳密には別途検証を要する。
> - 「**勝浦**」「**白浜**」は **全国に複数存在する** 地形語的地名でもあるため、阿波→房総の直接移植と断ずるには **他地域の事例との比較** が必要。
> - 房総側の地名の **成立年代** が阿波側より古い場合、阿波説は成立しない。**両者の地名年代の比定** は別途検討すべき。
> - 「**産業の移植**」は社会経済史的観察であり、考古学的物証（同型の漁具・織具など）による裏付けが望まれる。
