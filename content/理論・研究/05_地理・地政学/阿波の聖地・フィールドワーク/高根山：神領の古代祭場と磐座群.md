# 高根山：神領の古代祭場と磐座群（こうねやま）

> [!summary] 要旨
> **高根山（こうねやま）** は、徳島県名西郡神山町神領高根に広がる、**海抜700m前後・数十haの高原**。戦前戦後にはスキー場が開かれた緩やかな高地で、東端に磐座 **[[天禺岩：高根山の磐座と巫女の祈所|天禺岩（天寓岩）]]** と **台石**、谷側に人面状の大岩 **[[笑子岩：人面嶽と味鉏高彦根・事代主の磐座|笑子岩（人面嶽）]]**、そして標高720mに **[[高根山悲願寺：卑弥呼の宮室と常厳寺跡|高根山悲願寺]]** を擁する。X アカウント **@kamiyamafudoki（神山風土記）** は、高根を**縄文後期の粟・黍焼畑の可能性をもつ古代祭場** として捉え、**味鉏高彦根神（[[味耜高彦根命]]）** に関連する聖地、また[[大宜都比売命（オオゲツヒメ）]]の粟作圏の一角として論じる。本ノートは、高根に分布する個別の聖地・磐座を束ねる**地理的アンブレラ（ハブ）** として位置づけ、各専門ノートへの動線を整理する。

## 4. 阿波説における意義

### 4-1. 縄文後期の焼畑・古代祭場

@kamiyamafudoki は、三波川帯に集中する阿波の磐座信仰・山上集落（ソラ集落）が、明治まで続いた**粟や黍などの焼畑農耕**に出発をもつとみる。高根もその一角で、海抜700mの高原に磐座群（天禺岩・台石・笑子岩）が分布することを、**縄文後期の祭場** の痕跡と解釈する。

### 4-2. 味鉏高彦根神と大宜都比売の粟作圏

高根は「高根の元となった神」として **[[味耜高彦根命|味鉏高彦根神]]** と関連づけられ、また[[上一宮大粟神社]]を中心とする[[大宜都比売命（オオゲツヒメ）]]の粟作圏の一角に位置する。笑子岩の祭神比定（味鉏高彦根／事代主）も、この文脈に接続する。
