# 佐那河内：佐那縣と天岩戸神話の地

徳島県名東郡 **佐那河内村**（さなごうちそん）は、徳島県唯一の「村」として現存する地域で、阿波説における **天岩戸神話の本舞台** と比定される最重要の聖地。『古事記』が天手力男神の坐す場所として明記する **「佐那那縣（さなのあがた）」** こそが当地である、というのが阿波説の中核命題のひとつ。本ノートは、地名・神社・古伝・遺物・系図にわたる佐那河内の伝承を総合的に整理する。

## 概要

- **位置：** 徳島市の南、四国山地に抱かれた園瀬川（そのせがわ）上流域。標高1019mの **旭ヶ丸（大川原高原）** を擁する。
- **古地名：** 「**佐那縣（さなのあがた）**」、後に「**狭長村（さながむら）**」、天慶年間（938〜947）に「中邊村（なかへむら）」に改称、現在は「佐那河内村」。
- **地名の構造：** 「佐那」＋「河内（こうち）」。**河内** は四国に分布する地名群で、「川の内側」を意味する地形語。畿内河内国（カワチ）の特権を持つ語ではない。
- **比定の根拠：**
  - 『古事記』天孫降臨段「**手力男神は佐那那縣に坐す**」
  - 『先代旧事本紀』「天手刀雄神 此者座佐那縣也」
  - 『阿波志』「天石門別祠 **中邊村天嶺** にあり鎮守と称す」

## 🗻 大川原高原（王ケ原）と天空の祭祀

### 「王ケ原」の伝承

佐那河内村の山頂部、標高700〜1019mに広がる **大川原高原** は、かつて **「王ケ原（おうがわら）」** と呼ばれていたという地元伝承がある。

- 阿波説研究家の **大杉博氏**（『四国は死国にされていた：大和朝廷の大秘密政策』）は、「ここは、かつて『王ケ原』と呼ばれ、また『**高天原**』とも呼ばれていた」と述べる。
- 「1000m超えの高地で『大川原』というのは不自然」――地形と地名の不整合が、原語「王ケ原」を示唆する。
- 旭ヶ丸展望台からは、**吉野川下流域・鮎喰川・徳島平野・淡路島まで** を一望できる絶景で、古代の王権が国土を俯瞰する祭祀地として最適である。

### 「倭総鎮守 王ケ原神宮」の謎の石碑

旭ヶ丸頂上付近の展望台脇には、

> **倭総鎮守　王ケ原神宮**

と刻まれた **謎の石碑** が現存する。「佐那河内村史」にも由来の記載がなく、いつ誰が建てたかは不明。だが「**倭の総鎮守**」を称する点で、阿波説の象徴的物証として注目される（→ [[王ケ原神宮|王ケ原神宮]]）。

### 「天嶺（あまね）」と山頂遷座伝承

江戸時代の徳島藩編『阿波志』に：

> **天石門別祠　中邊村天嶺にあり鎮守と称す**

→ 中邊村は佐那河内村の旧称。「天嶺」とは大川原高原の山頂部を指すと考えられる。現在の府能（ふのう）にある天岩戸別神社は、**もともと山頂にあった社が遷されたもの** である可能性が高い。同じ佐那河内村の **嵯峨天一神社** は、社伝で「弘仁3年（812年）に恵穂嶽（えぼしだけ）山頂にあった社を現地へ遷した」と明記されており、山頂祭祀の遷座事例が確認される。

## ⛩ 天岩戸別神社（府能・牛木屋）

### 基本情報

| 項目 | 内容 |
|---|---|
| 鎮座地 | 徳島県名東郡佐那河内村上字牛木屋15 |
| 御祭神 | **天手刀雄神**（あめのたぢからお）／天照皇大神／豊受皇大神 |
| 通称 | 三社皇大神宮、三社様、三所様 |
| 字名 | 「牛木屋」（『徳島県神社誌』）／「府能牛小屋」（村HP） |
| 創立年代 | 不詳 |

### 字名「牛木屋」の語源

「牛木屋（うしきや）」は本来 **「大人（うし）木屋」**＝「大人（うし＝偉大なもの）の木屋（神を祀る木造小屋）」であったと推定される。後世に意味が失われ「牛」の字が当てられた。これは「**天降→雨降**」「天帯→雨降」のような **聖性の喪失型音転換** の典型例で、地名学的に重要な痕跡である。

### 江戸時代の崇敬

享保年間（1716〜35）に「不思議の霊験」があり、徳島藩主・蜂須賀探珠院が深く尊崇し、代参により金幣・幟・灯籠が奉納されている。

### 神社名「天岩戸別」の由来をめぐる二説

1. **天岩戸開きの故事説**：天手刀雄神が天照大神の手を引いた（『古事記』）／岩戸を引き開けた（『日本書紀』一書・『古語拾遺』）故事による
2. **天石門別神同体説**：天石門別神の名を冠した

『古事記』天孫降臨段は **天力男神と天石門別神を別神として扱う** が、長崎県壱岐市・天手長男神社の社伝は天手力雄神の別名として「天石戸別命、櫛盤窓命、伊佐布魂神、明口名戸命、阿居太都命、**天背男命**、天岩戸別安国玉命、天嗣鉾命」を列挙し、**両者同一神論** を支持する。

## ⛩ 御間都比古神社（みまつひこ）

### 基本情報

| 項目 | 内容 |
|---|---|
| 鎮座地 | 名東郡佐那河内村下 |
| 主祭神 | **観松彦色止命（みまつひこいろとのみこと）**＝長国造・韓背宿禰の9世祖 |
| 延喜式 | 名方郡「**御間津比古神社**」に比定 |
| 別称 | 三木松神（みつまつのかみ） |

### 祭神の三説

1. **観松彦色止命説（有力）**：『先代旧事本紀』国造本紀「長国　志賀高穴穂宮御世。**観松彦色止命** 九世孫 **韓背足尼** 定賜国造」。長国の祖神。
2. **第5代孝昭天皇（観松彦香殖稲命）説**：徳島藩士・赤堀良亮『阿府志』、長谷川貞彦『阿波式内神社考』、岩利大閑『道は阿波より始まる』。
3. **水神（水間津比古神）説**：志賀剛『式内社の研究』。『播磨国風土記』「弥麻都比古命が井を治めた」の引用に基づく。

### 観松彦色止命と海人族・出雲系譜

『古代豪族系図集覧』（近藤敏喬編）の系譜：

> 大国主命 ‐ 事代主命 ‐ 天八現津彦命 ‐ **観松彦色止命** ‐ …… ‐ 韓背宿禰

→ 観松彦色止命は **大国主命・事代主命の系譜** に連なる海人族の祖。**「ミマツ」は「ミ＋マツ（水辺）」** の意で、水運・海人族と関連する地名語と推定される。

『新撰姓氏録』には観松彦色止命系の氏族として：

- 和泉国 長公（大奈牟智神児 積羽八重事代主命之後也）
- 摂津国 我孫（大己貴命孫 天八現津彦命之後也）
- 大和国 長柄首（天乃八重事代主神後也）

→ **長国（南阿波）から始まり、和泉・摂津・大和に展開した「長氏」** の系譜が確認される。

### 阿波と隠岐の意外な接続

『先代旧事本紀』国造本紀には：

> **意岐国造　軽島豊明朝（応神） 観松彦色止命5世孫　十揆彦命**

→ 隠岐国造も観松彦色止命の後裔。さらに隠岐の延喜式内大社 **水若酢神社** の社人は忌部氏が務めた（『西郷町史下巻』）。鎌倉時代には、阿波守護を拝領した佐々木経高の兄・佐々木定綱が隠岐守護地頭となるなど、**阿波と隠岐の歴史的接続** が指摘される。

### 御神宝「御間都比古石」

戦国時代に長宗我部元親の侵攻で社殿は破壊された。御神宝の宝物リストには、

- **御間都比古石 二つ**（龍神石は海中より、水神石は勝浦川から得たと伝わる）
- 阿波の青石による男根石・石船
- 鉾一振・矢根

が記載される。これら宝物は **猿田彦神社社宝として七ヶ井開家** に保管されていた、と『佐那河内の古書』に記される。→ 御間都比古神社と猿田彦神社の宝物が混在した可能性。

→ 出典：kohun-jinjya（2024-06-26）御間津比古神社の祭神 （[出典](https://kohun-jinjya.blog/%e3%80%90%e9%98%bf%e6%b3%a2%e3%81%ae%e7%a5%9e%e7%a4%be%e3%82%92%e8%a1%8c%e3%81%8f%ef%bc%81%e3%80%91/)）

## ⛩ その他の佐那河内の神社

### 大宮神社（大宮正八幡大神宮）

『佐那河内古書』は次のように記す：

> 人皇42代文武天皇の御宇大寶3癸卯年御神説有に依て第一本宮備前国宇佐宮より43代元明天皇和銅元戊申年（708年）二月初卯日 **佐那縣に宮柱太數立 高間原** 二千高知りて斎祭る

→ 「**高間原**」（高天原）の地名が、佐那河内の古文書に明記される稀有な例。

### 朝宮神社

「上八万の朝宮祠より佐那河の朝宮へ遷し…」と『大宮神社古文書』に記される。佐那河内 → 上八万 → 佐那河内、というルートで遷座した可能性。徳島市八万町の宅宮神社とのつながりが示唆される。

### 猿田彦大神宮

『佐那河内古書』に「猿田彦大神は **岐の神、来名戸（クナト）の祖神**」「**是道教の神**」と記される。猿田彦＝韓背宿禰の祖の可能性も指摘されている（→ awa-otoko（2017-01-28）猿田彦神が韓背宿禰の祖説 （[出典](https://awa-otoko.hatenablog.com/entry/2017/01/28/205449)））。

### 嵯峨天一神社

弘仁3年（812年）に **恵穂嶽（えぼしだけ）山頂** にあった社を現在地に遷座（社伝）。佐那河内における **山頂祭祀 → 山麓遷座** の確実な事例。

## 🪶 佐那河内の祭神群と一神異名の交差点

佐那河内の神社群を貫く神格を整理すると、

| 神社 | 祭神 | 異名／別解 |
|---|---|---|
| 天岩戸別神社（府能） | 天手刀雄神／天照皇大神／豊受皇大神 | 天手力雄＝天石門別神＝天背男命（平田篤胤説）／豊受＝大宜都比売命 |
| 御間都比古神社 | 観松彦色止命 | 大国主・事代主の系譜 |
| 大宮神社 | 八幡大神 | 宇佐よりの勧請（708年） |
| 嵯峨天一神社 | 天照大神 | 山頂祭祀の名残 |
| 猿田彦大神宮 | 猿田彦大神 | 韓背宿禰祖説／岐の神／道教の神 |

→ **天手力男命・天照大神・豊受大神（＝大宜都比売命）・事代主神・猿田彦** という、**阿波説の中核神格が一村に集中** している点が極めて重要。

awa-otoko氏は次のように総括する：

> 佐那河内村は◯◯◯が推している手力男命伝説だけではなく、**猿田彦、天石門別豊玉比賣（壹與）、天照、素戔嗚** にも関わる重要な地域。

## 🧬 系図的中心としての佐那河内

『古屋家家譜』に、天石門別安国玉主命（＝天背男命）の妻は **八倉比売命** と記される。八倉比売を祀る延喜式内社 **天石門別八倉比賣神社**（徳島市国府町矢野）の摂社「**箭執神社**」の祭神は **櫛石窓神・豊石窓神**＝天石門別神の亦名。

→ つまり、

- **佐那河内（佐那縣）** ：天石門別＝天手力男命の本拠
- **国府町矢野** ：その后神・八倉比売命の本拠

という **夫婦神祭祀の地理的二極構造** が成立する。両社名に「天石門別」が冠せられるのも、この夫婦神論で説明がつく。

さらに『斎部宿祢本系帳』の系譜：

> 天背男命（＝天石門別命） × 八倉比売命 → 天日鷲翔矢命（阿波忌部祖）

を加えると、佐那河内は **阿波忌部の祖父・祖母神の祭祀地**＝阿波における祭祀王権の **発生地** という位置づけになる。

awa-otoko氏「大宜都比売命の父は天手力男命」は、ここからさらに踏み込み、

> 天石門別八倉比賣神社は、佐那河内村の天手力男命の娘である栲幡千千姫命こと、事代主神を夫に持つ阿波の国魂「大宜都比売命」を祭神とする

として、**佐那河内＝大宜都比売命の父祖の地**＝阿波の国魂神を生み出した源流地、とする最大級の主張を行う。

→ 出典：awa-otoko（2016-01-14）大宜都比売命の父は天手力男命 （[出典](https://awa-otoko.hatenablog.com/entry/2016/01/14/003629)）

## 🌐 「佐那縣」の比定論争――伊勢説との対立

三重県多気郡多気町仁田の **佐那神社**（祭神：天手力男命）を佐那縣に比定する説が一般的だが、阿波説の立場では次のように反論する：

1. 『古事記』の佐那縣の所在については、研究者間で「**いまだに不明**」という見解もある（伊勢比定への懐疑）。
2. **「佐那」という具体的固有地名** として現存するのは、徳島県の佐那河内村（旧・佐那縣）。
3. 伊勢国そのものが、**阿波忌部による開拓地**（『古語拾遺』「天日鷲命の孫を率て肥饒の地を求めて遣しむ。阿波国に殖えしむ穀・麻の種、その裔は今、彼の国に在り」）。伊勢佐那神社は阿波からの分祀／東遷の産物と解釈可能。
4. **邇藝速日命が天降った「河内之国」** も、畿内河内国ではなく **四国の河内（こうち）地名群** に属する（佐那河内・徳島の河内・高知の語源も同根）。
