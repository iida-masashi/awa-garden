# 太政官道と阿波の交通網：官道が示す古代の物流と権力

← ポータルへ戻る

> [!summary] 要旨
> 律令制下の **太政官道（官道・駅路）** は、中央朝廷の権力を地方へ及ぼす **古代の幹線道路網**。阿波説では、**南海道** に組み込まれた阿波の官道が、単なる地方道ではなく **古代国家の物流・祭祀ネットワークの中枢** であったとする。後の **遍路道（八十八ヶ所巡礼路）** との重なり、阿波忌部の麁服貢進路としての役割を含め、官道が示す阿波の歴史的重要性を整理する。

## 2. 太政官道（官道・駅路）の制度

### 2-1. 律令制下の七道

律令制下、日本は **五畿七道** に区分され、各道に **幹線官道** が整備された。

| 道 | 主要国 | 阿波の位置 |
|---|---|---|
| 東海道 | 関東〜畿内東部 | 対象外 |
| 東山道 | 中部〜東北 | 対象外 |
| 北陸道 | 越前〜越後 | 対象外 |
| 山陰道 | 丹波〜出雲 | 対象外 |
| 山陽道 | 播磨〜安芸 | 対象外 |
| **南海道** | 紀伊・**淡路・阿波・讃岐・伊予・土佐** | **阿波が中継・要衝** |
| 西海道 | 九州 | 対象外 |

阿波は **南海道** に組み込まれ、紀伊水道経由で畿内と接続する **海陸両用の要衝** であった。

### 2-2. 官道の役割

| 役割 | 内容 |
|---|---|
| 物流 | 中央への貢納物の運搬 |
| 通信 | 駅家（うまや）を介した情報伝達 |
| 軍事 | 防人・国司の派遣ルート |
| 祭祀 | 大嘗祭貢納物の運搬路 |

## 3. 阿波の官道と物流

### 3-1. 阿波からの貢進物

阿波の官道を通じて、以下の貢納物が中央に運ばれた。

| 産物 | 用途 |
|---|---|
| 麁服（麻織物） | 大嘗祭の天皇神服 |
| 楮（紙の原料） | 朝廷の文書・典籍 |
| 朱（水銀朱） | 神事・建築・医薬 |
| 海産物 | 阿波・海部の漁業 |
| 木材 | 山地の伐採・建築用 |

### 3-2. 太政官道の阿波ルート

阿波の官道は、**畿内→紀伊水道→鳴門→阿波平野→讃岐境** を経るルートを基本とし、**祭祀拠点（式内社）と古代集落** を結ぶ。

## 4. 官道と遍路道の重なり

### 4-1. 四国八十八ヶ所巡礼路の起源

**四国八十八ヶ所** の遍路道は、中世以降に発達した宗教巡礼路だが、阿波説では **古代官道との大幅な重なり** が指摘される。

- 阿波の札所（霊山寺〜大窪寺）は、**律令期の官道沿い** に分布
- 遍路宿・古道の多くが古代駅家跡と重なる可能性
- 宗教的巡礼が **古代の交通網を継承** している

→ 遍路道（[出典](https://xn--mnqu5jib741oy19b.xyz/category4/entry16.html)）、お遍路さんの真相（[出典](https://xn--mnqu5jib741oy19b.xyz/category4/entry84.html)）

### 4-2. 遍路の起源論

通説では、遍路は **空海（弘法大師）の修行ルート** を起源とするが、阿波説では：

- 古代の **官道＝祭祀路** が原型
- 空海以前から阿波の山岳信仰（剣山・高越山）と一体の巡礼が存在
- 中世に空海信仰が結びつき「遍路」として定着

という多層構造を見る。

→ [[木綿麻山（高越山）：忌部の聖域と修験の源流]]、[[剣山での宝剣奉斎]]

## 5. 阿波説における意義

「太政官道と阿波の交通網」は、阿波説の **以下の論点を支える**：

1. **古代の物流中枢としての阿波**：単なる地方ではなく、**中央へ重要物資を運ぶ起点** としての阿波。
2. **官道と祭祀の一体性**：官道が **祭祀路** として機能したことが、阿波の祭祀地理と整合する。
3. **遍路の起源論**：宗教巡礼が古代官道を継承するモデル。
4. **大嘗祭麁服貢進の物流的裏付け**：麁服を中央へ運ぶ実体的ルートとしての官道。

## 8. 留保

> [!warning] 注意
> - **南海道の阿波ルートの厳密な路線比定** は、考古学的・文献的検討が継続中であり、本ノートは概観的整理に留まる。
> - 「**遍路道＝古代官道の継承**」とする主張は **魅力的な仮説** だが、両者の重なりは **部分的** であり、全面的な継承を断ずるには検証が必要。
> - **空海の修行ルートとの関係** を否定する論ではなく、**古代官道がベースにあった可能性** を示唆する立場である。
> - 古代官道の現地遺構（駅家跡・道路遺構）の発見は限定的であり、地質的・地名的痕跡からの推定が中心となる。
