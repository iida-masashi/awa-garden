# 東国古代史と香取海の神々

> [!summary] 要旨
> 古代「**香取海（かとりのうみ）**」は、現在の利根川下流域・霞ヶ浦・北浦・印旛沼を一体として広がっていた **巨大な内海** で、関東平野の東部祭祀・交易の中心であった。その沿岸に並ぶ **鹿島神宮（常陸）・香取神宮（下総）・息栖神社（常陸）= 東国三社** は、ヤマト王権の東国経営の最前線として位置付けられる。阿波説では、この香取海ネットワークの祭祀的基層を、**阿波忌部・阿波海人族の東遷** によって築かれた **「西国（阿波）の祭祀構造の東国版」** として読み解く。本ノートは東国古代史と阿波説をつなぐハブとして機能する。

---

## 1. 命題の構造

| 観点 | 通説 | 阿波説 |
|---|---|---|
| 鹿島・香取の起源 | ヤマト王権による東国経営、藤原氏氏神化 | 阿波忌部の東遷・阿波海人族の航海ネットワークが祭祀基層 |
| 武甕槌・経津主 | 国譲り神話で活躍した武神。中臣・物部氏の氏神 | 阿波の鉄・剣祭祀（[[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配|阿波物部]]）の東国分派 |
| 香取海の交通圏 | 関東東部の内海交易圏 | 黒潮ルートで阿波（紀伊水道）と直結する、**東国版・瀬戸内海** |
| 東国三社の関係 | 並立する独立祭祀 | 阿波の **三社祭祀パターン**（神山三峰・忌部三社等）の関東版 |

## 2. 香取海の地理

### 2-1. 古代の香取海

| 項目 | 内容 |
|---|---|
| 範囲 | 利根川下流〜霞ヶ浦・北浦・印旛沼を一体とする内海 |
| 現在の状態 | 江戸期の利根川東遷で分断され、湖沼群として残存 |
| 古代名 | 「**香取海**」「流海（ながれうみ）」「海上潟（うなかみがた）」 |
| 沿岸国 | 常陸国・下総国・上総国の境界をなす |

### 2-2. 「菟上（うなかみ）」の地名

- 古代の **菟上国（うなかみのくに）** は香取海一帯を含む
- 後の下総国・常陸国に分割される以前の **原・東国** の単位
- 「うなかみ」＝「海上」「菟上」の表記揺れあり

## 4. 阿波説における意義

### 4-1. 阿波忌部の東遷と香取海

[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] は、**阿波忌部の天富命が安房（房総南端）を開拓** した後、その勢力が **上総・下総・常陸へと北上**したとする。

香取海沿岸の祭祀地名（**フサ**＝総、**忌部**地名、**鷲**地名群）は、この東遷ルートの物的痕跡。

- 詳細：[[阿波忌部の東国痕跡：千葉・上総・安房の祭祀地名]]
- 詳細：[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]

### 4-2. 阿波物部・経津主祭祀の東国版

経津主神（[[経津主神]]）は **物部氏祖神** とされ、香取神宮の主祭神。阿波説では：

- 阿波物部氏（[[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配]]）の祖系
- 阿波の **鉄・剣祭祀** が東国に移植された結果が香取神宮
- 「**フツ**」＝刀剣の刃の音（フツヌシ＝刃の主）と、阿波の鉄器・鍛冶文化の対応

### 4-3. 武甕槌・国譲り神話の阿波本舞台論

[[阿波における出雲勢力：大国主・事代主祭祀の原層と国譲りの舞台|国譲り神話の阿波本舞台論]] によれば、国譲りの舞台は阿波（徳島）。すると：

- **武甕槌が降臨した稲佐の浜** ＝ 阿波の海岸
- **経津主・武甕槌の伝承の原本舞台** ＝ 阿波
- 香取・鹿島はその **東国遷座先** という構造

### 4-4. 鹿島の「フツノミタマ」と石上神宮・阿波

- 鹿島神宮の御神体は **韴霊剣（フツノミタマノツルギ）**
- 石上神宮（大和）にも同名の神剣
- 阿波の **天村雲命**（[[阿波物部氏：天村雲命を祖とする武人集団と鉄の支配]]）が両社の祭祀祖系として連続

### 4-5. 阿波海人族と香取海の水運

[[阿波海人族：海洋王権を支えた安曇・海部・那賀のネットワーク|阿波海人族]] の黒潮ルートは：

- 阿波（紀伊水道）→ 黒潮 → 房総（安房・上総）→ 香取海
- **息栖神社の天鳥船命** ＝ 阿波海人族の航海技術神
- 「**菟上国**」＝ 海上交通の **「上（かみ）の方の海道」** ＝阿波から見た東国側の海路終着点

```
【阿波】(西国の祭祀・産業中心)
   ┃
   ┃ 黒潮ルート + 内陸ルート
   ┃
   ▼
【安房】(阿波忌部の上陸地)
   ┃
   ┃ 房総半島を北上
   ┃
   ▼
【上総・下総】(忌部勢力の拡大)
   ┃
   ┃ 香取海沿岸へ展開
   ┃
   ▼
【香取海ベルト】(東国三社の祭祀ネットワーク完成)
   ┣━ 鹿島神宮（武甕槌＝阿波物部・武神）
   ┣━ 香取神宮（経津主＝阿波物部・剣神）
   ┗━ 息栖神社（天鳥船＝阿波海人・航海神）
```

## 7. 留保

> [!warning] 注意
> - 「東国三社の祭祀基層＝阿波忌部・物部」は阿波説の解釈で、通説は中臣氏・物部氏の中央氏族による東国経営とする
> - 阿波忌部の東遷の物的痕跡（地神塔・地名・神社）は江戸期・近代まで重層化しており、古代の連続性の証明は別途必要
> - 香取海＝菟上国の構造は古代地理学の議論の余地あり
> - 経津主＝阿波物部祖神 説は、中央物部の祖（饒速日命）系との関係を含めて再検証が必要
