# 📚 引用文献ハブ

阿波説 Vault で参照される主要資料を一覧化し、各資料に `ref-id` を付与する。今後の論文・記事執筆時の引用基盤とする。

## 凡例
- **ref-id**: 短い識別子（`ref-{著者or略称}-{年}` 形式）
- **資料種別**: 一次史料 / 二次資料 / Web資料 / 個人研究 / 古文書 / 考古学報告
- **入手元**: 国立国会図書館・地方資料館・Web・私的所蔵 など

各個別史料の詳細抜粋は [[00_一次史料インデックス_ポータル]] および [[00_考古学ファクトシート_ポータル]] を参照。

## 個別ノートでの cite 使用ガイド

各ノートの frontmatter に `cite:` フィールドを追加することで、引用元を明示できる：

```yaml
---
cite: [ref-engishiki-927, ref-genbu-net, ref-tsubouchi-2024]
---
```

単一引用：
```yaml
---
cite: ref-tsubouchi-2024
---
```

本文での記載例：
```markdown
延喜式神名帳には「阿波国 美馬郡 倭大国玉神大国敷神社」と記載される（`ref-engishiki-927`）。
```

**推奨ルール**:
1. 一次史料からの直接引用は `cite:` に必ず含める
2. Web資料は本文に [URL](URL) 形式で個別貼付＋ハブ参照
3. 信頼度（confidence）と cite を併記：`confidence: 3` + `cite: [ref-tsubouchi-2024]`
4. 一括追加は行わない方針（個別ノートの編集ごとに必要に応じて）
