# 阿波説タイムライン

阿波説における時代区分と、各時代に対応する **主要事象・関連神社・関連氏族・伝承・考古学的物証** の統合年表。

> 本ノートは「時代軸」を主キーに据えた MOC（Map of Content）。各時代欄から関連ノートへ横展開する。郡軸での閲覧は [[氏族×祭祀×地理_統合MOC]]、神社軸は [[00_式内社_目次]] を参照。

---

## 🕐 時代区分（概観）

| 時代 | 推定年代 | 阿波説における核心テーマ |
|---|---|---|
| **神代前期** | 縄文〜弥生中期 | 大宜都比売命 の阿波鎮座、結晶片岩・東阿波型土器の文化圏 |
| **神代後期** | 弥生後期〜古墳発生期 | [[天照大神（大日孁尊）]] の阿波生誕説、天岩戸神話の阿波比定 |
| **神武東征期** | 古墳前期 | 神武天皇の阿波経由東征、稲飯命の阿波留泊 |
| **崇神朝** | 古墳前期 | 倭大国魂祭祀の物理的分離、伊加賀志許賣命の系譜 |
| **景行朝** | 古墳中期 | 日本武尊の四国遠征伝承、白鳥伝承 |
| **神功皇后** | 古墳中期 | 三韓征伐への阿波忌部の関与、忌部氏祭祀権の確立 |
| **古墳時代** | 4-7世紀 | 阿波の前方後円墳築造、杉尾古墳（卑弥呼陵説） |
| **大化改新〜律令** | 7-9世紀 | 阿波国造の中央祭祀統合、忌部氏の麻織祭祀権 |
| **平安** | 10世紀 | 延喜式神名帳成立、阿波 50 座が公認 |

---

## 📅 各時代の詳細

### 1. 神代前期（縄文〜弥生中期）

**主要事象**
- 大宜都比売命の阿波鎮座（国魂神の発生）
- 結晶片岩文化圏の形成（吉野川中流〜紀の川流域）
- 東阿波型土器の流通（瀬戸内・近畿への拡散）
- 麻・穀物の原産地としての阿波
- 高天原の物理的実在地としての神山町・大川原高原

**関連論考**
- [[高天原阿波説：神山町の巨大湖と天津の民]]

**関連神社**
- [[上一宮大粟神社]] — 大宜都比売命の中心祭祀
- [[上一宮大粟神社：阿波国魂・大宜都比売命の中心祭祀]]
- [[天石門別八倉比売神社]]（前身祭祀）

**関連氏族**
- 粟氏（粟国造）/ 大粟氏

**関連伝承・古典記載**
- 『古事記』神産み段「粟国を大宜都比売と謂ふ」
- 五穀起源神話（大宜都比売の身体化生）

**考古学的物証**
- 結晶片岩石棒（神山町・吉野川流域）
- 東阿波型土器の広域分布

### 3. 神武東征期（古墳前期）

**主要事象**
- 神武天皇の阿波経由東征
- 稲飯命の阿波留泊と海中入水伝承
- 事代主神の阿波軍師的役割

**関連神社**
- [[稲飯神社]] — 神武天皇の兄・稲飯命
- [[勝占神社]] — 事代主神の阿波拠点
- [[生夷神社]] — 事代主（エビス神）生誕地

**関連氏族**
- 海部氏（東征の海路担当）/ 阿波君（鷲住王系）

**関連伝承・古典記載**
- 『日本書紀』神武紀 稲飯命入水段
- 阿波留泊伝承（地方伝承）
- [[事代主神と神武東征：阿波郡における軍師的役割]]

- 御間都比古命（孝昭天皇）の阿波拠点

**関連神社**

- [[倭大國玉神大國敷神社：全国唯一「倭」を冠する式内社]]
- [[伊加加志神社]] — 崇神天皇の母の足跡
- [[御間都比古神社]] — 孝昭天皇の阿波拠点

**関連氏族**
- 阿波忌部 / 物部氏（祭祀統合期）

**関連伝承・古典記載**
- 『日本書紀』崇神紀 倭大国魂神の遷座
- 『古事記』崇神段 系譜記載

### 5. 景行朝（古墳中期）

### 7. 古墳時代（4-7世紀）

**主要事象**
- 阿波の前方後円墳築造（鳴門・徳島平野）
- 杉尾古墳（八倉比売神社 奥院）の築造
- 大里古墳（南阿波 鷲住王陵説）
- 長国造による那賀郡支配確立
- 後漢書東夷伝の倭国大乱（146-189）と田村遺跡衰退の同期

**関連神社・遺跡**
- [[天石門別八倉比売神社]] 奥院 杉尾古墳

**関連氏族**
- 阿閉氏 / 長氏（長国造）/ 阿波君（鷲住王系）/ 海部氏

**関連伝承・古典記載**

- 『後漢書』東夷伝（倭奴国・帥升・倭国大乱）
- 地方氏族伝承（鷲住王・阿波君）

**考古学的物証**

- 大里古墳群（南阿波）
- 萩原墳墓群（鳴門）
- 気延山・眉山赤色立体地図に基づく古墳群分布

**関連論考**

### 9. 平安期（10世紀〜）

**主要事象**
- 延喜式神名帳成立（927年）— 阿波 50 座が公認
- 阿波国一宮 大麻比古神社の確立
- 多祁御奈刀弥神社からの諏訪勧請（宝亀10年=779年の社伝）

**関連氏族**
- 阿波忌部（律令祭祀の継承）/ 賀茂氏

## 🌟 時代別 式内社（dataview による動的集計）

### 時代（epoch）別の式内社
```dataview
TABLE epoch, deities AS 主祭神, 旧郡
FROM "式内社/01_阿波国"
WHERE epoch
SORT epoch ASC
```

### 時代（epoch）ごとの件数
```dataview
TABLE length(rows) AS 件数
FROM "式内社/01_阿波国"
WHERE epoch
GROUP BY epoch
SORT epoch ASC
```

### 氏族（clans）ごとの式内社
```dataview
TABLE clans, deities AS 主祭神
FROM "式内社/01_阿波国"
WHERE clans AND length(clans) > 0
SORT 旧郡 ASC
```
