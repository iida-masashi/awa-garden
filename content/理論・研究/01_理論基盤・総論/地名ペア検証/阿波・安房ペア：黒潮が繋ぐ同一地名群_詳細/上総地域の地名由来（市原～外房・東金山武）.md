# 上総地域の地名由来（市原～外房・東金山武）

旧 **上総国（11郡）** に属する市町の地名由来資料群。安房から内陸・東岸へと阿波系地名がスライド展開する **二次拡散域** であり、阿波勝浦郡＝房総勝浦市の同名一致をはじめ、麻植・須恵器・海人・長氏などの痕跡が郡名・市名に濃く残る。

## 阿波説における位置づけ

- **勝浦市** = 阿波 勝浦郡と完全同名。地名スライドの最も明瞭な実証例。
- **市原郡（いちはら）** = 阿波 名西郡市原に対応。
- **武射郡（むさ）** = 阿波 麻植郡（おえ／麻＝むさ）に対応。**「総（フサ）＝麻」の語源**に直結。
- **周淮郡（すえ）** = 阿波 麻植郡 須恵器産地に対応。職業部（陶部）の移転。
- **天羽郡（あまは）** = 阿波 海部郡（あま＝海人）に対応。
- **望陀郡（もうだ）** = 阿波 名東郡望田に対応。
- **長柄郡（ながら）** = 阿波 長国／長氏に対応。

→ 詳細は [[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] 参照。
