# 上総地域の地名由来（市原～外房・東金山武）

> [!summary] 要旨
> 旧上総国（11郡）に属する市町の地名由来資料群。安房から内陸・東岸へと阿波系地名がスライド展開する二次拡散域として、阿波勝浦郡＝房総勝浦市の同名一致をはじめ、麻植・須恵器・海人・長氏などの痕跡が郡名・市名に残るとみる。市原郡＝阿波名西郡市原、武射郡（むさ）＝阿波麻植郡（麻＝むさ）で「総（フサ）＝麻」の語源に直結、周淮郡（すえ）＝須恵器産地、天羽郡（あまは）＝海部郡、望陀郡＝名東郡望田、長柄郡＝長国／長氏、と対応づける。地名の対応はいずれもブログ資料（fusa）に依拠する阿波説的解釈である。

旧 **上総国（11郡）** に属する市町の地名由来資料群。安房から内陸・東岸へと阿波系地名がスライド展開する **二次拡散域** であり、阿波勝浦郡＝房総勝浦市の同名一致をはじめ、麻植・須恵器・海人・長氏などの痕跡が郡名・市名に濃く残る。

## 1. 阿波説における位置づけ

- **勝浦市** = 阿波 勝浦郡と完全同名。地名スライドの最も明瞭な実証例。
- **市原郡（いちはら）** = 阿波 名西郡市原に対応。
- **武射郡（むさ）** = 阿波 麻植郡（おえ／麻＝むさ）に対応。**「総（フサ）＝麻」の語源**に直結。
- **周淮郡（すえ）** = 阿波 麻植郡 須恵器産地に対応。職業部（陶部）の移転。
- **天羽郡（あまは）** = 阿波 海部郡（あま＝海人）に対応。
- **望陀郡（もうだ）** = 阿波 名東郡望田に対応。
- **長柄郡（ながら）** = 阿波 長国／長氏に対応。

→ 詳細は [[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] 参照。

## 4. 留保

> [!warning] 注意
> - 本ノートの地名対応（勝浦・市原・武射・周淮・天羽・望陀・長柄など）は、いずれも「未知の駅 總フサ」（fusa）ブログ資料に依拠する阿波説的解釈であり、`evidence_type: blog_hypothesis`、`confidence: 2`。
> - 通説では、上総・安房の地名は当地の地形・在地語・開発過程に由来するものと理解され、阿波の同名・類似地名との一致は偶然や独立した命名による可能性が一般的に指摘される。地名の音・字面の類似だけでは移転・東遷を実証できない。
> - 「総（フサ）＝麻」「あま＝海人」などの語源解釈、職業部（陶部）の移転、阿比留族＝隼人系といった比定は、阿波説固有の読み替えであり、文献・考古による直接の裏付けがあるわけではない。
> - 「安房から上総への二次拡散」という枠組み自体が阿波忌部東遷論を前提とした解釈であり、本ノートはその拡散域の地名資料を集成したものである。
