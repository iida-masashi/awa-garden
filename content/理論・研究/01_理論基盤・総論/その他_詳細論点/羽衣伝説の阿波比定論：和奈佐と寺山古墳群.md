# 羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

『丹後国風土記』逸文「奈具の社」に記される **羽衣伝説の天女＝豊宇賀能賣命（とようかのめのみこと）** ――その出発地（出港地）が **徳島県海部郡海陽町鞆浦字那佐（旧 和奈佐）** であり、近傍の **寺山古墳群（3世紀初頭）・芝遺跡** がその物的痕跡を残す、という阿波説の核心比定論を整理する。本ノートは koraku ブログ「羽衣伝説 Vol.阿波 ①〜③、神宝・遺物から考察」の論点を統合する。

| 神話の要素 | 阿波説の比定 |
|---|---|
| **羽衣伝説の天女** | **豊宇賀能賣命**（豊受大神の原型） |
| **和奈佐老父・和奈佐老女** | 海陽町鞆浦字那佐（旧 **和奈佐**） |

| **天女の出発地（出港地）** | **海陽町鞆浦字那佐** |

| **関連遺跡** | **芝遺跡**（広域交易の物証） |

## 📜 丹後国風土記「奈具の社」の概要

> 丹後の国丹波郡郡家の西北に **比治の里** がある。
> 比治山の頂きに井があり、その名を **間奈井（まなゐ）** という。
> 今はすでに沼になっている。
> この井に **天女が八人** 降って来て、水浴をしていた。
> その時、老夫婦がいた。その名を **和奈佐老父（わなさおきな）、和奈佐老女（わなさおみな）** といったが、
> この老人たちは天女の一人の衣装を取って隠した。
> （中略）
> 『これは、いわゆる竹野の郡の **奈具の社** においでになる **豐宇賀能賣命（とようかのめのみこと）** なり。』

→ 「和奈佐」を冠する老夫婦の名は、阿波の地名「**和奈佐**（わなさ）」に直接対応。

## 🏝 和奈佐＝海陽町鞆浦字那佐

| 項目 | 内容 |
|---|---|
| 現在地名 | 徳島県海部郡海陽町鞆浦字那佐 |
| 旧地名 | **和奈佐**（わなさ） |
| 位置関係 | 那佐湾の入口 |
| 関連神社 | **和奈佐意富曽神社**（阿波・式内社、那賀郡） |

### 和奈佐意富曽神社（式内社）
- 延喜式神名帳：阿波国 那賀郡 **和奈佐意富曽神社（わなさおほそ神社）**
- 比定社：海部郡海陽町大里松原32-133（式内社データベース〔[shikinaisya.net](https://shikinaisya.net/?p=213)〕より）
- 別の論社：羽浦神社、蛭子神社
- → **「和奈佐」を冠する式内社が阿波に現存** することは、丹後国風土記の「和奈佐老父・老女」との直接接続を強く示唆

## 🪦 寺山古墳群――3世紀初頭の墳丘墓

### 立地と意義

| 項目 | 内容 |
|---|---|
| 場所 | 徳島県海陽町野江 |
| 時代 | **3世紀初頭**（古墳時代極初期） |
| 性格 | 墳丘墓（前方後円墳の原型ではない初期段階） |
| 阿波説解釈 | **羽衣伝説の天女（豊受大神）の墓** ／ **イザナミの神陵候補** |

### 寺山3号墳から出土した内行花文鏡

> **寺山3号墳から内行花文鏡が出土**

- 「**内行花文鏡（ないこうかもんきょう）**」は古代中国の青銅鏡形式
- 同型の鏡が **萩原墳丘墓**（徳島県鳴門市大麻町萩原・現存最古の前方後円墳の原型）からも出土

→ **少なくとも徳島県の海岸沿いにあった「長國」には、大陸側（当時の中国）と交易ができるほどの航海術があった** ことが考古学的に証明される。

### 籠神社の海部氏伝世鏡との同型性

元伊勢 **籠神社**（京都府宮津市）には海部氏が82代2000年にわたり伝世した二鏡：
- **息津鏡**（おきつかがみ）：後漢時代の鏡、約1950年前
- **邊津鏡**（へつかがみ）：前漢時代の鏡、約2050年前
- 学名：**内行花文長宜子孫八葉鏡** ／ **内行花文昭明鏡**

→ **寺山3号墳・萩原墳丘墓・籠神社海部氏鏡** がすべて **内行花文鏡系統** という重要な事実。
→ 阿波（海陽町）⇔ 丹後（籠神社）の **海部氏ネットワーク** の物的証拠。

## 🏛 芝遺跡――広域交易の中心地

寺山古墳群から **北東200m** の位置にある **芝遺跡**：

| 項目 | 内容 |
|---|---|
| 時代 | 古墳時代初期（約1800年前＝3世紀） |
| 担当 | 林田真典氏ほか発掘 |
| 出土土器 | **多地域からの土器が集中** |

### 出土土器の地域構成

| 地域 | 土器 |
|---|---|
| 徳島 | **東阿波型土器** |
| 香川 | 下川津B型土器 |
| 高知 | ヒビノキ式土器 |
| 岡山 | （特定型） |
| 関西 | **布留式土器** |

→ 特に **「布留式土器」（関西地域）** の出土点数の多さは、徳島県内で類例なし。

### 阿波説の意義

> 芝遺跡では、頻繁な交流が行われた結果として、多くの土器が出土した。

→ 海陽町・和奈佐は **古代瀬戸内・近畿との海上交易の中継基地** ＝羽衣伝説の天女が「天に帰った」のは **船で出港して別地へ向かった** ことの暗喩。

## 🌐 羽衣伝説と阿波説の総合物語論

```
【阿波・海陽町・和奈佐】（出発地）
   ┃
   ┃ 海陽町鞆浦字那佐 ＝ 和奈佐老父・老女の地
   ┃ 寺山古墳群 ＝ 天女（豊受大神）の墓
   ┃ 芝遺跡 ＝ 多地域交易の中心地
   ┃ 内行花文鏡 ＝ 大陸交易の物証
   ┃
   ▼ 海路で展開
【丹後】（伝承の継承地）
   ┗ 比治の里・奈具の社・比沼麻奈為神社
   ┗ 籠神社（海部氏伝世鏡）

【伊勢】（最終遷座地）
   ┗ 伊勢神宮外宮（豊受大神）
```

→ つまり、**伊勢神宮外宮の豊受大神** の本源は：
- **阿波・海陽町・和奈佐**（物的拠点）
- → 丹後（伝承継承）
- → 伊勢（最終遷座）

という三段階の遷座ルート。

## 🔗 既存ノートとの接続

### 既存元宮ハブ_MOC との接続

[[元宮ハブ_MOC]] における伊勢神宮外宮の元宮論：
- 従来：[[岡上神社]]（板野郡・豊受姫命）が外宮の元宮候補
- 本論：**和奈佐＋寺山古墳群** が **更に古層の元宮候補**

→ 両者は矛盾せず、**「外宮の最古層は和奈佐 → 板野郡岡上へ移動 → 後に丹後経由で伊勢」** という多段階遷座論として整合可能。

### 黄泉比良坂・淤能碁呂島との接続

|---|---|

## 🌟 阿波説における5つの意義

### 1. 伊勢神宮外宮の本源論
豊受大神の本源は **阿波・和奈佐**。丹後・伊勢は **遷座先**。

### 2. 海部氏ネットワークの物的証拠
内行花文鏡の **阿波（寺山）⇔丹後（籠神社）** の同型性は、海部氏の海洋祭祀ネットワークの直接物証。

### 3. 阿波の大陸交易ルートの確立
寺山・萩原両墳丘墓の **内行花文鏡** は、3世紀初頭に阿波が **大陸（漢）との直接交易圏** にあったことを示す。

### 4. 邪馬台国阿波説との整合性
芝遺跡の **布留式土器（関西）** との交流は、邪馬台国（阿波）の **広域経済圏** を物的に裏付ける。

### 5. 「神話と地名の完全対応」
丹後国風土記の **「和奈佐」** が阿波の **「和奈佐」** とそのまま地名対応する稀有な事例。
