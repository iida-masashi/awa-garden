# 高天原阿波説：神山町の巨大湖と天つの民

阿波説における **高天原（たかまがはら）の比定地論** の決定版。本ノートは、奈良県御所市・宮崎県高千穂・福岡県朝倉市などの諸説を退け、**徳島県神山町を中心とした山岳地帯こそが古代の高天原** であった可能性を、神話・語源・考古学・地名証拠の四面から論証する。

> 📚 親ハブ: [[元宮ハブ_MOC]]

## 🎯 核心命題

**「天つ神＝山岳地帯の港（船つ場）を治めていた神々」** ＝ 神山町を中心とした標高1000m級の山岳地帯に居住した古代の支配者集団。

## 🗺 高天原の地理的範囲（阿波説）

| 方位 | 範囲 |
|---|---|
| 中心 | **神山町**（標高1000m級） |
| 西 | 平 |
| 東 | 佐古（佐那河内村） |
| 北 | 吉野川南の山々 |
| 南 | 勝浦川 |

→ **広大な山岳地帯**であり、「高天原」は単一の山名ではなく **地域名**として理解すべき。

## 🌊 神山の巨大湖伝承

**重要物証**：標高1000m近い神山にかつて、

| 項目 | 値 |
|---|---|
| 形状 | 南北 **6km**、東西 **500m** |
| 面積 | **300ヘクタール（東京ドーム約60個分）** |
| 用途 | 古代の船の往来路 |

→ 神山フォーラムの郷土史調査資料による。湖はすでに失われたが、**地名に痕跡が残る**：
- **室**（むろ）
- **高浜**（たかはま）
- **滝**（たき）
- など水由来の地名

これだけの広大な淡水源があれば、**飲料水・農業用水・船の交通**すべてが万人単位で賄える。
**山深い場所にもかかわらず古代に大規模集落が形成可能**であったことの証拠。

## 🚢 「天つ」「国つ」の語源解釈

阿波説では：

| 用語 | 阿波説の解釈 |
|---|---|
| **天つ神** | 山岳地帯の **港（船つ場）** を治めた神々（天＝高い場所、つ＝津＝港） |
| **国つ神** | 地上の **港** を治めた神々（国＝大地、つ＝港） |
| 「川津」 | 川の船つ場（実例） |

→ つまり「天つ＝空の港の神」＝ **山岳の湖港を支配した王権**。神山の巨大湖は、まさにこの「天の港」だった可能性。

## 📜 神山周辺の天岩戸関連神社

天照大神の天岩戸隠れに由来する神社が神山町周辺に集中：

| 神社名 | 関連 |
|---|---|
| **天の岩戸神社** | 天照大神隠れの本舞台 |
| **天の岩戸別神社** | 同上 |
| **天野岩戸別神社** | 同上 |

### 田力雄神＝佐名居住伝
**『先代旧事本紀』** には、天の岩戸を開いた **田力雄神（天手力男神）** が「**佐名（さな）**」に住んでいたと記される。

→ 神山町の **隣町は「佐那河内村」**――そのままの地名対応！

### 佐古地（さこじ）の地名由来
- 『日本書紀』：天照大神が高天原で造った田「**天野狭田**」
- 「**佐古**」は **「狭田（さだ）」** から派生
- 佐古には **日本最古の棚田「佐古舞」** があり、古くは天皇への献上前の地

## 🏔 大ヶ原（おおがはら）伝承

神山町と佐那河内村の中間地点、**標高1000mの山頂部に「大ヶ原」と呼ばれていた広大な高原**が存在する。

| 項目 | 内容 |
|---|---|
| 標高 | 約1000m |
| 眺望 | 徳島平野・吉野川・紀伊水道・阿讃山脈・**淡路島まで一望** |
| 石碑 | **天の岩戸別神社の石柱**、**大和総樹**、**大原神宮の石碑** |
| 性格 | 「天空の都」、王の居処の可能性 |

→ 「**ひょっとすれば高ヶ原を治めた王の居処がここにあったのかもしれない**」（ANYA考）

| 遺跡・発見 | 場所 | 時代 | 内容 |
|---|---|---|---|
| **人量大字遺跡** | 神山町 | 弥生時代 | 石斧出土 |

→ 石斧と銅剣の発見場所は、**かつての湖を取り囲むように分布**。湖を中心に古代集落が定住していたことを物的に示す。

## 🌌 高天原と阿波の語彙対応

| 神話の語 | 阿波の地理 |
|---|---|
| 高天原 | 神山町周辺・標高1000m級山岳地帯 |
| 天つ神の故郷 | 神山町（巨大湖地帯） |
| 天野狭田（あめのさだ） | **佐古地**（さこじ）の棚田 |
| 天の岩戸 | 神山町周辺の天岩戸関連神社 |
| 田力雄神の住所「佐名」 | **佐那河内村** |
| 国生み神話「淡路島→四国→九州→…奈良は8番目」 | 阿波（四国）が西、淡路島の東 |

→ **「西の淡路島→東の四国→九州→…→最後に奈良」** という国生みの順序は、奈良に高天原があった説と矛盾する。**阿波説のほうが地理的に整合**。

### 「筑紫」の解釈
- 『古事記』天孫降臨：「**筑紫の日向の高千穂**」
- 一般解釈：筑紫＝九州
- 阿波説の指摘：『古事記』で九州を指す時は **「築紫（つくし）」** と書く。「**筑紫（つくし）**」は別字で、**九州を意味しない**。
