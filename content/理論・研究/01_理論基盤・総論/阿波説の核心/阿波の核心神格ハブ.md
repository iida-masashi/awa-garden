## 🧬 阿波説の祭神系譜（核心構造）

阿波説の神々の系譜は、**佐那河内（天石門別神）を起点** に、阿波忌部と粟国造の二系統が分岐し、出雲系（大国主一族）と婚姻ネットワークを結ぶ：

```
                  天石門別神（佐那河内）
                 ＝天手力男命＝天背男命
                          │
        ┌─────────────────┴─────────────────┐
        │                                   │
    天日鷲命                          大宜都比売命
   （阿波忌部祖）                     （阿波国魂神）
        │                                   │
        │                          × 積羽八重事代主神
        │                            （大国主の子）
        │                                   │
        ┗━ 妹 天津羽羽命              ┗━ 葦稲葉神
              （事代主の妻）              （板野郡の御子神）
```
