# 元伊勢笠縫邑の比定論：阿波・名方郡説

崇神天皇の代、天皇宮中から **天照大神** が初めて外に出されて祀られた **「倭笠縫邑（やまとのかさぬいむら）」**。通説では奈良県磯城郡など畿内に10箇所以上の比定地が並立するが、阿波説ではこれを **阿波・名方郡内**（特に上一宮大粟神社周辺、または佐古地＝旧「伊勢郡」）に比定する。

## 1. 『日本書紀』崇神紀の記述

> **崇神天皇6年**：
> 「百姓流離、或有背叛、其勢難以徳治。是以、晨興夕惕、請罪神祇。先是、天照大神・倭大国魂、二神並祭於天皇大殿之内。然畏其神勢、共住不安。故、以天照大神、託豊鍬入姫命、祭於倭笠縫邑。仍立磯堅城神籬。亦以日本大国魂神、託渟名城入姫命令祭。」

すなわち：
1. **天照大神** と **倭大国魂神** が同居していた天皇大殿は神威が強すぎて不安
2. 天照大神 → **豊鋤入姫命** に託し、**倭笠縫邑** に祀る
3. 倭大国魂神 → **渟名城入姫命**（沼名木入姫命）に託す

→ 豊鋤入姫が33年間奉仕後、垂仁朝に **倭姫命** が引き継ぎ、伊勢へ向かう90年の **元伊勢巡幸** が開始。

## 3. 阿波説における比定論

### 3-1. 上一宮大粟神社 ＋ 天石門別八倉比売神社（名方郡）

- [[上一宮大粟神社]]（神山町神領）：**大宜都比売命**＝豊受姫命＝倭大国魂神 の本貫
- [[天石門別八倉比売神社]]（徳島市国府町）：天照大神（大日孁尊）の真陵説、御本記・五角形祭壇・杉尾古墳（卑弥呼陵説）

阿波説：崇神朝に **天皇宮中** から外に出された天照大神は、阿波・名方郡の **既存の祭祀地** ＝天石門別八倉比売神社へ託された。

### 3-2. 「式（しき）」「敷島」の地名解釈

ANYA(187)説：
- 崇神天皇の宮「**磯城瑞籬宮**（しきのみずがきのみや）」の「**式**（しき）」は **「川辺・河川敷・敷地」** を意味する慣用字
- 通説の桜井市・大神神社山麓は **大きな水辺と無縁** で矛盾
- 阿波説では **「半田川流域」**（吉野川南岸・つるぎ町半田）を磯城瑞籬宮の比定地とし、ここに **「天皇」という地名** が現存することを根拠とする

→ 笠縫邑も「式」（川辺）にあるはずで、**[[倭大國玉神大國敷神社：全国唯一「倭」を冠する式内社|倭大国玉神大国敷神社]]** の近辺（吉野川流域）に存在したと推定。

### 3-3. 佐古地・天一神社（旧「伊勢郡」）— ANYA(187)の本命説

| 項目 | 内容 |
|---|---|
| 神社名 | **佐古天一神社**（さこあめのひとつじんじゃ／旧称：**天一神宮**） |
| 鎮座地 | 徳島県名東郡佐那河内村 佐古（旧「伊勢郡 佐古地」） |
| 主祭神 | **天照大神**＋月読命＋大星神（**三柱**） |
| 由緒 | 812年1月11日に神のお告げで現在地に遷座（元は奥のエ嶽山頂） |
| 1568年 | 棟札に再建記録 |
| 式内社 | **未選定**（あえて選定されなかったと推定） |
| 現存事実 | **徳島県立図書館所蔵の文献に「伊勢郡の佐古地」の記述** あり、江戸初期まで佐古は「伊勢郡」と呼ばれていた |

#### 「伊勢郡 佐古地」の地理範囲

- 現在の **徳島市の南部**＋**名西郡石井町の一部**＋**佐那河内村の全域**
- 江戸時代初期まで実在した郡名「**伊勢郡**」
- 県立図書館所蔵史料に確認

#### 「佐古」の語源

- 古来「**佐の地**（さのち）」と呼ばれた
- 天照大神の田＝**佐田・長田**に由来
- 『古事記』天岩戸段：天手力男（タヂカラオ）の表記が **「佐之男に坐す」**（さのおにます）→ 佐古がただならぬ場所であることの傍証

#### 「天一」の語源

- **「天の第一の神」** ＝天照大神を指す
- 伊勢神宮の式年遷宮で **大工が「太一（たいいち）」** を背負うシンボル
- 阿波説：**「天一」が伊勢遷座の際に「太一」に変えられた**（強力な意味を持つ文字を意図的に変更）
- だから式内社に **選ばれなかった**（時の権力が伊勢神宮伝承への関与を隠蔽）

## 4. 元伊勢巡幸の出発点としての阿波

```
【崇神朝・宮中】
  天照大神 ＋ 倭大国魂神 が天皇大殿に同居
       ↓
  神威に耐えられず、豊鋤入姫に天照大神を託す
       ↓
【阿波説：倭笠縫邑＝佐古地 or 上一宮大粟神社周辺】
  812年（古来）の伝承を持つ天一神宮（佐古天一神社）に遷座
  ※伊勢神宮内宮で4年間しか祀られなかった元伊勢「籠神社」より、
   33年間奉仕された大和（阿波）の笠縫邑の方が本来重要
       ↓
【垂仁朝・倭姫命の巡幸】
  阿波 → 大和 → 丹後 → 伊賀 → 美濃 → … → 伊勢
  90年の歳月を経て伊勢神宮に永遠の鎮座
```
