# 春日大社の元宮論：阿波忌部・中臣氏の本貫と多氏東遷

奈良春日大社の四柱（武甕槌・経津主・天児屋根・比売神）の祭祀が、阿波の阿波忌部・中臣氏・多氏の本貫を経由して **常陸 → 大和 → 鹿島** の二段階遷座を経て成立したとする阿波説の論考。

> 📚 親ハブ: [[元宮ハブ_MOC]]
> 🔗 連結ノート: [[鹿島神宮の元宮と多氏の東遷]]

## 概要

| 項目 | 内容 |
|---|---|
| 遷座先 | 春日大社（奈良市、768年創建） |
| 阿波の元宮（候補） | **建布都神社**（経津主＝建御雷神／阿波郡）／**中臣大鳥神社跡**（板野郡）／**忌部神社**（阿波忌部祖神祭祀） |
| 阿波の鎮座地 | 阿波郡市場町／板野郡板野町大寺／名西郡 |
| 主張根拠 | 多氏（神八井耳命系）の東遷ルート、中臣氏の阿波痕跡、武甕槌＝建布都神＝建御雷神の阿波先行祭祀 |
| 確度 | **★（伝承のみ）** — 768年大生神社→春日遷座は史実だが、それ以前の阿波先行を示す一次史料は限定的 |

## 1. 春日大社の四柱

| 殿 | 祭神 | 通説の系統 | 阿波説の比定 |
|---|---|---|---|
| 第一殿 | **武甕槌命**（たけみかづちのみこと） | 鹿島の主神 | [[建布都神社]]＝建御雷神＝建布都神（阿波郡市場町） |
| 第二殿 | **経津主命**（ふつぬしのみこと） | 香取の主神 | [[建布都神社]]（建布都＝経津主の異名）／伊予国桑村郡 **布都神社** |
| 第三殿 | **天児屋根命**（あめのこやねのみこと） | 中臣氏祖神 | **中臣大鳥神社**（板野郡）の中臣氏痕跡 |
| 第四殿 | **比売神**（ひめがみ） | 天児屋根の妻 | 阿波忌部・天日鷲命系の女神（諸説） |

→ 第一殿・第二殿の **武甕槌＋経津主** は記紀の国譲り段で派遣される一対の武神で、阿波説では **同一神の二側面**（建御雷＝建布都）として[[建布都神社]]に統合される。

## 2. 多氏（神八井耳命系）の東遷と春日

### 二段階遷座（史実）

```
神護景雲2年（768）：大生神社（常陸潮来）→ 春日（奈良）へ遷座
       ↓
大同2年（807）：春日 → 鹿島神宮へ再遷座
```

→ 詳細：[[鹿島神宮の元宮と多氏の東遷]]

### 多氏の阿波起源

- **神武天皇の皇子・神八井耳命**を祖とする多氏（オフ氏・飯富族）が大和を経て常陸へ東遷
- 阿波説では、神八井耳命の **本来の本拠は阿波の名方郡**（大和大国魂神の祭祀地）
- 大生古墳群（110基）は多氏一族の奥津城
- 多氏の東遷経路：**阿波 → 大和 → 常陸 → 春日 → 鹿島**

## 3. 中臣氏の阿波痕跡：中臣大鳥神社

板野郡に存在した **「中臣大鳥神社」** は、阿波における中臣氏の活動痕跡を示す式外社。

| 項目 | 内容 |
|---|---|
| 神名 | 中臣大鳥神 |
| 史料初見 | **大同元年（806年）** 『新抄格勅符抄』に「中臣大鳥神 二戸 阿波」 |
| 旧鎮座地 | 板野郡板野町大寺字高樹（現・高樹公会堂跡） |
| 現状 | 明治44年、亀山神社に合祀（八坂神社・大鳥神社・春日神社などと合併） |
| 祭神 | 日本武尊（『大寺村史』）、和泉国大鳥神社の分祀（『大日本史神祇志』） |

> 注目点：天石門別八倉比賣神社の最古神階授与（841年）より **35年早い806年** に、中臣大鳥神社が神封戸を与えられている。すなわち平安初期の阿波で **中臣系神社が朝廷から最大級の格を受けていた**。

→ 出典：2025-12-16_【阿波の神社を行く！】忌部一族の阿波で中臣一族の痕跡が！「中臣大鳥神社」 （[出典](https://kohun-jinjya.blog/nakatomiootorijinjya/)）

合祀された **春日神社** との関係：明治44年に亀山神社が合祀した社の中に **「村社 春日神社」** が含まれており、板野町大寺の祭祀圏には **中臣系（春日系）の信仰** が古来存在していた。

## 4. 阿波忌部と中臣氏の系譜的縁戚

阿波忌部祖 **天日鷲命** の系統と中臣氏の祖 **天児屋根命** は、ともに **天孫降臨の五伴緒** に列せられる祭祀氏族。

```
天日鷲命（阿波忌部祖）── [[忌部神社]]
   ┃
   ┣ 長白羽命（天八坂彦命）→ 伊勢神麻続部、八坂刀売命を生む
   ┣ 由布津主命 → 安房開拓
   ┗ 天津羽羽命 → 事代主命の妻

天児屋根命（中臣氏祖）── 春日大社 第三殿
   ┃（阿波での祭祀痕跡）
   ┗ 中臣大鳥神社（板野郡）／中臣氏は阿波忌部と祭祀儀礼で連携
```

阿波説では、**忌部と中臣は阿波で連携して天孫降臨の祭祀を担い**、その後それぞれ安房（千葉）と大和へ東遷したとする。

## 5. 春日遷座のタイムライン（阿波説）

```
【神代】
  阿波で武甕槌＝建布都神の国譲り祭祀 → [[建布都神社]]
  阿波忌部＋中臣氏が連携 → [[忌部神社]]・中臣大鳥神社
       ↓
【神武東征以後】
  多氏（神八井耳命系）が阿波 → 大和 → 常陸へ東遷
  大生神社（潮来）に氏神タケミカヅチを祀る
       ↓
【神護景雲2年（768）】
  大生神社 → 奈良春日へ遷座（藤原氏興隆と連動）
  → 春日大社の創建
       ↓
【大同2年（807）】
  春日 → 鹿島神宮へ再遷座
```

## 6. 通説（藤原氏中心）との対立点

| 論点 | 通説 | 阿波説 |
|---|---|---|
| 春日大社の創建 | 768年、藤原永手が鹿島より勧請 | 大生神社（常陸）経由、阿波の多氏祭祀が本源 |
| 武甕槌の出自 | 高天原から派遣された武神 | 阿波の建布都神＝建御雷神が本源 |
| 経津主の出自 | 香取の主神、物部氏との関連 | 阿波郡 建布都神社の建布都神と同一 |
| 中臣氏の本貫 | 大和（中臣連） | 阿波（中臣大鳥神社）から大和へ東遷 |

## 7. 残された課題

| 課題 | 内容 |
