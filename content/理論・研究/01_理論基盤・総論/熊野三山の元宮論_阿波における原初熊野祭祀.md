# 熊野三山の元宮論：阿波における原初熊野祭祀

紀伊熊野三山（本宮・速玉・那智）の祭神が、阿波の那賀川流域・板野郡・吉野川北岸に分布する熊野系祭祀群を本源とする、という阿波説の主張を整理する。

> 📚 親ハブ: [[元宮ハブ_MOC]]
> 🔗 地名検証: [[阿波・熊野・八坂ペア：紀伊と山城へ移された原初の祭祀]]

## 概要

| 項目 | 内容 |
|---|---|
| 遷座先（通説） | 熊野本宮大社／熊野速玉大社／熊野那智大社（和歌山県） |
| 阿波の元宮候補 | **板野郡の熊野神社**（社紋・古社数）／**土成町熊野村**（高尾字熊之庄）／**那賀川流域の熊野神社群** |
| 阿波の鎮座地 | 板野郡・阿波市土成町・那賀郡・名西郡神山町周辺（諸説） |
| 主張根拠 | 社紋の格、神武東征「熊野村」の阿波比定、地名「クマ」＝「隈」「神」「ク（神）マ（地）」の語源、熊野系式内社の阿波集中 |
| 確度 | **★（伝承のみ）** — 単一の社伝で確定できる元宮はなく、複数比定が並立 |

## 1. 熊野三山の祭神と「クマノ」の意味

| 三山 | 主祭神 | 別称 |
|---|---|---|
| 熊野本宮大社 | **家都美御子大神**（けつみみこのおおかみ） | 須佐之男命と同一視 |
| 熊野速玉大社 | **熊野速玉大神**（くまのはやたまのおおかみ） | 伊邪那岐命と同一視 |
| 熊野那智大社 | **熊野夫須美大神**（くまのふすみのおおかみ） | 伊邪那美命と同一視 |

「**クマノ**」は **「隈（くま）の野」＝山の奥まった霊地** とする解釈と、「**神（くま）＝神聖な地**」とする解釈がある。阿波説では後者を採り、阿波の **神山町・隈・久万** など「クマ」音を持つ地名群を原初の熊野とみる。

## 2. 阿波の熊野系祭祀の痕跡

### 2-1. 板野郡の熊野神社（伊太郡隈野庄）

阿波説の中で最も有力に主張される元宮候補。

- 祭神：**隈野久須比命**（くまのくすひのみこと）
- 旧称：**伊太郡隈野庄** の総鎮守「熊野大明神」
- **社紋は十六菊花紋＋桐紋**（天皇・皇后の象徴）
- 紀伊熊野三山の社紋「**八咫烏**」とは格が異なり、阿波の熊野神社は皇室紋を許された古社
- 同じ地域に **式内社の熊野神社が五社** あったと伝わる

> 阿波説の主張：「**社紋の格は阿波の圧勝**」「式内社数も５対３で阿波の勝ち」
>
> 出典：熊野神社は、阿波と紀伊とどちらが本家本元 （[出典](https://xn--mnqu5jib741oy19b.xyz/category4/entry27.html)）

### 2-2. 土成町熊之庄の熊野神社（神武東征の「熊野村」）

『古事記』神武東征段で、皇軍が **「熊野村」** で大熊の邪気にかかって倒れ、高倉下が建御雷神から霊剣を授かる場面。

- **阿波説の比定地**：阿波市土成町高尾字 **熊之庄** に鎮座する熊野神社
- 同地の **「高尾」** という地名は **「高倉下（タカクラジ）」** に由来
- 西側丘陵の土成町樫原に **樫原神社**（神武天皇祭神）が鎮座
- 隣接：[[建布都神社]]（建御雷神＝建布都神の本拠）
- 出典：2015-01-13-高天原の武神_建御雷神（建布都神） （[出典](https://awa-otoko.hatenablog.com/entry/2015/01/13/232001)）

すなわち神武東征の「熊野村の危機」は **吉野川北岸の阿波で発生した物語** であり、紀伊熊野ではなく **阿波の熊野こそが原初の戦地** とする解釈。

### 2-3. 八万町王子祠・丈六町熊野神社（眉山周辺）

眉山（**以乃山**）周辺の **素戔嗚尊一族の祭祀ネットワーク** の一部として熊野神社が機能。
- [[熔造皇神社：八坂神社・祇園信仰の元宮と素戔嗚尊の鉄鋳造祭祀]] と一体の祭祀圏
- 熊野本宮の主祭神・**家都美御子大神＝須佐之男命** の同一視と整合

### 2-4. 那賀郡・那賀川流域

「**那賀（なか）**」の地名そのものが熊野の中核祭祀との関連を示唆。
- 八桙神社（大国主＝八千矛）所在地
- 剣山系の山岳信仰ラインの東端
- 紀伊熊野が「南紀の山岳信仰」であるのに対し、阿波の那賀川流域は **剣山＝山岳神道の本貫**

## 3. 阿波説における「熊野＝阿波」の論理

1. **語源論**：「クマノ」の「クマ」は、阿波の **神山町・隈・久万・神領** など「神聖な地」を意味する地名群と同源
2. **神武東征の舞台**：『古事記』の「熊野村」は阿波・吉野川北岸の土成町熊之庄であり、紀伊半島ではない
3. **社紋の格**：板野郡熊野神社は皇室紋を許された古社で、八咫烏紋の紀伊三山より格上
4. **式内社の集中**：阿波の伊太郡には熊野系式内社が５社あったと伝わる
5. **神格の同一性**：熊野本宮の家都美御子大神＝須佐之男命は、[[熔造皇神社：八坂神社・祇園信仰の元宮と素戔嗚尊の鉄鋳造祭祀|熔造皇神社（眉山）]] の素戔嗚祭祀と一致

## 4. 通説（紀伊熊野中心）との対立点

| 論点 | 通説 | 阿波説 |
|---|---|---|
| 熊野信仰の発祥 | 紀伊半島の山岳信仰 | 阿波の山岳信仰が紀伊へ伝播 |
| 神武東征の熊野 | 紀伊半島南部 | 阿波・吉野川北岸 |
| 八咫烏の出身 | 不詳・神話的存在 | 阿波・**八多村**出身（人名由来） |
| 熊野権現の本地 | 紀伊本宮 | 板野郡熊野神社 or 那賀川流域 |
| 全国熊野神社の勧進 | 紀伊からの修験者経由 | 阿波からの原初祭祀が紀伊経由で全国化 |

→ 関連：中四国の霊山１５ 土佐の熊野権現の勧進と修験者 瀬戸の島から （[出典](https://tono202.livedoor.blog/archives/4573474.html)） では土佐の熊野神社128社は紀伊からの勧進としており、修験道伝播ルートは中世以降は紀伊中心。

## 5. 残された課題

| 課題 | 内容 |
|---|---|
| 元宮の一意比定 | 板野郡説／土成町熊之庄説／那賀川流域説／眉山周辺説が並立し、絞り込めていない |
| 熊野三山の祭神配分 | 本宮・速玉・那智がそれぞれ阿波のどの社に対応するか未整理 |
| 隈野久須比命の正体 | 「隈野久須比」は記紀に登場しない独自の神名で、出自不詳 |
| 八咫烏＝八多村説の検証 | 阿波内の「八多」地名と八咫烏伝承の接続は未だ仮説段階 |
| 中世修験道との分離 | 中世以降の熊野権現勧進ルートは紀伊中心であり、それ以前の阿波先行を示す物証が薄い |
