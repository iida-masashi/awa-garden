# 阿波・畿内地名ペア検証：東遷（ひがしうつり）の法則

阿波説（徳島説）の最大の根拠の一つは、阿波にある **古い地名が、そのまま他地域（近畿・関東）に存在し、しかも阿波の方が地理的・神話的に「原初的な意味」を保持している** という実態にある。これを阿波説では **「東遷（ひがしうつり）の法則」** と呼ぶ。

本ノートは、**地名ペア検証** の理論的ハブ。具体的なペア検証は `地名ペア検証/` フォルダ内の各専門ノートを参照する。

---

## 🗿 東遷の法則とは

> 阿波の有力氏族（**忌部・海人族・物部・多氏・賀茂氏**）が、初期王権の拡大に伴って全国へ進出した際、**自らのアイデンティティと祭祀の正統性を守るため、故郷の地名を新しい開拓地へ「移植」した**。

この単純な現象を、阿波と畿内・関東の **同名地名分布** が物的に証明している。

### 東遷の三要素

```
氏族の移動  →  地名の輸出  →  祭祀の移植
  │             │              │
  忌部         地名             式内社
  海人        トポロジー       祭神の同一性
  物部
```

## 🎯 東遷の法則が示すもの

東遷の法則は、単なる地名類似ではなく、**阿波の祭祀王権が全国的な氏族ネットワークを構築していた** ことを示す物的痕跡である：

1. **地名 ＋ 氏族 ＋ 祭祀** の三点セットが、阿波→畿内・東国に **同型で複製** されている
2. **阿波の方が祭祀的・地理的に原初的な意味** を保持している
3. **逆方向（畿内→阿波）の地名輸出の痕跡はほぼ存在しない**
4. **個別ペアの確率論的検証** で、偶然の一致を超えた相関が確認される

→ これは、**「阿波が原点で、そこから全国に拡散した」** とする阿波説の核心仮説を **地理学的・統計学的に裏付ける** ものとなる。
