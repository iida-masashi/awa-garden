# 景初2年朝貢と献上品の阿波対応：金印・銅鏡・藍染・朱

景初2年（238年）の卑彌呼による魏への遣使、**「親魏倭王」金印** の冊封、そして **献上品リスト（銅鏡百枚・真珠・鉛丹・絳青縑・異文雑錦）が阿波の特産品と完全に対応する** ことを示す詳細考察。

## 1. 景初2年（238年）の朝貢

### 1.1 『魏志倭人伝』原文

> **景初二年六月、倭女王遣大夫難升米等詣郡、求詣天子朝獻、太守劉夏遣吏將送詣京都**
> （景初二年六月、倭の女王が大夫の難升米らを帯方郡に遣わし、天子に朝献せんことを求めた）

### 1.2 朝貢使節の構成

| 項目 | 内容 |
|---|---|
| **年次** | **景初2年（238年）** 6月（『梁書』は景初3年とも） |
| **派遣元** | 卑彌呼（倭女王） |
| **正使** | **難升米**（大夫の官） |
| **副使** | **都市牛利** |
| **経由地** | 帯方郡 → 洛陽 |
| **接受側** | 魏皇帝 **曹叡**（明帝） |

### 1.3 「親魏倭王」の冊封

| 授与品 | 身分 |
|---|---|
| **金印紫綬** | 王の身分 ＝ 卑彌呼 |
| **銀印青綬** | 官の身分 ＝ 難升米・都市牛利 |
| **詔書** | 親魏倭王の称号 |

### 1.4 大月氏王との対比

- 同時期、**229年に大月氏国に「親魏大月氏王」印** が授与
- 東西の魏国影響圏 ＝ 東端「親魏倭王」（倭国）／西端「親魏大月氏王」（中央アジア）
- 倭国 ＝ 阿波 は **魏帝国の東端の冊封国** という地政学的位置付け
- 関連: (191）『金印と銅鐸と阿波　失われた王朝の記憶』（[出典](https://www.youtube.com/watch?v=sTMNA0v-rKI)）

## 2. 献上品リストと阿波の特産品

### 2.1 倭から魏への献上品（景初2年）

> 男生口四人、女生口六人、班布二匹二丈、を貢ぐ

### 2.2 魏から倭への下賜品（同年〜翌年）

> 銅鏡百枚、真珠、鉛丹、絳青縑、異文雑錦、白絹、金、刀…

### 2.3 阿波特産品との対応表

| 下賜・献上品 | 内容 | 阿波での対応 |
|---|---|---|
| **銅鏡百枚** | 漢式鏡・内行花文鏡など | **寺山古墳群・萩原墳丘墓 出土の内行花文鏡**（→ [[羽衣伝説の阿波比定論：和奈佐と寺山古墳群]]） |
| **真珠** | 海産真珠 | 阿波の **海部郡海産物**（古代真珠採取地） |
| **鉛丹（朱）** | 水銀朱・酸化鉛朱 | **若杉山辰砂採掘遺跡** の朱（→ [[阿波の水銀朱（辰砂）：若杉山遺跡と権力の象徴]]） |
| **絳青縑（こうせいけん）** | 紅・青の上質絹布 | **阿波藍染** の可能性（藍染は古代から阿波の特産） |
| **異文雑錦** | 異なる文様の織物 | **阿波文字** の推定文様？／阿波忌部の織物 |
| **班布二匹二丈** | 縞模様の布 | 阿波忌部の麻織物・絹織物 |

→ 献上品・下賜品の主要項目が **阿波の特産・遺跡出土物と直接対応**。

### 2.4 「其山有丹」（朱）の決定的証拠

- 『魏志倭人伝』に **「其山有丹（その山に丹あり）」** と明記
- **若杉山辰砂採掘遺跡**（阿南市）は **国指定史跡**、弥生時代の水銀朱採掘遺跡
- 朱を魏へ献上できる地は限定的（中国側で珍重された）
- → **「其山有丹」の物的証拠地は若杉山以外に同等の候補なし**
- 関連: [[加茂宮ノ前遺跡：縄文後期からの朱生産]]（縄文後期からの朱生産系統）

## 3. 景初2年と弥生終末期の阿波

### 3.1 年代整合

| 出来事 | 年代 | 阿波の対応事象 |
|---|---|---|
| 倭国大乱 | 146-189年 | 弥生後期末の集落動態変化 |
| 卑彌呼共立 | 190年頃 | 神山・那賀の祭祀拠点化 |
| 景初2年朝貢 | 238年 | 弥生終末期の威信財蓄積 |
| 卑彌呼死去 | 248年頃 | 杉尾古墳・寺山古墳群の築造期 |
| 壹與継承 | 250年代 | 庄内式土器期、初期前方後円墳との接続 |

### 3.2 内行花文鏡の阿波分布

| 出土地 | 種類 |
|---|---|
| **寺山古墳群**（海陽町） | 内行花文鏡片 |
| **萩原墳丘墓**（鳴門市大麻町） | 内行花文鏡 |
| **芝遺跡** | 弥生終末期遺物 |

→ 「銅鏡百枚」の一部が阿波に到達した可能性。

### 3.3 「鏡を分配する」記述との関連

- 『魏志倭人伝』に明記はないが、後の伝承では女王が銅鏡を諸国に分配
- 阿波内分布は **配布の中心地としての邪馬壹國** と整合

## 4. 経済規模：7万戸×5人＝35万人

### 4.1 anaya 考察（→ (102) 『漢委奴国王印から邪馬台国解明！』）

- 邪馬壹國7万戸 × 5人 ＝ **約35万人**（鳴門市規模に相当）
- 「祖賦税の定格あり」の **高度行政システム**
- 農業・水産だけで35万人を養えない阿波の地形条件
- → **「労役＝技術者活動」** と推測（朱採掘・銅鏡製作・玉作・藍染・織物）

### 4.2 物的証拠

- **淡路島入田成遺跡** から **古代中国貨幣3枚** 出土
- → 阿波・淡路圏が **中国との交易圏** に組み込まれていた物的証拠

### 4.3 後漢時代の前史

- 57年「漢委奴国王」印（光武帝）の朝献は **純粋な友好** の証
- 107年帥升の朝献（後漢書）は阿波の **帥升ミマ説** と接続（→ [[帥升ミマ説：元始ヤマト王権初代王と若杉山]]）
