# 邪馬壹國の中心地と卑彌呼の宮室・統治体制

邪馬壹國（徳島県）の **中心比定地**（神山町・那賀町・剣山周辺）と、**卑彌呼の宮室・楼観・城柵・千人の婢** という統治構造、および対立勢力 **狗奴國** の比定を扱う。

> 補完関係：卑弥呼の **正体論（天照大神との習合）・墓（八倉比売神社）** は [[卑弥呼と天照大神：阿波における女王の墓と正体]] を参照。本ノートは **宮室・統治・行政構造** に特化する。

## 1. 邪馬壹國の中心比定地

### 1.1 中心三点

| 場所 | 役割 |
|---|---|
| **神山町** | 高天原祭祀の中心地（→ [[高天原阿波説：神山町の巨大湖と天津の民]]） |
| **那賀町** | 卑弥呼の宮室・統治拠点の候補地 |
| **剣山周辺** | 古代祭祀の聖山・霊的中心 |

### 1.2 地理的妥当性

- **神山町**：吉野川支流・鮎喰川上流の盆地。古代湖の伝承、上一宮大粟神社の鎮座。
- **那賀町**：那賀川上流域の山間盆地。杉尾古墳（弥生終末期円形周溝墓）の存在。
- **剣山**：四国山地最高峰、古代祭祀痕跡。
- → **吉野川流域（北）と那賀川流域（南）の中間山岳地帯** が邪馬壹國の中核。

### 1.3 邪馬壹國7万余戸の収容

- 7万余戸 × 平均5人 ＝ **約35万人**
- 単独盆地では収容不可能 → **県内連合体** としての邪馬壹國像
- 吉野川流域（板野・阿波・美馬・麻殖・名方郡）＋ 那賀川流域 ＋ 海部郡北部 の総体

## 2. 卑彌呼の宮室・楼観・城柵：物的対応

### 2.1 『魏志倭人伝』の記述

> **居處宮室樓觀城柵、嚴設、常有人持兵守衛**
> （住まいは宮室・楼観・城柵、厳設にして、常に人が兵を持して守衛す）

| 要素 | 内容 | 阿波での想定地 |
|---|---|---|
| **宮室** | 王の居住建築 | 神山町盆地／那賀町盆地 |
| **楼観** | 見張り台・物見櫓 | 山頂祭祀地（剣山系） |
| **城柵** | 防御柵で囲まれた集落 | 高地性集落・要塞型集落 |
| **守衛** | 武装常備兵 | 武器副葬の弥生終末期遺跡 |

### 2.2 候補遺跡

| 遺跡 | 関連 |
|---|---|
| **杉尾古墳**（那賀町） | 弥生終末期の円形周溝墓・卑彌呼陵候補 |
| **稲持遺跡**（東みよし町） | 弥生時代玉作遺跡、勾玉出土 |
| **井手上遺跡**（三好市） | 翡翠製勾玉（新潟系）、広域交易の証 |
| **若杉山辰砂採掘遺跡**（阿南市） | 「其山有丹」と完全整合（→ [[阿波の水銀朱（辰砂）：若杉山遺跡と権力の象徴]]） |
| **天石門別八倉比売神社** | 卑弥呼陵候補（詳細は [[卑弥呼と天照大神：阿波における女王の墓と正体]]） |

## 3. 卑彌呼の統治体制

### 3.1 『魏志倭人伝』

> **其國本亦以男子為王、住七八十年、倭國亂、相攻伐歷年、乃共立一女子為王、名曰卑彌呼**

→ 倭国大乱（146-189年、後漢期）の後、卑彌呼を共立。

### 3.2 統治構造の阿波対応

| 統治要素 | 原文記述 | 阿波での物的・伝承的対応 |
|---|---|---|
| **シャーマニズム** | 「事鬼道、能惑衆」 | 神山町の祭祀地、剣山信仰、上一宮大粟神社の祭祀 |
| **千人の婢** | 「以婢千人自侍」 | 大規模集落の存在（吉野川流域の弥生集落群） |
| **楼観・城柵** | 「居處宮室樓觀城柵、嚴設」 | 高地性集落、武装常備の痕跡 |
| **男弟の補佐** | 「唯有男弟佐治國」 | 男女双系の統治体制、阿波忌部の祭政分離 |
| **唯一の通訳** | 「唯有男子一人給飲食、傳辭出入」 | 厳格な隔絶体制 |

### 3.3 「共立」の政治的意味

- 倭国大乱（後漢書では桓霊間＝146-189年）後の **諸国合議による擁立**
- 単独王権ではなく **連合王権** の象徴的女王
- 阿波忌部・長国造などの複数氏族による合議体制と整合
- 関連: [[後漢書東夷伝の倭国記事と阿波比定：光武帝・帥升・倭国大乱]]

## 5. 狗奴國：邪馬壹國の南方対立勢力

### 5.1 原文

> **其南有狗奴國、男子為王、其官有狗古智卑狗、不屬女王**

- 邪馬壹國の **南** に位置
- 男王、官は **狗古智卑狗（くこちひこ）**
- **女王に属さない** ＝ 独立勢力・対立勢力

### 5.2 阿波説での比定候補

| 候補 | 根拠 |
|---|---|
| **那賀町〜海部郡南部** | 邪馬壹國中心の地理的「南」、長国造（[[八桙神社]]）の系統 |
| **高知県南部** | より遠方の独立勢力、太平洋側 |

### 5.3 長国造との関連

- **長国造**：阿波南部・海部地域の古代国造
- [[八桙神社]]（阿南市）の祭祀圏
- 大国主の子孫系統で、邪馬壹國中心とは別系統
- → 狗奴國 ＝ 長国造の前身的勢力という仮説
