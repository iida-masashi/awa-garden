# 日本書紀の行幸非対称性と阿波——「沈黙」を史料批判的に読む

> [!summary] 要旨
> 『日本書紀』全30巻には、阿波国・讃岐国への天皇の**行幸・遠征・使者派遣の記録が一件もない**——という観察を出発点に、これを「記録の欠如＝証拠の欠如」で片付けず、**非対称性**として読み解こうとする論考フレームを整理する。鍵は、阿波には行幸記録こそ無いが**屯倉設置（安閑2年）・海人動員（允恭14年）という行政記録は存在する**点である。「認識し記録する能力はあったのに行幸では描かれない」というこの非対称を、九州・東国・吉備（いずれも征討・服属の物語で繰り返し登場）と対比し、「阿波・讃岐は記紀の世界観で**最初から"内側"だった**ため組み込みの叙述（行幸・征討）が不要だった」とする**阿波説的解釈（Tier-2の読み）**を検討する。
> ──ただしこのフレームは note.com の個人ブログ論考 に由来し、核心の「全30巻で行幸ゼロ」は**全称否定**で主証拠（行幸地名DB）は未公開Excel にあり本Vaultでは独立検証できていない。本ノートは断定せず、論法の構造・強さ・弱さを史料批判的に整理する。

## 1. 観察される非対称性（フレームの骨子）

| 阿波・讃岐に**ある**記録 | 阿波・讃岐に**ない**記録 |
|---|---|
| 行政的関与：阿波國春日部屯倉の設置（安閑2年/534・巻18） | 行幸・遠征・使者派遣（全30巻でゼロと主張される） |
| 海人動員：男狹磯「是阿波國長邑之海人也」（允恭14年/c.427・巻13） | 征討・平定の対象としての登場 |
| | 祭祀・神宮参拝の目的地としての登場 |
| | 温湯・狩猟の行幸地・遷都先・航路途次の経由地 |

論者の主張：「記録能力がなかったから書かれていない」のではない。屯倉・海人という**積極的な行政関与記録が現に残る**以上、阿波を認識・記録する能力は存在した。それでも行幸の五類型（①征討②祭祀③温湯狩猟④遷都⑤航路途次）の**どれにも一件も該当しない**——この非対称が論証の核心である。

## 2. 比較軸——なぜ「沈黙」が問いになるのか

論者は阿波・讃岐の「沈黙」を、記紀が繰り返し描く地域との対比で浮かび上がらせる。

| 地域 | 行幸・遠征記事（論者の集計） | 記紀での描かれ方 |
|---|---|---|
| 九州 | 30件 | 景行の熊襲征討・土蜘蛛平定など、12年にわたる詳細な征討譚 |
| 東国 | 21件 | ヤマトタケル東征、四道将軍——「英雄的征服で及んだ辺境」 |
| 吉備 | 9件 | 神武の高嶋宮3年、応神期の反乱——同じ瀬戸内でも「征討・服属の物語」を持つ |
| **阿波・讃岐** | **0件** | 征討も服属も奉仕も祭祀も、いずれの「外側からの接触」記録もない |

- **航路途次との乖離**：淡路島への行幸は5件あるのに、淡路南端から鳴門まで直線10km強の阿波には上陸記録がない。距離・アクセスは「行幸ゼロ」の説明にならない、と論者は言う。
- **吉備との対照**：吉備は同じ瀬戸内・大型墳墓を擁しながら「征討の物語」を持つ。阿波には征討譚が全30巻にない。

> [!note] フレームの中核的主張（Tier-2 の読み）
> 行幸記録のない地域には二種類ある——「記紀が関心を持たなかった**辺境**」と「行幸する必要がなかった**内側**」。九州・東国・吉備が征討・服属で繰り返し描かれるのは「外側を内側に組み込む」叙述上の必要があったからで、**行幸はその組み込みを可視化する記述装置**である。阿波・讃岐にはその装置が一切使われない＝「組み込む必要がなかった＝最初から"内側"だった」可能性を示唆する、というのが論者の読みである。

## 3. この論法の強さと弱さ（史料批判）

### 強い点
- 「記録がない」を単独で論拠にせず、**屯倉・海人という陽の記録との非対称**に着目している。これは「沈黙」論法の典型的弱点（沈黙論証 argumentum ex silentio）を一段回避する設計。
- ヤマト12件の比定地（奈良）を「通説的前提」として論証から**意図的に外し**、九州・東国・吉備という「どの史観でも外側」とされる記事群だけで比較している点は、論証として誠実。
- 推論を a（行幸として描かれない）→ b（"内側"の可能性）→ c（考古学的裏付け）と段階化し、c を【推測】とラベルする抑制が効いている。

### 弱い点・留保
> [!warning] このフレームを Vault の結論として扱わないための留保
> - **全称否定の未検証**：「全30巻で行幸ゼロ」は全称否定であり、その主証拠は論者の行幸地名DB（Excel）にある。本Vaultにアーカイブした記事本文にはDBが含まれず、**ゼロ主張を独立に検証できていない**。本ノートは「論者が全30巻を確認しゼロと主張する」と**帰属**するにとどめ、事実として断定しない。
> - **屯倉記録の両刃性**：「屯倉＝行政的実効支配」は論者が非対称の片翼として使うが、**屯倉は本来"外部からの王権の administrative reach（行政的到達）"の証拠**でもある。これは「最初から内側だった」という結論とは**むしろ緊張する**（内側なら屯倉を新設する必要があったのか？）。論者はこの緊張を半ば伏せている。
> - **出自**：フレームは査読論文ではなく note.com 個人ブログ論考（AI生成をうかがわせる構造化体裁）に由来する。Tier-2 の解釈として扱う。
> - **屯倉記述の不正確さ**：論者は「春日部屯倉は筑紫・豊国・火国・播磨・備後に設置」と書くが、これは安閑2年の屯倉**一斉設置全体**の設置域であって「春日部屯倉」単体ではない。一次史料（日本書紀安閑紀）では**「春日部」名の屯倉は火国と阿波国の2箇所**であり、この点は [[安閑天皇]]・[[欠史八代の阿波比定論：宮・陵・妃の地名対応一覧]] の記述（火国・阿波の二国）の方が正確。
