# 殿宮神社（とのみや）

> [!summary] 要旨
> 殿宮神社は、徳島県板野郡上板町神宅の[[葦稲葉神社]]境内に鎮座する摂社で、現在の主祭神は素戔嗚命とされる。しかし阿波説では、社名「殿宮（とのみや）」は本来「田宮（たのみや）」の転訛であり、神宅地区に伝わる「奥宮（大山山頂）・里宮（山麓）・田宮（水田）」という三層祭祀構造の最下層――稲作そのものを守護する田の神を祀った社であったとする解釈がある。素戔嗚命という現在の祭神は中世以降の神仏習合期に付会されたもので、本来は倉稲魂命（大宜都比売命の別名・稲荷神の本源）を祀っていたとみる立場が阿波説内部の有力説である。本ノートは、葦稲葉神社・鹿江比賣神社と一体をなす神宅地区の祭祀構造の中に殿宮神社を位置づける。

## 3. 祭神と社伝

境内の鳥居扁額には「鹿江姫神社、葦稲葉神社、殿宮神社」の三社が並記される。『徳島県神社誌』の由緒書には次のように記される。

> 葦稲葉神社は葦稲葉大明神と号し倉稲魂命・鹿江比賣命を、殿宮神社には素戔嗚命を夫々主祭神として奉祀せり…

この記載に従えば、殿宮神社の祭神は素戔嗚命であり、葦稲葉神社（倉稲魂命・鹿江比賣命の二座）とは別の系統として明確に区別されている。

一方、阿波説（awa-otoko氏）はこの素戔嗚命祭祀を中世以降の付会と見る。根拠は社名の語源解釈にある。「殿宮」は本来「**田宮（たのみや）**」であり、これが江戸期以降の漢字表記の固定化を経て「殿宮（とのみや）」となったとする説である。この立場に立てば、本来の祭神は水田・稲作を守護する**稲倉魂神**（大宜都比売命・稲荷神の本源）であったことになる。

## 4. 歴史

殿宮神社の歴史は、単独の創建史としてではなく、[[葦稲葉神社]]・[[鹿江比賣神社]]の遷座史の中に位置づけられる。

| 時代 | 出来事 |
|---|---|
| 古代 | 神体山「大山」山際の「芽野原（葦野原）」に葦稲葉神社が鎮座（奥宮層） |
| ある時期 | 山崩れにより奥宮の社殿が倒壊 |
| → | 扇状地下端の宮ヶ谷川河畔、鹿江姫神社の地へ遷座（里宮層） |
| → | 鹿江姫神社も失火により社殿焼失 |
| 現在 | 現在地――**殿宮（田宮）の地**――に葦稲葉神・鹿江比賣神が合祀される形で集約 |

この経緯により、現在の殿宮神社境内は「奥宮（葦稲葉神＝大山祇神系）」「里宮（鹿江比賣神＝野槌神系）」「田宮（殿宮＝稲魂系）」という神宅地区の三層祭祀が、災害を契機に一箇所へ集約された姿を示している。殿宮神社自体は、その最下層――もっとも人々の生活圏に近い水田の守護神――として最終的に全体の祭祀地を担う形になった。

## 5. 「田宮」から「殿宮」への転訛論

阿波説における殿宮神社の核心論点は、社名の音韻・表記の変化にある。

```
田宮（たのみや）── 水田を守護する田の神を祀る社
   ↓ 音韻・表記の変化（江戸期以降）
殿宮（とのみや）── 現在の表記・呼称
```

「田（た）」と「殿（との）」は字義上まったく異なるが、音の類似（「た」→「との」への転訛）と、水田地帯に鎮座する社という立地の一致から、阿波説では両者を同一起源とみる。この転訛が正しければ、現在「素戔嗚命」を祭神とする表記は、本来の田神・稲魂祭祀が中世の神仏習合・牛頭天王信仰の広まりの中で素戔嗚命（牛頭天王と習合）に置き換えられた結果と解釈できる。

牛頭天王＝素戔嗚命という習合は日本各地の農村で広く見られる現象であり、水田守護の土着神が疫病除け・農耕神としての牛頭天王＝素戔嗚命に置き換えられること自体は特異な事例ではない。ただし「田宮→殿宮」の転訛そのものは阿波説側の解釈であり、文献的な確証は得られていない。

## 6. 阿波説における意義

### 6-1. 神宅地区三層祭祀構造の完成形

殿宮神社は、[[葦稲葉神：天日鷲命の御子神と板野郡の稲祭祀]]で整理される「奥宮（大山山頂・黒岩大権現）－里宮（山麓・鹿江比賣神）－田宮（殿宮・稲魂神）」という三層祭祀構造の最終到達点である。二度の災害（山崩れ・失火）を経て、山の神・野の神・田の神の祭祀が一箇所に集約された結果が現在の葦稲葉神社・殿宮神社の姿であり、殿宮神社はその中でも最も生活に近い「稲作そのものへの感謝」を体現する層として位置づけられる。

### 6-2. 稲荷信仰の本源論との接続

阿波説では、板野郡の稲魂祭祀（葦稲葉神社・殿宮神社）と神山町の[[上一宮大粟神社]]を、伏見稲荷大社の二大元社候補とみる。殿宮神社の「本来は倉稲魂神を祀った」とする解釈は、この稲荷信仰本源論の一角を占める。

### 6-3. 素戔嗚命祭祀の意味づけの分岐

殿宮神社の祭神を通説通り「素戔嗚命」と見るか、阿波説的に「本来は稲魂神」と見るかは、そのまま阿波説の解釈方法論――中世以降の神仏習合による祭神の上書きをどこまで遡及的に読み解くか――の試金石になっている。
