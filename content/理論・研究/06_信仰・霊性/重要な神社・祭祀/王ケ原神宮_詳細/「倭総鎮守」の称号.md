# 「倭総鎮守」の称号

阿波・佐那河内村の大川原高原（旧称：王ケ原）山頂、旭ヶ丸（標高1019m）の展望台脇に現存する **謎の石碑**。そこに刻まれた **「倭総鎮守　王ケ原神宮」** という称号の意味を、佐那河内の山頂祭祀の文脈に絞って徹底解析する。

> ⚠️ **重要な区別**：本稿が扱う **「倭総鎮守 王ケ原神宮」** は、佐那河内村の山頂にある **謎の石碑そのもの** であり、美馬郡に鎮座する延喜式内社 **「倭大國玉神大國敷神社二座」**（祭神：倭大国魂命・大国敷命）とは **地理的にも性格的にも別物** である。両者は安易に同一視できない。
> - **王ケ原神宮**：佐那河内村・大川原高原山頂（社殿・由緒なし、石碑のみ）／山頂祭祀（天嶺＝天石門別祠）の文脈に属する
> - **倭大國玉神大國敷神社**：美馬郡（脇町拝原・美馬町）の延喜式内社／崇神紀「大殿祭祀」の倭大国魂神の文脈に属する
>
> 本稿は **前者** に限定する。後者は別ノート 倭大國玉神大國敷神社 を参照のこと。

地元の公的記録（『佐那河内村史』『徳島県神社誌』など）にも由来は一切記されておらず、設置の経緯は **完全な空白** である。神社としての社格・由緒もない。だが「**倭の総鎮守**」――これは並の称号ではない。

## 🔑 「倭総鎮守」とは何を意味するか

### 「総鎮守」の重み

「総鎮守」とは、ある地域・国土の **すべての神々を統括する** 上位神を祀る社の称号。日本各地に「鎮守神社」は無数にあるが、「**倭（やまと）全体の総鎮守**」を称しうる社は本来、極めて限定的である。

阿波における類似称号：

- **大麻比古神社**（阿波国一宮）：「阿波国・淡路国両国の総鎮守」「徳島県総鎮守」
- **王ケ原神宮の石碑**：「**倭** 総鎮守」

→ 大麻比古神社が「阿波・淡路の総鎮守」であるのに対し、王ケ原神宮の石碑は「倭（ヤマト全体）の総鎮守」を称しており、**地理的スケールが一段上** である点に注意。これは大麻比古神社をすら凌ぐ称号であり、近世以降の通常の建立物としては不自然な過大さである。

### 「倭」表記の古さ

ヤマトの当て字は、古い順に **「倭」 → 「大和」 → 「日本」**。石碑が「**倭**」を選択している点は、**意図的に最古層の表記** を用いていることを示す。

近世以降の人が単なる地域の鎮守として建てたなら「大和」「日本」「徳島」などを用いるはずで、わざわざ「倭」を選ぶには、**「ヤマトの本源としての阿波」** という阿波説的世界観が前提されていたと見るのが自然である。

## 🗻 山頂祭祀の文脈における「王ケ原神宮」

王ケ原神宮の石碑を理解する正しい枠組みは、**佐那河内村における山頂祭祀の伝統** である。本石碑は、延喜式の国魂社（倭大國玉神大國敷神社）とは独立した、**山頂祭祀系の称号** として読まれるべきものである。

### 『阿波志』の「天嶺」記述

江戸時代の徳島藩編『阿波志』に：

> **天石門別祠　中邊村天嶺にあり鎮守と称す**

- 「中邊村」は天慶年間（938〜947年）に **狭長村（さながむら）** から改称した、現在の佐那河内村の旧称。
- 「天嶺（あまね）」は **大川原高原の山頂部** を指すと考えられる。
- **「鎮守と称す」** ――王ケ原神宮石碑の「**総鎮守**」と、ここでの「**鎮守**」は呼応する。

→ 江戸時代において、佐那河内村の山頂部には「**鎮守と称された天石門別祠**」が確かに認識されていた。

### 嵯峨天一神社の遷座社伝

同じ佐那河内村の **嵯峨天一神社** は、社伝に：

> 弘仁3年（812年）に **恵穂嶽（えぼしだけ）山頂** にあった社を現在の地に遷した

と明記する。**山頂祭祀 → 山麓遷座** は佐那河内において実在した祭祀パターン。

### 府能の天岩戸別神社との関係

現在、山麓の府能（ふのう）に鎮座する **天岩戸別神社**（祭神：天手刀雄神／天照皇大神／豊受皇大神、別名「三社様」）は、

> **もともと大川原高原の山頂にあった社が遷座した可能性が高い**

と考えられる。王ケ原神宮石碑の傍らに「**天岩戸別神社**」と刻んだ石柱が現存することは、この遷座伝承の物理的痕跡と見ることができる。

### 結論：王ケ原神宮 = 天岩戸別神社の元宮（山頂祭祀地）

- **天嶺（山頂）の天石門別祠**（『阿波志』）
- **王ケ原神宮**（現代の石碑）
- **天岩戸別神社の元宮**（山頂祭祀地）

――これらは **同一の祭祀地** を指している可能性が高い。「**倭総鎮守**」は、この **山頂祭祀の自己認識** が現代に凝結した称号として読むべきもの。

## 🪨 「王ケ原の王」とは誰か

「**倭総鎮守 王ケ原神宮**」が「鎮守」する祭神を、山頂祭祀の主神 = **天手力男命** の系譜で考えると、次の解釈が成立する。

### 『古事記』の決定的記述

> **手力雄命は佐那那縣に坐す**

佐那那縣（さなのあがた）= **佐那河内村**（旧・狭長村）。よって佐那河内山頂の主神は **天手力男命**。

### 平田篤胤の「一神異名」説

天手力男命 = 天石門別神 = 天石門別安国玉主命 = **天背男命**――これら一連の神名はすべて同神の異名であるとする説。これに従えば、

- **王ケ原山頂の主神 = 天手力男命**
- 后神 = **八倉比賣命**（『斎部宿祢本系帳』『古屋家家譜』）
- 御子 = **天日鷲命**（阿波忌部の祖）

→ **王ケ原 = 阿波忌部の祖父神の祭祀地**

### 伊勢神宮内宮の同殿坐神

天手力男神は、伊勢神宮内宮で天照大神と **同殿に祀られる** 二柱のうちの一柱（左方・東・神体は弓）。これほどの地位を持つ神が、佐那河内の山頂にこそ「本拠地」を持っていた――というのが阿波説の世界観。

→ **「倭総鎮守」を称しうる祭神 = 天手力男命**

詳細：[[天手力男命：佐那縣の主神と天岩戸の力業|天手力男命：佐那縣の主神と天岩戸の力業]]

## 🌐 高天原比定論との接続

阿波説研究家 **大杉博氏**（『四国は死国にされていた：大和朝廷の大秘密政策』）は：

> ここは、かつて『**王ケ原**』と呼ばれ、また『**高天原**』とも呼ばれていた

と述べている。

「**高天原**」は神々が住んだ天空の聖域。それが阿波の大川原高原に比定されるとすれば、

- 高天原 = 天津神の本拠
- その「総鎮守」 = ヤマトの根源神
- 称号「倭総鎮守」 = 高天原祭祀の自己認識の現代的表現

という連鎖が成立する。

地形的に見ても、大川原高原は **吉野川下流域・鮎喰川・徳島平野・淡路島まで** を一望できる絶景地で、古代の王権が国土を俯瞰し祭祀を行う **天空の祭祀地** として最適である。

関連：[[佐那河内村大川原高原|佐那河内村大川原高原]]

## 🧩 「倭総鎮守」石碑の歴史的解釈

### 解釈1：近世以降の阿波説運動の産物

刻字が新しく見え、村史にも記載がないことから、近世〜現代の **阿波説支持者** が建立した可能性。だが、設置者・経緯が一切記録されていない点は逆に不自然で、「**地元の何らかの伝承を踏まえて建てられた**」可能性も否定できない。

### 解釈2：忘却された山頂祭祀の記憶

『阿波志』の「中邊村天嶺」記述、嵯峨天一神社の山頂遷座社伝、そして大川原高原を「王ケ原」と呼ぶ口伝――これらの **山頂祭祀の記憶** が、近代になって「倭総鎮守 王ケ原神宮」という石碑として結晶した可能性。

### 解釈3：神武以前の祭祀王権の刻印

阿波説の核心仮説：阿波＝原ヤマト＝高天原。神武東征以前の祭祀王権が大川原高原山頂に存在し、それが「**倭の総鎮守**」を称するに値する地位を持っていた、という見方。

## ⚠ 倭大國玉神大國敷神社との混同を避ける

本石碑「倭総鎮守 王ケ原神宮」と、延喜式内社「倭大國玉神大國敷神社」は **明確に分けて考える必要がある**。

| 比較項目 | **王ケ原神宮（石碑）** | **倭大國玉神大國敷神社** |
|---|---|---|
| 所在 | 名東郡 **佐那河内村** 大川原高原山頂 | 美馬郡（**美馬市脇町拝原** / 美馬市美馬町ほか） |
| 文献記載 | **村史等になし**（現代の石碑のみ） | **延喜式神名帳（927年）** に明記 |
| 社格 | 神社としての実体なし | 延喜式内社（**全国唯一**「倭」を冠する） |
| 祭神 | 不詳（山頂祭祀＝天手力男命の可能性） | 倭大国魂命・大國敷命 |
| 文脈 | 佐那河内の **山頂祭祀**（天嶺＝天石門別祠）／『古事記』の佐那縣 | 崇神紀の **天皇大殿祭祀**／国譲り以前のヤマト国魂 |
| 周辺氏族 | 阿波忌部の祖父神（天背男命の系譜） | 阿波忌部の居住地（拝原東遺跡、神紋＝梶葉紋） |
| 称号 | 「倭**総鎮守**」（独自） | 「倭**大國玉**」「倭**大國敷**」（国魂・国敷） |

両者の共通点は「**阿波が『倭』の起源を主張する文脈**」に位置することだが、

- 王ケ原神宮：**山頂祭祀＝祭祀王権の聖域** の文脈
- 倭大國玉神大國敷神社：**崇神朝の大殿祭祀＝国家祭祀の根源** の文脈

と、阿波説の中でも **別系統の論証ルート** に属する。**両者を統合した「阿波＝倭」論を構築しようとする場合は、それぞれの文脈を保ったうえで接続を論じるべき** であり、安易に同一視すべきではない。

## まとめ：「倭総鎮守」石碑が証言するもの

「倭総鎮守　王ケ原神宮」――この石碑は、

1. **延喜式内社ではない**（社殿も由緒もない）
2. **山頂祭祀（天嶺＝天石門別祠）の文脈** に位置する
3. **天手力男命系の祭祀地** としての佐那河内山頂を象徴する
4. 倭大國玉神大國敷神社（美馬郡）とは **独立の存在**

近代に建立された石碑かもしれない――だがそれが **大川原高原山頂** に、**「倭」**（最古層の表記）で、**「総鎮守」**（最上位の称号）を冠して立っているという事実そのものが、

- 佐那河内における **山頂祭祀の長い記憶**
- 『阿波志』の「天嶺鎮守」伝承
- 嵯峨天一神社の遷座社伝
- 『古事記』の「手力雄命は佐那那縣に坐す」

という重層的な根拠を、現代に再喚起している。「倭総鎮守」は **称号としては不釣り合いに巨大** だが、その巨大さこそが、佐那河内山頂祭祀の本来の規模を示唆していると見るのが、阿波説の立場である。
