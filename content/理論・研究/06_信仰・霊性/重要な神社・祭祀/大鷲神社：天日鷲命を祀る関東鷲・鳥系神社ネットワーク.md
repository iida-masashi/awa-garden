# 大鷲神社：天日鷲命を祀る関東鷲・鳥系神社ネットワーク

← ポータルへ戻る

> [!summary] 要旨
> **大鷲神社（おおとり／おおわし）** および同系統の **鷲神社・鷲宮神社・大鳥神社** は、**阿波忌部の祖神・天日鷲命** を本来の祭神とする関東広域の祭祀ネットワーク。**酉の市** で全国的に知られる東京・浅草の鷲神社、**鷲の総本社** 鷲子山上神社（栃木・茨城県境）、印旛沼沿岸の酒々井大鷲神社など、関東に圧倒的多数が分布する。現在の社伝では **日本武尊** を祭神とするものが多いが、阿波説および古樹紀之房間の研究では **「後世の訛伝で、本来の祭神は天日鷲命」** と読む。本ノートは関東のワシ・トリ系神社を阿波忌部東遷の祭祀ネットワーク再構築の物証として総合する。

## 2. 天日鷲命と「鷲」の名の由来

### 鷲神社（東京都台東区千束）の社伝

最も有名な「**おとりさま**」こと **浅草鷲神社** の社伝に、「鷲」の名の由来が明記される：

> 天照大御神が天之岩戸にお隠れになり、天宇受売命が岩戸の前で舞われた折、**弦（げん）という楽器を司った神様** がおられた。天手力男命が天之岩戸をお開きになった時、**その弦の先に鷲がとまった** ので、神様達は **世を明るくする瑞象を現した鳥** だとお喜びになり、以後、この神様は鷲の一字を入れて **鷲大明神、天日鷲命** と称される様になった。

→ 天日鷲命の本質は **岩戸開きの祭祀神**。「鷲」の名は岩戸開きの **吉祥瑞鳥** に由来する。

## 4. 阿波忌部の東遷ルートと祭祀ネットワーク

### 4-1. 古樹紀之房間「天鳥船神の実体」より核心引用

研究サイト「古樹紀之房間」の重要な指摘：

> 那珂郡には **阿波郷の地名** も見えるが、このあたりには、少彦名神・**天日鷲翔矢命の後裔で安房忌部の同族たる衣服氏族の倭文連・長幡部一族** が繁衍し、**静大社や鷲子山上神社などを奉斎した**。

> **「大鳥・大鷲」を名乗る神社の祭神が日本武尊とされるものがあるが、これは後世の訛伝**

→ **大鳥・大鷲神社の祭神は本来 → 天日鷲命**。日本武尊は中世以降の合祀。

### 4-2. 利根川下流域の阿波忌部痕跡

> 利根川下流域の両総・安房あたりから武蔵・下野にかけての地域には、**フサ（総）、麻生（常陸国行方郡）、結城（木綿キで、木綿を作るカヂの生える地）等々の麻・衣服関係の地名** が多く見える。

> 麻生は『常陸風土記』行方郡条に見える古い地名であり、**大麻神社が鎮座**する。現在の祭神は天太玉命とも、武甕槌神・経津主神などともするが、**おそらく安房忌部の祖・大麻比古命（天日鷲命の子）が本来の祭神** ではなかろうか。

→ **「麻・衣服関係の地名 + 鷲神社（天日鷲命） + 大麻神社」** の三点セットが、利根川下流域から武蔵・下野までを覆う。

### 4-3. 横浜市都筑区杉山神社の創建譚

神奈川県横浜市の **杉山神社** には決定的な創建譚がある：

> 天武天皇白鳳3年に **安房神社神主の忌部勝麿呂** が御神託によって、武蔵国の杉山の岡に **高御産日命・天日鷲命・由布津主命（阿八別彦命）** の三柱を祀った。

→ 武蔵国の杉山神社系（南西部に式内社含めて多数分布）は **安房忌部の支族が奉斎** したと判明。**由布津主命（阿八別彦命）＝天日鷲命の孫・忌部氏の祖** が祭神に含まれる。

## 4-bis. 茂原「鷲妙見大菩薩」と酉の市の真の起源

### 茂原市鷲巣の「鷲妙見大菩薩」顕現

千葉まほろば神社（chiba_jinja）の調査による、**酉の市の真の起源**：

| 年 | 場所 | 出来事 |
|---|---|---|
| **1265年（文永2）** | **千葉県茂原市鷲巣** | 日蓮聖人が小早川内記の藻原（もはら）鷲巣の邸宅で国家平穏を祈ると、**明星（金星）が動き出し「鷲妙見大菩薩」が顕現**。この日が **11月酉の日** |
| 1277年 | 茂原市鷲巣 | 大本山 **長國山 鷲山寺**（じゅせんじ）開山 |
| 1630年 | 東京・鳥越町 | 鷲山寺の日乾上人が末寺「**鷲在山 長國寺**」開山 |
| 1669年 | 東京・浅草 | 長國寺が浅草に移転 |
| 1689年 | 茂原 | **茂原鷲神社（おおとりじんじゃ）創建** |
| 1771年 | 茂原→浅草 | 「**鷲に乗った妙見の像**」が茂原から浅草長國寺へ移される |
| 1869年（明治2） | 東京・浅草 | 神仏分離に伴い「鷲に乗った妙見の像」を祭神に **浅草鷲神社** を建設 |

→ **酉の市の真の発祥は茂原市鷲巣**（千葉県）。江戸の浅草はその江戸進出形である。

### 「鷲巣」の地名と忌部氏

茂原市鷲巣は、日蓮聖人が「鷲妙見大菩薩」を顕現させる以前から **「鷲巣」という地名** だった（『千葉県長生郡郷土誌』P188）。

近隣4kmに **忌部氏祖神「天太玉命」を祀る2社** が鎮座：
- **安房洲神社**（茂原市国府関）
- **國府里神社**（茂原市国府里）

→ 「**天太玉命は天日鷲命の上司**」。当地は **忌部氏が開拓した地域** で、「鷲巣」の地名は **天日鷲命の祖神祭祀** に由来した可能性が高い。日蓮聖人は **在来の天日鷲命信仰** と **妙見信仰** を融合させ「鷲妙見大菩薩」を顕現させた。

### 神武東征「酉の日」起源説

石川修道『宗祖生国の先住者─安房に移住した阿波忌部族の動向について』からの重要引用：

> **神武天皇の持つ弓の先に止まっている黄金に輝く鳥（金鵄）が、神武帝を先導した天太玉命と天日鷲命** である。つまり **忌部の象徴** なのである。その「大鷲（おおとり）」が日蓮法華宗の妙見信仰と結びついて発展したのが「鷲（わし）妙見」である。
>
> 茂原にある鷲宮神社と法華宗本門流の本山・鷲山寺である。その分身で有名なのが、浅草「酉（とり）の市」である。**阿波忌部族による神武東征の出発日が「酉の日」によるもの** である。

→ **酉の市の「酉の日」の真の起源は、阿波忌部族が神武東征に出発した日**。これは記紀の **金鵄（きんし）伝説** ＝ **天太玉命・天日鷲命の忌部祖神** という解釈と直結する。

### 5-1. 浅草鷲神社の社伝

浅草鷲神社の社伝の後半：

> 後に **日本武尊が東夷征討の際、社に立ち寄られ戦勝を祈願** し、志を遂げての帰途、社前の松に武具の「**熊手**」をかけて勝ち戦を祝い、お礼参りをされた。その日が **十一月酉の日** であったので、この日を鷲神社例祭日と定めたのが酉の祭、「**酉の市**」である。

→ 日本武尊の戦勝祈願は **後世の追加伝承**（江戸期に整序）で、もとは天日鷲命の祭祀地。

### 5-2. 阿波説的解釈

阿波説的解釈では、酉の市の本質は：

| 要素 | 阿波説の読み |
|---|---|
| **11月酉の日** | 天日鷲命（鷲＝鳥＝酉）の祭日。木綿・麻の収穫祭の時期 |
| **熊手** | 麻・穀の収穫具を起源とする祭具 |
| **「おとりさま」** | 「大鳥」と「鷲」の重層、本質は天日鷲命 |
| **商売繁盛・開運の御神徳** | 天日鷲命の「開拓・殖産・開運」職能の中世以降の発展形 |

→ 江戸期の商業発達期に、**阿波忌部の祖神祭祀が商売繁盛の都市祭祀に転換** したのが酉の市の実像。

### 5-3. 日本武尊の東征と忌部

下野国 **鷲宮神社**（栃木市都賀町家中）の社伝：

> 御祭神の天日鷲命は、別名を **天日鷲翔矢命** と申し、阿波（徳島県）忌部氏の遠い祖先で、楮（こうぞ）、麻を植えて製紙、紡績の業を興し、皇祖天照大御神が天磐屋に御隠れになった時、白和幣を作り神々と共に祈祷せられ、磐戸開きに大きな功績をあげられた神様。
>
> その後、**日本武尊の東征の際に東国治定や開発の為、日本武尊と共に三浦半島を経て船で安房国（千葉県）に移って来た忌部氏** が、**利根川を上るようにして東国を開発** していくのに伴い、天日鷲命も広く祀られていった。
>
> **弓削連（ゆげのむらじ）の祖** でもある天日鷲命は、東国武士等に **弓矢を作り始めた神様、武道守護の神様** としても篤く崇敬されていた。

→ 日本武尊の東征伝承は **阿波忌部の東国展開ルートを正史化** したフレーム。実態は **天富命率いる阿波忌部の利根川流域開拓**。

## 10. 阿波説における意義

### 10-1. 関東祭祀ネットワークの本貫証拠

関東に集中する **数百社のワシ・トリ系神社** は、阿波忌部の東遷後の祭祀ネットワーク再構築の物的証拠：

| 観点 | 内容 |
|---|---|
| **分布の集中性** | 関東〜南東北の太平洋沿岸軸に圧倒的に集中 |
| **地名との連動** | フサ・麻生・結城など麻関連地名と重なる |
| **同系統社の総本社性** | 鷲子山上神社・鷲宮神社・浅草鷲神社など |
| **祭神の重層構造** | 表面：日本武尊 → 本質：天日鷲命 |

### 10-2. 「日本武尊」フレームの解読

関東の **「大鳥・大鷲」を名乗る神社の祭神が日本武尊とされるもの** は、阿波説的には：

1. **古層**：阿波忌部祖神・天日鷲命の祭祀
2. **中層**：日本武尊東征伝承による正史化（記紀以降）
3. **新層**：江戸期の酉の市文化による商業神化

→ 関東の祭祀史を読み解く **「三層構造」モデル** の典型例。

### 10-3. 三軸構造：海岸軸・利根川軸・山地軸

阿波忌部の関東祭祀ネットワークは三軸構造：

| 軸 | 起点 | 中継 | 終点 | 性格 |
|---|---|---|---|---|
| **海岸軸** | 安房神社 | 鴨川滝口神社 | 浅草鷲神社 | 黒潮海運 |
| **利根川軸** | 麻賀多神社 | 大鷲神社（印旛圏）| 大杉神社（稲敷阿波） | 内陸水運 |
| **山地軸** | 鷲子山上神社 | 鷲宮神社（埼玉） | 福島県内の鷲・日鷲神社 | 山岳・和紙業 |

→ 三軸全てに **天日鷲命の祭祀** が貫流している。

### 10-4. 弓削連と武道祭祀

天日鷲命は **弓削連（ゆげのむらじ）の祖** でもあり、東国武士による篤い崇敬：

- **弓矢を作り始めた神様**
- **武道守護神**
- 鷲宮神社の **「武蔵国総社」的位置**
- 鷲は **武勇の象徴鳥**

→ 関東武士団（鎌倉・室町）の崇敬基盤は、本来は阿波忌部の **弓削連系統の武具祭祀** にあった可能性。

## 15. 留保（中立的併記）

> [!warning] 注意
> - 「**大鳥・大鷲神社の本来の祭神は天日鷲命**」とする読みは、古樹紀之房間および阿波説論者の解釈で、現在の神社本庁公式祭神（日本武尊が多数）とは異なる
> - **酉の市の起源を天日鷲命の祭日に求める論** は、浅草鷲神社の社伝にも日本武尊の故事として記される。阿波説的読み替えは可能だが、本来の祭神確定は文献的に証明困難
> - 鷲子山上神社の「阿波忌部関東開発拠点」由緒は、後世編纂の地誌（『和紙の里』）に依拠する。中世以前の文献的裏付けは限定的
> - 横浜杉山神社の創建譚（白鳳3年、安房神社神主・忌部勝麿呂による）は、社伝・地誌レベルの伝承であり、史実性は議論の余地がある
> - 「**日本武尊東征は阿波忌部東遷の正史化フレーム**」とする解釈は阿波説特有で、通説の日本武尊東征伝承とは異なる読み
> - 関東の鷲・鳥系神社の **数百社の分布**は事実だが、すべてを阿波忌部東遷で説明する単一因モデルは慎重に扱う必要がある
> - 本ノートのevidence_typeは "shrine_origin"、confidence は3（中位）— 個別神社ごとに論点強度は異なる
