# 天石門別豊玉比賣神社：母を継ぐ娘神と海洋王権

延喜式神名帳（927年）に「**阿波国 名方郡 天石門別豊玉比売神社**」と記された式内社。**「天石門別」を冠する三社**（天石門別八倉比賣神社・天石門別豊玉比賣神社・土佐 天石門別安國玉主天神社）の一つで、**豊玉姫**（神武天皇の祖母）系の祭祀と **天石門別神**（天手力男命）系の祭祀が交差する、阿波説における重要な神社。

延喜式神名帳全2861社中、**豊玉姫の名を冠する神社は阿波国の二社のみ**：
- **阿波国 名方郡 和多都美豊玉比賣神社**（雨降神社）
- **阿波国 名方郡 天石門別豊玉比売神社**（春日神社境内社・元 徳島城跡竜王神社）

天皇家と深いかかわりのある豊玉姫の式内社が **阿波にしか存在しない** という事実は、阿波説の核心的物証である。

## 📜 全国唯一性――豊玉姫式内社が阿波にしかない事実

豊玉姫命は、**海神 大綿津見の娘**。初代神武天皇の祖父・**彦火火出見尊**（山幸彦）の妻で、**鸕鶿草葺不合尊**（うがやふきあえずのみこと）を産み、その子が神武天皇となる、皇室直系の祖母神である。

これほどの皇統に直結する神格を冠する **延喜式内社が阿波国にのみ二社存在** することは、阿波説的に決定的な意味を持つ：

- 通常、皇祖関係神の式内社は **大和・伊勢・日向** などに集中する
- 「豊玉姫」を冠する社が **阿波だけ** にあるのは、**豊玉姫の祭祀の起源が阿波** であった可能性を示唆
- 神武天皇の出生に関わる神格群（彦火火出見・豊玉姫・鸕鶿草葺不合・神武）の祭祀地が阿波に集中するなら、**天孫降臨の地は阿波** とする阿波説の根幹と整合

## 🏛 現比定地：眉山町大滝山・春日神社境内

天石門別豊玉比売神社は、徳島市眉山町大滝山にある **春日神社の境内** にある。鳥居も社殿も立派な春日神社の **鳥居左手にひっそりと建つ祠** が天石門別豊玉比売神社。

### 祠横の説明書き（核心引用）

> 豊玉比売神社の御祭神は **天石門別豊玉比売** であります。此の神は「古事記」神代記物語中、実に多くの頁を費やし、種々の寓話を述べられている **大女王** です。そのにまた **神武天皇の出生に連なる山彦、海彦** も記しています。わが国天皇家生の歴史は **この海人族の大女王を無視しては成立しません**。
>
> **山幸彦は倭城（現脇町）の住人** です。隠国といわれ、倭は言挙げせぬ国などと称され、発言を封じられていた阿波国ですが事実の前にはさからえなかったのでしょう。
>
> 醍醐天皇の御代に定められた延喜式神名帳では、日本国内で **阿波一国にのみ奉祀** せられています。
>
> 日孁命と同様、**天石門別豊玉比売が豊日孁命の殯宮**、同じく式内社綿津見豊玉比売神社が「古事記」海幸彦、山幸彦の物語中に出てくる **龍王宮の宮殿跡** を社地として祀られています。
>
> わが国の国始めの基礎を不動のものとしたこの大女王の神名の上に「**天石門別**」と延喜式で記されています。はるか太古、神々の物語時代から **天石門の外界に現れた** の意味で、この神より後 **人皇の歴史** となってきます。**倭国天皇の皇統に君臨するのが日孁命、豊日孁命** であることが歴然としています。

→ この説明書きは阿波説の中核を平然と語っている：

1. **山幸彦（彦火火出見尊）は美馬郡脇町（倭城）の住人**
2. 天石門別豊玉比売神社は **豊日孁命の殯宮**（葬礼地）
3. 和多都美豊玉比売神社（雨降神社）は **龍王宮の宮殿跡**
4. **倭国天皇の皇統＝日孁命（卑弥呼？）・豊日孁命（壹与？）**

### 元社地：徳島城跡・竜王神社

天石門別豊玉比売神社はもともと **徳島城跡にあった竜王神社** に祀られていたと伝わる。徳島城跡には「**竜王さんのクス**」と呼ばれるクスノキがあり、かつて100mほど離れたところに **竜王神社** があったことに由来する。

豊玉姫が **龍の姿で鵜茅不合葺命を産む**（『日本書紀』）という神話と、龍＝雨乞いの霊獣という民俗信仰から、豊玉姫を祀る社が **「竜王神社」** と呼ばれていた。

#### 「雨降（あまたらし）」の語源論

雨降神社は元「**雨降大明神**」と呼ばれた。近くに池があり、雨乞いをすれば必ず雨が降ったと伝わる。

> 「**雨降（あまたらし）**」は、もともと「**天足（あまたらし）**」（古事記では「**天帯**」）と記されていたのではないか？

「たらし」は古代天皇の和風諡号に頻出する重要語：

- 第5代孝昭天皇の子：**天足彦国押人命**（あまたらしひこ）
- 第6代孝安天皇：**日本足彦国押人**（やまとたらしひこ）
- 第12代景行天皇：**大足彦忍代別**（おおたらしひこ）
- 第13代成務天皇：**稚足彦**（わかたらしひこ）
- 第14代仲哀天皇：**足仲彦**（たらしなかつひこ）
- 神功皇后：**気長足姫**（おきながたらしひめ）
- 母 世襲足媛命（よそたらしひめ）

→ 「**たらし**」は皇統の聖性語。雨降＝天帯＝天足＝**皇統に連なる聖性を帯びた地名** と読み直せる。

### 「おきつとり加毛度久斯麻」――豊玉姫の所在地

『古事記』海幸山幸段：彦火火出見尊が鸕鶿草葺不合尊を産んだ豊玉姫が去るときの歌：

> **おきつとり　加毛度久斯麻（かもどくしま）に　わがいでし　いもはわすれじ　よのことごとに**
>
> （原文：意岐都登理 加毛度久斯麻邇 和賀韋泥斯 伊毛波和須禮士 余能許登碁登邇）

通説：「沖にいる鴨の着く島」と訳す。

#### 阿波説の読み替え

「**おきつとり**」は **鴨につく枕詞**。枕詞は地名・人名にかかる修辞であるから、

> 「おきつとり」は鴨ではなく、「**加毛度久斯麻**」という地名にかかる枕詞

として読み、**「かもとくしま」** ＝ **「賀茂の徳島」** と解釈する。

#### 根拠

- 阿波の **名方郡には賀茂郷** があった
- 当時、**吉野川河口には多くの島** があった
- 徳島の地名は天正13年（1585年）に蜂須賀家政が命名したとされ、「**とくしま**」という島が吉野川三角州に存在
- 美馬郡にいた山幸彦（彦火火出見尊）が **吉野川を下って** 豊玉姫に会いに来ていた

→ **彦火火出見尊と豊玉姫が出会った場所＝賀茂の徳島**＝阿波吉野川河口域。

## 🔀 「天石門別豊玉比賣」の祭神論――三層解釈

awa-otoko 氏（『天手力男神の系譜：異名同神・天石門別豊玉比賣は誰なのか？』）は、天石門別豊玉比賣の祭神について次のような階層的解釈を示す：

### 祭神の三世代モデル

```
第一世代：天手力男神（＝天石門別神＝高皇産霊系の祖父神）
              ┃
第二世代：栲幡千千姫命（＝大宜都比売命＝大粟姫＝卑弥呼）
              ┃        ＝「天石門別八倉比賣」
              ┃        （父・天石門別の御称を継承）
              ┃
第三世代：玉依姫命（＝壹与＝稚日女尊＝豊受皇大神）
                       ＝「天石門別豊玉比賣」
                       （祖父・天石門別の御称を継承）
```

### awa-otoko の核心主張

> **豊玉比賣命とは手力男神の子である大宜都比売命の娘たる神**。壹与（トヨ）を当て字にした「**豊**」、玉依姫命の「**玉**」、そして手力男神の系譜を受け継いだ姫としての御名「**天石門別**」。全てを併せた諱（いみな）が「**天石門別豊玉比賣命**」なのです。

→ つまり「**天石門別豊玉比賣**」は **個人の固有名ではなく、系譜的称号**：

- **天石門別**：祖父・天手力男神の御称（父系継承）
- **豊**：壹与（トヨ）の当て字
- **玉**：玉依姫の「玉」
- **比賣**：女神の意

→ **「天石門別系の血を引く、壹与＝玉依姫」** という意味の諱。

### 大日孁命と豊日孁命の関係

説明書きが示す：

- **日孁命**（おおひるめ）：天石門別八倉比賣命＝大宜都比売命＝**卑弥呼**
- **豊日孁命**（とよひるめ）：天石門別豊玉比賣命＝玉依姫＝**壹与**

> 大日孁神（卑弥呼）の後を継いだ稚日女神（壹与）は、天石門別八倉比賣（大宜都比売命）の後を継いだ天石門別豊玉比賣（玉依姫命）の **母と子の間柄** になる

→ つまり、

```
天石門別八倉比賣（大宜都比売命＝卑弥呼）  
     ↓ 母娘継承
天石門別豊玉比賣（玉依姫命＝壹与）
```

という **邪馬台国の女王継承** を、二社の式内社が祭祀構造として保存しているという主張。

→ 出典：awa-otoko（2016-09-19）天手力男神の系譜：異名同神・天石門別豊玉比賣は誰なのか？ （[出典](https://awa-otoko.hatenablog.com/entry/2016/09/19/184922)）

## 🌊 「天石門別」を冠する三社の体系

延喜式神名帳全2861社中、「**天石門別＋神名**」となっているのは、阿波・土佐の **3社のみ**：

| 神社 | 国 | 祭神 | 系譜的位置 |
|---|---|---|---|
| 天石門別八倉比賣神社 | 阿波国 名方郡 | 大日孁命（八倉比賣＝大宜都比売） | **母**（卑弥呼？） |
| 天石門別豊玉比賣神社 | 阿波国 名方郡 | 玉依姫命（豊玉比賣＝壹与） | **娘**（壹与？） |
| 天石門別安国玉主天神社 | 土佐国 吾川郡 | 天手力雄命（天石門別＝天背男命） | **父**（祖父神） |

→ この三社は、**天石門別神の血脈** を一つの祭祀体系として保存している。土佐の安国玉主神社は **祖父神**、阿波の八倉比賣神社は **母**、阿波の豊玉比賣神社は **娘**。**阿波・土佐の海洋連環地域に固有の祭祀構造** として読める。

## 🐉 龍宮伝承と海人族

天石門別豊玉比賣神社の元社地が **徳島城跡・竜王神社** であり、和多都美豊玉比賣神社（雨降神社）の説明書きが「**龍王宮の宮殿跡**」と明記する点は重要。

『日本書紀』は豊玉姫が **龍の姿で鸕鶿草葺不合尊を産む** と記す。両社は **海神の宮殿＝海人族の祭祀拠点** として位置づけられる：

### 阿波海人族との接続

- 豊玉姫＝海神 大綿津見の娘
- 彦火火出見尊（山幸彦）＝美馬郡脇町（倭城）の住人
- 雨降神社＝**鮎喰川が吉野川に流れ込む田園地帯**
- 元社地・徳島城跡＝**吉野川河口域**

→ 豊玉姫祭祀は、**吉野川を貫く山幸彦と海幸の海上交通権** を象徴する。これは事代主神＝海人族（→ [[事代主命（エビス）|事代主命]]）の祭祀ネットワークと地理的に重なる。

### 「綿津見豊玉比売神社」の所在

説明書きの「式内社綿津見豊玉比売神社が龍王宮の宮殿跡」――これは現・**雨降神社**（不動西町）を指す。「綿津見＝海神」「豊玉＝海神の娘」の二重表現は、**海洋祭祀の本拠** であることを示す。

## 🧬 阿波における豊玉姫祭祀の系譜的意味

### 神武天皇の祖母としての豊玉姫

```
天孫 邇邇芸命
   ┃
   ┣━━ 彦火火出見尊（山幸彦）  × 豊玉姫（海神綿津見の娘）
   ┃                                ┃
   ┃                                ┗━ 鸕鶿草葺不合尊
   ┃                                        ┃
   ┃                                        ┗━ **神武天皇**
```

→ 豊玉姫祭祀地＝**神武天皇の祖母神の祭祀地**。阿波が **天孫降臨の地** であり、神武東征の **出発点** であった可能性を示唆する。

### 阿波の中心的祭神群との重層

阿波における三女神祭祀の重層構造：

```
天石門別八倉比賣神社（杉尾・気延山）── 大日孁＝大宜都比売命＝卑弥呼？
                                          ↓ 母娘継承
天石門別豊玉比賣神社（春日神社境内）── 玉依姫＝豊玉姫＝壹与？
                                          ↓
和多都美豊玉比賣神社（雨降神社）── 豊玉姫（神武祖母）
```

→ **邪馬台国の女王継承** ＋ **皇室の祖母祭祀** という二重の重要性が、阿波の名方郡に集中している。

## 🏔 山幸彦＝美馬郡脇町（倭城）住人説

説明書きの「**山幸彦は倭城（現脇町）の住人**」という記述は、阿波説の核心仮説の一つを直接的に示す：

- **山幸彦**＝彦火火出見尊＝天孫 邇邇芸命の子＝神武天皇の祖父
- **倭城**＝美馬郡脇町
- 美馬郡＝倭大國玉神大國敷神社の鎮座地＝「倭」を冠する唯一の延喜式内社の地

→ つまり、**天孫降臨の地は美馬郡脇町**、彦火火出見尊が **倭城（脇町）から吉野川を下って徳島城跡（賀茂の徳島）で豊玉姫に出会った**、という地理的物語が成立する。

## まとめ：天石門別豊玉比賣神社が証言するもの

天石門別豊玉比賣神社の存在は、阿波説における次の主張群を支える：

1. **皇統の祖母神（豊玉姫）の式内社が阿波にしかない** ＝ 阿波が天孫降臨と神武出生の舞台
2. **山幸彦が美馬郡脇町の住人** ＝ 倭大国魂神社の鎮座地と接続
3. **「天石門別」を冠する三社の体系** ＝ 父・母・娘の三世代祭祀構造
4. **大日孁（卑弥呼）→豊日孁（壹与）の母娘継承** ＝ 邪馬台国女王継承の祭祀的保存
5. **龍宮伝承＝海人族の祭祀拠点** ＝ 吉野川水運と海上交通権の象徴
6. **天石門別の御称の継承** ＝ 父系の聖性を娘が継ぐ古代祭祀の系譜的構造

「天石門別豊玉比賣」――この6字の社名そのものが、阿波の祭祀王権の系譜を凝縮した諱として、千年以上保存されてきたことの意味は、計り知れない。
