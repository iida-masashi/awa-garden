# 親神社

## 概要
- **読み**: オヤジンジャ
- **意味**: 延喜式神名帳に記された **神名帳社（元の式内社）** に対する、その **本源・親元** にあたる神社の呼称。論社（神名帳社の比定候補となる複数社）が併存する場合、それらの **「親」となる神名帳上の元社** を指す。
- **対概念**: 論社（ろんしゃ）／比定社／里宮

## 用語の位置づけ
本Vaultでは、**templates/論社サブノート.md** において：

```
親神名帳社名: ""
論社元社: "[[親神社]]"
```

という形でテンプレート的に参照される。すなわち：

- **親神社** = 延喜式に名を載せる **本来の神名帳社（元宮）**
- **論社** = その親神社の **比定候補となる現存する複数社**

例：式内社「**多祁御奈刀弥神社**」（阿波国名方郡）には複数の論社候補があり、それらにとっての「親神社」は **多祁御奈刀弥神社という神名帳上の名称** そのものを指す。

## 阿波説における位置づけ
阿波説では、**全国各地の有名神社（諏訪大社・伏見稲荷大社・春日大社・香取神宮・安房神社 等）の親神社（元宮）が阿波に存在する** とする論考が中核を成す：

| 全国の有名社 | 阿波の親神社（元宮比定） |
|---|---|
| 諏訪大社 | [[多祁御奈刀祢神社]]（名西郡石井町） |
| 伏見稲荷大社 | [[上一宮大粟神社]]（神山町神領） |
| 春日大社 | 阿波中臣氏祭祀地群 |
| 安房神社（千葉） | [[大麻比古神社]]（阿波忌部の総氏神） |
| 下鴨神社 | 御蔭神社の阿波元宮 |
| 出雲大社 | 阿波の出雲勢力祭祀圏 |

→ 「**親神社＝阿波の元宮**」という構造は、阿波説の根本論点である **「阿波 = 古代日本祭祀の中心地」** を支える概念装置となる。

## Vault内での運用
論社サブノートを作成する際、`templates/論社サブノート.md` を呼び出すと、本ノート（`[[親神社]]`）への参照が自動挿入される。論社ごとに：

1. その論社の **比定の根拠** を独自部分として記述
2. **親神社（神名帳社）への参照** を明示
3. **同じ親神社を持つ他の論社** へのリンク
4. **親神社の郡別フォルダ** にあるメインノートへリンク

という構造で、論社群を **親神社単位でグループ化** する。

## 補足
本ノートは、`templates/論社サブノート.md` のリンク先として参照される **概念ハブ**。個別の神社ノートを指すものではなく、**「親神社」という用語そのもの** を定義する位置づけ。論社サブノートを実際に作成する際は、`論社元社` のフィールドを **具体的な親神社名（例：[[多祁御奈刀祢神社]]）に書き換える** ことが期待される。
