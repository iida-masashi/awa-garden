# 気延山・眉山 赤色立体地図でわかる古墳群

LiDAR（航空レーザー測量）由来の **赤色立体地図** によって、徳島県の **気延山**・**眉山** 周辺の古墳群が新たに視認可能になった。本ノートは ANYA(203) で取り上げられた赤色地図解析の概要と、阿波説における意義を整理する。

> 📚 関連: [[阿波の核心神社ハブ]], [[氏族×祭祀×地理_統合MOC]]

## 🗺 赤色立体地図とは

| 項目 | 内容 |
|---|---|
| 技術 | **LiDAR**（航空レーザー測量）による高精度標高データ |
| 表現 | 標高の傾斜・凹凸を**赤色濃淡** で立体的に可視化 |
| 利点 | **樹林に覆われた古墳・遺跡** も視認可能 |
| 用途 | 未発見古墳の探索、地形遺跡の発見、城跡・段丘の確認 |

→ 通常の航空写真では見えない **樹林内の埋没遺跡** が次々と発見されつつある。

## 🏛 気延山と古墳群

**気延山（きのべやま）**は徳島市国府町の西方、**天石門別八倉比売神社の背後** にそびえる聖山。

| 項目 | 内容 |
|---|---|
| 標高 | 約212m |
| 中心神社 | **天石門別八倉比売神社**（[[天石門別八倉比売神社]]） |
| 阿波説における意義 | **天照大神（大日孁尊）の真の陵墓**、**卑弥呼の終焉地** 説 |
| 山頂古墳 | **杉尾古墳**（卑弥呼陵候補） |
| 五角形祭壇 | 奥の院の特異な石積祭壇 |

### 赤色地図で見える気延山古墳群
- 山頂の **杉尾古墳**（卑弥呼陵説）
- 周辺の **石棺古墳群**
- 樹林に覆われ通常は見えない複数の **小型古墳**

## 🏔 眉山と古墳群

**眉山（びざん／古名：以乃山）** は徳島市中心部の南、東西に細長い独立山地。

| 項目 | 内容 |
|---|---|
| 標高 | 約290m（最高地点・西峰の毛受ヶ原） |
| 旧称 | **以乃山**（いのやま、「真っ先に出現した山」） |
| 山頂祭祀 | **熔造皇神社**（[[熔造皇神社：八坂神社・祇園信仰の元宮と素戔嗚尊の鉄鋳造祭祀]]） |
| 古墳 | **八人塚古墳**（須佐之男尊の御陵伝） |

### 番号付き古墳の例（ANYA(203) より）
| 番号 | 名称 |
|---|---|
| 31番 | **八人塚古墳**（須佐之男御陵伝） |
| 32番 | セ山 |
| 34番 | 野懐子 |
| その他多数 | 樹林内の埋没古墳 |

→ 赤色地図によって、これまで未認知だった **数十基の古墳** が確認できる。

## 🌐 阿波説における意義

### 1. 古墳発見の新時代
赤色立体地図の登場により、阿波の古墳数は今後 **大幅に増える可能性**。古墳数の増加 = **古代阿波の人口・権力の規模が再評価される**。

### 2. 気延山＝邪馬台国の中心説の補強
気延山一帯に多数の古墳があることは、ここが古代の **王権中心地** であった可能性を強める。

### 3. 眉山＝古代要塞説
山頂部の祭祀地（熔造皇神社）と周辺古墳群は、眉山が単なる聖山ではなく **古代の防衛拠点・要塞** だった可能性も示唆。

### 4. 須佐之男一族の祭祀ネットワーク
- 眉山（八人塚＝御陵）
- 八万町王子祠（息子達）
- 丈六町熊野神社（誓約皇子）

これらが眉山周辺に集中 = **須佐之男一族の阿波本貫**の証拠。
