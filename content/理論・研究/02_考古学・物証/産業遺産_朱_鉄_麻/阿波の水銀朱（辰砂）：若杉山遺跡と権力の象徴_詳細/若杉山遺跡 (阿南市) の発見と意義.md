# 若杉山遺跡 (阿南市) の発見と意義

那賀川を遡り、鷲敷町との境、四国霊場21番札所・**太龍寺（旧称：龍山＝弥山）** の北側に位置する若杉山にある、**日本唯一の弥生〜古墳期辰砂採掘遺跡**。

> 📚 親ノート: [[阿波の水銀朱（辰砂）：若杉山遺跡と権力の象徴]]

## 📊 出土品の構成

### 主要出土物
- **大量の辰砂原石**
- **石杵（いしきね）**：辰砂粉砕用
- **石臼（いしうす）**：辰砂粉末化用
- 弥生時代終末〜古墳時代初頭の **土器**
- **採掘坑跡**

### 全国唯一性の理由
日本各地に「丹生（にゅう）」地名はあれど、**採掘から加工（粉砕・精製）まで連続して行った遺跡は若杉山のみ**。これは：

| 阿波（若杉山） | 他地域 |
|---|---|
| 採掘＋現地加工 | 消費地・流通中継地のみ |
| 朱の生産・流通の中枢 | 朱の輸入・使用 |

→ つまり、**阿波が朱産業の本源**。

## 🔥 採掘技術：火入れ法

2024年確認された **火入れ法（fire-setting）**：
- 岩石に火を当てて加熱
- 水を急激にかけて急冷
- 熱応力で岩石を割る
- 古代ローマ・漢代中国・エジプト等の **世界最新技術**
- 国内記録より **1400年以上早い** 弥生後期の使用例

→ 詳細：[[火入れ法と国際技術交流：徐福伝説との接合]]

## 💎 産業の前史：加茂宮ノ前遺跡

若杉山採掘遺跡の **2000年以上前から、阿波には朱産業の集落** があった：
- **加茂宮ノ前遺跡**（阿南市加茂町、約4000年前＝縄文後期）
- 朱関連遺物 **1000点以上（国内最多）**
- 祭祀遺構300点以上

→ 詳細：[[加茂宮ノ前遺跡：縄文後期からの朱生産]]

## 📈 生産の時代区分

| 時代 | 状態 |
|---|---|
| 縄文後期（約4000年前） | 加茂宮ノ前遺跡で生産集落・祭祀地化 |
| 弥生時代前期〜中期 | （資料少なめ） |
| **弥生時代後期** | **若杉山で大規模採掘・火入れ法導入** |
| **古墳時代前期** | **採掘ピーク、畿内古墳への独占供給**（δ34S分析で確認） |
| 古墳時代中期以降 | 生産規模縮小 |

## 🔬 産地同定の科学的根拠

硫黄同位体比（δ34S）分析により、以下の畿内大型古墳の朱が **若杉山産** と特定：

| 古墳 | 場所 |
|---|---|
| **箸墓古墳** | 奈良県桜井市 |
| **ホケノ山古墳** | 奈良県桜井市 |
| **纒向遺跡周辺古墳** | 奈良県桜井市 |
| その他初期前方後円墳多数 | 西日本各地 |

→ 詳細：[[水銀朱の硫黄同位体比分析と若杉山産地の同定]]

## 🌐 阿波説における意義

### 1. 邪馬台国阿波説の核心物証
『魏志倭人伝』「**其山有丹**」と完全一致。卑弥呼の権力源泉は朱の独占にあった。
→ [[『魏志倭人伝』との整合性]]

### 2. 世界水準の技術圏
弥生時代に既に **古代ローマ・漢代中国と同等の採掘技術**。日本最古の国際技術導入例。

### 3. 経済基盤としての朱
古代において **辰砂は金より高価**。阿波の朱独占は **巨万の富** をもたらした。

### 4. 政治・祭祀的優位
朱は **王権祭祀の最重要物資**。阿波が朱を供給したことは、阿波が **全国の王権祭祀の正当性を握っていた** ことを意味する。
