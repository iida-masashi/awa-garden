# 3. 『魏志倭人伝』との整合性

- **「其山有丹」:** 『魏志倭人伝』には「其の山に丹（朱）あり」と記されている。中央構造線沿いに水銀鉱床が並ぶ阿波は、この記述に完璧に一致する。

## 📐 包括的整合性：邪馬壹國の阿波比定

「其山有丹」だけでなく、魏志倭人伝全体の地理・里程記述が阿波を指す：

| 記述 | 阿波での対応 |
|---|---|
| **其山有丹** | 若杉山辰砂採掘遺跡（本ノート） |
| **周旋可五千餘里** | 徳島県周旋 約396km ≒ 5,150短里（完全整合） |
| **絶在海中洲島之上、或絶或連** | 阿讃山脈＋吉野川流域の二重地形 |
| **女王國東渡海千餘里、復有國、皆倭種** | 徳島県東 → 紀州（和歌山）に倭種の国 |
| **景初2年（238年）の献上品**：銅鏡・真珠・鉛丹・絳青縑・異文雑錦 | 内行花文鏡・海産物・阿波朱・阿波藍染・阿波文字（推定） |
