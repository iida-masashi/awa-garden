# 多良古墳群：海部郡の須佐之男一族王家墓

> [!summary] 要旨
> 徳島県海部郡の多良古墳群（たらこふんぐん）は、古墳時代前期（200〜300年代）の5連古墳群。中でも15号古墳（全長50m）は須佐之男一族の王家の墓とされる説がある。古墳時代前期の構築は3世紀の阿波王権の存在を物的に示し、邪馬台国時代と重なる。近隣の獅井坂神社（旧 祇園社、祭神 須佐之男尊）、福山・島根・徳島を結ぶ「友字地図ライン」、船林神社や貝族の海洋民伝承などとあわせ、阿波説は海部郡を須佐之男一族・海人族の本拠地と位置づける。本ノートは ANYA(154) の調査と意見交換会の内容を整理する。

## 3. 周辺の祭祀・地理

### 3-1. 獅井坂神社（祇園社改名）との関係
多良古墳群の近隣には：

| 神社 | 旧称 | 祭神 |
|---|---|---|
| **獅井坂神社** | **祇園社** | 須佐之男尊 |

→ 獅井坂神社が **祇園社（八坂神社系）から改名** された事実は、**多良古墳群が須佐之男一族の墓** であることを補強する。

### 3-2. 「友字地図ライン」――三地点の直線関係
ANYA(154) で指摘された地理的直線関係：

| 地点 | 関連 |
|---|---|
| 福山（広島県） | 須佐之男系の遺跡・神社 |
| 島根県（出雲） | 須佐之男・大国主祭祀の中心地 |
| 徳島（多良古墳群） | 同神格の祭祀地 |

→ 三地点が **ほぼ直線上** に並ぶ。これは：
- 偶然ではない可能性
- **古代海洋ネットワークの軸線**
- **須佐之男一族の移動・連絡ルート**

の物的痕跡として解釈される。

### 3-3. 貝族と船林神社

- **船林神社**

## 4. 阿波説における意義

### 4-1. 3世紀の阿波王権の物的証拠
古墳時代前期（200〜300年代）の大規模古墳群は、**阿波が邪馬台国時代に既に王権を持っていた** ことの証拠。

### 4-2. 須佐之男一族の阿波本貫

| 阿波の須佐之男系祭祀地 | 内容 |
|---|---|
| **眉山・熔造皇神社** | 鉄鋳造祭祀（八坂神社元宮） |
| **八人塚古墳**（眉山） | 須佐之男御陵伝 |
| **王子祠**（八万町） | 須佐之男の息子達5祠 |
| **熊野神社**（丈六町） | 誓約皇子 |
| **多良古墳群**（海部郡） | 須佐之男一族王家墓 |
| **獅井坂神社**（旧 祇園社） | 須佐之男祭祀 |

→ 阿波に **須佐之男一族の祭祀地が集中** している決定的物証。
