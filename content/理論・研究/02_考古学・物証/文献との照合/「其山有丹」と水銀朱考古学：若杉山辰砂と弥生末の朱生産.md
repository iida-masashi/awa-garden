# 「其山有丹」と水銀朱考古学：若杉山辰砂と弥生末の朱生産

『魏志倭人伝』のわずか四文字「**其山有丹**」（其の山に丹あり）を、阿波の **水銀朱（辰砂・HgS）採掘・精製・流通** の考古学的物証と照合する専門ノート。文字史料と考古遺跡の **一対一対応** が成立する阿波説の中核論点を扱う。

## 1. 倭人伝原文と読み

> **其山有丹**（『三国志』魏書東夷伝倭人条）

- **丹（に）** ＝ 水銀朱（辰砂 HgS）。古代において **王権の象徴・防腐剤・神聖染料** として極めて高い価値を持つ。
- 倭人伝の編者・陳寿は、倭の特産品として「真珠・青玉」と並び **丹** を明記。
- 中国本土でも水銀朱は希少資源であり、「其の山に丹あり」と特記される国は **東アジア全体でも限定的**。

---

## 2. 考古学的物証：若杉山辰砂採掘遺跡（国指定史跡）

阿南市水井町・若杉山中腹（標高 140〜250m）に立地する、**国内唯一の弥生末〜古墳発生期の水銀朱鉱山遺跡**。

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県阿南市水井町 |
| 標高 | 約 140〜250m（山腹採掘） |
| 操業年代 | **弥生時代後期〜古墳時代発生期（1世紀〜3世紀）** |
| 採掘規模 | 露頭辰砂脈の直接採掘＋粉砕加工場（石杵・石臼出土） |
| 国史跡指定 | 2019年10月16日 |
| 倭人伝との時代整合 | 卑弥呼の活動期（2〜3世紀）と完全に重なる |

### 2-1. 操業の物的証拠
- **石杵（いしぎね）・石臼**：辰砂粉砕に使用された加工具が大量に出土
- **辰砂原鉱片**：採掘跡から赤色顆粒が回収
- **住居跡なし**：採掘専従の **作業場型遺跡**。生活拠点は山麓に別途存在

### 2-2. 倭人伝記述との対応
- 「**其山有丹**」 → **若杉山という具体的な山に、丹（水銀朱）が現実に産出していた**。
- 卑弥呼朝貢時期（景初2年・238年）と若杉山操業期が完全一致。

## 3. 加茂宮ノ前遺跡：縄文後期からの朱生産の連続性

徳島県阿南市加茂町の **加茂宮ノ前遺跡** は、**縄文後期から弥生・古墳期にかけての朱生産工房跡** を含む。

| 物証 | 意義 |
|---|---|
| 縄文後期の朱付着土器 | 阿波の朱生産が **若杉山以前から連続** していた証拠 |
| 朱付着石杵・石臼 | 工房型操業の継続 |
| 縄文〜古墳の層位 | **千年単位の朱生産技術蓄積** が阿波に存在 |

→ 阿波の朱は「卑弥呼の時代に突如出現した」のではなく、**縄文以来の伝統技術** であり、倭人伝記述の重みを裏付ける。

## 4. 朱の用途と流通：王権の血液

水銀朱は単なる顔料ではなく、古代王権の **政治・宗教資源**：

| 用途 | 物的痕跡 |
|---|---|
| **古墳石室の朱塗り** | 萩原墳丘墓・寺山古墳ほか阿波の弥生墳墓に朱の使用 |
| **棺内の朱充填** | 邪馬台国期前後の畿内・吉備の前期古墳に阿波産朱が流通した可能性 |
| **神事の朱顔料** | 阿波忌部・秦氏の祭祀における朱の使用 |
| **防腐・防虫** | 木棺・遺体の保存処理 |

→ **阿波が産出地、畿内・吉備が消費地** という構図は、卑弥呼の朝貢時代の交易ネットワークと整合する。

## 5. 「其山有丹」の他説（畿内・九州）との比較

| 比定地 | 弥生末の朱鉱山 | 物的証拠 |
|---|---|---|
| **阿波（若杉山）** | **あり（国指定史跡）** | 採掘跡・石杵・操業年代の一致 |
| 大和（宇陀） | 後代（7世紀以降）の採掘 | 弥生末の操業証拠 **なし** |
| 北九州 | 朱鉱山は確認されず | 朱は輸入（阿波産含む）と推定 |

→ **弥生末に「其山有丹」と書ける国は、考古学的に阿波しかない**。
