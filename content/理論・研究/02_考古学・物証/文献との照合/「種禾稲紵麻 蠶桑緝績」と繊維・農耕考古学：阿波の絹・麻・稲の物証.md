# 「種禾稲紵麻 蠶桑緝績」と繊維・農耕考古学：阿波の絹・麻・稲の物証

『魏志倭人伝』の **「種禾稲紵麻 蠶桑緝績 出細紵縑緜」**（禾稲・紵麻を種え、蚕桑して緝績し、細紵・縑・緜を出だす）を、阿波の **繊維・農耕の考古学的物証** と照合する専門ノート。倭人伝が列挙する **5つの物産** が、阿波忌部・秦氏の伝統産業と一対一対応する点を整理する。

## 1. 倭人伝原文と語釈

> **種禾稲紵麻 蠶桑緝績 出細紵縑緜**（『三国志』魏書東夷伝倭人条）

| 用語 | 意味 |
|---|---|
| **禾稲（かとう）** | 稲（粟稲、または穂状の稲） |
| **紵麻（ちょま）** | 苧麻（からむし／チョマ）。麻繊維の原料 |
| **蠶桑（さんそう）** | 蚕を飼い、桑を植える ＝ **養蚕業** |
| **緝績（しゅうせき）** | 糸を紡ぐ ＝ **製糸・紡績** |
| **細紵（さいちょ）** | 細く上質な麻織物 |
| **縑（けん）** | 上質な絹織物（横糸を密にした絹） |
| **緜（めん）** | 真綿・絹綿（繭から取った絹綿） |

→ 倭人伝は倭国を **「絹と麻の両方を高度に生産する国」** として記述。この組み合わせは弥生末の日本列島内で **限定的な国にしか成立しない**。

## 2. 麻（紵麻）：阿波忌部の中核産業

### 2-1. 麁服（あらたえ）の伝統
阿波の **麻栽培と織物** は、大嘗祭の **麁服（あらたえ）** として現代まで連続している、文献史料上もっとも長い伝統を持つ。

| 物証・記録 | 内容 |
|---|---|
| 麁服貢進 | 大嘗祭において阿波忌部のみが麻織物（麁服）を貢進する権限を独占 |
| 木屋平の麻栽培 | 美馬市木屋平の麻畑が現代まで残存 |
| 古代麻織機関連遺物 | 阿波内の弥生〜古墳遺跡から紡錘車が多数出土 |

→ 倭人伝「**紵麻**」「**細紵**」と完全一致。
- 関連: [[阿波の麻（忌部）：大嘗祭と東国開拓の源流]]
- 関連: [[阿波忌部の産業：麁服と麻・穀・紙の伝統]]

### 2-2. 麻と忌部氏
- 麁服貢進は **阿波忌部の特権**。記紀・延喜式・大嘗祭次第式に明記。
- 忌部の麻祭祀 → 卑弥呼の祭祀王体制と接続可能。

## 3. 絹（縑・緜）：阿波秦氏と養蚕

### 3-1. 秦氏と養蚕技術
阿波には **秦氏** の濃密な分布があり、養蚕・絹織物の技術導入が伝承される。

| 地名・神社 | 関連 |
|---|---|
| 秦河勝・忌部秦氏 | 阿波忌部と秦氏の融合氏族（[[阿波秦氏と鉱山開発：四国の水銀朱と東大寺大仏]]） |
| 機織神社 | 阿波内の機織神社・倭文神社の分布 |
| 倭文部（しとり） | 阿波の倭文部による文織物（縞織物）の伝統 |

→ 倭人伝「**蠶桑緝績**」「**縑緜**」と整合。

### 3-2. 倭文（しとり）と倭文神社
- **倭文神社**（阿波・板野郡）— 倭文部の祖神を祀る式内社
- 倭文部 ＝ 古代の **染織技術者集団**
- 関連: [[阿波忌部の産業：麁服と麻・穀・紙の伝統]]

## 4. 稲（禾稲）：阿波の弥生農耕

### 4-1. 吉野川流域の弥生水田
- 吉野川下流域の弥生遺跡群（鮎喰川流域・矢野遺跡など）から **水田跡・炭化米** が出土
- 弥生中期〜後期の **大規模水稲耕作** が阿波平野で行われていた物的証拠

### 4-2. 戸数七万戸との整合
- 倭人伝は邪馬壹國を **七万余戸** と記す
- 吉野川流域の弥生農耕生産力は、この規模を支える唯一の候補地の一つ
- 関連: [[邪馬壹國の中心地と卑彌呼の宮室・統治体制]]

## 5. 「絹＋麻＋稲」三位一体の生産国

倭人伝の物産記述は、単に **個別の物産** を並べたのではなく、**「絹と麻と稲を同時に高度生産する国」** として倭を描写している。この条件を弥生末で満たすのは：

| 候補地 | 絹（養蚕） | 麻（麁服級） | 稲（大規模水田） |
|---|---|---|---|
| **阿波** | **秦氏・倭文部** | **忌部の麁服伝統** | **吉野川流域水田** |
| 北部九州 | 養蚕痕跡限定 | 麻織伝統限定 | 水田あり |
| 畿内 | 弥生末の養蚕証拠少 | 麻織痕跡限定 | 水田あり |

→ 三要素を **同時に・最高水準で** 満たすのは阿波のみ。

## 6. 風俗記述との整合

倭人伝には繊維・農耕に続いて、海人族風俗の記述がある：

> **男子無大小 皆黥面文身** … **今倭水人 好沈没捕魚蛤**

→ 阿波の **海人族（安曇・海部・那賀）** の風俗と一致。繊維・農耕国 ＋ 海人族風俗 ＝ 阿波の地形（吉野川平野＋紀伊水道沿岸）と完全整合。
