# 多良古墳群：海部郡の須佐之男一族王家墓

徳島県海部郡の **多良古墳群（たらこふんぐん）** は、古墳時代前期（200〜300年代）の **5連古墳群**。中でも **15号古墳**（全長50m）は **須佐之男一族の王家の墓** とされる説がある。本ノートは ANYA(154) の調査と意見交換会の内容を整理する。

> 📚 関連: [[氏族×祭祀×地理_統合MOC]], [[阿波説タイムライン]]

## 📜 多良古墳群の概要

| 項目 | 内容 |
|---|---|
| 所在地 | 徳島県海部郡（海陽町・牟岐町近辺） |
| 規模 | **5連の前方後円墳**および周辺古墳 |
| 時代 | **古墳時代前期（200〜300年代）** |
| 15号古墳 | 全長 **50m**、徳島県最難の前方公園分 |
| 阿波説の比定 | **須佐之男一族（または大国主系）の王家墓** |

### 多良古墳群の重要性
- 古墳時代 **前期** の構築 → **3世紀**の阿波王権の存在を物的に証明
- 邪馬台国時代と重なる → 阿波王権 = 邪馬台国候補
- **海部郡** という海洋交通の要衝に立地

## 🏯 獅井坂神社（祇園社改名）との関係

多良古墳群の近隣には：

| 神社 | 旧称 | 祭神 |
|---|---|---|
| **獅井坂神社** | **祇園社** | 須佐之男尊 |

→ 獅井坂神社が **祇園社（八坂神社系）から改名** された事実は、**多良古墳群が須佐之男一族の墓** であることを補強する。

## 🗺 「友字地図ライン」――三地点の直線関係

ANYA(154) で指摘された地理的直線関係：

| 地点 | 関連 |
|---|---|
| 福山（広島県） | 須佐之男系の遺跡・神社 |
| 島根県（出雲） | 須佐之男・大国主祭祀の中心地 |
| 徳島（多良古墳群） | 同神格の祭祀地 |

→ 三地点が **ほぼ直線上** に並ぶ。これは：
- 偶然ではない可能性
- **古代海洋ネットワークの軸線**
- **須佐之男一族の移動・連絡ルート**

の物的痕跡として解釈される。

## 🐚 貝族と船林神社

多良古墳群周辺には：
- **船林神社**
- **貝族（かいぞく？）** と呼ばれる海洋民族の伝承

→ 海部郡が **海人族（海部氏など）の本拠地** であったことの間接証拠。

## 🌐 阿波説における意義

### 1. 3世紀の阿波王権の物的証拠
古墳時代前期（200〜300年代）の大規模古墳群は、**阿波が邪馬台国時代に既に王権を持っていた** ことの証拠。

### 2. 須佐之男一族の阿波本貫
| 阿波の須佐之男系祭祀地 | 内容 |
|---|---|
| **眉山・熔造皇神社** | 鉄鋳造祭祀（八坂神社元宮） |
| **八人塚古墳**（眉山） | 須佐之男御陵伝 |
| **王子祠**（八万町） | 須佐之男の息子達5祠 |
| **熊野神社**（丈六町） | 誓約皇子 |
| **多良古墳群**（海部郡） | 須佐之男一族王家墓 |
| **獅井坂神社**（旧 祇園社） | 須佐之男祭祀 |

→ 阿波に **須佐之男一族の祭祀地が集中** している決定的物証。
