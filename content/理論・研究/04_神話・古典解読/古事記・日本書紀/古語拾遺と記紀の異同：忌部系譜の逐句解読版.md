# 古語拾遺と記紀の異同：忌部系譜の逐句解読版

> [!summary] 要旨
> 『古語拾遺』（807年・斎部広成）と『古事記』（712）・『日本書紀』（720）の記述を、**忌部の祖神系譜・忌部の祭祀職能・神武朝の忌部組織化**に絞って **逐句的（passage by passage）** に対比する。各段について「古語拾遺の原文 → 古事記本文 / 書紀本文 / 書紀神代一書の対応状況」を並べ、**古語拾遺にのみ現れる記述（＝「拾遺」の名の由来）** を特定する。斎部広成が記紀に「拾い遺された」と訴えた事項の大半は、**忌部の祖系譜・職掌・地方分掌**に関わるものであった。本ノートは [[古語拾遺_阿波説解釈]] の §7（記紀異同の一覧表）の **逐句精密版** であり、神話全体の祭祀構造は [[天岩戸神話の記紀解読版：阿波の祭祀構造]] に、阿波説の論拠本体は [[阿波説の根幹]] に委ねる。

> [!info] 本ノートの史料的立場
> - **古語拾遺**は [[古語拾遺_原文と読み下し]] の本文（西宮一民校注 岩波文庫を参照基準とする note.com 整備版）を逐語引用する。
> - **記紀**側は、本Vaultで逐語確認できる範囲（古事記 天石屋戸段の演者、書紀神代一書の忌部祖神職能）に限って対応を断じ、それ以外は **「記紀本文に対応記述を見ない」** と中立的に記す。記紀に「無い」ことの厳密な悉皆検証は本ノートの射程外とする。
> - 阿波接続は **阿波説固有の仮説**であり、§5・留保に明示する。

## 1. 命題の構造

| 観点 | 通説 | 阿波説 |
|---|---|---|
| 古語拾遺の独自記述 | 斎部氏の家伝による補綴。史実性は記紀と同等以上とは言えない | 記紀編纂時（中臣＝藤原氏主導期）に削除された忌部側の記憶を「拾い遺した」記録 |
| 「忌部五部神の祖系譜」の異同 | 古語拾遺にのみ体系的記載。書紀一書に部分的並行 | 阿波忌部を筆頭とする分掌系譜が、記紀から落ちた忌部の本来の自己認識 |
| 「阿波忌部・麻殖郡・安房東遷」の異同 | 古語拾遺にのみ記載 | 阿波の歴史的優位を示す情報の意図的隠蔽からの復元 |
| 斎部広成の党派性 | 史料批判の対象（忌部に有利なバイアス） | 党派的だからこそ、記紀が消した記述が残った |

## 2. 史料の前提：三本のテキスト

| 史料 | 成立 | 編纂主体 | 忌部記述の性格 |
|---|---|---|---|
| **古事記** | 712 | 太安万侶撰・稗田阿礼誦習 | 天石屋戸段に布刀玉命（＝天太玉命、忌部首祖）・天児屋命（中臣連祖）が登場。地方忌部の分掌系譜は記さない |
| **日本書紀** | 720 | 舎人親王ら。中臣（藤原）氏主導期の正史 | 本文・一書に忌部祖神の職能が散見。神代下の一書に作笠者・作盾者の祖神を挙げる |
| **古語拾遺** | 807 | 斎部広成（従五位下 斎部宿祢広成撰） | 忌部側の党派的史書。記紀に「拾い遺された」古事として、忌部祖系譜・地方分掌・神武朝組織化を体系的に記す |

> [!info] 「拾遺」という書名
> 「拾い遺された（記紀に漏れた／中臣氏に消された）古事を集めた書」というのが文字通りの含意。斎部広成は序文で **「愚臣が言はずば恐く傳へること無く絶へなむ（愚臣不言恐絶無傳）」** と述べ、記紀の遺漏を補う動機を明言する。→ 政治的経緯（806年の祭祀権争い勝訴の翌年に奏進）は [[古語拾遺_阿波説解釈]] §1 に詳しい。

## 3. 逐句対比（忌部系譜・職掌・組織化）

### 3-1. 忌部五部神の祖系譜（古語拾遺 本文 22 段）

> [!quote] 古語拾遺 原文
> 又男名曰、**天太玉命（斎部宿袮祖也）**、太玉命所率神名曰、**天日鷲命（阿波國忌部等祖）**、手置帆負命（讃岐國忌部祖也）、彦狭知命（紀伊國忌部祖也）、櫛明玉命（出雲國玉作祖也）、天目一筒命（筑紫伊勢両國忌部祖也）。

| 記述要素 | 古語拾遺 | 記紀の対応状況 |
|---|---|---|
| 天太玉命＝斎部宿祢（忌部）祖 | **明示** | 古事記 天石屋戸段に「布刀玉命」が御幣を捧げ持つ忌部首祖として登場（系譜列挙ではなく演者として） |
| 天日鷲命＝阿波国忌部の祖 | **明示** | **記紀本文に「阿波国忌部祖＝天日鷲命」という系譜記述を見ない** |
| 手置帆負命＝讃岐国忌部祖 | **明示** | 書紀神代一書に作笠者「手置帆負神」を忌部の遠祖とする並行記述あり（讃岐の地名比定は古語拾遺独自） |
| 彦狭知命＝紀伊国忌部祖 | **明示** | 書紀神代一書に作盾者「彦狭知神」を忌部の遠祖とする並行記述あり |
| 櫛明玉命＝出雲国玉作祖 | **明示** | 記紀には玉作の祖神として並行記述あり。忌部分掌としての体系化は古語拾遺独自 |
| 天目一筒命＝筑紫伊勢両国忌部祖 | **明示** | 同上 |

**逐句所見**：天太玉命を統率者とする **五国忌部の体系的な分掌系譜** は古語拾遺に固有である。書紀神代一書は作笠者・作盾者などの **個別職能神**を散発的に挙げるが、「これを天太玉命を頂点とする五系統の地方忌部として束ねる」整理は古語拾遺で初めて現れる。
→ 五部神の分掌の詳細は [[忌部五部神の全国分掌体系_MOC]]、各祖神は [[天太玉命]]・[[天日鷲命：天岩戸の功績と「鷲」の由来]]・[[手置帆負命]]・[[彦狭知命]]・[[櫛明玉命]]・[[天目一箇命]] を参照。

### 3-2. 天岩戸の祭具製作における役割分担（古語拾遺 本文 26 段）

古語拾遺は、岩戸開きの祭具製作で各神の職能を **逐一注記つきで列挙**する。原文の役割分担を正確に転記する。

> [!quote] 古語拾遺 原文（抜粋）
> 令石凝姥神（…作鏡遠祖也）取天香山銅以鑄日像之鏡／令長白羽神（伊勢國麻續祖…）種麻以為青和幣（古語爾伎弖）／**令天日鷲神**以造穀木綿（…）作白和幣（是木綿也）／令天羽槌雄神（倭文遠祖也）織文布／令天棚機姫神織神衣（…和衣）／令櫛明玉神作八坂瓊五百箇御統玉／令手置帆負彦狹知二神以天御量伐大峽小峽之材而造瑞殿 兼作御笠及矛盾／令天目一箇神作薙刀斧及鐵鐸（古語佐那伎）

| 神格 | 役割（古語拾遺 本文 26 段） | 後裔の分掌 |
|---|---|---|
| 石凝姥神 | 天香山の銅で日像の鏡を鋳る | 鏡作（後に紀伊国日前神・伊勢太神） |
| 長白羽神 | 麻を種え青和幣（にぎて）とする | 伊勢国麻続 |
| **天日鷲神** | 穀木綿（ゆう）を造り白和幣とする | **阿波忌部（麻・木綿）** |
| 天羽槌雄神 | 文布（あや）を織る | 倭文（しとり） |
| 天棚機姫神 | 神衣（和衣＝にぎたえ）を織る | 機織 |
| 櫛明玉神 | 八坂瓊五百箇御統玉を作る | 出雲玉作 |
| 手置帆負・彦狭知 二神 | 天御量で材を伐り瑞殿を造り、御笠・矛盾を作る | 讃岐忌部（→矛竿）・紀伊忌部（→盾） |
| 天目一箇神 | 薙刀・斧・鉄鐸（さなぎ）を作る | 筑紫・伊勢忌部（鍛冶） |

| 記述要素 | 古語拾遺 | 記紀の対応状況 |
|---|---|---|
| 岩戸神事の演者（思金・天児屋・布刀玉・天宇受売・天手力男ら） | 記載 | **古事記 天石屋戸段に並行する演者列**あり（→[[天岩戸神話の記紀解読版：阿波の祭祀構造]]） |
| 天日鷲神が穀木綿（白和幣）を造る | **明示** | **記紀本文に天日鷲神の穀木綿製作の明文を見ない**（古語拾遺の職能注記が独自に詳しい） |
| 手置帆負・彦狭知が「御笠・矛盾」を作る | **明示** | 書紀神代一書の作笠者・作盾者の職能と並行 |

> [!info] 重複回避
> 天岩戸神話「全体」の祭祀構造・登場神格の役割分担は、既存ノート [[天岩戸神話の記紀解読版：阿波の祭祀構造]] が逐句的に扱う。本節は **忌部祖神の職能注記の異同**にのみ焦点を絞り、神話の筋立て自体は再説しない。

### 3-3. 神武朝の橿原宮造営と忌部の組織化（古語拾遺 本文 38–39 段）

> [!quote] 古語拾遺 原文（抜粋）
> 仍令天富命（太玉命之孫）率手置帆負彦狹知二神之孫以齋斧齋鉏始採山材構立正殿（…）故其裔今在紀伊國名草郡御木麁香二郷（古語正殿謂之麁香）

| 記述要素 | 古語拾遺 | 記紀の対応状況 |
|---|---|---|
| 天富命（太玉命の孫）が忌部諸氏を率いて橿原宮の正殿を造営 | **明示** | **記紀本文に天富命の宮殿造営記述を見ない**。神武紀の橿原宮造営に忌部の役は明文化されない |
| 紀伊国名草郡 御木・麁香二郷の地名起源（造殿の忌部の居地） | **明示** | 記紀に対応記述を見ない（地名起源は古語拾遺独自） |

**逐句所見**：神武朝に **忌部が制度的に組織化され、宮殿造営・祭具製作を分掌した**という記述は古語拾遺に固有である。記紀の神武段は日臣命（大伴）・饒速日命（物部）・椎根津彦（大和）・八咫烏（賀茂県主）の功を記すが、**忌部の役割はほぼ語られない**。古語拾遺はここを補い、忌部の起源的職掌を主張する。

### 3-4. 阿波忌部の麻殖郡開拓と安房東遷（古語拾遺 本文 39 段）── 古語拾遺の最独自記述

> [!quote] 古語拾遺 原文（抜粋）
> 天日鷲命之孫造木綿及麻并織布（古語阿良多倍）仍令天富命率日鷲命之孫求肥饒地遣阿波國殖穀麻種其裔今在彼國当大嘗之年貢木綿麁布及種種物**所以郡名爲麻殖之縁也**／天富命更求沃壌分阿波齋部率往東土播殖麻穀（…）**阿波忌部所居便名安房郡**（今安房國是也）

| 記述要素 | 古語拾遺 | 記紀の対応状況 |
|---|---|---|
| 阿波国に麻穀を植え、大嘗の年に木綿麁布を貢進 | **明示** | **記紀本文に対応記述を見ない** |
| 「麻殖（おえ）郡」の地名起源（麻を植えた縁） | **明示** | 記紀に対応記述を見ない |
| 阿波忌部を東土に分かち、麻穀を植えた地が「総（ふさ）国」 | **明示** | 記紀に対応記述を見ない |
| 阿波忌部の居地が「安房郡」（安房国の起源） | **明示** | 記紀に対応記述を見ない |
| 天富命が太王命社（安房社）を建てる | **明示** | 記紀に対応記述を見ない |

**逐句所見**：この一段は **記紀に並行記述を全く見ない、古語拾遺の最も独自的な箇所**である。阿波忌部の麻殖郡開拓・大嘗祭麁服貢進・安房東遷という、阿波説の中核命題が連続して語られる。論証の本体は [[古語拾遺_阿波説解釈]] §4–§5、[[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]]、[[大嘗祭と麁服（あらたえ）_天皇即位に必須の阿波の神布]] に委ねる。

## 4. 「11箇条の失われた古事」── 斎部広成の史料批判的価値

古語拾遺後半、斎部広成は記紀以降の制度に「拾い遺された（所遺）」事項として **11箇条**を列挙する。その骨子は **「忌部の祭祀権が中臣氏に簒奪された」** という訴えに収斂する。

| 箇条（要旨） | 主張内容 |
|---|---|
| 草薙神剣（一） | 天璽たる草薙剣が尾張熱田社に留まり奉幣の礼を欠く |
| 伊勢神宮の班幣序列（二） | 諸神の後に伊勢を序するのは祖宗尊崇の礼に反する |
| 伊勢宮司の中臣独占（三） | 本来は中臣・斎部・猿女の三氏の職が中臣に偏る |
| 神殿造営の斎部参与（四） | 伊勢宮・大嘗の由紀主基宮造営に斎部が預からない |
| 殿祭門祭の奏詞改変（五） | 宝亀年中に中臣が奏詞を「中臣率斎部」と恣意改変 |
| 斎宮寮の斎部降格（六） | 延暦初に斎部を八位官に降格、未復 |
| 大宰主神司の中臣独占（七） | 斎部が預からない |
| 諸国大社の中臣任用（八） | 斎部が預からない |
| 鎮魂の儀（九） | 天鈿女命の遺跡たる御巫の職が旧氏に任じられない |
| 大幣造備の神部欠落（十） | 中臣・斎部ほか諸氏が考選に預からず神裔が散逸 |
| 伊勢幣帛使の中臣専用（十一） | 勝宝九歳の口宣で中臣専用とされ、官例に残存 |

| 観点 | 古語拾遺 | 記紀の対応状況 |
|---|---|---|
| 忌部と中臣の祭祀権分掌の本来の姿 | **11箇条で詳細に主張** | 記紀には祭祀権の党派的対立を語る視点を見ない |

**逐句所見**：11箇条は **記紀には存在しない「忌部の側からの祭祀史批判」** である。記紀が正史として制度を是認的に記すのに対し、古語拾遺は **同じ制度を忌部の被害という視点から逆照射**する。ここに、記紀との「異同」が単なる記載の有無ではなく **編纂主体の党派性の差** に根ざすことが明瞭に表れる。

> [!info] 古事記・日本書紀・古語拾遺の編纂主体
> 古事記・日本書紀の編纂は中臣（藤原）氏が朝廷を主導した時期にあたる。一方、天児屋命（中臣連祖）は記紀でも岩戸神事の太祝詞を担う重要演者として描かれ、忌部祖の布刀玉命と並記される。古語拾遺の党派性は、この「記紀における中臣・忌部の対称的描写」が、平安初期には中臣優位へ大きく傾いていた現実への抗議として読める。

## 5. 阿波説における意義

### 5-1. 「異同」は情報の偏在を示す

記紀と古語拾遺の異同を逐句に並べると、**古語拾遺に固有の記述は、その大半が忌部の祖系譜・地方分掌・阿波忌部の事績に集中する**ことが分かる。阿波説はこれを、

> 記紀編纂時に削除された「忌部側の記憶」、とりわけ阿波忌部に関わる情報が、95年後に斎部広成によって公式の場（平城天皇への奏進）で取り戻された

と読む（阿波説固有の解釈）。

### 5-2. 三段の制度的記憶

古語拾遺（807）の阿波忌部・八倉比売系譜は、斎部宿祢本系帳（[[斎部宿祢本系帳]]）・1070年太政官符（[[邦国之大典：平安時代の公式文書が語る神社の格]]）と三角整合する。逐句対比で確認した「記紀にない／古語拾遺にある」記述が、後続の公文書で **繰り返し復元され続けた**経緯は [[古語拾遺_阿波説解釈]] §8 に詳しい。

> [!note] 阿波説固有の解釈（仮説、確証なし）
> 「記紀の遺漏＝中臣氏による阿波忌部情報の意図的削除」という読みは **阿波説固有の仮説であり、確証はない**。通説では、古語拾遺の独自記述は斎部氏の家伝による補綴であり、記紀に「無い」ことは必ずしも「削除された」ことを意味しない。論拠本体は親ノート [[阿波説の根幹]]・[[忌部五部神の全国分掌体系_MOC]] に委ねる。
