# 天岩戸神話の記紀解読版：阿波の祭祀構造

> [!summary] 概要
> 記紀の **天岩戸（天石屋戸）神話** ―天照大神の岩戸隠れと再臨―を、登場神格の **役割分担（祭祀構造）** という切り口で逐句的に読み直し、その主要神格群が **忌部・中臣を中核とする祭祀儀礼の演者** で構成されている点を整理する。阿波説では、この神話を **阿波忌部の祭祀儀礼（幣帛奉献・麻木綿の生産）の神話的投影** と解し、天太玉命（忌部祖）・天日鷲命（阿波忌部祖）・天手力男命（佐那縣の神）を阿波の地理・祭祀と結ぶ。ただしこれは阿波説固有の **仮説** であり、各神格の阿波比定の論拠本体は既存の専門ノート（[[天手力男命：佐那縣の主神と天岩戸の力業]]・[[天日鷲命：天岩戸の功績と「鷲」の由来]]・[[天照大神の阿波生誕と天岩戸の秘儀]]）に委ねる。本ノートは神話 **全体の祭祀構造・登場神格の役割分担** に特化し、これら個別神格ノートと重複させず相互リンクする。

## 2. 記紀本文（一次史料）の検討

> [!info] 本節は記紀本文に厳密に限定する
> 阿波接続の解釈は §3 以降で扱う。本節は『古事記』『日本書紀』本文の記述のみを整理する。

### 2-1. 『古事記』上巻 天石屋戸段の演者

『古事記』天石屋戸段に登場し、岩戸開きの儀礼を担う主要神格は以下の通り。

| 神格 | 役割（古事記本文） |
|---|---|
| **思金神**（おもひかねのかみ） | 八百万神を集めて策を巡らす知恵の神。儀礼全体の演出を立案 |
| **天児屋命**（あめのこやねのみこと） | 太祝詞（ふとのりと）を申し上げる。**中臣連の祖** |
| **布刀玉命**（ふとだまのみこと／天太玉命） | 御幣（みてぐら）を捧げ持つ。**忌部首の祖** |
| **天宇受売命**（あめのうずめのみこと） | 桶を踏み鳴らし神懸かりして舞う。猿女君の祖 |
| **伊斯許理度売命**（いしこりどめのみこと） | 八咫鏡を作る。鏡作の祖 |
| **玉祖命**（たまのおやのみこと） | 八尺勾璁之五百津之御須麻流之珠（八尺瓊勾玉）を作る。玉作の祖 |
| **天手力男神**（あめのたぢからをのかみ） | 岩戸の脇に隠れ立ち、天照大神の御手を取って引き出す怪力神 |

『古事記』は本段の後、天孫降臨段で天手力男神について「**手力男神は佐那那縣に坐す**」と、その鎮座地を特記する。

### 2-2. 『日本書紀』神代上 第七段（本文・一書）の演者

『日本書紀』本文および諸「一書」も同様の演者を記すが、神名・役割に異同がある。とりわけ **一書第三** は、真榊（まさかき）の枝に祭具を懸ける場面で次のように記す。

> 下枝には、粟国の忌部の遠祖 **天日鷲（あまのひわし）** が作（は）ける木綿（ゆふ）を懸でて、乃ち忌部の首の遠祖 **太玉命** をして執り取らしめて、広く厚く称辞を…祈み啓さしむ。

→ ここで初めて **天日鷲（粟国＝阿波の忌部の遠祖）** が、木綿（ゆふ）の生産者として明示的に登場する。中・上枝の鏡・玉とともに、下枝の木綿が三種の祭具を構成する。

### 2-3. 本文上の論点：天日鷲は『古事記』本文に登場しない

重要な史料的事実として、**天日鷲命は『古事記』天石屋戸段の本文には登場しない**。同神が天岩戸の祭祀（木綿・白和幣の生産）に関与するのは、

- 『日本書紀』神代上 第七段 **一書第三**（粟国忌部の遠祖として）
- 後述の **『古語拾遺』**（807年・斎部広成撰）

においてである。すなわち天日鷲命の天岩戸での功績は、**記紀本文ではなく、一書および忌部側の家伝（古語拾遺）に拠る**。この区別は、阿波忌部の祭祀的地位を論じるうえで決定的に重要である（→ [[天日鷲命：天岩戸の功績と「鷲」の由来]] §一次資料における天岩戸の功績）。

## 3. 阿波説における祭祀構造の解読

> [!note] 本節は仮説の提示であり、論拠は各専門ノートに委ねる
> 以下は阿波説固有の解釈であり、学術的に確証された因果ではない。本ノートは神話の祭祀構造の読みを示すにとどめ、個別神格の阿波比定の論拠本体は既存の専門ノートが担う。

### 3-1. 記紀本文 vs 『古語拾遺』── 忌部視点の祭祀構造

天岩戸神話を「祭祀儀礼の起源譚」として最も明示的に語るのは、**忌部氏の家伝『古語拾遺』**（807年・斎部広成撰）である。同書の天岩戸段は次のように記す。

> 天日鷲神と津咋見神とをして、穀木（かぢのき）の種を殖えしめ、以て白和幣（しろにきて）を作らしむ。【是、木綿（ゆふ）なり。】

『古語拾遺』は、中臣氏に対して劣勢に置かれた忌部氏の祭祀的権利を訴えるために編まれた書であり、天岩戸の儀礼を **忌部の幣帛・木綿生産の起源** として強調する。阿波説はこの忌部視点に立ち、天岩戸神話を次の祭祀分業構造として読む。

| 祭祀の機能 | 担当神格 | 氏族的属性 |
|---|---|---|
| 策の立案（演出） | 思金神 | ― |
| **祝詞の奏上** | 天児屋命 | **中臣連の祖** |
| **幣帛（御幣）の奉献** | 天太玉命（布刀玉命） | **忌部首の祖** |
| **木綿・白和幣の生産** | 天日鷲命 | **粟国（阿波）忌部の遠祖**（一書・古語拾遺） |
| 鏡の鋳造 | 伊斯許理度売命 | 鏡作 |
| 玉の製作 | 玉祖命 | 玉作 |
| 神楽（神懸かりの舞） | 天宇受売命 | 猿女君 |
| 岩戸の力業（開扉） | 天手力男神 | ― |

→ この構造の核は **「中臣（祝詞）＋忌部（幣帛・木綿）」の祭祀分業** にあり、阿波説はこのうち **忌部側（太玉・天日鷲）の比重** を阿波に求める。なお天児屋命は **中臣の祖** であって忌部ではない点に注意を要する（後述 §7 留保）。

### 3-2. 天手力男神＝佐那縣（佐那河内）の力業

『古事記』が天手力男神について「**佐那那縣に坐す**」と記す **佐那縣** を、阿波説は徳島県名東郡 **佐那河内村**（旧・佐那縣／狭長村）に比定する。岩戸を引き開けた怪力神の鎮座地を阿波に置くことで、天岩戸神話の「開扉」の場面を阿波の地理に接続する。

→ 比定の対立軸（伊勢国多気郡 [[佐那神社]] 説 vs 阿波佐那河内説）および論拠本体は [[天手力男命：佐那縣の主神と天岩戸の力業]]・[[佐那河内：佐那縣と天岩戸神話の地]] に委ねる。本ノートでは「天岩戸神話の演者の一人＝天手力男神の鎮座地比定」という位置づけに留める。

### 3-3. 天日鷲命＝阿波忌部祖と「木綿（ゆふ）」の生産

天日鷲命は、一書第三・古語拾遺において **粟国（阿波）忌部の遠祖** として木綿・白和幣を生産する神として現れる。阿波説では、この木綿生産の神話的功績を、阿波忌部が現に大嘗祭へ **麁服（あらたえ）** を貢進してきた歴史的祭祀実践（三木家の麻栽培・献上）の起源譚と解する。

→ 「鷲」の名の由来・系譜論・全国分布の論拠本体は [[天日鷲命：天岩戸の功績と「鷲」の由来]] に委ねる。本ノートでは「天岩戸の祭祀構造における木綿生産担当」という役割に限定する。

### 3-4. 天照大神の岩戸隠れと阿波

天岩戸に隠れた主役 **天照大神** については、その本貫・生誕を阿波に求める議論が別途存在する。

→ 論拠本体は [[天照大神の阿波生誕と天岩戸の秘儀]] に委ねる。本ノートはこれと重複せず、「岩戸隠れ → 演者群の祭祀 → 再臨」という **儀礼の構造** の側から天照大神を扱う。

## 7. 留保（中立的併記）

> [!warning] 注意
> - **記紀本文と一書・古語拾遺の区別**：天日鷲命の木綿生産は『古事記』本文には無く、『日本書紀』一書第三および『古語拾遺』に拠る。天岩戸の演者全体を「記紀本文」と一括しないこと。
> - **天児屋命は中臣連の祖** であって忌部ではない。本ノートの「忌部の祭祀儀礼の神話化」という読みは、太玉命・天日鷲命（忌部側）に重心を置くものであり、天児屋命（中臣側）を忌部に組み入れるものではない。天岩戸の祭祀は中臣（祝詞）と忌部（幣帛・木綿）の **協働分業** として読むべきである。
> - **佐那縣の比定は未確定**：天手力男神の鎮座地「佐那縣」は学術的にも未確定で、伊勢国多気郡（佐那神社）説が通説。阿波佐那河内説は阿波説固有の解釈＝仮説である。
> - **天岩戸神話＝阿波忌部祭祀の起源譚** という読み自体が阿波説固有の解釈であり、記紀・古語拾遺がこれを明言するわけではない。各神格の阿波比定の確度は個別ノートの留保に従う。
> - 思金神・玉祖命・天宇受売命・伊斯許理度売命・佐古天一神社は専門ノート未作成のためプレーン表記とした。
