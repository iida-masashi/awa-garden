# 『続日本後紀』

**続日本後紀（しょくにほんこうき）** は、六国史の一つ。

## 📚 基本情報

| 項目 | 内容 |
| --- | --- |
| **編纂完了** | 貞観11年（869年） |
| **対象期間** | 仁明天皇天長10年（833）〜 嘉祥3年（850） |
| **編者** | 藤原良房・春澄善縄ほか |
| **巻数** | 全20巻 |

## 🏛 神社史料としての性格

仁明朝に集中する **神階の大昇叙時代** の記録。承和年間（834-848）に全国の地方神が大規模に階位を上げられ、阿波の **八倉比賣神** もこの時期に正八位 → 従五位下に叙された（承和8年・841）。**阿波説における中央朝廷の阿波認識** を示す重要史料。

### 主な神社関連記事
- 承和8年（841）阿波 八倉比賣神 従五位下
- 承和年間の全国地方神への大規模神階授与
- 畿外神への国家祭祀の制度化

## 🌟 阿波説の文脈

**承和8年（841年）の阿波 八倉比賣神 従五位下叙位** は本書が伝える最重要記録の一つ。
中央朝廷が阿波の神を国家祭祀体系に組み込んだ画期にあたり、
後の [[邦国之大典：平安時代の公式文書が語る神社の格|1070年太政官符]] における「邦国之大典」位置付けの前提となる。
