# 『日本三代実録』

**日本三代実録（にほんさんだいじつろく）** は、六国史の一つ。

## 📚 基本情報

| 項目 | 内容 |
| --- | --- |
| **編纂完了** | 延喜元年（901年） |
| **対象期間** | 清和天皇天安2年（858）〜 光孝天皇仁和3年（887） |
| **編者** | 藤原時平・菅原道真・大蔵善行ほか |
| **巻数** | 全50巻 |

## 🏛 神社史料としての性格

**六国史最大規模で、神階記録の極盛期**。本 Vault の Shrine-heritager 索引においても **断トツの最多典拠**（68 件）。清和朝の貞観年間（859-877）に地方神への神階奉授が制度化され、全国の神社が記録される。阿波の **八倉比賣神** も貞観13年（871）に従四位上に叙された。延喜式（927）に先立つ最後の正史であり、両者を併読することが式内社研究の基本。

### 主な神社関連記事
- 貞観13年（871）阿波 八倉比賣神 従四位上
- 貞観年間の全国神階奉授（地方神の制度化）
- 風水害・疫病に対する奉幣記事

## 🌟 阿波説の文脈

**貞観13年（871年）の阿波 八倉比賣神 従四位上叙位** は本書が伝える最重要記録の一つ。
9世紀後半における阿波の神々の制度的位置付けを示し、
延喜式（927）以前の阿波最高位の確立を裏付ける。

阿波の式内社のうち、本書を典拠とするものは [[上一宮大粟神社]]・[[天村雲神社]]・[[宇奈為神社]]・[[王子和多都美神社]]・[[意富門麻比売神社]]・[[和多都美豊玉比売神社]]・[[天村雲神伊自波夜比売神社]] など多数。
