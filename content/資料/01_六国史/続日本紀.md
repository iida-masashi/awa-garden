# 『続日本紀』

**続日本紀（しょくにほんぎ）** は、六国史の一つ。

## 📚 基本情報

| 項目 | 内容 |
| --- | --- |
| **編纂完了** | 延暦16年（797年） |
| **対象期間** | 文武天皇元年（697）〜 桓武天皇延暦10年（791） |
| **編者** | 菅野真道・藤原継縄ほか |
| **巻数** | 全40巻 |

## 🏛 神社史料としての性格

律令制下における朝廷の政務記録。神社制度では神階奉授の開始期にあたり、神護景雲〜延暦の重要な神階授与記録を含む。式内社制度に先立つ神社認識を伝える。

### 主な神社関連記事
- 天平勝宝元年（749）の各社への神階授与
- 桓武朝の遷都に伴う山城・近江の神社記録
