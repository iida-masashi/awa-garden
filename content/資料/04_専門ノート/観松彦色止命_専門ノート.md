# 👑 観松彦色止命(みまつひこいろどのみこと) 専門ノート

> [!abstract] このノートの役割
> 観松彦色止命は、阿波説における **核心神格** の一つ。
>
> - **阿波佐那河内村** の 式内社 御間都比古神社 が **全国唯一**の主祭神として祀る
> - 『国造本紀』により **阿波長国造**(9世孫 韓背足尼命) と **隠岐国造**(5世孫 十挨命) **両方の祖** とされる
> - 第 5 代 **孝昭天皇**(欠史八代)の和風諡号「**観松彦香殖稲尊**」と同体とする説が通説
> - 阿波の地名「観松」「佐那河内」「松」群との連環、阿波長国造の祖神祭祀
>
> 本ノートは、観松彦色止命を **欠史八代の阿波在位論・海人族の同祖論・隠岐 = 阿波同祖論** の三重接続点として位置づけ、関連史料・神社・氏族系譜を統合する。

## 🌟 第一章 名前の構造分析

### 「観松(みまつ)」 — 御間都の音通

- **観松(かんしょう/みまつ)** = 漢字表記
- **御間都(みまつ)** = 万葉仮名的表記、音通
- → 同一の音「みまつ」を表す異表記

### 「色止(いろど)」 — 三つの解釈

| 解釈 | 説明 |
| --- | --- |
| (A) 同腹の弟・妹 | 「色」=「同色(=同腹)」、「止」=「弟」 |
| (B) 尊号 | 「色止」自体を尊号として孝昭天皇本人を指す |
| (C) 別称 | 後代の同名異称 |

通説では (B) を採り、観松彦色止命 = 孝昭天皇本人と比定。

### 「伊呂止(いろど)」表記

- 『国造本紀』では「**観松彦伊呂止命**」と表記
- 「色止」と「伊呂止」は音通
- 同一神を異表記したもの

## 🌳 第二章 系譜 — 阿波長国造と隠岐国造の同祖

『**先代旧事本紀**』「国造本紀」の核心記述:

### 阿波長国造

> 「**長国造** 志賀高穴穂朝御世 以 **観松彦伊呂止命 九世孫** 諱**韓背足尼**(からせのすくね) 定賜国造」
>
> (長国造は志賀高穴穂朝(成務天皇代)に、観松彦伊呂止命の九世孫 韓背足尼命を以て国造に定め賜う)

→ **観松彦色止命 → 9 世 → 韓背足尼命 = 阿波長国造**

### 隠岐国造

> 「**隠岐国造** 軽島豊明朝御代 観松彦伊呂止命 **五世孫 十侯**(十挨命) 定賜億岐図造」
>
> (隠岐国造は軽島豊明朝(応神天皇代)に、観松彦伊呂止命の五世孫 十挨命を以て国造に定め賜う)

→ **観松彦色止命 → 5 世 → 十挨命 = 隠岐国造**

### 阿波長国造と隠岐国造の **時代差**

- **隠岐国造任命**:応神朝(軽島豊明朝) → 4 世紀末〜5 世紀初頭
- **阿波長国造任命**:成務朝(志賀高穴穂朝) → 4 世紀前半

→ **阿波長国造の任命は隠岐国造より早い**
→ 観松彦色止命の本貫は **阿波**、後に隠岐へ分流という構造(🟡)

## 🏛 第三章 主要式内社 — 御間都比古神社(阿波名方郡)

### 基本情報

- **神社名**:御間都比古神社
- **所在地**:徳島県名東郡佐那河内村下モノミ石 74-2
- **延喜式社格**:小社
- **主祭神**:**御間都比古色止命**(全国唯一)
- **歴史**:
  - 延喜式神名帳(927)に「阿波国 名方郡 御間都比古神社」として記載
  - 大正時代に **宮内省諸陵考証官** が実地調査(中央からも無視できない歴史的信憑性)
  - 江戸期『**阿府志**』にも祭神は孝昭天皇と明記

### 由緒の重要記述(社伝)

> 「観松彦色止命の九世孫にあたる **韓背宿禰**(からせのすくね)が **長国造**(阿波国南部の支配者)に任命され、祖神を祀ったのが始まり」

→ 神社由緒自体が『国造本紀』と整合
→ 孝昭天皇の直系子孫が阿波を統治した歴史的記憶の物的痕跡

### 佐那河内村という地

- 阿波山地に深く入り込んだ盆地
- 神山町([[上一宮大粟神社]] = 大宜都比売命)
- 徳島市国府町([[天石門別八倉比売神社]] = 天照大神)と山系で接続
- **天岩戸別神社**(佐那河内村) — 天岩戸神話の阿波内地比定地
- 阿波説では **天孫族・天皇家の阿波本拠の一拠点** とされる

→ 周辺の式内社群密度が異常に高い (第四章参照)

## ⚖ 第四章 孝昭天皇との同体論

### 同体論の根拠

1. **諡号の音通**
   - 観松彦色止 ≒ **観松彦**香殖稲(日本書紀)
   - 観松彦色止 ≒ 御真津日子訶恵志泥(古事記)
   - 「観松(みまつ) = 御間都(みまつ) = 御真津(みまつ)」 — すべて同音

2. **江戸期地誌の明記**
   - 『阿府志』(徳島藩):祭神 = 孝昭天皇と明記
   - 『阿波志』も同様

3. **国造本紀の系譜**
   - 阿波長国造の祖 = 観松彦色止命
   - 神武 → 綏靖 → 安寧 → 懿徳 → 孝昭 (= 観松彦) → 孝安 → ... の継承を支持

### 孝昭天皇(諡号)の意味

> **観松彦香殖稲尊**(みまつひこかえしねのみこと)

- **観松彦** = 「松を観(み)る彦」 = 松林・松山との縁
- **香殖稲** = 「香しい稲を殖やす」 = **稲作・農耕の神格**

→ 阿波の稲作・粟作祭祀(大宜都比売)と神格構造が親和(🟡)

### 阿波説の在位論

阿波説では、孝昭天皇から開化天皇に至る **欠史八代の天皇たちは大和ではなく阿波国(名方・麻殖周辺)に在位した** とする。

孝昭天皇の宮:
- 通説:**池心宮**(掖上池心宮、奈良県御所市)
- 阿波説:**佐那河内村周辺**(殯宮跡の伝承あり)

→ 阿波説は記紀の宮地比定を **後代の編集による大和への写し替え** と読む

## 🧭 留保

- 観松彦色止命 = 孝昭天皇は **諡号の音通** による比定。延喜式神名帳が直接「孝昭天皇」と記すわけではない
- 欠史八代の阿波在位説は阿波説固有の枠組であり、通説(大和盆地での王権形成)とは前提が異なる
- 御間都比古神社の存在は阿波説の状況証拠の一つだが、それ単独で在位地論争を決着させるものではない
- 大和盆地の関連伝承との優先関係は、各天皇ごとに個別に検証する必要
- 「色止(いろど)」の語義は古語であり、確定的解釈は学界で議論中
- 信頼度 4 は、『国造本紀』記載(🟢)と式内社の全国唯一性(🟢)に基づく総合評価
