# 🏛 億岐氏(おきし) 系譜 専門ノート

> [!abstract] このノートの役割
> **億岐氏(おきし)** は、隠岐国造の後裔として **応神朝の十挨命**(観松彦色止命 5 世孫)に始まり、**現代まで連綿と継承** されている希少な氏族。出雲大社の **千家氏**(国造)、紀伊国造の **紀伊氏** と並び **「全国三家」** の一つに数えられる。
>
> - **玉若酢命神社**(隠岐国惣社、隠岐の島町下西)の **宮司を世襲継承**
> - **隠岐国駅鈴・隠伎倉印** = **国の重要文化財**(現存品が現代まで伝承)
> - 平成期には光格天皇の即位式で **駅鈴貸出** の事例も
> - 阿波説では、**観松彦色止命系氏族の隠岐分流の現代直系継承家**
>
> 本ノートは、億岐氏の系譜・物的継承品・現代まで続く祭祀権を統合し、**古代国造系譜の物的検証可能事例** として位置づける。

### 「大国主命の後裔」説

> 「**大国主命**(=飯入根を神格化)の後裔」

→ 観松彦色止命 5 世孫 十挨命説と並列の伝承
→ 出雲系王権との接続を示唆(🟡)
→ 出雲大社 千家氏との「全国三家」並列の背景

## 🏛 第二章 玉若酢命神社 — 億岐氏の祭祀拠点

### 基本情報

| 項目 | 内容 |
| --- | --- |
| **正式名** | 玉若酢命神社(たまわかすみことじんじゃ) |
| **所在地** | 島根県隠岐郡隠岐の島町下西 701 |
| **性格** | 隠岐国惣社 |
| **主祭神** | **玉若酢命**(たまわかすみこと) |
| **配祀** | 大己貴命・須佐之男命・稲田姫命・事代主命・須世理姫命 |
| **延喜式社格** | 旧県社(明治 5 年) |
| **本殿様式** | **隠岐造** 7 坪 |
| **境内** | 1,698 坪 |
| **末社** | 4 社 |
| **氏子** | 1,500 戸 |
| **崇敬者** | 約 10,000 人 |

### 由緒

- **景行天皇** が皇子を各国に分置 → 隠岐国に **大酢別命** を遣わす
- 大酢別命の **御子 = 玉若酢命**
- → 玉若酢命 = 隠岐開拓の祖神
- 玉若酢命神社の宮司を **代々勤める神主家の億岐家** が古代の国造を称し、玉若酢命の末裔とされる

→ [[ぐーたら気延日記（重箱の隅） 隠岐と阿波（１）]] 詳細

### 神階履歴

- **貞観 13 年(871)**:従五位下叙位
- 寛文以後:周吉郡・穏地郡の両郡で造営、修繕費は周吉郡 25 ヶ村が負担
- **明治 5 年(1872)**:県社に列す

### 御神体伝承

『神社取調帳』:

> 「尊號 玉若酢命、神體秘箱。相殿ニ大己貴命ヲ鎭祭ス。神體一尺三寸位ノ坐像、古作也。」
>
> 「又左ニ八寸位ノ男神一坐、女神一坐、是ヲ **須佐之男命・稻田比賣命** 也ト申傳フ。」
>
> 「又右ニ九寸位ノ男神一坐、女神一坐、是ヲ **須世理毘賣命・事代主命** 也ト申傳フ。」

→ **須佐之男 + 稲田姫 + 須世理姫 + 事代主** の出雲神格群を配祀
→ 億岐氏 = 出雲系王権と海人族の融合体としての性格(🟡)

## 🏺 第三章 国宝・重要文化財 — 物的継承の確実な証拠

### 1. 隠岐国駅鈴(おきのくにのえきれい)

| 項目 | 内容 |
| --- | --- |
| 種類 | 古代律令制下の駅鈴 |
| 用途 | **駅伝制での通行証明** |
| 現存 | 億岐家所有 |
| 指定 | 国の重要文化財(後に国宝級) |
| 古代律令制の生き証人 | 全国でほぼ唯一現存 |

#### 光格天皇即位式での貸出

> 「**光格天皇は億岐家より駅鈴を借上げ、即位の式列に加えられ、返還の砌の下賜の辛檐も伝えている**」

→ 江戸後期の天皇即位式で **駅鈴が実際に使用された** 物的事例(🟢)
→ 億岐氏の中央朝廷との直接接続の証

### 2. 隠伎倉印(おきのくらいん)

- 律令制下の倉印 = 公印
- 古代隠岐国の行政文書に押印された印
- 国の重要文化財

### 3. 玉若酢命神社社家億岐家住宅

- 宮司家の現存住宅
- 国の重要文化財指定
- 古代国造系譜の生活様式を伝える物的物証

→ 三点すべての物的継承 = **古代国造制の現代まで残る物的確認可能事例**(🟢)

## 🌳 第四章 阿波 三木家との対比

『阿波学会研究紀要』に見える対照:

> 「阿波における **三木家** が天日鷲命の裔として **歴代の即位式に献上する 荒妙(あらたえ) の事故** と対照的でもある」

| 観点 | 阿波 三木家 | 隠岐 億岐家 |
| --- | --- | --- |
| 始祖 | 天日鷲命(阿波忌部祖) | 十挨命(観松彦色止命 5 世孫) |
| 即位式 献上 | **麁服(あらたえ)** = 麻の織物 | **駅鈴** 貸出 |
| 中央朝廷との接続 | 大嘗祭 麁服貢進 | 即位式 駅鈴 |
| 現代継承 | 木屋平の三木家(現代も麁服貢進) | 玉若酢命神社の隠岐家(宮司) |
| 国指定 | 三木家文書(県指定) | **駅鈴・倉印・社家住宅 = 国指定** |

→ 阿波(忌部系)と隠岐(国造系)が **異なる方式で天皇即位儀礼に直接関与** する稀有な並列構造(🟡)

## 🌊 第五章 阿波説における意義

### 1. 国造系譜の現代継承の物証

- **古代の人物伝承が後代の物的継承を伴う** 最重要事例
- 観松彦色止命(=孝昭天皇)系の系譜の現代まで続く実証
- → 欠史八代 = 神話ではなく実在の論拠の一つ(🟡)

### 2. 阿波 ⇔ 隠岐 同祖関係の現代物証

- 億岐氏 = 隠岐国造系の現代継承
- 阿波の **観松彦色止命祭祀**(御間都比古神社)と並列
- → 古代の海上ネットワークが氏族祭祀として中世まで保持された証(🟢)

### 3. 出雲・忌部・国造の三角構造

| 系統 | 代表氏族 | 阿波説的位置 |
| --- | --- | --- |
| **国造系** | 出雲 千家 / 隠岐 億岐 / 紀伊 紀伊 | 王権祭祀の系譜継承 |
| **忌部系** | 阿波 三木家 | 大嘗祭祭祀の系譜継承 |
| **海人族系** | 阿波 海部・那賀氏 | 海上交通の系譜継承 |

→ 三系統が **異なる方式で天皇制と接続** する古代日本の祭祀構造(🟡)

### 4. 観松彦色止命の本貫地論との連動

- 億岐氏 → 5 世孫 十挨命 → 観松彦色止命
- 阿波長国造 → 9 世孫 韓背足尼命 → 観松彦色止命
- → 阿波本貫説(任命時期の早期性)を物的に補強(🟡)
