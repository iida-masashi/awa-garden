# 👑 十挨命(とあいのみこと) 専門ノート

> [!abstract] このノートの役割
> **十挨命**(十挨族命、十侯、十拶彦)は、『先代旧事本紀』「**国造本紀**」および『**伊未自由来記**』に **隠岐国造の初代** として記される人物。
>
> - **観松彦色止命(=孝昭天皇)の五世孫**
> - **軽島豊明朝(応神天皇代、4 世紀末〜5 世紀初頭)** に隠岐国造に任命
> - 妻は **伊未自姫**(久米首の祖) — **『伊未自由来記』書名の語源**
> - 十挨命と伊未自姫の間に **十人の男子** — 隠岐の海人族系譜の祖
> - **阿波長国造 韓背足尼命** との **同祖関係** の隠岐側代表
> - 後裔は **億岐氏(玉若酢命神社祠官家)** として現代まで継承
>
> 本ノートは、十挨命を **阿波 ⇔ 隠岐 同祖関係の核心人物** として位置づけ、観松彦色止命系氏族の隠岐分流の祖として整理する。

## 🌟 第一章 史料記述

### 『先代旧事本紀』「国造本紀」

> 「**隠岐国造** 軽島豊明朝御代 観松彦伊呂止命 **五世孫 十侯** 定賜億岐図造」
>
> (隠岐国造は **軽島豊明朝**(応神天皇代)の御代に、観松彦伊呂止命の **五世孫 十侯**(十挨命)をもって億岐国造に定め賜う)

→ 十挨命 = **隠岐国造の初代**(🟢)

### 『伊未自由来記』第七章「国造」

『伊未自由来記』(隠岐の古史古伝)第七章の対応記述:

> 「**誉田天皇**(応神天皇) **御間都比古伊呂止命 五世の孫 十挨族命** を **隠岐国造に定め給える** に及び、大津部・伊勢部・海部・山部・服部の五首は国造に協力し功あり」

→ 『国造本紀』と完全一致(🟢)

### 第六章「奈賀命」内の十挨命

『伊未自由来記』第六章末尾:

> 「神功皇后の兵船が役道の主栖に来れる時、久米首の祖 **伊未自姫は十挨命の妻となり 十男子あり**、後に姫死して男子は **大和美和の父命** の許に送られしという」

→ 十挨命の **妻 = 伊未自姫**、**子 = 十男子**
→ **「伊未自姫」 = 『伊未自由来記』の書名の語源**(🟢)
→ 母方の祖父は「大和美和の父命」(=大物主命系か?)(⚪)

### 玉若酢命神社社伝

- 億岐氏(玉若酢命神社祠官家)の祖
- 「**十拶彦の代あたりから隠岐国造となり**、国造制度廃止後は国司となって代々隠岐国を治めていた」
- 億岐家所有の **隠岐国駅鈴・隠伎倉印** = 国宝指定

| 国造 | 世孫 | 任命朝 | 推定年代 |

## 🌐 第三章 妻 伊未自姫 と書名の語源

### 伊未自姫の系譜

『伊未自由来記』第六章:
- **久米首の祖**
- 神功皇后の三韓征伐に従軍した **美豆別主命(伴の首)** の関連系譜
- 十挨命の妻となり **十男子** を生む

### 「伊未自(いみじ)」と「忌部(いみべ)」

阿波説的論点:
- **「伊未自(いみじ)」 = 「忌部・斎部(いみべ)」** の音韻的近さ(⚪)
- 阿波忌部との何らかの系譜的接続の可能性
- → [[伊未自由来記_専門ノート]] 参照

### 書名の語源としての位置

- 『伊未自由来記』 = 隠岐の独自伝承を記した古史古伝
- 書名は **久米首の祖 伊未自姫** に由来
- → 伊未自姫(と十挨命の妻)が隠岐の歴史伝承の **象徴的人物**
- 阿波 ⇔ 隠岐の血縁的接続(久米首)を示す重要人物(🟡)

## 🗺 第四章 任命地 — 隠岐諸島

### 隠岐の地理

- 北緯 36 度、東経 133-133 度 20 分
- **島後**(おき、隠岐の島町) + **島前**(どうぜん、知夫里島・西ノ島・中ノ島)
- 4 つの主要島 + 周辺島嶼
- 詳細:[[隠岐_専門ノート]]

### 十挨命の統治体制

『伊未自由来記』第七章により:
- **五首**(大津部・伊勢部・海部・山部・服部) が国造に協力
- 異国人の来襲が盛んな時期 → **沿岸防備強化**
- 道路開発・医師薬師の各邑配置
- 兵船建造
- 賞罰の明確化
- 各部の氏神に領地配分
- 漂着者の保護

→ **海洋国家としての隠岐の制度的確立** を担った人物(🟡)

### 億岐氏(玉若酢命神社祠官家)への継承

- 十挨命 → 子孫 → **億岐氏**
- 玉若酢命神社の宮司を **現代まで世襲継承**
- 億岐家所有の **隠岐国駅鈴・隠伎倉印** = **国の重要文化財**(後に国宝)
- 国造制度廃止後も国司 → 宮司として継承

→ 古代国造系譜の **現代までの直接継承事例** として全国的にも稀(🟢)

## 🌊 第五章 阿波説における意義

### 1. 阿波 ⇔ 隠岐 同祖関係の隠岐側代表

- 観松彦色止命系の **隠岐分流の祖**
- 阿波長国造 韓背足尼命 との **共通祖**
- → 古代の海上ネットワークの物的証拠(🟡)

### 2. 「伊未自姫」を介した血縁的接続

- 妻 伊未自姫 = 久米首の祖
- 久米首 = 神功皇后の三韓征伐に関与
- 阿波 ⇔ 隠岐 ⇔ 朝鮮半島 の三角ネットワーク(⚪)

### 3. 隠岐の海人族(億岐氏・海部首・阿曇首)の祖

『伊未自由来記』が示す系譜:
- 十挨命 → 億岐氏(玉若酢命神社祠官家)
- 奈岐の浦命 → 海部首 → 阿曇首(出雲大阿曇造に属す)
- → 隠岐の主要海人族はすべて十挨命系の系譜

→ [[海人族_MOC]] 参照

### 4. 国造制の物的証拠

- 応神朝の国造任命 = 国造制整備期の事例
- 阿波・隠岐両方に観松彦色止命系国造 → 同制度の広域展開
- → 古代国家形成史における重要事例(🟡)

### 5. 中世以降の継承の確かさ

- 億岐氏は **現代まで国造系譜を継承**
- 出雲大社の千家・紀伊国造の紀伊家 と並ぶ **全国三家** の一
- 駅鈴・倉印が国宝指定
- → 十挨命の伝承が単なる神話ではなく **物的継承を伴う歴史記憶** であることの証(🟢)

## 🧭 留保

- 十挨命の **歴史的実在性** は『国造本紀』『伊未自由来記』記載の信頼性に依存
- 『伊未自由来記』は **古史古伝**(成立年代不詳)であり、史料批判が必要
- 「観松彦色止命 5 世孫」の世代計算は推定値であり、確定的年代は不明
- 「十挨」「十侯」「十拶彦」の語義は学界での確定的解釈がない
- 億岐氏系譜の中世以前の細部は確認しがたい
- 信頼度 3 は、『国造本紀』記述(🟢)と億岐氏現代継承(🟢)の確実性と、人物そのものの歴史的詳細の不確定性(🟡 + ⚪)の総合
