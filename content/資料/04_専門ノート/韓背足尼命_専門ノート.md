# 👑 韓背足尼命(からせのすくねのみこと) 専門ノート

> [!abstract] このノートの役割
> **韓背足尼命**(韓背宿禰)は、『先代旧事本紀』「**国造本紀**」に **阿波長国造の初代** として記される人物。
>
> - **観松彦色止命(=孝昭天皇)の九世孫**
> - **志賀高穴穂朝(成務天皇代、4 世紀前半)** に長国造に任命
> - 阿波那賀郡(那賀川流域)を統治
> - **隠岐国造 十挨命**(観松彦色止命 5 世孫、応神朝任命)の **同祖関係** の阿波側代表
>
> 本ノートは、韓背足尼命を **阿波説の国造制論の核心人物** として位置づけ、観松彦色止命系氏族の阿波分流の祖として整理する。

## 🌟 第一章 史料記述

### 『先代旧事本紀』「国造本紀」(最重要典拠)

> 「**長国造** 志賀高穴穂朝御世 以 **観松彦伊呂止命 九世孫** 諱 **韓背足尼** 定賜国造」
>
> (長国造は **志賀高穴穂朝**(成務天皇代)の御世に、**観松彦伊呂止命の九世孫**、諱「韓背足尼」をもって国造に定め賜う)

→ 韓背足尼命 = **阿波長国造の初代**(🟢)

### 御間都比古神社(佐那河内村)社伝

> 「観松彦色止命の **九世孫にあたる韓背宿禰**(からせのすくね)が **長国造**(阿波国南部の支配者)に任命され、**祖神を祀ったのが始まり**」

→ 御間都比古神社の創建が韓背足尼命の業績として位置づけられる(🟢)
→ 式内社 御間都比古神社

### 『阿府志』『阿波志』

- 御間都比古神社の祭神 = 孝昭天皇 と明記
- 韓背宿禰 = 阿波長国造の祖として記述

### 隠岐国造との関係

- **十挨命(5 世孫) = 隠岐国造**(応神朝、軽島豊明朝)
- **韓背足尼命(9 世孫) = 阿波長国造**(成務朝、志賀高穴穂朝)

→ **韓背足尼命は十挨命より 4 世代後** だが、**阿波長国造の任命は隠岐国造より早期**

| 国造 | 世孫 | 任命朝 | 推定年代 |
| --- | ---: | --- | --- |
| 阿波長国造(韓背足尼) | 9 世孫 | **成務朝** | 4 世紀前半 |
| 隠岐国造(十挨命) | 5 世孫 | **応神朝** | 4 世紀末〜5 世紀初頭 |

→ 阿波長国造の任命時期の早期性 = **観松彦色止命の本貫が阿波** という阿波説の根拠(🟡)
→ [[観松彦色止命_専門ノート]]

## ⚓ 第四章 名前「韓背」の解釈

### 「韓背」の語義

「**韓背(からせ)**」は古代の人名表記として複数の解釈が可能:

| 解釈 | 説明 |
| --- | --- |
| (A) 韓(から)+背(せ) | 「韓の方角(西方)」または「韓を背にする」 |
| (B) 韓背(からせ) | 「唐瀬」「迦羅勢」などの音写 |
| (C) 韓人系 | 朝鮮半島・韓族との何らかの接点 |

### 阿波説的論点

- 海部郡 [[海部郡_専門ノート|脚咋別 鷲住王伝承]] と並んで、**韓系氏族との接触** を示唆する可能性
- 鹽深 大山祠の **韓人鐘(明昌 7 年=1196 銘)** との並列(時代は大きく違うが)
- 隠岐 [[伊未自由来記_専門ノート|『伊未自由来記』のコノハビト = 新羅徐羅伐由来]] とも構造的に並ぶ
- → 古代の **韓朝鮮との海上交流** の名残か(⚪)

### 「足尼(すくね)」の意味

- **足尼(すくね) = 宿禰** = 古代の称号
- 「宿の禰(古老)」、後の臣・連と並ぶ上層族長称号
- → 韓背足尼命 = 古代の有力氏族の長

## 🌊 第五章 阿波説における意義

### 1. 国造制論の核心

韓背足尼命の任命は **国造制の阿波における物的事例**:
- 成務朝の国造制整備
- 観松彦色止命系の阿波分流の祖
- → 阿波が **古代国家形成の重要拠点** だった証拠(🟡)

### 2. 海人族(那賀氏)の祖

- 韓背足尼命の後裔 = 那賀氏(長氏)
- 那賀氏 = [[海人族_MOC|阿波海人族]] の中核
- → 阿波長国造 = **海洋王権の系譜上の祖**

### 3. 隠岐との同祖関係

- 隠岐国造(十挨命)と **観松彦色止命を共通祖** とする
- → 古代の **阿波 ⇔ 隠岐 海上ネットワーク** の物的根拠
- → [[伊未自由来記_専門ノート]] の同祖記述と整合

### 4. 御間都比古神社の創建者

- 阿波佐那河内村の 式内社 御間都比古神社 = **韓背足尼が祖神を祀って創建**
- → 阿波における観松彦色止命祭祀の物的源頭
- 大正期に宮内省諸陵考証官が実地調査

### 5. 神武東征説との接続

阿波説では:
- 神武東征 = 阿波 → 大和への東遷
- 神武 → 綏靖 → ... → 孝昭(=観松彦色止命) → ... → 開化 の欠史八代が阿波在位
- 韓背足尼命 = この系譜の地方分流の祖
- → 阿波 = 王権母胎説の補強(🟡)

## 🧭 留保

- 韓背足尼命の **歴史的実在性** は、『国造本紀』記載の信頼性に依存する
- 『先代旧事本紀』自体が **平安期成立**(8 世紀末〜9 世紀)で、4 世紀の人物記録としての直接性は限定的
- 「韓背」の語義は学界での確定的解釈がない
- 観松彦色止命 = 孝昭天皇は **諡号の音通による比定** であり、確定的物証ではない
- 信頼度 3 は、『国造本紀』記述(🟢)の重要性と、人物そのものの直接物証の少なさ(🟡 + ⚪)の総合
