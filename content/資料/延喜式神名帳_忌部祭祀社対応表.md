# 📜 延喜式神名帳 忌部祭祀社対応表

> [!abstract] このノートの役割
> 『延喜式』神名帳(927 年成立)に掲載された **忌部関係式内社の全国対応表**。
>
> 阿波 50 座中の忌部祭祀社、および **東遷先各国** (讃岐・紀伊・出雲・筑紫・伊勢・安房・上総・下総・遠江・武蔵・常陸ほか)の忌部関係社を一覧化し、忌部諸族祖系譜の地理的展開を可視化する。

## 🌊 阿波説における意義

### 延喜式は忌部祭祀権の制度的確認

- 古語拾遺(807) → 神名帳(927) → 太政官符 1070
- **120 年スパンの 3 文献が同じ忌部祭祀権を確認**
- → 延喜式は **平安期国家による公式追認** の中段

### 忌部諸族祖系譜の地理的展開

- 阿波 → 讃岐 → 紀伊 → 出雲 → 筑紫 → 伊勢
- + 東遷:阿波 → 安房 → 上総 → 下総 → 武蔵 → 常陸 → 遠江
- 各国の式内社が **物理的痕跡** として残る

### 「麻殖郡」の郡名そのものが忌部の証言

- 郡名「麻殖(おえ)」 = 「麻を植える」
- 郡名そのものが忌部の本領を示す
- 全国唯一の事例(全国の郡名で「麻殖」を含むのは阿波のみ)

### 神階累進記録との一体性

延喜式は神階累進記録([[国史見在社_MOC]])と一体:
- 続日本紀(神階授与の開始期) → 続日本後紀 → 三代実録(累進記録)
- 太政官符 1070(累進の頂点)
- → [[国史見在社_MOC]] で総合索引
