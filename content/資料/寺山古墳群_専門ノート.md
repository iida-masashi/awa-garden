# 🪦 寺山古墳群(てらやまこふんぐん) 専門ノート

> [!abstract] このノートの役割
> 徳島県海陽町野江の **寺山古墳群** は、**3 世紀初頭** の **墳丘墓**(前方後円墳プロトタイプ以前)。
>
> - 阿波最南端の海岸地帯の重要古墳群
> - **寺山 3 号墳** から **内行花文鏡** 出土
> - 同型鏡が **萩原墳丘墓**(鳴門市)・**籠神社海部氏伝世鏡**(息津鏡・邊津鏡)に存在
> - **阿波 ⇔ 丹後 ⇔ 大陸(後漢)** の海洋交易ネットワークの物的物証
> - 阿波説では **羽衣伝説の天女(豊宇賀能賣命=豊受大神)の墓**、または **イザナミの神陵候補**
> - 隣接 **芝遺跡** から多地域交易土器(東阿波型・布留式・下川津 B・ヒビノキ式)出土
>
> 本ノートは、寺山古墳群を **阿波の大陸交易圏所属の物的物証** + **羽衣伝説・伊勢外宮元宮論の物的拠点** として統合的に位置づける。

## 🌟 第一章 物的物証 — 内行花文鏡

### 寺山 3 号墳出土 内行花文鏡

| 項目 | 内容 |
| --- | --- |
| 鏡種 | **内行花文鏡(ないこうかもんきょう)** |
| 起源 | **古代中国(後漢時代)** の青銅鏡 |
| 出土地 | 海陽町野江 寺山 3 号墳 |
| 学術的意義 | 3 世紀の阿波と大陸の直接交易物証 |

### 「内行花文鏡」とは

- 古代中国の青銅鏡形式の一つ
- **後漢〜三国時代**(1〜3 世紀)に流行
- 円周に沿って **花文(蓮華文・連弧文)** が内側に向かって展開
- 邪馬台国時代の倭の朝貢礼物として中国から輸入
- 倭の支配者層の墓に副葬されることが多い

→ 阿波が **大陸交易圏に直接接続** していた物的物証(🟢)

### 同型鏡の阿波・丹後ネットワーク

| 出土地 | 鏡 | 時代 |
| --- | --- | --- |
| **寺山 3 号墳**(海陽町野江) | 内行花文鏡 | 3 世紀初頭 |
| **萩原墳丘墓**(鳴門市大麻町萩原) | 内行花文鏡 | 3 世紀初頭(同型) |
| **籠神社海部氏伝世**(京都府宮津市) | **息津鏡**(内行花文長宜子孫八葉鏡、後漢、約 1,950 年前) | 約 1,950 年前 |
| **籠神社海部氏伝世** | **邊津鏡**(内行花文昭明鏡、前漢、約 2,050 年前) | 約 2,050 年前 |

→ **寺山 3 号墳・萩原墳丘墓・籠神社海部氏鏡** がすべて内行花文鏡系統(🟢)
→ 阿波(寺山・萩原) ⇔ 丹後(籠神社) の **海部氏ネットワーク** の物的証拠

## 🌐 第二章 芝遺跡(隣接) — 広域交易の中心地

### 立地と性格

- 寺山古墳群から **北東 200m** の位置
- **古墳時代初期**(約 1,800 年前=3 世紀)
- 林田真典氏ほかによる発掘
- → 寺山古墳群の被葬者層の **生活・交易拠点** と推定

### 出土土器の多地域構成

| 地域 | 土器 | 性格 |
| --- | --- | --- |
| **徳島** | **東阿波型土器** | 阿波の地元土器 |
| 香川 | 下川津 B 型土器 | 讃岐系 |
| 高知 | ヒビノキ式土器 | 土佐系 |
| 岡山 | (特定型) | 吉備系 |
| **関西** | **布留式土器** | **畿内系**(古墳前期の畿内代表土器) |

→ **「布留式土器」の出土点数の多さは徳島県内で類例なし**(🟢)
→ 阿波説では **海陽町・和奈佐は古代瀬戸内・近畿との海上交易の中継基地**

### 阿波説の意義

> 「芝遺跡では、頻繁な交流が行われた結果として、多くの土器が出土した」

- 寺山古墳群の被葬者 = 広域交易ネットワークの中心人物
- 羽衣伝説の天女が「天に帰った」 = **船で出港して別地へ向かった** ことの暗喩(⚪)
- → 海陽町・和奈佐 = **古代日本の東西交易のハブ**

## 🌊 第六章 阿波説における意義

### 1. 大陸交易圏の物的物証(🟢)

- 内行花文鏡 = 後漢(中国)の直接物証
- 阿波 ⇔ 大陸 の直接交易の確認
- 邪馬台国時代の阿波王権の物的根拠

### 2. 海部氏ネットワークの物的接続(🟢)

- 寺山 3 号墳 + 萩原墳丘墓 + 籠神社息津鏡・邊津鏡
- → 阿波 ⇔ 丹後 の海部氏海上ネットワーク
- 阿波本貫地説 vs 丹後発祥説の論争に物的根拠を提供

### 3. 羽衣伝説 = 阿波出立論(🟡)

- 「和奈佐」地名 + 寺山古墳群 + 芝遺跡 = 三点セットの物的拠点
- 伊勢神宮外宮 豊受大神の **本源地** 候補
- 丹後への伝承伝播の方向性

### 4. 邪馬台国阿波説の物的補強(🟡)

- 3 世紀初頭 = 卑弥呼時代と同時代
- 阿波の南北 + 海部郡 + 気延山 = 邪馬壹國の構造的密度
- 内行花文鏡 = 魏志倭人伝の鏡賜与記事との関連

### 5. 古墳発生期の阿波先行(🟡)

- 萩原墳丘墓(2 世紀末〜3 世紀初頭)= 前方後円墳プロトタイプ
- 寺山墳丘墓(3 世紀初頭)= 同時代の海部郡拠点
- 大和の **箸墓古墳**(3 世紀中葉以降)よりも早期
- → **古墳は阿波で発生し畿内へ伝播** という阿波説の物的根拠
