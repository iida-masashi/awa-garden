# 📜 伊未自由来記(いみじゆらいき) 専門ノート

> [!abstract] このノートの役割
> 隠岐諸島(島根県)に伝わる **古史古伝**『伊未自由来記』を、阿波説の文脈で位置づける本格論考。
>
> 本書は **記紀には登場しない隠岐独自の創成神話・人物系譜** を記録した口述伝承書で、成立年代・伝来不詳ながら、地元では古来から伝承されてきた。**コノハビト(木の葉比等)→ アマ(海人族)→ ヤマヅミ → 大人様 → 美豆別主命 → 奈賀命 → 隠岐国造**という 7 段階の支配者交代物語を通じて、**朝鮮半島(新羅)・出雲・北部九州(粕屋)・丹波・阿波** と古代隠岐の交流を描く。
>
> 学界では **偽書・古史古伝の一種** とされるが、KCI 韓国語論文(2008?)の言語学的分析や民謡『隠岐の子守唄』との符合から、**部分的に古い口承を保存している可能性** が指摘される。

## 🌟 第一章 七章構成 — 隠岐の支配者交代物語

『伊未自由来記』は **七章構成** で、隠岐の支配者を以下のように描く。各章の要点を整理する(原文は [[goutara_隠岐と阿波_2_END]] に部分引用)。

### 第一章:木の葉比等(コノハビト)

- 隠岐に **最初に住み着いた人間**
- 獣皮の上に **木の葉を塩水に漬けて乾かしたもの・川柳の皮を綴ったもの** を着る
- 髪を切らず延びたまま、目だけくるくる、人柄は良い
- 後世の **「木の葉爺・木の葉婆・箕爺・箕婆」** などの妖怪伝承の源
- **「西方千里加羅斯呂(からのしろふれ)」/「韓之徐羅(からのそら)国」** から来住したと伝える

#### 阿波説的論点

- 「斯呂触(しろふれ)」「徐羅(そら)」は **新羅の別名「ソラブル(徐羅伐)」** の音写の可能性
- → 朝鮮半島(新羅)からの移住伝承
- ただし新羅建国(BC57)以後と矛盾する記述は **後代の改変** の可能性

### 第二章:海人(阿麻=アマ)

- **鯨面文身**(顔と全身に入墨)した者たち
- コノハビトに次いで来住、当初対立したが温和で漁が上手 → 雑居
- 後にコノハビトは海人がつけた名称となる(支配/被支配の逆転)
- アマの長は **於佐神(おさのかみ)**、於母島(島後)の東後・奈岐の浦に居住
- この頃の隠岐の呼称:**「小之凝呂島(オノコロジマ)」**
- 出雲の **大山祇神** 一族も来航(少数)
- 於佐神が海賊に殺される

#### 阿波説的論点

- **隠岐 = 小之凝呂島(オノゴロ島)** とする独自伝承
- 阿波説の鳴門オノゴロ説と **両論並立** の関係
- 海人(アマ)= 入墨をした者 = 魏志倭人伝の「黥面文身」の倭人と一致(🟢)

### 第三章:山祇(ヤマヅミ)

- 出雲の **鞍山祇之大神** の御子 **沖津久斯山祇神(オキツクシヤマヅミ)** が小之凝呂島の神として来航
- 於母島の東大津に宮居
- やがて出雲が **於漏知(オロチ)** に奪われ、隠岐にも於漏知が侵入
- 於漏知は **踏鞴(たたら)を踏んで金属を作り、鎧・兜・盾・剣** を作る = **強力な渡来系金属技術集団**
- 山祇神は流宮の加須屋(かすや、福岡県粕屋郡か)の **大神祇大神** に救援を求める

#### 阿波説的論点

- 於漏知 = 八岐大蛇神話の **オロチ** = 出雲を制圧した渡来系金属民
- たたら製鉄 = 阿波説の **天目一箇命**(忌部五部神の鍛冶祖)と接続(🟡)
- → [[阿波の鉄と鍛冶技術：天目一箇神の足跡]]

### 第四章:大人様(ウシサマ)

- 流宮(加須屋)の **大海祇大神** が御子 **奈賀の大人様** に軍兵を率いて派遣
- 兵戦・武器・衣料・農工具・種子類を準備して出発
- 於漏知を討伐するが、於漏知は次々に渡来して油断ならず
- **6 代** にわたり闘争継続
- 6 代目が **出雲の大山祇神の姫** を娶り、その援助で於母の島(島後)全体を征服
- 三子の島(島前)征服のため本拠を **大津 → 公処(くむだ)** に移転
- 公処 = 後の宮田
- 地公の命(別名 **奈岐の命**)、奈岐の浦と呼ぶ

#### 阿波説的論点

- 「流宮の加須屋」 = 福岡県 **糟屋郡** との比定 → 阿波 ← 九州ルートの海上交流(🟡)
- 大人様の 6 代闘争 + 出雲大山祇神との通婚 = **氏族同盟による統一**
- 「奈岐の浦命の子孫は全島海部大神として栄えた」 → 隠岐に **海部氏** が存在(🟢)
- → 阿波の海部氏との同祖関係の可能性(🟡)

### 第五章:美豆別之主之命(ミズワケノヌシ)

- 別名:**小之凝呂別命・水別酢命・瑞別主命**
- **天津神の御子**
- 数多の **久米部・綾部・工部・玉造部** の民を率いて来島
- 奈岐命より小之凝呂島を譲り受け、奈岐の浦中の鼻に宮居・**目の城** を築く
- 大川沿いに農耕を進める
- **比等那公** に統治を委任
- 出雲との交流の中継地として **重栖(おもす)** = 後の「穏息」(おもす)港が韓国との交通要衝に
- 後に出雲で大きな戦いが起こり、大山祇大神勢力が衰退
- 出雲から **奈賀の命** が新たに来航 → 美豆別之主命は **久米部首** として主栖に移住

#### 阿波説的論点

- 美豆別之主之命 = **水若酢命(みずわかすのみこと)** と同一神(🟢)
- 隠岐国一の宮 **水若酢神社** の祭神
- 久米部・綾部・工部・玉造部 = **記紀の伴造制度** と同型
- 阿波の **玉作部・忌部** と並列構造(🟡)

→ [[水若酢神社]]・[[水若酢神社（隠岐の島町郡）  たんぽぽろぐ]] 参照

### 第六章:奈賀命(ナガノミコト)

- **后中言命(きさきなかごとのみこと)** とも称す
- **阿遅鍬高彦根命(あぢすきたかひこねのみこと)** の御子
- **丹波の須津姫** を娶って来島
- 新野川辺に宮居(後の蔵見)
- 農耕・開墾・溜池・道路・漁船の建造を進める
- 妻神須都姫命は **丹波の長自羽麻緒姫** と織女を迎えて織布を教える
- 薬師・医師を丹波の須津から招く
- **珠城宮天皇(垂仁天皇)** の皇子 **誉津部** の名代部を主栖に設置
- **日代宮天皇(景行天皇)** の代に **田部屯倉** を新野と主栖に設定
- **息長足姫皇后(神功皇后)** の三韓征伐に **美豆別主命(伴の首)** が久米部を率いて従軍
- **久米首の祖 伊未自姫** が **十挨命(隠岐国造)** の妻となり、十男子を生む

#### 阿波説的論点(本書の阿波接続の最重要点)

- **奈賀命 = 阿遅鍬高彦根命の御子** + **丹波の須津姫を娶る**
- → **阿波** の **阿遅鍬高彦根** 系祭祀 + **丹波** との婚姻 = **阿波・丹波・隠岐の三角ネットワーク**(🟡)
- 阿遅鍬高彦根 = 出雲系の神格、阿波では [[丹田古墳（加茂山）：阿遅鋤高日子根神の神陵と巨石文化]] で祀られる
- **「奈賀(なか)」 = 「長(なが)」** の音通 = **阿波長国造** との関連暗示(🟡)
- **久米首の祖 伊未自姫** → 本書のタイトル『伊未自由来記』の語源!(🟢)

### 第七章:国造

- **誉田天皇(応神天皇)** が **御間都比古伊呂止命(=孝昭天皇)五世の孫 十挨族命** を隠岐国造に任命
- 大津部・伊勢部・海部・山部・服部の五首が国造に協力
- この頃 **異国人の来襲** 盛ん → 沿岸防備を強化
- 道路開発・医師薬師の各邑配置・兵船の建造・賞罰の明確化
- 各部の氏神に領地を配し、敬神の志を厚く
- 孕婦の労力を禁じ、幼少老人病人に食衣を給する
- 密察使を置いて民情を糺し、漂着者の保護

#### 阿波説的論点(同祖関係の決定的記述)

- **「観松彦伊呂止命 五世孫 十挨命 = 隠岐国造」**
- **「観松彦伊呂止命 九世孫 韓背足尼命 = 長国造(阿波)」** ※先代旧事本紀『国造本紀』
- → **隠岐国造と阿波長国造は同祖**(🟢 確実)
- 観松彦伊呂止命 = **孝昭天皇**(欠史八代第 5 代)
- 阿波の 式内社 御間都比古神社 が観松彦色止命を主祭神とする全国唯一の社
- → [[欠史八代_MOC]]・[[goutara_隠岐と阿波_2_END]] 参照

- **観松彦伊呂止命 九世孫 韓背足尼命 = 阿波長国造**
- 阿波の 式内社 御間都比古神社(佐那河内村) = 観松彦色止命を主祭神とする全国唯一の社

→ **阿波 → 隠岐 への国造系譜の派遣**、または **同祖からの分岐**(🟡)

### 「奈賀(なか)」と「長(なが)」 — 言語的接続

- 隠岐 第六章の **「奈賀命」** = 阿遅鍬高彦根命の御子
- 阿波の **「長国(那賀郡)」** = 阿波長国造の領地
- 音通の偶然ではなく **氏族・地名の系譜的継承** の可能性(🟡)

### 「伊未自姫」 — 書名の語源 = 阿波関連?

- 第六章で **「久米首の祖 伊未自姫」** が十挨命の妻となり 10 男子を生む
- 本書のタイトル『伊未自由来記』 = この姫の系譜書
- 「伊未自(いみじ)」の語源は不詳だが、**忌部・斎部(いんべ・いみべ)** との音韻的近さに注目すべき(⚪)

### 海人族・出雲・丹波・北部九州ネットワーク

## ⚖ 第四章 史料批判 — 偽書論争

### 「偽書」とされる根拠

学界での『伊未自由来記』への一般的評価:

1. **成立年代不詳・原本不存在** — 写本のみで伝来経緯が不明
2. **記紀との矛盾** — 独自の神々が大量に登場、年代記の不整合
3. **「於漏知」のたたら製鉄記述** — 史料的に確認できる時期と矛盾
4. **「韓之徐羅国(新羅)由来」** — 新羅建国前の記述と整合しない
5. **6 代闘争の年数の矛盾** — 八岐大蛇神話との接続困難

### 「真書」性を支持する論点

近代の再評価:

1. **言語学的証拠** — KCI 韓国語論文(2008?)が **隠岐民謡に含まれる韓国語要素** を指摘し、本書の朝鮮半島由来説と整合
2. **海人(鯨面文身)記述** — 魏志倭人伝の倭人記述と一致
3. **国造同祖記述** — 『国造本紀』と整合する(観松彦伊呂止命系)
4. **久米部・綾部・工部・玉造部** — 記紀の伴造制度と整合
5. **民俗の連続性** — 「木の葉爺・木の葉婆」の妖怪伝承が現代まで残る
6. **隠岐の子守唄** との符合 — 民謡が本書の記述を裏付け

詳細:
- [[KCI_FI000940885_日本語要約|📜 KCI 論文 隠岐民謡韓国語要素]]
- [[隠岐の子守唄 The Oki Islands lullaby  inoueyukari|🎵 隠岐の子守唄]]

### 部分的真実説

阿波説 Vault の立場:
- **全体としての歴史的事実性は確定できない**
- しかし **口承伝承を反映した部分** が含まれる可能性
- 特に **国造同祖・海人族・氏族ネットワーク** の記述は他史料(『国造本紀』・魏志倭人伝)と整合
- 部分的に **古い口承を保存** している可能性(🟡)
