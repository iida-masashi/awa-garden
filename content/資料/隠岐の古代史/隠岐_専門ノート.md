# 🏝 隠岐(おき)諸島 専門ノート

> [!abstract] このノートの役割
> 隠岐諸島(島根県)を **阿波説の文脈** で位置づける本格論考。
>
> 隠岐は『国造本紀』により **観松彦色止命(=孝昭天皇)五世孫十挨命** を祖とする隠岐国造の地であり、阿波長国造と **同祖関係** にある。本ノートは、隠岐の地理・考古・神話・式内社・独自伝承(『伊未自由来記』)・中世以降の流刑地としての歴史を統合し、隠岐 = 阿波の海上ネットワークの一翼として再評価する。

## 🌟 第一章 三段証拠フレームでの隠岐

### 🟢 確実な事実

#### 1. 黒曜石交易の物的証拠

- **隠岐産黒曜石** が **3 万年前の兵庫県遺跡** で出土(国土交通省 [[mlit_隠岐に最初にやってきた人々]] 参照)
- 朝鮮半島からも出土事例
- → 先史時代から **広域交易ネットワークの拠点**
- 火山ガラスの分解されにくい性質により、考古学的指標として優秀

#### 2. 四隅突出型墳丘墓の存在

- **島後** に出雲式の四隅突出型墳丘墓
- 弥生時代(紀元前 300 〜西暦 300 年)末期
- 約 18m × 11m の長方形、四隅が突出
- → 古代出雲王朝の文化圏が隠岐まで及んだ物証

#### 3. 水若酢神社 — 隠岐国一の宮・名神大社

- 延喜式神名帳(927)で **名神大社**
- 隠岐国一の宮
- 主祭神:**水若酢命**(独自神)
- 配祀:鈴御前命・中言神
- 詳細:[[水若酢神社]]・[[水若酢神社（隠岐の島町郡）  たんぽぽろぐ]]

#### 4. 焼火神社 — 島前最高峰の海上信仰

- 島前最高峰の **焼火山(たくひやま)** 山頂
- 海上守護神としての中世以降の信仰
- 後鳥羽上皇配流(1221)・後醍醐天皇配流(1331)時にも信仰された
- 詳細:[[焼火神社]]

#### 5. 中世の流刑地

- **後鳥羽上皇**(承久の乱、1221 〜 1239 崩御)
- **後醍醐天皇**(元弘の乱、1331 〜 1333 脱出)
- → 中央朝廷から見た重要な遠隔地という認識

### 🟡 有力な推測

#### 1. 隠岐国造 = 阿波長国造 の同祖関係

『国造本紀』(『先代旧事本紀』所収)の記述:
- **隠岐国造**:「**観松彦色止命** 五世孫 **十挨命**」を祖とする
- **阿波長国造**:「**観松彦色止命**」を祖とする

→ 両者は同一の祖を持つ。**観松彦色止命 = 第 5 代孝昭天皇**(欠史八代)に比定される。

詳細:
- [[goutara_隠岐と阿波_2_END]] — 同祖論の詳論
- [[欠史八代_MOC]]
- [[阿波の核心氏族ハブ]]

#### 2. 海人族(アマ族)の広域ネットワーク

『伊未自由来記』(隠岐の独自伝承)による神々と人物:
- **コノハビト**(木の葉人) — 縄文人または先住民
- **アマ**(海人族) — 入墨をした出雲・北部九州系
- **オキツクシヤマヅミ** — アマの祖神(日本書紀になし)
- **オオアマヅミ** — 流宮(竜宮)加須屋(福岡県粕屋郡?)の祖神
- **オオヒト** — 奈賀の祖、オロチ討伐の英雄

→ 隠岐 ← 北部九州 ← 出雲 を結ぶ海人族ネットワーク
→ 阿波の海部族(忌部) も同質のネットワークの一翼

#### 3. 出雲文化圏の北限

- 四隅突出型墳丘墓・黒曜石交易圏が出雲と隠岐で重なる
- 出雲神話のオオヤマヅミ系譜が隠岐にも伝承される
- → 出雲王権の海洋的展開の証拠

### ⚪ 推測

#### 1. 隠岐 = オノゴロ島 説

『伊未自由来記』に「アマが栄えた頃に隠岐は **オノゴロ島** と呼ばれていた」との記述。
- 国生み神話の最初の島と同名
- 阿波説では国生み = 鳴門・淡路周辺なので、別系統の伝承
- 海人族の広域伝承が地方ごとに変異した可能性

#### 2. 『伊未自由来記』の韓国語要素

KCI 論文(韓国学術)による隠岐民謡の韓国語解釈:
- セイボン・ハイベンタイベンソウベン などのフレーズが韓国語起源と推定
- → 朝鮮半島からの海人族の到来との接続
- → 阿波説の海洋ネットワーク論と相補的

詳細:[[KCI_FI000940885_日本語要約]]

#### 3. 観松彦色止命の阿波での祭祀

- 阿波の 式内社 御間都比古神社 — 主祭神 観松彦色止命(全国唯一)
- 隠岐国造の祖と同神を阿波で祀る = 阿波が本貫地か
- → [[欠史八代_MOC]] の阿波母系継承論と接続

## 🌳 第三章 隠岐国造と億岐氏祠官家

- 隠岐国造の後裔とされる

## 🌊 第四章 阿波説における隠岐の意義

### 阿波と隠岐の構造的類似

| 観点 | 阿波 | 隠岐 |
| --- | --- | --- |
| 国造の祖 | 観松彦色止命 | 観松彦色止命 五世孫 十挨命 |
| 海人族 | 阿波忌部・海部氏 | アマ族(『伊未自由来記』) |
| 国生み伝承 | 鳴門・淡路 = オノゴロ | 隠岐 = オノゴロ(別系統) |
| 中央への貢物 | 麁服(大嘗祭) | 黒曜石・海産物 |
| 中世の地位 | 細川氏守護領 | 流刑地(後鳥羽・後醍醐) |
| 独自史料 | 古語拾遺・神別本紀 | 伊未自由来記 |

### 阿波説への寄与

1. **同祖神話の物証** — 観松彦色止命 = 阿波・隠岐の同祖は『国造本紀』の明文記載(🟢)
2. **海上ネットワークの実在性** — 黒曜石交易・出雲文化圏で物的に証明(🟢)
3. **独自史料の存在** — 『伊未自由来記』が記紀以外の伝承体系を保持(🟡)
4. **韓国朝鮮との接続** — 海人族ネットワークの広域性(⚪)

### 阿波説の補強と修正

- **補強**:隠岐の独立性 = 古代日本の中央集権ではない多元的構造(阿波説の根幹)
- **修正**:阿波 → 全国への一方向的展開ではなく、阿波・隠岐・出雲・北部九州の **多極ネットワーク** として捉え直し
