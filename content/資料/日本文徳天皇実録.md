# 『日本文徳天皇実録』

**日本文徳天皇実録（にほんもんとくてんのうじつろく）** は、六国史の一つ。

## 📚 基本情報

| 項目 | 内容 |
| --- | --- |
| **編纂完了** | 元慶3年（879年） |
| **対象期間** | 文徳天皇嘉祥3年（850）〜 天安2年（858） |
| **編者** | 藤原基経・菅原是善ほか |
| **巻数** | 全10巻 |

## 🏛 神社史料としての性格

文徳朝の僅か8年間を扱う短編史。地方神への奉幣・神階授与記録が集中する。陸奥（陸前高田・大船渡）の **理訓許段神・登奈孝志神・衣太手神** など、後の延喜式に載らない神々の記録を保存している。

### 主な神社関連記事
- 陸奥国（現岩手県沿岸部）への神階授与記事
- 東北辺境の祭祀体制
