# 🗺 邪馬台国阿波説 MOC

> [!abstract] このノートの役割
> 『魏志倭人伝』に記される **邪馬壹國(邪馬台国)= 徳島県** の阿波説を、**学術系譜・文献・考古学・地理** の四側面から統合する総合索引。
>
> 阿波説は **笠井新也(1922)** に学術的源流を持ち、現代では考古学・地理学・文献学を横断する複合論証として再構築されている。本 MOC は Vault 内の関連論考を主題別に整理し、学術的根拠の重層構造を可視化する。

## 🧬 学術系譜:笠井新也以降の阿波説研究史

### 笠井新也(1882-1970)— 邪馬台国阿波説の創始者

- **「邪馬台国は大和である」**(1922, 考古学雑誌) — 大和説の論文だが、阿波の地名・神話との接続を初めて学術的に提示
- **「卑弥呼の冢墓と箸墓」**(1942) — 卑弥呼=倭迹迹日百襲姫命説の起源
- 笠井の遺産:**地名・神話・考古学の三重照合方法** が現代阿波説の方法論的基礎に

- **畿内説**:寺澤薫(纏向遺跡)・石野博信

- **阿波説**:在野研究の伝統(笠井 → 岩利 → 大杉)+ 一部学者の支持

## 🌊 阿波説における意義

### 邪馬台国阿波説の三段証拠フレーム

#### 🟢 確実(物的・文献)

1. 若杉山辰砂採掘遺跡(国指定史跡)
2. 萩原墳墓群の年代測定(2 世紀末)
3. 宮谷古墳出土の三角縁神獣鏡
4. 短里 ≒ 77m の度量衡(歴史学的合意)
5. 周旋五千余里・東渡海千余里の里程

#### 🟡 有力

1. 短里換算で徳島県だけが里程条件を満たす
2. 「其山有丹」 = 若杉山辰砂
3. 畿内古墳への朱独占供給 = 卑弥呼権力の物的基盤
4. 阿波 → 畿内への古墳技術伝播(萩原 → ホケノ山 → 箸墓)
5. 港湾連合王権の地理的整合性

#### ⚪ 推測

1. 卑弥呼 = 天照大神 = 倭迹迹日百襲姫命
2. 卑弥呼墓 = 気延山五角形祭壇
3. 卑弥呼宮室 = 高根山悲願寺
4. 狗奴國 = 阿南市〜那賀町南端

## 🧭 留保

- 邪馬台国阿波説は **主流学界では少数派**。現在は畿内説(纏向遺跡を中心とする)が主流
- 卑弥呼の比定(天照大神・倭迹迹日百襲姫命など)は **⚪ 推測層** であり、確定的物証はない
- 笠井新也自身は **大和説** を主張したが、その方法論(地名・神話・考古学の三重照合)が現代阿波説の基礎となった構造に注意
- 阿波説支持者の中でも、邪馬壹國中心地の比定(神山・那賀・剣山周辺)には複数仮説が並立
- 本 MOC は阿波説支持者の視点から論証を整理したものであり、主流学界の反論(畿内発祥説・北九州先行説など)を網羅していない
