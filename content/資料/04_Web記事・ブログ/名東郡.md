**名東郡**（みょうどうぐん）は、[徳島県](https://ja.wikipedia.org/wiki/徳島県 "徳島県")（[阿波国](https://ja.wikipedia.org/wiki/阿波国 "阿波国")）の[郡](https://ja.wikipedia.org/wiki/郡 "郡")。

[人口](https://ja.wikipedia.org/wiki/人口 "人口")1,836人、[面積](https://ja.wikipedia.org/wiki/面積 "面積")42.28km²、[人口密度](https://ja.wikipedia.org/wiki/人口密度 "人口密度")43.4人/km²。（2026年10月1日、[推計人口](https://ja.wikipedia.org/wiki/推計人口 "推計人口")）

以下の1村を含む。

* [佐那河内村](https://ja.wikipedia.org/wiki/佐那河内村 "佐那河内村")（さなごうちそん）

## 郡域

[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")（[明治](https://ja.wikipedia.org/wiki/明治 "明治")12年）に行政区画として発足した当時の郡域は、上記1村のほか、[徳島市](https://ja.wikipedia.org/wiki/徳島市 "徳島市")の一部（[吉野川](https://ja.wikipedia.org/wiki/吉野川_(代表的なトピック) "吉野川 (代表的なトピック)")以南かつ[国府町矢野](https://ja.wikipedia.org/wiki/国府町矢野 "国府町矢野")、[国府町延命](https://ja.wikipedia.org/wiki/国府町延命 "国府町延命")、[一宮町](https://ja.wikipedia.org/wiki/一宮町_(徳島市) "一宮町 (徳島市)")以東かつ[津田海岸町](https://ja.wikipedia.org/wiki/津田海岸町 "津田海岸町")、[津田町](https://ja.wikipedia.org/wiki/津田町_(徳島市) "津田町 (徳島市)")、[津田本町](https://ja.wikipedia.org/wiki/津田本町 "津田本町")、[新浜本町](https://ja.wikipedia.org/wiki/新浜本町 "新浜本町")、[西新浜町](https://ja.wikipedia.org/wiki/西新浜町 "西新浜町")、[八万町](https://ja.wikipedia.org/wiki/八万町 "八万町")、[上八万町](https://ja.wikipedia.org/wiki/上八万町 "上八万町")以北および[三軒屋町](https://ja.wikipedia.org/wiki/三軒屋町_(徳島市) "三軒屋町 (徳島市)")の一部）にあたる。

## 歴史

かつては[名方郡](https://ja.wikipedia.org/wiki/名方郡 "名方郡")であったが、[寛平](https://ja.wikipedia.org/wiki/寛平 "寛平")8年（[896年](https://ja.wikipedia.org/wiki/896年 "896年")）に名方郡の東部が名東郡、西部が[名西郡](https://ja.wikipedia.org/wiki/名西郡 "名西郡")として2つに分かれた。また、[鎌倉時代](https://ja.wikipedia.org/wiki/鎌倉時代 "鎌倉時代")中期から[寛文](https://ja.wikipedia.org/wiki/寛文 "寛文")4年（[1664年](https://ja.wikipedia.org/wiki/1664年 "1664年")）までは一部が[以西郡](https://ja.wikipedia.org/wiki/以西郡 "以西郡")として分立していた。

### 近世以降の沿革

* [明治](https://ja.wikipedia.org/wiki/明治 "明治")初年時点で、全域が阿波**[徳島藩](https://ja.wikipedia.org/wiki/徳島藩 "徳島藩")**領であった。「[旧高旧領取調帳](https://ja.wikipedia.org/wiki/旧高旧領取調帳 "旧高旧領取調帳")」に記載されている村は以下の通り。（1町51村9浦）

:   徳島、下八万村、中村、矢野村、延命村、下町村、早淵村、一宮村、島田村、東名東村、南新居村、北新居村、佐野塚村、川原田村、東黒田村、敷地村、桜間村、和田村、西高輪村、南浜浦、山城屋浜村、北浜浦、上助任村、下助任村、富田浦、新浜浦、津田浦、南斎田浦、西名東村、住吉島村、大岡浦、福島浦、沖洲浦、蔵本村、佐古村、庄村、花園村、上八万村、祖母ヶ島村、北岩延村、池尻村、観音寺村、日開村、芝原村、東高輪村、南岩延村、下佐那河内村、上佐那河内村、田宮村、高崎村、今切村、矢三村、府中村、井戸村、西黒田村、末広新田、万代新田、大工島村、安宅村、前川村、常三島村

* 明治4年
  + [7月14日](https://ja.wikipedia.org/wiki/7月14日_(旧暦) "7月14日 (旧暦)")（[1871年](https://ja.wikipedia.org/wiki/1871年 "1871年")[8月29日](https://ja.wikipedia.org/wiki/8月29日 "8月29日")） - [廃藩置県](https://ja.wikipedia.org/wiki/廃藩置県 "廃藩置県")により徳島県（第1次）の管轄となる。
  + [11月15日](https://ja.wikipedia.org/wiki/11月15日_(旧暦) "11月15日 (旧暦)")（1871年[12月26日](https://ja.wikipedia.org/wiki/12月26日 "12月26日")） - 第1次府県統合により**[名東県](https://ja.wikipedia.org/wiki/名東県 "名東県")**の管轄となる。
* 明治9年（[1876年](https://ja.wikipedia.org/wiki/1876年 "1876年")）
  + [8月21日](https://ja.wikipedia.org/wiki/8月21日 "8月21日") - 第2次府県統合により**[高知県](https://ja.wikipedia.org/wiki/高知県 "高知県")**の管轄となる。
  + 南浜浦・北浜浦が合併して沖浜村となる。（1町52村7浦）
* 明治12年（[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")）[1月4日](https://ja.wikipedia.org/wiki/1月4日 "1月4日") - [郡区町村編制法](https://ja.wikipedia.org/wiki/郡区町村編制法 "郡区町村編制法")の高知県での施行により行政区画としての**名東郡**が発足。「勝浦名東郡役所」が徳島寺島町に設置され、[勝浦郡](https://ja.wikipedia.org/wiki/勝浦郡 "勝浦郡")とともに管轄。
* 明治13年（[1880年](https://ja.wikipedia.org/wiki/1880年 "1880年")）[3月2日](https://ja.wikipedia.org/wiki/3月2日 "3月2日") - **徳島県**（第2次）の管轄となる。
* 明治14年（[1881年](https://ja.wikipedia.org/wiki/1881年 "1881年")） - 佐古村の一部が分立して南佐古村となる。（1町53村7浦）
* 明治15年（[1882年](https://ja.wikipedia.org/wiki/1882年 "1882年")） - 福島浦が改称して福島本町となり、徳島の一部となる。（1町53村6浦）

1.加茂村 2.沖洲村 3.斎津村 4.八万村 5.上八万村 6.佐那河内村 7.国府村 8.加茂名村 9.新居村 10.南井上村 11.北井上村（紫：徳島市 青：合併なし ＊は発足時の徳島市）

* 明治22年（[1889年](https://ja.wikipedia.org/wiki/1889年 "1889年")）[10月1日](https://ja.wikipedia.org/wiki/10月1日 "10月1日") - [町村制](https://ja.wikipedia.org/wiki/町村制 "町村制")の施行により、以下の各村が発足。特記以外は全域が現・徳島市。（11村）
  + **[加茂村](https://ja.wikipedia.org/wiki/加茂町_(徳島県名東郡) "加茂町 (徳島県名東郡)")** ← 上助任村、田宮村、矢三村、今切村
  + **[沖洲村](https://ja.wikipedia.org/wiki/沖洲村 "沖洲村")** ← 沖洲浦村、末広新田、大岡浦
  + **[斎津村](https://ja.wikipedia.org/wiki/斎津村 "斎津村")** ← 津田浦、新浜浦、万代新田、南斎田浦
  + **[八万村](https://ja.wikipedia.org/wiki/八万村 "八万村")** ← 沖浜村、山城屋浜村、下八万村
  + **[上八万村](https://ja.wikipedia.org/wiki/上八万村 "上八万村")** ← 一宮村、下町村、上八万村
  + **[佐那河内村](https://ja.wikipedia.org/wiki/佐那河内村 "佐那河内村")** ← 上佐那河内村、下佐那河内村（**現存**）
  + **[国府村](https://ja.wikipedia.org/wiki/国府町_(徳島県) "国府町 (徳島県)")** ← 観音寺村、府中村、中村、矢野村、延命村、早淵村、和田村、南岩延村、北岩延村
  + **[加茂名村](https://ja.wikipedia.org/wiki/加茂名町 "加茂名町")** ← 庄村、島田村、東名東村、西名東村、蔵本村
  + **[新居村](https://ja.wikipedia.org/wiki/新居町_(徳島県) "新居町 (徳島県)")** ← 南新居村、北新居村、高崎村
  + **[南井上村](https://ja.wikipedia.org/wiki/南井上村 "南井上村")** ← 井戸村、花園村、東高輪村、西高輪村、日開村、池尻村、敷地村、川原田村、桜間村
  + **[北井上村](https://ja.wikipedia.org/wiki/北井上村 "北井上村")** ← 芝原村、東黒田村、西黒田村、佐野塚村、祖母ヶ島村
  + [市制](https://ja.wikipedia.org/wiki/市制 "市制")の施行により徳島・大工島村・安宅村・住吉島村・前川村・下助任村・常三島村・富田浦・佐古村・南佐古村の区域をもって**[徳島市](https://ja.wikipedia.org/wiki/徳島市 "徳島市")**が発足し、郡より離脱。
* 明治24年（[1891年](https://ja.wikipedia.org/wiki/1891年 "1891年")）[4月1日](https://ja.wikipedia.org/wiki/4月1日 "4月1日") - [郡制](https://ja.wikipedia.org/wiki/郡制 "郡制")を施行。郡役所が本郡単独となる。
* 明治41年（[1908年](https://ja.wikipedia.org/wiki/1908年 "1908年")）[7月1日](https://ja.wikipedia.org/wiki/7月1日 "7月1日") - 国府村が町制施行して**[国府町](https://ja.wikipedia.org/wiki/国府町_(徳島県) "国府町 (徳島県)")**となる。（1町10村）
* [大正](https://ja.wikipedia.org/wiki/大正 "大正")4年（[1915年](https://ja.wikipedia.org/wiki/1915年 "1915年")）[11月10日](https://ja.wikipedia.org/wiki/11月10日 "11月10日") - 加茂名村が町制施行して**[加茂名町](https://ja.wikipedia.org/wiki/加茂名町 "加茂名町")**となる。（2町9村）
* 大正12年（[1923年](https://ja.wikipedia.org/wiki/1923年 "1923年")）4月1日 - 郡会が廃止。郡役所は存続。
* 大正15年（[1926年](https://ja.wikipedia.org/wiki/1926年 "1926年")）
  + 4月1日 - 斎津村・沖洲村が徳島市に編入。（2町7村）
  + 7月1日 - 郡役所が廃止。以降は地域区分名称となる。
* [昭和](https://ja.wikipedia.org/wiki/昭和 "昭和")8年（[1933年](https://ja.wikipedia.org/wiki/1933年 "1933年")）4月1日 - 加茂村が町制施行して**[加茂町](https://ja.wikipedia.org/wiki/加茂町_(徳島県名東郡) "加茂町 (徳島県名東郡)")**となる。（3町6村）
  + [10月1日](https://ja.wikipedia.org/wiki/10月1日 "10月1日") - 加茂町の一部（上助任の一部）[板野郡](https://ja.wikipedia.org/wiki/板野郡 "板野郡")[川内村](https://ja.wikipedia.org/wiki/川内村_(徳島県) "川内村 (徳島県)")に編入。
* 昭和12年（[1937年](https://ja.wikipedia.org/wiki/1937年 "1937年")）
  + 4月1日 - 加茂名町・八万村が徳島市に編入。（2町5村）
  + 10月1日 - 加茂町が徳島市に編入。（1町5村）
* 昭和27年（[1952年](https://ja.wikipedia.org/wiki/1952年 "1952年")）[1月1日](https://ja.wikipedia.org/wiki/1月1日 "1月1日") - 新居村が町制施行して**[新居町](https://ja.wikipedia.org/wiki/新居町_(徳島県) "新居町 (徳島県)")**となる。（2町4村）
* 昭和30年（[1955年](https://ja.wikipedia.org/wiki/1955年 "1955年")）
  + 1月1日（1町4村）
    - 新居町が徳島市に編入。
    - 国府町が名西郡[入田村](https://ja.wikipedia.org/wiki/入田村_(徳島県) "入田村 (徳島県)")の一部（矢野）を編入。
  + [2月1日](https://ja.wikipedia.org/wiki/2月1日 "2月1日") - 国府町・北井上村・南井上村が合併し、改めて**国府町**が発足。（1町2村）
  + [2月11日](https://ja.wikipedia.org/wiki/2月11日 "2月11日") - 上八万村が徳島市に編入。（1町1村）
* 昭和42年（[1967年](https://ja.wikipedia.org/wiki/1967年 "1967年")）1月1日 - 国府町が徳島市に編入。（1村）
