鳥居

**阿波命神社**（あわのみことじんじゃ）は、[東京都](https://ja.wikipedia.org/wiki/東京都 "東京都")[神津島村](https://ja.wikipedia.org/wiki/神津島村 "神津島村")長浜にある[神社](https://ja.wikipedia.org/wiki/神社 "神社")。[式内社](https://ja.wikipedia.org/wiki/式内社 "式内社")（[名神大社](https://ja.wikipedia.org/wiki/名神大社 "名神大社")）で、[旧社格](https://ja.wikipedia.org/wiki/近代社格制度 "近代社格制度")は[府社](https://ja.wikipedia.org/wiki/府社 "府社")。

[神津島](https://ja.wikipedia.org/wiki/神津島 "神津島")北部、長浜から入った谷部に鎮座する。

## 祭神

祭神は次の1柱。

* **阿波咩命** （あわのめのみこと、阿波命/阿波比咩命）

  :   神津島の開拓神であると伝えられる。『[続日本後紀](https://ja.wikipedia.org/wiki/続日本後紀 "続日本後紀")』によると、三嶋神（[伊豆国](https://ja.wikipedia.org/wiki/伊豆国 "伊豆国")[一宮](https://ja.wikipedia.org/wiki/一宮 "一宮")の[三嶋大社](https://ja.wikipedia.org/wiki/三嶋大社 "三嶋大社")祭神）の本后であるといい、物忌奈命（[物忌奈命神社](https://ja.wikipedia.org/wiki/物忌奈命神社 "物忌奈命神社")祭神）はその[御子神](https://ja.wikipedia.org/wiki/御子神 "御子神")であるという。

[鎌倉時代](https://ja.wikipedia.org/wiki/鎌倉時代 "鎌倉時代")末期の成立とされる『[三宅記](https://ja.wikipedia.org/wiki/三宅記 "三宅記")』では、三嶋神が神集島（神津島）に置いた「**長浜の御前**」から長子「たゝない王子（たたない王子）」、次子「たふたい王子」が生まれたと記す。これら3神の社はそれぞれ阿波命神社、物忌奈命神社、[日向神社](https://ja.wikipedia.org/wiki/物忌奈命神社#関係地 "物忌奈命神社")に比定される。

そのほか、「阿波」の神名から、[忌部氏](https://ja.wikipedia.org/wiki/忌部氏 "忌部氏")が[阿波国](https://ja.wikipedia.org/wiki/阿波国 "阿波国")から[安房国](https://ja.wikipedia.org/wiki/安房国 "安房国")に東遷する際（[忌部氏の東遷](https://ja.wikipedia.org/wiki/忌部氏#阿波忌部の東遷説話 "忌部氏")）、当地に逗留したことに由来するという伝承もある。[平田篤胤](https://ja.wikipedia.org/wiki/平田篤胤 "平田篤胤")は『[古史伝](https://ja.wikipedia.org/wiki/古史伝 "古史伝")』伊古奈比咩命神社項において、阿波咩命を[天津羽羽神](https://ja.wikipedia.org/wiki/天津羽羽神?action=edit&redlink=1 "天津羽羽神 (存在しないページ)")（あまつはばのかみ、[天石門別神](https://ja.wikipedia.org/wiki/天石門別神 "天石門別神")の娘神）に比定している。

## 歴史

[![](images/330px-Kozushima_island.JPG)](https://ja.wikipedia.org/wiki/ファイル:Kozushima_island.JPG)

[神津島](https://ja.wikipedia.org/wiki/神津島 "神津島")全景

中央は、[承和](https://ja.wikipedia.org/wiki/承和_(日本) "承和 (日本)")5年（[838年](https://ja.wikipedia.org/wiki/838年 "838年")）に大噴火を起こした[天上山](https://ja.wikipedia.org/wiki/天上山_(東京都) "天上山 (東京都)")。その下の浜辺（長浜）に阿波命神社が、右端の集落に[物忌奈命神社](https://ja.wikipedia.org/wiki/物忌奈命神社 "物忌奈命神社")が鎮座する。

### 概史

創建は不詳。

国史の初見は『[続日本後紀](https://ja.wikipedia.org/wiki/続日本後紀 "続日本後紀")』の[承和](https://ja.wikipedia.org/wiki/承和_(日本) "承和 (日本)")7年（[840年](https://ja.wikipedia.org/wiki/840年 "840年")）における記事で、上津島（[神津島](https://ja.wikipedia.org/wiki/神津島 "神津島")）に坐す神は阿波神は「三嶋大社本后」である旨、物忌奈乃命はその御子神である旨、そしてこの神々のため神宮四院が新たに造営された旨が記載されている。同記事では、続いて神院の様子が描写される。そして、去る承和5年（[838年](https://ja.wikipedia.org/wiki/838年 "838年")）7月5日夜に神津島で激しい噴火が発生したといい、占いの結果、それは三嶋大社の後后が位階を賜ったにもかかわらず、本后たる阿波神には沙汰がないことに対する怒りによるものだと見なされた。同記事にある「後后」とは、[静岡県](https://ja.wikipedia.org/wiki/静岡県 "静岡県")[下田市](https://ja.wikipedia.org/wiki/下田市 "下田市")の[伊古奈比咩命神社](https://ja.wikipedia.org/wiki/伊古奈比咩命神社 "伊古奈比咩命神社")祭神を指すとされており、先の天長9年（[832年](https://ja.wikipedia.org/wiki/832年 "832年")）には三嶋神・伊古奈比咩命両神を名神に預けるという記事が載っている。

上記の承和7年の記事を受けて、約一ヶ月後に阿波神・物忌奈乃命両神の[神階](https://ja.wikipedia.org/wiki/神階 "神階")は無位から従五位下に昇った。その後はいずれも物忌奈命とともに、[嘉祥](https://ja.wikipedia.org/wiki/嘉祥 "嘉祥")3年（[850年](https://ja.wikipedia.org/wiki/850年 "850年")）に従五位上が授けられたのち、同年には[官社](https://ja.wikipedia.org/wiki/官社 "官社")に列し、[仁寿](https://ja.wikipedia.org/wiki/仁寿 "仁寿")2年（[852年](https://ja.wikipedia.org/wiki/852年 "852年")）には正五位下に昇った。

[延長](https://ja.wikipedia.org/wiki/延長_(元号) "延長 (元号)")5年（[927年](https://ja.wikipedia.org/wiki/927年 "927年")）成立の『[延喜式](https://ja.wikipedia.org/wiki/延喜式 "延喜式")』[神名帳](https://ja.wikipedia.org/wiki/延喜式神名帳 "延喜式神名帳")では、[伊豆国](https://ja.wikipedia.org/wiki/伊豆国 "伊豆国")[賀茂郡](https://ja.wikipedia.org/wiki/賀茂郡 "賀茂郡")に「阿波神社 名神大」と記載され、[名神大社](https://ja.wikipedia.org/wiki/名神大社 "名神大社")に列している。現在の東京都の中で、名神大社は阿波命神社と物忌奈命神社のみである。

[中世](https://ja.wikipedia.org/wiki/中世 "中世")の『[伊豆国神階帳](https://ja.wikipedia.org/wiki/伊豆国神階帳 "伊豆国神階帳")』では伊豆国[田方郡](https://ja.wikipedia.org/wiki/田方郡 "田方郡")に三嶋神の次に「一品きさきの宮」と記載されているが、これは阿波咩命が三嶋大社に招祭されたことによるとされる。

[近世](https://ja.wikipedia.org/wiki/近世 "近世")には、当社は「長浜明神」「長浜御前」と称された。

[明治](https://ja.wikipedia.org/wiki/明治 "明治")21年（[1888年](https://ja.wikipedia.org/wiki/1888年 "1888年")）9月1日、[近代社格制度](https://ja.wikipedia.org/wiki/近代社格制度 "近代社格制度")において[府社](https://ja.wikipedia.org/wiki/府社 "府社")に列した。

## 境内

[![](images/250px-Awanomikoto-jinja_honden.JPG)](https://ja.wikipedia.org/wiki/ファイル:Awanomikoto-jinja_honden.JPG)

本殿

前述の『[続日本後紀](https://ja.wikipedia.org/wiki/続日本後紀 "続日本後紀")』[承和](https://ja.wikipedia.org/wiki/承和_(日本) "承和 (日本)")7年（[840年](https://ja.wikipedia.org/wiki/840年 "840年")）9月23日の記事では、「伊豆国言」の中で次の記述がある。

|  |  |  |
| --- | --- | --- |
|  | 其嶋東北角、有新造神院、其中有壟、高五百許丈、基周八百許丈、其形如伏鉢、東方片岸有階四重、青黄赤白色沙次第敷之、其上有一閣室、高四許丈、次南海邊有二石室、各長十許丈、廣四許丈、高三許丈、其裏五色稜石、屏風立之、巖壁伐波、山川飛雲、其形微妙難名、其前懸夾纈軟障、即有美麗濱、以五色沙成修、次南傍有一礒、如立屏風、其色三分之二悉金色矣、眩曜之状不可敢記、云々 |  |
| —『続日本後紀』承和7年9月23日条（抜粋） | | |

このうち冒頭の「神院」が阿波命神社を指すとされており、「其中有壟」以下で記された神院の描写は現社地や周辺の形状に一致するとされる。特に文中では「即有美麗濱、以五色沙成修」とあるが、現在の長浜の浜辺も様々な色な小石から成り「五色浜」とも呼ばれている。このように、阿波命神社境内は古代神社の立地を現代に伝えるとされることから、境内は「神津島阿波命神社境域」として東京都指定史跡に指定されている。

社殿は[昭和](https://ja.wikipedia.org/wiki/昭和 "昭和")63年（[1988年](https://ja.wikipedia.org/wiki/1988年 "1988年")）の集中豪雨で倒壊した後、[平成](https://ja.wikipedia.org/wiki/平成 "平成")4年（[1992年](https://ja.wikipedia.org/wiki/1992年 "1992年")）に復元修理された。
