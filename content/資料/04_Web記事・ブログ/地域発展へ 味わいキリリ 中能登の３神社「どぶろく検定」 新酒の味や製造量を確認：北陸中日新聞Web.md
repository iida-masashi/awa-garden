# 地域発展へ 味わいキリリ 中能登の３神社「どぶろく検定」 新酒の味や製造量を確認

2025年11月13日 05時05分 (11月13日 05時06分更新)

![どぶろくの味を確認する船木清崇禰宜（左）ら＝中能登町二宮で](images/465612e6341b3c96a6fdb5d040794a34_1.jpg)

どぶろくの味を確認する船木清崇禰宜（左）ら＝中能登町二宮で

神事などに使われるどぶろくの新酒の味や製造量、アルコール度数などを調べる「どぶろく検定」が１２日、中能登町であった。町はどぶろくを使った地域おこしを進めており、来年１月に生産者数百人を招いた「第１７回全国どぶろく大会」が町で初開催されるのに合わせ、町観光協会は試飲イベントを企画するなどして地元の魅力を発信する。（浜中創太）

検定を受けたのは天日陰比咩（あめひかげひめ）（二宮）、能登比咩（ひめ）（能登部下）、能登部（能登部上）の３神社。金沢国税局の坂本和俊鑑定官室長と、七尾税務署の宮村孝廉署長が各神社を訪れ、味や製造量などを確認した。アルコール度数は、同局に持ち帰って検査する。
