**大国主**（オオクニヌシ、[歴史的仮名遣](https://ja.wikipedia.org/wiki/歴史的仮名遣 "歴史的仮名遣")：オホクニヌシ）は、[日本神話](https://ja.wikipedia.org/wiki/日本神話 "日本神話")に登場する[神](https://ja.wikipedia.org/wiki/神_(神道) "神 (神道)")。[国津神](https://ja.wikipedia.org/wiki/天津神・国津神#概要 "天津神・国津神")の代表的な神で、国津神の主宰神とされる。

## 神話における記述

[![](images/250px-Susanowo_family_tree.png)](https://ja.wikipedia.org/wiki/ファイル:Susanowo_family_tree.png)

須佐之男命から大国主神までの系図（『古事記』による）。青は男神、赤は女神

『[古事記](https://ja.wikipedia.org/wiki/古事記 "古事記")』・『[日本書紀](https://ja.wikipedia.org/wiki/日本書紀 "日本書紀")』の異伝や『[新撰姓氏録](https://ja.wikipedia.org/wiki/新撰姓氏録 "新撰姓氏録")』によると、[須佐之男命](https://ja.wikipedia.org/wiki/スサノオ "スサノオ")の6世の孫、また『日本書紀』の別の一書には7世の孫などとされている。父は[天之冬衣神](https://ja.wikipedia.org/wiki/天之冬衣神 "天之冬衣神")、母は[刺国若比売](https://ja.wikipedia.org/wiki/刺国若比売 "刺国若比売")。また『日本書紀』正文によると素戔嗚尊の息子。日本国を創った神とされている。

須佐之男命の娘である[須勢理毘売命](https://ja.wikipedia.org/wiki/スセリビメ "スセリビメ")との婚姻の後に[スクナビコナ](https://ja.wikipedia.org/wiki/スクナビコナ "スクナビコナ")と協力して天下を経営し、[禁厭](https://ja.wikipedia.org/wiki/禁厭 "禁厭")、医薬などの道を教え、[大物主神](https://ja.wikipedia.org/wiki/大物主 "大物主")を祀ることによって[葦原中国](https://ja.wikipedia.org/wiki/葦原中国 "葦原中国")の国作りを完成させる。だが、[高天原](https://ja.wikipedia.org/wiki/高天原 "高天原")からの[高御産巣日神](https://ja.wikipedia.org/wiki/タカミムスヒ "タカミムスヒ")の使者に[国譲り](https://ja.wikipedia.org/wiki/国譲り "国譲り")を要請され、対話と武力を交えた交渉の末に[幽冥界](https://ja.wikipedia.org/wiki/常世 "常世")の主、幽事の主宰者となった。国譲りの際にかつて須佐之男命から賜って建立した「富足る天の御巣の如き」大きな宮殿（[出雲大社](https://ja.wikipedia.org/wiki/出雲大社 "出雲大社")）を修復してほしいと条件を出したことに[天津神](https://ja.wikipedia.org/wiki/天津神・国津神#天津神 "天津神・国津神")が同意したことにより、このときの名を杵築大神（きづきのおおかみ）ともいう。

大国主神を扱った話として、因幡の白兎の話、[根の国](https://ja.wikipedia.org/wiki/根の国 "根の国")訪問の話、[沼河比売](https://ja.wikipedia.org/wiki/沼河比売 "沼河比売")への妻問いの話が『古事記』に、国作り、国譲り等の神話が『古事記』と『日本書紀』に記載されている（但し、『日本書紀』では「大国主神」という神名ではない）。『[出雲国風土記](https://ja.wikipedia.org/wiki/出雲国風土記 "出雲国風土記")』においても多くの説話に登場し、例えば意宇郡母里郷（現在の[島根県](https://ja.wikipedia.org/wiki/島根県 "島根県")[安来市](https://ja.wikipedia.org/wiki/安来市 "安来市")）の条には「越八口」を大穴持命が平定し、その帰りに国譲りの宣言をしたという説話がある。また山陰、四国、近畿、三遠信、北陸、関東など広範囲における地方伝承にも度々登場する。

## 別称

* 大国主は多くの別名を持つ。（※名義は[新潮日本古典集成](https://ja.wikipedia.org/wiki/新潮日本古典集成 "新潮日本古典集成")神名釈義から） 同名の記載順は『古事記』、『日本書紀』、『風土記』、『旧事紀』、その他[祝詞](https://ja.wikipedia.org/wiki/祝詞 "祝詞")や神社とする。
* 大国主神（おおくにぬし の かみ）・大国主大神 - [根国](https://ja.wikipedia.org/wiki/根国 "根国")から帰ってからの名。「偉大な国の主人」の意。
* 大穴牟遅神（おおあなむぢ-）・大己貴命（おおなむち-）・於褒婀娜武智（おほあなむち-）・大穴持命（おおあなもち-、『出雲国風土記』、『[伊予国風土記](https://ja.wikipedia.org/wiki/伊予国風土記?action=edit&redlink=1 "伊予国風土記 (存在しないページ)")』逸文での表記』）・大汝命（おおなむち-、『[播磨国風土記](https://ja.wikipedia.org/wiki/播磨国風土記 "播磨国風土記")』での表記）・大名持神（おおなもち-）・国作大己貴命（くにつくりおおなむち-） - 誕生後の名。
* 八千矛神（やちほこ-） - 沼河比売との歌物語での名。「多くの矛」の意。
* 葦原色許男・葦原醜男・葦原志許乎 / 葦原志挙乎命（あしはらのしこを） - 根国での侮蔑を込めた呼称。「地上の現実の国にいる醜い男」の意。
* 三諸神（みもろ の かみ）・大物主神（おおものぬし-）・八戸挂須御諸命 / 大物主葦原志許（やとかけすみもろ の みこと / おおものぬしあしはらのしこ、『播磨国風土記』での表記） - 『古事記』においては別の神、『日本書紀』においては国譲り後の別名。「偉大な精霊の主」の意。
* 宇都志国玉神（うつしくにたま-）・顕国玉神 - 根国から帰ってからの名。「現実の[国の神霊](https://ja.wikipedia.org/wiki/国魂 "国魂")」の意。
* [大国魂神](https://ja.wikipedia.org/wiki/大国魂神 "大国魂神")（おおくにたま-） - 各地の神社で同一視される。「偉大な国の神霊」の意。
* 伊和大神（いわ の おおかみ）・国堅大神（くにかためましし おおかみ）・占国之神（くにしめましし かみ）・大神 - [伊和神社](https://ja.wikipedia.org/wiki/伊和神社 "伊和神社")主神 - 『播磨国風土記』での呼称。
* 所造天下大神（あめのしたつくらしし おおかみ） - 『出雲国風土記』における尊称。「地上の国造った神」の意。
* 地津主大己貴神（くにつぬしおおなむち の かみ）・国作大己貴神（くにつくりおおなむちのかみ） - 祝詞『大国神甲子祝詞』での呼称。
* 幽世大神（かくりよ の おおかみ） - 祝詞『幽冥神語』での呼称。
* 幽冥主宰大神 （かくりごとしろしめすおおかみ） - 「[幽冥界](https://ja.wikipedia.org/wiki/幽世 "幽世")を主宰する神」の意。
* 杵築大神（きづき の おおかみ）

このうち、大穴牟遅神について、記紀神話で少名毘古那神と連携して国土経営を行って著しい功績を残し、2神は多くの伝承に連称して現れる。
[白鳥庫吉](https://ja.wikipedia.org/wiki/白鳥庫吉 "白鳥庫吉")は「オオナ」は「スクナ」（少兄、宿禰）に対する「大兄」と解釈している。
また「ナ」の文献上の表記例では、[和名類聚抄](https://ja.wikipedia.org/wiki/和名類聚抄 "和名類聚抄")では大穴はオホナと発音が振られ、『古事記』では「大穴牟遅」、『日本書紀』の万葉仮名では「オホアナムチ」、『[万葉集](https://ja.wikipedia.org/wiki/万葉集 "万葉集")』では「大穴道」などと表記されるため「洞窟」を指す言葉だと推定されている。
また「ムチ」は「貴い神」を表す尊称で、神名に「ムチ」が附く神は大己貴のほかには[大日孁貴](https://ja.wikipedia.org/wiki/大日孁貴 "大日孁貴")（オオヒルメムチ、天照大御神の別名）、[道主貴](https://ja.wikipedia.org/wiki/道主貴 "道主貴")（ミチヌシノムチ、[宗像三女神](https://ja.wikipedia.org/wiki/宗像三女神 "宗像三女神")の別名）、[布波能母遅久奴須奴神](https://ja.wikipedia.org/wiki/布波能母遅久奴須奴神 "布波能母遅久奴須奴神")、[八島牟遅能神](https://ja.wikipedia.org/wiki/八島牟遅能神 "八島牟遅能神")など、わずかしか見られない。

## 信仰

『古事記』上つ巻、及び『日本書紀』神代紀（下）に拠れば、スクナビコナらと共に「大国主神が行った国作りとは、人々に農業や医術を教え、生活や社会を作ること」であったとされる。荒ぶる八十神を平定して日本の国土経営の礎を築いた。また出雲大神には[祟り神](https://ja.wikipedia.org/wiki/祟り神 "祟り神")としての側面があり、転じて「病を封じる神（医療神）」になったという。『古事記』には、出雲大神の[祟り](https://ja.wikipedia.org/wiki/祟り "祟り")で口がきけなかった[本牟智和気命](https://ja.wikipedia.org/wiki/本牟智和気命 "本牟智和気命")（[垂仁天皇](https://ja.wikipedia.org/wiki/垂仁天皇 "垂仁天皇")第一皇子）が、出雲大神に参拝することで口が利けるようになったとの逸話がある。

医療神としての信仰の事例を近世挙げると、[1883年](https://ja.wikipedia.org/wiki/1883年 "1883年")（明治16年）10月に[明治天皇](https://ja.wikipedia.org/wiki/明治天皇 "明治天皇")[皇后](https://ja.wikipedia.org/wiki/皇后 "皇后")（[昭憲皇太后](https://ja.wikipedia.org/wiki/昭憲皇太后 "昭憲皇太后")）もしくは大正天皇の生母[柳原愛子](https://ja.wikipedia.org/wiki/柳原愛子 "柳原愛子")が病弱だった明宮（のち[大正天皇](https://ja.wikipedia.org/wiki/大正天皇 "大正天皇")）の健康を祈り、[出雲大社](https://ja.wikipedia.org/wiki/出雲大社 "出雲大社")より大国主の分霊をとりよせ、明宮が生活していた[中山忠能](https://ja.wikipedia.org/wiki/中山忠能 "中山忠能")邸の神殿に祀っている。

大正天皇は皇太子時代の1907年（明治40年）[5月27日](https://ja.wikipedia.org/wiki/5月27日 "5月27日")、軍令部長[東郷平八郎](https://ja.wikipedia.org/wiki/東郷平八郎 "東郷平八郎")大将と共に、出雲大社を参拝した。先述の「記紀にて人々に医術を教えた事による医療神信仰」に加えて、大正天皇は[己卯](https://ja.wikipedia.org/wiki/己卯 "己卯")の年の生まれ（平易に言えば干支は卯年の生まれ）であるので、（大国主の兄弟神たち・八十神に嘘の治療法を教えられて浜辺で泣いていた兎を正しい治療法・蒲の穂の花粉で癒やしたという[因幡の白兎](https://ja.wikipedia.org/wiki/因幡の白兎 "因幡の白兎")の）逸話等から験を担いだものとされる。

### 神仏習合

「大国」はダイコクとも読めることから同じ音である[大黒天](https://ja.wikipedia.org/wiki/大黒天 "大黒天")（大黒様）と習合していった。
