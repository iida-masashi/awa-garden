**延喜式神名帳**（えんぎしき じんみょうちょう、しんめいちょう）は、[延長](https://ja.wikipedia.org/wiki/延長_(元号) "延長 (元号)")5年（[927年](https://ja.wikipedia.org/wiki/927年 "927年")）にまとめられた『[延喜式](https://ja.wikipedia.org/wiki/延喜式 "延喜式")』の巻九・十の神名式上・下の総称。

延喜式によって「[官社](https://ja.wikipedia.org/wiki/官幣社 "官幣社")」に指定する[神社](https://ja.wikipedia.org/wiki/神社 "神社")一覧である。独立の写本などが作られるようになった時期は明確でないが、おそらく中世初期のことと思われる。

## 神名帳の性質・成立

本来「神名帳」とは、古代[律令制](https://ja.wikipedia.org/wiki/律令制 "律令制")における[神祇官](https://ja.wikipedia.org/wiki/神祇官 "神祇官")が作成した官社の一覧表を指し、官社帳ともいう。国・[郡](https://ja.wikipedia.org/wiki/郡 "郡")別に神社が羅列され、官幣・国幣の別、大社・小社の別と座数、幣帛を受ける祭祀の別を明記するのみで、各式内社の祭神名や由緒などの記載はない。延喜式神名帳とは、延喜式の成立当時の神名帳を掲載したものである。

### 式内社

延喜式神名帳に記載された神社、および現代におけるその[論社](#論社)を「延喜式の内に記載された神社」の意味で**延喜式内社**、または単に**式内社**（しきないしゃ）、**式社**（しきしゃ）といい、一種の[社格](https://ja.wikipedia.org/wiki/社格 "社格")となっている。

延喜式神名帳に記載された神社（式内社）は全国で2861社で、そこに鎮座する[神](https://ja.wikipedia.org/wiki/神_(神道) "神 (神道)")の数は3132座である。

式内社は、延喜式が成立した10世紀初頭には朝廷から官社として認識されていた神社で、その選定の背景には政治色が強くみえる。

### 式外社

これに対して、当時すでに存在したが延喜式神名帳に記載がない神社を**式外社**（しきげしゃ）という。式外社には、朝廷の勢力範囲外の神社や、独自の勢力を持った神社、また、[神仏習合](https://ja.wikipedia.org/wiki/神仏習合 "神仏習合")により仏を祀る寺となった神社、[僧侶](https://ja.wikipedia.org/wiki/僧 "僧")が管理した神社、正式な社殿がなかった神社などが含まれる。

### 国史見在社

式外社だが延喜式成立以前に成立した[六国史](https://ja.wikipedia.org/wiki/六国史 "六国史")に社名が見えながら、延喜式に登載されなかった神社を「[国史見在社](https://ja.wikipedia.org/wiki/国史見在社 "国史見在社")」あるいは略して「見在社」といい、[石清水八幡宮](https://ja.wikipedia.org/wiki/石清水八幡宮 "石清水八幡宮")、[大原野神社](https://ja.wikipedia.org/wiki/大原野神社 "大原野神社")などがある。

## 式内社の社格

[![](images/250px-Engishiki_cropped_Engishiki_Vol_2_Flame_67.jpg)](https://ja.wikipedia.org/wiki/ファイル:Engishiki_cropped_Engishiki_Vol_2_Flame_67.jpg)

日本古典全集に収録された『延喜式』巻9の「遠江國」の部分

[![](images/250px-Engishiki_cropped_Engishiki_Vol_2_Flame_69.jpg)](https://ja.wikipedia.org/wiki/ファイル:Engishiki_cropped_Engishiki_Vol_2_Flame_69.jpg)

日本古典全集に収録された『延喜式』巻9の「駿河國」の部分

式内社は各種の種別がある。まず官幣社と国幣社の別である。官社とは、毎年2月の[祈年祭](https://ja.wikipedia.org/wiki/祈年祭 "祈年祭")に[神祇官](https://ja.wikipedia.org/wiki/神祇官 "神祇官")から[幣帛](https://ja.wikipedia.org/wiki/幣帛 "幣帛")を受ける神社のことで、各神社の[祝部](https://ja.wikipedia.org/wiki/祝部 "祝部")（ほうりべ、[旧仮名遣](https://ja.wikipedia.org/wiki/歴史的仮名遣 "歴史的仮名遣")：はふりべ）が神祇官に集まり幣帛を受け取っていた。その後[平安時代](https://ja.wikipedia.org/wiki/平安時代 "平安時代")の[延暦](https://ja.wikipedia.org/wiki/延暦 "延暦")17年（[798年](https://ja.wikipedia.org/wiki/798年 "798年")）に、引き続き[神祇官](https://ja.wikipedia.org/wiki/神祇官 "神祇官")から幣帛を受ける官幣社と、[国司](https://ja.wikipedia.org/wiki/国司 "国司")から幣帛を受ける国幣社とに分けられた。式内社では、官幣社が573社 737座、国幣社が2288社 2395座である。国幣社が設けられたのは、遠方の神社では祝部の上京が困難なためと考えられるが、遠方でも重要な神社は官幣社となっている。

次が大社と小社の別である。この別はその神社の重要度や社勢によったと考えられる。官幣社・国幣社および大社・小社はすべての式内社について定められたので、式内社は以下の4つに分類されることとなる。

|  |  |  |
| --- | --- | --- |
| 官幣大社 | 0198社 | 0304座 |
| 国幣大社 | 0155社 | 0188座 |
| 官幣小社 | 0375社 | 0433座 |
| 国幣小社 | 2133社 | 2207座 |

官幣大社は畿内に集中しているが、官幣小社は全て[畿内](https://ja.wikipedia.org/wiki/畿内 "畿内")に、国幣大社と国幣小社は全て畿外にある。なお、[近代社格制度](https://ja.wikipedia.org/wiki/近代社格制度 "近代社格制度")にも同じ名称の社格があるが、式内社の社格とは意味が異なる。また、近代社格制度の社格は延喜式における社格とは無関係で、制定時の重要度や社勢に応じて定められた。

式内社の中には、祈年祭以外の祭にも幣帛を受ける神社があり、社格とともに記された。

|  |  |
| --- | --- |
| 名神 | [名神祭](https://ja.wikipedia.org/wiki/名神祭 "名神祭")が行われる神社 |
| 月次 | [月次祭](https://ja.wikipedia.org/wiki/月次祭 "月次祭")に幣帛を受ける神社 |
| 相嘗 | [相嘗祭](https://ja.wikipedia.org/wiki/相嘗祭 "相嘗祭")が行われる神社 |
| 新嘗 | [新嘗祭](https://ja.wikipedia.org/wiki/新嘗祭 "新嘗祭")に幣帛を受ける神社 |

## 写本

『延喜式神名帳』には複数の[写本](https://ja.wikipedia.org/wiki/写本 "写本")の系統が知られている。

* 金剛寺本 - [金剛寺](https://ja.wikipedia.org/wiki/金剛寺 "金剛寺")に伝わる写本で、[大治](https://ja.wikipedia.org/wiki/大治 "大治")2年（[1127年](https://ja.wikipedia.org/wiki/1127年 "1127年")）の奥書をもつ。現存する写本の中では最古のものとされる。巻9・12・14・16のみが現存する。
* 花山院本 - [13世紀](https://ja.wikipedia.org/wiki/13世紀 "13世紀")以前の写本とされる。
* 吉田家本 - [鎌倉期](https://ja.wikipedia.org/wiki/鎌倉期 "鎌倉期")の写本とされる。[天理図書館](https://ja.wikipedia.org/wiki/天理図書館 "天理図書館")所蔵。
* 九条家本 - 鎌倉期初頭の写本とされる。[東京国立博物館](https://ja.wikipedia.org/wiki/東京国立博物館 "東京国立博物館")所蔵。
* 一条家本 - 鎌倉期初頭の写本とされる。[空襲](https://ja.wikipedia.org/wiki/空襲 "空襲")により原本は焼失した。
* 三条西家本 - 鎌倉期の写本とされる。
* 中院家本 - [建長](https://ja.wikipedia.org/wiki/建長 "建長")3年（[1251年](https://ja.wikipedia.org/wiki/1251年 "1251年")）の奥書をもつ。

## 論社

式内社の後裔が現在のどの神社なのかを比定する研究は古くから行われている。現代において、延喜式に記載された神社と同一もしくはその後裔と推定される神社のことを**論社**（ろんしゃ）・**比定社**（ひていしゃ）などと呼ばれる。

式内社の後裔としてほぼ確実視されている神社でも、確実な証拠はほとんど無く、伝承により後裔の可能性がきわめて高い論社という扱いである。延喜式編纂時以降、社名や祭神・鎮座地などが変更されたり、他の神社に合祀されたり、また、荒廃した後に復興されたりした場合、式内社の後裔と目される神社が複数になることもある。

論社には、他の研究によって後裔社だとみなされることもあるが、その神社自ら式内社だと主張することも多い。
