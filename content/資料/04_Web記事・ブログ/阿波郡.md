徳島県阿波郡の位置（薄黄：後に他郡に編入された区域）

**阿波郡**（あわぐん）は、[徳島県](https://ja.wikipedia.org/wiki/徳島県 "徳島県")（[阿波国](https://ja.wikipedia.org/wiki/阿波国 "阿波国")）にあった[郡](https://ja.wikipedia.org/wiki/郡 "郡")。

## 郡域

[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")（[明治](https://ja.wikipedia.org/wiki/明治 "明治")12年）に行政区画として発足した当時の郡域は、下記の区域にあたる。

* [阿波市](https://ja.wikipedia.org/wiki/阿波市 "阿波市")の大部分（[吉野町五条](https://ja.wikipedia.org/wiki/吉野町五条 "吉野町五条")・[吉野町西条](https://ja.wikipedia.org/wiki/吉野町西条 "吉野町西条")・[土成町高尾](https://ja.wikipedia.org/wiki/土成町高尾 "土成町高尾")・[土成町宮川内](https://ja.wikipedia.org/wiki/土成町宮川内 "土成町宮川内")・[土成町吉田](https://ja.wikipedia.org/wiki/土成町吉田 "土成町吉田")を除く）
* [吉野川市](https://ja.wikipedia.org/wiki/吉野川市 "吉野川市")の一部（[鴨島町知恵島](https://ja.wikipedia.org/wiki/鴨島町知恵島 "鴨島町知恵島")・鴨島町知恵島番外）

### 近世以降の沿革

* [明治](https://ja.wikipedia.org/wiki/明治 "明治")初年時点で、全域が阿波**[徳島藩](https://ja.wikipedia.org/wiki/徳島藩 "徳島藩")**領であった。「[旧高旧領取調帳](https://ja.wikipedia.org/wiki/旧高旧領取調帳 "旧高旧領取調帳")」に記載されている村は以下の通り。（30村）

:   切幡村、興崎村、尾開村、市場町、香美村、山野上村、八幡町、秋月村、伊月村、西野川村、久千田村、勝命村、大俣村、上喜来村、犬墓村、日開谷村、大影村、柿原村、土成村、浦池村、成当村、水田村、郡村、知恵島村、粟島村、大野島村、西林村、伊沢村、小倉原村、東林村

* 明治4年
  + [7月14日](https://ja.wikipedia.org/wiki/7月14日_(旧暦) "7月14日 (旧暦)")（[1871年](https://ja.wikipedia.org/wiki/1871年 "1871年")[8月29日](https://ja.wikipedia.org/wiki/8月29日 "8月29日")） - [廃藩置県](https://ja.wikipedia.org/wiki/廃藩置県 "廃藩置県")により徳島県（第1次）の管轄となる。
  + [11月15日](https://ja.wikipedia.org/wiki/11月15日_(旧暦) "11月15日 (旧暦)")（1871年[12月26日](https://ja.wikipedia.org/wiki/12月26日 "12月26日")） - 第1次府県統合により**[名東県](https://ja.wikipedia.org/wiki/名東県 "名東県")**の管轄となる。
* 明治初年 - 西野川村が久千田村に合併。（29村）
* 明治9年（[1876年](https://ja.wikipedia.org/wiki/1876年 "1876年")）[8月21日](https://ja.wikipedia.org/wiki/8月21日 "8月21日") - 第2次府県統合により**[高知県](https://ja.wikipedia.org/wiki/高知県 "高知県")**の管轄となる。
* 明治12年（[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")）[1月4日](https://ja.wikipedia.org/wiki/1月4日 "1月4日") - [郡区町村編制法](https://ja.wikipedia.org/wiki/郡区町村編制法 "郡区町村編制法")の高知県での施行により行政区画としての**阿波郡**が発足。「阿波麻植郡役所」が[麻植郡](https://ja.wikipedia.org/wiki/麻植郡 "麻植郡")川島町に設置され、同郡とともに管轄。
* 明治13年（[1880年](https://ja.wikipedia.org/wiki/1880年 "1880年")）[3月2日](https://ja.wikipedia.org/wiki/3月2日 "3月2日") - **徳島県**（第2次）の管轄となる。

### 町村制以降の沿革

[![](//upload.wikimedia.org/wikipedia/commons/0/0e/Tokushima_Awa-gun_1889.png?utm_source=ja.wikipedia.org&utm_campaign=parser&utm_content=thumbnail_unscaled)](https://ja.wikipedia.org/wiki/ファイル:Tokushima_Awa-gun_1889.png)

1.柿島村 2.土成村 3.八幡村 4.市香村 5.大俣村 6.久勝村 7.伊沢村 8.林村（赤：阿波市 紫：吉野川市）

* 明治22年（[1889年](https://ja.wikipedia.org/wiki/1889年 "1889年")）[10月1日](https://ja.wikipedia.org/wiki/10月1日 "10月1日") - [町村制](https://ja.wikipedia.org/wiki/町村制 "町村制")の施行により、以下の各村が発足。特記以外は全域が現・阿波市。（8村）
  + **[柿島村](https://ja.wikipedia.org/wiki/柿島村 "柿島村")** ← 柿原村（現・阿波市）、知恵島村（現・吉野川市）
  + **[土成村](https://ja.wikipedia.org/wiki/土成村 "土成村")** ← 土成村、成当村、郡村、浦池村、水田村［大部分］、秋月村、伊月村［一部］
  + **[八幡村](https://ja.wikipedia.org/wiki/八幡町_(徳島県) "八幡町 (徳島県)")** ← 粟島村、八幡町、大野島村、山野上村、伊月村［大部分］、切幡村、水田村［一部］
  + **[市香村](https://ja.wikipedia.org/wiki/市場町_(徳島県) "市場町 (徳島県)")** ← 市場町、興崎村、香美村、尾開村、上喜来村［一部］
  + **[大俣村](https://ja.wikipedia.org/wiki/大俣村 "大俣村")** ← 大俣村、日開谷村、犬墓村、大影村、上喜来村［大部分］
  + **[久勝村](https://ja.wikipedia.org/wiki/久勝町 "久勝町")** ← 勝命村、久千田村
  + **[伊沢村](https://ja.wikipedia.org/wiki/伊沢村_(徳島県) "伊沢村 (徳島県)")** ← 伊沢村、小倉原村、東林村［一部］
  + **[林村](https://ja.wikipedia.org/wiki/林町 "林町")** ← 西林村、東林村［大部分］
* 明治24年（[1891年](https://ja.wikipedia.org/wiki/1891年 "1891年")）[4月1日](https://ja.wikipedia.org/wiki/4月1日 "4月1日") - [郡制](https://ja.wikipedia.org/wiki/郡制 "郡制")を施行。
* 明治25年（[1892年](https://ja.wikipedia.org/wiki/1892年 "1892年")）[10月](https://ja.wikipedia.org/wiki/10月 "10月") - 市香村に郡役所が落成した。
* 明治40年（[1907年](https://ja.wikipedia.org/wiki/1907年 "1907年")）[11月1日](https://ja.wikipedia.org/wiki/11月1日 "11月1日") - 市香村が町制施行・改称して**[市場町](https://ja.wikipedia.org/wiki/市場町_(徳島県) "市場町 (徳島県)")**となる。（1町7村）
* 明治41年（[1908年](https://ja.wikipedia.org/wiki/1908年 "1908年")）[7月20日](https://ja.wikipedia.org/wiki/7月20日 "7月20日") - 八幡村が町制施行して**[八幡町](https://ja.wikipedia.org/wiki/八幡町_(徳島県) "八幡町 (徳島県)")**となる。（2町6村）
* [大正](https://ja.wikipedia.org/wiki/大正 "大正")12年（[1923年](https://ja.wikipedia.org/wiki/1923年 "1923年")）4月1日 - 郡会が廃止。郡役所は存続。
* 大正15年（[1926年](https://ja.wikipedia.org/wiki/1926年 "1926年")）[7月1日](https://ja.wikipedia.org/wiki/7月1日 "7月1日") - 郡役所が廃止。以降は地域区分名称となる。
* [昭和](https://ja.wikipedia.org/wiki/昭和 "昭和")3年（[1928年](https://ja.wikipedia.org/wiki/1928年 "1928年")）11月1日 - 林村が町制施行して**[林町](https://ja.wikipedia.org/wiki/林町 "林町")**となる。（3町5村）
* 昭和26年（[1951年](https://ja.wikipedia.org/wiki/1951年 "1951年")）[11月3日](https://ja.wikipedia.org/wiki/11月3日 "11月3日") - 久勝村が町制施行して**[久勝町](https://ja.wikipedia.org/wiki/久勝町 "久勝町")**となる。（4町4村）
* 昭和30年（[1955年](https://ja.wikipedia.org/wiki/1955年 "1955年")）[3月31日](https://ja.wikipedia.org/wiki/3月31日 "3月31日")（2町1村）
  + 八幡町・市場町・大俣村が合併し、改めて**市場町**が発足。
  + 久勝町・伊沢村・林町が合併して**[阿波町](https://ja.wikipedia.org/wiki/阿波町 "阿波町")**が発足。
  + 土成村が[板野郡](https://ja.wikipedia.org/wiki/板野郡 "板野郡")[御所村](https://ja.wikipedia.org/wiki/御所村_(徳島県) "御所村 (徳島県)")と合併して板野郡**[土成町](https://ja.wikipedia.org/wiki/土成町 "土成町")**が発足。
* 昭和32年（[1957年](https://ja.wikipedia.org/wiki/1957年 "1957年")）3月31日 - 柿島村が分割し、一部（柿原）が板野郡[一条町](https://ja.wikipedia.org/wiki/一条町 "一条町")と合併して板野郡[吉野町](https://ja.wikipedia.org/wiki/吉野町_(徳島県) "吉野町 (徳島県)")が発足。残部（知恵島）が[麻植郡](https://ja.wikipedia.org/wiki/麻植郡 "麻植郡")[鴨島町](https://ja.wikipedia.org/wiki/鴨島町 "鴨島町")に編入。（2町）
* [平成](https://ja.wikipedia.org/wiki/平成 "平成")17年（[2005年](https://ja.wikipedia.org/wiki/2005年 "2005年")）4月1日 - 市場町・阿波町が板野郡吉野町・土成町と合併して**[阿波市](https://ja.wikipedia.org/wiki/阿波市 "阿波市")**が発足。同日阿波郡消滅。
