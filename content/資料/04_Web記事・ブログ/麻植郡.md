**麻植郡**（おえぐん）は、[徳島県](https://ja.wikipedia.org/wiki/徳島県 "徳島県")（[阿波国](https://ja.wikipedia.org/wiki/阿波国 "阿波国")）にあった[郡](https://ja.wikipedia.org/wiki/郡 "郡")。

## 郡域

[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")（[明治](https://ja.wikipedia.org/wiki/明治 "明治")12年）に行政区画として発足した当時の郡域は、下記の区域にあたる。

* [吉野川市](https://ja.wikipedia.org/wiki/吉野川市 "吉野川市")の大部分（[鴨島町知恵島](https://ja.wikipedia.org/wiki/鴨島町知恵島 "鴨島町知恵島")および[鴨島町牛島](https://ja.wikipedia.org/wiki/鴨島町牛島 "鴨島町牛島")のうち字先須賀ノ一・先須賀ノ二・先須賀ノ三・先須賀ノ四・四ツ屋を除く）
* [美馬市](https://ja.wikipedia.org/wiki/美馬市 "美馬市")の一部（[木屋平](https://ja.wikipedia.org/wiki/木屋平 "木屋平")）

## 歴史

### 古代

『[古語拾遺](https://ja.wikipedia.org/wiki/古語拾遺 "古語拾遺")』によれば、[天富命](https://ja.wikipedia.org/wiki/天富命 "天富命")が肥沃な土地を求め阿波国の開拓をし、穀・**麻**種を**植**えたことから**麻植郡**の名になったという。天富命は[神武東征](https://ja.wikipedia.org/wiki/神武東征 "神武東征")において[忌部氏](https://ja.wikipedia.org/wiki/忌部氏 "忌部氏")を率いて[紀伊国](https://ja.wikipedia.org/wiki/紀伊国 "紀伊国")の[材木](https://ja.wikipedia.org/wiki/材木 "材木")を採取し、[畝傍山](https://ja.wikipedia.org/wiki/畝傍山 "畝傍山")の[麓](https://ja.wikipedia.org/wiki/麓 "麓")に[橿原宮](https://ja.wikipedia.org/wiki/橿原神宮 "橿原神宮")を造営したことで知られる。

### 近世以降の沿革

* [明治](https://ja.wikipedia.org/wiki/明治 "明治")初年時点で、全域が阿波**[徳島藩](https://ja.wikipedia.org/wiki/徳島藩 "徳島藩")**領であった。「[旧高旧領取調帳](https://ja.wikipedia.org/wiki/旧高旧領取調帳 "旧高旧領取調帳")」に記載されている村は以下の通り。（32村）

:   川田村、瀬詰村、桁山村、森藤村、山路村、麻植塚村、内原村、上浦村、中島村、牛島村、鴨島村、山田村、上下島村、敷地村、飯尾村、喜来村、西麻植村、桑村、児島村、宮ノ島村、川島町、学村、山崎村、三ツ島村、別枝山村、中村山村、三ツ木村、川井村、木屋平村、東山、川田山、種野山

* 明治4年
  + [7月14日](https://ja.wikipedia.org/wiki/7月14日_(旧暦) "7月14日 (旧暦)")（[1871年](https://ja.wikipedia.org/wiki/1871年 "1871年")[8月29日](https://ja.wikipedia.org/wiki/8月29日 "8月29日")） - [廃藩置県](https://ja.wikipedia.org/wiki/廃藩置県 "廃藩置県")により徳島県（第1次）の管轄となる。
  + [11月15日](https://ja.wikipedia.org/wiki/11月15日_(旧暦) "11月15日 (旧暦)")（1871年[12月26日](https://ja.wikipedia.org/wiki/12月26日 "12月26日")） - 第1次府県統合により**[名東県](https://ja.wikipedia.org/wiki/名東県 "名東県")**の管轄となる。
* 明治9年（[1876年](https://ja.wikipedia.org/wiki/1876年 "1876年")）[8月21日](https://ja.wikipedia.org/wiki/8月21日 "8月21日") - 第2次府県統合により**[高知県](https://ja.wikipedia.org/wiki/高知県 "高知県")**の管轄となる。
* 明治12年（[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")）[1月4日](https://ja.wikipedia.org/wiki/1月4日 "1月4日") - [郡区町村編制法](https://ja.wikipedia.org/wiki/郡区町村編制法 "郡区町村編制法")の高知県での施行により行政区画としての**麻植郡**が発足。「阿波麻植郡役所」が川島町に設置され、[阿波郡](https://ja.wikipedia.org/wiki/阿波郡 "阿波郡")とともに管轄。
* 明治13年（[1880年](https://ja.wikipedia.org/wiki/1880年 "1880年")）[3月2日](https://ja.wikipedia.org/wiki/3月2日 "3月2日") - **徳島県**（第2次）の管轄となる。

### 町村制以降の沿革

[![](//upload.wikimedia.org/wikipedia/commons/4/45/Tokushima_Oe-gun_1889.png?utm_source=ja.wikipedia.org&utm_campaign=parser&utm_content=thumbnail_unscaled)](https://ja.wikipedia.org/wiki/ファイル:Tokushima_Oe-gun_1889.png)

1.牛島村 2.森山村 3.鴨島村 4.西尾村 5.桑川村 6.東山村 7.学島村 8.山瀬村 9.川田村 10.三山村 11.中枝村 12.木屋平村
（紫：吉野川市 桃：美馬市）

* 明治22年（[1889年](https://ja.wikipedia.org/wiki/1889年 "1889年")）[10月1日](https://ja.wikipedia.org/wiki/10月1日 "10月1日") - [町村制](https://ja.wikipedia.org/wiki/町村制 "町村制")の施行により、以下の各村が発足。特記以外は全域が現・吉野川市。（12村）
  + **[牛島村](https://ja.wikipedia.org/wiki/牛島村 "牛島村")** ← 牛島村、上浦村、麻植塚村
  + **[森山村](https://ja.wikipedia.org/wiki/森山村_(徳島県) "森山村 (徳島県)")** ← 森藤村、山路村、内原村、中島村［大部分］
  + **[鴨島村](https://ja.wikipedia.org/wiki/鴨島町 "鴨島町")** ← 喜来村、上下島村［大部分］、鴨島村、中島村［一部］
  + **[西尾村](https://ja.wikipedia.org/wiki/西尾村_(徳島県) "西尾村 (徳島県)")** ← 飯尾村、敷地村、西麻植村、上下島村［一部］
  + **[桑川村](https://ja.wikipedia.org/wiki/川島町_(徳島県) "川島町 (徳島県)")** ← 川島町、桑村、宮ノ島村、山田村、東山［一部］
  + **[東山村](https://ja.wikipedia.org/wiki/東山村_(徳島県) "東山村 (徳島県)")**（東山の大部分が単独村制）
  + **[学島村](https://ja.wikipedia.org/wiki/学島村 "学島村")** ← 学村、児島村、三ツ島村
  + **[山瀬村](https://ja.wikipedia.org/wiki/山瀬町 "山瀬町")** ← 山崎村、瀬詰村、川田村［一部］
  + **[川田村](https://ja.wikipedia.org/wiki/川田町 "川田町")**（川田村の大部分が単独村制）
  + **[三山村](https://ja.wikipedia.org/wiki/三山村 "三山村")** ← 川田山、種野山、別枝山村［一部］、桁山村［大部分］
  + **[中枝村](https://ja.wikipedia.org/wiki/中枝村 "中枝村")** ← 中村山村（現・吉野川市、美馬市）、別枝山村［大部分］、桁山村［一部］（現・吉野川市）
  + **[木屋平村](https://ja.wikipedia.org/wiki/木屋平村 "木屋平村")** ← 木屋平村、川井村、三ツ木村（現・美馬市）
* 明治24年（[1891年](https://ja.wikipedia.org/wiki/1891年 "1891年")）[4月1日](https://ja.wikipedia.org/wiki/4月1日 "4月1日") - [郡制](https://ja.wikipedia.org/wiki/郡制 "郡制")を施行。
* 明治30年（[1907年](https://ja.wikipedia.org/wiki/1907年 "1907年")）10月1日 - 桑川村が町制施行・改称して**[川島町](https://ja.wikipedia.org/wiki/川島町_(徳島県) "川島町 (徳島県)")**となる。（1町11村）
* 明治31年（[1908年](https://ja.wikipedia.org/wiki/1908年 "1908年")）[7月20日](https://ja.wikipedia.org/wiki/7月20日 "7月20日") - 鴨島村が町制施行して**[鴨島町](https://ja.wikipedia.org/wiki/鴨島町 "鴨島町")**となる。（2町10村）
* [大正](https://ja.wikipedia.org/wiki/大正 "大正")12年（[1923年](https://ja.wikipedia.org/wiki/1923年 "1923年")）
  + 4月1日 - 郡会が廃止。郡役所は存続。
  + [5月5日](https://ja.wikipedia.org/wiki/5月5日 "5月5日") - 山瀬村が町制施行して**[山瀬町](https://ja.wikipedia.org/wiki/山瀬町 "山瀬町")**となる。（3町9村）
* 大正15年（[1926年](https://ja.wikipedia.org/wiki/1926年 "1926年")）[7月1日](https://ja.wikipedia.org/wiki/7月1日 "7月1日") - 郡役所が廃止。以降は地域区分名称となる。
* 昭和3年（[1928年](https://ja.wikipedia.org/wiki/1928年 "1928年")）[11月10日](https://ja.wikipedia.org/wiki/11月10日 "11月10日") - 川田村が町制施行して**[川田町](https://ja.wikipedia.org/wiki/川田町 "川田町")**となる。（4町8村）
* 昭和29年（[1954年](https://ja.wikipedia.org/wiki/1954年 "1954年")）
  + [3月20日](https://ja.wikipedia.org/wiki/3月20日 "3月20日") - 牛島村が[板野郡](https://ja.wikipedia.org/wiki/板野郡 "板野郡")[一条町](https://ja.wikipedia.org/wiki/一条町 "一条町")の一部（西条の一部）を編入。
  + [3月31日](https://ja.wikipedia.org/wiki/3月31日 "3月31日") - 鴨島町・森山村・西尾村・牛島村が合併し、改めて**鴨島町**が発足。（4町5村）
* 昭和30年（[1955年](https://ja.wikipedia.org/wiki/1955年 "1955年")）
  + [1月1日](https://ja.wikipedia.org/wiki/1月1日 "1月1日")（3町3村）
    - 東山村の一部が鴨島町に編入。
    - 中枝村の一部（中村山の一部）が木屋平村に編入。
    - 山瀬町・川田町および三山村の残部が合併して**[山川町](https://ja.wikipedia.org/wiki/山川町_(徳島県) "山川町 (徳島県)")**が発足。
    - 東山村の残部・中枝村の残部・三山村の一部が合併して**[美郷村](https://ja.wikipedia.org/wiki/美郷村 "美郷村")**が発足。
  + [2月11日](https://ja.wikipedia.org/wiki/2月11日 "2月11日") - 川島町・学島村が合併し、改めて**川島町**が発足。（3町2村）
* 昭和32年（[1957年](https://ja.wikipedia.org/wiki/1957年 "1957年")）3月31日 - 鴨島町が[阿波郡](https://ja.wikipedia.org/wiki/阿波郡 "阿波郡")[柿島村](https://ja.wikipedia.org/wiki/柿島村 "柿島村")の一部（知恵島）を編入。
* 昭和47年（[1973年](https://ja.wikipedia.org/wiki/1973年 "1973年")）7月1日 - 木屋平村の所属郡が[美馬郡](https://ja.wikipedia.org/wiki/美馬郡 "美馬郡")に変更。（3町1村）
* [平成](https://ja.wikipedia.org/wiki/平成 "平成")16年（[2004年](https://ja.wikipedia.org/wiki/2004年 "2004年")）10月1日 - 鴨島町・川島町・山川町・美郷村が合併して**[吉野川市](https://ja.wikipedia.org/wiki/吉野川市 "吉野川市")**が発足。同日麻植郡消滅。徳島県内では初の郡消滅となった。
