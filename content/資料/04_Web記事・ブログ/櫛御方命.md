**鴨王**（かも の きみ/かも の おおきみ、[生没年不詳](https://ja.wikipedia.org/wiki/生没年不詳 "生没年不詳")）は、[古代](https://ja.wikipedia.org/wiki/古代#日本史 "古代")[日本](https://ja.wikipedia.org/wiki/日本 "日本")の人物。**天日方奇日方命**（あまのひがたくしひがた の みこと）の名で知られ、鴨王の表記は懿徳天皇紀のみ。

## 系譜

『[先代旧事本紀](https://ja.wikipedia.org/wiki/先代旧事本紀 "先代旧事本紀")』「地祇本紀」によれば、父は**[都味歯八重事代主神](https://ja.wikipedia.org/wiki/都味歯八重事代主神 "都味歯八重事代主神")**（[大己貴神](https://ja.wikipedia.org/wiki/大己貴神 "大己貴神")の子）、母は[活玉依姫](https://ja.wikipedia.org/wiki/活玉依姫 "活玉依姫")（[三島溝杭](https://ja.wikipedia.org/wiki/三嶋湟咋 "三嶋湟咋")の娘）。事代主神が[鰐](https://ja.wikipedia.org/wiki/和邇 "和邇")となって活玉依姫のもとに通い、天日方奇日方命をはじめとする子が生まれたという。同書によれば、天日方奇日方命の妹には[姫踏韛五十鈴姫命](https://ja.wikipedia.org/wiki/姫踏韛五十鈴姫命 "姫踏韛五十鈴姫命")（[神武天皇](https://ja.wikipedia.org/wiki/神武天皇 "神武天皇")（初代[天皇](https://ja.wikipedia.org/wiki/天皇 "天皇")）の[皇后](https://ja.wikipedia.org/wiki/皇后 "皇后")）・[五十鈴依姫命](https://ja.wikipedia.org/wiki/五十鈴依姫命 "五十鈴依姫命")（[綏靖天皇](https://ja.wikipedia.org/wiki/綏靖天皇 "綏靖天皇")（第2代天皇）の皇后）がいるという。

『[日本書紀](https://ja.wikipedia.org/wiki/日本書紀 "日本書紀")』によれば、祖父は**[事代主神](https://ja.wikipedia.org/wiki/事代主神 "事代主神")**であるという。父の名は不明。

『[古事記](https://ja.wikipedia.org/wiki/古事記 "古事記")』によれば、父は**[大物主大神](https://ja.wikipedia.org/wiki/大物主大神 "大物主大神")**、母は[活玉依毘売](https://ja.wikipedia.org/wiki/活玉依毘売 "活玉依毘売")（[陶津耳命](https://ja.wikipedia.org/wiki/陶津耳命 "陶津耳命")の娘）であるという。

* 妻：[日向賀牟度美良姫](https://ja.wikipedia.org/wiki/日向賀牟度美良姫 "日向賀牟度美良姫")（ひむかのかむとみらひめ）
  + 第1子：**[健飯勝命](https://ja.wikipedia.org/wiki/健飯勝命?action=edit&redlink=1 "健飯勝命 (存在しないページ)")**（たけいいかつ の みこと/たけいいかち の みこと）

    :   [三輪氏](https://ja.wikipedia.org/wiki/三輪氏 "三輪氏")・[賀茂氏](https://ja.wikipedia.org/wiki/賀茂朝臣氏 "賀茂朝臣氏")の祖。
  + 第2子：[渟中底姫命](https://ja.wikipedia.org/wiki/渟中底姫命 "渟中底姫命")（ぬなそこひめ の みこと）

    :   [安寧天皇](https://ja.wikipedia.org/wiki/安寧天皇 "安寧天皇")（第3代天皇）の皇后で、[懿徳天皇](https://ja.wikipedia.org/wiki/懿徳天皇 "懿徳天皇")（第4代天皇）などの母。

## 記録

### 日本書紀

『[日本書紀](https://ja.wikipedia.org/wiki/日本書紀 "日本書紀")』においては、[懿徳天皇](https://ja.wikipedia.org/wiki/懿徳天皇 "懿徳天皇")の母親[渟名底仲媛命](https://ja.wikipedia.org/wiki/渟名底仲媛命 "渟名底仲媛命")の父親として名が見えるのみで、事績については触れられていない。また[崇神天皇](https://ja.wikipedia.org/wiki/崇神天皇 "崇神天皇")紀では[大田田根子](https://ja.wikipedia.org/wiki/大田田根子 "大田田根子")の外祖父として**奇日方天日方武茅渟祇**（くしひかたあまつひかたたけちぬつみ）の名で現れる。

### 古事記

『[古事記](https://ja.wikipedia.org/wiki/古事記 "古事記")』においても、[意富多々泥古](https://ja.wikipedia.org/wiki/意富多々泥古 "意富多々泥古")の[曾祖父](https://ja.wikipedia.org/wiki/曾祖父 "曾祖父")として**櫛御方命**（くしみかたのみこと）の名が見えるのみで、やはり事績については触れられていない。

### 先代旧事本紀

『[先代旧事本紀](https://ja.wikipedia.org/wiki/先代旧事本紀 "先代旧事本紀")』の「[天皇本紀](https://ja.wikipedia.org/wiki/天皇本紀 "天皇本紀")」によれば、『日本書紀』と同じように懿徳天皇の外祖父であるほか、[神武天皇](https://ja.wikipedia.org/wiki/神武天皇 "神武天皇")2年[2月2日](https://ja.wikipedia.org/wiki/2月2日_(旧暦) "2月2日 (旧暦)")に[宇摩志麻治命](https://ja.wikipedia.org/wiki/宇摩志麻治命 "宇摩志麻治命")とともに[申食国政大夫](https://ja.wikipedia.org/wiki/申食国政大夫?action=edit&redlink=1 "申食国政大夫 (存在しないページ)")（おすくにのまつりごともうすまちぎみ）に任命されたという。この申食国政大夫は[大和王権](https://ja.wikipedia.org/wiki/大和王権 "大和王権")時代の[大連](https://ja.wikipedia.org/wiki/大連_(古代日本) "大連 (古代日本)")または[大臣](https://ja.wikipedia.org/wiki/大臣_(古代日本) "大臣 (古代日本)")に相当するとも述べられている。

### 粟鹿大明神元記

『[粟鹿大明神元記](https://ja.wikipedia.org/wiki/粟鹿大明神元記 "粟鹿大明神元記")』では、久斯比賀多命と阿麻能比賀太命と分けられて記されている。久斯比賀多命は宇治夜須姫命を娶り阿麻能比賀太命と淳中底仲姫命をもうけ、墓は「泉国知努乎曽村」にあるという。そして、「大和氏文」から引用する形で、「太祁知遅若命」という別名も記している。

阿麻能比賀太命は意富多弊良姫を娶り櫛甑戸忍速栖浦浦稚日命をもうけたという。そして、「大和氏文」から引用する形で、「太祁弥賀乃保命」と言う別名も記している。

## 後裔

### 氏族

『[先代旧事本紀](https://ja.wikipedia.org/wiki/先代旧事本紀 "先代旧事本紀")』「天皇本紀」では、天日方奇日方命を[大神君](https://ja.wikipedia.org/wiki/大神氏 "大神氏")（おおみわのきみ）の祖としており、その他に[鴨君](https://ja.wikipedia.org/wiki/賀茂朝臣氏 "賀茂朝臣氏")、石辺君、[宗像氏](https://ja.wikipedia.org/wiki/宗像氏 "宗像氏")の祖とされる。
