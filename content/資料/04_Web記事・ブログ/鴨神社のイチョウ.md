| ● | 名称 ： 鴨神社のイチョウ |  | 
| ● | 所在地　： [兵庫県丹波市市島町梶原482-2](http://www.mapion.co.jp/m/35.1970878067728_135.1348801537733_8/) | ○地図リンク提供：マピオン |

| ● | 指定 ： 丹波市指定天然記念物 （S54年3月19日指定） |  | 
| ● | アクセス ： JR福知山線・市島駅から約2km、徒歩30分。 |  | 
| ● | 鴨神社（かもじんじゃ）は、10世紀に編集された延喜式に記録のある古い神社。大イチョウは、神社の本殿から東に少し離れた、一の鳥居のわきに立っています。痛みが激しく治療が施されたことがそばの石碑に記されていました。 鴨神社の社叢は田圃の中に浮かぶようにあります。祭神は鴨別雷神で、京都の上賀茂神社と同じです。神社前の道を東に200mほど行くと一の鳥居があり、その四つ辻の北東角にイチョウがあります。兵庫県の天然記念物の石碑があり、最近の治療のかいがあったのか多くの葉が茂っており、これからも長生きして欲しいもの。 （HP管理者） |  |
