兵庫県八部郡の位置

**八部郡**（やたべぐん）は、[兵庫県](https://ja.wikipedia.org/wiki/兵庫県 "兵庫県")（[摂津国](https://ja.wikipedia.org/wiki/摂津国 "摂津国")）にあった[郡](https://ja.wikipedia.org/wiki/郡 "郡")。

## 郡域

[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")（[明治](https://ja.wikipedia.org/wiki/明治 "明治")12年）に行政区画として発足した当時の郡域は、おおむね下記の区域にあたる。

* [神戸市](https://ja.wikipedia.org/wiki/神戸市 "神戸市")
  + [兵庫区](https://ja.wikipedia.org/wiki/兵庫区 "兵庫区")
  + [長田区](https://ja.wikipedia.org/wiki/長田区 "長田区")
  + [須磨区](https://ja.wikipedia.org/wiki/須磨区 "須磨区")の大部分（菅の台・西落合・神の谷・緑台・弥栄台および友が丘・竜が台・北落合の各一部を除く）
  + [灘区](https://ja.wikipedia.org/wiki/灘区 "灘区")の一部（六甲山町の一部）
  + [北区](https://ja.wikipedia.org/wiki/北区_(神戸市) "北区 (神戸市)")の一部（山田町各町および内包する各町）
  + [中央区](https://ja.wikipedia.org/wiki/中央区_(神戸市) "中央区 (神戸市)")の一部（[楠町](https://ja.wikipedia.org/wiki/楠町_(神戸市) "楠町 (神戸市)")）

## 郡名の由来

『摂津』P7「郡名異同一覧」には、矢田部・八田部・八部と、時代あるいは書物によって異なる表記が用いられてきたことが記されている。

**雄伴郡**は、[淳和天皇](https://ja.wikipedia.org/wiki/淳和天皇 "淳和天皇")の時代（在位823年 - 833年）、天皇の諱である「大伴」（おおとも）に発音が近いことから、八部郡（やたべぐん）と改名された。[仁徳天皇](https://ja.wikipedia.org/wiki/仁徳天皇 "仁徳天皇")の妃[八田皇女](https://ja.wikipedia.org/wiki/八田皇女 "八田皇女")の[名代](https://ja.wikipedia.org/wiki/名代 "名代")が付近にあったためともいわれている。『摂津』P538 第三章 氏族 第十三節矢田部郡の「八田部」の項に、「古事記仁徳段に[八田皇女](https://ja.wikipedia.org/wiki/八田皇女 "八田皇女")の[御名代（みなしろ）](https://ja.wikipedia.org/wiki/名代 "名代")として八田部を定める」と引用する。矢田部郡及び八部郡の地名（矢田部郡は八部郡の別表記）は、御名代八田部の名に由来するとする。改名当初は八田部郡と書いた。

## 歴史

### 古代

八部郡の範囲は定かではない。時代によっても異なると考えられる。[和名類聚抄](https://ja.wikipedia.org/wiki/和名類聚抄 "和名類聚抄")（[承平年間](https://ja.wikipedia.org/wiki/承平_(日本) "承平 (日本)")（931年 - 938年）編纂）には、[摂津国](https://ja.wikipedia.org/wiki/摂津国 "摂津国")八田部郡として、生田・[宇治](https://ja.wikipedia.org/wiki/宇治郷_(神戸市) "宇治郷 (神戸市)")・[神戸](https://ja.wikipedia.org/wiki/神戸 "神戸")・八部（やたべ）・[長田](https://ja.wikipedia.org/wiki/長田区 "長田区")の５つの郷が記されている。

  + [2月2日](https://ja.wikipedia.org/wiki/2月2日_(旧暦) "2月2日 (旧暦)")（[1868年](https://ja.wikipedia.org/wiki/1868年 "1868年")[2月24日](https://ja.wikipedia.org/wiki/2月24日 "2月24日")） - 幕府領・旗本領が**[兵庫裁判所](https://ja.wikipedia.org/wiki/兵庫裁判所 "兵庫裁判所")**の管轄となる。
  + [5月23日](https://ja.wikipedia.org/wiki/5月23日_(旧暦) "5月23日 (旧暦)")（1868年[7月12日](https://ja.wikipedia.org/wiki/7月12日 "7月12日")） - 兵庫裁判所の管轄地域が**[兵庫県](https://ja.wikipedia.org/wiki/兵庫県 "兵庫県")**の管轄となる。
  + 神戸村・二茶屋村・走水村が合併して神戸町となる。（1町43村）
* 明治4年
  + [7月14日](https://ja.wikipedia.org/wiki/7月14日_(旧暦) "7月14日 (旧暦)")（[1871年](https://ja.wikipedia.org/wiki/1871年 "1871年")[8月29日](https://ja.wikipedia.org/wiki/8月29日 "8月29日")） - [廃藩置県](https://ja.wikipedia.org/wiki/廃藩置県 "廃藩置県")により、藩領が**[古河県](https://ja.wikipedia.org/wiki/古河県 "古河県")**、**[小泉県](https://ja.wikipedia.org/wiki/小泉県 "小泉県")**の管轄となる。
  + [11月14日](https://ja.wikipedia.org/wiki/11月14日_(旧暦) "11月14日 (旧暦)")（1871年[12月25日](https://ja.wikipedia.org/wiki/12月25日 "12月25日")） - 第1次府県統合により、古河県の管轄地域が**[印旛県](https://ja.wikipedia.org/wiki/印旛県 "印旛県")**の管轄となる。
  + [11月20日](https://ja.wikipedia.org/wiki/11月20日_(旧暦) "11月20日 (旧暦)")（1871年[12月31日](https://ja.wikipedia.org/wiki/12月31日 "12月31日")） - 第1次府県統合により、全域が**兵庫県**の管轄となる。
* 明治5年（[1872年](https://ja.wikipedia.org/wiki/1872年 "1872年")） - 生田宮村・中宮村・花熊村・北野村・宇治野村が神戸町に合併。（1町38村）
* 明治12年（[1879年](https://ja.wikipedia.org/wiki/1879年 "1879年")）[1月8日](https://ja.wikipedia.org/wiki/1月8日 "1月8日") - [郡区町村編制法](https://ja.wikipedia.org/wiki/郡区町村編制法 "郡区町村編制法")の兵庫県での施行により、下記の変更が行われる。
  + 神戸町・兵庫津・坂本村の区域をもって**[神戸区](https://ja.wikipedia.org/wiki/神戸区 "神戸区")**が発足し、郡より離脱。（36村）
  + 残部の区域をもって行政区画としての**八部郡**が発足。郡役所が湊村に設置。
* 明治14年（[1881年](https://ja.wikipedia.org/wiki/1881年 "1881年")） - 西小部村・東小部村が合併して小部村となる。（35村）
* 明治16年（[1883年](https://ja.wikipedia.org/wiki/1883年 "1883年")） - 神戸区の一部が分立して今和田新田となる。（36村）
* 明治22年（[1889年](https://ja.wikipedia.org/wiki/1889年 "1889年")）[4月1日](https://ja.wikipedia.org/wiki/4月1日 "4月1日") - [町村制](https://ja.wikipedia.org/wiki/町村制 "町村制")の施行により、以下の町村が発足。全域が現・神戸市。（4村）
  + **[湊村](https://ja.wikipedia.org/wiki/湊村_(兵庫県) "湊村 (兵庫県)")** ← 奥平野村、石井村、夢野村、烏原村、荒田村［[飛地](https://ja.wikipedia.org/wiki/飛地 "飛地")］（概ね現・兵庫区）
  + **[林田村](https://ja.wikipedia.org/wiki/林田村_(兵庫県八部郡) "林田村 (兵庫県八部郡)")** ← 東尻池村、西尻池村、長田村、駒ヶ林村、野田村、御崎村、今和田新田、吉田新田（概ね現・長田区）
  + **[須磨村](https://ja.wikipedia.org/wiki/須磨町 "須磨町")** ← 板宿村、大手村、西代村、池田村、妙法寺村、車村、白川村、東須磨村、西須磨村、多井畑村（概ね現・須磨区）
  + **[山田村](https://ja.wikipedia.org/wiki/山田村_(兵庫県武庫郡) "山田村 (兵庫県武庫郡)")** ← 上谷上村、下谷上村、原野村、福地村、中村、東下村、西下村、衝原村、小河村、坂本村、藍那村、小部村、与左衛門新田（現・北区）
  + 荒田村の大部分（飛地を除く）が[神戸市](https://ja.wikipedia.org/wiki/神戸市 "神戸市")の一部となる。
* 明治29年（[1896年](https://ja.wikipedia.org/wiki/1896年 "1896年")）4月1日
  + 湊村・林田村および須磨村の一部（池田）が神戸市に編入。
  + [郡制](https://ja.wikipedia.org/wiki/郡制 "郡制")の施行のため、武庫郡・[菟原郡](https://ja.wikipedia.org/wiki/菟原郡 "菟原郡")・八部郡の区域をもって、改めて**[武庫郡](https://ja.wikipedia.org/wiki/武庫郡 "武庫郡")**が発足。同日八部郡廃止。
