# 📜 斎部宿祢本系帳

> [!abstract] このノートの役割
> 『**斎部宿祢本系帳**』(いんべのすくねほんけいちょう)は、阿波忌部(斎部)氏が朝廷に提出した家系図文書。**古語拾遺(807)** の前提となる系譜資料であり、[[古語拾遺_MOC|古語拾遺]] と [[神別本紀_MOC|神別本紀]] を結ぶ **中間段階の文献** として位置づけられる。
>
> 本ノートは Vault 内既存資料および公開学術文献からの引用を統合し、原典精読への足場とする。**原本そのものへの直接アクセスはなし**ため、二次資料経由の整理にとどまる(信頼度 2)。

## 🧭 史料的位置づけ

### 三段証拠の中間層

斎部宿祢本系帳は、阿波忌部の文献的正統性チェーンの **中間段階** に位置する:

```
神代 — 日本書紀・古事記(720・712)
      ↓
807  — 古語拾遺(忌部広成 — 自家証言、神話・伝承)
      ↓
9C   — 斎部宿祢本系帳(系図形式、朝廷提出)  ← 本ノート
      ↓
1070 — 太政官符 邦国之大典(朝廷追認・第三者証言)
      ↓
江戸 — 神別本紀(系譜の体系化)
      ↓
現代 — 大嘗祭 麁服貢進(現代継承)
```

### なぜ「本系帳」が重要か

古語拾遺は **神話・伝承を含む叙述形式** だが、本系帳は **純粋な系図形式** で:
- 各代の系譜関係(誰の子か)
- 出自(阿波忌部/讃岐忌部/紀伊忌部/出雲玉作/筑紫忌部/伊勢忌部)
- 職掌(祭祀・玉作・木工・笠・鍛冶)
- 居住地(本貫地)

を **構造化された情報** として朝廷に提出した、と推定される。

→ 古語拾遺のナラティブな証言を **系図データとして体系化** した資料。

| 神格 | 職能 | 後裔氏族の本貫 |

| **天日鷲命** | 木綿(ゆう)・麻 | **阿波忌部** |
| **手置帆負命** | 笠・盾・幄(幕) | 讃岐忌部 |
| **彦狭知命** | 木工・矛 | 紀伊忌部 |

### 神別本紀(江戸期)による継承

『神別本紀』は **斎部宿祢本系帳の系譜情報を体系化した後代資料** と評価できる。

> 「**祭祀の家系の人々をその編纂の列に加えなかった**」(神別本紀)

→ 記紀編纂時に忌部の本系情報が反映されなかったことへの **当事者からの抗議** が、本系帳・神別本紀の編纂動機。

## 🌊 阿波説における意義

### 中央公認の系譜資料という重み

斎部宿祢本系帳は **朝廷に提出された公的文書** であり、忌部氏の自家証言の中でも特に格式高い:

| 文献 | 性格 | 朝廷との関係 |
| --- | --- | --- |
| 古語拾遺 | 神話・伝承中心 | 奏進(献上)文書 |
| **本系帳** | **系図中心** | **朝廷提出文書(本系)** |
| 神別本紀 | 江戸期の家伝書 | 朝廷非提出 |

→ 古語拾遺との **対** をなす公的文献として位置づけられる(🟡)。

### 五部神の構造的意義

本系帳が示す五部神系譜は、**阿波忌部 = 単一氏族ではなく複数本貫の合同氏族部隊** という構造を支持する物的痕跡:

- 安房神社(東遷終着点)で 5 柱すべて配祀
- → 全国唯一の祭祀構成
- → [[安房神社]] および [[安房忌部_MOC]] 参照

### 大嘗祭 麁服貢進の正統性根拠

斎部宿祢本系帳が朝廷に提出された段階で:
- 阿波忌部の祭祀権が **系図として認証**
- → これが後の大嘗祭 麁服貢進の制度的根拠に
- → 太政官符 1070 と接続(忌部祭祀権の朝廷追認)

→ [[太政官符1070_翻刻と注釈|📜 太政官符 1070 翻刻と注釈]] 参照

## ⚠ 史料批判

### 現存問題

- **完本は伝存せず**、他文献の引用断片からの推定構築になる
- 後代写本も限定的で、宮内庁書陵部の所蔵本へのアクセスは制限される
- 原本精読には **直接資料調査** が必要

### 自家証言の限界

- 本系帳は忌部氏自身による系譜であり、**他氏族との競合関係** で記述が偏っている可能性
- 中臣氏・物部氏の系譜と相互チェックする必要

### 神別本紀との比較注意

- 神別本紀は **江戸期成立** であり、平安期一次史料との等価性はない
- 本系帳 → 神別本紀の継承関係も、神別本紀側で再構成された部分が含まれる可能性
