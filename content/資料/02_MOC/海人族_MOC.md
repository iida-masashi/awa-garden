# 🌊 海人族(あまぞく) 横断 MOC

> [!abstract] このノートの役割
> 古代日本の **海洋民族集団**(海人族)を横断的に統合する MOC。
>
> 阿波説では、海人族は **阿波南部(那賀郡・勝浦郡・海部郡)を母胎** とし、黒潮を「道」として太平洋・日本海沿岸の各拠点に展開した海洋勢力。本 MOC は、阿波本貫地から **隠岐・対馬・壱岐・北部九州・伊豆諸島・安房・常陸** までの拠点を地理・氏族・神格の三軸で統合する。

## 👥 第二章 主要氏族の系譜と展開

### 1. 海部氏(あまべ) — 阿波 → 丹後 → 尾張

阿波海部郡から始まり、丹後(籠神社)・尾張(熱田神宮)へと展開した広域氏族。

#### 阿波海部氏

- 海部郡(現徳島県海陽町・阿南市) — 古代から海上交易の拠点
- 阿波志 第 12 巻「**海部**」(村里・氏族・祠廟・古蹟・塚墓) — Vault に詳細あり
- [[多良古墳群：海部郡の素佐之男一族系王家墓]]
- [[みなみ阿波のスサノオ足跡：海部郡の鉄伝承と家族祭祀]]

#### 丹後海部氏(籠神社祠官家)

- 国宝『**海部氏系図**』『**海部氏勘注系図**』を伝承
- 始祖:彦火明命(= 天火明命 = 饒速日命)
- **第 82 代** 海部光彦宮司まで継承(籠神社公式)
- 詳細:海部氏勘注系図/_MOC

#### 尾張氏(海部氏支流)

- 天火明命を祖神
- 熱田神宮
- 詳細:海部氏勘注系図/amabe-k2_海部氏系図の疑問続編 「丹後の海部氏の出自とその一族」

### 2. 安曇氏(あずみ) — 鳴門 → 信濃安曇野

阿波鳴門・北灘から日本海・信濃へ展開。

- 祖神:**綿津見三神**(底津綿津見・中津綿津見・上津綿津見)
- 阿波の本拠:鳴門海峡周辺(渦潮の掌握)
- 主要展開先:信濃(安曇野)、北部九州、志賀島(志賀海神社)
- 「**阿曇磯良**(あづみのいそら)」 = 海神族の代表的神格

### 3. 那賀氏(長国造) — 阿波那賀郡

阿波南部の海洋王権を担った氏族。

- 系譜:**観松彦色止命(孝昭天皇) 九世孫 韓背足尼命** = 阿波長国造
- 本貫:那賀川流域(現徳島県阿南市・那賀町)
- 主要式内社:[[八桙神社]](事代主神)、[[宇奈為神社]]
- 関連:[[長国（南阿波）：ヤマト王権への抵抗と海洋勢力の拠点]]

### 4. 宗像氏 — 玄界灘 + 阿波西照神社

- 祖神:**宗像三女神**(田心姫・湍津姫・市杵島姫)
- 本貫:玄界灘(福岡県宗像市)
- 阿波における祭祀痕跡:🌙 高安城と月読尊・宗像三女神

### 5. 住吉氏 — 摂津住吉

- 祖神:**住吉三神**(底筒男・中筒男・表筒男)
- 神功皇后の三韓征伐との関連
- 阿波の地名対応:[[住吉|阿波・畿内マイナー地名ペア:住吉]]

### 6. 億岐氏(おき) — 隠岐国造家

- 祖神:**観松彦色止命 五世孫 十挨命**
- 阿波長国造と **同祖関係**(『国造本紀』)
- 玉若酢命神社の宮司を現代まで継承
- 詳細:[[伊未自由来記_専門ノート]]・[[隠岐_専門ノート]]

### 7. 阿曇首(隠岐) — 海部首継承家

- 奈岐の浦命の子孫 → 全島海部大神
- 後に阿曇首と改称
- 隠岐における海部氏の在地分派
- 出典:『伊未自由来記』第六章 → [[伊未自由来記_専門ノート]]

## 🌊 第五章 三段証拠フレーム

### 🟢 確実な事実

1. **阿波の地名**「海部郡」「那賀郡」「安曇野(信濃)」「海部直」(各種正税帳) — 古代から海人族の本貫地として記録
2. **海神信仰の式内社密集** — 阿波の和多都美豊玉比売神社、対馬の海神神社、壱岐の海神神社
3. **海部氏勘注系図**(国宝) — 海人族系譜の現存最古史料
4. **隠岐国造の同祖記述** — 『国造本紀』に観松彦色止命系
5. **阿波志『海部』巻** — 江戸期の海部郡詳細記録
6. **鯨面文身** — 魏志倭人伝の倭人記述 = 海人族の身体的特徴

### 🟡 有力な推測

1. **阿波 → 各地への海人族展開** — 隠岐・伊豆・安房・常陸への東進ルート
2. **三嶋大明神 = 事代主の伊豆展開** — 伊豆諸島神話と阿波の接続
3. **「奈賀」と「長」の音通** — 隠岐の奈賀命と阿波長国造の言語的接続
4. **黒潮ルート** — 太平洋沿岸の海上交易網
5. **海部氏 vs 阿波本宗** — 丹後海部氏は宝賀寿男により批判的検証あり(海部氏勘注系図/_MOC)

### ⚪ 推測

1. **「伊未自姫」= 阿波忌部との関連** — 隠岐『伊未自由来記』の書名語源
2. **隠岐 = オノゴロ島** — 阿波の鳴門オノゴロ説とは別系統
3. **コノハビト = 朝鮮半島由来** — 新羅 徐羅伐起源

## ⚖ 第六章 主要論点

### 論点 1: 阿波本貫地説の根拠

阿波説の海人族論の核心:
- **「海部郡」** という地名 = 海人族の中核拠点
- 江戸期『阿波志』第 12 巻「海部」(村里・氏族・古蹟など)が現代まで残る詳細記録
- 三段ネットワーク(鳴門・那賀川・海部郡)の地理的一体性
- 観松彦色止命を主祭神とする全国唯一の式内社(式内社 御間都比古神社)

### 論点 2: 海人族と忌部の関係

阿波説特有の構造:
- **海部氏**(海人族・航海技術)
- **忌部氏**(祭祀・麻・大嘗祭麁服)
- 両者が **並列・補完的に共存**(他地域では稀)
- → 阿波が本貫地であることの傍証

参照:[[忌部と海人族の融合：上総一宮の玉依姫命]](玉前神社の融合例)

### 論点 3: 出雲との関係

- 阿波海人族 = 出雲系も含む(スサノオ・大国主)
- [[スサノオと海部氏（あまべし）の系譜]]
- [[長国と海人族：ヤマト王権への抵抗勢力としての出雲系]]
- 海人族 = 出雲系王権の海洋的展開でもあった

### 論点 4: 韓国・朝鮮との交流

- 隠岐『伊未自由来記』のコノハビト = 新羅徐羅伐由来
- KCI 論文の隠岐民謡韓国語要素
