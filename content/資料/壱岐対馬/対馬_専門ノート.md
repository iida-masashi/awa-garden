# 🏝 対馬(つしま)国 専門ノート

> [!abstract] このノートの役割
> 対馬(長崎県対馬市)を **阿波説の文脈** で位置づける本格論考。
>
> 対馬は『**魏志倭人伝**』の **「対馬国(つしまこく)」** に比定される、朝鮮半島と九州を結ぶ古代日本の **対外交易の最前線**。中世以降は **宗氏** が支配し、室町〜江戸期には「**偽使**」を朝鮮半島に多数派遣した記録が『海東諸国紀』にも残る。本ノートは、対馬の考古学・神話・式内社・宗氏・偽使を整理し、阿波説における海上ネットワーク・対外交渉の枠組みで再評価する。

## 🌟 第一章 三段証拠フレームでの対馬

### 🟢 確実な事実

#### 1. 魏志倭人伝の記述 — 「対馬国」

> **「始度一海千余里、至対馬国、其大官曰卑狗、副曰卑奴母離、所居絶島、方可四百余里、土地山険、多深林、道路如禽鹿径、有千余戸、無良田、食海物自活、乗船南北市糴(なんぼくしてき)」**
>
> (現代語訳:はじめて一海を渡ること千余里、対馬国に至る。その大官を **卑狗(ひこ)** といい、副を **卑奴母離(ひなもり)** という。居る所は絶島で、方四百余里ばかり、土地は山険しく、深林多く、道路は禽鹿の径の如し。千余戸あり、良田なく、海物を食ひて自ら活く。船に乗りて南北に市糴(してき)す。)

阿波説における重要性:
- 帯方郡から最初に到達する倭の国(🟢)
- **「南北市糴」** = 朝鮮半島(北)と九州(南)との交易で生計を立てる海上民
- 卑狗(ひこ)・卑奴母離(ひなもり) = 壱岐と同じ官職名 → 同質の文化圏

#### 2. 古事記の国生み — 「天之狭手依比売」

『古事記』国生み段:
> 「次に **津島(つしま)** を生みき。亦の名は **天之狭手依比売**(あめのさでよりひめ) と謂う」

- **「天の狭手依姫」** — 神格化された対馬の女神
- 阿波説では:阿波の海洋祭祀女神(豊玉姫など)との同型性(⚪)

#### 3. 対馬の式内社 29 座(うち名神大 6)

**全国でも極めて密度が高い** 式内社配置:

| 神社 | 主祭神 | 備考 |
| --- | --- | --- |
| **海神神社** | 豊玉姫命・彦火火出見尊 | 対馬国一の宮、名神大 |
| **和多都美神社** | 彦火火出見尊・豊玉姫命 | 海宮(竜宮)伝承の地、名神大 |
| **多久頭魂神社** | 多久頭魂命 | 名神大 |
| **天神多久頭魂神社** | 天神多久頭魂命 | 名神大 |
| **太祝詞神社** | 太祝詞命 | 中臣氏の祖神 |
| **阿麻氐留神社** | 天照大神 | 名神大 |
| **小船越神社** | — | 重要な海上要衝 |

→ **海神信仰の密集地** (豊玉姫・彦火火出見)
→ **中臣氏の祖神祭祀**(太祝詞神社)

#### 4. 弥生時代の交易遺跡

- **塔ノ首遺跡** — 弥生末期〜古墳前期、楽浪系青銅器
- **三根遺跡群** — 楽浪鏡・銅鏃出土
- **久原遺跡** — 朝鮮半島系遺物
- → 紀元前後からの大陸交易の最前線

#### 5. 宗氏の支配と偽使

- 鎌倉期以降、**宗氏(そうし)** が対馬を世襲支配
- 室町〜江戸期は **朝鮮との通商の独占** を幕府から認められる
- **「偽使」** = 名義を偽った使節を朝鮮に多数派遣して交易
- 『**海東諸国紀**』(1471)に偽使の実態が詳細に記載
- → [[海東諸国紀_専門ノート]] 参照

### 🟡 有力な推測

#### 1. 海神信仰の集中 — 山幸彦・豊玉姫伝説の原郷

- 海神神社・和多都美神社が **彦火火出見尊**(山幸彦)と **豊玉姫** を祀る
- 海宮(竜宮)伝説の **舞台候補地** の一つ
- 阿波説では、豊玉姫 = 阿波の海洋祭祀女神(和多都美豊玉比売命神社)と同神
- → 対馬・阿波 で同神を祀る系譜の物証(🟡)

参照:
- 式内社 和多都美豊玉比売神社 (阿波・名方郡)
- 阿波の海部氏との接続

#### 2. 邪馬台国阿波説の起点

- 帯方郡 → **対馬国** → 一支国 → 末廬 → 伊都 → ... → 邪馬壱国(阿波)
- 短里換算で里程整合(対馬は本州との渡海距離千余里 = 約 77km、実距離と一致)
- → [[邪馬台国阿波説_MOC]]・[[短里と里程整合性：周旋五千余里・東渡海千余里の数理基盤]]

#### 3. 中臣氏との関係

- **太祝詞神社**(対馬) = 中臣氏の祖神祭祀
- 中臣氏は神祇官として中央朝廷を支えた氏族
- 阿波説では中臣氏と忌部氏は **競合関係**
- → [[中臣氏と阿波：忌部の地における藤原氏の源流]]

## 🧭 留保

- 「対馬 = 天之狭手依比売」と阿波の豊玉姫祭祀の同神論は **🟡 有力** にとどまる
