# 🏝 壱岐(いき)国 専門ノート

> [!abstract] このノートの役割
> 壱岐(長崎県壱岐市)を **阿波説の文脈** で位置づける本格論考。
>
> 壱岐は『**魏志倭人伝**』の **「一支国(いきこく)」** に比定される島で、邪馬台国への水行ルート上の重要な中継点。物的証拠として **原ノ辻遺跡**(国指定特別史跡)・三角縁神獣鏡出土・弥生時代の交易拠点が確認される。本ノートは、壱岐の考古学・神話・式内社を整理し、阿波説における海上ネットワークの一翼として再評価する。

## 🌟 第一章 三段証拠フレームでの壱岐

### 🟢 確実な事実

#### 1. 原ノ辻遺跡(国指定特別史跡) — 一支国の王都

- 壱岐市芦辺町・石田町
- **弥生時代の大規模環濠集落**(BC2 世紀〜AD3 世紀)
- 『**魏志倭人伝**』の「一支国」の王都に比定
- 国指定特別史跡(吉野ヶ里遺跡・三内丸山遺跡などと並ぶ最高位)
- 出土遺物:
  - 弥生土器・木製品・骨角器
  - 中国・朝鮮系遺物
  - 銅鏃・銅剣・銅矛
  - 楽浪郡の前漢鏡・後漢鏡
- → **東アジア交易の中継拠点** の物的証拠

#### 2. 魏志倭人伝の記述

> **「又南渡一海千余里、名曰瀚海、至一支国、官亦曰卑狗、副曰卑奴母離、方可三百里、多竹木叢林、有三千許家、差有田地、耕田猶不足食、亦南北市糴(なんぼくしてき)」**
>
> (現代語訳:また南へ一海を渡ること千余里、名を瀚海(かんかい)という。一支国に至る。官は亦た卑狗(ひこ)と曰い、副は卑奴母離(ひなもり)と曰う。方三百里ばかり、竹木叢林多く、三千許家あり。差(やや)田地あるも、田を耕すも猶食に足らず、また南北に市糴す。)

阿波説における意義:
- 壱岐は対馬と同じく **「南北に市糴」**(交易で生計)する海上民の島
- 「**卑狗**(ひこ)・**卑奴母離**(ひなもり)」の官職名は対馬と同じ
- → 古代の **対外交易の前線基地** という位置づけ

#### 3. 古事記の国生み — 「天比登都柱」

『古事記』国生み段:
> 「次に伊伎島(いきのしま)を生みき。亦の名は **天比登都柱**(あめひとつばしら) と謂う」

- **「天の一つ柱」** — 天と地を結ぶ柱という意味
- → 神聖な島という古代の認識
- 阿波説では:阿波の **天石門別** 系神格との関連可能性(⚪ 推測)

#### 4. 月読神社 — 壱岐市芦辺町

- 延喜式神名帳「壱岐郡 月読神社 名神大」
- 主祭神:**月読命**
- 『日本書紀』顕宗天皇 3 年(487)条:壱岐の月読神を山城国葛野郡(松尾)に遷座
- → **京都松尾大社の月読社** の元宮
- 全国の月読神社の総本社という伝承

#### 5. 海神(綿津見)神社の集中

- 壱岐には海神を祀る式内社が多数
- 海人族・宗像氏との深い関係

### 🟡 有力な推測

#### 1. 邪馬台国阿波説と壱岐

阿波説の魏志倭人伝解読では:
- 帯方郡 → 狗邪韓国 → **対馬国** → **一支国(壱岐)** → 末廬国(松浦) → 伊都国(糸島) → 奴国(博多) → 不弥国 → 投馬国 → **邪馬壱国(阿波)**
- 壱岐は **邪馬台国 = 阿波** への水行ルート上の確実な中継点(🟢)
- 短里換算で里程整合性が成立(🟡)

詳細:[[邪馬台国阿波説_MOC]]・[[短里と里程整合性：周旋五千余里・東渡海千余里の数理基盤]]

#### 2. 月読神社の阿波系譜

- 月読命は阿波説で重要視される神格(阿波の月信仰)
- **松尾大社** が秦氏の本貫の山城国にあり、秦氏 = 海人族系
- 壱岐 → 京都への遷座 = 海人族の畿内展開ルート

#### 3. 海人族の連続性

- 壱岐の海人族 = 宗像氏・安曇氏・住吉氏との同系統
- 阿波の海部氏とも構造的に類似
- → 古代海洋ネットワークの一翼

### ⚪ 推測

#### 1. 天比登都柱 = 阿波天石門別の関連

- 壱岐の別名「天比登都柱」 = 天の柱
- 阿波の **天石門別神** = 岩窟の柱
- 神話的同型性(⚪)

#### 2. 一支国の支配者と阿波

- 卑狗・卑奴母離の系譜
- 阿波忌部・海部氏との直接的接続は不明(⚪)

## 🌳 第三章 壱岐と古代海上ネットワーク

### 「南北に市糴」の交易構造

魏志倭人伝の「**南北市糴(してき)**」(南北との交易で生計)は壱岐・対馬共通の特徴:
- **北**:朝鮮半島・楽浪郡
- **南**:九州本土(末廬・伊都・奴・不弥)
- → 食料を **耕作ではなく交易** で得る海上民の島

### 出土遺物が示す対外交易

- 楽浪郡の前漢鏡・後漢鏡(原ノ辻)
- 朝鮮半島系土器
- 中国系青銅器
- → 紀元前後から東アジア海上交易の中継点

### 阿波説における位置

| 月読神社 | 松尾大社元宮 | 海人族の畿内展開ルート(🟡) |
