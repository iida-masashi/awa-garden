# 🗺 壱岐・対馬 MOC

> [!abstract] このフォルダの役割
> **壱岐(いき)** と **対馬(つしま)** は、玄界灘・朝鮮海峡を挟んで朝鮮半島と九州を結ぶ古代の海上交通の要衝。**魏志倭人伝**の「**対馬国**」「**一支国**」に比定され、邪馬台国への水行ルート上の確実な中継点である。
>
> 本フォルダは、壱岐・対馬の両国を **阿波説の文脈** で位置づける専門ノートを集約する。

## 🌟 壱岐・対馬の共通構造

### 魏志倭人伝の対馬・壱岐

- どちらも「卑狗(ひこ)・卑奴母離(ひなもり)」が官職名
- どちらも「南北市糴(してき)」 = 交易で生計を立てる海上民
- → 同質の文化圏・行政構造

### 国生み神話における位置

| 島 | 古事記の別名 | 意味 |
| --- | --- | --- |
| 対馬 | 天之狭手依比売 | 神格化された女神 |
| 壱岐 | 天比登都柱 | 天と地を結ぶ柱 |

→ どちらも **神聖な島** として古代に認識された

### 阿波説における意義

- 邪馬台国阿波説における **必須の中継点**
- 海人族ネットワーク(宗像・安曇・住吉・阿波海部) の北端
- 対外交易の最前線 = 阿波の独自外交論との接続

## 🌊 三段証拠フレーム(統合)

### 🟢 確実

1. 原ノ辻遺跡(壱岐)・塔ノ首遺跡(対馬) = 弥生末期の交易拠点
2. 楽浪郡の前漢鏡・後漢鏡 = 大陸交易の物証
3. 魏志倭人伝の「対馬国」「一支国」の比定は学界共通見解
4. 延喜式神名帳:壱岐 24 座、対馬 29 座(密度高い)

### 🟡 有力

1. 月読神社(壱岐) → 松尾大社の遷座 = 海人族の畿内展開
2. 海神神社(対馬) = 豊玉姫・彦火火出見尊祭祀 = 阿波 式内社 和多都美豊玉比売神社 と同神
3. 短里換算で里程整合 → 邪馬台国 = 阿波への水行ルート確定

### ⚪ 推測

1. 阿比留文字 = 対馬の神代文字との阿波の関連
2. 天之狭手依比売 = 阿波豊玉姫の同神
3. 「天比登都柱」 = 阿波天石門別系の同型
