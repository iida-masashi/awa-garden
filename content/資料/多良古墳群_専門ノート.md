# 🏛 多良古墳群(たらこふんぐん) 専門ノート

> [!abstract] このノートの役割
> 徳島県海部郡(現海陽町・牟岐町周辺)の **多良古墳群** を、阿波説の文脈で位置づける本格論考。
>
> 多良古墳群は **古墳時代前期(3 世紀)** の前方後円墳を含む 5 連古墳群で、特に **15 号古墳**(全長 50m)は **須佐之男一族の王家墓** と推定される。**邪馬台国時代と重なる阿波王権の物的物証** であり、**海部郡 = 海洋王権の本貫地** を裏付ける考古学的核心物証。

## 🌟 第一章 三段証拠フレーム

### 🟢 確実な事実

1. **5 連の前方後円墳** が海部郡に物的に存在(現地確認可能)
2. **古墳時代前期(3 世紀)** の構築 = 邪馬台国時代と同時代
3. **15 号古墳 全長 50m** = 海部郡内最大級
4. 多良村は『阿波志』(江戸後期)に村里として記録
5. 海陽町野江の **寺山古墳群** が同地域に並列(3 世紀初頭)、内行花文鏡出土

### 🟡 有力な推測

1. **多良古墳群 = 須佐之男一族の王家墓**
   - 近隣の **獅井坂神社(旧 祇園社)** が須佐之男尊を祭神とする
   - 海部郡周辺の須佐之男系祭祀集積([[みなみ阿波のスサノオ足跡：海部郡の鉄伝承と家族祭祀]])
2. **3 世紀の阿波王権の物的証拠** = 邪馬台国比定論を補強
3. **海洋ネットワークの中継拠点** としての立地

### ⚪ 推測

1. **「友字地図ライン」** — 福山(広島)・島根(出雲)・徳島(多良) の三地点直線関係
2. 須佐之男一族の移動・連絡ルートとしての解釈
3. 寺山古墳群との氏族的連続性

## 🌊 第四章 邪馬台国阿波説における意義

### 3 世紀の物的証拠

多良古墳群の構築時期(3 世紀)は:
- 魏志倭人伝の **邪馬台国** 時代と完全に重なる
- 阿波説の **邪馬台国 = 阿波** 比定論の物的基盤
- 同時代の **萩原墳丘墓**(鳴門・3 世紀初頭、前方後円墳プロトタイプ)と並列

→ [[邪馬台国阿波説_MOC]]・[[古墳考古学_MOC]]

### 海洋王権の物的痕跡

- 海部郡 = 太平洋・瀬戸内海・紀伊水道の結節点
- 古墳前期に既に **王家規模の墳墓** が築造される地域 = 海洋王権の存在
- 海部氏(あまべ)・須佐之男系氏族の本貫地論を補強

### 寺山古墳群との関係

近隣の **寺山古墳群**(海陽町野江、3 世紀初頭):
- **内行花文鏡** 出土 → 大陸交易の物証
- 同型鏡が萩原墳丘墓(鳴門)・籠神社(丹後)からも出土
- 阿波説では **羽衣伝説の天女(豊宇賀能賣命)の墓** と比定

→ [[羽衣伝説の阿波比定論：和奈佐と寺山古墳群]]・[[和奈佐意富曽神社_専門ノート]]

→ **多良古墳群(須佐之男系) + 寺山古墳群(天女・忌部系)** の **同地域並存** は、海部郡が異なる氏族の王家祭祀地として機能した複層構造を示す(🟡)
