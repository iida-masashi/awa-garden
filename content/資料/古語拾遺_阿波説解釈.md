# 古語拾遺の阿波説的解釈

> [!summary] 要旨
> 大同 2 年(807)に斎部広成が奏進した『古語拾遺』は、阿波説における **最重要の現存一次史料の一つ** である。
> 本書は記紀(712/720)に「拾い遺された」古事を忌部氏の側から提示するもので、
> **阿波忌部の祖系譜・麻殖郡開拓・安房国東遷・大嘗祭麁服貢進**という、
> 阿波説の中核命題のすべてが、本書において明示的・連続的に語られている。
> 斎部広成の党派性を史料批判として認識しつつも、
> **「中臣氏 = 藤原氏が削除した忌部側の記憶」を取り戻す書**として、阿波説の論拠の中軸を担う。

---

## 1. 歴史的背景:大同元年(806)の祭祀権争いと斎部氏の勝訴

『古語拾遺』が世に出るに至る政治的経緯は極めて重要である。

### 806 年:中臣氏との裁判

平安遷都(794)から十数年、朝廷では中臣氏(後の藤原氏)が祭祀権を独占しつつあった。
**大同元年(806 年)**、中臣氏は次のように主張した:

> 「**斎部氏には祝詞を唱えて幣帛(へいはく)を捧げる儀式はできない。斎部氏ができるのは幣帛を作ることだけ。**」(意訳)

これに対し斎部氏は、

> 「**幣帛を捧げることも祝詞を唱えることもできる。**」

と反論し、訴訟となった。**この裁判で斎部氏は勝訴した** (nihonsinwa.com 解説 より)。

### 807 年:勝訴の翌年に古語拾遺を奏進

裁判勝訴の翌年、**斎部広成は平城天皇に召されて古事を問われる**。
広成は「**長年の蓄積した憤慨**(攄蓄憤)」を述べる機会と捉え、忌部側に伝わる旧説を朝廷に奏進した。

これが『古語拾遺』である。

### 「拾遺」という書名の含意

- 「拾い遺された(=記紀に漏れた / 中臣氏に消された)古事」を集めた書、というのが文字通りの意味
- 斎部広成の党派性 → **本書は忌部側の党派的史料**である(史料批判の出発点)
- 阿波説の立場 → **だからこそ価値がある**。中臣氏主導で編纂された記紀には載らない、忌部側の伝承がここに残されている

> [!info] 阿波説のテーゼ(本論の前提)
> 「記紀(712/720)の編纂時に、阿波忌部の独自伝承は中臣氏(藤原氏)主導で削除・改竄された。
> しかし 95 年後、忌部側の生き残り(斎部広成)が **公式の場で**、削除されたはずの伝承を朝廷に奏進した。
> これが『古語拾遺』である。」

## 2. 阿波忌部の祖系譜:天太玉命を統率者とする 5 系譜

### 原文(本文 22 段)

> 又男名曰、**天太玉命(斎部宿袮祖也)**、太玉命所率神名曰、
> **天日鷲命(阿波國忌部等祖)**、
> 手置帆負命(讃岐國忌部祖也)、
> 彦狭知命(紀伊國忌部祖也)、
> 櫛明玉命(出雲國玉作祖也)、
> 天目一筒命(筑紫伊勢両國忌部祖也)。

### 阿波説の解釈

#### (a) 天太玉命を頂点とする統一氏族としての忌部

**5 国の忌部**が独立した別系統ではなく、**天太玉命(斎部宿祢祖)の率いる一族**として記される。
これは「忌部諸国分散」が偶然ではなく、**意図的な氏族戦略**であったことを示唆する。

#### (b) 阿波忌部が筆頭に書かれる意義

5 系譜のうち、**最初に書かれる**のが阿波(天日鷲命)である。
讃岐・紀伊・出雲・筑紫伊勢の各祖がそれに続く。

通説では「太玉命の率いる神々の単なる列挙」とされるが、阿波説では:

> **「太玉命の本拠こそ阿波であり、そこから讃岐・紀伊・出雲・筑紫伊勢へと忌部が広がった」と読む**。

筆頭であることは、忌部の **本貫地(発祥地)** の表示であると解釈する。

#### (c) 天日鷲命と八倉比賣命の親子関係

『斎部宿祢本系帳』(忌部氏の家伝)には:

> 「天背男命(=天太玉命)の后神 = **八倉比賣命**、その子 = **天日鷲翔矢命(=天日鷲命、阿波忌部祖)**」

との系譜が示される。

『古語拾遺』本文では八倉比賣命は直接には登場しないが、

> **[[邦国之大典：平安時代の公式文書が語る神社の格|1070 年太政官符]]の写本『阿波国徴古雑抄』に「天石門別八倉比賣神」が「忌部神」と書かれている**

ことと、古語拾遺の系譜は完全に整合する。

つまり:

- 古語拾遺(807) → 阿波忌部祖 = 天日鷲命
- 斎部宿祢本系帳 → 天日鷲命の母 = 八倉比賣命
- 太政官符(1070) → 八倉比賣神 = 「忌部神」

**この三角整合は、9 世紀から 11 世紀まで、中央朝廷の制度的記憶において「阿波忌部 = 八倉比賣の系譜」が継承され続けたことを示す**。

## 3. 天岩戸神話における天日鷲命の役割

### 原文(本文 26 段、抜粋)

> 令石凝姥神(...)取天香山銅以鑄日像之鏡
> 令長白羽神(伊勢國麻續祖...)種麻以為青和幣(古語爾伎弖)
> **令天日鷲神以造穀木綿**津咋見神(...)<或無神>穀木種殖之以作白和幣(是木綿也...)

### 阿波説の解釈

天岩戸を開く祭具製作で、天日鷲神は **穀木綿(ゆう = 楮の樹皮から作る麻織物)** を作る役を担う。
これが阿波忌部の祭祀職能の **神話的起源**である:

| 神格 | 役割 | 後世の地理的継承 |
| --- | --- | --- |
| 天日鷲神 | 穀木綿(白和幣)を造る | **阿波国麻殖郡で麻穀栽培** |
| 長白羽神 | 麻(青和幣)を種える | 伊勢国麻續(後の伊勢神宮服部) |
| 石凝姥神 | 鏡を鋳る | 紀伊国日前神 / 伊勢太神 |
| 櫛明玉命 | 八坂瓊曲玉を作る | 出雲国玉作 |
| 天目一箇神 | 薙刀斧・鐵鐸を作る | 筑紫・伊勢の鍛冶 |

阿波説では、これらは **「神代の祭具製作の役割分担が、後世の地理的氏族分布として継承された」** と読む。
天日鷲命の麻織物製作 → 阿波麻殖郡の麻栽培 → 大嘗祭麁服貢進 という連続が、神代から現代まで途切れていない。

## 4. 麻殖郡の地名起源と大嘗祭麁服貢進

### 原文(本文 39 段前半)— 阿波説の決定的箇所

> 仍令天富命(太玉命之孫)率手置帆負彦狹知二神之孫以齋斧齋鉏始採山材構立正殿
> (...)
> **天日鷲命之孫造木綿及麻并織布**(古語阿良多倍)
> **仍令天富命率日鷲命之孫求肥饒地遣阿波國殖穀麻種**
> 其裔今在彼国当大嘗之年貢木綿麁布及種種物
> **所以郡名爲麻殖之縁也**

### 阿波説の解釈

**「麻殖(おえ)郡」の地名起源**を古語拾遺が直接明示している。

| 原文の記述 | 阿波説における意義 |
| --- | --- |
| 天日鷲命の孫が木綿(ゆう)・麻・織布を造る | 阿波忌部の祭祀職能の確認 |
| 天富命が日鷲命の孫を率いて阿波に派遣 | 神武朝に阿波忌部が制度的に組織化された証拠 |
| **大嘗の年に木綿麁布(=麁服)を貢進** | **大嘗祭麁服伝統の起点を 9 世紀の文献が明記** |
| 郡名「麻殖」の由来 | 麻を植えた → 麻殖、という直截な地名起源 |

**この一節だけで、阿波説の主要命題のうち以下が同時に証言される**:

1. 阿波忌部は神代から続く由緒ある氏族
2. 麻殖郡(現吉野川市鴨島町・山川町・川島町周辺)が阿波忌部の本拠
3. 大嘗祭への麁服貢進は神武朝に遡る伝統
4. これらは中央朝廷の **公式記録(平城天皇への奏進)** として記録されている

## 5. 阿波忌部の東遷:安房・上総・下総の地名起源

### 原文(本文 39 段後半)

> 天富命更求沃壌
> **分阿波齋部率往東土播殖麻穀**
> 好麻所生故謂之**總國**
> 穀木所生故謂之**結城郡**(古語麻謂之總今爲上總下總二國是也)
> **阿波忌部所居便名安房郡**(今安房國是也)
> 天富命即於其地立太王命社**今謂之安房社**
> 故其神戸有齋部氏

### 阿波説の解釈

これは [[安房忌部_MOC|安房忌部 MOC]] が依拠する **東遷論の決定的典拠**である。

| 古語拾遺の記述 | 現代地名比定 | 阿波説の解釈 |
| --- | --- | --- |
| 「総国(ふさのくに)」← 麻が良く育つから | 上総・下総(現千葉県北部・中部) | **「総」(古語: 麻)** が直接「上総下総」の語源 |
| 「結城郡」← 穀木(かじのき)が育つから | 茨城県結城郡 | 結城紬の発祥地と接続 |
| **「安房郡」← 阿波忌部が住んだから** | **千葉県南房総市・館山市** | **「安房 = 阿波」**の語源論拠 |
| 「太王命社」← 天富命が建てた | **安房神社(現安房国一之宮)** | 安房神社の創建縁起 |

**「安房 = 阿波」**という地名連関は、後世の語呂合わせや偶然ではなく、
**9 世紀初頭の中央朝廷の公文書(古語拾遺)が直接記述している事実**である。

阿波説における意義:

> **阿波忌部の東遷は、神話的物語ではなく、平安初期の朝廷文書が認知した歴史である。**

これが [[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] [[安房国忌部家系：高山家伝承と由布津主命の系譜]] 等のすべての論考の出発点である。

## 6. 「11 箇条の失われた古事」と中臣氏の祭祀権簒奪

『古語拾遺』後半には、斎部広成が **「拾い遺された古事」** として 11 箇条を列挙する(本ノートでは詳細は割愛し、[[古語拾遺_原文と読み下し]] を参照)。

主な論点:

- 神璽の鏡・剣の本来の管掌者は誰か
- 大嘗祭の幣帛・祝詞の正統な担い手は誰か
- 神祇官の構成における忌部の位置

斎部広成の主張は一貫している:

> **「これらの祭祀権は本来忌部のものであった。中臣氏が政治的に簒奪した。記紀の編纂時に意図的に削除された記述を、本書(古語拾遺)で取り戻す。」**

### 阿波説からの読み解き

中臣氏(後の藤原氏)による忌部排除は、単なる氏族闘争ではなく、**「阿波の歴史的優位性」を消す政治運動**だったと解釈する。
古語拾遺が取り戻そうとした「失われた古事」は、その大半が **阿波忌部の祭祀的優位**に関わるものである。

→ 詳細は [[邦国之大典：平安時代の公式文書が語る神社の格]] の「中央朝廷の制度的記憶 vs 阿波の現地の忘却」論を参照。
古語拾遺(807) → 太政官符(1070) は、**忌部側の真実が中央で繰り返し復元され続けた**経緯を示す。

## 7. 記紀との異同 — 阿波説の論証ポイント

| 主題 | 記紀での扱い | 古語拾遺での扱い | 阿波説の解釈 |
| --- | --- | --- | --- |
| 天日鷲命 = 阿波国忌部祖 | 明示なし | **明示** | 記紀編纂時に削除された記述の復元 |
| 麻殖郡の地名起源 | 言及なし | **明示** | 阿波の歴史的優位を示す情報の意図的隠蔽からの復元 |
| 阿波忌部の安房東遷 | 言及なし | **明示** | 同上 |
| 八倉比賣命の系譜 | 言及なし | (本文には無いが斎部宿祢本系帳と整合) | 中臣氏が記紀から削除した阿波の最高神 |
| 大嘗祭麁服 | 言及なし | **明示** | 阿波の中央祭祀における特殊な役割の証言 |

→ **記紀に書かれていないことが、古語拾遺には書かれている。**
これが阿波説における古語拾遺の決定的価値である。

## 8. 邦国之大典 との接続 — 阿波説の三段証拠

阿波忌部 / 八倉比賣の系譜は、以下の三段階で **中央朝廷の制度的記憶として継承された**:

```
┌─────────────────────────────────────────────────┐
│ 第一段: 古語拾遺(807)                            │
│   天日鷲命 = 阿波国忌部祖                        │
│   阿波忌部 → 安房郡東遷                          │
│   麻殖郡の地名起源                                │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ 第二段: 斎部宿祢本系帳(忌部氏家伝)               │
│   天背男命(=太玉命)の后神 = 八倉比賣命           │
│   その子 = 天日鷲翔矢命                          │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│ 第三段: 太政官符(1070) ─ 阿波国徴古雑抄          │
│   「天石門別八倉比賣神」 = 「忌部神」            │
│   「祈年月次祭は邦国之大典也」                    │
└─────────────────────────────────────────────────┘
```

**3 つの史料が三角整合する**。
これは阿波説における **動かしがたい構造的証拠** である。

詳細: [[邦国之大典：平安時代の公式文書が語る神社の格]]

## 9. 史料批判:中立的併記

### 通説の立場

> [!warning] 通説の留保
> - 古語拾遺は **斎部広成 = 忌部側の党派的史料**である。中臣氏との利害対立を踏まえた読解が必要
> - 古語拾遺の独自記述は、必ずしも記紀よりも史実的とは断定できない
> - 「安房 = 阿波」の地名連関は、後世の語源解釈である可能性も指摘される
> - 神武朝に阿波忌部が組織化されたという記述自体、神代と歴史時代を連続させる説話的記述

### 阿波説の立場

党派性は認めつつも、

- **党派的だからこそ価値がある**:中臣氏が記紀から消した記述が、忌部側の党派的史料に残っている
- 同時代の公文書(太政官符 1070)と整合する
- 麻殖郡・安房郡という地名は **現実に存在し**、9 世紀初頭の文献に既に同じ語源説明がある
- 否定するには、より強い反証(別の同時代史料、考古学的物証等)が必要

### この論考の立場

本ノートは阿波説の立場で書かれている。通説と矛盾する箇所もある。読者は両論を踏まえて判断されたい。

## 10. 結語:古語拾遺は阿波説の中軸である

『古語拾遺』807 年奏進という事実は、阿波説の枠組みにおいて以下を意味する:

1. **阿波忌部の歴史的実在は同時代の公文書で証明されている**
2. **阿波 → 安房の東遷は朝廷が公式に認知していた**
3. **大嘗祭麁服貢進の伝統は神代に遡るものとして 9 世紀初頭に既に成立していた**
4. **これらの記述は、中臣氏 = 藤原氏の政治的排除を経ても、なお中央朝廷の制度的記憶として残った**
5. **後の太政官符(1070)、徴古雑抄等は、この記憶を引き継いだものである**

これらは個別に見ても強い証拠だが、**連続して見ると阿波説の構造的論証になる**。
古語拾遺はその出発点であり、阿波説における最重要の現存一次史料として位置付けられる。
