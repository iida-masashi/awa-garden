# 👸 伊未自姫(いみじひめ)・久米首(くめのおびと) 専門ノート

> [!abstract] このノートの役割
> **伊未自姫(いみじひめ)** は、隠岐国造 **十挨命** の妻として『**伊未自由来記**』第六章に登場する女性人物。
>
> - **久米首(くめのおびと)** の祖
> - 十挨命との間に **十男子** を産む
> - **『伊未自由来記』書名の語源**(本書のタイトルそのもの)
> - 神功皇后の三韓征伐の時期の人物
> - 子の十男子は **「大和美和の父命」** の許に送られる
>
> 本ノートは、伊未自姫を **阿波 ⇔ 隠岐 海洋ネットワークの婚姻的結節点** + **久米首氏族の起源** として位置づけ、特に **「伊未自(いみじ)」と「忌部(いみべ)」の音韻的近接** という阿波説の重要論点を **深層検証** する。

## 🌟 第一章 史料記述

### 『伊未自由来記』第六章末尾(原文)

> 「**息長足姫皇后**(神功皇后)、三韓を討ちたまうみぎり、皇后は多遅摩出石にいたり、**美豆別主命又の名 伴の首** に兵船の事を命じたまう。命は小之凝呂(隠岐)の **久米部を数多く率いて皇后の軍に従いたれば**、韓国より得たる数多くの財宝をば皇后より賜る。この時の剣は後 **美豆別酢神社** に残った。
>
> 竹内宿弥は都万の地に祖神紀之健名草三神を祀りて武運長久を祈り神地神戸に定む。更に **神功皇后の兵船が役道の主栖に来れる時、久米首の祖 伊未自姫は十挨命の妻となり 十男子あり、後に姫死して男子は 大和美和の父命の許に送られしという**」

→ 伊未自姫の登場は **三韓征伐の直前**(🟢)

### 重要なポイント

1. **久米首の祖** = 伊未自姫(明示)
2. 隠岐の **久米部** が神功皇后の三韓征伐に大規模従軍
3. 伊未自姫は十挨命の妻として **十男子** を産む
4. 姫の死後、子らは **「大和美和の父命」** の許に送られる
5. **「大和美和」 = 大物主命神 / 三輪山周辺**(⚪)

## 🌐 第二章 「伊未自(いみじ)」と「忌部(いみべ)」の音韻接続

### 阿波説の核心論点

阿波説では、**「伊未自(いみじ)」と「忌部(いみべ・いんべ)」の音韻的近接** が長く論じられてきた:

| 表記 | 古代音 | 現代音 |
| --- | --- | --- |
| 伊未自 | いみじ / いみざ | いみじ |
| 忌部 | いみべ / いみへ | いみべ |
| 斎部 | いみべ / いんべ | いんべ |
| 忌 | いみ / み(忌み) | いみ |
| 自 / 部 | じ(自) / べ(部) | じ / べ |

### 音韻学的分析

| 観点 | 検討 |
| --- | --- |
| 語頭 | **「いみ(忌)」が共通** = 「神聖なものを忌避・斎(いつ)く」概念 |
| 語尾 | 「自(じ)」vs 「部(べ)」 |
| 「自」の用法 | 古代倭語「みづから」「己」 |
| 「部(べ)」の用法 | 律令制下の職業集団称号 |
| 同源説の根拠 | 両方とも **祭祀権**(神を斎く)に関連する用語の可能性 |
| 反対説の根拠 | 「自」と「部」は別語源との指摘も |

→ 学界では確定的解釈なし(⚪)

### 阿波説的論点

阿波忌部の海上展開:
- **阿波忌部** = 大嘗祭麁服貢進、麻の織物専門集団
- 安房・上総・下総 への東遷
- 全国に「忌部」「斎部」地名が点在

→ **隠岐の伊未自姫 = 阿波忌部の系譜分流の可能性?**(⚪)

### 仮説:伊未自姫 = 阿波忌部 系譜?

阿波説的解釈の仮説:
1. **「伊未自姫」 = 「忌部姫」** の音韻変化または異表記
2. 神功皇后の三韓征伐に **阿波忌部** が参加
3. 阿波忌部の女性が **十挨命の妻** となり隠岐に移住
4. その子が **大和美和** = 三輪山(阿波忌部系祭祀域?)へ送られる
5. → 阿波忌部の **隠岐分流** が「久米首」として定着(⚪)

→ 仮説段階の重要研究テーマ

## 🌳 第三章 久米首・久米部の系譜

### 久米首(くめのおびと)とは

- 律令制下の **氏族称号**(「首=おびと」 = 中位の称号)
- **久米部(くめべ)** を統率する伴造氏族
- 神武東征の **「久米歌」** で有名

### 久米歌(くめうた)

『古事記』『日本書紀』に伝わる:
- 神武天皇即位時に **久米部が歌った戦歌**
- 「みつみつし久米の子等が」の冒頭句
- → 久米部 = 古代の戦闘集団・武装集団

### 阿波説における久米歌阿波起源論

阿波説の一部論者:
- 久米歌は **阿波で歌われていた**
- 阿波の「**久米津・粟(あわ)**」の地名分布
- 歌詞内容(粟原・神風・しじはふ等)が阿波の地理と整合

参照:
- [[神武と徐福伝説・久米歌の阿波]]
- 2009-09-18-「久米歌」は阿波で歌われていた

### 『伊未自由来記』の久米首

第五章末尾:

> 「**美豆別之主之命** — その後 出雲に大きな戦いが起こって因縁の深かった大山祇大神の勢力が落ちてきたために、新たに出雲から奈賀の命が来航、この島の治神となり、**小之凝呂別命は免じられて、全島の久米の首として 久米部の主力を率いて主栖に移住** されることとなった」

第六章:

> 「神功皇后の兵船が役道の主栖に来れる時、**久米首の祖 伊未自姫** は十挨命の妻となり 十男子あり」

→ 隠岐の **久米首・久米部** は **美豆別之主之命(水若酢命)系統** の血統と関連

参照:[[水若酢神社]]・[[隠岐_専門ノート]]

## 👶 第四章 十男子と「大和美和の父命」

### 「大和美和」の意味

「**美和(みわ)**」 = **三輪山(奈良県桜井市)** とほぼ確定

→ 大和の **三輪山周辺** = **大物主神** の祭祀地

### 「大和美和の父命」とは

候補:
1. **大物主神**(大和三輪山の主神)
2. **大物主神を祀る氏族の長**(三輪氏など)
3. **オオモノヌシの父神**(=阿遅鍬高彦根命などの父神系)(⚪)

### 阿波説的論点

第六章冒頭:

> 「**奈賀命(后中言命)**。**阿遅鍬高彦根命の御子** にて丹波の須津姫を娶り、来島」

→ 第六章の **奈賀命 = 阿遅鍬高彦根命の御子**
→ 第六章末尾の **伊未自姫の子が「大和美和の父命」の許へ**
→ もし **「大和美和の父命」= 阿遅鍬高彦根命** なら、隠岐 → 阿波 → 大和の三角ネットワーク(🟡)

### 阿波の阿遅鍬高彦根祭祀

- [[丹田古墳（加茂山）：阿遅鋤高日子根神の神陵と巨石文化]] — 阿波の阿遅鍬高彦根祭祀地
- → 阿波における **阿遅鍬高彦根神格** の重要性
- → 「大和美和の父命」 = 阿波の阿遅鍬高彦根 系譜の可能性(⚪)


### 三角ネットワークの意味

4. **戦争**:神功皇后の三韓征伐 に 阿波・隠岐・大和の連合

→ 古代日本の **王権形成期の氏族ネットワーク** の物的痕跡(🟡)
