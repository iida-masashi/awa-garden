## 🎯 「座」のカウント原則

延喜式神名帳の「**座**」は **祭神（祀られる神格）の単位**であり、神社単位ではない。
1社に複数の祭神が祀られている場合、それぞれが独立した「座」として数えられる。

阿波国の例：
- 通常社（1社=1座）が 42社
- 「二座」（1社=2座）が 4社：
  - 美馬郡 **倭大国玉神大国敷神社**（倭大国玉神 + 大国敷神）
  - 麻殖郡 **天村雲神伊自波夜比売神社**（天村雲神 + 伊自波夜比売神）
  - 麻殖郡 **天水沼間比古神天水塞比売神社**（天水沼間比古神 + 天水塞比売神）
  - 麻殖郡 **秘羽目神足浜目門比売神社**（秘羽目神 + 足浜目門比売神）
- 合計 50座

frontmatter の `deities:` には**全祭神**を記載し、`座数:` フィールドで明示する（1座も省略せず記載）。

## 📋 frontmatter スキーマ規約

式内社ノートは以下のスキーマで統一する：

```yaml
---
type: "式内社"
社格: "(名神大 / 大 / 小)"
旧国: "阿波国"
旧郡: "板野郡"
延喜式表記: "(神名帳記載どおり)"
読み: "(カタカナ)"
deities: ["祭神A", "祭神B"]
座数: 1
郵便番号: "771-1320"
所在地: "(現在地住所)"
比定社: "(複数の場合 ; 区切り)"
---
```

### キー使用ルール

| キー | 必須 | 説明 |
|---|---|---|
| `type` | ✓ | 常に "式内社" |
| `社格` | ✓ | CSV `社格` 列から |
| `旧国` / `旧郡` | ✓ | 延喜式準拠 |
| `延喜式表記` | ✓ | CSV `神名帳社名` から |
| `読み` | ✓ | CSV `読み` 列から |
| `deities` | △ | リンク配列。空でも空配列 `[]` で記載 |
| `座数` | ✓ | 1, 2, 3 のいずれか |
| `郵便番号` | - | CSV から |
| `所在地` | - | CSV `所在地` 列から |
| `比定社` | - | CSV `比定社名` 列（複数は `;` 区切り） |
| `aliases` | - | 異体字・別名（逆引きで吸収） |

**廃止フィールド**: `saijin:` は使わない（→ `deities:` に統一）

## 📐 ノート構造の二重設計

阿波国の郡別調査では、各比定社に対し **2系統のノート** を併設する設計を採用している：

| 系統 | ファイル名 | 役割 | 主frontmatter |
|---|---|---|---|
| **研究ポータル** | 旧字体・古い表記（例：`天都賀佐比古神社`） | 専門論考リンクのハブ、dataview連携 | `deities/clans/industries/beliefs` |
| **延喜式参照カード** | 延喜式表記準拠（例：`天都賀佐毘古神社`） | 基本情報・社格・所在地・比定社 | `延喜式表記/読み/郵便番号/所在地` |

異体字ペア（重複ではない、意図的な二重構造）：
- 鹿江比売神社 ⇄ 鹿江比賣神社（板野郡 / 葦稲葉神社）
- 波爾移麻比禰神社 ⇄ 波尓移麻比弥神社（美馬郡 / 馬岡新田神社）
- 天都賀佐比古神社 ⇄ 天都賀佐毘古神社（美馬郡）
- 倭大國魂神大國敷神社 ⇄ 倭大国玉神大国敷神社（美馬郡）
- 天水沼間比古神天水塞比賣神社 ⇄ 天水沼間比古神天水塞比売神社（麻殖郡）

## 📂 論社サブノート化の規約

延喜式式内社の比定論社は1社につき複数存在することが多い（例：天水沼間比古神天水塞比売神社 → 敷島・杉尾・美奴間の3論社）。
これら論社の個別ノート化は、以下の条件を満たす場合のみ行う：

1. **論社が3件以上、かつ伝承・遺物・社伝の明確な差異がある場合**
2. その論社が独自に **氏族・祭祀史で重要な役割**を担っている場合
3. 上記以外は、親ノートの本文・frontmatter で論社一覧として記載するに留める

例外：すでに独立ノート化されている `[[上一宮大粟神社]]`、`[[王子和多都美神社]]`、`[[葦稲葉神社]]`、`[[生夷神社]]`、`[[天村雲神社]]` は阿波説で重要な役割を持つため、規約適用前から個別化されており、**現状維持**。
