# 熊野那智大社（くまのなちたいしゃ）

> [!summary] 要旨
> 紀伊国牟婁郡那智山に鎮座する熊野三山の一角。**那智の滝**（落差133m、一段の滝として国内最大級）を御神体として発祥し、後に山上に社殿を建てた、原始的滝信仰・水神信仰を継承する古社。**熊野夫須美大神（くまのふすみのおおかみ、伊邪那美神とされる）**を主祭神とし、熊野三山の中で唯一、**滝そのものの原始信仰**に始まる社である（本宮・新宮の二社と異なり社殿の創建は遅れた）。本ノートは、那智の滝＝水神・龍神信仰が阿波の[[速雨神社]]・[[宇母理比古神社]]系統の水神祭祀と同型構造を持つこと、補陀落渡海の起点として阿波海部の捨身海上行と黒潮文化圏祭祀を共有すること、そして**伊邪那美の阿波死去伝承**と紀伊有馬村埋葬伝承（花の窟神社）の二重性を論じる。3社相互参照は [[熊野本宮大社]]・[[熊野速玉大社]]。

## 1. 命題の構造

| 観点 | 通説 | 阿波説 |
|---|---|---|
| **創建** | 神武東征時の熊野上陸で発祥（社伝） | 自然崇拝（滝信仰）が阿波・紀伊海人族の祭祀として先行成立、後に社殿整備 |
| **那智の滝の意味** | 紀伊在地の山岳信仰 | 阿波の水神信仰（[[速雨神社]]・[[宇母理比古神社]]）と同型の**龍神＝水神祭祀** |
| **熊野夫須美大神** | 伊邪那美神に比定（中世以降） | 阿波説のイザナミ阿波死去伝承との緊張関係。紀伊有馬村埋葬伝承（花の窟神社）と二重性 |
| **延喜式表記** | 式内社ではなく**式外社**。確認できる古代の記録は『新抄格勅符抄』所引の天平神護2年（766年）熊野牟須美神への神封戸4戸であり、『日本三代実録』の貞観年間の昇階記事に夫須美神の名はない | 三山中で最古層の滝信仰を継承するが、文書化が遅れたため式内社化を逃した |
| **補陀落渡海** | 中世以降の那智浜起点の捨身行 | 阿波海部の海人族の捨身海上行と同根、黒潮文化圏の他界観 |
| **修験道の聖地化** | 那智参籠所・行者宿の発達 | 阿波修験（剣山修験・太龍寺修験）と双方向交流 |
| **「那智」地名** | 「ナチ」の原義は不明（「滑」「魚町」「奈智」など諸説） | 阿波地名との比較対照は今後の課題 |

## 3. 祭神と社伝

### 3-1. 熊野夫須美大神＝伊邪那美神

主祭神**熊野夫須美大神**は中世以降、**伊邪那美神**と同体とされてきた：

| 比定 | 根拠 |
|---|---|
| **伊邪那美神** | 中世神仏習合期以降の主流説。本地仏は**千手観音**（第四殿・西御前の本地仏） |
| **熊野久須毘命** | 夫須美大神を熊野久須毘命とする説もある（Wikipedia「熊野那智大社」） |
| **事解男命（事解之男神）** | 祭神そのものを事解男命とする説もある（同上） |
| **結（むすび）の神** | 公式サイトは御神徳により古くより「結宮（むすびのみや）」と称されたとする。ただし「フスミ」の語源自体は諸説あり未確定（留保参照） |
| **農業神・水神** | 那智の滝を御神体とすることから、農業に必要な水を司る神 |

### 3-2. 社伝にみる創建

出典で確認できる社伝は次のとおりである：
- 『熊野権現金剛蔵王宝殿造功日記』：孝昭天皇の頃、インドから渡来した**裸形上人**が十二所権現を祀ったとする
- 『熊野略記』：仁徳天皇の頃に鎮座したとも伝える
- 当初は那智滝の正面にある現・**飛瀧神社**の地に社殿があり、仁徳天皇5年（317年）に社殿が現在地に移転されたとされる。滝そのものを御神体とする飛瀧神社（別宮）は別途維持される
- 第一殿・滝宮の祭神は**大己貴命（飛瀧権現）**であり、滝の神は大己貴命として祀られる

なお、旧稿が記した「神武天皇が熊野上陸時に那智の滝を遠望して大己貴命を遣わし、滝を祀ったのが起源」とする神武東征の社伝は、今回の照合範囲（Wikipedia・公式サイト）では出典を確認できなかったため未検証とする（留保参照）。

### 3-3. 那智の滝＝御神体

| 項目 | 内容 |
|---|---|
| 落差 | 133m（総合落差では国内12位だが、一段の滝としては落差140mのラッキベツの滝（北方領土・択捉島）に次ぐ国内2位。日本の施政権の及ぶ範囲内では一段の滝として最大） |
| 銚子口（落ち口）の幅 | 13m |
| 滝壺の深さ | 約10mとされることがあるが、出典を確認できず**未検証**（再検証 2026-11-16：那智大社公式・和歌山県観光資料でも確認できず、未検証のまま残す） |
| 祭祀形態 | 滝そのものを御神体とする原始神道形態 |
| 別宮 | 飛瀧神社（ひろうじんじゃ） |
| 名瀑 | 華厳滝・袋田の滝とともに日本三名瀑に数えられる。那智大滝として国指定名勝 |

那智の滝は**那智原始林**（国指定天然記念物、1928年指定。社有林）から流れ出る神聖な水であり、古代から滝そのものが信仰対象とされてきた。

### 3-4. 「結宮（むすびのみや）」構造

熊野三山では夫須美大神（イザナミ）は**結宮**として速玉宮と並立する（「結宮」の称は公式サイトも用いる）：
- 那智大社では第一殿が**滝宮（大己貴命＝飛瀧権現）**、第二殿が**証誠殿（家津御子大神・国常立尊）**、第三殿が**中御前（御子速玉大神）**、**第四殿が西御前（夫須美大神）**、第五殿が**若宮（天照大神）**で、これら上五社に中四社・下四社を合わせる
- 平安時代後期には三山とも十二所権現を祀る形が整ったが、那智は別格の滝宮を加えて**十三所権現**となっており、康暦元年（1379年）の記録などに残る（一方、公式サイトは当社を「日本第一大霊験所根本熊野十二所権現」と称する）
- 構造は本宮・速玉と類似だが、滝宮を第一に置く点が独自

## 4. 歴史

### 4-1. 創建伝承
- 『熊野権現金剛蔵王宝殿造功日記』：孝昭天皇の頃に裸形上人が十二所権現を祀ったとする
- 『熊野略記』：仁徳天皇の頃の鎮座を伝える
- 仁徳天皇5年（317年）に社殿が滝本（現・飛瀧神社の地）から現在地へ移転されたとされる（いずれも社伝で、創成の詳細は不明）

### 4-2. 文献上の記録
- 『新抄格勅符抄』（大同元年・806年）所引：天平神護2年（766年）、熊野牟須美神に熊野速玉男神とともに**神封戸4戸**
- 『日本三代実録』の貞観元年（859年）の早玉神・坐神の従五位上への昇階記事にも、同5年（863年）の早玉神の正二位への昇階記事（対象は早玉神のみで坐神を含まない）にも、牟須美神（夫須美神）の記述は**ない**
- **延喜式神名帳には未記載**（牟婁郡六座は熊野早玉神社・熊野坐神社・海神社三座・天手力男神社。巻第十原文で確認）
- 永観2年（984年）『三宝絵詞』：熊野両所として速玉神とともに夫須美神を取り上げる
- 本宮・新宮と併せて熊野三山とする記述は永保3年（1083年）9月4日の『熊野本宮別当三綱大衆等解』が最も早い
- 『中右記』天仁2年（1109年）10月27日条の藤原宗忠らの参拝記録から、この頃までに現在の社地に遷祀されていたとされる
- なお、熊野三山の垂迹縁起は『長寛勘文』所収（平安時代）であり、旧稿の「南北朝期『熊野権現御垂迹縁起』」という位置付けは、本宮ノートの照合結果と同様に是正する

### 4-3. 神仏習合と那智参詣
- 平安中期以降、熊野三山一体の参詣対象に
- 神宮寺として[[青岸渡寺]]（西国三十三所第一番）が隣接、神仏習合最濃密の地
- 那智参籠（なちさんろう）：行者・参詣者の参籠が活発化
- 後白河院ら熊野御幸の重要訪問地

### 4-4. 補陀落渡海（ふだらくとかい）

中世、那智浜が**補陀落渡海**の最も有名な拠点となる：
- **補陀落（ふだらく）**＝南海上の観音浄土
- 渡海行者は密閉式の小舟に乗り、扉を釘で打ちつけられて沖へ漕ぎ出される
- 食料は30日分のみ、生還の意図はない**捨身行**
- 補陀落渡海の最古の事例は貞観10年（868年）11月3日に熊野で慶龍上人が行ったものとされ、那智の**補陀洛山寺**を拠点に行われた渡海は最も有名で資料も多い。『熊野年代記』には貞観10年から享保7年（1722年）まで20例の記録がある

### 4-5. 戦国〜近世
- 天正9年（1581年）、堀内氏善が那智山への支配を強化したことに反発した社家・御師の廊ノ坊が武力決起し、氏善の攻撃で本殿などの社殿が焼失した（旧稿の「豊臣秀吉の熊野攻め」はこの堀内氏善との戦いの誤記とみられる）
- 社殿（第一殿〜第六殿）はその後の再建で、社蔵文書によれば嘉永7年（1854年）までに竣工している
- 慶長6年（1601年）、紀州藩主浅野幸長によって市野々村・二河村に300石が与えられた（『熊野那智山神領注文写』では神領633石余）

### 4-6. 近代以降
- 明治6年（1873年）に県社に指定され那智神社と称し、さらに熊野夫須美神社と改称
- 明治7年（1874年）に如意輪堂が青岸渡寺として当社から独立（本宮・速玉では仏堂が全て廃されたが、那智では西国三十三所第一番札所であったため破却を免れた）
- 大正10年（1921年）に官幣中社に昇格し熊野那智神社と改称（旧稿の「旧官幣中社（明治4年）」は年次の誤り）
- 昭和23年（1948年）に神社本庁の別表神社に加列、昭和38年（1963年）に熊野那智大社に改称
- 社殿8棟（第一殿〜第六殿・御県彦社・鈴門及び瑞垣）が国の重要文化財（1995年指定）
- 2004年「紀伊山地の霊場と参詣道」として世界遺産登録

## 5. 那智の滝＝水神信仰と阿波接続

### 5-1. 那智の滝の祭祀構造

那智の滝は**原始神道の自然崇拝形態**を継承する典型例：
- 滝そのものを御神体とする（社殿は滝の遥拝所）
- 滝壺・滝口・滝水のそれぞれに神聖性
- 飛瀧神社では現在も**滝を直接拝む**形式
- 滝の上流には磐座祭祀の痕跡（修験者の行場）

### 5-2. 阿波の水神祭祀との同型性

阿波には濃密な水神・龍神祭祀が存在し、那智の滝祭祀と同型構造を持つ：

| 阿波の水神祭祀 | 内容 | 那智との同型性 |
|---|---|---|
| [[速雨神社]]（勝浦郡） | 暴れ川（勝浦川・吉野川）の鎮守、降雨・治水の水神・龍神 | 自然神格化された水神、農業との結合 |
| [[宇母理比古神社]]（勝浦郡） | 海神の御子、海人族祭祀 | 海と滝水の連続性、海人族との結合 |
| [[水神社 (北島町)]] | 吉野川河口の水運・龍神 | 河口・滝の水神信仰の同根 |
| [[山方比古神社]] | 山岳神＋鉱山開発 | 山岳信仰と水信仰の結合（那智原始林） |

> [!important] 阿波説的解釈
> 那智の滝＝水神・龍神信仰は阿波の[[速雨神社]]の水神信仰と同根構造を持つ。阿波説では「**阿波忌部・海人族の水神祭祀が黒潮ルートで紀伊熊野に展開し、那智の滝という巨大水落を御神体として体系化された**」と読む。両地の水神祭祀は農業（稲作・粟作）開拓と密接に結びつく点でも共通する。

### 5-3. 「那智」と「勝浦」

| 地名 | 紀伊 | 阿波 |
|---|---|---|
| 勝浦 | 那智勝浦町（東牟婁郡） | 勝浦郡（小松島市～勝浦町） |

## 6. 阿波説における意義

### 6-1. 黒潮文化圏の水神・滝信仰の紀伊側拠点

- 那智の滝＝水神・龍神信仰は阿波の[[速雨神社]]・[[宇母理比古神社]]と同型
- 黒潮ルート上の水神祭祀の連続性（阿波→紀伊）
- 農業開拓と水神祭祀の結合

### 6-2. 補陀落渡海と阿波海部の捨身海上行

- 那智浜の補陀落渡海は中世海上他界観の典型
- 阿波海部郡（海部郡・那賀郡）の海人族にも同型の捨身海上行伝承
- 黒潮文化圏共通の**南海観音浄土観**
- 阿波→紀伊→南海への祭祀ライン

### 6-3. イザナミの阿波死去伝承と紀伊有馬村埋葬伝承の二重性

『日本書紀』神代巻上一書：
> 伊弉冉尊は、軻遇突智（火の神）の出産時に焼かれて死に、「紀伊国の熊野の有馬村」に埋葬された。以来、近隣の住人たちは季節の花を供えて伊弉冉尊を祭った（趣意）。

→ イザナミは紀伊国熊野有馬村に葬られたとされ、花の窟神社（三重県熊野市有馬町）が伝承地であることを当社（花の窟神社）側が伝える。

一方、阿波説では：
- イザナミは**阿波で死んだ**説（阿波の伊邪那美陵伝承地）
- 阿波→紀伊への祭祀移動の痕跡として、那智大社・花の窟神社にイザナミ祭祀が転移したと読む
- 熊野夫須美大神＝伊邪那美神の比定は、紀伊熊野が**国生み夫婦神の終着地**として体系化された結果

### 6-4. 修験道の双方向交流

- 熊野修験（本山派・当山派）と阿波修験（剣山修験・太龍寺修験）の中世交流
- 那智参籠所・行者宿に阿波系修験者の往来痕跡
- 滝行・参籠行の作法に共通性

### 6-5. 西国三十三所第一番・青岸渡寺との関係

- 西国三十三所巡礼の起点が那智に置かれることの意味
- 阿波の四国八十八ヶ所巡礼（弘法大師創始）と西国三十三所巡礼の対比
- 阿波・紀伊の聖地観の互換性

### 6-6. 「結（むすび）の神」と阿波の生成神

夫須美＝結（むすび）の神は生成・結合の女神：
- 阿波の大宜都比売＝食物・生成の女神
- 両者ともに**生成・結合・農業豊穣**の女神
- 紀伊熊野の夫須美大神は阿波の生成女神祭祀と同型構造
