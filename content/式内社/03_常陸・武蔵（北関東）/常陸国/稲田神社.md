# 稲田神社（いなだじんじゃ）

> [!summary] 要旨
> **稲田神社（茨城県笠間市稲田）** は、『延喜式』神名帳に常陸国新治郡の**名神大社**として記載される式内社（新治郡三座のうち唯一の大社）。主祭神は**奇稲田姫命**で、江戸時代の『稲田姫宮神社縁起』は、姫が当地の泉「好井」に顕現し「当地の地主神」として父母の宮・夫婦の宮を営むよう神託した由緒を伝える。本宮（奥の院）の磐座は姫の降臨地とされる。縁結び・安産等の御神徳で崇敬を集めるが、**阿波説の観点から具体的に論じられる材料は乏しく**、本ノートも常陸国式内社としての一般情報を中心に記載する。

## 3. 祭神と社伝

主祭神の**奇稲田姫命**は、記紀神話における素戔嗚尊の八岐大蛇退治神話に登場する女神で、足名椎命・手名椎命の娘、素戔嗚尊の妻とされる。

当社の由緒は、江戸時代の**『稲田姫宮神社縁起』**が伝える。縁起によれば、当地の邑長・武持の家童が稲田の「好井」の水を汲もうとすると泉の傍らに女性が現れ、武持が尋ねると「自分は奇稲田姫で当地の地主神である」と答え、姫の父母の宮・夫婦の宮を建て、好井の水で稲を作り祀るよう神託を下したという。茨城県神社庁の由緒も同旨で、百枝の椎の木の下の泉「好井」に稲田姫が現れたとし、その後に字宮山へ遷宮、火災で焼失し嘉永元年（1848年）に再建されたのが今の稲田神社であると伝える。

境内には縁起の「父母の宮」「夫婦の宮」に対応する境内社が鎮座する。

- **手摩乳神社**（祭神：手摩乳命）—「父母の宮」の父宮
- **脚摩乳神社**（祭神：脚摩乳命）—「父母の宮」の母宮
- **八雲神社**（祭神：素盞鳴尊）—「夫婦の宮」の夫宮

また本社の北西約300メートル、稲田山中腹には**本宮（奥の院）**が鎮座し、本社の旧鎮座地と伝わる。本宮の祠の左手に突き出た巨石（磐座）が稲田姫の降臨地と伝わっている。

なお、当社は**新治国造が奉斎した神社と考えられている**。新治国造は律令制以前に新治郡地域を治めたとされる国造で、『先代旧事本紀』「国造本紀」新治国造条には美都呂岐命の子の比奈羅布命を初代国造とする旨の記載がある。美都呂岐命（弥都侶伎命）は天穂日命の八世孫で出雲国造と同祖にあり、当社周辺の式内社（佐志能神社・鴨大神御子神主玉神社・大国玉神社）もいずれも出雲系の神々を祀ることから、文献との関係が指摘される（以上、Wikipedia「稲田神社」による指摘の紹介であり、確定した史実ではない）。

## 4. 歴史

- 創建は不詳。**六国史等の正史には当社に関する記載はない**。
- 『延喜式』神名帳（巻第九）に常陸国新治郡「稲田神社／名神／大」と記載され、名神大社に列する。新治郡は三座（大一座・小二座）で、名神大社に列するのは稲田神社のみ（延喜式原文で確認）。
- 鎌倉時代初期、領主の笠間時朝は藤原光俊・宇都宮泰綱ら8人を招いて当社で奉納歌会を催し、『新和歌集』（宇都宮新和歌集）にその歌が記載される。
- 室町時代末期に兵火により社殿を焼失。慶長7年（1602年）に伊奈忠次が当地を検地した際に本殿等が再建された。
- 寛文8年（1668年）には藩主の井上正利が除地4石を与えた。
- 元禄7年（1694年）には徳川光圀が当社に参詣し、古社の衰微する様子を嘆き、縁起等を奉納した。社宝の四神旗は元禄11年（1698年）の奉納。
- 社殿は弘化2年（1845年）に焼失し、嘉永元年（1848年）に再建された。
- 明治6年（1873年）に合祀神5柱が合祀された。近代社格制度では県社に列格。
- 境内近くには浄土真宗の稲田禅房西念寺（親鸞ゆかりの地）があり、稲田の地自体が古代からの由緒に加え中世宗教史上も知られる。

## 5. 新治郡における位置づけ

延喜式神名帳の常陸国新治郡は三座（大一座・小二座）で、**稲田神社（名神大）・佐志能神社・鴨大神御子神主玉神社**が登載される。稲田神社は郡内唯一の大社であり、郡内随一の格式を持つ。

出雲系神話（八岐大蛇・稲田姫伝承）を祭神の由緒とする点は、常陸国内の他の式内社（鹿島神宮の武神祭祀、静神社の倭文祭祀、吉田神社の日本武尊東征伝承など）とは異なる系統に属し、常陸国式内社の中でも独自の性格を持つ社である。さらに新治国造（出雲国造と同祖）と周辺の出雲系式内社の分布は、この地域の祭祀の出雲系の性格を示すものとして指摘される。

## 6. 阿波説における意義

[[常陸国の式内社一覧]]における阿波接続の主要論点（那賀郡・稲敷市周辺の「阿波」地名集中、静神社の建葉槌命＝阿波忌部系譜、大生神社を起点とする多氏の東遷）のいずれにも、稲田神社は直接該当しない。一覧ノートの表でも稲田神社の「阿波接続」欄は空欄であり、これは記載漏れではなく**該当する具体的論点が確認されていないことを示す**。

奇稲田姫命は出雲神話の系譜に属する神格であり、阿波忌部の祖神（天日鷲命・天太玉命等）や、阿波忌部の東国進出に伴う麻・製織関連の祭祀とは伝承の系統が異なる。現時点では、稲田神社について阿波説の枠組みで論じるべき具体的な地名・祭神・氏族の一致点は見出されていない。

> [!warning] 注意

1. **改訂記録（2026-11-15、事実照合実施）**: 本ノートの事実主張を、延喜式神名帳巻第九の原文（Vault保存のWikisource転写）、Wikipedia「稲田神社」、茨城県神社庁の当社ページと照合し、以下の訂正・補完を行った。原文バックアップは監査フォルダに保存。
2. **配祀の訂正**: 旧稿§2の配祀「素盞嗚尊とする伝もあり」は不正確だったため訂正した。公的資料では、合祀神は布都主神・菅原道真公・大山咋命・大日孁貴命・未詳1座の5柱（明治6年（1873年）合祀、『日本の神々』による）であり、素盞嗚尊は境内社・八雲神社（「夫婦の宮」の夫宮）の祭神である。なお境内説明板では祭神を奇稲田姫命1柱とする。
3. **「日本一社 縁結大社」の通称は未検証**: 旧稿§2の通称「日本一社 縁結大社」および要旨の「『日本一社』を称する」は、今回照合したWikipedia・茨城県神社庁では確認できなかったため本文から外した。神社庁の愛称は「稲田姫」であり、御神徳としての「縁結びの神」は神社庁で確認できる。
4. **「生誕地・出身地」説は未検証**: 旧稿§3の「奇稲田姫命の生誕地・出身地」とする社伝表現は、『稲田姫宮神社縁起』の伝える内容（当地の泉「好井」への顕現・降臨と「当地の地主神」であること）とは異なり、縁起本文による裏付けを確認できなかったため、本文は縁起の内容に沿って書き改め、生誕地説は未検証としてここに分離する。他地域にも稲田姫ゆかりを称する社（島根県奥出雲町の稲田神社等）がある。
