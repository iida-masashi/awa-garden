# 鹿島神宮の元宮と多氏の東遷

> 📚 親ハブ: [[元宮ハブ_MOC]]

茨城県潮来市に鎮座する**大生神社（おおうじんじゃ）**は、東国を代表する武神の聖地・鹿島神宮の**「元宮」**として極めて重要な位置を占めている。本ノートは、その由緒と多氏（オフ氏・飯富族）の東遷との関係を整理する。

## 📜 鹿島神宮の元宮

由緒によれば、鹿島神宮の祭神（タケミカヅチ）が現在の地に遷座する以前の、本来の鎮座地（元宮）が大生神社であるとされる。

### 二段階遷座の年代

| 年 | 事象 | 史料 |
|---|---|---|
| **神護景雲2年（768）** | 大生神社の鹿島神 → **春日大社**へ遷座 | 春日大社社伝、奈良時代の文書 |
| **大同2年（807）** | 春日 → 現在の**鹿島神宮**地へ遷幸 | 鹿島神宮社伝、息栖神社遷座年と一致 |

→ 興味深いことに、**斎部広成の『古語拾遺』編纂年（807年）と鹿島遷座年が一致**。同じ年に息栖神社も日川から現在地へ遷座しており、東国祭祀の大規模再編期だった。

### 特殊な祭祀資格

大生神社は、鹿島神宮の **「物忌（一生独身で仕える斎女）」が神宮外へ出て祭祀を行う唯一の特例の場所**である。これは元宮であった伝承の制度的な反映と解釈できる。

## 📜 多氏（オフ氏）の東遷と大生古墳群

この神社を創祀したのは、神武天皇の皇子・**神八井耳命（かんやいみみのみこと）**を祖とする**多氏（オフ氏・飯富族）**である。

彼らは大和（阿波）から常陸へ移住した際、一族の氏神として鹿島神を祀った。境内周辺には**110基を超える「大生古墳群」**が存在し、多氏一族の奥津城（墓）として彼らの強大な勢力を今に伝えている。

### 古墳群の特徴

- 5～6世紀の築造
- 前方後円墳・帆立貝形古墳・円墳を含む
- 「**手捏ね祭器**」（鹿島型）が出土
- 大賀立野遺跡（鹿島神宮周辺の出土物と同型）

→ 物的証拠として、阿波忌部の千葉側痕跡（房総半島の古墳群）と並ぶ重要遺跡。

## 📜 鹿島神宮の祭祀掌握過程

大生神社（多氏奉斎）から鹿島神宮（中臣氏奉斎）への祭祀権の移動は、以下のプロセスで説明される：

| 年 | 事象 |
|---|---|
| 古墳時代 | 多氏が大生に鹿島神を祀る |
| 645年 | 乙巳の変、中臣鎌足が政治の実権を握る |
| **649年** | 鹿島が「**神郡**」となり、神戸が8戸から50戸に増加（『常陸国風土記』）。中臣部兎子らによる申請 |
| 662-671年 | 鹿島神宮が建設される（中臣部から「鹿島社祝」が出る） |
| 710年 | 藤原不比等、鹿島から**春日大社**に武甕槌命を遷す |
| 746年 | 常陸国鹿島郡の中臣部20戸が**中臣鹿島連**へ改氏姓（『続日本紀』） |
| 768年 | 藤原氏、春日大社の社殿造営、第一祭神を武甕槌命とする |
| 807年 | 春日 → 鹿島へ再遷座 |

→ 多氏祭祀（大生神社）から中臣氏祭祀（鹿島神宮）への移行は、ヤマト王権中央の藤原氏台頭と完全にシンクロしている。

## 📜 鹿島・香取・息栖の三社配置

『常陸国風土記』に「天の大神の社・坂戸の社・沼尾の社の三社を合わせて香島の天の大神という」とあり、三社セットの祭祀構造が古層に存在する。さらに**東国三社**（鹿島・香取・息栖）は、利根川下流・常陸利根川に**直角二等辺三角形**を成す配置で、海路・水路を統括する祭祀ネットワークを形成した。

| 位置関係 | 内容 |
|---|---|
| 鹿島跡宮 ⇔ 香取 | 真東西の直線 |
| 息栖 | 鹿島跡宮の真南、香取の真東 |
| 大戸神社 | 息栖・香取の延長線上（オオ氏の関連説） |

→ この配置は **太陽の動きに合わせた日祀り** の構造を持ち、オオ氏（多氏）の祭祀方式の特徴と一致する（2023-08-31_謎のオオ氏を探せ！　1．はじめに）。
