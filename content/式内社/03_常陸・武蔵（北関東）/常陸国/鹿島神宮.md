# 鹿島神宮（かしまじんぐう）

> [!summary] 要旨
> **鹿島神宮**（茨城県鹿嶋市宮中2306-1）は **常陸国一宮**・**延喜式名神大社**・**月次新嘗の幣帛にあずかる古代国家祭祀の最高格社**。主祭神 **武甕槌大神（タケミカヅチノオオカミ）** は『古事記』『日本書紀』の **国譲り・神武東征** の双方で霊剣 **韴霊（フツノミタマ）** を振るう武神で、香取神宮（経津主神）と対をなす東国武神祭祀の中核。阿波説では (1) **大生神社（潮来）を元宮とする多氏奉斎**、(2) **武甕槌＝阿波・建布都神社の祭神と本来同体**、(3) **境内 鷲宮に阿波忌部祖神・天日鷲命を祀る痕跡**、(4) **香取（経津主）⇔鹿島（武甕槌）の対構造は阿波で一社統合祭祀されていた武神を東国経営のため分祀した姿** という四層の阿波接続論を構成する。768年大生→春日、807年春日→現鹿島地という二段階遷座と、同年（807）の斎部広成『古語拾遺』編纂が祭祀政治史上シンクロする点が阿波説の最強論拠の一つ。

## 3. 祭神：武甕槌大神の三層性

### 3-1. 記紀における三段階の役割

| 段階 | 神話の場面 | 役割 |
|---|---|---|
| **神産み段** | 伊邪那美命の死後、伊邪那岐命が十拳剣で迦具土を斬る | 剣先から滴る血の最後から生まれた **鍛冶神・刀剣神** |
| **国譲り段** | 伊都之尾羽張神の子として大国主のもとへ派遣 | 大国主・事代主の承諾を得、**建御名方を諏訪へ追討** |
| **神武東征段** | 神武軍が熊野で大熊の邪気に倒れる | **霊剣 韴霊（布都御魂）を高倉下経由で下し**、神武軍を救う |

→ 鹿島神宮の御神格「**武道の祖神・決断力の神**」は、この韴霊神話を直接根拠とする。

### 3-2. 別名・関連神格

| 別名 | 出典・関係 |
|---|---|
| **建御雷之男神**（タケミカヅチノオ） | 『古事記』 |
| **武甕槌神**（タケミカヅチ） | 『日本書紀』 |
| **建布都神**（タケフツノカミ） | 『古事記』異伝、[[建布都神社]]（阿波）の祭神名 |
| **韴霊（フツノミタマ）** | 神武東征時の霊剣神格、[[石上神宮]] の祭神と同体（『旧事本紀』） |
| **豊布都神**（トヨフツノカミ） | 『古事記』異伝 |

→ **「タケミカヅチ＝タケフツ＝フツノミタマ」** の名称群は、武甕槌神が **「剣（フツ）」を核とする神格** であることを示す。これは経津主神（フツヌシ）と本質的に **同根の神格** である可能性を示唆する。

### 3-3. 春日大社祝詞での並列

『延喜式』巻8「春日祭祝詞」冒頭：

> 鹿嶋坐 健御賀豆智命（かしまにます たけみかつちのみこと）・香取坐 伊波比主命（かとりにます いはひぬしのみこと）・枚岡坐 天之子八根命（ひらおかにます あめのこやねのみこと）・比賣神（ひめかみ）

→ **春日大社四神の筆頭** が鹿島大神。710年の藤原不比等による春日大社造営時に、鹿島の武甕槌神が分祀された。これが **藤原氏＝中臣氏による鹿島祭祀掌握の証跡**。

## 4. 元宮論：大生神社と多氏奉斎

→ 詳細：[[鹿島神宮の元宮と多氏の東遷]]、[[阿波説における意義]]、[[大生神社]]

### 4-1. 二段階遷座の年代

| 年 | 事象 | 史料 |
|---|---|---|
| 古墳前期 | 多氏（飯富族）が **大生神社**（潮来市大生）に鹿島神を祀る | 大生古墳群110基、社伝 |
| 649年 | **鹿島が「神郡」**となり、神戸が8戸→50戸に増加（『常陸国風土記』）。中臣部兎子らによる申請 | 『常陸国風土記』 |
| 662-671年頃 | 鹿島神宮が建設される。中臣部から「鹿島社祝」が出る | 社伝・推定 |
| 710年 | **藤原不比等**、鹿島から **春日大社**へ武甕槌命を遷す | 春日大社社伝 |
| 746年 | 常陸国鹿島郡の中臣部20戸が **中臣鹿島連** へ改氏姓 | 『続日本紀』 |
| 768年 | 大生神社の鹿島神 → **春日大社**へ遷座（藤原氏の社殿造営第一祭神とする） | 春日大社社伝 |
| **807年** | **春日 → 現在の鹿島神宮地** へ遷幸 | 鹿島神宮社伝、息栖神社遷座年と一致、斎部広成『古語拾遺』編纂年と一致 |

### 4-2. 大生神社＝元宮の制度的痕跡

- 鹿島神宮の **「物忌（一生独身で仕える斎女）」が神宮外へ出て祭祀を行う唯一の特例の場所** が大生神社
- 大生神社周辺の **手捏ね祭器（鹿島型）** は鹿島神宮周辺出土物と同型
- **大生古墳群110基**（前方後円墳・帆立貝形古墳・円墳、5〜6世紀）は多氏一族の奥津城

→ Shrine-heritager（鹿島神宮）も別途、**跡宮（あとのみや、鹿嶋市神野）** を「鹿島の大神が初めて天降り給いし所」とし、物忌が傍らに居住していたと記録。これは大生神社→現鹿島地の二段階遷座を前提とする「**初期降臨地**」の伝承層が現鹿島地（宮中）以外に複数存在することを示す。

### 4-3. 多氏（飯富族）と神八井耳命

大生神社の創祀氏族は **神八井耳命（神武天皇皇子）を祖とする多氏（オフ氏・飯富族）**。多氏のルーツ＝阿波の「大和（やまと）」（名西郡石井町、[[多祁御奈刀祢神社]] 周辺）とする論は [[多氏（オフ氏）：初期ヤマト王権の拡大と東遷]] を参照。

→ **「大和（阿波）→ 大和（畿内）→ 常陸」** の二段階東遷ルート上で、多氏が氏神として鹿島神を祀ったのが大生神社、その遷座先が現鹿島神宮、というのが阿波説における元宮論の骨子。

## 5. 阿波・建布都神社との同体論

→ 詳細：[[建布都神社]]、[[建布都神と阿波の武神伝承]]

### 5-1. 全国唯一の「建布都神社」

延喜式神名帳で **「建布都神社」を独立社名とするのは全国で阿波国阿波郡のみ**（一座）。祭神 **建布都神（タケフツノカミ）** は社伝・神社明細帳で建御雷神＝武甕槌神と同神とされる。

| 項目 | 内容 |
|---|---|
| 比定社 | 建布都神社（阿波市市場町香美） |
| 配祀 | 経津主命・大山祇命・事代主命 |
| 境内古墳 | 建布都神社古墳（直径18.5m円墳、横穴式石室、6世紀後半） |
| 神紋 | 武甕槌神の帯びていた霊剣を表す紋 |

→ **建布都神社の本殿に武甕槌神（建布都神）と経津主神が同座配祀** されている事実は、東国における鹿島（武甕槌）・香取（経津主）の **対構造の起源** が阿波の一社統合祭祀にあった可能性を示す重要証拠。

### 5-2. 国譲り神話の阿波現場説

阿波国阿波郡周辺に **国譲り神話の主要登場神** が半径15km圏内に完全配置：

| 神 | 阿波の比定社 |
|---|---|
| 建御雷神（建布都神） | 建布都神社（阿波市市場町香美） |
| 諏訪に追われた建御名方神 | [[多祁御奈刀祢神社]]（名西郡石井町諏訪） |
| 事代主神（承諾） | [[事代主神社]]（阿波市市場町伊月） |
| 伊都之尾羽張神（建御雷神の父） | 「尾羽丁」地名／勝占神社（徳島市） |

→ **鹿島の武甕槌神＝阿波・建布都神社の建布都神** とする読みは、国譲り神話地理の整合性によって補強される。

### 5-3. 神功皇后への神託「淡郡」

『日本書紀』神功皇后摂政前紀：
> 吾は **尾田吾田節（おだあがたふし）の淡郡（あわのこおり）** にいる神である。

志賀剛『式内社の研究』は「淡郡＝阿波国阿波郡」「吾田＝赤田（土成町成当・赤田神社）」と比定。神功皇后に神託を授けた神を **阿波郡の建布都神＋事代主神** と読む。

→ 阿波説では、神功皇后が三韓征伐前に神託を受けたのは鹿島（常陸）ではなく **阿波の建布都神** であり、これは武甕槌神信仰の本貫が阿波にあった傍証とされる。

## 6. 阿波忌部の関東祭祀軸との接続

### 6-1. 境内 鷲宮：天日鷲命

鹿島神宮の境内社のうち **鷲宮（わしのみや）《主》天日鷲命** が祀られている事実は重要。

- **天日鷲命**は阿波忌部の祖神（[[天日鷲命：天岩戸の功績と「鷲」の由来]]）
- 阿波忌部の関東祭祀ネットワーク（[[大鷲神社：天日鷲命を祀る関東鷲・鳥系神社ネットワーク]]）の北端
- 鹿島神宮の中枢に阿波忌部祖神が境内社として残ることは、**中臣による上書き以前の祭祀層** が阿波忌部由来であった可能性を示唆

→ Shrine-heritager 採録の境内社リスト：奥宮・三笠社・高房社（建葉槌神）・坂戸社（天児屋根命）・**沼尾社（経津主神）**・須賀社・熊野社・稲荷社・熱田社・御厨社・年社・潮社・阿津社・国主社・海辺社・**祝詞社（太玉命）**・押手社・津東西社・**鷲宮（天日鷲命）**・大黒社。

→ **沼尾社（経津主神）・祝詞社（太玉命＝阿波忌部祖神）・鷲宮（天日鷲命）** の三社が境内社として揃っていることは、鹿島祭祀圏が **阿波忌部の祭祀構造を内包** していたことの強い物的証拠。

### 6-2. 三社配置（坂戸社・沼尾社・天大神）

『常陸国風土記』：

> 天の大神の社・坂戸の社・沼尾の社の三社を合わせて **香島の天の大神** という

→ 古層の鹿島祭祀は **「天大神社（現本殿の前身）＋坂戸社＋沼尾社」の三社合体構造**。沼尾社が経津主神を祀る点は重要で、現在鹿島神宮境内社として残るが、本来は **独立した古社** だった可能性。

### 6-3. 東国三社の幾何学的配置

| 軸 | 内容 |
|---|---|
| 鹿島跡宮 ⇔ 香取 | 真東西の直線 |
| 息栖 | 鹿島跡宮の真南、香取の真東 |
| 大戸神社（オオ氏関連） | 息栖・香取の延長線上 |

→ 旧鎮座地基準で **直角二等辺三角形〜正三角形** を成す配置は、太陽の動きに合わせた **日祀り** の構造をもち、オオ氏（多氏）の祭祀方式と整合する（[[息栖神社]] §4 参照）。

## 7. 中臣氏による祭祀掌握の過程

| 年 | 事象 |

| 事象 | 内容 |

→ 807年は **中臣（藤原）・忌部の祭祀権闘争の頂点** であり、東国三社の祭祀再編が一斉に行われた政治祭祀史上の決定的年次。

## 9. 阿波説における意義

### 9-1. 多層構造の整理

| 層 | 祭祀主体 | 神格 | 拠点 |
|---|---|---|---|
| 最古層 | 阿波忌部 | 天日鷲命・太玉命 | 境内 鷲宮・祝詞社（残痕） |
| 古層 | 多氏（飯富族） | 鹿島神（武甕槌・タケカシマ） | 大生神社 |
| 中層 | 中臣氏（鹿島連） | 武甕槌大神 | 現鹿島神宮（建設7世紀後半） |
| 新層 | 藤原氏 | 武甕槌＋経津主＋天児屋根＋比売 | 春日大社（710年）／鹿島再編（807年） |
| 武家層 | 源氏・徳川 | 武道の祖神 | 本殿・奥宮造営（江戸初期） |

→ 阿波説は **最古層〜古層の阿波接続** を読む立場。中層以降の中臣・藤原祭祀は通説と共有する。

### 9-2. 香取との対構造の起源

東国における **鹿島（武甕槌）⇔ 香取（経津主）** の対構造は：

- 阿波 [[建布都神社]] における **建布都神（武甕槌）＋経津主神の同社配祀** が原型
- 東国経営の必要から、利根川（古・香取海）を挟む二拠点に **分割祭祀** されたのが鹿島・香取の対構造
- → 対構造そのものが阿波の一社統合祭祀の **分祀後の姿** という読み

### 9-3. 阿波忌部の関東祭祀軸の北端

阿波忌部の東遷ルート（黒潮：阿波→紀伊→伊豆→安房→上総→下総→常陸）の **北端拠点**。具体的痕跡：

- 境内 **鷲宮**（天日鷲命）
- 境内 **祝詞社**（太玉命）
- 「**斎瓮（イミベ）＝忌部**」の語源（[[側高神社]]・[[息栖神社]] の甕祭祀ネットワーク参照）
- 鹿島の先の海に **甕が埋められている** 伝承

→ 鹿島・香取・息栖の東国三社、および側高神社・大生神社を含む **香取海周辺の祭祀ネットワーク** は、阿波忌部の東国祭祀軸の最終発展形と読むことができる。

### 9-4. 「鹿島立ち」と祓神

鹿島から出立することを「**鹿島立ち**」と呼び、旅の安全祈願の信仰が古代から続く。これは **武甕槌神の「韴霊」による邪気祓い** の神格に由来し、阿波忌部の **祓神職能**（[[息栖神社]] の「気吹戸主神＝忌部の語源」論参照）と機能的に連続する。

## 12. 留保（中立的併記）

> [!warning] 重要な留保
>
> ### 通説と阿波説の関係
> - 鹿島神宮の主祭神 **武甕槌大神** が記紀神話の独立武神であること、本拠が常陸国鹿島郡であること、中臣氏（藤原氏）が古代以来の奉斎氏族であることは **通説・神社側の正式見解** であり、本ノートはこれを前提に整理する
> - 阿波説の「**多氏奉斎（大生）→中臣奉斎（鹿島）の二段階構造**」は社伝・『常陸国風土記』・春日大社社伝・『続日本紀』改氏姓記事などの **一次史料および地域社伝に依拠** する読みであり、これら一次史料からの推論として一定の根拠を持つ
> - 一方、「**武甕槌神＝阿波・建布都神の本来同体**」「**国譲り神話の現場＝阿波**」「**香取・鹿島の対構造＝阿波建布都神社の分祀**」とする読みは **阿波説固有の解釈** であり、通説の学界では支持されていない
>
> ### 個別論点の確度
> - **多氏（飯富族）が大生神社で鹿島神を奉斎していた** ことは、110基の大生古墳群・手捏ね祭器・物忌の特例祭祀地という **物的・制度的証拠** から確度が高い
> - **二段階遷座（768年大生→春日、807年春日→現鹿島）** は春日大社社伝・鹿島神宮社伝に依拠するが、史料は中世以降の編纂物であり、年代の厳密性は留保が必要
> - **大生神社＝鹿島神宮の元宮** とする伝承自体は江戸期以降の整理である可能性があり、古墳時代の祭祀がどの程度連続して現大生神社に至ったかは考古学的に確定していない
> - **境内 鷲宮（天日鷲命）・祝詞社（太玉命）** の祭祀は阿波忌部祖神との連続性を示唆するが、これらの境内社の創祀年代は不詳で、後世の合祀である可能性も排除できない
>
> ### 神武紀年・年代論
> - 鹿島神宮社伝の「神武天皇即位年（皇紀元年・紀元前660年）勅祭」は **儀礼的紀年** であり、考古学的・文献的に確実なのは古墳時代以降の祭祀層
> - 「**創祀2000年以上**」は社伝の表現であり、現代の歴史学的検証では古墳時代前期（4世紀頃）以降に祭祀の始原を求めるのが妥当
>
> ### 「阿波建布都神社＝武甕槌神の本貫」論の限界
> - 阿波・建布都神社が **延喜式神名帳で「建布都神社」の独立社名を冠する唯一の社** であることは事実
> - 「建布都神＝武甕槌神」の同神視は社伝・神社明細帳に依拠するが、記紀本文では建御雷神と経津主命を別神として描く場合もあり、フツノミタマ（剣神）と建御雷神の関係は古来議論がある
> - 志賀剛『式内社の研究』は建布都神を「**淵の神（水神）→武神への意味展開**」と読む慎重論を提示しており、武神としての性格は後世の意味付与である可能性
> - したがって「**鹿島の武甕槌＝阿波の建布都が本貫**」とする読みは、複数の解釈仮説のうち阿波説に親和的なものの **一つ** であり、確定論ではない
>
> ### 古事記異伝としての「タケフツ／トヨフツ」
> - 『古事記』では建御雷之男神の異名として「建布都神」「豊布都神」が記されており、これらが阿波の建布都神社祭神と同一名であることは事実
> - ただし、これは **「建御雷神＝建布都神」の名称的同一性** を示すものであり、「**阿波が本貫地**」までを直接示すものではない
> - 「阿波本貫」論は、(a) 「建布都神社」社名の全国唯一性、(b) 国譲り神話地理の阿波配置、(c) 大生神社の元宮論、の **複合的論拠** によって主張される
>
> ### 「斎部広成『古語拾遺』編纂年（807）と鹿島・息栖遷座年の一致」
> - 三重一致は **史料事実** であるが、これを「中臣による忌部祭祀権の上書き」とする解釈は阿波説の枠組み
> - 中臣・斎部の祭祀権闘争自体は『古語拾遺』本文から明確だが、それが東国三社の同年遷座と **直接の因果関係** を持つかは推論
>
> ### evidence_type と confidence
> - 本ノートのevidence_typeは **"primary_source_based"**（記紀・延喜式・常陸国風土記等の一次史料に基づく整理）
> - confidence は **4**（中位上）— 通説部分（一宮・名神大・祭神・遷座史）は確度が高いが、阿波接続論（建布都同体・国譲り阿波現場・元宮多氏阿波本貫）は仮説層
> - 個別論点の強度は項目ごとに大きく異なる。元宮論（大生）と境内鷲宮の阿波忌部祖神祭祀は **比較的確度が高い** のに対し、「香取・鹿島の対構造＝阿波建布都神社の分祀」は **解釈強度の高い仮説**
