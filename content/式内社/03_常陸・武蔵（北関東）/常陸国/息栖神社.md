# 息栖神社（いきすじんじゃ）

> [!summary] 要旨
> **息栖神社（茨城県神栖市息栖）** は **鹿島神宮・香取神宮と並ぶ「東国三社」** の一つ。**鹿島神宮境外摂社** で、神宮の南9.3kmに鎮座し、常陸利根川のほとりに位置する。主祭神は **久那戸神（くなどのかみ／岐神）**、相殿に **天鳥船神** および **住吉三神**。**応神朝に日川（現・神栖市日川）に創建**、799年の津波で流失、**807年に現在地へ遷座**。境内の **「忍潮井（おしおい）」の男瓶・女瓶** は『諸国里人談』所載の神代の銚子土器伝承を持ち、[[側高神社]] の「四箇の甕」、[[鹿島神宮]] の甕祭祀と共に **香取海周辺の甕祭祀ネットワーク** を構成する。阿波説では **「斎瓮（イミベ）＝忌部の語源」** から、息栖神社の甕祭祀を阿波忌部の関東祭祀軸の北端拠点として読む。

## 3. 祭神の重層構造

### 3-1. 五柱の祭神（息栖五所明神）

| 位置 | 神名 | 性格 |
|---|---|---|
| **主神** | **久那戸神（くなどのかみ）** | 大国主より遣わされた「**案内の神**」（『鹿島神宮』東実著）。境界で災難の侵入を防ぐ神 |
| 相殿 | **天乃鳥船神** | 出雲神話の「同行の神」 |
| 相殿 | 底筒男命 | 住吉三神、伊邪那岐命が黄泉の穢れを祓った際に海中から生じた神 |
| 相殿 | 中筒男命 | 同上 |
| 相殿 | 表筒男命 | 同上 |

### 3-2. 文献ごとに異なる祭神

| 文献 | 祭神 |
|---|---|
| 『日本後紀』 | **岐神（ふなど／くなどのかみ）** |
| 『日本三代実録』 | **於岐都説神（おきつせのかみ）** |
| 『息栖神社の文書』（『日本の神々 関東』所引） | **猿田彦** |
| 江戸期『木曽名所図会』『新編常陸国史』 | **気吹戸主神（いぶきどぬしのかみ）** |
| 現行 | 久那戸神・天乃鳥船神・住吉三神 |

→ 祭神の変遷は **岐神（道祖神） → 於岐都説神（沖洲神＝海神）→ 猿田彦（道案内神）→ 気吹戸主神（祓神）→ 久那戸神（現行）** という五層構造。本来は **「沖洲（おきつせ）の神」＝海神** で、後世に **岐神＝道祖神** が習合した。

### 3-3. 「於岐都説（オキツセ）」の語源

『十根川図誌』（江戸期）：

> 「息栖」は「**息洲**」で「**沖洲・浮洲**」の意

→ 「オキツセ」 → 「オキス」 → 「イキス（息栖）」 の音韻転化。**香取海に突き出た砂州の先端**に祀られた **海神**。

→ 『三代実録』仁和元年（885）3月15日の条：「**於岐都説**（おきつせ）」に従五位下を授ける。

### 3-4. 「気吹戸主神」と忌部祭祀

江戸期文献では主神を **気吹戸主神（いぶきどぬしのかみ）** とする。これは **海原に強風を生み出し罪穢を吹き払う神**。境内の **芭蕉の句碑** にも：

> 此里は気吹戸主の風寒し

→ 「**気吹（いぶき）**」と「**忌部（いんべ・いみべ）**」の音韻的接続が想起される。**祓神＝祭祀職能神** という性格は、忌部の本質と整合する。

## 4. 東国三社の幾何学的配置

### 4-1. 鹿島・香取・息栖の三角形

| 息栖の鎮座地 | 三社の形状 |
|---|---|
| **現社地（息栖）** | **直角二等辺三角形** |
| **旧社地（日川）** | **正三角形** |

→ kamimasu_com の指摘：「**意識的にそのような場所に神社を建てた**」と推定される。

### 4-2. 「鹿島跡宮・息栖・香取」軸の重要性

- **息栖神社の一の鳥居** は **鹿島神宮の南の鳥居** を兼ねる
- **鹿島の跡宮の真南** に息栖神社が位置
- **息栖の真西** に香取神宮
- 「**息栖→香取**」の延長線上に **大戸神社** が来る

→ 大戸神社は「**オオ氏**」関連と推察される（[[多氏（オフ氏）：初期ヤマト王権の拡大と東遷]]）。

### 4-3. 海面5m上昇シミュレーション

- 古代（縄文海進期）の水位を5m上昇させると：
  - **鹿島神宮・香取神宮は丘陵上で残存**
  - **息栖神社は現社地・旧社地ともに海中**
- これは [[側高神社]] の「**安婆嶋（あんばじま）**」と同様の地形変動史

→ 古代の **香取海（こうとりのうみ）** が現在の利根川下流域に広がっていた地形を考慮すると、**三社の幾何学的配置は古代の海岸線を前提**に設計されていた。

## 5. 忍潮井（おしおい）：男瓶・女瓶の甕祭祀

### 5-1. 忍潮井の概要

息栖神社の最重要祭祀物：

| 項目 | 内容 |
|---|---|
| **位置** | 常陸利根川沿い、一の鳥居の両脇 |
| **名称** | **忍潮井（おしおい／おししおい）** |
| **構造** | 水中に **男瓶（おかめ）・女瓶（めかめ）** の二つの土器（甕） |
| **創建伝承** | 神功皇后3年に造られた |
| **移転伝承** | **元宮地（神栖市日川）から自力で当地までついてきた** |
| **現状** | 河川改修により昭和48年（1973）に移転 |
| **湧水** | **男瓶は素水（淡水）にして潮の味なし**、潮の満ち引きに連動 |

### 5-2. 『諸国里人談』所載の伝承

吉田東伍『大日本地名辞書・板東』所引：

> 息栖明神の磯ぢかき海中に、**女瓶男瓶** とて、二つの奇石あり。**男瓶は経一丈あまりにして、銚子のかたちなり**。その口とおぼしき所に溝あり、中は穴のごとくに窪みて、鍋の形なり。
>
> **女瓶はわたり五六尺ばかり、土器に似たり**。土俗曰く、**これは神代の銚子土器なり** と。
>
> 此石満潮には二三尺沈めり。干潟には水上にあらはれけり。**その銚子の中は素水にして、潮の味ひなし**。これを **忍塩井の水** といへり。

→ **「神代の銚子土器」** という伝承。海中で淡水を保つ奇瑞から、**潮の干満を制御する神器** として崇敬された。

### 5-3. 「水中の甕が見えると願いが叶う」伝承

現代の信仰：
- 水の中の甕がはっきり見えると **願いが叶う**
- もしくは「**何らかのラッキー**」がある

→ 古代の **占術儀礼** の名残。[[側高神社]] の「**四箇の甕（四季の甕）**」と同じく、**水量や見え方による占い** の機能を持つ。

## 6. 「甕（カメ）」祭祀ネットワーク：香取海の忌部痕跡

### 6-1. 三社の甕祭祀

利根川を挟む3社すべてに **甕祭祀** が共通：

| 神社 | 所在 | 甕の名称・形態 |
|---|---|---|
| **[[側高神社]]** | 千葉県香取市大倉 | **四箇の甕（四季の甕）** — 春・夏・秋・冬の4甕、雨水占い |
| **息栖神社** | 茨城県神栖市息栖 | **忍潮井（男瓶・女瓶）** — 神代の銚子土器、潮の干満連動 |
| **[[鹿島神宮]]** | 茨城県鹿嶋市 | 鹿島の先の海に **甕が埋められている** 伝承 |

→ **東国三社＋側高神社の四社すべてに甕祭祀** が共通する。これは偶然ではない。

### 6-2. 「斎瓮（イミベ）＝忌部の語源」

田中勝也『サンカ研究』所引の下総一・印部一郎の伝承（[[側高神社]] §7で詳述）：

> 私の印部は神武様の前の前、ずうっと前から **スガベ** でございます。スガベというのは、清々しく身を清めて、**祭事の御供物 容器（イレ）を奉る一族** のことであります。
>
> 神前に延べる斉庭の真菰を編み、**御神酒（ミケ）を奉る陶（ヤキモノ）を作り、海幸山幸野幸を奉る箕（ミカラワケ）** などを、身を清めて作ります。
>
> これが **斎瓮（イミベ）** で、その遠祖の神が、**天太玉命** であります。

→ **「斎瓮（イミベ）＝忌部（インベ／イミベ）」** の語源。忌部の本質は **甕・箕製作の祭祀技術氏族**。

### 6-3. 阿波説的読み

| 観点 | 内容 |
|---|---|

| **東遷後の祭祀** | 阿波忌部の関東進出に伴い、**香取海周辺で甕祭祀が再構築** |
| **三社+側高の四社** | 阿波忌部の関東祭祀の **古層の物的証拠** |
| **「気吹戸主神」の祭神** | 「**忌部（いんべ／いみべ）**」の語源との音韻接続 |

## 7. 創建史と遷座

### 7-1. 移転年表

| 年代 | 出来事 |
|---|---|
| **270〜310年（応神朝）** | **日川**（現・神栖市日川）に **久那斗神・天乃鳥船神** を祭神として創建 |
| **799年（延暦18）** | 常陸国に津波襲来。**朝から晩まで15回も潮が満ち引き**、満潮時には **109m内陸まで潮が迫る**（『日本後紀』）。「岐神を祀る社」流失 |
| **807年（大同2）** | 平城天皇の勅命を受けた **藤原内麻呂**（鎌足4代孫、内麻呂7代孫が道長）により息栖（現在地）に遷座 |
| **885年（仁和元年）** | **「於岐都説神」に従五位下** を授ける（『日本三代実録』）。これが息栖神社のことと推定 |
| **昭和48年（1973）** | 河川改修により忍潮井（男瓶・女瓶）移転 |

### 7-2. 「大同2年（807年）」の意義

- 同年、**鹿島神が「今の鹿島」に遷座**（kamimasu_com の重要指摘）
- → 鹿島・息栖の **同年遷座** は偶然ではなく、**藤原氏（中臣系）による東国祭祀の再編** の一環
- 同時期に **斎部広成が『古語拾遺』を著す**（807年） — 中臣氏との祭祀権闘争の最中

→ 大同2年（807）は **中臣・忌部の祭祀権闘争の頂点**。藤原内麻呂の主導で東国三社祭祀が再編された時期に、阿波忌部祖神の祭祀権が中臣系に **上書き**された可能性が高い。

### 7-3. 旧鎮座地（神栖市日川）の現状

- 現社地から **東南東7km**、利根川を銚子港から **21km上流** の平地
- 現在は **「石塚開発の碑」の横に看板が立つのみ**
- 小祠も石碑もなく、自治会員の高齢化により草刈りも行われていない
- 日川地区遺跡からは **平安時代の遺物**（水上交通祭祀痕跡）が発見

→ **東国三社の起点でありながら荒廃** している現状。

## 9. 阿波説における意義

### 9-1. 甕祭祀による忌部接続

[[側高神社]]・[[鹿島神宮]]・息栖神社の **甕祭祀の三社共通性** は、**阿波忌部の祭祀器製作職能（斎瓮＝イミベ）** が東遷後も保存された痕跡。

→ 三社は **阿波忌部の関東祭祀軸の核心** であり、表層の祭神（経津主・武甕槌・岐神）の下に **忌部の原祭祀** が保存されている。

### 9-2. 「猿田彦」祭神説と忌部

『息栖神社の文書』に主神を **猿田彦** とする記述。猿田彦は：

- 阿波 [[大麻比古神社]] の祭神でもある（**大麻比古大神・猿田彦大神**）
- 阿波忌部の祭祀と接続する天孫降臨の案内神
- **岐神（道祖神）との習合** がしばしば起こる

→ 阿波 → 安房 → 上総 → 下総 → 常陸 という **阿波忌部の東遷ルート上で「猿田彦祭祀」の連続性** が観察される。

→ 詳細：[[大麻比古神社]]、[銚子の三笠山の謎 銚子市猿田町 猿田神社 未知の駅 總フサ](https://ameblo.jp/books-fu-sa/entry-12635977193.html)

### 9-3. 「天鳥船神」と阿波忌部祖神

相殿の **天鳥船神（あめのとりふねのかみ）** は：

- 出雲神話の「同行の神」
- **「鳥船」**＝鳥に乗る船、または鳥の形をした船
- [[側高神社]] の境内末社 **梶鳥社（カジトリシャ）の祭神「鳥船大神」** と同一神

→ 古樹紀之房間の指摘：**「鳥船神＝天日鷲命（阿波忌部祖神）の関連神」** （[[大鷲神社：天日鷲命を祀る関東鷲・鳥系神社ネットワーク]] 参照）。

→ 息栖神社の相殿に **天鳥船神** が並ぶことは、**阿波忌部の祖神祭祀の保存** を意味する。

### 9-4. 東国三社の幾何学設計と古代測量

旧鎮座地基準で **正三角形**を形成する三社配置は：

- **古代の測量技術** の物的証拠
- **海岸線・水運を考慮した祭祀地理**
- 阿波説では **阿波忌部の「斉瓮職能」を持つ祭祀技術氏族** による設計と読む

→ 三社の正三角形は **「東国の祭祀結界」** として機能していた可能性。

### 9-5. 「中臣則良」宮司の現状

現息栖神社の宮司は **中臣則良氏**（境内石碑「悠久」題額）。

→ 中世以降、息栖神社の祭祀権は **中臣系（藤原系）に最終的に確立** された。これは大同2年（807）の遷座（藤原内麻呂主導）の延長線上にある。

→ **阿波忌部 → 中臣の祭祀権交代** が祭祀史の長期トレンド。

## 12. 留保（中立的併記）

> [!warning] 注意
> - 息栖神社の祭神「久那戸神」は現行祭神であり、古層の祭神は **岐神・於岐都説神・猿田彦・気吹戸主神** など複数候補があり確定していない
> - 「**忍潮井＝神代の銚子土器**」伝承は『諸国里人談』（江戸期）所載で、考古学的検証は別途必要
> - 「**三社共通の甕祭祀＝阿波忌部の斎瓮職能**」とする読みは、田中勝也『サンカ研究』の伝承解釈に依拠する。サンカ研究の文献的地位については歴史学的に異論あり
> - 「**東国三社の幾何学的配置（直角二等辺三角形／正三角形）が古代の意図的設計**」とする論は、現代の地図観察に基づく推定で、古代の測量意図を直接示す史料はない
> - **「天鳥船神＝天日鷲命の関連神」** とする読みは古樹紀之房間の解釈で、文献的確証はない
> - **「気吹戸主神＝忌部の語源」** の音韻論的接続は阿波説特有の解釈
> - 大同2年（807）の遷座は史実だが、これを「中臣による忌部祭祀権の上書き」とする解釈は阿波説の枠組み
> - 本ノートのevidence_typeは "shrine_origin"、confidence は3（中位）— 個別論点の強度は項目ごとに異なる
