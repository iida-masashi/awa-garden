# 大桑神社（おおくわじんじゃ）

> [!summary] 要旨
> 茨城県結城市小森に鎮座する大桑神社は、由緒書に **「阿波忌部が東国に養蚕・織物を伝え、稚産霊尊を祭神として創建した」** と明記する稀有な神社。地名「**結城（ユフキ）**」「**小森（こもり＝蚕守）**」は、『古語拾遺』記載の **「結城郡＝穀（こうぞ）の生育地」** との文献的整合性を持つ。

## 1. 命題の構造

| 観点 | 通説 | 阿波説 |
|---|---|---|
| **養蚕の起源** | 養蚕は渡来系氏族等によって各地に伝来したとする説が主流 | 阿波忌部が結城下向の際に養蚕技術を伝え、「結城種」の起源となった |
| **地名「結城（ユフキ）」の由来** | 地名の語源は諸説あり確定していない | 『古語拾遺』の「穀（こうぞ）の生育地を結城郡と言う」との記述に対応する阿波忌部の到達地名 |
| **地名「小森」の由来** | 単なる地形・集落名 | 阿波斎部の伝えた蚕種を守ったことに由来する「蚕守（こもり）」の転訛 |

## 3. 祭神と社伝

### 結城市教育委員会の社頭説明

> **大桑神社**の由来については、古代、東国に養蚕・織物を伝えたとされる**阿波忌部**が、養蚕・農業の神、**稚産霊尊（わかむすびのみこと）**を祭神として北方の大水河原に**創建**、この辺り一帯を**大桑郷と名付けた**ことに始まり〜

> **小森**という地名は、阿波斎部の伝えた蚕種を守り、養蚕・織物が盛んであったことから、いつとはなしに、この辺りは**蚕守（こもり）**と称され〜

### 大桑神社由来書

> 阿波の忌部、結城に下向のとき、此所を御通りありしに大なる桑生して国民蚕をこふ（中略）世に蚕をかいはむること、此所より起こる。故に自今日本国中にて結城種を用いて、他の国の種を不要の故是なり。

→ これは「**日本の養蚕の起源が阿波忌部による結城下向にある**」という極めて強い主張。「結城種」は江戸時代まで全国の蚕種の主流であった。

## 4. 歴史

由緒書によれば、古代、阿波忌部が東国への下向の途上でこの地を通った際、北方の大水河原に稚産霊尊を祭神として社を創建し、この辺り一帯を「大桑郷」と名付けたことに始まるという。あわせて阿波斎部が伝えた蚕種を守ったことから、この地は「蚕守（こもり）」＝小森と称されるようになったと伝わる。以降の社格変遷等、由緒書を超える一次史料は現時点で確認されていない（旧郷社）。

---

## 5. 『古語拾遺』との文献整合性

斎部広成『古語拾遺』（807年）は、阿波忌部の東遷について次のように記す：

> 天富命、更に肥沃な土地を求めて**阿波の斎部**を分けて東の国に率いて往き、麻・穀を播き殖え、良い麻が生育した。故にこの国を**總国（フサノクニ）**と言う。**穀・木の生育したところは、是を結城郡（ユフキノコオリ）と言う**。古くは麻を總と言う。今の上總・下總の二国がこれである。阿波の忌部が居るところを**安房郡（アワノコオリ）**と言う。

→ 『古語拾遺』は **「結城郡」を阿波忌部の到達地として明示的に列挙**。結城郡は現在の茨城県結城市域を含む（古代の下総国北西部）。

→ 大桑神社の由緒書は、この『古語拾遺』記事と**完全に整合**する。文献史料・地名・社伝・産業（養蚕）が四重に揃う、阿波忌部東遷の最も強固な物的拠点の一つ。

### 養蚕・織物の阿波忌部ネットワーク

阿波忌部が伝えた製織・養蚕技術は、東国各地に拠点を残した：

| 拠点 | 内容 |
|---|---|
| **阿波・麻殖郡（吉野川市）** | 麻と織物の本拠（地名「麻殖」は麻栽培の意） |
| **結城（茨城県結城市）** | 大桑神社・小森（蚕守）／「結城紬」のルーツ |
| **常陸 久慈郡（那珂市）** | [[静神社]]、倭文（しどり）の祖神祭祀、「静織の里」 |
| **常陸 那珂郡** | 長幡部一族の繁栄 |
| **武蔵 賀美郡（埼玉北部）** | 長幡部神社 |

→ 阿波忌部の織物技術は、**安房上陸 → 結城（養蚕） → 久慈・那珂（倭文） → 賀美（長幡部）**と段階的に北上・内陸へ展開。

## 6. 阿波説における意義

### 阿波接続の三大論点

| # | 論点 | 根拠 |
|---|---|---|
| **1** | 由緒書が阿波忌部の創建を明記 | 結城市教育委員会の社頭説明、大桑神社由来書 |
| **2** | 地名「結城」が『古語拾遺』に登場 | 「穀（こうぞ）の生育地を結城郡と言う」 |
| **3** | 地名「小森」＝「蚕守（こもり）」の転訛 | 阿波斎部の伝えた蚕種を守ったことから |

| 観点 | 内容 |
|---|---|
| **史料整合性** | 『古語拾遺』記載と由緒書が四重整合（極めて稀） |
| **産業証拠** | 結城紬の起源地としての阿波忌部養蚕技術 |
| **地名証拠** | 結城（ユフキ）、小森（蚕守）、大桑郷の三重地名痕跡 |
| **祭神証拠** | 稚産霊尊（養蚕・農業）の阿波忌部祭祀 |

### 6-1. 文献・地名・社伝・産業の四重整合

『古語拾遺』の記述、地名「結城」「小森」、社伝の創建譚、結城紬という現存する産業実態が相互に矛盾なく重なる点が、大桑神社を阿波忌部東遷論の中でも特に強固な物的拠点たらしめている。

### 6-2. 養蚕起源説としての特異性

由来書が主張する「日本の養蚕の起源は阿波忌部の結城下向にある」という言説は、他地域の阿波忌部伝承と比べても踏み込んだ主張であり、結城種が江戸期まで全国の蚕種の主流であった実績と結びつけて語られている点が特徴的である。

### 6-3. 阿波忌部ネットワークの北上経路における位置づけ

大桑神社は、安房上陸後に阿波忌部の織物・養蚕技術が久慈・那珂・賀美へと内陸展開していく経路上の中間拠点として位置づけられる。
