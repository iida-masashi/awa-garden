# 大桑神社（おおくわじんじゃ）

> [!summary] 要旨
> 茨城県結城市小森に鎮座する大桑神社は、結城市の公式説明に **「東国に養蚕・織物を伝えたとされる阿波斎部（阿波忌部）が、稚産霊尊を祭神として創建した」** と明記される神社である。社伝では和銅年間（708〜715年）の創建、文明11年（1479年）の現在地への移転を伝え、現本殿は享保7年（1722年）建立で結城市指定有形文化財。『延喜式』神名帳には登載されない式外社で、康永2年（1343年）に結城直朝が定めた結城七社の三の宮。地名「結城」は『古語拾遺』に「穀木の生ずる所を結城郡と謂う」と見え、「小森」の由来には「蚕守（コモリ）」説と「篭（コモリ）」説の二説が市の説明で併記される。

## 3. 祭神と社伝

### 結城市の公式説明（結城七社資料）

> 大桑神社の成立については、古代、東国に養蚕・織物を伝えたとされる**阿波斎部（アワノインベ）**が、養蚕・農業の神、**稚産霊尊（ワカムスビノミコト）**を祭神として、**和銅年間（708年〜715年）**北方の大水河原に**創建**、この辺り一帯を**大桑郷（オオクワノサト）**と名付けたことに始まり、その後、洪水により流失、**文明11年（1479年）**今の地に移ったと伝わる。現在の本殿は**享保7年（1722年）**に建てられ、結城市指定有形文化財に指定されている。

> **小森**という地名は、阿波斎部の伝えた蚕種を守り、養蚕・織物が盛んであったことからいつとはなしに、この辺りは**蚕守（コモリ）**と称され、中世結城氏の時代には、合戦に備えてこの地に兵を篭らせたことから、**「篭（コモリ）」**と称されたことに由来すると伝わる。

境内の大欅は推定樹齢350年以上とされ、結城市指定天然記念物に指定されている（結城市公式資料）。

### 大桑神社由来書（旧稿引用・原文未照合）

> 阿波の忌部、結城に下向のとき、此所を御通りありしに大なる桑生して国民蚕をこふ（中略）世に蚕をかいはむること、此所より起こる。故に自今日本国中にて結城種を用いて、他の国の種を不要の故是なり。

→ これは「**日本の養蚕の起源が阿波忌部による結城下向にある**」という強い主張を含む社伝資料である。ただし由来書そのものは本照合では未取得で、上記は旧稿が引く転記である（留保参照）。

## 4. 歴史

- **和銅年間（708〜715年）**：社伝では、阿波斎部が北方の大水河原に稚産霊尊を祀って創建し、一帯を大桑郷と名付けたという。
- **康永2年（1343年）**：結城氏7代直朝が領内の由緒ある七社を選定した「結城七社」の一つ（大桑大明神、三の宮）に数えられた（『結城御代記』に基づく結城市の説明）。
- **文明11年（1479年）**：社伝では、洪水で流失したため現在地に移ったという。
- **享保7年（1722年）**：現本殿が建立された（現・結城市指定有形文化財）。
- **近代以降**：社格は旧郷社とされるが、本照合では公的資料で確認できなかった（未検証）。現在は健田須賀神社の兼務社で、御朱印は健田須賀神社で授与される。

## 5. 『古語拾遺』との文献整合性

斎部広成『古語拾遺』（大同2年、807年）は、阿波忌部の東遷について次のように記す（原文、Vault保存の転写で照合）：

> 天富命更求沃壤。分阿波齋部率往東上。播殖麻穀。好麻所生。故謂之總國。**穀木所生。故謂之結城郡。**

読み下し：天富命、更に沃壌を求め、阿波の斎部を分かちて率い往きて東に上り、麻・穀を播き殖やす。好き麻の生ずる所なり、故に之を総の国と謂う。穀木の生ずる所なり、故に之を結城郡と謂う。

→ 『古語拾遺』は、阿波斎部を分けて東上させた文脈で **「結城郡」の名を明記** する。古代の結城郡は下総国の一郡（現在の結城市域を含む）であり、大桑神社の鎮座地はその結城郡小森村にあたる。

→ ただし注意すべき点が二つある。第一に、『古語拾遺』が記すのは麻と穀（楮＝コウゾ、布・紙の原料）の播殖であり、**養蚕そのものには触れていない**。養蚕伝来の物語は大桑神社の社伝・由来書の層である。第二に、『古語拾遺』は「結城郡」とのみ記し国名を伴わないため、下総国結城郡への同定は郡名の一致に基づく（同名の郡は他に知られず、通説的にもこの同定が採られる）。

### 養蚕・織物の阿波忌部ネットワーク（阿波説の整理）

阿波説では、阿波忌部が伝えた製織・養蚕技術は東国各地に拠点を残したと整理される：

| 拠点 | 内容 |
|---|---|
| **阿波・麻殖郡（吉野川市）** | 麻と織物の本拠（地名「麻殖」は麻栽培の意） |
| **結城（茨城県結城市）** | 大桑神社・小森（蚕守）／結城紬の産地 |
| **常陸 久慈郡** | [[静神社]]（延喜式・久慈郡の名神大社）、倭文（しどり）の祖神祭祀 |
| **常陸 那珂郡** | 長幡部一族の繁栄 |
| **武蔵 賀美郡（埼玉北部）** | 長幡部神社 |

→ 阿波説では、この技術伝播は **安房上陸 → 結城（養蚕） → 久慈・那珂（倭文） → 賀美（長幡部）** と段階的に北上・内陸へ展開したと読まれる。なお結城紬の起源については、通説的伝承では崇神天皇の時代に長幡部連の祖・多弖命（多屋命）が美濃から常陸国久慈郡に移って始めた「長幡部絁」に求められており（結城市公式・Wikipedia「結城紬」）、阿波忌部起源説とは別系統の伝承である。

## 6. 阿波説における意義

### 阿波接続の三大論点

| # | 論点 | 根拠 |
|---|---|---|
| **1** | 社伝・市の公式説明が阿波斎部の創建を明記 | 結城市公式資料（結城七社）、大桑神社由来書 |
| **2** | 地名「結城」が『古語拾遺』に登場 | 「穀木の生ずる所を結城郡と謂う」 |
| **3** | 地名「小森」＝「蚕守（こもり）」説 | 阿波斎部の伝えた蚕種を守ったことから（ただし「篭」説と併記される） |

| 観点 | 内容 |
|---|---|
| **史料整合性** | 『古語拾遺』の「結城郡」記事と社伝の舞台が地名の上で重なる。ただし古語拾遺は麻・穀の播殖を記すのみで養蚕には触れない |
| **産業証拠** | 結城は古来養蚕の盛んな土地で、生産集落の一つ・小森は「蚕守」と表記された時代もある（Wikipedia「結城紬」）。結城紬は1956年に国の重要無形文化財、2010年にユネスコ無形文化遺産に登録された |
| **地名証拠** | 結城（ユフキ）、小森（蚕守説あり）、大桑郷の地名痕跡 |
| **祭神証拠** | 稚産霊尊（養蚕・農業の神）の阿波斎部による奉斎という社伝 |

### 6-1. 文献・地名・社伝の重なり

『古語拾遺』の記述、地名「結城」、社伝の創建譚が重なる点が、大桑神社を阿波忌部東遷論の拠点の一つたらしめている。ただし旧稿の「文献史料・地名・社伝・産業が四重に揃う最も強固な物的拠点」という評価は、養蚕と古語拾遺の記事（麻・穀）とのずれを捨象した過大な表現であり、本照合で上記の範囲に限定した。

### 6-2. 養蚕起源説としての特異性

由来書が主張する「日本の養蚕の起源は阿波忌部の結城下向にある」という言説は、他地域の阿波忌部伝承と比べても踏み込んだ主張である。一方、養蚕の伝来に関する主流の理解では、養蚕は弥生時代に大陸から伝わり奈良時代には全国に広がったとされる（Wikipedia「養蚕業」）。またWikipedia「蚕影神社」は、当社について「東国に養蚕を伝来した阿波斎部（忌部）氏による創祀と伝えられる。小森は蚕守の変化ともいう」と紹介しており、社伝の存在自体は公的・準公的資料にも記録されている。

### 6-3. 阿波忌部ネットワークの北上経路における位置づけ

大桑神社は、安房上陸後に阿波忌部の織物・養蚕技術が久慈・那珂・賀美へと内陸展開していく経路上の中間拠点として、阿波説の整理の中で位置づけられる。
