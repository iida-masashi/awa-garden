# 事任八幡宮（ことのままはちまんぐう）

> [!summary] 要旨
> 遠江国一宮・式内小社の古社。主祭神は言霊を司る女神 **己等乃麻知比売命**（ことのまちひめのみこと）で、『延喜式神名帳』の「己等乃麻知神社」に比定される。社伝（公式サイト）では「忌部の神である玉主命の娘」と明記され、中臣氏の祖・天児屋命の母ともされる、忌部系譜と中臣系譜の結節点に位置する神である。阿波説では、近隣の粟ヶ岳山頂に鎮座する[[阿波々神社]]（祭神・阿波比売命）との「山と麓」の対構造、夫神ココトムスビをめぐる同一神説などを核心論点とする。本ノートは、八幡勧請元・例祭日・主祭神復帰の時期など旧版の事実誤りをエビデンスに基づき修正した改訂版である。

## 3. 祭神と社伝

### 主祭神：己等乃麻知比売命

公式サイト「御祭神」は、主祭神を次のように説明する。

- **忌部の神である玉主命（たまぬしのみこと）の娘**
- **中臣の祖である興台産命（こことむすびのみこと）の后**
- **天児屋命（天児屋根命）の母**（枚岡神社・春日大社に祀られる中臣氏の祖）

「こと」は「事」でもあり「言」でもあり、「まち」は「麻知」でも「真知」でもある。真を知る神、言の葉で事を取り結ぶ神として、また言の葉を通して世の人々に加護を賜う「**ことよさし**」の神として敬われる。「願いが言のままに叶う」という信仰はこの社名・神名に由来する。

なお、興台産霊神（公式表記は興台産命）は**当社の祭神ではない**（公式サイトによれば四国の天川神社に祀られる）。旧版ノートが「相殿」として記載していたのは誤りであり、興台産霊神は系譜上の夫神であるにとどまる。当社に祀られるのは主祭神と八幡大神3柱である。

### 配神：八幡大神

康平5年（1062年）、源頼義が**石清水八幡宮**から八幡神を勧請した（旧版の「宇佐八幡宮から勧請」は誤り）。以来、誉田別命・息長帯比売命・玉依比売命の3柱は「八幡大神」と総称される。玉依比売命は公式サイトでは神武天皇の母、大綿津見神の娘で豊玉姫命の妹と説明される。

### 『枕草子』の記載と解釈

『枕草子』には神々を列挙する段に「**ことのままの明神、いとたのもし。さのみ聞きけんとや言われたまはんと思ふぞ、いとをかしき**」とある。平安時代に「ことのままの神」の名が都にまで伝わっていたことは確かである。ただし、この一節を霊験への称賛と読む通俗的解釈に対して、「言われていると思う」ことを強調した皮肉であるとする異説も存在する（Wikipedia「事任八幡宮」の解釈批判の項）。本ノートでは両説を併記するに留める。

> [!note] 循環参照への注意
> 「玉主命の娘」という系譜は公式社伝に明記されるが、これは社伝そのものが忌部系譜を伝えるものであり、阿波忌部の東遷を裏付ける独立した史料ではない。本ノートで社伝を引く際は「社伝の主張」として扱い、記紀等の一次史料による裏付けとは区別する。

## 4. 歴史

| 時代 | 出来事 |
|---|---|
| 創建 | 時期不詳。社伝では成務天皇の頃。当初は本宮山に鎮座 |
| 大同2年（807年） | 坂上田村麻呂が桓武天皇の勅命を奉じ、本宮山から現在地（里宮）へ遷座したと伝わる。本宮山の本宮には現在も小祠が残る |
| 平安（927年頃） | 『延喜式神名帳』に遠江国佐野郡「己等乃麻知神社」（小社）と記載 |
| 康平5年（1062年） | 源頼義が石清水八幡宮から八幡神を勧請。「八幡宮」を称するようになる |
| 戦国期 | 社家が比売神の分霊を各地に祀ったと伝わる（公式由緒） |
| 江戸 | 徳川家康が本殿を造営（棟札あり）、朱印百石余を寄進。秀忠が中門を造営。通称は「誉田八幡宮」 |
| 明治5年（1872年） | 県社に列格し「県社八幡神社」と称する |
| 昭和22年（1947年） | 社格制度撤廃に伴い古来の社号に基づき「事任八幡宮」に改称。この時点で御祭神として認められていたのは八幡大神のみ |
| 平成11年（1999年） | 「ことのままおこし」により本宮から己等乃麻知比売命を里宮に再迎し、主祭神として県知事の認証を受ける |

主祭神の「復帰」は明治ではなく平成11年のことであり、旧版ノートの「明治に主祭神復帰」は誤りであった（公式由緒による）。

## 5. 言霊信仰と本宮・里宮の二重構造

事任八幡宮の信仰の中核は「ことのまま＝言のままに願いが叶う」という言霊信仰であり、『枕草子』のほか『吾妻鏡』『東海道中膝栗毛』にも「願い事が叶う神社」として登場する（Wikipedia）。東海道の難所・小夜の中山の西の入口に位置し、旅の安全と願望成就を祈る人々で栄え、国道1号日坂バイパスの「ことのままトンネル」の命名由来ともなった。

鎮座地は二重構造をなす。里宮（現社殿）の北側の**本宮山**には元の鎮座地である**本宮**があり、現在も小さな祠で祀られ、毎月8日・18日・28日に本宮月次祭が執り行われる（公式サイト祭事暦）。平成の「ことのままおこし」まで己等乃麻知比売命はこの本宮にあり、里宮では八幡大神が主として祀られていた。

なお、Wikipedia「事任八幡宮」概要は、当社と諏訪大社下社春宮・戸隠山がほぼ南北一直線上にあることを指摘している。レイライン的な読みは阿波説でも用いられるが、本ノートではWikipedia記載の地理的指摘として紹介するに留める。

境内社として五社神社・稲荷神社・金比羅神社があり（Wikipedia）、大楠は掛川市指定天然記念物である（Wikipedia写真説明）。

## 6. 阿波説における意義

### 6-1. 玉主命の娘の祭祀

己等乃麻知比売命を「玉主命の娘」と明記する社伝は、通説的な中臣氏系譜（天児屋命の母）とは別の、忌部固有の系譜認識を示すものとして阿波説では重視される。父神・玉主命は阿波忌部の祖神であり、天日鷲命と並ぶ忌部の主要神とされる。すなわち事任八幡宮は、遠江における阿波忌部祭祀の中心と位置づけられる。
→ [[祭神の系譜：父・玉主命と対の女神]]

### 6-2. 阿波々神社との「山と麓」の対構造

近隣の粟ヶ岳山頂に鎮座する[[阿波々神社]]（祭神：阿波比売命＝天津羽羽命）とは、玉主命の二人の娘による姉妹神の対祭祀を構成すると阿波説では解釈される。

| 配置 | 神社 | 祭神 | 神格（阿波説） |
|---|---|---|---|
| 山頂 | [[阿波々神社]] | 阿波比売命（天津羽羽命） | 祖神／和魂・幸魂 |
| 麓 | 事任八幡宮 | 己等乃麻知比売命 | 巫女・神託／荒魂 |

これは阿波忌部が東遷先で構築した祭祀システムであり、阿波国における[[上一宮大粟神社]]と周辺社群の関係を遠江に再現したものと考えられる。
→ [[祭神・阿波比売命と事任八幡宮との対構造]]

### 6-3. 阿波の建嶋女祖命との対応

阿波国勝浦郡の建嶋女祖命神社（式内社）の祭神は、阿波忌部系の女祖神とされる。「事任（ことのまま）」の神格＝言霊・祭祀の巫女の元宮として、建嶋女祖命との系譜的連続性が阿波説では指摘される（未検証：第12節参照）。

### 6-4. 夫神ココトムスビ＝饒速日命説の含意

夫神・興台産霊神（ココトムスビ）は通説では中臣氏の祖だが、阿波説・古史古伝の文脈では物部氏の祖・饒速日命（ニギハヤヒ）と同一神ともされる。これが正しければ、事任八幡宮は中臣（祭祀）と物部（呪術・軍事）の交差点となり、阿波忌部から両氏族が分派した可能性を示唆する拠点となる。ただしこの説は『ホツマツタヱ』等に依拠するもので、史料的裏付けは乏しい。
→ [[夫神・ココトムスビと饒速日（ニギハヤヒ）同一神説]]

### 6-5. 東海道上の祭祀拠点

東海道は古代の伊勢→東国を結ぶ回廊であり、その中で事任八幡宮は言霊を司る神託所として機能した。阿波忌部の東遷ルートが後の東海道に重なることを考えれば、事任八幡宮は阿波忌部の祭祀的ハブとして東遷後も中央との接続を維持していたと考えられる。
