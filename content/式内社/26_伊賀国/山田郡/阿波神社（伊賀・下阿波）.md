# 阿波神社（伊賀・下阿波）（あわじんじゃ）

> [!summary] 要旨
> 伊賀国**山田郡**（現・三重県伊賀市下阿波）に鎮座する**式内小社**。『延喜式』神名帳に「山田郡三座（並小）」の一つとして登載されることを、Wikisource『延喜式』巻第九の原文で直接確認した。社名「阿波（あは）」は鎮座地「下阿波」の地名に対応する。『日本三代実録』に「伊賀国 阿波神」への神階授与（貞観三年〔861〕・同十五年〔873〕）が見える国史見在の古社で、近代社格は旧郷社。現在の祭神は稚日女尊・猿田毘古神・火産霊命とされるが、『神社覈録』は神功皇后とするなど史料間で異同があり、本来の祭神は確定しない。**社名「阿波」が伊賀の地名「下阿波」と阿波国の国名とで音の上で一致する点**が阿波説の関心事だが、本ノートはこれを**地名相同の指摘（偶合の指摘）にとどめ、両地の因果は主張しない**。

## 3. 祭神と社伝

現在の祭神は**稚日女尊・猿田毘古神・火産霊命**の3柱とされる（現地系データベース genbu.net「阿波神社 (伊賀市)」による。旧ノートは火産霊命を合祀側に置いていたが、同資料では御祭神の筆に列する）。これに上記の合祀諸神が配される。

一方、近世以降の地誌類では祭神が大きく分かれる。

| 資料 | 祭神 |
|---|---|
| 現行（社伝・現地案内） | 稚日女尊・猿田毘古神・火産霊命 |
| 『神社覈録』（1870） | 神功皇后 |
| 『伊水温故』 | 猿田彦命・神功皇后 |
| 『三国地誌』 | 神功皇后 |
| 『三重県神社誌』 | 息長田別命 |
| 『神名帳考證』（出口延経） | 天日方奇日方命 |

この異同のため、**本来の祭神は確定できない**。いずれの祭神からも阿波国との接続は導けない（神功皇后説は『日本書紀』の「淡郡の神」の比定に、息長田別命説は阿波君の祖神伝承に、それぞれ依拠するもので、独立した裏付けは確認していない）。

### 「淡郡の神」比定説について

『日本書紀』神功皇后の条には、仲哀天皇の斎宮を小山田邑に造り、神託で神々の名を聞き出した際、「尾田の吾田節の**淡郡（あわのこおり）**にいる神である」と答えられた、という記事がある。この「小山田邑」を当地とし、淡郡の神を当社の祭神とする説がある（現地系資料が紹介する説）。ただし「淡郡」の比定自体が諸説あり（志摩国伊射波神社の祭神・稚日女尊に結ぶ理解もある）、この説は書紀本文の地名比定に依存するものであって、当社の由緒を独立に裏づけるものではない。循環参照を避けるため、本ノートではこの説を「説の一つ」としてのみ記録する。

## 4. 歴史

- **貞観三年（861）四月十日甲寅**、『日本三代実録』に伊賀国 正六位上 **阿波神** に従五位下を授ける記事があるとされる。
- **貞観十五年（873）九月己丑**、同書に阿波神を従五位上に進める記事があるとされる。以上により当社は国史見在社とされる（原文の直接照合は未了。留保参照）。
- 『神祇志料』（1876）は「昔 粟郷 河南里に在りしを、今 下阿波村に移祭る」と、遷座の伝を記す。
- 中世、郷士・阿波越後が杉尾白鬚神を合祀したため、椙生社・白鬚惣社・杉尾大明神などとも呼ばれたという（現地系資料）。旧ノートは中古の称号を「阿波大明神・杉尾白髭大明神」とする。
- 近代社格では**旧郷社**に列した（現地系資料）。

## 5. 「阿波」という地名・社名の重なり（核心テーマ）

当社の社名「阿波」は、鎮座地の地名「下阿波」に由来する在地の社名であり、その点は通説どおりである。ここでは「阿波」の名が重なる諸事例を、因果を主張せず事実の範囲で並べる。

- **伊賀市内の「阿波」地名**：当社の鎮座する「下阿波」と、隣接する「上阿波」（式内社・葦神社の鎮座地）がある。いずれも伊賀国山田郡の在地地名である。
- **阿波君（あわのきみ）**：伊賀の阿波を阿波君の本貫とし、その氏人が祖神・息長田別命を祀ったとする説がある（現地系資料、『三重県神社誌』の息長田別命説と結ぶ）。「阿波君」は伊賀在地の氏族名として現れるもので、これと阿波国との関係を示す史料は本ノートでは確認していない。
- **類社**：『神社覈録』は「類社」に大和国添上郡の**率川阿波神社**を挙げる。「阿波神社」を名のる式内社は、伊豆国賀茂郡（現・神津島の阿波命神社、名神大社）など全国に分布し、社名の一致だけから相互の関係は導けない。

## 6. 阿波説における意義

### 6-1. 地名ペアの一事例としての位置づけ

阿波説は、伊賀「下阿波」と阿波国の地名の音の一致を**地名対応（地名ペア）の一事例**として記録しうるとみる。同じ論点は同国の[[敢国神社]]ノート（伊賀市「下阿波」の地名対応）でも触れられている。ただしこれは相同の指摘にとどまり、伊賀と阿波国を直接結ぶ物的・文献的証拠を提示するものではない。

### 6-2. 主張しないこと

- 社名・地名の一致から、阿波国からの勧請・移住・祭祀伝播などの因果は主張しない。
- 祭神（稚日女尊・神功皇后・息長田別命のいずれの説からも）阿波接続は主張しない。
- 阿波君と阿波国の関係は未検証であり、接続は主張しない。
