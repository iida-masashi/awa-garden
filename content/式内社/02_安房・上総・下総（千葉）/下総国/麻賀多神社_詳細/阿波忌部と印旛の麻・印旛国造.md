# 阿波忌部と印旛の麻・印旛国造

> [!summary] 要旨
> **印旛沼** は古代下総国の祭祀的中核であり、その沿岸に **「麻賀多十八社」** が分布する。総本社の麻賀多神社（成田市台方）と奥宮（成田市船形）を頂点に、印旛地域は **「麻」を冠する社名・地名の集中分布地** である。阿波説では、安房上陸後に北上した **阿波忌部** が印旛沼沿岸で麻栽培地を開拓し、**印旛国造・伊都許利命** が祭祀統治の中心を形成したと読む。本ノートは印旛地域の祭祀景観・地名・国造系譜・伝承を総合し、阿波忌部東遷の中継拠点としての印旛を描く。

---

## 1. 印旛沼と古代「印旛郡」

### 印旛の地理・地名

『和名抄』下総国印旛郡（または「印幡」「印波」）には**11郷**があった：

| # | 郷名 | 比定地 | 地名解釈 |
|---|---|---|---|
| 1 | 余戸郷（あまるべ） | 佐倉市天辺 | 律令余部制（10戸以上の超過地） |
| 2 | **印幡郷（いんば）** | 佐倉市飯野・飯田・大佐倉〜酒々井町本佐倉 | **印波国造の居所**、後に郡家設置 |
| 3 | 鳴矢郷（かぶら） | 佐倉市鏑木 | 傾斜地 |
| 4 | 言美郷（とみ） | 印西市平岡・小林 | 崖・崩れ地 |
| 5 | 長隈郷（ながくま） | 佐倉市長熊 | 印旛沼の屈曲、水曲の意 |
| 6 | 船穂郷（ふなほ） | 印西市船尾・結縁寺 | 山が船型に張り出した地 |
| 7 | 三宅郷（みやけ） | 印西市小倉・浦部 | **印波国造の官倉** |
| 8 | 村神郷（むらかみ） | 八千代市村上 | 神を祀った地の意 |
| 9 | 八代郷（やつしろ） | 成田市八代・船形 | **ヤツシロ＝湿地の場所**／**ヤシロ（社）＝神社所在地** |
| 10 | 吉高郷（よしたか） | 印西市吉高 | 印旛沼に臨む微高地 |
| 11 | 曰理郷（わたり） | 佐倉市臼井 | 印旛湖の渡津 |

→ **印旛**の語源は「いなば」の転訛で「**いな（砂）・ば（処）＝砂のある所**」。または「**イナバ＝稲庭＝穀倉地帯**」。

→ **印旛沼を中心とした水運・農業・祭祀の一大ネットワーク** が古代から成立しており、麻賀多神社の奥宮所在地「**八代（やつしろ）**」が「**社（ヤシロ）所在地**」を意味する可能性が高い。

### 印旛沼の祭祀景観

印旛沼は古代において現在より遥かに広く、東は香取海に通じ、海面上昇期には半島地形が島状になっていた地域。沿岸に多数の **古墳群** と **麻賀多十八社** が分布する：

| 古墳群 | 所在 | 関連 |
|---|---|---|
| **公津原古墳群**（39号墳） | 成田市船形 | **伊都許利命墳墓**、麻賀多神社奥宮に隣接 |
| 鬼塚古墳・岩名貝塚・三ヶ月山貝塚 | 佐倉市飯野 | 印幡郷比定地 |
| 八代台第1〜25号古墳・瓢塚第1〜37号古墳・天王塚船塚第1〜30号古墳 | 成田市八代・船形 | 八代郷比定地、麻賀多神社近傍の巨大古墳群 |
| 一本松貝塚・泉台古墳群・若作古墳群・十三仏古墳群・第六天古墳群 | 印西市吉高 | 吉高郷比定地 |

→ **古墳・式内社・祭祀地名の三層が一体化した稀少な景観**。

## 2. 印旛国造・伊都許利命（いつこりのみこと）

### 系譜と任命

| 項目 | 内容 |
|---|---|
| **任命** | 応神天皇の時代に **印旛国造（印波国造）** に任じられる |
| **系譜** | **神八井耳命**（神武天皇皇子）の後裔（皇別氏族） |
| **典拠** | 『先代旧事本紀』「国造本紀」 |
| **墳墓** | 公津原古墳群39号墳（成田市船形、麻賀多神社奥宮隣接） |
| **古墳形式** | 7世紀後半の方墳 |

→ **式内社の祭神に位置付けられる人物の墳墓が現存・同定可能** な極めて稀有な例。

### 公津上陸伝承と平賀の地

印旛村の **平賀**（現印西市平賀）の地名由来として、口碑に次の伝承がある：

> **印旛国造・伊都許利命が公津（こうづ）から上陸し、当地を開拓した**

→ 公津＝「神津（こうづ）」で、**式内社麻賀多神社のための港・神津が印旛沼にあった** ことに由来する地名。後に成田市公津村として明治期まで残った。

→ つまり伊都許利命は **海路（または印旛沼の水運）で公津に上陸し、平賀方面に進出して開拓を行った** という伝承構造。これは阿波忌部の **水運による段階的北上展開** と整合する。

### 麻賀多神社奥宮の独自由緒

ブログ「**かもめ**」（2026-03-18-「稚日霊女命」と「和久産巣日神」：「麻賀多神社」を訪ねた）の考察によれば、奥宮には次の独自由緒がある：

- **稚日霊女命（わかひるめのみこと）** ＝鏡を御神体
- **和久産巣日神（わくむすひのかみ）** ＝杉の木の下から掘り出した玉を御神体
- 両神を併せ祀って「**真賀多真（まかたま）の大神**」と称した
- 「**真賀多真＝勾玉**」の意で、社名「麻賀多」の語源とする説

→ **「マカタ」の語源候補**：
| 説 | 内容 |
|---|---|
| 真潟（まかた） | 印旛沼に面する地形 |
| 麻形・麻象（まかた） | 麻の祭祀形象 |
| 目方（めかた）→マカタ | 伊都許利命が八掬の勾玉を「目方」の井戸に埋めた伝承 |
| **真賀多真（まかたま）** | **勾玉**を御神体とする祭祀 |

## 3. 阿波忌部と「麻」の伝統

### 社名「麻賀多」と祭神の対応

| 要素 | 内容 |
|---|---|
| **社名** | 「麻」の文字を冠する稀な式内社 |
| **本宮主祭神** | **稚産霊神**（わくむすびのかみ） |
| **奥宮主祭神** | **和久産巣日神**（同神、表記異） |
| **神格** | 火神カグツチ／伊弉冉尊の死後の化生神。**蚕・桑・五穀・木綿（ゆふ）の祖神** |

→ 稚産霊神／和久産巣日神は **麻・穀・蚕・木綿の生成神**。阿波忌部祖神 **天日鷲命**（麻・穀の祖、[[天日鷲命：天岩戸の功績と「鷲」の由来]]）と **職能領域が完全に重なる**。

### 阿波忌部の麻栽培と印旛

『古語拾遺』に明記される阿波忌部の事跡：

> 天富命をして、天日鷲命の孫を率いて阿波国に麻・穀を植えしむ。其の能き地を求めて東国に分かち遣はす。**好麻の生ふる所、故、総国と謂ふ。穀木の生ふる所、故、結城郡と謂ふ**。

→ 房総半島南部（安房）から **北上して印旛沼沿岸に麻栽培地を拡大**した阿波忌部の足跡。**「麻賀多十八社」** の分布は印旛地域全体への麻祭祀の浸透を示す。

### 麻賀多十八社の分布

成田市を中心に印旛郡内に **18社** の麻賀多神社が存在し、本宗（総本社）が麻賀多神社（成田市台方）：

| カテゴリ | 数 | 性格 |
|---|---|---|
| 本宗（総本社） | 1 | 成田市台方の麻賀多神社 |
| 奥宮 | 1 | 成田市船形（伊都許利命墳墓隣接） |
| 印旛郡内分社 | 16 | 印旛沼沿岸の各地 |

→ **同一社名の式内社が広域に18社分布する例は全国でも極めて稀少**。阿波忌部の麻栽培ネットワークが祭祀ネットワークと一体化した痕跡。

## 4. 印旛地域の独自伝承

### 松虫姫伝説（印旛村松虫）

印旛村松虫（現印西市松虫）の地名由来：

> **聖武天皇の皇女・松虫姫** が当地に療養に来たという伝説

→ 関連地名：**舞姫（まいひめ、印西市）**、これも松虫姫伝説にちなむか。

阿波説における意義：
- 皇女が療養地として選ぶ程の **古代祭祀地としての権威** が印旛にあった
- 阿波の **八倉比賣神社の天照大神葬儀地伝承** と同様、**皇族との祭祀的接続** を示す痕跡

### 龍腹寺・龍角寺・龍尾寺の三身分断伝説

印旛地域に **「龍の三身分断伝説」** がある：

| 寺 | 所在 | 落ちた部位 |
|---|---|---|
| **龍角寺**（りゅうかくじ） | 印旛郡栄町 | **頭** |
| **龍腹寺**（りゅうふくじ） | 印西市本埜（旧本埜村） | **腹** |
| **龍尾寺**（りゅうおじ） | 匝瑳市 | **尾** |

→ 寺伝によれば、天平年間（729〜749）に **雨乞いをした際に現れた龍が大空で死に**、その三身が三地点に落ちたとされる。

→ 雨乞い儀礼は **古代祭祀の中心要素**。印旛・匝瑳地域が広域水神祭祀圏として機能していた可能性。

### 蘇我入鹿伝説（印西市鹿黒）

印西市 **鹿黒（かぐろ）** の地名由来：

> 蘇我入鹿が殺された時、その縁者が **入鹿の首を携えて当地に到着し、首を葬り居住** したことによる伝説

→ **阿波蘇我氏の東遷** と整合する伝承（[[阿波蘇我氏：石井町・曽我氏神社を源流とする中央進出の軌跡]]、[房総の聖徳太子と蘇我氏の残香 未知の駅 總フサ](https://ameblo.jp/books-fu-sa/entry-12633794586.html) 参照）。印旛地域は阿波蘇我氏の東国展開拠点でもあった可能性。

### 摩伽陀国伝説（袖ケ浦市神納）

上総国だが印旛圏に近い袖ケ浦市神納に **「摩伽陀国（マガダ国）から逃れてきた皇后」** 伝説（率土神社）。

→ 「**マガダ**」と「**マカタ**」の音韻的近似が指摘される（[摩伽陀国から逃れてきた皇后 率土神社 袖ケ浦市神納 未知の駅 總フサ](https://ameblo.jp/books-fu-sa/entry-12635989406.html) 参照）。インド・ベンガル系の伝承と日本古代史の交差点として注目される（阿波説外論点だが、印旛地域の祭祀重層性を示す）。

## 5. 日月神示の降臨地：天之日津久神社

境内（本宮）の摂社 **天之日津久神社（あめのひつくじんじゃ）** は、**1944年に岡本天明が「日月神示」を自動書記し始めた聖地**。現代の神学・予言研究において極めて重要。

→ 詳細：[[日月神示の降臨地：天之日津久神社]]

阿波説における位置づけ：
- 印旛・成田の祭祀地が **昭和期にもスピリチュアルな霊的磁場として機能** していた継続性の象徴
- 麻賀多神社の **古代から現代に至る霊脈の連続** を示す現象

## 6. 阿波説における意義

### 6-1. 阿波忌部東遷の中継拠点

| 段階 | 場所 | 性格 |
|---|---|---|
| ① 阿波本貫 | 麻殖郡（吉野川市） | 阿波忌部の本拠 |
| ② 海路移動 | 黒潮ルート | 鳴門→紀伊水道→太平洋 |
| ③ 安房上陸 | 千葉県館山市 | [[安房神社]] 創建 |
| ④ 北上展開 | 房総半島内陸 | 上総→下総への麻栽培伝播 |
| ⑤ **印旛展開** | **印旛沼沿岸** | **麻賀多十八社の祭祀ネットワーク確立** |
| ⑥ 利根川流域 | 結城郡（茨城南西部）・常陸 | 穀木（かじ）栽培、[[大杉神社]] 連携 |

→ 印旛は阿波忌部東遷の **房総中継拠点** として極めて重要。

### 6-2. 皇別氏族と忌部の祭祀重層

- 印旛国造・伊都許利命は **神八井耳命系の皇別氏族**
- 阿波忌部は **天太玉命系の神別氏族**
- 両者が **印旛沼祭祀において重層** している → 公的国家祭祀（皇別系）と産業祭祀（忌部系）の **二重構造**

→ これは安房神社（中央国家祭祀） + 阿波忌部本部隊（産業基盤） の二重構造と相似形。

### 6-3. 古墳・式内社・地名の三点セット

印旛地域は阿波説の **「地名と氏族の東遷法則」（四大柱の④）** において、以下の物証性が揃う：

| 物証 | 内容 |
|---|---|
| **古墳** | 公津原古墳群（伊都許利命墳墓）、八代台古墳群、瓢塚古墳群 |
| **式内社** | 麻賀多神社（本宗・奥宮） |
| **地名** | 公津（神津）、八代（社所在地）、印旛（稲庭・穀倉地）、平賀（伊都許利命開拓地） |
| **伝承** | 公津上陸、勾玉祭祀、麻栽培 |

→ 四層が **一体的に祭祀景観を形成** している例は全国でも稀少。

## 9. 留保（中立的併記）

> [!warning] 注意
