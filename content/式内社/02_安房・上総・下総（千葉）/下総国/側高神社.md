# 側高神社（そばたかじんじゃ）

> [!summary] 要旨
> **側高神社（千葉県香取市大倉）** は **香取神宮の第一摂社** にして「**言わず語らずの神**」を祀る謎の古社。社伝に **「神武天皇18年創建」** と伝わり、御祭神は **「古来神秘として口にすることを許されず」** とされる。香取神宮の中でも **別格扱い** で、起請の質神とされた。下総国〜旧武射郡域に **10社のソバタカ系神社**（漢字表記は様々）が分布し、その中核に天日鷲命（阿波忌部祖神）・高皇産霊神・満珠干珠伝説・忌部の甕祭祀が交差する。本ノートは阿波忌部の関東祭祀軸における **香取神宮以前の古層** を代表する社として、側高神社の重層構造を総合する。

## 3. 「言わず語らずの神」の謎

### 3-1. 御祭神不明の社伝

側高神社の御祭神について、書物には次のように記される：

> **古来神秘として口にすることを許されず、俗に「言わず語らずの神」とのみ伝う**

香取神宮の古い差定（書記録）には：

> **起請（誓い）することあれば、必ず此の神に質す**

→ 香取神宮の中で **別格扱い**、起請の質神（誓約の最高神）。これは通常、その地の **地主神** または **元宮の祭神** に対する待遇である。

### 3-2. 阿波説的解釈：女神隠匿

ブログ「總フサ」の指摘：

- 本殿の装飾が **極めて女性的**、**フルール・ド・リス**（百合紋）の彫刻
- **女性的な繊細な装飾**
- 神紋は **菊と五七桐**（皇室紋・豊臣紋）
- **千葉県内の他の一宮はすべて女神**：
  - 上総一宮 [[玉前神社]] → 神玉依姫命
  - 安房一宮 [[安房神社]] → 本殿が女千木（祭神は天比理刀咩命＝天太玉命妃）

→ 阿波説的読み：**側高神＝香取神宮にもともと祀られていた女神**（後に「[[香取神宮]] 奥宮」に追いやられた可能性）。現在の香取神宮奥宮も **女千木**。

→ 関連：2026-03-19-⑯『この国は、誰の神話か』　阿波から読み直す日本創世 系の議論で、**「朝廷にとって都合の悪い女神」** であったため「言わず語らず」を強制されたと読む。

### 3-3. 撞賢木厳之御魂天疎向津媛命説

ブログ筆者の最重要仮説：

> **側高神＝撞賢木厳之御魂天疎向津媛命**（つきさかきいつのみたまあまさかるむかつひめのみこと）

根拠：
- 関門海峡の **和布刈神社の御祭神** が撞賢木厳之御魂天疎向津媛命で、満珠干珠を司る
- **高良玉垂命＝安曇磯良＝武甕槌**の同一視説と、これに対応する **女神** としての撞賢木厳之御魂天疎向津媛命
- 古代香取海への入り口である **海峡の両岸** に、潮の満ち引きを司る神々が鎮座していた形になる

→ 鹿島の武甕槌（男神・安曇磯良系） + 側高（女神・撞賢木厳之御魂） で、**香取海の海峡守護の男女ペア祭祀** を構成していた可能性。

## 4. 満珠干珠伝説：陸奥の馬2000疋

### 4-1. 『千葉県香取郡誌』所載の伝承

側高神社に伝わる最重要伝承：

> 伝へ曰う、側高神、香取大神の命を奉じ陸奥に至り、荒野を廻り **牝牡馬2000疋** を捉へ得て帰り、常陸国霞ヶ浦浮島に達す。
>
> 彼国の神これを惜み追跡し至る。側高神急に水を済り本郡の地に達す。其の地を **馬渡** と称す。
>
> 敵神また済らむとす。**側高神満珠を示すに潮水忽ち満ち渡るを得ず**。其の地を **玉落** と称す。
>
> 尋て川を済り岩ヶ崎に達し、其の地を **乗越洲** と云う。馬を香取の境なる牧野の牧に繋き、遂にこれを本州の諸野に放つ。
>
> 故に牧場の本州に多きは此時に基つく。敵神遂に国に還るを得ずして此地に止まる。

→ 側高神が **満珠（潮を満たす珠）** を用いて敵神を退け、馬2000疋を確保した話。

### 4-2. 関連地名（伝承の物的痕跡）

| 地名 | 由来 |
|---|---|
| **馬渡（うまわたり）** | 側高神が水を渡って馬を運んだ地 |
| **玉落（たまおち）** | 側高神が満珠を示した地 |
| **乗越洲（のっこすす、現・新川）** | 馬と神が乗り越えた洲 |
| **牧野（まきの）** | 陸奥から強奪した馬2000疋を放った名牧 |
| **釜塚（かまづか）** | 馬糧の粥を煮た釜を埋めた塚 |
| **隠井（かくれい）** | 関連地名 |
| **笠塚（かさづか）** | 後述の「白状祭」で笠を掛けた塚 |

→ **地名と祭祀伝承が一体化** した稀少な物証性。

### 4-3. 追手明神（追島明神）：敵神の祭祀

側高神社と相対する位置に **追手明神（おうてみょうじん、現・追島明神）** が祀られる。これは **側高神に追跡してきた敵神（彼国＝常陸国の神）** を祀ったもの。

→ 敗者を祀る稀有な祭祀構造。**伝承の対立構造を地理的に固定化**。

### 4-4. 忍男神社の「白状祭」

香取神宮摂社の **忍男神社（おしおじんじゃ、香取市津宮字東宮560）** で、かつて執り行われていた神事：

| 項目 | 内容 |

| **由来** | **馬盗みの経緯を白状に記す** ことから命名 |

→ 側高神の代わりに **馬盗みの罪を詫びる神事**。伝承の儀礼化として現存。

## 7. 「四箇の甕」と忌部祭祀

### 7-1. 側高神社境内の四箇の甕

側高神社境内には **「四箇の甕（よんかのかめ）」** という極めて特殊な祭祀物がある：

| 名称 | 内容 |
|---|---|
| **春の甕** | 春の降水量を示す |
| **夏の甕** | 夏の降水量を示す |
| **秋の甕** | 秋の降水量を示す |
| **冬の甕** | 冬の降水量を示す |

> 自然に溜った雨水の量を以て **占の基礎** としたものであろう。神験によって、その年の豊凶や、生活の吉凶を知ろうとした古人の純朴な信仰が偲ばれる。

→ **古代の水占（みなうら）** の物証。雨水占いという形式は **農耕民族の祭祀** の原型。

### 7-2. 利根川を挟む3社の甕祭祀

「**甕（カメ）**」を持つ3社：

| 神社 | 所在 | 甕の名称 |
|---|---|---|
| **側高神社** | 千葉県香取市大倉 | 四箇の甕（四季の甕） |
| **息栖神社** | 茨城県神栖市息栖 | **忍潮井（男瓶・女瓶）** |
| **鹿島神宮** | 茨城県鹿嶋市 | 鹿島の先の海に甕が埋められているという伝承 |

→ **東国三社（鹿島・香取・息栖）と側高** の四社すべてに「甕」祭祀が共通。

### 7-3. 忌部の「斎瓮（イミベ）」職能

『サンカ研究』田中勝也著の極めて重要な伝承（下総一こと印部一郎の語り）：

> 私の印部は神武様の前（カミ）の前、ずうっと前から **スガベ** でございます。スガベというのは、清々しく身を清めて、祭事の **御供物 容器（イレ）** を奉る一族のことであります。
>
> 神前に延べる斉庭の真菰（茅チガヤ）を編み、**御神酒（ミケ）を奉る陶（ヤキモノ）を作り、海幸山幸野幸を奉る箕（ミカラワケ）** などを、身を清めて作ります。
>
> これが **斎瓮（イミベ）** で、その遠祖（トオツオヤ）の神が、**天太玉命** であります。

→ **甕を造ったのは忌部** であり、もし忌部であれば **側高・息栖・鹿島の三社に忌部が関係していた** ことになる。

→ 「斎瓮（イミベ）」は **忌部（インベ／イミベ）** の語源そのもの。忌部の本質は **祭祀用器（甕・箕）製作の氏族** であった。

### 7-4. 安房国に甕が見当たらない問題

総フサブログの指摘：

> 不思議なことに **安房国の忌部関連の神社に甕は見当たらない**。私の推測では安房国は元は **真の忌部** がいたと思うのですが、後からきた **偽忌部（？）** に乗っ取られたんじゃないかと思うのです。

→ 阿波説的読み：**側高・息栖・鹿島の原忌部** と **安房神社の中央化忌部** は性格が異なる可能性。**側高の方が古層の阿波忌部の原型** を保存している。

→ 関連：[[阿波忌部氏伝承詳細]]、[[15_忌部氏系図・氏文]]

## 9. 阿波説における意義

### 9-1. 「香取神宮以前の祭祀」の物証

側高神社は **香取神宮の主祭神（経津主＝中央化された武神）以前の祭祀層** を示す稀有な遺跡：

- 「言わず語らずの神」 = **隠された原祭神**
- 第一摂社の地位 = **本来の地主神**
- 起請の質神 = **最高神格**
- 12月7日同日祭祀 = **祭祀の連動構造**

→ 通説の「経津主神（物部氏祭神）」以前に、**阿波忌部・海部・多氏の重層祭祀** があった。

### 9-2. 阿波忌部祖神祭祀の北端拠点

> - 御祭神「**側高神**」は **正式神名不詳** で、現代の神社界では「不詳の神」として扱われる。本ノートで紹介する候補（天日鷲命・撞賢木厳之御魂天疎向津媛命など）はすべて **推定**

> - 「**側高神＝経津主の后神**」とする読みは、12月7日の同日祭祀構造に基づく推定で、文献的確証はない
