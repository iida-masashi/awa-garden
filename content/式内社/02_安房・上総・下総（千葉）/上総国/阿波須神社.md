# 阿波須神社（あわすじんじゃ）

> [!summary] 要旨
> **阿波須神社（千葉県市原市五井3389）** は通称 **「あわすさま」**、安房神社（館山市）の祖神 **天比理刀咩命（あめのひりとめのみこと）** を祀る上総国の阿波忌部関連社。**治承4年（1180）、源頼朝が石橋山の戦に敗れて安房から東上する際に当地で勧請** したと伝わる。安房神社の女神 **天比理刀咩命（天太玉命の后神）** を **「阿波須権現」** として祀り、市原市の **阿波須・阿波能須・阿葉系神社群** の一翼を構成する。「**アワス**」の社名は **「阿波の州（洲）」** の意で、阿波忌部の上総進出における **「阿波・安房」表記の保存例** の一つ。

## 2. 源頼朝による勧請伝承

『阿波須神社縁起』（chiba_jinja 所載）の重要記述：

> **治承四年、源頼朝が安房より上総を経て東上の際、同年九月二九日当所に阿波須権現を勧請され、武運長久を祈られた** という。

→ **「治承4年9月29日」** という具体的な日付が伝わる稀有な事例。

### 2-1. 家僕岡崎某の再会譚

> 時に **家僕岡崎某が、石橋山の戦に公を失い追慕の情止み難く陸路より公の行方を追跡した** ところ、図らずも **当所阿波須権現の森林中において会見することが出来た** という。

→ **阿波須権現の森林** が源頼朝と家僕の **再会の地** となった。これは：

- 阿波須神社が当時すでに **森林に囲まれた古社** であった証拠
- 頼朝が当地を **武運祈願の聖地** として認知していた
- 治承4年の頼朝勧請は **既存の祭祀地への加護祈願** の形を取った可能性

### 2-2. 社殿改造の歴史

| 年 | 出来事 |
|---|---|
| 1247年（宝治元年） | 社殿改造 |
| 1334〜1338年（建武） | 社殿改造 |
| ...（5度の改造） | 各時代 |
| 1751年（宝暦元年） | 5度目の改造（建武から400年余で5度） |
| 1901年（明治34年）9月29日 | 改造 |
| 1985年（昭和60年）9月 | 現社殿新修造 |

→ **明治34年・昭和60年ともに「9月」** の改造で、**創建日「9月29日」の継続性** が保持されている。

## 3. 祭神「天比理刀咩命」の位置

### 3-1. 安房神社祖神の上総拠点

天比理刀咩命は：

- **天太玉命（忌部総祖神）の后神**
- [[安房神社]] および [[后神天比理乃咩命神社]]（館山市洲宮）の祭神
- 阿波忌部の **女神祭祀** の中心

→ 阿波須神社は **安房から上総へ進出した阿波忌部** が、本貫の女神祭祀を移植した拠点として位置付けられる。

### 3-2. 「天日鷲命系」と「天太玉命系」の対比

市原市内の阿波忌部関連社は **二系統**：

| 系統 | 祭神 | 性格 |
|---|---|---|
| **天日鷲命系**（阿波忌部祖、男神） | 天日鷲命 | 鷲神社（今津朝山）、大鷲神社（柳原）、大国主神社（宮原）、阿葉大杉神社 |
| **天比理刀咩命系**（安房神社后神、女神） | 天比理刀咩命 | **阿波須神社（五井）**、阿波能須神社（菊間） |

→ 阿波忌部の **「父系（天日鷲）と母系（天比理刀咩）」の二重祭祀** が市原市内で並行展開している。

## 4. 「アワス」「アワノス」の音韻論

「**阿波須（アワス）**」と「**阿波能須（アワノス）**」の関係：

| 表記 | 読み | 意味 |
|---|---|---|
| **阿波須** | あわす | 阿波の州（洲） |
| **阿波能須** | あわのす | 阿波の州（「能」は助詞「の」） |
| **安房洲** | あわす | 安房の洲 |

→ 三社とも基本的に **「阿波（安房）の州（す）」** という同じ意味。**「洲（す）」は河口・砂州** を意味し、海岸線の祭祀地を示す。

→ 市原市の **「阿波須＋阿波能須」** ペアは、**村田川河口域** （阿葉大杉神社のある飯香岡八幡宮周辺と隣接）の阿波忌部祭祀の二大拠点。

## 5. 阿波説における意義

### 5-1. 「阿波→安房」地名移植の物証

社名「阿波須」は **「阿波（あわ）の州（す）」**：

- 『古語拾遺』所載の **「阿波忌部所居、便名安房郡」** の地名移植法則を具現
- 市原市五井（旧海上郡）は **安房上陸後の北上ルート上** に位置
- 阿波忌部が **「阿波の州」と命名して祭祀を移植** した痕跡

→ 関連：[[阿波・安房ペア：黒潮が繋ぐ同一地名群]]、[[上総・下総・安房の古郡名と阿波接続論：總フサ国の地名学的痕跡]]

### 5-2. 五井（ごい）の地名

「**五井**」の地名：

- 五つの井戸（聖泉）の地という意味
- **古代の祭祀井戸** が複数存在した可能性
- 阿波須権現の森林とともに、当地が古代の **複合祭祀地** であった証拠

### 5-3. 源頼朝の安房上陸ルートの祭祀化

治承4年（1180）の源頼朝の安房→上総→鎌倉ルート上に：

| 地点 | 神社 | 祈願内容 |
|---|---|---|
| 安房 | [[安房神社]] | 上陸祈願 |
| 安房 | [[莫越山神社]] | 修復・配祀拡充 |
| 上総（市原） | **阿波須神社（本社）** | 武運長久 |
| 鎌倉 | 鶴岡八幡宮 | 関東統治 |

→ 頼朝の **安房復活の祭祀ライン** に阿波須神社が位置付けられる。阿波忌部の祭祀地が **中世武家政権の聖地** として再生した事例。

## 8. 留保

> [!warning] 注意
> - 治承4年（1180）源頼朝勧請伝承は『阿波須神社縁起』所載で、史実性は中世神社縁起の一般的水準にとどまる
> - **創建以前の祭祀の有無は不明**。「森林中で頼朝と家僕が会見」した記述から、**頼朝勧請以前に既存の祭祀地** であった可能性が高いが文献的裏付けは限定的
> - 「**アワス＝阿波の州**」とする読みは阿波説的解釈で、別解（朝廷の役職「阿波掾（あわのじょう）」由来説など）もある
