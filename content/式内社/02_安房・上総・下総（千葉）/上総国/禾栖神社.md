# 禾栖神社（かすじんじゃ）

> [!summary] 要旨
> **禾栖神社（千葉県長生郡長南町小生田741）** は **忌部総祖神「天太玉命」** を主祭神とする上総国の阿波忌部関連社。社名「**禾栖（かす）**」の **「禾（か）」** は **「いね・穀物」** を意味する漢字で、「**穀物の栖（すみか）**」 = **阿波忌部の麻穀栽培祭祀地** を直接的に示す稀有な命名。茂原市鷲巣の **鷲妙見大菩薩顕現地（酉の市発祥）** に近接し、[[安房洲神社]]（茂原市国府関）・**国府里神社**（長柄町）と共に **長生郡の阿波忌部祭祀群** を構成する。「**禾栖（かす）**」と「**阿波須（あわす）**」の音通接続説も指摘される。

## 2. 「禾栖（かす）」の社名解読

### 2-1. 「禾（か）」の意味

「**禾**」 = **穀物の総称、特に稲穂**（古代漢字の本義）：

- 「禾本科」（イネ科）の「禾」
- 古代中国で **穀物の象形文字**
- 日本でも **稲・粟・黍** などの総称

→ 「**禾栖**」 = **「穀物の栖（すみか）」 = 穀倉地、または穀物祭祀地**。

### 2-2. 「禾栖（かす）」と「阿波須（あわす）」の音通

| 表記 | 読み |
|---|---|
| **禾栖** | かす |
| **阿波須** | あわす |
| **安房洲** | あわす |
| **粕** | かす |

→ 「**かす**」と「**あわす**」の音通：「**あ**」音の消失で「**わす → かす**」（または「**かす**」が略形）の可能性。

→ もう一つの解釈：「**禾＝米麦穀物**」「**栖＝住むところ**」で、**阿波忌部の麻穀栽培職能の祭祀地** を **意味的に表現** した社名。

### 2-3. 阿波忌部の麻穀栽培との直結

『古語拾遺』所載の阿波忌部の核心職能：

> 阿波国に率て往きて、**麻・穀（こうぞ）を植えしむ**。其の裔、今、彼の国に在り。大嘗の年に、**木綿・麻布を貢る**。所謂、阿波忌部の祖なり。

→ 阿波忌部の本貫職能は **「麻・穀の栽培」**。「**禾栖**」社名はこの **職能を社名化** した稀有な事例。

### 3-1. 鷲巣鷲神社との接続

長生郡内に **鷲巣鷲神社**（茂原市鷲巣18、祭神：天日鷲神）が鎮座。これは：

- **酉の市発祥地**
- 1265年に **日蓮聖人が「鷲妙見大菩薩」を顕現** させた地
- **天日鷲命の祭祀地**

→ 長生郡内で **「天太玉命（父・上司）」と「天日鷲命（子・部下）」の二重祭祀** が完備されている。

### 3-2. 阿波忌部の長生郡進出

長生郡（旧長柄郡＋埴生郡）の阿波忌部祭祀群は：

| 拠点 | 性格 |
|---|---|
| **禾栖神社（本社）** | 穀物祭祀の本拠 |
| **安房洲神社** | 「安房洲＝阿波忌部の祭祀地」の地名社 |
| **国府里神社** | 安房洲と対社 |
| **鷲巣鷲神社** | 天日鷲命祭祀の中核 |

→ **阿波忌部の長生郡進出** は安房（千葉南端）・上総中部（市原）に続く第3の集中地。

## 4. 「小生田（こうだ／おばえだ）」の地名

地名「**小生田**」の解：

- 「**生田（いくた／うまれた）**」 = 稲が生まれる田、神聖な水田
- 「**小**」 = 美称または「神の」

→ 「**神聖な水田の地**」と解される。禾栖神社の **穀物祭祀** と整合する地名。

## 5. 阿波説における意義

### 5-1. 阿波忌部の職能を社名化した稀少例

「**禾栖**」社名は **阿波忌部の麻穀栽培職能を社名化** した極めて稀有な例：

- 多くの阿波忌部関連社は **地名（阿波・安房）** または **祖神名（天日鷲・天太玉）** を社名とする
- **「禾栖」のように職能（穀物栽培）を社名にする例は稀**
- これは当地の阿波忌部が **麻穀栽培で特に著名** であったことの証拠

### 5-2. 長生郡の阿波忌部祭祀集中

長生郡内で：

- **天太玉命3社**（禾栖・安房洲・国府里）
- **天日鷲命1社**（鷲巣鷲神社）
- **酉の市発祥地**（鷲巣）

→ 千葉県内でも有数の **阿波忌部祭祀集中地**。

### 5-3. 「父・子神」の祭祀分業

長生郡内で：

- **天太玉命（父・忌部総祖神）**：禾栖・安房洲・国府里 → **穀物・祭祀器製作職能**
- **天日鷲命（子・阿波忌部祖）**：鷲巣鷲神社 → **麻・木綿職能**

→ **父系（穀物）と子系（麻・木綿）の祭祀分業** が地理的に分離されている稀有な構造。

### 5-4. 鷲妙見大菩薩・酉の市の背景祭祀

1265年の **鷲巣における鷲妙見大菩薩顕現** および後の **江戸浅草酉の市** の文化的基盤は：

- 長生郡内の **阿波忌部の長期祭祀** にある
- **禾栖神社（天太玉）と鷲巣鷲神社（天日鷲）の併存** が古代から続いた
- これが日蓮聖人の **「鷲妙見」顕現** の土壌となった
