# 阿止粉未神社（あとちまつじんじゃ）

> [!summary] 要旨
> **阿止粉未神社(あとちまつじんじゃ、論社未確定)** は **上総国望陀郡(現千葉県君津市周辺)の式内小社**。延喜式に名を残すが、**比定社が確定していない不詳社**の一つ。阿波説では、ヤマトタケル東征以前から望陀郡(鹿野山)を拠点としていた **阿久留王(あくるおう)** ─ 阿波忌部の先住首長 ─ との関連で論じられる。「阿止粉未」と「阿久留」の音韻関係や、望陀郡という地理的一致から、**阿久留王関連祭祀**の痕跡として注目される。「阿波(から来て)久しく留まった王」とする阿波説の解釈と、本社の存在は密接に絡み合う。

## 3. 望陀郡の地理的文脈

### 3-1. 望陀郡の範囲

望陀郡は古代上総国の一郡で、現在の **君津市・木更津市・袖ケ浦市** 一部に相当。
郡の中心には **鹿野山(かのうざん、別名: 金生山)** がそびえ、これが本社の論考における最重要地点となる。

### 3-2. 鹿野山 = 金生山(製鉄の山)

鹿野山の漢字表記には「**金生**」の異表記があり、**製鉄に由来する地名**とする説が阿波説では有力。

- **「金生」** = 「金属(鉄)を生む」
- 阿波忌部が **製鉄技術**を東国に持ち込んだ拠点として、鹿野山が機能した可能性

→ 詳細: [[阿久留王（あくるおう）と阿波]] §1〜2

### 3-3. 戦闘伝承地名群

望陀郡には **阿久留王とヤマトタケルの戦闘**を物語る地名が現存:

| 現地名 | 伝承 |
| --- | --- |
| **鬼泪山(きなだやま)** | 追い詰められた阿久留王が涙を流して命乞いした山 |
| **血染川(現染川)** | 阿久留王一族の血で三日三晩赤く染まった川 |
| **地臭浦(現千種ヶ浦)** | 血が海に流れ込み腐敗して血臭が漂った海岸 |
| **飯香岡八幡宮**(旧六所御影神社) | ヤマトタケルが献上された飯の香りを喜んだ |

→ これらと本社は **同一の望陀郡内に位置**しており、**地名と式内社の地理的同時性**は注目に値する。

## 4. 阿久留王伝承との接続 — 阿波説の核心解釈

### 4-1. 「阿波(から来て)久しく留まった王」説

[[阿久留王（あくるおう）と阿波]] §1 が示す阿波説の核心:

> 「**アクル**」の語源は「**阿波(から来て)久しく留まった王**」を意味する(阿波説)

→ 阿波忌部の祖 **天富命**が阿波から黒潮に乗って房総に上陸し、独自の「阿波(安房)王国」を築いた。**阿久留王はその王国の首長**で、ヤマトタケル東征以前から望陀郡を支配していた、と読む。

### 4-2. 「阿止粉未」と「阿久留」の音韻接近?

「**阿止粉未(あとちまつ)**」と「**阿久留(あくる)**」の語頭一致(「**ア-**」)は注目される:

- 古代日本語の音韻変化として、「**ク-**」音と「**ト-**」音は子音調音点が近い(両者とも閉鎖音)
- 阿波忌部関連の祭祀地名が、後世「鬼の名前」として変形した可能性
- これは推測の域を出ないが、**両者を結びつける論点**として記録に値する

### 4-3. 「跡を留めた」 — 別解釈

字義通りに読むと:

- **止** = とどまる、足跡を残す
- **粉** = 砕けた、散らされた
- **未** = まだ来ていない、未完

→ 「(ヤマトに)散らされたが、まだ完全には消えていない、阿(=阿波?)の跡を留める地」と読める。
**「阿波忌部の先住勢力がヤマトタケルに敗れたが、祭祀の痕跡を残した」**という阿波説の解釈と整合する。

→ 字義解釈は推測の域を出ないが、祭祀消滅の理由としては整合的。

## 5. 比定社未確定の意味

### 5-1. 「式内社で比定不明」の阿波説的解釈

延喜式神名帳に名があるにもかかわらず比定社が確定しない「不詳社」は、阿波説では以下のように解釈される:

1. **政治的に祭祀権が剥奪された** — 中央朝廷(ヤマト)に敵対した氏族の祭祀地は意図的に放置・荒廃
2. **記憶の意図的抹消** — 「鬼」とされた敵対勢力の祭祀社は、地域社会から忌避された
3. **祭祀継承氏族の絶滅** — ヤマトタケル討伐により本系氏族が滅び、祭祀継承者がいなくなった

→ 阿止粉未神社の **「比定不明」**は、阿波忌部先住系の祭祀が **抹消されたことの物的痕跡**である、と読む。

### 5-2. 鹿野山・神野寺との関係

望陀郡の主要寺院 **神野寺(じんやじ)**(鹿野山)の本尊は **軍荼利明王(六臂)**:

- 阿久留王は **「六手王(むておう)」**とも呼ばれた(腕が 6 本ある異形)
- 軍荼利明王が **阿久留王の霊を鎮める仏**、あるいは王自身の化身とする説あり
- 神野寺周辺に阿止粉未神社の **遺跡的痕跡**がある可能性(要現地調査)

→ 詳細: [[阿久留王（あくるおう）と阿波]] §2

## 6. 阿波説における意義

### 6-1. 「敗れた阿波忌部」の祭祀痕跡

[[安房忌部_MOC|🗺 安房忌部 MOC]] が描く阿波忌部の東遷は **「成功した東遷」**:
天富命 → 安房神社創建 → 朝夷郡の祭祀網確立 → 上総・下総への展開

しかしその一方で、**敗れた阿波忌部系勢力**もまた存在した:

- 望陀郡の阿久留王 = ヤマトタケル東征以前の先住首長
- 阿止粉未神社 = その祭祀の痕跡(比定不明)

→ **「成功した忌部(安房神社)」と「敗れた忌部(阿久留王・阿止粉未神社)」の対**が、阿波忌部東遷史の **複層構造**を示す。

### 6-2. 製鉄技術の東遷ルート

鹿野山(金生山)に阿波忌部が **製鉄技術**を持ち込んだとする論点は、阿波説の重要主張:

- 阿波には **天目一箇神**(忌部五部神の一、筑紫・伊勢忌部祖)を祀る伝承あり
- 望陀郡の鹿野山が **「金生山」**(製鉄の山)と呼ばれることは、阿波忌部の **金属技術の東遷**を示す物的傍証
- 阿止粉未神社が鹿野山周辺の祭祀社であったなら、**製鉄技術祭祀の神格化**であった可能性

→ 関連: [[理論・研究/02_考古学・物証/産業遺産_朱_鉄_麻/鍛冶・金属/阿波の鉄と鍛冶技術：天目一箇神の足跡|阿波の鉄と鍛冶技術：天目一箇神の足跡]]

### 6-3. ヤマトタケル東征の阿波説的位置付け

ヤマトタケル東征は **「阿波忌部先住勢力の征服」**として再解釈される:

- ヤマト王権(陸路東征) ⇄ 阿波忌部(海洋ルート先住)
- 阿久留王 = 敗れた海洋王権の象徴
- 阿止粉未神社 = その祭祀の消えかけた残映
