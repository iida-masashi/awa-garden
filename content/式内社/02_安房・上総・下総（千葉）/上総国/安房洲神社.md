# 安房洲神社（あわすじんじゃ）

> [!summary] 要旨
> **安房洲神社（千葉県茂原市国府関852）** は **忌部氏祖神「天太玉命（あめのふとだまのみこと）」** を主祭神とする上総国の阿波忌部関連社。社名「**安房洲**」は **「安房（あわ）の洲（す）」** の意で、**[[安房神社]]（館山市）の祖神祭祀** を上総北部・茂原地区に移植した拠点。**茂原市鷲巣（わしのす）の鷲巣鷲神社**（天日鷲神を祀る、「**鷲妙見大菩薩**」顕現の地）と **長柄町国府里の国府里神社**（天太玉命）と共に、**茂原圏の忌部祖神祭祀三角形** を構成する。**「酉の市」の真の発祥地（鷲巣）の北西4km** という地理的近接が、阿波忌部の **茂原進出の物的物証**。

## 2. 「安房洲」の社名解読

### 2-1. 「安房（あわ）の洲（す）」

- 「**安房（あわ）**」 = 阿波忌部の安房郡命名地（『古語拾遺』「阿波忌部所居、便名安房郡」）
- 「**洲（す）**」 = 砂州、河口の祭祀地

→ 「**安房洲**」は **「安房から移住した忌部の祭祀地（洲）」** の意。社名そのものが阿波忌部の東遷を地名として記録した稀有な例。

### 2-2. 表記の揺れ

「安房洲」「阿波洲」「安房須」「阿波須」など、表記は様々：

| 表記 | 神社 | 所在 |
|---|---|---|
| **安房洲** | 本社 | 茂原市国府関 |
| **阿波須** | [[阿波須神社]] | 市原市五井 |
| **阿波能須** | [[阿波能須神社]] | 市原市菊間 |

→ いずれも基本的に **「アワス（アワノス）」読み** で、阿波忌部の祭祀痕跡を示す。

## 3. 茂原圏の阿波忌部祭祀三角形

茂原市鷲巣を中心とする半径4km圏に **阿波忌部祭祀の三角形** が形成：

| 神社 | 所在 | 祭神 | 性格 |
|---|---|---|---|
| **安房洲神社（本社）** | 茂原市国府関852 | **天太玉命** | 忌部総祖神祭祀 |
| **鷲巣鷲神社** | 茂原市鷲巣18 | **天日鷲神** | **酉の市発祥地、鷲妙見大菩薩顕現地** |
| **国府里神社** | 長生郡長柄町国府里409 | **天太玉命** | 安房洲と対の祭祀 |

→ 詳細：[[大鷲神社：天日鷲命を祀る関東鷲・鳥系神社ネットワーク]] §4-bis「茂原『鷲妙見大菩薩』と酉の市の真の起源」

### 3-1. 「酉の市」の真の起源と忌部祭祀

千葉まほろば神社（chiba_jinja）の重要指摘：

> 茂原市鷲巣に **「天日鷲命」を祀る忌部氏の小祠** があったため、後に **「鷲妙見大菩薩」と結合**。これが **江戸へ進出して浅草「酉の市」** の起源となった。

→ 「**天日鷲命は天太玉命の上司にあたる神様**」（chiba_jinja）。**安房洲神社（天太玉命）と鷲巣鷲神社（天日鷲命）の祭祀ペア** は、**阿波忌部の父・子神祭祀** を保存する稀有な配置。

### 3-2. 安房洲・国府里の二社対称

安房洲（国府関）と国府里（長柄町）の対称配置：

- 両社とも **天太玉命** を主祭神
- **「国府」関連の地名** を共有 — 古代上総国の国府所在地（市原市惣社）に近い
- **同一氏族による二社並立祭祀** の可能性

→ これは [[側高神社]]・[[蘇羽鷹神社]] のソバタカ系の **本宗・分社並立構造** と類似する。

## 4. 「国府関（こうのせき）」の地名

「**国府関**」の地名解：

- 「**国府**」 = 上総国府への要衝
- 「**関**」 = 関所、または **「関を越える」聖地**

→ 上総国府への入り口に位置する祭祀地。**国家祭祀との接点**を示す地名。

## 5. 阿波説における意義

### 5-1. 「安房→上総」地名移植の物証

社名「安房洲」は『古語拾遺』所載の：

> **阿波忌部所居、便名安房郡。後に改めて安房国となす。**

の地名移植法則を、**上総北部にまで延伸** した形での具現。**安房（千葉南端）から上総北部（茂原）への忌部移住** の物的証拠。

→ 関連：[[阿波・安房ペア：黒潮が繋ぐ同一地名群]]

### 5-2. 天太玉命の上総拠点

千葉県内で **天太玉命** を主祭神とする社は限定的：

| 神社 | 所在 | 性格 |
|---|---|---|
| [[安房神社]] | 館山市 | 阿波忌部総本山 |
| **安房洲神社（本社）** | 茂原市国府関 | 上総北部拠点 |
| **国府里神社** | 長柄町国府里 | 上総北部対社 |
| [[禾栖神社]] | 長南町小生田 | 上総南部、天太玉命系・「禾＝穀物の栖」 |
| 大原神社 | 君津市平山 | 小櫃川流域（後に春日合祀） |
| 坂戸神社 | 袖ケ浦市坂戸市場 | 小櫃川流域 |

→ 房総半島内で **天太玉命主祭神社は約6社**。安房・上総の阿波忌部祭祀の中核を構成。

### 5-3. 酉の市発祥との地理的連動

**鷲巣鷲神社（酉の市発祥地）の北西4km** という地理的近接は：

- 阿波忌部の **「父・子神祭祀」**（天太玉→天日鷲）の組み合わせ
- 1265年（文永2）に日蓮聖人が「**鷲妙見大菩薩**」を顕現させた **鷲巣の古層祭祀** の背景
- **古代の阿波忌部祭祀** が中世の「鷲妙見」「酉の市」の文化的基盤
