# 高家神社（たかべじんじゃ）

> [!summary] 要旨
> **高家神社**(千葉県南房総市千倉町南朝夷)は **安房国朝夷郡の式内小社**。**料理の祖神・磐鹿六雁命(いわかむつかりのみこと、尊称: 高倍神)** を祀る、**全国唯一の料理祖神を主祭神とする式内社**。 醤油醸造業者・料理人・調味料関係者から篤い信仰を受け、**毎年 5 月・10 月の包丁式神事**(鳥獣魚に手を触れず包丁と箸のみで料理する古式儀礼)が奉納される。阿波忌部の東遷拠点である朝夷郡内において、**[[莫越山神社]](盾・木工)・[[下立松原神社]](麻・穀)・本社(料理)** と並ぶ職能祭祀の三社一組を形成し、阿波忌部祭祀圏に皇別氏族(高橋氏=膳臣)の祭祀が重層した稀有な祭祀景観を構成する。

## 3. 磐鹿六雁命の伝承

### 3-1. 安房浮島宮の料理伝承(『日本書紀』景行天皇 53 年条)

> 景行天皇が皇子・倭建命(日本武尊)の東国平定の事跡を偲び、**安房の浮島の宮**に行幸された折、覚賀鳥(かっかどり = 鴎)の声を頼りに舟遊をなされた際に、侍臣の **磐鹿六雁命** が **白蛤(うむぎ = 蛤、一説には鮑)と鰹** を膾(なます)に調理して天皇に献上された。

→ 安房 = 海産物の供御地(蛤・鰹・鮑)であったことを示す。**阿波忌部の海上交易・漁撈機能と連動**する地理的接続。

### 3-2. 「膳大伴部(かしわでのおおともべ)」の賜姓

> その料理と味覚の見事さに賞美され、命は後に **膳大伴部(かしわでのおおともべ)** を賜り、子孫は **高橋氏** として代々宮中の **大膳職(だいぜんしき)** に任ぜられ、**安房と若狭の国の一部を賜った**(『高橋氏文』)。

→ 「**安房と若狭**」が高橋氏の本貫地。**安房 = 阿波忌部の本貫であると同時に、高橋氏(料理・膳職)の本貫**でもあった。

### 3-3. 「高倍(たかべ)神」と宮中醤院

> 功績の大なるところから **高倍神** として **宮中 醤院(ひしおつかさ)** の鎮護の神として祀られている。

**醤(ひしお)の三種**:

| 醤 | 内容 | 現代の対応 |
| --- | --- | --- |
| **草醤(くさびしお)** | 野菜の発酵食品 | 漬物 |
| **穀醤(こくびしお)** | 穀物の発酵食品 | 味噌・醤油 |
| **肉醤(にくびしお)** | 魚介の発酵食品 | 塩辛 |

→ 「日本料理の基礎」を体現する祭神。**醤油醸造業者の信仰の源泉**。

## 4. 朝夷郡の忌部祭祀三社一組

### 朝夷郡内の職能祭祀景観

| 神社 | 主祭神 | 職能 | 出典 |
| --- | --- | --- | --- |
| **[[下立松原神社]]** | **天日鷲命** | **麻・穀** | 古語拾遺「天日鷲命之孫…作木綿及麻并織布」 |
| **[[莫越山神社]]** | **手置帆負命・彦狭知命** | **盾・幄・木工** | 古語拾遺・莫越山神社記 |
| **本社(高家神社)** | **磐鹿六雁命** | **料理・醤** | 日本書紀景行紀・高橋氏文 |

→ **「織物 → 建築 → 料理」**という古代国家の祭祀的三要素が、朝夷郡という狭い地理範囲に集約されている。これは:

- **記紀以前の国家祭祀の物的痕跡**
- 阿波忌部の東遷が単なる氏族移動ではなく、**完成された祭祀ネットワークの移植** であったことの証拠
- 古語拾遺の「**阿波忌部所居便名安房郡**」(本文 39 段)記述と整合

## 5. 由緒・歴史

### 5-1. 古代

- 景行天皇朝(社伝) → **安房浮島宮の料理伝承**(『日本書紀』景行 53 年条)
- 延暦8年(789) — **『高橋氏文』** 朝廷奏進、磐鹿六雁命の伝承を公式化
- 延喜式神名帳(927) — 「安房国 朝夷郡 髙家神社」として登載(小社)

### 5-2. 中世

- 中世に一時所在不明・荒廃
- 朝廷祭祀との関係も中断

### 5-3. 近世の再興

| 年 | 事項 |
| --- | --- |
| **元和6年(1620)** | 高木吉右衛門が桜の木下から **木像と御神鏡 2 面** を発見、「神明社」として創建 |
| **元和〜寛永期** | 「神明社」として在地祭祀 |
| **文政2年(1819)** | 御神鏡裏面に「**御食津神 磐鹿六雁命**」の銘が発見され、京都吉田御所(神祇道管領卜部朝臣良長)に届出、**「高家神社」への改称・復元**を達成 |
| **江戸後期** | 醤油沿革史(田中直太朗 = ヒゲタ醤油始祖)、料理法大全(石井治兵衛)、日本料理研究会初代理事長(三宅弧軒)らの活動で **「料理の祖神」としての御神徳**が再発揚される |

### 5-4. 近現代

- 県社 → 神社本庁包括神社
- 全国の料理人・調理師会・醤油醸造業者・調味料関係者からの崇敬を受ける

## 7. 阿波説における意義

### 7-1. 安房 = 阿波忌部本貫における皇別氏族の重層祭祀

『古語拾遺』(807)は:

> **阿波忌部所居便名安房郡**(=阿波忌部の居住地を安房郡という)

と記し、安房郡を **阿波忌部の本貫**と位置付ける(→ [[古語拾遺_MOC]])。

本社の祭神 **磐鹿六雁命は皇別氏族(高橋氏=膳臣)の祖神** であり、阿波忌部とは別系統。
しかし、磐鹿六雁命の料理伝承の舞台が **安房浮島宮** であることは:

1. 安房が古代から **海産物供御地** として朝廷に認識されていた
2. その地理的優位は **阿波忌部の海上交易・漁撈機能** に由来する可能性
3. 阿波忌部の祭祀ネットワーク(忌部五部神)上に、皇別氏族(高橋氏)の祭祀が **重層・併存**した

→ **阿波説における「重層祭祀の典型例」**。

### 7-2. 朝夷郡の祭祀三角形

```
        下立松原神社(麻・穀)
         天日鷲命
              │
              │ 阿波忌部祖神
              │
莫越山神社 ─────── 高家神社
(盾・木工)         (料理・醤)
手置帆負・彦狭知    磐鹿六雁命
              │
              │
       「織 → 建築 → 食」
   阿波忌部祭祀+高橋氏祭祀の重層
```

→ 朝夷郡という狭い地理範囲に **古代国家祭祀の三要素**(織物・建築・料理)が集約されている。
これは [[安房忌部_MOC|🗺 安房忌部 MOC]] の中核を構成する祭祀景観。

### 7-3. 「高橋氏文」と古語拾遺の関係

『高橋氏文』(延暦8年・789奏進)と『古語拾遺』(大同2年・807奏進)は **同時代の氏族系譜文書**:

| 項目 | 高橋氏文 | 古語拾遺 |
| --- | --- | --- |
| 奏進年 | 789 | 807(18 年後) |
| 編者の立場 | 高橋氏 = 膳臣 | 斎部広成 = 忌部側 |
| 主題 | 高橋氏(膳臣)の祭祀権 | 忌部の祭祀権 |
| 安房との関係 | 磐鹿六雁命が安房の長 | 阿波忌部が安房郡を名付ける |

→ **奈良末〜平安初期は氏族系譜文書の奏進ラッシュ期**。中央朝廷から離れた地方氏族が祭祀権を主張する文書を相次いで奏進した。本社の祭祀はこの政治的背景の中で重要視された。

### 7-4. 「醤(ひしお)」と阿波忌部

醤院(ひしおつかさ)は宮中の調味料製造機関。これは:

- **木綿(ゆう)・麻** の生産が阿波忌部の祭祀職能(古語拾遺)
- **醤(ひしお)** は高橋氏の祭祀職能

両者は **「神饌(しんせん)」と「服喪用具」**として、宮中の祭祀器具供給の両輪を担った。**安房 = 阿波 が両職能の本貫**であることは、古代国家祭祀における安房の重要性を示す。

## 11. 留保(中立的併記)

> [!warning] 注意
> - 高家神社祭神(磐鹿六雁命)は **皇別氏族(高橋氏=膳臣)の祖神**であり、阿波忌部系ではない。阿波説的接続は **「同一地理空間における重層祭祀」**の論点
> - 中世の所在不明・近世再興のため、古代祭祀の **連続性に不確定要素**がある
> - 元和6年(1620)発見の御神鏡が古代の物かは確定していない。文政2年(1819)の銘発見と京都吉田家の証は近世の祭祀復元の手続き
> - 「磐鹿六雁命 = 安房の長」とする伝承は『高橋氏文』所載で、他史料による独立検証は限定的
> - 包丁式の起源年代は確定していない。江戸期に体系化された可能性
