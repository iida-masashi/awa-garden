# 廣幡八幡宮（ひろはたはちまんぐう）

> [!summary] 要旨
> 千葉県柏市増尾に鎮座する八幡宮。主祭神は誉田別命（応神天皇）で、息長足姫命・玉依姫命・仲哀天皇・武内宿禰をあわせ祀る五柱構成である。社伝では宇多天皇の治世（887〜897年）に「下総国第一鎮守宇多天皇勅願所」として鎮座したと伝えるが、創建後いったん廃れ、建久4年（1193年）の再建が継続の起点とされる（平成5年・1993年に鎮座800年として本殿を造営）。『延喜式』神名帳に当社の登載はなく**式外社**であり、近代社格は**旧村社**である。旧稿が掲げた「式内社・社格 大」「房総総鎮守」という位置付けは典拠がなく、本改訂で是正した。阿波説との接続を示す資料は今回の照合範囲では確認できていない。

## 3. 祭神と社伝

祭神は五柱。主祭神の誉田別命（応神天皇）に、息長足姫命（神功皇后）・玉依姫命の八幡三神を構成する二柱と、仲哀天皇・武内宿禰をあわせ祀る（公式サイト・Wikipedia・『千葉県の神社一覧』で一致）。地元では「はちまんさま」と親しまれる（宿坊研究会）。

社伝によれば、宇多天皇の時代（887〜897年）に「下総国第一鎮守宇多天皇勅願所」として鎮座したという（Wikipedia「由緒」）。ただしこの創建は社伝の域を出ず、創建後いったん廃れたとされる点も含め、実証的な裏付けは §12 に留保する。

## 4. 歴史

- **（伝）887〜897年**: 社伝の創建（宇多天皇治世）。その後いったん廃れる（Wikipedia「歴史」）
- **1193年（建久4年）**: 再建。以後の継続はこの再建を起点とする（1993年の「鎮座800年」は1193年起点の計算）
- **1649年（慶安3年）**: 徳川家光より朱印地十石を献上される
- **1758年（宝暦7年）**: 伯州刺史藤原正珍が石華表一基を寄進
- **近代**: 社格は村社（旧村社）
- **1993年（平成5年）**: 鎮座800年を記念して本殿を造営。本殿の様式は権現流造（Wikipedia）

## 5. 核心論点

### 5-1. 式内社ではないことの確定（延喜式原文照合）

Wikisource『延喜式』巻九原文で下総国は「下總國十一座／大一座／小十座」、千葉郡は「千葉郡二座／並／小」＝寒川神社・蘇賀比咩神社の二座のみであり、当社の登載はない。よって当社は**式外社**である。

下総国十一座の静的分布表:

| 郡 | 座数・格 | 社名 |
|---|---|---|
| 香取郡 | 一座・大（名神大） | 香取神宮 |
| 千葉郡 | 二座・並小 | 寒川神社、蘇賀比咩神社 |
| 匝瑳郡 | 一座・小 | 老尾神社 |
| 印播郡 | 一座・小 | 麻賀多神社 |
| 結城郡 | 二座・並小 | 高椅神社、健田神社 |
| 岡田郡 | 一座・小 | 桑原神社 |
| 葛飾郡 | 二座・並小 | 茂侶神社、意富比神社 |
| 相馬郡 | 一座・小 | 蛟魍神社 |

（巻九原文に基づく。長柄郡・海上郡・望陀郡の各座は上総国分として原文上は上総国側に並ぶため本表には含めない）

### 5-2. 「下総国第一鎮守」という社伝と実証的社格の乖離

社伝の「下総国第一鎮守宇多天皇勅願所」という称は当社の自己規定であり、延喜式登載の有無・近代社格（村社）とは対応しない。旧稿の「房総総鎮守」という表現は、社伝の「下総国第一鎮守」とも異なり、今回照合した資料のいずれにも確認できなかったため採用しない。

### 5-3. 同名社・重複ノートへの注意

- 岡山県岡山市南区にも同名の廣幡八幡宮（旧村社、嘉慶元年・1387年創建と伝える別社）が鎮座する。旧稿の参照には両社の混同は見られなかったが、Web検索では混在するため注意を要する
- Vault内には同一社を扱う重複ノート「廣幡八幡宮」（下総国/相馬郡フォルダ、新テンプレート型）が併存していた。同ノートは旧郡を相馬郡・社格を旧県社とし、藤原秀郷勧請説や相馬氏による再建を記すなど、本ノートの照合結果（旧村社）と記載が相違していた。2026-11-15の本人の判断により同ノートは削除され、本ノートに一本化された（削除前の内容は監査用バックアップに保管。§12 参照）

## 6. 阿波説における意義

旧稿は「房総の総鎮守が阿波国式内社ネットワークに位置付けられる」「宇多天皇の創建が阿波系神社の広がりと連関する」と論じていたが、いずれも典拠の提示がない。当社は宇佐・石清水系の八幡信仰に属する八幡宮であり、祭神五柱にも阿波忌部系の神格は含まれない。今回の照合範囲（Wikipedia・公式サイト・延喜式原文）で、阿波忌部や阿波国との接続を示す資料は確認できなかった。したがって旧稿の阿波説的意義付けは、現時点では裏付けのない仮説として分離し、本ノートの evidence_type は社伝中心の shrine_origin、confidence は 2 とする。
