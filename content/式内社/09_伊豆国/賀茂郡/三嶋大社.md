# 三嶋大社（みしまたいしゃ）

> [!summary] 要旨
> **三嶋大社**は伊豆国賀茂郡（現・三島市）に鎮座する **延喜式神名帳「伊豆三島神社 名神大」** の比定社、伊豆国一宮。主祭神は **大山祇命** と **積羽八重事代主神**（両神を併祀し「**三嶋大明神**」と総称）。この祭神論は数百年来の「**大山祇神説（伊予系）⇔ 事代主神説（伊豆系）**」の対立を抱え、伊予 [[大山積神社]]（大三島）を本源とすれば大山祇神、伊豆諸島の創世神話『三宅記』（→ [[三宅記_MOC]]）と神津島の阿波命・物忌奈命を本源とすれば事代主神となる。阿波説は両系を排他的に扱わず、**両系の母胎が阿波にある**とする止揚的立場を取りつつ、特に伊豆系（事代主＋阿波命＋物忌奈命）が阿波国の事代主祭祀（[[事代主神社]]）の黒潮東遷終着点であると論じる。本ノートは三嶋大社固有の祭祀・歴史・神事を中心に整理し、祭神論争のハブは [[三嶋大明神：事代主神か大山祇神か─伊豆・伊予の祭神論争と阿波]] に委ねる。

## 3. 祭神と社伝

### 3-1. 三嶋大明神＝両神併祀

三嶋大社の主祭神は、現在の社伝では **大山祇命と積羽八重事代主神** の両神を「三嶋大明神」と総称する。両神併祀は中世以降に確立した習合的祭神配置であり、古代の祭神が伊予系（大山祇）であったか伊豆系（事代主）であったかは古来論争が続いている。

### 3-2. 大山祇神説（伊予系）

『伊予国風土記』逸文：「乎知（越智）の郡。御嶋に坐す神の御名は大山積の神、一名は和多志の大神なり。是の神は、難波の高津の宮に御宇しめしし天皇の御世に顯れましき。此神、百濟の國より度り來まして、津の國の御嶋に坐しき。云々」

→ この記述に基づき、伊予大三島（[[大山積神社]]）→ 摂津御島（[[三島鴨神社]]）→ 伊豆三島へと遷祀された山神・渡海神とする立場。三嶋大社の現在の祭神筆頭が大山祇命であることはこの伝承を反映する。

### 3-3. 事代主神説（伊豆系・阿波説）

伊豆諸島の創世神話『三宅記』に基づく：

- **三嶋大明神**：三宅島を拠点に伊豆諸島を「焼き出す」（火山島の創世）
- **后神「阿波命」**：神津島に名神大社として鎮座
- **御子神「物忌奈命」**：同じ神津島に名神大社として鎮座（[[物忌奈命神社]]）
- **后神「伊古奈比咩命」**：白浜（下田）に鎮座（[[伊古奈比咩命神社]]）
- 父神＝三嶋大明神は **積羽八重事代主神**

「阿波命（后）」「物忌＝忌部（子）」が揃って絶海の神津島に名神大社として存在することは、**阿波国の事代主祭祀が阿波忌部・海人族の東遷とともに伊豆諸島へ移植された**痕跡と読む。

### 3-4. 中世以降の両神併祀

両説は排他的ではなく、中世以降は **両神を「三嶋大明神」と総称する併祀構造** が確立した。三嶋大社の祭神表記に大山祇命と事代主神の両神が含まれるのはこの習合の結果である。

→ 詳細：[[三嶋大明神：事代主神か大山祇神か─伊豆・伊予の祭神論争と阿波]]

## 4. 歴史

- 創建年代不詳。伊豆諸島での祭祀（神津島・三宅島・白浜）が先行し、後に伊豆半島の現社地へ遷祀されたとの伝承（『三宅記』）。
- **承和5年（838）神津島大噴火** と神階奉授（『続日本後紀』）が三嶋神の国家祭祀化を象徴する画期。
- **延喜式神名帳**（927年）：「伊豆国賀茂郡 伊豆三島神社 名神大」として記載。
- 平安〜中世：神階奉授が累進し、伊豆一宮として国家祭祀の中枢に組み込まれる。
- **治承4年（1180）**：源頼朝が伊豆配流中に三嶋大社で挙兵祈願し、平家追討の挙兵を成功させる。以降、**鎌倉武家政権の総氏神** として崇敬される。
- 鎌倉期：『三宅記』が成立し、三嶋大明神の島焼き神話と本地薬師如来の習合が確立。
- 中世：北条得宗家・足利氏・後北条氏など武家政権の崇敬を集める。
- 江戸期：東海道五十三次の三島宿の中心。参詣者を多数集める。
- 明治：官幣大社に列せられる。
- 戦後：別表神社。

### 4-1. 神階奉授の連動性

伊豆三嶋神への神階奉授は、伊予大山積神への神階奉授と歩調を合わせて進行した（『続日本後紀』『日本三代実録』）。両「三嶋」の連動性は、中央政府が両神を関連神格として認識していた可能性を示唆する。

### 4-2. 源頼朝の挙兵と三嶋信仰

治承4年（1180）8月17日、源頼朝は三嶋大社の祭礼の日を選んで挙兵した。この故事は三嶋信仰と武家祭祀の結節点となり、鎌倉幕府成立後の三嶋大社の隆盛を方向付けた。

## 5. 『三宅記』と伊豆諸島祭祀ネットワーク

### 5-1. 『三宅記』の島焼き神話

『三宅記』は伊豆国一宮・三嶋大明神を主人公とする中世の縁起物語で、薬師如来を本地仏とする。骨子：

1. 三嶋大明神が **三宅島を拠点** に、神々を率いて伊豆諸島を次々と「焼き出す」（火山島の創成＝島焼き）
2. 后神として **阿波命** ほかを娶り、御子神（物忌奈命ほか）をもうける
3. 各島に后神・御子神を配し、伊豆諸島の祭祀ネットワークが形成される

この「島焼き」は伊豆諸島の **火山活動**（噴火による新島形成）を神話化したもの。

→ 詳細：[[三宅記_MOC]]・[[三宅記_伝承・事蹟完全目録]]

### 5-2. 考古学から見た三嶋神の三画期（深澤太郎）

| 画期 | 年代 | 性格 |
|---|---|---|
| **第一画期** | 7〜8世紀 | 火山噴火に対応した国家的・公共的な神祇祭祀。石積みなど原初的祭祀形態 |
| **第二画期** | 9〜11世紀 | 国衙祭祀の拠点化。各地の「三嶋神」が神階を累進（神津島噴火と神階奉授など） |
| **第三画期** | 12世紀以降 | 鎌倉武家祭祀の定着。『三宅記』の神仏習合・本地垂迹（薬師如来）が一般化 |

阿波説の重要点：**第一画期（7〜8世紀）の原初的海人祭祀こそが阿波系東遷の痕跡**であり、『三宅記』（第三画期）はそれを中世的世界観で再編したもの。

### 5-3. 伊豆諸島祭祀ネットワーク

| 島 | 中核社 | 祭神 |
|---|---|---|
| 三宅島 | 富賀神社など | 三嶋大明神（父神） |
| 神津島 | [[物忌奈命神社]]（名神大） | 物忌奈命（御子神） |
| 神津島 | 阿波命神社 | 阿波命（后神） |
| 大島 | [[波布比売命神社]] | 波布比売命 |
| 利島 | 阿豆佐和気命神社 | 阿豆佐和気命 |
| 下田 | [[伊古奈比咩命神社]]（白浜神社） | 伊古奈比咩命（后神） |

これら島嶼の祭祀群が **絶海の島に名神大社を擁する** という事実そのものが、伊豆諸島祭祀の古代的中枢性を示す物的証拠である。

## 6. 阿波説における意義

### 6-1. 事代主祭祀の東遷終着点

阿波国は事代主信仰の濃密地：[[事代主神社]]（阿波郡）・[[生夷神社]]（勝浦郡）が本貫。三嶋大明神（事代主神）を伊豆一宮の頂点に据える伊豆系三嶋信仰は、**阿波の事代主祭祀の東遷終着点**と位置付けられる。[[率川阿波神社の元宮論：阿波の事代主神社が本源]] と同じ「阿波が本源」の構図。

### 6-2. 「阿波命」という后神＝阿波そのもの

后神の名がそのまま「**阿波命**」であることは、伊豆諸島の祭祀が **阿波を母胎とする自己認識** を持っていたことの直接的証拠である。神津島で母（阿波命）と子（物忌奈命＝忌部）が名神大社として並ぶ構造は、**阿波忌部の東遷神話そのものの神格化** と読める。

### 6-3. 黒潮ネットワークの結節点

伊豆諸島は阿波→安房の [[阿波忌部の東遷：安房・上総開拓と黒潮ネットワーク]] の中継拠点。三嶋大明神信仰は、この海人・忌部の航海ネットワークが伊豆で結晶した祭祀体系である。

### 6-4. 物忌＝忌部の祭祀権

「**物忌奈命**」の「物忌」は神事における斎戒・忌部の祭祀権を表す名称で、御子神の名がそのまま **忌部の祭祀権** を表象している。阿波忌部が伊豆諸島に祭祀権を移植した過程の神話化と読まれる。

### 6-5. 事代主（海神）と忌部（祭祀）の習合

阿波で事代主の海神系譜と忌部の祖神系譜が併存していたものが、伊豆諸島で結びつき、新たな島造り神話（『三宅記』）を生んだ。三嶋大明神は **事代主＝海神性** と **忌部＝祭祀性** の融合の象徴である。

### 6-6. 伊予系と伊豆系の止揚

阿波説は伊予系（大山祇）と伊豆系（事代主）を排他的に扱わず、

- **伊予系**：阿波の山祇祭祀（[[山方比古神社]]・[[西照神社]]・剣山系）が瀬戸内海西進 → 大三島
- **伊豆系**：阿波の事代主祭祀（[[事代主神社]]）が黒潮東遷 → 伊豆諸島
- **両系の母胎が阿波** にあり、東西に展開した二経路

と整理する。三嶋大社が両神を併祀する事実は、**阿波を母胎とする東西二経路が中世に再合流した姿**として読まれる。

→ 詳細：[[大山積神社]]・[[三嶋大明神：事代主神か大山祇神か─伊豆・伊予の祭神論争と阿波]]

## 12. 留保（中立的併記）

> [!warning] 注意
> 本ノートは三嶋大社の通説情報と阿波説固有の解釈を併記する。両者の境界を以下に整理する。

### 12-1. 祭神論争の未決着

- **三嶋大明神＝事代主神 vs 大山祇神** は数百年来の論争事項であり、現在も決着していない。三嶋大社は両神を併祀して「三嶋大明神」と総称する。本ノートはこの併存を前提に、伊豆系の阿波接続を主軸としつつ、伊予系（大山祇）を対比軸として扱う。
- 阿波説は両系を排他的に扱わず「両系の母胎が阿波にある」とする止揚的立場を取るが、これは阿波説固有の解釈である。

### 12-2. 阿波説固有の解釈に関する留保

- **后神「阿波命」を阿波国そのものに直結させる**解釈は阿波説の観点による。一般には伊豆諸島固有の地母神・海神とする見方もある。
- **「物忌奈命」を阿波忌部の祭祀権の表象とする**解釈は阿波説固有。一般には伊豆諸島の祭祀斎戒の神格化とする見方が主流。
- 阿波の事代主祭祀から伊豆諸島への東遷ルートは仮説段階であり、考古学的物証は限定的。

### 12-3. 『三宅記』成立年代

- **『三宅記』は中世（12世紀以降）成立**の縁起であり、記載内容を古代の史実として直ちに扱えない。
- 考古学的には第一画期（7〜8世紀）の海人祭祀がその母胎とされる（深澤太郎）。神話の成立は新しくとも、その母胎は古代の海人祭祀に遡る、というのが阿波説と考古学の整合点。

### 12-4. 神津島の名の由来

- 神津島の名は「**神集島（神々が集う島）**」とする伝承もあり、阿波忌部専用の島であったわけではない。
- 「阿波命神社」「物忌奈命神社」の存在は阿波接続を強く示唆するが、神津島祭祀の全体性は阿波忌部以外の海人ネットワーク（阿曇・住吉など）も関与した可能性がある。

### 12-5. 信頼度の自己評価

- 本ノートの evidence_type は **"primary_source_based"**（『延喜式』『続日本後紀』『日本三代実録』『三宅記』『吾妻鏡』に依拠）、confidence は **4**（基本情報・社格・延喜式記載・神階奉授・源頼朝挙兵故事は一次史料で確実）。
- 一方、祭神論争そのものは未決着であり、「**三嶋大明神＝事代主神（阿波系）**」という核心命題の confidence は 3 程度に留まる（祭神論争の未決着・伊予系との対立・『三宅記』の中世成立を勘案）。
- 基本情報部分と仮説部分の信頼度に差があることを明示する。

### 12-6. 「日本総鎮守」称号との関係

- 伊予 [[大山積神社]] が「日本総鎮守」を称するのに対し、伊豆三嶋大社は中世武家祭祀の中枢として「**伊豆国一宮**」「**鎌倉武家総氏神**」の地位を占める。両「三嶋」の称号差は、伊予系と伊豆系の中世武家社会における役割分担を反映する。
