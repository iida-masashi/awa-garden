# 伊豆多神社（いつたのじんじゃ／現・伊豆田神社）

> [!summary] 要旨
> 土佐国幡多郡の式内小社。『延喜式』神名帳巻十に「幡多郡三座／並／小」として伊豆多神社・高知坐神社・賀茂神社が並び、原文で小社・一座を確認できる。比定社は土佐清水市下ノ加江の伊豆田神社で、現行祭神は伊豆那姫命（産土神）とされる。本社は幕末の火災で記録を失い由緒は未詳である。旧稿が主祭神とした事代主神・三嶋大神は今回照合した公開資料では確認できず、阿波説の「伊豆＝伊豆国三嶋系」読みおよび阿波海部氏の南海航路の最西端拠点論は、その前提（祭神比定）自体が未検証の仮説として扱う。

## 3. 祭神と社伝

### 3-1. 伊豆那姫命（現行祭神）

- 伊豆那姫命（いづなひめのみこと）は、土佐清水市高知山の伊豆田神社と、南国市田村地区・前浜地区の伊都多神社に祀られる女神で、『古事記』『日本書紀』には記載がない（Wikipedia「伊豆那姫命」）。
- 本社（旧称・伊豆那神社）は江戸時代幕末期に火災に遭い記録が消失したため由来は未詳だが、少なくとも室町時代以前から産土神（うぶすながみ）として信仰されていたとされる。
- 分社である前浜の伊都多神社では、脚気平癒のご利益がある「御伊都多様」として土佐一円で広く崇敬された。また南国市では、伊都多神社に祀られる伊豆那姫命は三柱の姉妹神であるとの言い伝えがある（次女神が前浜、末女神が田村）。これは南国市側の伝承であり、本社・伊豆田神社自体の社伝として確認できるものではない。

### 3-2. 旧稿の祭神比定（事代主神・三嶋大神）について

- 旧稿は主祭神を事代主神、配祀を三嶋大神（伝）としていた。しかし今回照合した資料（Wikipedia「伊豆那姫命」「伊都多神社」「土佐国の式内社一覧」）のいずれにも、伊豆田神社の祭神を事代主神・三嶋大神とする記載は確認できなかった。
- したがって事代主神・三嶋大神の比定は、典拠未確認の主張として未検証に分離する（留保1）。阿波説の意義づけ（第6節）はこの比定を前提とするため、前提自体が未検証である点に注意が必要である。
- なお事代主神が伊豆国三嶋大社の祭神「三嶋大神」に比定される説自体は他社（伊豆三島神社等）の文脈で知られるが、それを本社へ接続する根拠は今回確認できていない。

## 4. 歴史

| 時代 | 出来事 |
|---|---|
| 平安時代 | 『延喜式』神名帳（巻十）に「土佐国 幡多郡 伊豆多神社」が小社として登載（原文確認済み） |
| 室町時代以前 | 産土神として信仰されていたとされる（本社の記録は幕末の火災で消失し、それ以前の社史の詳細は未詳） |
| 江戸時代幕末期 | 本社が火災に遭い、記録が消失（Wikipedia「伊豆那姫命」） |
| 明治元年（1868） | 旧称「伊豆那神社」から「伊豆田神社」へ改称（中国語版Wikipedia「伊豆那姬命」。日本語版の裏付けは未取得、留保6） |
| 明治初期 | 近代社格では無格。住民が県社への昇格を訴請したが実現しなかった（Wikipedia「伊豆那姫命」） |
| 明治22年（1889） | 下ノ加江村・布村・久百村・立石村・鍵掛村が合併し伊豆田村が発足（Wikipedia「下ノ加江町」）。村名と本社名「伊豆田」の関係は未確認 |
| 昭和27年（1952） | 宗教法人法により神社規則が承認され、神社本庁に所属（Wikipedia「伊豆那姫命」「伊都多神社」） |
| 昭和29年（1954） | 合併により土佐清水市が発足し、現所在地となる |

## 5. 社名「伊豆多」の読みと幡多郡三座

### 5-1. 読みの分離

| 対象 | 読み | 出典 |
|---|---|---|
| 神名帳の社名 | イツタノ（伊豆多神社） | Wikipedia「土佐国の式内社一覧」 |
| 現社名 | いずた（伊豆田神社） | Wikipedia「伊都多神社」ほか |
| 祭神 | いづなひめのみこと（伊豆那姫命） | Wikipedia「伊豆那姫命」 |

神名帳読み「イツタ」と現行の「いずた」は音がずれており、旧稿の aliases にあった「イツタ」は神名帳側の読みである。現社の読みは「いずたじんじゃ」。

### 5-2. 「伊豆」の語源（諸説はいずれも未検証）

旧稿は (1) 厳（いつ）＝聖性を表す美称、(2) 伊豆国の三嶋大神との関連、(3) 地名由来、の三説を並立させていた。今回照合した公開資料では、いずれの説についても本社に関する典拠を確認できなかった。したがって三説とも未検証の列挙として残し、優劣を断定しない（留保2）。

### 5-3. 幡多郡三座の分布（静的表）

『延喜式』巻十原文では、幡多郡は「三座／並／小」で、伊豆多神社・高知坐神社・賀茂神社の順に並ぶ。

| 式内社 | 比定社 | 所在地 |

| 伊豆多神社 | 伊豆田神社 | 土佐清水市下ノ加江 |
| [[高知坐神社]] | 高知坐神社 | 宿毛市平田町戸内（同郡ノートによる） |

## 6. 阿波説における意義

> 以下は阿波説の解釈であり、事実として確認された内容ではない。特に 6-1・6-2 は、留保1の通り未検証の祭神比定（事代主神）を前提とする。

### 6-1. 阿波海部航路の最西端論

- 阿波説では、土佐幡多郡を阿波海部氏が南海航路（紀伊・伊豆・九州）と接続する祭祀拠点群と位置付け、本社をその最西端（最遠到達点）と読む。
- 「伊豆」を伊豆国の三嶋大神（事代主）と読めば、阿波海部の航路が遠く伊豆まで及んだ祭祀的痕跡となる、という読みである。ただし前提となる祭神比定・社名語源はいずれも未検証である。

### 6-2. 事代主・葛城系祭祀の共有論

- 阿波説では、事代主神を葛城・賀茂系の神格とし、土佐郡の[[葛木男神社]]・[[都佐坐神社]]系祭祀と祭神を共有すると読む。
- 本社の現行祭神が伊豆那姫命である以上、この共有論は本社については成立根拠を欠く。解釈としてのみ併記する。

### 6-3. 補陀洛渡海との接続論

- 旧稿は、本社が中世以降に修験・補陀洛渡海（南方浄土信仰）と習合し、空海の入定・補陀洛渡海伝承とも関連したと述べた。しかし今回照合した資料では、本社と補陀洛渡海の接続を確認できなかった（留保5）。足摺岬周辺が補陀洛渡海の舞台となったこと自体は一般に知られるが、本社との直接の関係は未検証である。
