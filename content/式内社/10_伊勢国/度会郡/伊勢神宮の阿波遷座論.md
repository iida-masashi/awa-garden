# 伊勢神宮の阿波遷座論

阿波説の **最重要命題**：「**伊勢神宮（内宮・外宮）の祭神は、阿波・名方郡を本貫とする祭祀が、崇神・垂仁朝の遷座を経て伊勢に至った結果である**」。本ノートは、内宮・外宮それぞれの遷座ルートと、阿波元宮論を統合する **理論ハブ** である。

> 📚 親ハブ: [[伊勢国の式内社一覧]] / [[元伊勢笠縫邑の比定論_阿波・名方郡説]] / [[元宮ハブ_MOC]]

## 1. 核心命題

```
【内宮系】
  阿波・名方郡（天石門別八倉比売神社／上一宮大粟神社／佐古天一神社）
     ↓ 崇神6年・豊鋤入姫命に託す
  「倭笠縫邑」（阿波・佐古地＝旧伊勢郡 もしくは 名方郡内）
     ↓ 33年間奉仕後、垂仁朝に倭姫命が継ぐ
  90年の御杖代巡幸（阿波 → 丹波・丹後 → 大和 → 伊賀 → 近江 → 美濃 → 尾張 → 伊勢）
     ↓
  伊勢国度会郡・五十鈴川上流（内宮）

【外宮系】
  阿波・海陽町和奈佐（羽衣伝説の地・寺山古墳群）
     ↓
  阿波・板野郡 岡上神社（北阿波拠点・豊受姫＝大宜都比売）
     ↓
  丹後 多久神社／比沼麻奈為神社／籠神社
     ↓ 雄略22年・天照大神の託宣により遷座
  伊勢国度会郡・山田原（外宮）
```

## 2. 内宮系の遷座ルート

### 2-1. 阿波の三大元宮候補

| 候補社 | 所在 | 阿波説の位置付け |
|---|---|---|
| [[天石門別八倉比売神社]] | 徳島市国府町 矢野神山 | 天照大神（大日孁尊）の **真陵**。御本記・五角形祭壇・杉尾古墳（卑弥呼陵説） |
| [[上一宮大粟神社]] | 名西郡神山町 | **大宜都比売命** ＝ 倭大国魂神 の本貫。崇神朝の宮中祭祀の母体 |
| 佐古天一神社 | 名東郡佐那河内村 佐古（旧「伊勢郡」） | 天照＋月読＋大星神の三柱。812年（伝）遷座記録。**式内未選定**（あえて外された説） |

### 2-2. 倭笠縫邑＝阿波説の根拠

→ [[元伊勢笠縫邑の比定論_阿波・名方郡説]] に詳述。要点：

- **「伊勢郡」の地名**：江戸初期まで佐那河内村・徳島市南部・石井町一部は「伊勢郡」と呼ばれていた（県立図書館所蔵史料）
- **「天一」→「太一」改変説**：伊勢神宮式年遷宮で大工が背負う「太一」は、阿波の「天一」（天の第一の神＝天照大神）が伊勢遷座時に改変された
- **「式（しき）」の語源**：「磯城瑞籬宮」の「式」は川辺・河川敷の慣用字。阿波・半田川流域（吉野川南岸つるぎ町半田）に「天皇」地名が現存
- **30箇所以上の元伊勢比定地の並立**：通説の元伊勢候補は決定打を欠き、阿波説に道を開く

### 2-3. 倭姫命の90年巡幸

『倭姫命世記』が記す巡幸ルートは、通説では大和を出発点とするが、阿波説では：

| 段階 | 通説 | 阿波説 |
|---|---|---|
| 出発 | 大和・笠縫邑 | **阿波・佐古地 or 名方郡** |
| 中継1 | 丹波 籠神社（真名井） | 同じ |
| 中継2 | 大和・伊賀・近江・美濃・尾張 | 同じ |
| 終着 | 伊勢国度会郡 五十鈴川上流 | 同じ |

→ **「終着」は両説で一致**。対立点は「**出発点はどこか**」にある。

### 2-4. 内宮元宮論：瀧原宮・伊雑宮

- [[瀧原宮]]（度会郡大紀町）：内宮鎮座以前に倭姫命が一時祀ったとされる「**元宮の一つ**」
- [[伊雑宮]]（志摩国答志郡）：内宮系統の別宮で、独自の海人族伝承を持つ。阿波の海部氏ネットワークと接続

## 3. 外宮系の遷座ルート

### 3-1. 阿波最古層：海陽町和奈佐

『丹後国風土記』逸文「奈具の社」に登場する **和奈佐老父・和奈佐老女** の名が、阿波・海陽町鞆浦字 **那佐**（旧 和奈佐）と一致する。この地には **寺山古墳群**（3世紀初頭）があり、天女＝豊受大神の墓と推定される。

→ 詳細：羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

### 3-2. 北阿波拠点：岡上神社

板野郡の [[岡上神社]] は、阿波説における外宮元宮論の北阿波拠点。祭神 **豊受姫命 ＝ ウカノミタマ ＝ 大宜都比売命** の三神同体構造を保つ。

→ 詳細：[[岡上の聖域と吉野川北岸の祭祀]]

### 3-3. 丹後経由

- **多久神社**（京丹後市）：豊宇賀能咩命 ＝ 天酒大明神
- **比沼麻奈為神社**（京丹後市）：丹後における豊受大神の本貫候補
- **籠神社**（宮津市）：海部氏の祭祀拠点。伝世内行花文長宜子孫八葉鏡

→ 詳細：[[豊受大神：丹後多久神社と阿波の元宮論]]

### 3-4. 雄略22年の遷座

『止由気宮儀式帳』：雄略天皇の夢に天照大神が現れ、「丹波の比治真奈井から等由気太神を呼べ」と託宣 → 外宮鎮座。

阿波説の解釈：**丹波経由は事実**だが、その **上流（最古層）として阿波** がある。通説と阿波説は **排他的ではなく層的に整合する**。

## 4. 物的証拠

### 4-1. 内行花文鏡

| 出土地 | 内容 |
|---|---|
| 阿波・海陽町 寺山古墳群 | **内行花文鏡** 出土。3世紀初頭 |
| 丹後・籠神社 | **伝世内行花文長宜子孫八葉鏡**（海部氏所伝） |
| 阿波・八倉比売神社周辺 | 杉尾古墳ほか弥生末〜古墳前期の祭祀群 |

→ 同型遺物が **阿波 → 丹後 → 伊勢** の遷座ルートを物的に裏付ける。

### 4-2. 麁服（あらたえ）の貢進

- 大嘗祭の **麁服**（麻織物）は現在も **阿波忌部** 末裔（三木家）が貢進
- 伊勢神宮成立以前から阿波忌部が朝廷祭祀を担当していた証左
- → [[阿波忌部氏伝承詳細]]

### 4-3. 五角形祭壇

天石門別八倉比売神社奥之院の **五角形祭壇** は、伊勢神宮の祭祀構造（内宮本宮の心御柱を中心とする方位配置）と機能的に呼応する。

## 5. 「明治まで天皇は伊勢に参拝しなかった」問題

ANYA(終章)：歴代天皇は **明治天皇** まで伊勢神宮に親拝しなかった。

阿波説の解釈：

| 観点 | 内容 |
|---|---|
| 本来の祭祀重心 | 阿波の麁服貢進地・大嘗祭儀礼 |
| 伊勢の位置付け | 「分け御霊」の遷座先。奉幣で足りる |
| 明治期の再定置 | 国家神道整備により伊勢が「皇祖神の本宮」化 |

→ 詳細：[㉞終章『歴代天皇は なぜ明治まで伊勢神宮に参拝しなかったのか』](https://www.youtube.com/watch?v=3LNDn5cULv0)

## 6. 内宮・外宮の二重構造

伊勢神宮の内宮（天照大神）・外宮（豊受大神）の二重構造は、阿波の祭祀構造の **そのまま遷座** と解される：

| 阿波 | 伊勢 |
|---|---|
| 天石門別八倉比売神社（天照大神） | 内宮（天照大神） |
| 上一宮大粟神社（大宜都比売命 ＝ 豊受） | 外宮（豊受大神） |
| 佐那縣（天手力男命） | 佐那神社（多気郡）／内宮相殿 |
| 佐古天一神社（天照＋月読＋大星神） | 月読宮・月読荒御魂宮 |

→ 全体構造の **同型性** は、偶然ではなく **構造移転** と解するのが阿波説の立場。

## 7. 通説との対立点と整合性

| 論点 | 通説 | 阿波説 | 整合可能性 |
|---|---|---|---|
| 内宮本貫 | 大和（笠縫邑）→ 伊勢 | 阿波 → 大和 → 伊勢 | 阿波を「上流」として加える形で整合 |
| 外宮本貫 | 丹波・比治真奈井 → 伊勢 | 阿波・和奈佐 → 丹後 → 伊勢 | 同上 |
| 倭姫命の出発点 | 大和 | 阿波 | 対立 |
| 神宝（八咫鏡） | 神代に由来 | 阿波由来の鏡が遷座 | 補完 |
| 神宮の創建年代 | 垂仁26年（伝） | 同 | 一致 |

→ 阿波説は **「終着の伊勢」は否定しない**。あくまで **「起点・本貫の所在」** が争点。
