# 伊勢神宮の阿波遷座論

阿波説の **最重要命題**：「**伊勢神宮（内宮・外宮）の祭神は、阿波・名方郡を本貫とする祭祀が、崇神・垂仁朝の遷座を経て伊勢に至った結果である**」。本ノートは、内宮・外宮それぞれの遷座ルートと、阿波元宮論を統合する **理論ハブ** である。

> 📚 親ハブ: [[伊勢国の式内社一覧]] / [[元伊勢笠縫邑の比定論_阿波・名方郡説]] / [[元宮ハブ_MOC]]

## 1. 核心命題

```
【内宮系】
  阿波・名方郡（天石門別八倉比売神社／上一宮大粟神社／佐古天一神社（未検証））
     ↓ 崇神6年・豊鋤入姫命に託す
  「倭笠縫邑」（阿波・佐古地＝旧「伊勢郡」（未検証） もしくは 名方郡内）
     ↓ 『倭姫命世記』の伝承では33年間奉仕後、垂仁朝に倭姫命が継ぐ
  倭姫命の御杖代巡幸（阿波 → 丹波・丹後 → 大和 → 伊賀 → 近江 → 美濃 → 尾張 → 伊勢）※期間は未検証（留保参照）
     ↓
  伊勢国度会郡・五十鈴川上流（内宮）

【外宮系】
  阿波・海陽町和奈佐（羽衣伝説の地。寺山古墳群の年代・出土品は未検証）
     ↓
  阿波・板野郡 岡上神社（北阿波拠点・祭神 豊受姫命）
     ↓
  丹後 多久神社／比沼麻奈為神社／籠神社
     ↓ 雄略22年・天照大神の託宣により遷座
  伊勢国度会郡・山田原（外宮）
```

## 2. 内宮系の遷座ルート

### 2-1. 阿波の三大元宮候補

| 候補社 | 所在 | 阿波説の位置付け |
|---|---|---|
| [[天石門別八倉比売神社]] | 徳島市国府町 矢野神山 | 主祭神 大日孁尊。式内社「天石門別八倉比売神社（大）」の**論社の一つ**。「天照大神の真陵」説・杉尾古墳（卑弥呼陵説）は仮説（照合済みの親ノートでも留保済み） |
| [[上一宮大粟神社]] | 名西郡神山町 | 主祭神 **大宜都比売命**（阿波国の国魂神）。「大宜都比売命 ＝ 倭大国魂神」は同一視の主張であり断定できない |
| 佐古天一神社 | 名東郡佐那河内村 佐古（旧「伊勢郡」） | **未検証**：存在・祭神（天照＋月読＋大星神の三柱）・812年（伝）遷座記録・「式内未選定（あえて外された）」説のいずれも公的資料で確認できず。佐那河内村の公式資料に載るのは天岩戸別神社（別称・三社皇太神宮）で別物 |

### 2-2. 倭笠縫邑＝阿波説の根拠

→ [[元伊勢笠縫邑の比定論_阿波・名方郡説]] に詳述。要点：

- **「伊勢郡」の地名**（未検証）：江戸初期まで佐那河内村・徳島市南部・石井町一部は「伊勢郡」と呼ばれていたとする説。ただし公的資料で「伊勢郡」の実在は確認できず、実在した「**以西郡**（いさいぐん。鎌倉時代中期〜寛文4年（1664年）。『阿波国十三郡郷村田畠高辻帳』では佐那河内・佐我も以西郡とする）」との混同の可能性が高い
- **「天一」→「太一」改変説**（未検証）：伊勢神宮式年遷宮で大工が背負う「太一」は、阿波の「天一」（天の第一の神＝天照大神）が伊勢遷座時に改変されたとする阿波説系の説。公的資料で確認できず
- **「式（しき）」の語源**（未検証）：「磯城瑞籬宮」の「式」は川辺・河川敷の慣用字とする説。阿波・半田川流域（吉野川南岸つるぎ町半田）に「天皇」地名が現存するとされるが、いずれも公的資料で確認できず
- **元伊勢比定地の並立**：元伊勢候補の数（旧稿の「30箇所以上」）は概数に諸説があり確定できない。通説の元伊勢候補は決定打を欠き、阿波説に道を開くとするのが阿波説の立場

### 2-3. 倭姫命の巡幸

『倭姫命世記』（鎌倉時代成立の伊勢神道書）が記す巡幸ルートは、通説では大和を出発点とするが、阿波説では：

※旧稿の見出しにあった巡幸期間「90年」は公的資料で確認できず（一般に引かれるのは約20年）、未検証として留保に分離した。笠縫邑での奉仕「33年」は『倭姫命世記』系の伝承に基づく数値であり、史実として確定したものではない。

| 段階 | 通説 | 阿波説 |
|---|---|---|
| 出発 | 大和・笠縫邑 | **阿波・佐古地 or 名方郡** |
| 中継1 | 丹波 籠神社（真名井） | 同じ |
| 中継2 | 大和・伊賀・近江・美濃・尾張 | 同じ |
| 終着 | 伊勢国度会郡 五十鈴川上流 | 同じ |

→ **「終着」は両説で一致**。対立点は「**出発点はどこか**」にある。

### 2-4. 内宮元宮論：瀧原宮・伊雑宮

- [[瀧原宮]]（度会郡大紀町）：内宮鎮座以前に倭姫命が一時祀ったとされる「**元宮の一つ**」
- [[伊雑宮]]（志摩国答志郡）：内宮系統の別宮で、独自の海人族伝承を持つ。阿波の海部氏ネットワークと接続

## 3. 外宮系の遷座ルート

### 3-1. 阿波最古層：海陽町和奈佐

『丹後国風土記』逸文「奈具の社」に登場する **和奈佐老夫（わなさおきな）・和奈佐老婦（わなさおうな）** の名が、阿波・海陽町鞆浦字 **那佐**（旧 和奈佐）と音が一致する。ただし逸文の舞台は丹後国丹波郡比治の里（比治山＝磯砂山、現・京丹後市峰山町）であり、阿波との結びつきは音の一致のみに基づく阿波説の解釈である。この地に **寺山古墳群**（3世紀初頭）があり天女＝豊受大神の墓と推定されるとする記述は、公的資料で確認できず未検証（留保参照）。

→ 詳細：羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

### 3-2. 北阿波拠点：岡上神社

板野郡の [[岡上神社]] は、阿波説における外宮元宮論の北阿波拠点。祭神は **豊受姫命**。**豊受姫命 ＝ 宇迦之御魂神 ＝ 大宜都比売命** の三神同体論は『御鎮座伝記』（神道五部書）に基づく解釈であり、記紀・神名帳の裏付けはない（照合済みの親ノートでも blog_hypothesis として扱われている）。

→ 詳細：[[岡上の聖域と吉野川北岸の祭祀]]

### 3-3. 丹後経由

- **多久神社**（京丹後市峰山町丹波）：主祭神 **豊宇賀能売命**（別名・豊受大神）。羽衣天女伝承により天酒大明神とも称された。式内社（丹波郡「多久ノ神社」小社）
- **比沼麻奈為神社**（京丹後市峰山町久次）：主祭神 豊受大神。式内社「比治真名井神社」の比定社で、元伊勢とも称される。「豊受大神の本貫候補」とするのは社伝的主張として扱う
- **籠神社**（宮津市）：式内名神大・丹後国一宮・元伊勢。海部氏が宮司を世襲する祭祀拠点。伝世鏡は内行花文長宜子孫八葉鏡（後漢）ほか辺津鏡（内行花文昭明鏡・前漢）の2面で、いずれも**伝世品であり出土品ではない**

→ 詳細：[[豊受大神：丹後多久神社と阿波の元宮論]]

### 3-4. 雄略22年の遷座

『止由気宮儀式帳』：雄略天皇の夢に天照大神が現れ、「丹波の比治真奈井から等由気太神を呼べ」と託宣 → 外宮鎮座。鎮座年は神宮伝承で雄略天皇22年（478年）7月とされる（『止由気宮儀式帳』（804年）自体は年を記さず、『大神宮諸雑事記』は夢託を21年・遷座を22年とする）。

阿波説の解釈：**丹波経由は事実**だが、その **上流（最古層）として阿波** がある。通説と阿波説は **排他的ではなく層的に整合する**。

## 4. 物的証拠

### 4-1. 内行花文鏡

| 出土地・所蔵 | 内容 |
|---|---|
| 阿波・海陽町 寺山古墳群 | **内行花文鏡** が出土し3世紀初頭に遡るとされるが、公的資料で確認できず**未検証** |
| 丹後・籠神社 | **伝世内行花文長宜子孫八葉鏡**（後漢・海部氏所伝）ほか辺津鏡（内行花文昭明鏡・前漢）の2面。いずれも伝世品 |
| 阿波・八倉比売神社周辺 | 杉尾古墳ほか弥生末〜古墳前期の祭祀群 |

→ 籠神社の伝世鏡の実在は確認できるが、伝世品である以上「同型遺物が **阿波 → 丹後 → 伊勢** の遷座ルートを物的に裏付ける」とするのは推論であり、阿波説の解釈として分離する。

### 4-2. 麁服（あらたえ）の貢進

- 大嘗祭の **麁服**（麻織物）は現在も **阿波忌部** 直系末裔の三木家（美馬市木屋平）が御衣御殿人として調進する。最古級の記録は『古語拾遺』（807年）。大正期に約580年ぶりに復活し、平成・令和の大嘗祭でも調進された
- 「伊勢神宮成立以前から阿波忌部が朝廷祭祀を担当していた証左」とするのは阿波説の解釈であり、事実として確認できる範囲は上記の調進の伝統までである
- → [[阿波忌部氏伝承詳細]]

### 4-3. 五角形祭壇

天石門別八倉比売神社には **五角形の磐座** が存在する（Wikipediaで確認）。これが伊勢神宮の祭祀構造（内宮本宮の心御柱を中心とする方位配置）と「機能的に呼応する」とするのは阿波説の解釈である。

## 5. 「明治まで天皇は伊勢に参拝しなかった」問題

歴代天皇は **明治天皇** まで伊勢神宮に親拝しなかった（明治天皇の初参拝は明治2年（1869年）4月23日で史上初）。ただし本節の出典はANYAのYouTube動画のみであり、この点は留保に記録する。

阿波説の解釈：

| 観点 | 内容 |
|---|---|
| 本来の祭祀重心 | 阿波の麁服貢進地・大嘗祭儀礼 |
| 伊勢の位置付け | 「分け御霊」の遷座先。奉幣で足りる |
| 明治期の再定置 | 国家神道整備により伊勢が「皇祖神の本宮」化 |

→ 詳細：㉞終章『歴代天皇は なぜ明治まで伊勢神宮に参拝しなかったのか』

## 6. 内宮・外宮の二重構造

伊勢神宮の内宮（天照大神）・外宮（豊受大神）の二重構造は、阿波の祭祀構造の **そのまま遷座** と解される（以下は阿波説の解釈。通説の併記は留保参照）：

| 阿波 | 伊勢 |
|---|---|
| 天石門別八倉比売神社（天照大神） | 内宮（天照大神） |
| 上一宮大粟神社（大宜都比売命 ＝ 豊受） | 外宮（豊受大神） |
| 佐那縣（天手力男命） | 佐那神社（多気郡）／内宮相殿 |
| 佐古天一神社（天照＋月読＋大星神） | 月読宮・月読荒御魂宮 |

→ 全体構造の **同型性** は、偶然ではなく **構造移転** と解するのが阿波説の立場。

## 7. 通説との対立点と整合性

| 論点 | 通説 | 阿波説 | 整合可能性 |
|---|---|---|---|
| 内宮本貫 | 大和（笠縫邑）→ 伊勢 | 阿波 → 大和 → 伊勢 | 阿波を「上流」として加える形で整合 |
| 外宮本貫 | 丹波・比治真奈井 → 伊勢 | 阿波・和奈佐 → 丹後 → 伊勢 | 同上 |
| 倭姫命の出発点 | 大和 | 阿波 | 対立 |
| 神宝（八咫鏡） | 神代に由来 | 阿波由来の鏡が遷座 | 補完 |
| 神宮の創建年代 | 垂仁25年（伝。26年説も一部にある） | 同 | 一致 |

→ 阿波説は **「終着の伊勢」は否定しない**。あくまで **「起点・本貫の所在」** が争点。

### 確認できた事実

- 崇神天皇6年：『日本書紀』に、天照大神を豊鍬入姫命（豊鋤入姫命）に託し**倭（大和）の笠縫邑**に祀ったとある。笠縫邑が阿波にあるとするのは阿波説の主張であり、書紀の記述ではない。
- 垂仁天皇25年3月：『日本書紀』に、倭姫命に託されて伊勢に鎮座したとある。
- 外宮鎮座は神宮伝承で雄略天皇22年（478年）7月。『止由気宮儀式帳』（804年）自体は年を記さない。
- 明治天皇の伊勢神宮初参拝は明治2年（1869年）4月23日で、史上初の天皇親拝である。
- 籠神社の海部氏伝世鏡2面（辺津鏡＝内行花文昭明鏡・前漢／息聿鏡＝内行花文長宜子孫八葉鏡・後漢）は実在するが、いずれも伝世品であり出土品ではない。
- 多久神社（主祭神 豊宇賀能売命、式内社）・比沼麻奈為神社（主祭神 豊受大神、式内社「比治真名井神社」の比定社）の基本情報。
- 麁服は阿波忌部直系末裔の三木家が大嘗祭に調進する伝統があり、『古語拾遺』（807年）が最古級の記録である。
- 天石門別八倉比売神社に五角形の磐座が存在する。

2. **笠縫邑での奉仕「33年」**：『倭姫命世記』（鎌倉時代成立の伊勢神道書）系の伝承に基づく数値であり、史実として確定したものではない。伝承として扱う。
3. **佐古天一神社**：存在・祭神（天照＋月読＋大星神の三柱）・812年（伝）遷座記録・「式内未選定（あえて外された）」説のいずれも公的資料で確認できず、未取得。佐那河内村の公式観光資料に載る天岩戸別神社（別称・三社皇太神宮、祭神 天手力雄神・天照皇太神・豊受皇太神）とは別物である。
4. **「伊勢郡」の地名**：公的資料で確認できず、未取得。実在したのは「以西郡」（鎌倉時代中期〜寛文4年（1664年））であり、「伊勢郡」は以西郡との混同の可能性が高い。
5. **寺山古墳群（海陽町）・内行花文鏡の出土・3世紀初頭の年代**：公的資料で確認できず、未取得。
6. **「太一→天一」改変説・「式（しき）」語源説・半田の「天皇」地名**：阿波説系由来の説であり、公的資料で確認できていない。
7. **元伊勢候補「30箇所以上」**：概数には諸説があり確定できない。
8. **三神同体論（豊受姫命＝宇迦之御魂神＝大宜都比売命）**：『御鎮座伝記』（神道五部書）に基づく解釈であり、記紀・神名帳の裏付けはない。岡上神社の祭神は豊受姫命。
9. **天石門別八倉比売神社の「真陵」説・杉尾古墳の卑弥呼陵説／上一宮大粟神社の「大宜都比売命＝倭大国魂神」同一視**：いずれも仮説であり、照合済みの各親ノートでも留保されている。

11. **§6の阿波↔伊勢対応表**：阿波説の解釈である。通説では『古事記』の「手力男神者、坐佐那那県也」の佐那県は伊勢国佐那郡（多気郡）とされ、佐那神社は式内社「佐那神社二座」（主祭神 天手力男命・曙立王命）で、天手力男命は内宮の相殿神である。阿波・佐那河内村にも佐那県伝承がある。
12. **和奈佐の名の一致**：『丹後国風土記』逸文の舞台は丹後国丹波郡比治の里であり、天女は竹野郡奈具村に留まって豊宇賀能売命として奈具神社（京丹後市弥栄町船木）に祀られたとされる。阿波・海陽町那佐との結びつきは音の一致のみに基づく。
