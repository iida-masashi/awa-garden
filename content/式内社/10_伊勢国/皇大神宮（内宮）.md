# 皇大神宮（内宮）

**皇大神宮（こうたいじんぐう／内宮）** は伊勢国度会郡宇治（現・三重県伊勢市宇治館町）の **五十鈴川上流** に鎮座する、**天照坐皇大御神（天照大神）** を奉斎する社。延喜式神名帳に「**皇太神宮 三座**」と載る式内大社・名神大社にして、神宮125社の中心。日本の神社制度における最高位の宗廟であり、阿波説では **崇神朝に阿波・名方郡から離された天照大神** が、垂仁朝の倭姫命の御杖代巡幸を経て鎮座した「**遷座先**」と位置づけられる。

## 祭神と神話的背景

主祭神 **天照坐皇大御神** は『古事記』『日本書紀』において伊邪那岐命の左眼から生まれた太陽神であり、天孫降臨に際して瓊瓊杵尊に **八咫鏡** を授け「**この鏡を私と思って斎き祀れ**」と命じた。崇神朝までは天皇宮中に祀られていたが、その神威が強すぎたために宮中外に出された（『日本書紀』崇神6年）。

相殿には **天手力男神**（天岩戸を引き開けた力神）と **万幡豊秋津姫命**（瓊瓊杵尊の母）が祀られる。阿波説では天手力男神は [[佐那神社]]（多気郡）および阿波の **佐那縣**（佐那河内村）との対応で論じられる（→ [[天手力男命：佐那縣の主神と天岩戸の力業]]）。

## 歴史

### 1. 創建伝承

『倭姫命世記』『皇太神宮儀式帳』等の中世史料：

- 崇神6年：天照大神を **豊鋤入姫命** に託し、**倭笠縫邑** に祀る
- 豊鋤入姫命が33年間奉仕、各地を巡幸
- 垂仁朝に **倭姫命** が引き継ぎ、近江・美濃・尾張等を経て伊勢国に至る
- 五十鈴川上流で「**この国にいたい**」との大神の託宣により鎮座
- 垂仁26年（伝）に現在地に内宮を造営

### 2. 式年遷宮

天武朝に制定、持統4年（690）に第1回が行われ、以後20年ごとに **東御敷地・西御敷地** を交互に用いて社殿を造り替える。応仁の乱期や戦国期に中断はあるが、現代まで継続。

### 3. 神宮の組織と125社

- **両正宮**：内宮（皇大神宮）・外宮（豊受大神宮）
- **別宮**：内宮10宮・外宮4宮
- **摂社・末社**：内宮系・外宮系
- **所管社**：祭祀補助の社
- 合計 **125社** で「神宮」を構成

## 阿波説における意義

### 1. 内宮は「遷座の終着点」であって本貫ではない

阿波説の中核命題は、**天照大神の本貫は阿波・名方郡** にあり、内宮は **垂仁朝の遷座** の終着点に過ぎないという立場である。具体的には：

| 段階 | 阿波説の見立て |
|---|---|
| 本貫 | [[天石門別八倉比売神社]]（徳島市国府町）／[[上一宮大粟神社]]（神山町） |
| 崇神朝の遷座 | 倭笠縫邑 = **佐古天一神社**（佐那河内村佐古、旧「伊勢郡」）／上一宮大粟神社周辺 |
| 垂仁朝の巡幸 | 阿波 → 丹波・丹後（籠神社・多久神社） → 大和 → 伊賀 → 近江 → 美濃 → 尾張 → 伊勢 |
| 終着 | 伊勢国度会郡五十鈴川上流（現・内宮） |

### 2. 八咫鏡と阿波

天孫降臨に際して瓊瓊杵尊に授けられた **八咫鏡** は、内宮の神体である。阿波説では：

- 阿波 [[天石門別八倉比売神社]] の奥之院・五角形祭壇に古来「鏡」が奉斎されていたとする伝承
- 籠神社の **伝世内行花文長宜子孫八葉鏡**（海部氏所伝）が、阿波 → 丹後 → 伊勢の遷座ルートを物的に裏付ける論点
- 海陽町・寺山古墳群出土の **内行花文鏡** が、大陸交易を物語る同型遺物として注目される

→ 詳細：[[豊受大神：丹後多久神社と阿波の元宮論]]・羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

### 3. 「五十鈴川」の地名対応

阿波説では「**五十鈴**」の地名・神名素を阿波内に求める議論がある。阿波忌部関連の祭祀地に「鈴」「五十」が複合する事例（猪鼻・五十嵐・佐那等）と、内宮の五十鈴川との対応は **倭姫命巡幸の連続性** を示す傍証とされる。

### 4. 「歴代天皇は明治まで伊勢に参拝しなかった」問題

ANYA(終章)が提起する有名な論点：歴代天皇は **明治天皇** が初めて伊勢神宮に親拝するまで、伊勢を直接参拝しなかった。阿波説の解釈：

- 本来の天照大神の祭祀地は阿波であり、伊勢は「分け御霊」の遷座先に過ぎない
- 朝廷の祭祀重心は **大嘗祭の麁服貢進地・阿波** にあり、伊勢は奉幣による間接祭祀で足りた
- 明治期の国家神道整備により、伊勢が「皇祖神の本宮」として再定置された

→ 出典：㉞終章『歴代天皇は なぜ明治まで伊勢神宮に参拝しなかったのか』

### 5. 内宮・外宮二重構造と阿波の祖霊祭祀

- 内宮（天照大神）／外宮（豊受大神）の二重構造は、阿波の **天石門別八倉比売（天照）／大宜都比売（豊受）** の二重祭祀構造と対応
- いずれも「**太陽神＋食物・穀霊神**」の二極祭祀
- 阿波の祖霊祭祀（太龍寺奥之院 系の山岳祭祀）にも同じ二重構造が見られる

## 阿波説：詳細展開

### A. 「磯輪上乃秀真国是阿波国也」── 太龍寺縁起と阿波本宮論

『舎心山太龍寺縁起』には、**「磯輪上乃秀真国（しわかみのほつまのくに）是阿波国也」** とある。「磯輪上の秀真国」は『日本書紀』神武紀において饒速日命が天磐船で降臨した国、すなわち日本国の美称として用いられる句であり、これを **阿波国** と断ずる中世寺院縁起の存在は、阿波が古代において「日本の本貫」として認識されていたことの傍証とされる。

阿波説の見立てでは：

- 「磯輪上＝石上＝石門（いわと）」と読む系譜があり、**天石門別（あめのいわとわけ）** の神名と地名素を共有する
- 「秀真（ほつま）」は穀霊・稲魂の意。**大宜都比売命** の祭祀地（[[上一宮大粟神社]]）と意味的に符合する
- 太龍寺は阿南市加茂町の **舎心嶽** にあり、空海修行の地として「**虚空蔵求聞持法**」の発祥地。神仏習合期に阿波元宮論の物語が寺院縁起として固定された

→ この縁起は **内宮の本貫が阿波である** ことを、神社側ではなく **仏教側の文献**（中世期）から傍証する稀有な史料である。

### B. 三種の神器の阿波起源論

内宮の神体は **八咫鏡**。阿波説では三種の神器それぞれが阿波と接続するとされる：

| 神器 | 通説 | 阿波説の対応 |
|---|---|---|
| **八咫鏡** | 内宮神体 | [[天石門別八倉比売神社]] 奥之院・五角形祭壇の鏡奉斎伝承／海陽町寺山古墳群出土の内行花文鏡 |
| **天叢雲剣**（草薙剣） | 熱田神宮神体 | 阿波・忌部山系の製鉄遺跡群（阿波の製鉄遺跡群）／須佐之男命の阿波退治譚 |
| **八尺瓊勾玉** | 皇居 | 阿波・勝浦町 および 海陽町 の硬玉製勾玉出土。古代翡翠流通と阿波 |

→ 詳細：三種の神器と阿波・羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

阿波説の論理：神器三種が阿波由来であれば、それを奉斎する内宮もまた **阿波からの遷座** という結論に至る。これは「神器論」から「神社論」への論理的橋渡しを成す。

### C. 倭姫命巡幸の阿波起点論

『倭姫命世記』が記す巡幸ルートは中世神道五部書の所産だが、阿波説では巡幸の各段階に阿波の地名素・神名素が伏在するとする：

| 巡幸地（通説比定） | 阿波説における起点・対応 |
|---|---|
| 倭笠縫邑（大和磯城） | **阿波・佐古天一神社**（旧伊勢郡）／[[上一宮大粟神社]] 周辺 |
| 吉佐宮（丹波） | 丹後 籠神社 真名井神社 ── 阿波からの中継 |
| 伊豆加志本宮（大和） | 阿波経由後の再大和入り |
| 奈久佐浜宮（紀伊） | 紀伊国・名草郡 ── 阿波からの黒潮航路上 |
| 名方浜宮（吉備） | 「名方（なかた）」は阿波・名方郡の地名と同名（→ 名方郡） |
| 五十鈴川上（伊勢） | 終着 ── 両説一致 |

阿波説における **「名方浜宮」=吉備（岡山県）** の通説比定への疑義：阿波・名方郡こそが「名方」の本貫であり、巡幸譚の中に **阿波の地名がそのまま残された** 可能性が指摘される。

→ 詳細：[[元伊勢笠縫邑の比定論_阿波・名方郡説]]

### D. 「アマテラス＝大日孁貴神」の阿波における祭祀

『日本書紀』本文では天照大神の本名を **大日孁貴神（おおひるめのむちのかみ）** とする。阿波説では：

- [[天石門別八倉比売神社]] の主祭神は **大日孁尊** ── 『書紀』本文名と完全一致
- 同社の通称「**八倉乃日孁大神（やくらのひるめのおおかみ）**」は、八倉＝倉庫多数＝穀霊豊穣を司る日孁
- 内宮の神名「天照坐皇大御神」は **中世以降の整理名** であり、より古層の祭祀名は「大日孁貴」「日孁大神」である

→ 阿波説の解釈：阿波で「大日孁尊」として祀られた古層の太陽女神が、伊勢遷座後に「天照坐皇大御神」と神格化・体系化された。「天照」は称号、「大日孁」が本名である。

### E. 「五十鈴」と阿波の鈴祭祀

内宮鎮座地名「**五十鈴川**」と「**五十鈴宮**」の「五十鈴（いすず）」について、阿波説では阿波内の鈴・鐸祭祀地との対応を見る：

- 阿波・[[佐那神社]] 周辺（佐那河内村）── 古来「鈴」を神宝とする系譜
- 阿波・[[忌部神社]] 系統 ── 銅鐸鋳造ネットワーク
- 弥生末〜古墳前期の **阿波産銅鐸** の広域流通（→ 阿波銅鐸の編年と祭祀）

「五十鈴＝五十の鈴」は **古代の鈴祭祀** に淵源を持ち、その源流が阿波の鐸祭祀にあるとするのが阿波説の見立てである。ただし「五十鈴」の音は『書紀』神代下に瓊瓊杵尊巡幸地として既出する古い地名素であり、阿波対応は **音韻的傍証** に留まる。

### F. 内宮と「太一」── 阿波「天一」改変説

式年遷宮で大工棟梁が背負う **「太一（たいいち）」** の幟旗は、内宮の核心的シンボル。古代中国の北極星信仰における至高神「太一」に由来するとされる。

阿波説の見立て：

- 阿波・佐那河内村 **佐古天一神社** に伝わる「**天一（てんいち）**」が本来の表記
- 「天一」＝**天の第一の神＝天照大神** の古称
- 伊勢遷座時に道教風の「太一」へと文字を改変した

ただし「太一」「天一」の文字史を検証すると、平安期の道教受容（陰陽寮）を経由した「太一」が当時の宮廷祭祀で広く用いられており、佐古天一神社→伊勢の単純な改変関係は **史料的に直接実証されていない**。阿波説固有の解釈である。

## 一次史料の精読

### 『皇太神宮儀式帳』（延暦23年・804）

内宮側祠官・荒木田氏らが朝廷に提出した儀式帳。延喜式以前で最古の神宮成立譚を含む。要点抜粋：

- 倭姫命の御杖代巡幸経路 ── 大和を出て丹波・近江・美濃・尾張・伊勢に至る
- 五十鈴川上流での **大神の託宣**「**是の神風の伊勢国は、常世の浪の重浪帰する国、傍国の可怜国なり、是の国に居らむと欲ふ**」
- 神宮所摂社の四至 ── 摂社24座を列挙
- 神饌・神具の規定

阿波説の論点：儀式帳は出発点を「**大和**」とするが、これは804年時点の朝廷が **大和起点を公式化** したことを意味するに過ぎず、それ以前の祭祀史を否定しない。儀式帳成立より早い記録（『阿波国風土記』逸文・『先代旧事本紀』等）には阿波関連の祭祀伝承が断片的に残る。

### 『日本書紀』崇神紀・垂仁紀

崇神6年：「**国内に多く災害あり……天照大神・倭大国魂神の二神を、天皇の大殿の内に並べ祀る。然れども其の神の勢を畏れ、共に住み難し**」
→ 阿波説は **倭大国魂神 = 大宜都比売命 = [[上一宮大粟神社]]の主祭神** とし、宮中祭祀の二神並座が阿波の二大祭祀（天照／大宜都比売）の宮中投影だったとする。

崇神6年：「**乃ち天照大神を以ては、豊鋤入姫命に託けまつりて、倭の笠縫邑に祭る**」
→ 笠縫邑の比定地は奈良県磯城郡・桜井市など複数候補が乱立するが決定打を欠く。阿波説はこの「決定打の欠如」を **本来の比定地が大和外（=阿波）にある** ことの傍証とする。

垂仁25年：「**倭姫命……菟田の篠幡に詣り、又還りて近江国に入り、東美濃を廻りて、伊勢国に至る。時に天照大神、倭姫命に誨へて曰く、是の神風の伊勢国は……**」
→ 倭姫巡幸の最終段階のみが詳述され、出発からの初期経路は省略される。阿波説はこの省略部分に阿波→大和の経路が含まれていたと見る。

### 『延喜式』神名帳（927）

伊勢国度会郡条：
> 皇太神宮 三座（並名神大、月次、相嘗、新嘗）

「三座」は天照坐皇大御神＋天手力男神＋万幡豊秋津姫命に対応。月次・相嘗・新嘗の三祭預りは伊勢神宮固有の最高格祭祀。

### 『倭姫命世記』（中世神道五部書）

鎌倉期に度会氏らによって編まれた神宮神道書。倭姫命の **90年巡幸譚** を具体地名で物語化。記載の信頼性は中世神話としての扱いだが、阿波説では **巡幸地に阿波関連名（名方浜宮等）が伏在する** 点を重視する。

## 関連社：内宮の元宮候補群

### 瀧原宮（度会郡大紀町）

倭姫命が伊勢鎮座以前に一時祀ったとされる **内宮の元宮の一つ**。境内には瀧原宮・瀧原竝宮・若宮神社・長由介神社の4社が並ぶ。阿波説では、内宮鎮座前の倭姫命巡幸最終段階の比定地として重要視される。

→ 詳細：[[瀧原宮]]

### 伊雑宮（志摩国答志郡）

内宮の **遙宮（とおのみや）**。志摩国の海人族・磯部氏との結びつきが深く、阿波の海部氏ネットワーク（阿波海部氏）との比較から、阿波説では「海路を通じた阿波からの遷座経路」上の重要拠点とされる。中世には **「伊雑宮こそ真の内宮」** とする説が地元神官から提示され、江戸期に弾圧された経緯がある（伊雑宮事件・1644年）。

→ 詳細：[[伊雑宮]]

### 粟皇子神社（度会郡二見町・内宮摂社）

延喜式所載の内宮摂社。社名「**粟皇子**」を阿波説では「**阿波の御子神**」と読み解く。倭姫命の御贄定めの故事を持ち、阿波忌部・海部の黒潮ネットワークが伊勢に到達した痕跡として重要。

→ 詳細：[[粟皇子神社]]

### 留保（拡張）── 学界・通説における位置付け

> [!warning] 阿波元宮説は学界少数派である
> 本ノートで展開する阿波元宮説（内宮の本貫を阿波・名方郡とする立場）は、**現行の歴史学・神道学・考古学のいずれにおいても主流ではない**。以下、各分野での評価を中立的に整理する。

#### 1. 神道学・神宮側の公式立場

伊勢神宮神宮司庁および神道学の主流（西田長男・上田賢治ら）は、内宮の本貫を **大和（笠縫邑）→伊勢** とする『日本書紀』『皇太神宮儀式帳』の系統を公式見解とする。中世神道五部書（『倭姫命世記』ほか）は神話的体系として尊重するが、**史実としての厳密な経路復元は困難** とする立場が一般的。神宮側からは阿波元宮説への公式反応はほぼ存在しない。

#### 2. 歴史学・古代史学の評価

直木孝次郎・井上光貞・岡田精司ら戦後古代史学の主流は、伊勢神宮の成立を **7世紀後半（天武・持統朝）の国家祭祀整備** に位置付け、神話的な巡幸譚そのものを史実とは扱わない。この立場からは、本貫が大和か阿波かを問う以前に、**「倭姫命の御杖代巡幸」自体が後代の神学的構成** とされる。阿波元宮説はこの古代史学の枠組み外に位置する。

#### 3. 考古学の現状

- 内宮鎮座地周辺で **3〜4世紀の祭祀遺跡** は未発見（神宮敷地内は発掘困難）
- 阿波側では [[天石門別八倉比売神社]] 周辺・気延山 山麓に弥生末〜古墳前期の祭祀遺物・気延山古墳群 が存在するが、**伊勢遷座** を物的に証明する遺物は存在しない
- 内行花文鏡の阿波→丹後→伊勢の同型分布は **東日本一般** に広く見られ、阿波特有のルートを示すものではない

#### 4. 阿波説内部の異論

阿波説論者の間でも、内宮元宮の比定地は一致しない：

| 論者・系統 | 内宮元宮の比定 |
|---|---|
| 林博章ら | [[天石門別八倉比売神社]] を中心とする |
| 大杉博・三村隆範ら | 佐古天一神社（佐那河内村）を重視 |
| 阿波古事記研究会 | [[上一宮大粟神社]] 周辺の磯城瑞籬宮を重視 |
| 高木亀次郎ら戦前阿波説 | 阿波全土の祭祀地を統合的に解釈 |

→ 阿波説の **内部にも複数の比定地論** が並立し、単一の定説は未確立。

#### 5. 史料的限界

- 阿波元宮論の主要史料 ── 『阿波国風土記』逸文・舎心山太龍寺縁起・佐古天一神社縁起など ── は **中世以降の写本** に拠るものが多く、原本の成立年代は不明
- 御本記（八倉比売大神御本記）は **江戸期以前の伝来が確認できる物的証拠** に乏しい
- 「伊勢郡」（江戸初期の佐那河内村〜徳島市南部の旧郡名）は近世地誌に記載があるが、**古代律令制下の郡** ではない可能性が高い

#### 6. 倭姫命巡幸譚の文献批判

『倭姫命世記』は鎌倉期成立の **中世神道書** であり、巡幸地の具体地名は **その成立当時の神領・社家ネットワーク** を反映している可能性が高い。すなわち巡幸譚に含まれる地名（名方浜宮等）が阿波の地名と一致しても、それを **3〜4世紀の史実** に直結させることはできない。

#### 7. 「明治まで天皇親拝なし」問題の通説的解釈

「明治天皇まで歴代天皇が伊勢に親拝しなかった」事実は通説も認めるが、その理由を **「私幣禁断」の原則** および **奉幣使派遣による間接祭祀** に求めるのが一般的。阿波説の「祭祀重心が阿波にあった」とする解釈は、**国家神道整備以前の伊勢の独自性** を過小評価する側面もある。

#### 8. 本ノートの立場

本ノートは：

- **内宮の物理的所在・公式祭祀史**（伊勢国度会郡・8世紀以降の神宮成立）は通説に従う
- **阿波元宮論** は阿波説論者の主張として **明示的に併記** する
- 一次史料（記紀・延喜式・儀式帳）と二次史料（中世神道書・近世地誌・現代論者）を区別する
- evidence_type は **"primary_source_based"**（内宮自体の存在・式内社格は確定）
- confidence は **5**（内宮自体の祭祀的最高格としての確実性）。ただし阿波元宮論部分の確度は **★★（社伝＋系譜証拠）** に留まる
