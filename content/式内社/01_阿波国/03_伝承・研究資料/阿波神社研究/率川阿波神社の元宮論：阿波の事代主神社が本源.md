# 率川阿波神社の元宮論：阿波の事代主神社が本源

奈良市本子守町に鎮座する **率川阿波神社（いさがわあわじんじゃ）** ――大神神社（三輪山）の摂社・率川坐大神御子神社（いさがわにいますおおみわのみこじんじゃ）の境内末社で、**祭神は事代主神＋阿波咩命**。本ノートでは、阿波説におけるこの神社のルーツを **阿波の事代主神社（阿波郡・勝浦郡）** に求める論を整理する。

> 📚 親ハブ: [[元宮ハブ_MOC]]

> ⚠️ **過去の記述からの方針転換**：当ノートは以前、阿波の **板野郡阿波神社（式外）** を元宮候補としていた。しかし板野郡阿波神社の祭神は **大国主命** で、率川阿波神社の **事代主神** と直接の対応がない。一方、阿波には **事代主神社という社名の式内社が2社**（阿波郡・勝浦郡）存在し、祭神も一致する。したがって、**事代主神社ルーツ説**を本論として採用する。

| 項目 | 内容 |
|---|---|
| 鎮座地 | 奈良市本子守町18（大神神社摂社・率川神社境内） |

| **主祭神** | **事代主神** |

| 創建 | 推古天皇元年（593年） |
| 由緒 | 大神神社の御子神祭祀の延長として大和に建立、阿波系の神々を勧請 |

## 🌟 ルーツ：阿波の事代主神社（式内2社）

延喜式神名帳に「**事代主神社**」と記されたものは **全国で4社のみ**、そのうち **阿波国に2社が集中**する：

| 神社 | 鎮座地 | 祭神 | 阿波説における位置 |
|---|---|---|---|
| **事代主神社（阿波郡）** | 阿波市市場町伊月宮ノ本100 | 事代主神 | 阿波における事代主の本貫地・東遷起点 |
| **事代主神社（勝浦郡）** ＝ [[生夷神社]] | 勝浦町沼江田中71 | 事代主神（恵比寿） | 事代主神（エビス）の生誕伝承地 |

→ 阿波説の主張：**事代主神祭祀の本源は阿波**、そこから三嶋大社（伊豆）と率川阿波神社（奈良）に遷座した。

## 🔍 「阿波咩命」――阿波由来の証拠神

**阿波咩命（あわめのみこと）** は、率川阿波神社の配祀神。同時に：

- **神津島の長浜神社**でも主祭神
- 阿波説では **大宜都比売命の異名**、または **天日鷲命の妹／娘** とする論あり
- 「**阿波の女神**」を意味し、阿波咩命を祀る神社の存在自体が **阿波由来の物的証拠**

→ つまり、**「事代主神＋阿波咩命」のペア祭祀**が率川阿波神社の核心であり、これは：
- 事代主神 ＝ 阿波の事代主神社
- 阿波咩命 ＝ 阿波の女神

の **二重の阿波由来** を意味する。

→ 参考：2023-08-07-鳥の一族　19_-_⑦　神津島_長浜神　阿波咩命 （[出典](https://awanonoraneko.hatenadiary.com/entry/2023/08/07/022333)）

## 🏛 大神神社（三輪山）との接続

率川阿波神社は **大神神社の摂社（率川坐大神御子神社）の境内末社**。つまり、

```
大神神社（三輪山・大物主神＝大国主の和魂）
   ┃
   ┣ 率川坐大神御子神社（御子神＝事代主）
   ┃     ┃
   ┃     ┗ 率川阿波神社（事代主＋阿波咩命）
   ┃
   ┗ 阿波の対応：
        ┣ 大御和神社（名方郡・大国主祭祀）→ 三輪山の元宮候補
        ┗ 事代主神社（阿波郡・勝浦郡）→ 率川阿波神社の元宮
```

→ **大物主神＝大国主神** の御子神祭祀という構造は、阿波の **大御和神社 → 事代主神社** という親子関係と完全に対応する。
阿波説では、これを **三輪山祭祀全体が阿波先行** とする論拠の一つとする。

→ 参考：[[多祁御奈刀弥神社と建御名方神：諏訪大社の元宮と事代主の兄弟神]]（大国主一族の阿波集中論）

## 🗓 推古天皇元年（593）の創建意義

率川阿波神社の創建年代 **推古天皇元年（593）** は、**阿波忌部・斎部広成『古語拾遺』** が成立する以前。

阿波説では：
- 593年 ＝ 推古朝・聖徳太子の時代
- この時期に **阿波の祭祀系統が中央（大和）に正式に勧請** されたと位置づける
- 大神神社（崇神朝・神武東征以前から）→ 率川神社（推古朝）→ 率川阿波神社（推古朝） という三段階の祭祀整備

→ つまり率川阿波神社は、**阿波の祭祀権を大和に組み込んだ歴史的瞬間** の物的証拠。

## 🌟 板野郡阿波神社（式外）との関係

板野郡には **阿波神社（式外社）** が現存するが：

| 項目 | 板野郡阿波神社 | 率川阿波神社 |
|---|---|---|
| 祭神 | **大国主命** | **事代主神＋阿波咩命** |
| 場所 | 板野郡（北阿波） | 奈良 |
| 元宮としての対応性 | △（祭神が異なる） | ◎（事代主神社と直結） |

→ **板野郡阿波神社は「阿波忌部・大国主祭祀」の独立系統**、率川阿波神社の元宮ではない。両者は **阿波忌部の祭祀ネットワークの異なる末端** として位置づけられる。

ただし、両者ともに **大国主一族（大国主→事代主）の祭祀** という大枠では結びつく：
- 板野郡阿波神社 ＝ 父・大国主の祭祀
- 率川阿波神社 ＝ 子・事代主の祭祀
- 両者は **同一氏族（阿波忌部）の祭祀権の東遷** という枠組みに収まる

## 📖 関連する阿波説の議論

### 1. 大物主＝大国主、その御子＝事代主
大神神社の祭神 **大物主神** は **大国主神の和魂**。その御子神を祀る率川坐大神御子神社は、**大国主→事代主** の系譜祭祀。阿波の **大御和神社（大国主）→ 事代主神社（事代主）** という親子祭祀構造と一致。

### 2. 三嶋大明神（伊豆三嶋大社）との並列
事代主神祭祀の東方遷座先として、伊豆三嶋大社（→ [[三嶋大明神と阿波：伊豆一宮の元宮としての事代主祭祀]]）と率川阿波神社が並列。

### 3. 岐神（くなどのかみ）信仰との接続
率川阿波神社・大神神社圏では **岐神** 信仰が見られる。境界神・道祖神として阿波忌部祭祀の特徴の一つ。
→ 参考：2019-12-31-岐神再び（追記） （[出典](https://goutara.blogspot.com/2019/12/blog-post.html)）

### 4. 神武東征の事代主軍師説
阿波郡の事代主神社サブノート [[事代主神と神武東征：阿波郡における軍師的役割]] は、神武東征における事代主神の **軍師的役割** を論じる。神武東征のルートは「阿波→大和」であり、率川神社の創建（推古朝）はこの記憶の祭祀化と整合する。
