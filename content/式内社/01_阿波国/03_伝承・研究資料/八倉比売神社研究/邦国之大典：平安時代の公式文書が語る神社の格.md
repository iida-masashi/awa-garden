# 邦国之大典：平安時代の公式文書が語る神社の格

延久2年（1070年）6月28日付けとされる **太政官符**（『阿波国徴古雑抄』所収）が、**天石門別八倉比賣神社** の祭祀を「**邦国之大典也**」と公式に位置づけ、奉幣を怠った阿波国司を叱責した事実は、阿波説における **国家祭祀レベルの物証** として最重要のものである。

ただし本史料については、原典の伝来経路・写本の奥書比定・「邦国之大典」語の他用例など、**史料批判の余地が複数残っている**。本稿はそれを正確に整理した上で、阿波説の文脈における意義を論じる。

---

## 📜 太政官符とは

> **太政官符**（だいじょうかんぷ）は、日本の律令制のもとで太政官が管轄下の諸官庁・諸国衙へ発令した **正式な公文書**。**官符** とも言う。

特徴：

- **府** とは、元来官庁が自己の管轄下にある下位の官庁に出す命令文書
- 太政官以外の官庁でもこれを出すことが出来たが、太政官は **原則として他の全ての官庁** に対して符が出せた
- **格** のような重要な法令も太政官符の書式を用いて出されることがあったことから、**極めて重みを有した**
- 発給プロセス：**天皇の裁可**、もしくは国政の枢要を担う **太政官会議**（議政官会議、公卿会議とも）での決定 → 弁官局で文書作成 → 諸司諸国へ発給

→ 律令制下で考えうる **最高クラスの公文書**。地方の式内社の祭祀をその主題とする例は極めて異例である。

なお平安後期以降、太政官符の発給数は減少し、より簡便な **官宣旨（左弁官下文）** で代用されることが多くなった。1070年（延久2年）はちょうど太政官符の発給文化が衰退する時期にあたり、この時期に依然として太政官符の形式で発令されたという事実そのものが、本件の重要性を示唆する。

## 🏛 1070年太政官符の内容

> 八倉比賣神の **祈年月次祭は邦国之大典也** として、奉幣を怠った阿波国司をきびしく叱っている

「**邦国之大典**」――**国家の大典**。すなわち、八倉比賣神の祈年祭・月次祭は **日本国の根幹をなす祭祀** であると、中央朝廷が明示的に宣言した。

### 「邦国之大典」と並列される祭祀の系列

平安時代の朝廷祭祀のうち、「大典」と称せられるレベルにあるのは：

- **大嘗祭**（即位儀礼）
- **新嘗祭**（毎年11月／天皇親祭）
- **祈年祭**（春の祭祀／全国の式内社）
- **月次祭**（毎月／重要式内社・大宮中行事）
- **神嘗祭**（伊勢神宮）

これらと並列される位置に、阿波国の八倉比賣神の祭祀が置かれている――これは普通の地方神社では考えられない地位である。

## ⚠️ 史料批判：写本伝来と比定の検証

本史料を「動かしがたい物証」として扱う前に、**いくつかの整理すべき論点**がある。これは記録の信頼度を下げるためではなく、**学術的に正確な位置付けを与えるため**である。

### 論点1: 「関白内大臣師通の記」という地元解釈

goutara ブログ（2013-07-07）は、この太政官符の写本について「これが**関白内大臣師通の記**として残っていたと云うもの」と記している。しかしこれには **年代上の重大な矛盾** がある：

- **藤原師通（1062-1099）** は1070年時点では **8歳**であり、関白でも内大臣でもない（[Wikipedia](https://ja.wikipedia.org/wiki/%E8%97%A4%E5%8E%9F%E5%B8%AB%E9%80%9A)）
- 師通が内大臣に進むのは **1083年（21歳）**、関白に就任するのは **1094年（33歳）**
- すなわち「**延久2年（1070年）の関白内大臣 = 藤原師通**」という比定は **史実と整合しない**

この記述の解釈には複数の可能性がある：

| 解釈 | 説明 | 評価 |
| --- | --- | --- |
| **A. 後代の参照記** | 師通が後年（関白在任時 1094-1099）に過去の太政官符を写本した、もしくは『後二条師通記』等の日記に書き写した | 蓋然性あり。師通は『**後二条師通記**』を残しており朝廷文書を多く扱った |
| **B. 別人の関白の誤記** | 1070年の実際の関白は **藤原教通**（1075年没）。後代に「関白＝師通」と誤って混同された | 写本伝承の過程で起きうる |
| **C. goutara 氏の独自記述** | 略記掲示板や noraneko 記事には「師通の記」の文言はなく、goutara 氏のみが言及している | この記述自体が二次資料 |

本ノートでは、「**関白内大臣師通の記**」という地元解釈は **goutara ブログ独自の付記** として扱い、**徴古雑抄写本そのものの奥書を直接確認していない現時点では、断定を避ける** ものとする。

### 論点2: 『阿波国徴古雑抄』そのものの性格

『阿波国徴古雑抄』（あわのくにちょうこざっしょう）は、**徳島県小松島出身の国学者 小杉榲邨（こすぎ・すぎむら、1834-1910）** が50年以上かけて蒐集した阿波国関係の古文書・抄録の集成である（[Wikipedia](https://ja.wikipedia.org/wiki/%E5%BE%B4%E5%8F%A4%E9%9B%91%E6%8A%84)／[徳島県立博物館](https://museum.bunmori.tokushima.jp/hasegawa/manyu/kosugi.htm)）。

| 項目 | 内容 |
| --- | --- |
| **編者** | 小杉榲邨（1834-1910） |
| **編纂活動** | 江戸末期から明治期にかけて50年以上 |
| **刊行** | **大正2年（1913年）** に喜田貞吉らが日本歴史地理学会から主要部分を刊行（小杉の没後） |
| **性格** | **平安時代の同時代史料ではなく、明治期の蒐集物**。一次史料の写本を集めたコレクション |

→ つまり徴古雑抄は **一次史料への扉**であり、それ自体が一次史料ではない。
収録されている太政官符の写本がいつ誰によって作成されたか、原典との対校はどう行われたかは、**個別の写本ごとに検証が必要**である。

### 論点3: 「邦国之大典」語の他用例

「邦国之大典」という表現が、平安時代の他の太政官符や勅書、『類聚三代格』等の法令集に **他にも例があるか／孤立用例か** は、本史料の異例性を評価する上で決定的な情報となる。

現時点での Web 検索および Vault 内史料調査の範囲では、**他の太政官符での「邦国之大典」用例は確認されていない**。これが事実であれば本件は **孤立用例**ということになるが、これを確定するには、平安時代古文書のデータベース（『平安遺文』『大日本古文書』等）を直接検索する必要がある。

→ **今後の確認課題**：『**類聚三代格**』『**朝野群載**』『**政事要略**』等の平安期法令・典礼集に「邦国之大典」の他用例があるか調査する。

## 🧩 太政官符が示す非対称性

仮に本史料が真正であるとすれば、その含意は極めて重要である。
この太政官符は、**歴史的非対称性** を示している：

```
中央朝廷（11世紀）           │           阿波の現地（11世紀）
──────────────────────────────┼─────────────────────────────────
八倉比賣神の祭祀は             │   奉幣を怠っていた
「邦国之大典」と認識           │   国司は神の正体を忘却
し続けていた                   │   していた可能性が高い
```

つまり：

1. **中央朝廷** は、八倉比賣神が国家祭祀の中枢に位置することを **知り、その重要性を維持し続けていた**
2. **阿波の現地** は、神の正体・由緒を **既に忘却** しており、ゆえに奉幣を怠った
3. 中央が地方を叱責するという、通常とは **逆方向の知識ギャップ** が生じていた

### この非対称性の阿波説的解釈

阿波説の立場では、これは次のように読まれる：

- 八倉比賣神は **記紀以前から存在した阿波固有の最高神**（大宜都比売命＝大粟姫の異名）
- 記紀編纂時に **阿波の独自伝承は削除・改竄**
- にもかかわらず、**中央朝廷の祭祀システム** には、八倉比賣神を「邦国之大典」として位置づける記憶が制度的に残っていた
- 阿波の現地は、神話再編によって **自らの聖地の正体を忘れさせられた**

→ つまり、太政官符は、**「ない記憶」を中央が「ある記憶」として保持していた稀有な事例** であり、八倉比賣神＝阿波の真の最高神の物証として機能する。

太政官符が「邦国之大典」と位置づけた背景には、八倉比賣神の **異常な神階昇叙** がある：

| 年 | 西暦 | 神階 | 典拠 |
|---|---|---|---|
| 承和8年 | 841 | 正八位 → **従五位下** | [[続日本後紀]] |
| 仁明朝 | 841 | 正五位下に再叙 | 当社略記 |
| 貞観13年 | 871 | **従四位上** | [[日本三代実録]] |
| 延久2年 | 1070 | **太政官符「邦国之大典」** | 『阿波国徴古雑抄』所収 |
| 元暦2年 | 1185 | **正一位** | 当社略記（後鳥羽天皇） |

→ 9世紀から12世紀まで、一貫して **国家祭祀レベル** で重視され続けた。

### 承和8年（841年）の階位ジャンプの異例性

承和8年8月の **「正八位→従五位下」** という叙位は、**通常の神階昇叙の慣例から大きく逸脱した飛躍**である。

平安期の神階制度は以下の階位構造を持つ：

```
正一位 ← 最高位
従一位
正二位 上／下
従二位 上／下
正三位 上／下
従三位 上／下
正四位 上／下
従四位 上／下
正五位 上／下
従五位 上／下  ← 八倉比賣神が承和8年に到達
正六位 上／下
従六位 上／下
正七位 上／下
従七位 上／下
正八位 上／下  ← 八倉比賣神の出発点
従八位 上／下
大初位 上／下
少初位 上／下
```

通常の昇叙は **一階ずつ** 進められる。正八位から従五位下に到達するには、本来であれば **6〜7階の昇進**を要する。これを承和8年に **一度に飛躍した** ことになる。

考えられる解釈：

1. **記録に残らない先行神階が存在した** — 阿波の地で従前から相応の神階が授けられていたが、記録に残らないか、記録が散逸した
2. **記録上の出発点が正八位だった** — 承和大昇叙時に初めて「公的記録」に登場したが、それ自体が極めて高位での登場であった可能性
3. **一斉叙位の特例措置** — 承和年間（834-848）は **全国の地方神への大規模神階授与の時代**（[続日本後紀](https://www.tosyokan.pref.shizuoka.jp/data/open/cnt/3/354/1/SZK0002734_20040929063521944.pdf)）であり、阿波の中枢神を一気に格上げする政治的判断があった

承和7年（840）6月・10月には、駿河・遠江・伊豆の **39神** が一斉に従五位下を授けられた記事があり、阿波の八倉比賣神も同じ流れの中で承和8年（841）8月に叙位されたと考えられる。

ただし通常の地方神は **無位→従五位下**（=「無階の神に最低の有階を与える」）という形が多く、**「正八位→従五位下」という記録の刻み方** は阿波の特殊事例である可能性が残る。

### 延喜式神名帳における位置

延喜式神名帳（927年）編纂時点で、阿波国全式内社の神階は：

```
正四位上：天石門別八倉比賣神           ← 阿波最高位
従四位上：葦稲葉神／大麻比古神
従四位下：天日鷲神                    ← 阿波忌部祖
従五位上：鹿江比賣神／埴生女屋神／白鳥神
従五位下：伊射奈美神／伊比良咩神／船尽比賣神
```

→ 阿波最高位。これは1070年の「邦国之大典」称号の前提となる地位である。

## 🪶 「忌部神」との注記

goutara が紹介する太政官符の写本『徴古雑抄（ちょうこざっしょう）』には、もう一つ重要な情報がある：

> 「**天石門別八倉比賣神**」が「**忌部神**」と書かれている

→ 阿波忌部の祭祀対象としての八倉比賣神＝阿波の祖神という位置づけ。これは『斎部宿祢本系帳』に「天背男命の后神＝八倉比賣命」「その子＝天日鷲翔矢命（阿波忌部祖）」とある系譜と整合する。

> ⚠️ **未調査論点**：「忌部神」の注記が、徴古雑抄写本の本文内のどの位置（本文中・割注・奥書）に書かれているかは原典確認が必要。注記の出所が確定すれば、八倉比賣 = 忌部祖神論の制度的裏付けとして決定的な意味を持つ。

## まとめ：太政官符が証言する阿波の地位

延久2年（1070年）の太政官符は、

1. **八倉比賣神** が「邦国之大典」を担う神格であった
2. **阿波国** は本来、国家祭祀の最重要拠点の一つであった
3. **中央朝廷** と **阿波の現地** の間に、知識・記憶の非対称性があった
4. 阿波の祭祀の重要性は、**記紀の表向きの記述を超えて** 中央で制度的に保持され続けた

ことを公式文書として証言する、阿波説における **最重要の一次史料候補** である。

ただし以下の **3 点の史料批判課題** が残されており、これを順次解消することで証言価値はさらに強化される：

- ✅ **済**：藤原師通の年代矛盾を整理し、「関白内大臣師通の記」は地元解釈であることを明示
- ⏳ **継続課題**：徴古雑抄写本の原典奥書の直接確認
- ⏳ **継続課題**：「邦国之大典」語の他用例の網羅調査（『類聚三代格』『朝野群載』『政事要略』等）
