# 建布都神と阿波の武神伝承

阿波市市場町香美（かがみ）に鎮座する **建布都（たけふつ）神社** は、**全国で阿波国にのみ祀られる延喜式内社**「建布都神社」の論社の筆頭。
祭神 **建布都神（建御雷之男神／タケミカヅチ）** は『古事記』国譲り神話・神武東征譚の双方に登場する武神で、阿波説では **国譲りの舞台＝阿波国阿波郡** とする中核論拠の一つ。

> 親ノート: [[建布都神社]]

## ⚔ 建布都神とは何か――三つの神話的役割

『古事記』のみに登場する建布都神（＝建御雷之男神／豊布都神）には、三段階の神話的役割がある。

### 役割1：神産み――刀剣鋳造の神

伊邪那美命が火之迦具土神を産んで亡くなり、伊邪那岐命が十拳剣で迦具土を斬る。十拳剣の先から滴る血の最後から生まれたのが **建御雷之男神**。
古事記自身が「**刀剣を鍛えるときの火の働きを称えた神**」と注を加える、鍛冶神・刀剣神としての本義。

### 役割2：国譲り――出雲征服の最大功労者

葦原中国平定のため、伊都之尾羽張神の子として **大国主命のもとへ派遣**。
- 大国主 → 八重事代主神に判断を委ね、事代主は承諾
- 建御名方神は抵抗するも、建御雷之男神に **圧倒的に敗れ、諏訪まで追われる**
- → **国譲りの最大の功労者**（kohun-jinjya 2023-11-22）

### 役割3：神武東征――霊剣布都御魂を下す

熊野村で神武天皇の軍が大熊の邪気にかかり倒れた時、高倉下の夢に天照大御神が現れ、建御雷神に「葦原中国はもともとお前一人が平定した国。お前が降るがよい」と命じる。
→ 建御雷神は **霊剣・布都御魂** を下し、神武軍を救う。

この **布都御魂剣に宿る神霊**＝**布都御魂大神** ＝ 石上神宮の祭神（『旧事本紀』）。

### 吉野川対岸の対峙構造

> 諏訪に追放した大国主神の御子・建御名方神を **監視する役割** を担った建御雷神（の軍団）は阿波市市場町香美に構えた。
> （awa-otoko 2015-01-13）

→ **吉野川を挟んで対峙する建布都神社（北岸）と多祁御奈刀弥神社（南岸）** は、神話的論理に基づく一対の配置と読める。

## 📜 神功皇后への神託――「尾田吾田節の淡郡」

『日本書紀』神功皇后摂政前紀の有名な記事：
> 神功皇后が神主となり、仲哀天皇に神託を授けた神の名を問うと、伊勢国五十鈴宮にいる神（天照大神）と答え、さらに「**他の神もいるか**」と問うと、
> 「吾は **尾田吾田節（おだあがたふし）の淡郡（あわのこおり）** にいる神である。」
> さらに問うと「**天事代虚事代玉籤入彦嚴之事代神**」（事代主神）の名を答えた。

### 阿波郡＝「淡郡」説

『式内社の研究』（志賀剛）：
- 「淡郡」は **「あわのこおり」と読み、阿波国阿波郡**
- 「**吾田**」は「あかた」＝「**赤田**」（土成町成当の **赤田神社**）
- 「**節（ふし）**」は「**淵（ふち）**」（建布都神の神格として）
- 「**尾田**」は赤田南方の **「尾類（おるい）」**＝「**尾田→尾類田→尾類**」

→ 神功皇后に神託を授けた神は、**阿波国阿波郡の建布都神＋事代主神**。

### kohun-jinjya のまとめ

> 阿波国阿波郡には、延喜式内社の **建布都神社・事代主神社が揃って** あります。こんな偶然はないと思うのです。
> 建布都神も事代主神も **阿波の神様** だったのです。

## 🌾 『粟島史』の阿波侵入伝承

『粟島史』（大塚唯士）が伝える注目すべき伝承：

> 武布津の神が出雲を平定して天照大神に奉告するために **事代主命を道連れにして阿波に来た**。一行は、讃岐の志度に上陸して日開谷を過ぎて **伊笠山付近** にきた。その時、忌部族は高天族不意の侵入を咎めて小競り合いがあったが、やがて忌部族 **天日鷲命は武布津神のために休憩所を今の香美に建て、事代主命を自分の妹の阿波咩の館に迎えた**。

→ つまり：
- **市場町香美の建布都神社** ＝ 天日鷲命が建てた建布都神の休憩所
- 事代主神社（市場町伊月） ＝ 阿波咩（天日鷲命の妹）の館
- 天照大神は **阿波にいた** ことになる ＝ **高天原は阿波**

## 🏛 建布都神社の複数論社

建布都神社の比定論社は **少なくとも5社** あり、これは「**建御雷神（軍団）の拠点（砦・城）が複数あった**」とする awa-otoko 仮説の傍証ともされる。

### 1. 建布都神社（阿波市市場町香美）――本稿の主対象

| 項目 | 内容 |
|---|---|
| 移転史 | 大影村・伊笠神社 → 平地権現（参拝のしやすさのため平地遷座）→ 香美の建布都神社（扇状地開拓後） |
| 江戸期史料 | 『寛保御改神社帳』「香々美村 平地権現」 |
| 明治改称 | 明治3年、平地権現 → 建布都神社（延喜式内社として復称）、八幡神社との式内論争を経て |
| 戦国期 | 細川三好の兵乱・長宗我部の兵火で森林の小祠に荒廃 |
| 天正14（1586）| 太守家政が国内巡検で「いかなる神か」と問うた際、武神＝八幡宮との答え。以後「**北八幡宮**」 |
| 大正8年 | 近隣の野神社・恵比須神社を合祀 |

### 2. 伊笠神社（標高704.6mの伊笠山頂）

| 項目 | 内容 |
|---|---|
| 創建 | 承応3（1655）（神社誌）――ただし古来からの信仰地と推定 |
| 由緒 | 新田氏一族の祀る神／三浦為清が源頼朝より久千田荘を賜り氏神を分霊し衣笠山と命名 |
| 祭神 | 武甕槌命、経津主命、天御中主命、**天一目箇命**、誉田別命 |
| 阿波志記述 | 「犬墓山山頂にあり、新田氏の族逃れ来て常に笠を載せて行く、既に死し祠を造りこれを祀る」 |
| 野口年長記述（『阿波郡式内神社考』）| 「犬墓村に伊笠明神…祭神二座、建甕槌命、**天二登命**（あめのふたのぼり＝天村雲命）」 |

伊笠山頂は **広範囲を見渡せる戦略的要地**。後世に新田氏の城として使用されたことから、建御雷神（軍団）の拠点としての性格が継承された可能性。山頂は古墳の上に築かれたとも見える。

### 3. 建布都神社（土成町郡字建布都）

- 字名「**建布都**」そのものを冠する
- 祭神：建布都神・経津主命
- 平成12年に近くの西宮神社（事代主神）と合祀
- 『式内社の研究』志賀剛はこの社を式内社と比定
- 「**郡（こおり）**」の地名通り、**郡衙の守護神** だった可能性（徳島県神社誌）
- 志賀剛仮説：吉野川河畔ゆえ「**淵の神**」を祀り、「ふちのかみ」→「ふつのかみ」→「武神・建布都神」と展開

### 4. 赤田神社（土成町成当）

- 「あかんたじんじゃ」
- 祭神：武甕槌命、経津主命
- 神紋は変わった形状
- 北方の山に **赤田山古墳**（円墳）
- 神功皇后神託「**尾田吾田節の淡郡**」の **「吾田＝赤田」** 比定地

### 5. 八幡神社（合祀）

近隣の八幡神社に合祀されたとする論社もあり。

## 🛕 物部・中臣・忌部の三氏族交錯

建布都神社の祭神配置は、**物部氏・中臣氏・阿波忌部** の三氏族の祭祀交錯を示す：

| 神 | 関連氏族 |
|---|---|
| 建布都神（建御雷神）| 中臣氏の守護神（鹿島神宮系） |
| 経津主神 | 物部氏の祖神（石上神宮系） |
| 大山祇命 | 阿波忌部の山岳信仰 |
| 事代主命 | 阿波の事代主祭祀（[[事代主神社]]系統）|

→ 阿波忌部の本拠地に物部・中臣の祭神が共祀されている。

### goutara の系譜的視点

goutara（2012-06-24）は『阿波国続風土記』第五巻P76-77を引用：
> 河内国弓削宿禰ハ **天日鷲翔矢命** ノ後ナル由見エタリ
> **林ハ日鷲ノ転** ニテ郡モ翔ト近ク聞ユ
> 御物宿禰ハ拝原郷ニ成長シテ室家連ノ家ヲ續シナルベシ

→ 河内国弓削宿禰（物部系）は **天日鷲命の後裔**、つまり **物部氏と阿波忌部は同祖** に遡るという系譜論。
→ 河内国志紀郡の「**伴林氏神社**」は「天日鷲命の伴をする氏を祀る神社」かと示唆。

### 「妄想の阿波古代史」の物部論

kohun-jinjya は別記事で「**ヤマト王権の黎明期を支えた物部氏の祖・伊香色雄命** の母が **高屋阿波良姫**」と『先代旧事本紀』を引用し、阿波忌部本拠地に物部氏祭祀が広く分布する事実を整理する。建布都神社はその中核の一つ。

## 🏯 建布都神社古墳

境内の **建布都神社古墳**（直径18.5mの円墳）は、発掘調査で **横穴式石室** が確認され、6世紀後半の築造と推定。

> 6世紀後半の築造となると、**古墳の後に神社が建てられた** か・・・
> （kohun-jinjya 2023-11-22）

→ 神社の祭祀は **古墳被葬者祭祀から発展した** 可能性が高い。これは宇志比古神社・葦稲葉神社の周辺古墳と同じパターン。

応安2（1369）の「応安の板碑」（法眼定金建立）も境内に残り、中世以降も継続的に祭祀が行われた。

## 🌐 阿波説における意義

| 論点 | 阿波説の位置づけ |
|---|---|
| **国譲り神話の舞台** | 阿波郡周辺の建布都神社・多祁御奈刀弥神社・事代主神社の配置 |
| **神武東征譚** | 建御雷神の霊剣布都御魂を下す神話の現場 |
| **神功皇后神託** | 『日本書紀』「尾田吾田節の淡郡」＝阿波郡の建布都神＋事代主神 |
| **物部・忌部同祖論** | 河内弓削宿禰＝天日鷲命の後裔（阿波国続風土記） |

→ 建布都神社は、**阿波説の神話的論証構造の中心ピース** の一つ。特に「**全国唯一座**」「**神功皇后神託**」「**国譲り地理の完全配置**」の三点は、阿波説における強い論拠とされる。

### 「淵の神」説――志賀剛の慎重論

ただし通説・神社研究者側の見解として、志賀剛『式内社の研究』は **「淵の神（水神）」→「建布都」への意味転化** を提示：
- 吉野川河畔の郡衙守護神として「淵の神」を祀る
- 「ふちのかみ」→「ふつのかみ」→武神・建布都神への音転と意味付与
- 阿波の阿曇氏との関連

→ 武神としての建布都神は **後世の意味付与** で、本源は **水神・郡衙守護神** であった可能性。阿波説の神話的解釈と通説の地名学的解釈は **両立可能** で、相互排他ではない。

## 📚 留保（中立的併記）

- 建布都神社の式内社比定は **諸論社あり**、本ノートは香美の建布都神社・伊笠神社・土成町建布都神社・赤田神社の併存を整理する立場。
- 「国譲り神話の舞台＝阿波」とする解釈は **阿波説固有** であり、通説（出雲＝島根、諏訪＝長野）とは並立しない。本ノートは阿波説の論拠を整理するが、確定論ではない。
- 志賀剛『式内社の研究』の「淵の神」説（水神・郡衙守護）は阿波説と排他ではなく、**本源の水神信仰が後に武神・建布都神へと意味展開した** とすれば両説は両立しうる。
