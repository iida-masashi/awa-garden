# 天都賀佐毘古神社（あまつかさひこのやしろ）

## 3. 祭神と社伝

- **級長津彦命（シナツヒコ）／級長津姫命（シナツヒメ）**：風の神。論社・轟の天都賀佐比古神社の現行祭神としてWikipedia・玄武神社サイトで確認できる。
- ただし神名帳は祭神を記さないため、**式内社本来の祭神は不詳**である。現行祭神は論社の現行の祭神であって、古代の祭神そのものではない。
- 社名が示す「天都賀佐毘古神」という神格自体は『古事記』『日本書紀』に登場しない（阿波説ブログ kohun-jinjya の指摘）。社名の神と現行祭神（風神二柱）が一致しない点が本社の論点の一つである。
- 阿波説では「ツカサ＝塚の司」として古墳築造・土木技術を司る阿波忌部の頭領神と解する（ブログ仮説の層。§6）。

## 4. 歴史

- 『延喜式』神名帳（巻第十）に「阿波国 美馬郡 天都賀佐〓古神社」が一座・小社として登載される。美馬郡は十二座（並小）で、当該社はその一つ（§5に内訳）。
- 比定は未確定で、論社は美馬町轟の天都賀佐比古神社と美馬町西荒川の天津賀佐彦神社の2社（Wikipedia「阿波国の式内社一覧」はいずれも「（論）」付き）。
- 論社・轟社の近代社格は旧村社（Wikipedia・玄武神社サイト）。同社の沿革の詳細はポータル[[天都賀佐比古神社]]を参照。
- 天津賀佐彦神社については『阿波志』に「天津賀比古祠 延喜式、亦小祀と爲す 重清村荒川里に在り 或は西岡宮と稱す」とある（Wikipedia「天津賀佐彦神社」）。同社の主祭神は級長戸辺命で、当社の級長津彦命とは異なる。

## 5. 「二社別記」説の検証

### 5-1. 原文の内訳では天都賀佐の社は一座のみ

旧稿および旧ポータルは、神名帳に「天都賀佐比古神社」「天都賀佐毘古神社」が**二社別記**されていると主張し、「異体字並記（同一社）」あるいは「主社と摂社の関係」という解釈の前提としていた。しかしVault保存の『延喜式』神名帳巻第十転写を直接照合したところ、美馬郡十二座（並小）の内訳は次の11社名＝12座である。

| # | 社名 |
|---|---|
| 1 | 鴨神社 |
| 2 | 田寸神社 |
| 3 | 横田神社 |
| 4 | 伊射奈美神社 |
| 5 | 建神社 |
| 6 | 天椅立神社 |
| 7 | 天都賀佐〓古神社 |
| 8 | 八十子神社 |
| 9 | 弥都波能売神社 |
| 10 | 波尓移麻比弥神社 |
| 11 | 倭大国玉神大国敷神社（二座） |

天都賀佐の社はこのうち**一座のみ**であり、二つの社名が別々に登載されている事実は確認できない。よって「二社別記」を前提とする解釈（異体字並記説・主社摂社説）は成立しない。なお転写では当該字が欠字（〓）となっているため、本ノートの表記「毘」は一覧資料（Wikipedia「阿波国の式内社一覧」等）の表記に従ったものである。

### 5-2. ペアノートとの整合

ポータル[[天都賀佐比古神社]]も同日（2026-11-15）の照合で同一の結論に達し訂正済みであり、両ノート間の齟齬は解消した。本カードは延喜式表記「毘古」をファイル名とする参照カードとして存置するが、二社が存在したことを意味しない。

### 6-1. 阿波忌部氏の土木技術祭祀

阿波説では社名「ツカサ」を「塚の司」と解し、本社を阿波忌部氏の古墳築造・土木技術祭祀の中核と位置づける。

麻殖郡の忌部神社・天村雲神社と並び、美馬郡西部の忌部祭祀の中核とされる。ただし当社固有の裏付けはないため、frontmatter の clans は空欄とし、仮説として本節に分離した。
