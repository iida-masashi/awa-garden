# 葦稲葉神社の同殿・千鹿江比売の謎

延喜式内社「**鹿江比賣（かえひめ）神社**」（阿波国板野郡）の祭神 **鹿江比賣命** は、古事記にも日本書紀にも登場せず、**阿波国にのみ祀られる神** である。
比定論社は二つ──**葦稲葉神社（上板町神宅）** と **大麻比古神社境内末社・野神社（鳴門市大麻町板東広塚）**──にあり、それぞれ祭神の解釈系統が異なる。本稿は二つの「鹿江比売命」を整理し、神格と氏族系譜の二重構造を解読する。

> 親ノート: [[鹿江比売神社]] / [[鹿江比賣神社]] / [[葦稲葉神社]]

## 🪨 「カエヒメ」とは誰か――二つの解釈系統

### 系統A：鹿屋野比賣神（カヤノヒメ）説

『古事記』では **草祖草野姫**＝鹿屋野比賣神。別名 **野槌神（のづちのかみ）**。
- 伊邪那岐・伊邪那美の神産みで生まれる
- **大山祇神との間に四対八柱の神を生む**
- 「カヤ」は萱（茅）、屋根を葺く草。野の精霊（野つ霊）の意

#### 音韻変化
```
カヤノヒメ
   ↓
カヤヒメ（中間形）
   ↓
カエヒメ（鹿江比賣）
```

kohun-jinjya（2023-09-21）はこの音韻変化を主軸として、**葦稲葉神社（上板町大山麓）の鹿江比賣命＝鹿屋野比賣神** と推定。

##### 現地地形からの傍証
- 大山山頂の **黒岩大権現** には **大山祇神** が祀られる
- 大山山頂と葦稲葉神社の間に「**野の神と山の神を仲良く並んで祀る小祠**」が存在
  - 小祠は **古墳形状**
- 大山祇神（山）／鹿屋野比賣神（野）の **一対祭祀構造** が現地に保存されている

### 系統B：千鹿江比賣命（チカエヒメ）説

**安房国忌部家系**（国立国会図書館デジタルコレクション所蔵）の系図では：

```
天日鷲命（阿波忌部祖）
   ┃
大麻比古命（＝津咋見命）
   ┣ 千鹿江比賣命（ちかえひめのみこと）
   ┗ 由布津主命（安房忌部祖）
```

→ **千鹿江比賣命は阿波忌部祖・大麻比古命の娘**。

#### 阿波説における意味
- 大麻比古神社末社「**野神社**」の祭神＝千鹿江比賣命
- 大麻比古神社の摂社として位置づけられることと **完全に整合**
- 鹿江比賣命を **忌部系の女神** として位置づける系統

野口年長（江戸後期阿波の国学者）も、安房国下立松原神社忌部系図に基づき、**「大麻比古命の娘・千鹿江比売命」** 説を提唱（awa-otoko 2015-10-28）。

### 両説の併存

二つの「鹿江比賣」は、**音韻が同じだが神格・系譜が異なる別神** である可能性が高い：

| 系統 | 神格 | 鎮座 | 性格 |
|---|---|---|---|
| A：鹿屋野比賣神 | 野槌神／大山祇神の妃 | 葦稲葉神社（上板町大山麓） | 在地古層神 |
| B：千鹿江比賣命 | 大麻比古命の娘 | 大麻比古神社境内野神社 | 忌部系氏族祖神 |

両者が「**鹿江比賣**」として混同・統合されたのは、延喜式編纂期（10世紀）以降の整理過程と推測される。

## 🌾 同殿合祀構造（葦稲葉神社）

葦稲葉神社（上板町神宅）の現状は：

```
鹿江姫神社 ── 葦稲葉神社 ── 殿宮神社（摂社）
     │             │              │
  鹿江比賣命    倉稲魂命       素戔嗚命
  （野槌神）   （宇迦御魂）
```

境内の鳥居扁額に「**鹿江姫神社、葦稲葉神社、殿宮神社**」と三社並記。
徳島県神社誌の由緒：
> 葦稲葉神社は葦稲葉大明神と号し **倉稲魂命・鹿江比賣命** を、殿宮神社には素戔嗚命を夫々主祭神として奉祀せり…

→ 葦稲葉大明神＝**倉稲魂命＋鹿江比賣命** の二神合祀。
→ 殿宮神社の素戔嗚命は中世以降の付会で、本来は **稲倉魂神（大宜都比売命・稲荷神）** とされる（awa-otoko 2015-01-29）。

## 🏔 神宅地区の三層祭祀構造

上板町神宅地区には、**山上の「奥宮」、山麓の「里宮」、田地の「田宮」** という古代祭祀形態が伝承されている：

| 層 | 場所 | 神格 |
|---|---|---|
| 奥宮 | 神体山「大山」山頂（葦野原） | 葦稲葉神（男神）＝大山祇神 |
| 里宮 | 神宮寺付近 | **鹿江比賣神（女神・産土神）** |
| 田宮 | 殿宮（"たのみや"→"とのみや"の転訛） | 稲倉魂神（大宜都比売命・稲荷神） |

→ **「鹿江比賣神＝里宮＝産土の女神」** という古代の位置づけが明確。山と田の中間で、人々の生活圏を見守る **野の女神**。

### 殿宮（とのみや）の語源

「殿宮」は本来「**田宮（たのみや）**」の転訛。これは江戸期以降の漢字表記の固定で、本来は田地・水田の祭祀地を意味した。**素戔嗚命を主祭神とする現在の表記は中世神仏習合期の付会** で、本来祭神は稲魂（稲倉魂・大宜都比売命）とする説が阿波説内部の有力解釈。

## 🦊 大麻比古神社境内・野神社

延喜式内社「鹿江比賣神社」のもう一つの論社は、**大麻比古神社の大鳥居右手にひっそりと鎮座する野神社**。

| 項目 | 内容 |
|---|---|
| 所在 | 鳴門市大麻町・大麻比古神社境内（大鳥居脇） |
| 隣接 | 天神社（菅原道真ほか） |
| 規模 | 小さな祠──式内社としては極めて控えめ |
| 祭神 | 鹿江比賣命（**千鹿江比賣命説** が有力） |

### kohun-jinjya の式内社比定論

> 延喜式神名帳に記された鹿江比賣神社は、**大麻比古神社の末社として鹿江比売命を祀る現在の野神社** であると考えます。
> （kohun-jinjya 2023-09-21）

論拠は：
1. 鹿江比賣神の神階授位（883年）が大麻比古神（同883年）と同時期で、大麻比古神の昇位が連動的に影響
2. 延喜式編纂時、葦稲葉神社は式内社入りせず、**鹿江比賣神社** だけが式内社となった
3. 大麻比古神社境内末社という位置は、**忌部系の千鹿江比賣命祭祀** として最も自然

## 🌐 阿波説における意義

鹿江比賣神社の論点は **「単なる祭神比定問題」を超えて**、阿波の神話的構造そのものを照らす：

### 1. 大山祇神・鹿屋野比賣神の発祥地論

- 上板町大山が **大山祇神・鹿屋野比賣神の祭祀発祥地**
- 後に **伊予一宮（大三島）大山祇神社** へ遷座
- 鹿江姫（野槌神）→ 阿波の野神社ネットワーク → 全国の野神信仰へ

### 2. 忌部系女神の系譜

- 千鹿江比賣命（忌部系図）が大麻比古命の娘として記録
- 阿波忌部の女神祭祀（意富門麻比売・[[天石門別豊玉比売神社|豊玉比売]]等）と並列する一座
- 由布津主命（安房忌部祖）と兄妹関係

### 3. 神功皇后伝説との接続

「鹿江（かえ）」の音から、神功皇后（息長帯比賣命）の三韓征伐に関連する女神とみる説（awa-otoko 系の妄想ライン）もある。宇志比古神社の丹波道主命説・息長氏系譜論とも連動。
ただしこちらは確度の低い派生説で、本筋は **野槌神・忌部祖神** の二系統。

## 📚 留保（中立的併記）

- 鹿江比賣命の正体について、阿波説内部でも **二系統併存**（鹿屋野比賣神／千鹿江比賣命）。本ノートは両説を併記し、現地比定地に応じて主神格が異なる可能性を提示する立場。
