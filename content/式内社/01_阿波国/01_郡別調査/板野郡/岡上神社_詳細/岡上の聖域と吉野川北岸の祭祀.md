# 岡上の聖域と吉野川北岸の祭祀

板野郡板野町大寺に鎮座する **岡上（おかのうえ／おかのかみ）神社** は、吉野川北岸の独立丘陵 **韓崇山（かんぞうやま）** に位置する延喜式内社。

阿波説における重要性は二重で、第一に **伊勢神宮外宮（豊受大神）の元宮** とする説、第二に **大宜都比売命の祭祀系統（稲荷・倉稲魂）の北阿波拠点** としての位置づけにある。

## 🪨 「岡上」社名の語源――ウカノカミ転訛説

岡上神社で **最も重要な論点** は、社名「岡上」の本来の読みと意味。

### 阿波国式社略考の記録

> 社殿は、もともと大クスの辺りにありましたが、**寛政初年（1789年）に丘の上にあげた** とあります。
> つまり、それ以前は **丘の上にはなかったのに**、岡上祠と呼ばれていた。

→ **「丘の上」という地理的特徴から名付けられたのではない**。社名は地形由来ではない。

### 音韻変化の仮説

```
ウカノカミ（宇迦の神／豊宇気毘賣神）
    ↓
ウケオカ（通音）
    ↓
オカノカミ（岡の神／岡上神）
    ↓
オカノウエ（岡の上）と誤読 ※後世
```

→ 本来の社名は **「ウカノカミ」**＝**宇迦之御魂神** または **豊受姫命**（豊宇気毘賣神）。

### 異読の整理

| 表記 | 読み | 解釈 |
|---|---|---|
| 岡上 | おかのうえ | 一般読み（地形読みと誤解された後世形） |
| 岡上 | **おかのかみ** | **本来の読み**（ウカノカミの転訛） |
| 岡上 | おかがみ | 地元呼称の変化形 |

## 🌾 祭神論：豊受姫命＝宇迦之御魂神＝大宜都比売命

### 三神同体論（神道五部書『御鎮座伝記』）

鎌倉時代に伊勢神宮で編纂された『御鎮座伝記』は、外宮の **調御倉神（つきのみくらのかみ）** について次のように記す：

> 調御倉神は、**ウカノミタマ神**におわす。これイザナギ・イザナミ二柱の尊の生みし所の神なり。
> また、**オオゲツヒメ**とも号す。また、**保食神（ウケモチ）** とも名づく。
> 神祇官社内におわす御膳神（みけつかみ）とはこれなるなり。
> また、神服機殿に祝い祭る **三狐神** とは同座の神なり。

→ **ウカノミタマ＝オオゲツヒメ（大宜都比売命）＝ウケモチ＝御膳神＝三狐神** という公式の同体論。

### 阿波説における意味

- 岡上神社の祭神 **豊受姫命** ＝ ウカノミタマ ＝ **大宜都比売命**
- つまり岡上神社は **大宜都比売命の北阿波（板野郡）拠点**
- [[上一宮大粟神社]]（名方郡）が大宜都比売命の総本宮であるのに対し、岡上神社はその **北方分祀**

### 延喜式祝詞の傍証

延喜式祝詞（大殿祭）では：

> これ **稲の霊（みたま）** なり。世にウカノミタマという。

→ **稲の霊（稲荷信仰の本源）** が大宜都比売命に直結することを古典が明示。

## 🏛 伊勢神宮外宮の元宮論

[[元宮ハブ_MOC]] の **伊勢系（元伊勢）** において、岡上神社は **伊勢神宮外宮（豊受大神）の元宮候補** と位置づけられる。

### 根拠

1. **祭神の同一性**：豊受姫命を主祭神とする式内社は阿波国では岡上神社のみ
2. **大宜都比売命との同体**：上記の伊勢神道公式論
3. **稲祭祀の阿波先行**：阿波が稲作・絹織物の最初期拠点（[[葦稲葉神：天日鷲命の御子神と板野郡の稲祭祀]]）
4. **音韻接続**：ウカノカミ（岡上）→ ウケ（豊受）→ 等由気大神（伊勢外宮）

### kohun-jinjya の慎重な解釈

kohun-jinjya 氏は『止由気宮儀式帳』（延喜23年）の「丹波比沼真奈井から呼び寄せた」記述を踏まえ、**「豊受大神＝登由宇気神（とゆうけ）」と「豊宇気毘賣神」を別神** とする立場も示す。

ただしこの場合でも、阿波説の文脈では：
- 阿波 → 丹波（丹波比沼真奈井）→ 伊勢
- というルートで阿波が **二次的本源** となる可能性が残る

### 多段階遷座論：和奈佐 → 岡上 → 丹波 → 伊勢

koraku ブログ「羽衣伝説 Vol.阿波」シリーズで提示された：

```
【阿波・海陽町・和奈佐】（最古層）
  寺山古墳群（3世紀初頭）= 天女（豊受大神）の墓
  内行花文鏡 = 大陸交易の物証
        ↓
【阿波・板野郡・岡上神社】（北阿波拠点）
  豊受姫命 = ウカノミタマ = 大宜都比売命
  韓崇山古墳群の朱塗り埋葬
        ↓
【丹後】（遷座先）
  比治の里・奈具の社・比沼麻奈為神社
  籠神社海部氏伝世鏡（内行花文鏡同型）
        ↓
【伊勢】（最終遷座）
  伊勢神宮外宮（豊受大神）
```

→ **「外宮の最古層は和奈佐 → 板野郡岡上へ移動 → 後に丹後経由で伊勢」** という多段階遷座論。
→ 詳細：羽衣伝説の阿波比定論：和奈佐（海陽町）と寺山古墳群

## 🏯 韓崇山（かんぞうやま）と古墳群

岡上神社の鎮座する **韓崇山** は古墳時代の重要祭祀地。

### 古墳の規模

| 項目 | 内容 |
|---|---|
| 大型古墳 | 頂上に2基 |
| その他 | 十数基 |
| 境内墳一号跡 | 大正3年発見、現在は石碑で位置を示す |
| 出土品（境内墳一号） | **勾玉、紡錘車、須恵器、土師器** |
| 頂上古墳の箱式石棺 | **朱塗りの完全な全身人骨**、**直刀**、**直弧紋装飾鹿角刀剣装具**、**銅鏡** |
| 神社100m南の古墳 | **塚穴**（口承） |

### 朱塗り埋葬の意義

**全身朱塗り**は阿波の若杉山辰砂採掘（[[阿波の水銀朱（辰砂）：若杉山遺跡と権力の象徴]]）と直結する高位埋葬。

副葬品の **直刀＋銅鏡＋勾玉** は、古墳時代前期〜中期の **権力中枢の象徴**。これらが阿波の北東辺境にあることは、板野郡が単なる地方ではなく、**中央祭祀権を持つ氏族の本拠** であったことを示唆する。

### 古代窯跡

朱鳥居から石段左の竹藪には **古代の窯跡** が発見されている。これは：
- 須恵器生産地としての岡上一帯
- **祭祀用土器の生産** と **古墳副葬品の供給**

を示す物証。

## 🌾 粟凡直一族と葦稲葉神社からの勧請

### awa-otoko の仮説（2015-11-12）

> 結論から言うと、この岡上神社は **隣町に鎮座していた葦稲羽神（葦稲葉神社）が粟凡直一族により勧請** された可能性が高い。

### 系譜的根拠

```
大宜都比売命（阿波国魂）
   ┃
   ┣ 葦稲葉神（板野郡・葦稲葉神社）── 天日鷲命の御子神
   ┃     ┃
   ┃     ┗ 勧請（粟凡直一族により）
   ┃         ┃
   ┃         ▼
   ┃   岡上神社（板野郡板野町）
   ┃   = ウカノカミ祭祀の派生
   ┃
   ┗ その他の御子神祭祀（各地）
```

### 粟凡直一族の重要性

**粟凡直（あわのおおしのあたい）** ＝ **粟国造** の一族で、大宜都比売命直系の血筋。
- 名方郡を本拠とする祭祀一族
- 板野郡への進出 → 葦稲葉神社・岡上神社の祭祀権を保持
- 阿波女社宮祖系の流れ

→ 韓崇山頂上の朱塗り全身人骨埋葬は、**粟凡直一族の首長級** の埋葬と推定される。

## 🦊 稲荷信仰と岡上神社

倉稲魂命＝宇迦之御魂神＝**稲荷神** の本源として、岡上神社は **阿波における初期稲荷祭祀地** の一つ。

### 「みけつかみ＝三狐神」の阿波由来

延喜式祝詞・神道五部書ともに、**ウカノミタマ＝三狐神（みけつかみ）** と記す。「狐」を「ケツ」と読むのは関西方言だが、これと **大宜都比売命の御子神＝狐に関連** という阿波系の伝承（[[上一宮大粟神社]]の「黄金の狐」）が結びつく。

### 空海の介入

awa-otoko の興味深い指摘：

> 空海が狐を追い出したというのは、**大宜都比売命の様々な側面から荒御魂を他の神として阿波国外に出し、和御霊を阿波の国魂とした** かったのかもしれない。

→ 岡上神社の稲荷祭祀には、**真言密教（空海）による祭祀再編** の痕跡がある可能性。

## 🪞 異説：松浦年長の石凝姥命説

阿波の式内社研究で名高い **松浦年長** は、岡上神社の祭神を **石凝姥命（いしこりどめのみこと）** とする。

### 石凝姥命とは

- 『日本書紀』天孫降臨の段で、**天照大神の御鏡を作った神**
- 鍛冶・鋳造の女神
- 物部・鏡作部の祖

### 阿波説における接続

- 大宜都比売命系列の **手仕事・産業の側面**（稲穂・織物・鍛冶）
- 岡上神社の御神木「**御神鏡木**」（鏡を連想させる名）
- 韓崇山頂古墳から **銅鏡** 副葬品

→ 鏡作・鍛冶祭祀としての岡上神社、という解釈も成立。豊受姫命の **産業神格としての側面** を強調する。

## 🪶 中世以降の歴史

### 寿永（1184頃）：源義経の祈願

源義経が **屋島の平家を討たんと** した道中、岡上神社に立ち寄って **武運を祈願** したという伝承。

### 応仁の乱（1467）：祈雨成功

> 応仁の乱の最中、毎日のように降り続く雨で稲が腐り、困った村人たちは **五穀の祖神** である岡上大明神に祈願し、その秋は **五穀が実って飢餓から免れた**。

→ 中世においても **「五穀の祖神」** ＝ 大宜都比売命系の認識が継承されている証拠。

### 寛政初年（1789）：丘上への遷座

それ以前、社殿は **大楠の下** にあった。寛政期に **岡宮の山上（現在地）に移された**。この遷座と「岡上」の漢字表記が固定された可能性が高い。

### 明治・大正期

- 江戸期：藩から大楠の伐採命令 → 御神木として回避
- **大正3年（1914）**：境内墳一号古墳発見、勾玉等出土
- **大正4年（1915）**：王子の宮・若宮神社・山神社・楠木神社を合祀
