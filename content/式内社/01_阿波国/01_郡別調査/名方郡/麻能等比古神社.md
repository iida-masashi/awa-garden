# 麻能等比古神社（まのとひこじんじゃ）

> [!summary] 要旨
> 麻能等比古神社（まのとひこじんじゃ）は、阿波国名方郡の式内社（小社・一座）。徳島市明神町6丁目1に鎮座。祭神は**猿田彦命**（サルタヒコノミコト）。比定論社は**大麻比古神社**・**桜間神社**・天神社（合祀）。「麻能等比古」の社名は**阿波忌部氏の「麻」祭祀**との接続を示唆し、阿波説では猿田彦を阿波土着の先住神、あるいは「麻の戸彦」＝忌部の麻祭祀神と解釈する論がある。論社・天神社（入田町天ノ原）は全国「猿田彦神社」の総本社（元宮）論の対象ともされる。

## 3. 祭神と社伝

### 猿田彦命（サルタヒコノミコト）

- 天孫降臨神話の**道案内神**。天孫ニニギ命を伊勢の五十鈴川まで導いた神。
- 「衢神（ちまたのかみ）」「岐神（くなどのかみ）」として境界・道祖神的性格を持つ。
- 阿波説では、猿田彦を**阿波土着の先住神**と位置づける論があり、天孫族（後から来た神）を案内する役割は**先住氏族が天孫族を阿波に迎えた歴史的記憶**の神話化と解釈される。

### 「麻能等比古」の解釈

- 「**麻の戸彦（まのとひこ）**」と読み、阿波忌部の麻（麁服）祭祀の戸口を司る男神、と解釈する論。
- 大麻比古神社が論社に挙がる点も、本社が**大麻彦神（オオアサヒコ）＝阿波忌部の祖神格**と連結することを示唆する。
- → 阿波説では本社祭神を**猿田彦＝大麻彦＝阿波忌部の本貫神**という統合論で捉える。

### 論社：天神社（徳島市入田町天ノ原94）

麻能等比古神社の有力論社の一つに、**天神社（てんじんじゃ）**（徳島市入田町天ノ原94／北緯34.0407・東経134.4375）がある。創建年・由緒ともに不詳の式内社で、「麻能等比古神」が合祀されることから麻能等比古神社に比定される。

天神社の祭神（6柱）：

| 祭神 | 性格 |
|---|---|
| **天目一箇神**（あめのまひとつのかみ） | 鍛冶・金属神（忌部系の作金者） |
| **菅公**（菅原道真公） | 後世の天神信仰による合祀 |
| **天児屋根命** | 中臣氏祖神 |
| **武甕槌命** | 鹿島・春日の武神 |
| **武経津主命** | 香取の武神 |
| **麻能等比古神** | 本社祭神（伝・猿田彦） |

天目一箇神・天児屋根命・武甕槌・経津主の組み合わせは、阿波忌部・中臣・鹿島香取系の祭祀が重層していることを示す。菅公は中世以降の天神（天満宮）信仰による習合。

地名「**天ノ原**」は、神話の「**天の安河（あまのやすかわ）**」に由来するともいわれ、阿波＝高天原説（阿波国神話中心地説）の地名痕跡として引かれる。

## 4. 歴史

- 延喜式神名帳（927年）に「阿波国 名方郡 麻能等比古神社」として記載。
- 比定論社の**大麻比古神社**（板野郡板野町：阿波一宮）は格上の名神大社で、本社との関係は中世以降の祭祀ネットワーク再編の結果と思われる。
- **桜間神社**（徳島市国府町）も論社。桜間は古代名方郡の地名で、本社の旧鎮座地候補。
- 現代の徳島市明神町地区は、中世以降の遷祠地と推定される。

## 6. 阿波説における意義

### 6-1. 阿波忌部の「麻」祭祀と名方郡の接続

- 阿波説の核心命題：「**麻（麁服）の貢進は阿波忌部の特権**であり、その祭祀ネットワークが阿波全域に展開していた」。
- 本社「麻能等比古」は、麻殖郡（阿波忌部本拠）以外で**「麻」を社名に冠する数少ない式内社**の一つ。
- → 阿波忌部の祭祀網が名方郡にも延びていた物的証拠。
- 麻は麁服として大嘗祭で天皇に供される神聖な繊維であり、麻栽培・神事用麻布の生産を担う氏族の祖神が独立して式内社に祀られた事実は、阿波が古代日本の繊維祭祀の中核地であったことを傍証する（→[[阿波忌部の産業：麁服と麻・穀・紙の伝統]]）。
- 論社の一つ入田町宮ノ前は、船盡神社・船盡比賣神社・大日寺等と地理的に近接し、神仏混淆の歴史を共有する（→ 9節「2015-06-02-大日寺は船盡神社の別当寺」参照）。[[上一宮大粟神社]]・[[天石門別八倉比売神社]]・[[大御和神社]]・[[天佐自能和氣神社]]という王権祭祀の中核圏に忌部系の麻祭祀点が併存する構図は、名方郡が複数氏族の祭祀的共同管理下にあったことを示唆する。

### 6-2. 大麻比古神社（阿波一宮）との祭祀接続

- 大麻比古神社が論社に挙がることは、本社が**阿波一宮＝大麻比古の祭祀網の末社・分祀社**であった可能性を示す。
- 阿波忌部の祭祀網：
  - **忌部神社**（麻殖郡：本社）
  - **大麻比古神社**（板野郡：一宮）
  - **麻能等比古神社**（名方郡：本社）
  - **麻殖郡_8座** + **名方郡_12座**の周辺式内社
  → 全体で阿波国を覆う祭祀ネットワークを構成。

### 6-3. 「船盡神社」「一宮神社」との地理的近接

- 関連ブログ「2015-06-02-大日寺は船盡神社の別当寺（大日寺、船盡神社、一宮神社、船盡比賣神社、麻能等比古神社）」が示すように、本社は**国府町の式内社群**（一宮神社・船盡神社・大日寺）と祭祀的・地理的に同一圏内。
- これは名方郡の式内社が**国府町を中心に密集**していたことを示し、阿波国府＝阿波説における政治・祭祀の中核地という命題を補強する。

### 6-4. 猿田彦＝阿波先住神論

- 阿波説では、猿田彦命を**阿波土着の先住神**と位置づける論がある。
- 本社が**名方郡（天孫族祭祀の濃い郡）に猿田彦を祀る**ことは、天孫族が阿波に入植する以前の**阿波先住氏族の祭祀記憶**を保存している可能性を示す。
- 関連：[[天石門別八倉比売神社]]境内に猿田彦祠が存在する点（awa-otoko-blog 2016-06-17記事）。

### 6-5. 「麻」と「猿田彦」の習合

- 「麻能等比古＝猿田彦」という祭神同定は、阿波忌部の麻祭祀と先住神猿田彦祭祀が**習合された歴史的層序**を示す。
- 阿波の祭祀史における**先住神 → 忌部氏祭祀 → 天孫族祭祀**という三層構造の中間段階の証拠。

### 6-6. 全国「猿田彦神社」の総本社（元宮）論

- 阿波国神話中心地説（≒四国邪馬台国説、≒阿波国高天原説）によれば、「麻能等比古神＝猿田彦」を祀る本社（論社 天神社）は、**全国の「猿田彦神社」の総本社（の元宮）**にあたるとされる。
- 周辺地名「天ノ原」＝「天の安河」由来説とあわせ、本地が天孫降臨以前の阿波先住神（猿田彦）祭祀の本源地である、という主張を構成する。
- これは[[元宮ハブ_MOC]]が扱う「○○の元宮は阿波にある」という命題群の一例。

### 6-7. 麻能等比古神＝水戸神（速秋津日子）異説

- 「麻能等比古神」を、伊弉諾・伊弉冉が産んだ**水戸神（ミナトノカミ）＝速秋津日子神・速秋津比売神**とする異説がある。
- この説では本社祭神は「猿田彦」ではなく河口・港湾の神となり、祭神同定には複数説が並立する（留保事項）。

## 12. 留保（中立的併記）

> [!warning] 注意
> - 「麻能等比古＝猿田彦」の祭神同定は論社間で一致しておらず、水戸神（速秋津日子）とする異説も存在する。
> - 「全国猿田彦神社の総本社（元宮）」論は阿波説特有の位置づけであり、通説の猿田彦信仰の中心地（伊勢・鈴鹿など）とは異なる。
> - 「天ノ原」＝「天の安河」由来説は地名の音韻的類似に基づく解釈で、文献的に確定したものではない。
> - 大麻比古神社・桜間神社との論社関係は中世以降の祭祀再編を反映する可能性があり、式内社当時の実態と直結するとは限らない。
