# タケミナカタと諏訪信仰の阿波起源説

> [!summary] 概要
> 阿波国名方郡（なかたぐん）に鎮座する **多祁御奈刀祢（たけみなとね）神社／多祁御奈刀弥神社** は、信濃国一宮・**諏訪大社の主祭神「建御名方神（タケミナカタ）」の元宮**であるとする阿波説の中核論点を担う神社。**名方郡の「ナカタ」こそがタケミナカタの名乗りの語源**であり、記紀の「国譲り神話」が阿波内の勢力争いの記憶であったとする論証の鍵となる。本ノートは、多祁御奈刀祢神社の祭神論、国譲り神話の阿波内比定、諏訪大社東遷ルート、関連聖地の連動を整理する。

## 1. 多祁御奈刀祢神社の基本情報

| 項目 | 内容 |
|---|---|
| **正式名称** | 多祁御奈刀祢神社（たけみなとねじんじゃ）／多祁御奈刀弥神社 |
| **読み** | タケミナトネ／タケミナトミ |
| **鎮座地** | 徳島県名西郡石井町浦庄字諏訪 |
| **延喜式社格** | 阿波国名方郡 多祁御奈刀祢神社・小 |
| **主祭神** | 建御名方神（タケミナカタノカミ） |
| **配祀神** | 八坂刀売命（やさかとめのみこと）— 建御名方神の妃神 |
| **境内** | 「諏訪」字名の地に鎮座 |

→ **鎮座地が「諏訪」字名** という事実は、諏訪信仰との直接的関連を地名レベルで証明する。

## 2. 「名方郡」と「タケミナカタ」の音韻論

### 阿波説の核心主張

- **名方郡（なかたぐん）** の「ナカタ」＝ **タケミナカタ** の「ミナカタ」と直接対応
- **「タケ」＝武・建** の接頭辞、「**ミナカタ**」＝**名方** に「ミ（御）」を冠した形
- 神名は **「武の御-名方-神」** ＝「**名方の地から出た武勇の神**」と読める
- 名方郡が **タケミナカタの名乗りの発祥地** とする論証

### 通説との対比

| 観点 | 通説 | 阿波説 |
|---|---|---|
| 「ミナカタ」の語源 | 「水潟」「水形」など水神由来説、または不明 | **阿波国名方郡そのもの**（地名から神名へ） |
| 国譲りの舞台 | 出雲国 → 諏訪へ | **阿波国名方郡内** → 後に出雲・諏訪へ投影 |
| 神社の創建 | 後世の諏訪信仰の伝播 | **諏訪大社よりも古い元宮** |

## 3. 国譲り神話の阿波内比定

### 記紀の国譲り神話の概要

『古事記』『日本書紀』の国譲り段では：

1. 天照大神が地上（葦原中国）を高皇産霊尊の子に治めさせるため、使者を派遣
2. 大国主命とその子・**事代主神**・**建御名方神** に交渉
3. 事代主は **承諾**（恵比寿信仰の起源）
4. 建御名方は **抵抗** したが、建御雷神（タケミカヅチ）に敗北
5. 諏訪まで逃れて「この地から出ない」と誓う

### 阿波説における再解釈

阿波説では、この物語は **阿波国内の勢力争い** の記憶とされる：

- **大国主・事代主・建御名方** の本拠地 ＝ 阿波（名方郡・板野郡・那賀郡）
- **大国主**：阿波の在地王権
- **事代主**：阿波の海洋祭祀（[[積羽八重事代主神と阿波：大宜都比売命の配偶神としての海洋王権]]）
- **建御名方**：阿波の名方郡を本拠とする武人神
- **国譲り** ＝ 阿波内での **粟国（在地）→ 渡来系王権** への政権交代
- 建御名方は敗れて **阿波から諏訪へ東遷** した

### 阿波の関連聖地ネットワーク

| 神社 | 関連神格 | 阿波説的位置付け |
|---|---|---|
| **多祁御奈刀祢神社** | 建御名方神 | **諏訪大社元宮**、名方郡＝名乗り発祥地 |
| **大御和神社** | 大物主神（大国主の和魂） | **大和神社・大神神社元宮**、国譲りの中心地 |
| **事代主神社**（阿波郡） | 事代主神 | **国譲り承諾の地**、エビス信仰の元宮 |
| **生夷神社**（勝浦郡） | 事代主神 | **事代主＝エビスの生誕地** |
| **上一宮大粟神社** | 大宜都比売命 | 在地祭祀の中心、国譲り以前の阿波王権 |
| **天石門別八倉比賣神社** | 大日孁尊／天照大神 | 天照大神の本貫、国譲りを命じた側 |

→ 阿波説では、これらの神社が **国譲り神話の地理的舞台** を構成する。

## 4. 諏訪大社との関係：元宮論

### 諏訪大社の概要

- **諏訪大社**：信濃国一宮、長野県諏訪湖周辺
- 上社本宮・上社前宮・下社春宮・下社秋宮の四社で構成
- **主祭神**：建御名方神、八坂刀売命
- **創建**：神代と伝わる、実年代不詳

### 阿波説における元宮論

1. **建御名方の出発地**：国譲り敗北後、阿波・名方郡から逃走
2. **諏訪定着の経緯**：黒潮ルートか瀬戸内→紀伊→東国を経由
3. **多祁御奈刀祢神社の祭神**：建御名方＋八坂刀売 ＝ 諏訪大社と完全同一
4. **「諏訪」字名**：石井町浦庄字諏訪に鎮座、地名レベルでの一致

### 名前の音韻変化

| 阿波での名乗り | → 諏訪での名乗り |
|---|---|
| 多祁御奈刀祢（たけみなとね）／多祁御奈刀弥（たけみなとみ） | **建御名方（たけみなかた）** |

→ 「ナトネ／ナトミ」が「ナカタ」へと変化した可能性。

## 5. 出雲との関係：阿波→出雲→諏訪のルート論

### 出雲国譲りの実体

阿波説では、『古事記』『日本書紀』の **出雲国譲り** も、阿波説からの読み替えで：

- **出雲＝阿波の海岸部**（出津面、伊津面）
- 大国主の国譲りは **阿波内** で起こった
- 後世に **出雲国（島根）に投影された**

詳細：[[阿波・出雲ペア：伊津面と国譲りの地名証拠]]

[出雲経由 or 直接]
     ↓
[信濃・諏訪]

[諏訪大社]

## 9. 阿波説への反論

### 通説からの主要反論

| 反論 | 阿波説の応答 |
|---|---|
| 「ミナカタ」の語源は水神「水形」 | 名方郡の地名が先行、神名は地名から派生 |
| 諏訪大社の方が古く、阿波は分祀 | 多祁御奈刀祢の祭祀は古く、諏訪より遡る可能性 |
| 国譲りは出雲（島根）の神話 | 出雲は阿波内地名の投影、原舞台は阿波 |
| 名方郡と神名の音韻一致は偶然 | 配祀の八坂刀売・字諏訪などの複層的一致 |

## 11. 留保（中立的併記）

- 「名方郡＝タケミナカタの名乗り発祥地」という解釈は阿波説論者によるもので、主流学界の見解とは異なる
- 「ミナカタ」の語源には、水神「水形」説、未詳説など複数の主流説がある
- 国譲り神話を「阿波内の出来事」とする読み替えは、阿波説の核心命題だが、文献的直接根拠は限定的
- 多祁御奈刀祢神社の創建年代は不詳であり、諏訪大社との先後関係は学術的に確定していない
- 「諏訪」字名は後世の諏訪信仰流入による可能性も排除できない
- 本ノートは阿波説論者の整理であり、各論点は **学術的検証を受ける開かれた仮説** として提示される
