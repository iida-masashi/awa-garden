# 大和（おおみわ）祭祀と三輪山の起源

> [!summary] 概要
> 徳島市国府町（旧阿波国名方郡府中）に鎮座する **大御和（おおみわ）神社** は、奈良県の **三輪山（大神神社）の元宮** であるとする阿波説の中核論点を担う神社。**「おおみわ」という極めて特殊な読み**を共有し、**祭神は大物主神（大国主の和魂）** ― これは大神神社と完全一致。阿波の国府・名方郡の中枢に鎮座する事実とも合わせて、**ヤマト王権の畿内東遷時に「オオミワ」祭祀が奈良盆地の三輪山へ移植された** と論証される。本ノートは大御和神社の祭神論、大神神社との対応関係、阿波説における国譲り神話との接続を整理する。

## 1. 大御和神社の基本情報

| 項目 | 内容 |
|---|---|
| **正式名称** | 大御和神社（おおみわじんじゃ） |
| **読み** | オオミワ |
| **鎮座地** | 徳島県徳島市国府町府中644 |
| **延喜式社格** | 阿波国名方郡 大御和神社・小 |
| **主祭神** | **大物主神**（おおものぬしのかみ）— 大国主神の和魂 |
| **創建** | 不詳（神代と伝わる） |
| **特殊地位** | 阿波国府所在地の中枢に鎮座 |

→ **「府中」は阿波国府** ＝古代阿波の政治・祭祀中心地。その中心に大御和神社が立地する事実は、阿波王権における **大物主神祭祀の最高位** を意味する。

## 3. 阿波説における核心命題：「阿波こそが本来の大和（ヤマト）」

### 大和（ヤマト・オオミワ）の語源論

阿波説における重要主張：

- **「大和（ヤマト）」の本来の発音は「オオミワ」** — 三輪山祭祀の中心地という意味
- 阿波の大御和神社が立地する **名方郡府中** こそが **本来の「ヤマト」**
- 後代、ヤマト王権が **畿内へ東遷** した際、この「オオミワ」の名称と祭祀を **奈良盆地の三輪山へ移植**
- 奈良の三輪山＝阿波の大御和神社の **遷座先**

### 「大和」の表記と読みの謎

「大和」を「ヤマト」と読むのは特殊な訓読み：

- 通説：当て字、語源不詳
- 阿波説：**本来は「オオワ／オオミワ」と読んでいた** ものが、後に「ヤマト」と訓まれるようになった
- 阿波の **「大粟（おおあわ）」「大御和（おおみわ）」** が原初の「大和」発音

## 5. 国譲り神話と大物主神

### 大国主と大物主の関係

『日本書紀』の記述：

- 大国主神（出雲の神）の **和魂（にぎみたま、穏やかな魂）が大物主神**
- **荒魂（あらみたま、荒々しい魂）が大国主自身**
- 大物主は本来 **大国主の別名・別人格**

### 阿波説における大国主・大物主

- 阿波の **大国主祭祀** は名方郡の周辺に多数存在
- 大物主＝大国主の和魂 ＝ **阿波の在地大王の祭祀神格**
- 大御和神社は **大物主祭祀の中心**
- 国譲り神話で大国主が **「国を譲った」相手** ＝ 天孫族（阿波の渡来系王権）

### 三輪山祭祀の起源

- 三輪山祭祀の核心は **山そのものを神体** とする原始祭祀
- 阿波の大御和神社にも **同様の原始祭祀** の痕跡（注連縄の張り方、巨石信仰）
- 大神神社の **「酒の神」「医薬の神」** の側面も、阿波の祭祀との連動

## 6. 倭迹迹日百襲姫命（卑弥呼）と大物主

### 大神神社縁起の核心

『日本書紀』崇神紀の記録：

- **倭迹迹日百襲姫命** が大物主神の妻となる
- 大物主が **小蛇** の姿で現れる
- 倭迹迹日百襲姫命の **箸墓伝説** ＝ 卑弥呼の墓とする説

### 阿波説における倭迹迹日百襲姫命

- 阿波説では：**倭迹迹日百襲姫命＝大宜都比売命（オオゲツヒメ）の継承者**
- **「第二の大宜都比売命」** として位置付け
- 詳細：[[倭迹迹日百襲姫命と「第二の大宜都比売命」：卑弥呼系譜論]]
- 大物主＝大国主の和魂と、阿波の **大宜都比売命の継承系譜** が阿波で連動

## 7. 国府町＝阿波国府の中枢

### 阿波国府の地理的中心性

- **国府町** ＝ 古代阿波国府の所在地
- 古代の **政治・祭祀の中枢**
- 大御和神社はその **府中（中央）** に立地

### 国府町周辺の重要遺跡

- **観音寺遺跡**：阿波国府の官庁跡、木簡出土
- **国府町矢野遺跡**：弥生期の朱精製工房（[[加茂宮ノ前遺跡：縄文後期からの朱生産]] と並ぶ）
- **気延山（きのべやま）**：阿波の聖山、八倉比賣神社の神奈備山

→ 大御和神社は **古代阿波の最も重要な政治・祭祀の中心** に位置する。

## 8. 阿波説への反論と応答

### 通説からの主要反論

| 反論 | 阿波説の応答 |
|---|---|
| 大神神社は古代から大和に存在 | 大御和神社の創建年代は神代、両社の先後関係は確定していない |
| 「おおみわ」の読みの一致は偶然 | 祭神（大物主）まで完全一致は偶然不可能 |
| 阿波国府は古代国家の地方拠点に過ぎない | 名方郡＝大和の語源、国府町＝原初の中央 |
| 三輪山信仰は弥生〜古墳期の在地祭祀 | 三輪山祭祀の **原型** は阿波の大御和神社にある |
| 国譲り神話は出雲の物語 | 出雲は阿波内地名の投影、国譲りは阿波内の出来事 |

### 阿波説の補強論拠

- 阿波の **大物主祭祀の重層性**：大御和神社＋関連社の体系
- **東阿波型土器** の纒向遺跡最古層での圧倒的シェア
- **段の塚穴型石室** の阿波→畿内伝播
- **大嘗祭の阿波貢進** の継続性

## 10. 留保（中立的併記）

- 「大御和神社＝大神神社の元宮」という解釈は阿波説論者の主張であり、主流学界の見解とは異なる
- 「おおみわ」の読み一致は強力な根拠だが、両社の先後関係を確定するには **創建年代の物的証拠** が必要
- 「大和（ヤマト）」の原音を「オオミワ」とする読解は阿波説特有のもので、語源学的に主流ではない
- 大御和神社の祭神 **大物主神** は、後世の合祀・変更による可能性も完全には排除できない
- 国府町＝阿波国府の中心性は事実だが、これが「大和の中心」を意味するかは別議論
- 本ノートは阿波説論者の整理であり、**学術的検証を受ける開かれた仮説** として提示される
