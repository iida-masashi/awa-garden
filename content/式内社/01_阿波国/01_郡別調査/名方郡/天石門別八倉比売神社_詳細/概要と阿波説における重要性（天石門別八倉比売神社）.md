# 概要と阿波説における重要性（天石門別八倉比売神社）

> [!summary] 概要
> **天石門別八倉比売神社（あめのいわとわけやくらひめじんじゃ）** は、徳島市国府町西矢野の杉尾山に鎮座し、『延喜式』神名帳の阿波国名方郡の大社「天石門別八倉比売神社」の **論社の一つ**（確定比定社はない）。主祭神は大日孁尊（大日靈女命）で、天照大神の別名とされる。六国史に神階の記事が残る **国史見在社** であり、社伝『八倉比売大神御本記』に天照大神の葬儀の様子が記されることで知られる。阿波説では本社を **天照大神（大日孁尊）の陵墓所在地、卑弥呼の終焉地** などと位置づけるが、これらはブログ・在野研究に基づく **仮説** であり、確認できる事実とは分離して以下に記す（詳細は「8. 留保」参照）。

## 1. 神社の基本情報

| 項目 | 内容 |
|---|---|
| **正式名称** | 天石門別八倉比売神社（あめのいわとわけやくらひめじんじゃ。式内社名の読みは「あまのいわとわけ」ともされる） |
| **通称** | 八倉比売神社。江戸時代は「杉尾大明神」と称し、現社名は明治3年（1870年）の改称による |
| **鎮座地** | 徳島県徳島市国府町西矢野字宮谷531 |
| **延喜式社格** | 阿波国名方郡の大社（月次・新嘗）。**名神大社ではない**（神名帳転写では「大。月次／新嘗」とあり、名神の注記はない。阿波国の名神大は忌部神社・大麻比古神社のみ） |
| **比定** | 式内社「天石門別八倉比売神社」の論社の一つ。他の論社は上一宮大粟神社・一宮神社で、確定比定社は存在しない |
| **近代社格** | 旧県社 |
| **主祭神** | 大日孁尊（大日靈女命、おおひるめのみこと）— 天照大神の別名とされる |
| **配祀** | 公的資料で確認できず（旧稿の「月読命、伊勢宇之御魂神（豊受大神）」は出典未確認 → 8. 留保） |
| **神体** | 杉尾山（鎮座する山自体を神体とする） |
| **気延山** | 標高212.2m。社伝では、はじめ山頂に鎮座し、後に気延山南麓尾根の杉尾山（標高110m付近）へ移ったとされる |
| **奥の院** | 社殿背後の古墳（神陵とされる）の頂上にある **五角形の磐座（祭壇）** |
| **神階** | 『続日本後紀』承和8年（841年）従五位下から、元慶3年（879年）正四位上まで段階的に進んだ（六国史、親ノート照合済み） |

阿波国の式内社は計50座46社で、大社は3座（本社・忌部神社・大麻比古神社）のみである（Wikipedia「阿波国の式内社一覧」）。

## 2. 阿波説における核心的位置付け

### 「邦国之大典」と太政官符

- 『阿波国徴古雑抄』（小杉榲邨編、1913年刊）所収とされる **延久2年（1070年）太政官符** の写しに、「八倉比賣神 祈年月次祭 **邦国之大典也**」とあると伝えられる
- ただしこの太政官符は **明治期の蒐集物に残る写しのみで、原本は未確認** であり、「邦国之大典」の語の他文献での用例も確認されていない（Vault内史料ノート [[太政官符1070_翻刻と注釈]] も信頼度を低く置く）
- これを「国家祭祀の中心」「伊勢神宮以上の地位」の証拠とするのは **阿波説の解釈** であり、史料上確定した事実ではない
- 詳細：[[邦国之大典：平安時代の公式文書が語る神社の格]]

### 天照大神の葬儀伝承と陵墓説

- 社伝『八倉比売大神御本記』（『御本記』）に **天照大神の葬儀の様子** が記されていることは事実である（Wikipedia「天石門別八倉比売神社」もこの社伝に言及する）
- 阿波説では、社殿背後の古墳（奥の院の古墳、神陵とされる）が **天照大神の陵墓** と比定される
- しかし被葬者は特定されておらず、陵墓比定は **仮説** である
- 詳細：[[卑弥呼の墓と五角形祭壇：気延山の霊域検証]]

### 御本記（ごほんき）

- 本社に伝わる縁起『天石門別八倉比賣大神御本記』（別名『嘘楽（うらく）』）
- 大神の気延山への降臨・鎮座と葬儀を語る **社伝** であり、その存在自体は確認できる
- 成立年代については **中世以降の成立とする説や偽書説** があり、古代の記録（実録）であることは立証されていない
- 詳細：[[天照大神の葬儀記録：八倉比売大神御本記と嘘楽]]

### 邪馬台国卑弥呼との接続

- 阿波説では：**天照大神＝卑弥呼**（あるいは継承者）とし、気延山周辺を **邪馬台国の中心** の一部とみる
- 奥の院の古墳を卑弥呼の墓とする説は、Wikipediaも「一説には卑弥呼の墓であるという」と紹介する **一説** の段階である
- 邪馬台国の所在地については畿内説・北部九州説が通説的であり、阿波比定は仮説の一つ
- 関連：[[邪馬壹國・投馬國の阿波比定論：魏志倭人伝の里程と地形証拠]]

### 五角形祭壇

- 奥の院の **五角形の磐座（祭壇）** は実在する：社殿裏手約100メートル、標高116メートルの古墳の後円部頂上に、青石の木口積で築かれ、その上の祠に「つるぎ石」が祀られる（Wikipedia「天石門別八倉比売神社」境内項）
- 「日本唯一の五角形祭壇」「北斗七星の地上投影」との接続は **ブログ論考の主張** で、考古学的に検証されたものではない
- 大宜都比売命の **八前の伴神** との関連：[[八前の随神と北斗七星：大宜都比売命の降臨を支えた天文学的配置]]

## 3. 「八倉比賣」とは何者か

### 祭神同定

- 現社の祭神は **大日孁尊（大日靈女命）** で、天照大神の別名とされる（大日孁尊は『日本書紀』における天照大神の名の一つ）
- **八倉乃日孁大神（やくらのひるめのおおかみ）** の神名は『御本記』に見えるものである。旧稿が典拠とした『阿波国風土記』逸文によることは確認できない（→ 8. 留保）
- 『御本記』は社名の由来を「**八倉の郷に坐す姫の御神**」と説く（親ノート照合済み）。「八つの倉を持つ姫」「八矢倉の女神」といった語義解釈は後世の解釈である

### 阿波説における八倉比賣の系譜

| 説 | 内容 |
|---|---|
| **八倉比賣＝天照大神** | 現社の祭神同定（大日孁尊＝天照大神の別名とされる） |
| **八倉比賣＝大宜都比売命** | 大宜都比売（粟の女神）の別名／継承神とする阿波説（[[大宜都比売命と天照大神：阿波における重層的な女神崇拝の構造]]） |
| **八倉比賣＝卑弥呼** | 邪馬台国の女王、阿波の祭祀王とする説（marine816ブログ）|
| **八倉比賣＝石長比売** | 木花咲耶姫の姉、夏之売命と同体とする説（ブログ論） |
| **八倉比賣＝倭迹迹日百襲姫命** | 卑弥呼の継承者、第二の大宜都比売命とする説（[[倭迹迹日百襲姫命と「第二の大宜都比売命」：卑弥呼系譜論]]）|

### 阿波説の多重同体論

阿波説論者の中では：
- 八倉比賣 ＝ **大日孁尊 ＝ 天照大神 ＝ 卑弥呼 ＝ 大宜都比売命の継承神**
- これらは **同一の祭祀王の系譜** の各段階・各側面の名乗りとされる

いずれも阿波説・ブログ論者の解釈であり、古典史料による裏付けは確認できていない。

## 5. 周辺の聖地ネットワーク

### 気延山周辺の祭祀地理

阿波説が気延山を中心に描く聖地配置（各社の阿波説上の役割は解釈を含む）：

| 神社・聖地 | 位置 | 関連 |
|---|---|---|
| **天石門別八倉比売神社**（本ノート対象） | 杉尾山（気延山南麓） | 阿波説で天照大神の葬儀地とされる |
| **大御和神社** | 国府町府中 | 現行祭神は大己貴神。大物主神との同一視は阿波説の解釈（親ノート照合済み） |
| **天石門別豊玉比売神社** | 論社は春日神社境内社（徳島市眉山町、元は徳島城内） | 八倉比賣の海神族系姉妹とするのは阿波説 |
| **王子和多都美神社**（正表記は王子和多津美神社） | 徳島市国府町和田 | 式内社・和多都美豊玉比売神社の論社の一つ。海神族系祭祀とするのは阿波説 |
| **上一宮大粟神社** | 神山町（西） | 大宜都比売命を祀る。「八倉比賣の本体」とするのは阿波説 |
| **多祁御奈刀祢神社** | 石井町（東） | 「諏訪大社元宮」は阿波説（移遷伝承の出典は社伝記） |
| **観音寺遺跡** | 国府町 | 阿波国府の推定地、木簡出土 |
| **矢野遺跡** | 国府町 | 縄文時代の朱精製の痕跡、弥生時代の大規模集落 |

### 国府町と阿波国府

- **国府町** 一帯は古代阿波国府の **推定地** で、観音寺遺跡出土の木簡の内容から、近隣に国府・国衙が存在したことがほぼ確定している（徳島県公式「レキシルとくしま」）
- 大御和神社・八倉比売神社などがこの一帯に所在する
- これを「古代日本の中心地」とする位置付けは阿波説の解釈である

## 6. 物的痕跡と考古学

### 矢野遺跡

- 国府町矢野に所在する遺跡。**縄文時代** の低地性集落で、土器・石器に付着した水銀朱について「朱の精製としては全国的に見ても古い段階」のものとされる（徳島県公式「レキシルとくしま」。旧稿の「弥生期の朱精製工房」は時代の取り違え）
- **弥生時代** には徳島県最大級の集落となり、銅鐸（重要文化財）が出土している
- 朱の供給源とされる **若杉山辰砂採掘遺跡**（阿南市水井町、旧那賀郡。弥生時代後期〜古墳時代前期、2019年国史跡指定）との接続や、「古代王権の水銀朱独占」の物的証拠とするのは阿波説の解釈
- 関連：[[若杉山辰砂採掘遺跡_魏志倭人伝の「丹」の供給源]]、[[加茂宮ノ前遺跡：縄文後期からの朱生産]]

### 観音寺遺跡（阿波国府推定地）

- 阿波国府の推定地内にあり、多量の木簡の出土内容から近隣に国府・国衙が存在したことがほぼ確定した（徳島県公式）
- 出土品は重要文化財「徳島県観音寺・敷地遺跡出土品」に指定されている

### 段の塚穴型石室

- 段の塚穴古墳群（美馬市、国史跡）に代表される横穴式石室の系譜
- 「阿波→畿内→東国への古墳築造技術の流れ」は阿波説の解釈であり、技術伝播の方向は考古学的に確定していない
- 関連：[[纒向遺跡と東阿波型土器の定量分析]]

## 8. 留保（中立的併記）

### 改訂記録（2026-11-15・事実照合実施）

本サブノートは12セクションへの移行は行わず、既存構成のまま事実照合・訂正を行った。主な訂正は次の通り。

1. **延喜式社格の訂正**：旧稿の「名神大」は誤り。神名帳巻第十の転写では「天石門別八倉比売神社／大。月次／新嘗」で名神の注記はなく、Wikipedia「阿波国の式内社一覧」の凡例でも「大」は「式内大社（名神大社除く）」。阿波国の名神大は忌部神社・大麻比古神社のみ。阿波国の式内社は計50座46社・大社3座である点は旧稿の「50座」と整合するため、その旨に書き改めた
2. **比定の確定度を明記**：現社は式内社の **論社の一つ** で、確定比定社は存在しない（Wikipedia・親ノート）。旧稿の「阿波国名方郡の最重要式内社」という断定表現を改めた
3. **神体山の訂正**：神体は **杉尾山**（Wikipedia）。気延山（212.2m）は社伝で元の鎮座地とされる山で、現社はその南麓尾根の杉尾山にある
4. **祭神表記の精密化**：主祭神は大日孁尊（大日靈女命）で「天照大神の別名 **とされる** 」。旧稿の配祀「月読命、伊勢宇之御魂神（豊受大神）」は公的資料で確認できず基本情報から外した
5. **「邦国之大典」の層位**：延久2年太政官符は『阿波国徴古雑抄』（1913年）所収の写しのみで原本未確認。「唯一の社」「国家祭祀の中心」「伊勢神宮以上の地位」は阿波説の解釈として分離した
6. **典拠の訂正**：「八倉乃日孁大神」の典拠を『阿波国風土記』逸文から『御本記』へ是正（風土記逸文によることは未確認）
7. **周辺ネットワーク表の訂正**：大御和神社の祭神（大物主神→現行の大己貴神）、天石門別豊玉比売神社の論社所在地（国府町→春日神社境内社）、王子和多都美神社の正表記（王子和多津美神社）と論社である旨、観音寺遺跡（国府跡→推定地）
8. **矢野遺跡の時代訂正**：朱精製の痕跡は **縄文時代** の集落に伴うもの（徳島県公式）。弥生時代は大規模集落・銅鐸出土の時代として分離した
9. **frontmatter正規化**：分類「式内社」→「理論・研究」（本ノートは阿波説の位置付けを整理する論考系サブノートのため）、地域のパス形式値を「阿波国」に是正し旧国・旧郡を追加、evidence_type primary_source_based → **blog_hypothesis**、confidence 4 → **2**（中心命題がブログ・在野研究に依拠するため、親ノートの事実部分の評価とは別に設定）
