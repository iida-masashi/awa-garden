# オオトマヒメと巨大なる結界の女神

> [!summary] 概要
> **意富門麻比売（おおとまひめ）神社** は、阿波国名方郡の式内社で、現在の徳島市上八万町に鎮座する **宅宮（えのみや）神社** に比定される。祭神 **大戸麻比売命（おおとまひめのみこと、大苫邊尊／大戸麻邊尊）** は、**出入り口（門）を守護する女神**＝**結界の女神**。阿波国府の南方守護神として、古代の中枢防衛祭祀を担った。本社の存在は、阿波が古代日本における事実上の **「首都」** であったことの祭祀地理学的証拠となる。

## 2. 大苫邊尊（おおとまべのみこと）— 神代七代の女神

### 神代七代の系譜における位置

『古事記』『日本書紀』の**神代七代**：

1. 国之常立神
2. 豊雲野神
3. 宇比地邇神 ＋ 須比智邇神
4. 角杙神 ＋ 活杙神
5. 意富斗能地神 ＋ **大斗乃弁神（大苫邊尊）** ← **意富門麻比売の本体**
6. 於母陀流神 ＋ 阿夜訶志古泥神
7. 伊邪那岐神 ＋ 伊邪那美神

→ **イザナギ・イザナミよりも古い**、神世七代の第5代目の女神。

### 「大斗乃弁／大苫邊」の意味

- **「斗（と）」「苫（とま）」** ＝ **戸（と）** ＝出入り口、門
- **「大」** ＝ 偉大、根源
- **「弁／邊」** ＝ 女性神を示す古語
- 「**偉大なる門の女神**」「**根源の戸口の女神**」の意

→ **天地創成期に「門・戸口」を司る根源的女神**。

## 4. 「結界の女神」としての機能

### 古代の結界・門神祭祀

古代国家における門神祭祀の意義：

- 国家の **出入口（境界）** を護る
- 邪気・疫病・敵対勢力の **侵入を防ぐ**
- **国家の存続** を祭祀的に保証
- 中国の風水・道教の **辟邪思想** と通底

### 阿波国府＝事実上の首都としての証拠

意富門麻比売神社の存在は、**阿波が古代日本の中枢** であったことを示唆：

1. **大規模な門神祭祀** は地方の小国家には不要
2. **神代七代の女神** という最高位の祭神を擁する
3. **国府の周辺に結界系神社が配置** されている
4. **「邦国之大典」の八倉比賣神社** と組み合わせて、国家祭祀の中枢

## 7-B. 壹與女王陵説 — ひょうたん形古墳

### 宅宮神社後方の「ひょうたん形古墳」

宅宮神社の **後方にある「ひょうたん形古墳」** は、本社の元の鎮座地である。

> 「宅宮神社の後方にはひょうたん型をした『ひょうたん形古墳』があり、宅宮神社はもとはこの古墳の中腹にあったのですが、後世に現在地に移したと伝承されております。」(awa_kodaisi.xyz より)

**壹與(イヨ)女王陵説**:

- 大苫邊尊 = **壹與女王** という比定
  - 卑弥呼没後の男王の時代に国が乱れ、わずか **13 歳で即位した壹與**(『魏志倭人伝』)
  - その勢力範囲が **四国全域**(瓢箪 = 四国の形を象徴)
  - 「**ひょうたん節**」が全国に広まった起源とする説
- **「式内社で全国唯一」「神代七代の女神」「ひょうたん形古墳の存在」** という三重の特殊性は、壹與女王の祭祀地としての特異性を示唆

## 7-C. 神踊りの歌詞(三首)

宅宮神社の神踊りの代表歌詞(3 首)— 平安朝末期から伝承:

```
1. 神風や玉吹きおろす神風や
   悪魔を払う伊勢の神風

2. 御幣とる手の間の内の神風や
   悪魔を払う伊勢の神風

3. 榊葉に木綿紙垂付けて打払えば
   身には穢の霧雲もなし
```

特徴:

- **「神風」** = 国家を守護する祭祀の風
- **「伊勢の神風」** との接続(伊勢神宮との祭祀的連携の含意)
- **「木綿(ゆう)」「紙垂」** = **阿波忌部の祭具**(古語拾遺における忌部の麻木綿製作と直接対応)
- **「榊」** = 神籬(ひもろぎ)祭祀の象徴

→ 阿波説の含意: 神踊りの歌詞自体に **阿波忌部の祭祀職能** が刻印されており、本社が忌部系の祭祀社として機能していたことを示す
→ [[古語拾遺_MOC|🗺 古語拾遺 MOC]](天日鷲命の木綿製作伝承)と接続

## 9. 留保（中立的併記）

- 意富門麻比売神社の比定地（宅宮神社）は **江戸期以降の比定** であり、原初の鎮座地については議論がある
- 「神代七代の大苫邊尊を祀る式内社が阿波にあること」は事実だが、これが「阿波が古代首都であった」結論に直結するかは別議論
- 神代文字（阿波文字）の版木は近世のものとされる説もあり、上古からの継承かは確定していない
- 「結界の女神」という位置付けは阿波説論者の解釈であり、社伝に直接の記述があるわけではない
