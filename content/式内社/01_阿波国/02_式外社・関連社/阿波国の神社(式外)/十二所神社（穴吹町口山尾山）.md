# 十二所神社（穴吹町口山尾山）（じゅうにしょじんじゃ）

> [!summary] 要旨
> **十二所神社**（じゅうにしょじんじゃ／尾山十二所神社）は、徳島県美馬市穴吹町口山字尾山491に鎮座する古社。**舞中島を見下ろす標高70mの高所** にあり、**十二か所の祠を集めて一社** としたことが社名「十二所」の由来とされる。祭神は **伊弉諾命・伊弉冉命・国常立命・大山祇命・月読命・金山彦命**。重要な点として、麓の舞中島に鎮座する式内社 [[伊射奈美神社]]（イザナミを祀る全国唯一の式内社の論社）の **神社由緒は、この尾山十二所神社を「そもそもの元宮」と記す**。境内近くには6世紀後半の **尾山古墳**（円墳・横穴式石室）があり、舞中島を支配した豪族の墓と推定される。

## 3. 祭神と社伝

祭神は六柱：

| 神名 | 神格 |
|---|---|
| **伊弉諾命**（いざなぎ） | 国生みの男神 |
| **伊弉冉命**（いざなみ） | 国生みの女神 |
| **国常立命**（くにとこたち） | 天地開闢の根源神 |
| **大山祇命**（おおやまつみ） | 山の神 |
| **月読命**（つくよみ） | 月の神 |
| **金山彦命**（かなやまひこ） | 鉱山・鍛冶の神 |

- 「十二所」の名は、**十二か所の祠を集めて一つの神社とした** ことに由来すると伝える。
- かつては **「十二社大権現」** とも称した。麓の舞中島の社（現・[[伊射奈美神社]]）も、昭和になって伊射奈美神社と改称する以前は「十二社大権現／十二所神社」と呼ばれていたと、その神社由緒に記される。

## 4. 伊射奈美神社の元宮論

- 舞中島に鎮座する式内社 **[[伊射奈美神社]]**（穴吹町三島・舞中島）の **神社由緒は、尾山十二所神社を「そもそもの元宮」** と記す。
- 地理的に、尾山十二所神社は舞中島を見下ろす標高70mの高所にあり、**舞中島の伊射奈美神社は尾山十二所神社（および尾山古墳）を遥拝する位置** に建てられたとも考えられる（kohun-jinjya 考察）。
- すなわち、イザナミ祭祀の古層が尾山（高所・古墳近接）にあり、後に麓の舞中島へ展開した、という重層構造が想定される。

> [!note] 元宮論の出典と確度
> 本社を伊射奈美神社の元宮とする説は、**舞中島の伊射奈美神社の神社由緒（社伝）に明記** されたものを、参拝記（kohun-jinjya）が伝えるものである。社伝に基づく帰属であり、考古学的・文献史料的に実証された比定ではない。なお伊射奈美神社の式内論社は穴吹町三島・美馬町中鳥の二社が並立し、いずれが延喜式の本社かも未確定（[[伊射奈美神社]] §留保参照）。本社の元宮論はこの論社問題の一環として扱う。

## 5. 尾山古墳との関係

- 尾山十二所神社の近くに **尾山古墳** がある。
- **6世紀後半** の築造と考えられる **直径約13mの円墳** で、**横穴式石室が南に開口** する。
- 眼下に舞中島を見下ろす標高70mに位置することから、**舞中島を支配地域とした豪族の墓** と推定される。
- 本社・尾山古墳・舞中島（伊射奈美神社）が、高所の祭祀地と古墳と低地の遥拝社という一体の祭祀景観を構成する。

## 6. 阿波説における意義

- **イザナミ祭祀の古層**：阿波説では「伊射奈美」を冠する式内社が全国唯一阿波に存在する事実を、イザナミ祭祀の本貫が阿波であることの文献的証拠とする（[[伊射奈美神社]]）。本社（尾山十二所神社）がその式内社の元宮と社伝に記されることは、**イザナミ祭祀の最古層が尾山にある** 可能性を示す。
- **国生み神話の現地性**：祭神に伊弉諾・伊弉冉の両神を含み、美馬郡内には [[弥都波能売神社]]（イザナミの尿の水神）、[[波爾移麻比禰神社]]（イザナミの糞の土神）など国生み・神生み伝承の神々が同居する。本社もその祭祀圏の一点に位置づけられる。

## 12. 留保（中立的併記）

> [!warning] 注意
> - **主たる出典**：本社の祭神・由緒・元宮論は、舞中島 伊射奈美神社の **社伝** と、それを伝える参拝記（kohun-jinjya）に依拠する。神社台帳・一次史料による直接確認は本ノートでは取れていない。本社は式内社ではない。confidence=3。
> - **元宮論**：「尾山十二所神社＝伊射奈美神社の元宮」は社伝に基づく帰属であり、考古学的・文献史料的に実証されたものではない。伊射奈美神社の式内論社は穴吹町三島・美馬町中鳥の二社が並立し、本社を含めいずれが延喜式の本社・元宮かは未確定（[[伊射奈美神社]] §留保参照）。
> - **尾山古墳との関係**：古墳（6世紀後半）と本社・舞中島を一体の祭祀景観とみる読みは地理的近接からの推論で、被葬者と祭祀の直接の連関を示す物証はない。
> - **イザナミ祭祀の本貫＝阿波**は阿波説固有の解釈で、通説（イザナミ葬地は紀伊熊野有馬村／出雲伯耆境の比婆山の記紀二説）とは異なる。
> - 本ノートの evidence_type は "shrine_origin"、confidence は 3。祭神・社名由来・尾山古墳の存在は社伝・参拝記で一致するが、元宮論・阿波説接続は仮説・社伝段階として提示する。
