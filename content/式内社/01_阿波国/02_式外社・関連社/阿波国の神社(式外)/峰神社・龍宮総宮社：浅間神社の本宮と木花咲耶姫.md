# 峯神社・龍宮総宮社：浅間神社の本宮と木花咲耶姫

阿南市椿町と由岐町（現美波町）の境界にある **明神山山頂** に鎮座する **「巖座龍宮総宮社（いわくらりゅうぐうそうぐうしゃ）」** ――阿波説における **富士山本宮浅間大社の元宮（本宮）** とされる聖地。麓の **峯神社（みねじんじゃ）** がその里宮。徳島県神社誌に未掲載というほぼ秘匿された祭祀地でありながら、社伝には記紀神話と整合する **木花開耶姫命の家族祭祀の地理的配置** が刻まれ、さらに **古代石積神殿（ヘイアウ型）** という極めて稀な物的痕跡を伴う。

## 🌸 社伝が明言する「浅間神社の本宮」

峯神社境内に **平成7年（1995）11月吉日 峰神社氏子一同建立** の由緒書きが現存し、衝撃的な内容が刻まれている。

### 全文（平成7年由緒書き）

> **當峯神社ノ祭神ハ遠ク二千六百五十有餘年ノ昔皇室ノ祖神ニ當ル**
> **天照大神ノ天孫瓊瓊杵尊ノ妃神、木花開耶姫ノ命ヲ祀ル**
> **基ヨリ東方ノ静岡縣富士山ニ祀ル浅間神社ハ此ノ神社ノ本宮ニ當リ**
> **茲ニ対峙シ會フハ方ニ宜ベナラン**
> **亦タ西方ノ愛媛縣大三島ニ祀ル大山祇神ハ父君ニ當リ**
> **逢カニ父子ノ絆拘ヲ維ネル如ク亦タ此ニ対峙シ會フハ如斯**
> **猶北方ニ望ム津乃峰ニハ姉君賀志波姫命ガ祀ラレシコト洵ニ奇ナルベシ**
> **木花開耶姫命白蛇トナリテ屡々現ハルヲ以ツテ正ニ霊験顕カナリト**
> **蓋シ斯ル神秘ナルコト他ニ慮リ識レス仍而実ニ神聖ナル霊峰ト謂フベシ**

### 由緒書きが告げる5つの核心事実

1. **峯神社の祭神＝木花開耶姫命**（天孫瓊瓊杵尊の妃神）
2. **東方・富士山の浅間神社はこの神社の本宮**（つまり峯神社が元宮）
3. **西方・大三島の大山祇神社は父神（大山祇神）**――父子の絆として対峙
4. **北方・津乃峰の賀志波比売命は姉君**――姉妹として対峙
5. **木花開耶姫が白蛇となって度々現れる**――霊験の物証

→ 峯神社は **「東西南北の四方位に家族・遷座神社が対峙する中心点」** として位置づけられている。これは古代の **意図的な祭祀地理学** を示唆する。

## 🏛 巖座龍宮総宮社：ヘイアウ型古代神殿

### 物的構造

明神山山頂の本殿は、通常の社殿ではなく、**石積みの古代神殿**である。

> **本殿（明神山山頂：巖座龍宮総宮社）は石積みで立派に守られ石の猪が2体設置されている**
> （由岐町郷土事典 p63）

| 構造 | 詳細 |
|---|---|
| **石垣** | 周囲6m四方、高さ最大7m |
| **石の猪** | **2体設置**（神殿守護の象徴） |
| **時代区分** | 考古学上の **先史時代後期＝縄文時代後期相当**（阿波古代研究会） |
| **神殿形式** | **「ヘイアウ型」** |
| **公的扱い** | 由岐町合併前の郷土事典で言及あるが、徳島県神社誌には未掲載 |

### ヘイアウ（heiau）型神殿の意味

ヘイアウは古代ハワイの石積神殿で、太平洋諸島全域に類例がある祭祀構造。**阿波の明神山山頂の石積神殿がハワイのヘイアウと同型** とされる事実は、**阿波説における太平洋海洋ネットワーク説** の物的証拠となり得る。

| ヘイアウの特徴 | 巖座龍宮総宮社の対応 |
|---|---|
| 石積みの台座・神殿 | ✓ 6m四方・7m高 |
| 神聖な祭祀空間 | ✓ 山頂の聖地化 |
| 山頂・展望地への配置 | ✓ 明神山頂、橘湾を望む |
| 守護獣の設置 | ✓ 石の猪2体 |
| ポリネシア圏との連続性 | ⚠ 検証中、要研究 |

1999年9月、**ポルトガル国際岩石芸術学会** で発表され、日本国内では1999年初めに **阿波古代研究会・阿波ペトログラフ協会** が「ヘイアウ型古代神殿」と発表した。研究者の話題を集めている。

### 「賀志波比売＝石長比売」「木花開耶姫＝木花之佐久夜毘賣」の構造

『古事記』邇邇芸命の段で、大山津見神は娘2人を瓊瓊杵尊に差し出す：

> 我之女二並立奉由者、使石長比賣者、天神御子之命、雖雨零風吹、恒如石而、常堅不動坐。
> 亦使木花之佐久夜毘賣者、如木花之榮榮坐。

→ 石長比売（姉）と木花之佐久夜比売（妹）の姉妹。瓊瓊杵尊は**石長比売を返し、木花之佐久夜比売だけ留めた**ため、天皇の寿命が短くなったという。

阿波説では：
- **姉・石長比売＝賀志波比売命**（津峯神社・長寿延命の神）
- **妹・木花開耶姫＝峯神社の祭神**

として、この姉妹の祭祀地が **橘湾を挟んで北南に対峙** していることを重視する。

### 賀志波比売＝天照大神の幼名期説

ANYA チャンネル（137）では別の解釈も紹介されている：

> 賀志波比売は天照大神の弱年期の名前という説がある。
> 阿府志には宇神神社最人は「天照ラス交代という」と記され、江戸時代の偶事や土地の人は古来から賀志波比売狼を天照大神と認識していた。

つまり：
- 説 A：賀志波比売＝石長比売（木花開耶姫の姉、阿府志伝承）
- 説 B：賀志波比売＝天照大神の幼名（神社皇校）
- 説 C：賀志波比売＝祭祀を司どる「日の巫女」の役職名

これらは矛盾せず、**ある時代の祭祀王の称号** として重層的に解釈できる。

### 反証が峯神社の本宮論に与える含意

峯神社の **平成7年由緒書き** は「北方ノ津乃峰ニハ姉君賀志波姫命ガ祀ラレシコト洵ニ奇ナルベシ」と記すが：

- もし **賀志波比売の祭神論が江戸末期の改変** であるなら、平成7年由緒書きの「姉妹関係」記述も**それを前提とした再構築**である可能性
- 峯神社（木花開耶姫）の祭神論自体は浅間大社の本宮論として独立しているが、**賀志波比売との「姉妹対峙」論は別根拠が必要**

→ 阿波説のなかでも、**峯神社の浅間元宮論** と **賀志波比売＝石長比売論** は **論理的に切り離して評価** すべき。前者は社伝・物的痕跡（ヘイアウ型神殿）で支えられるが、後者は阿府志依存度が高い。

## 🏔 峰神社奥の院（妙人山）の存在

ANYA チャンネル（148）の調査で確認された **峰神社奥の院** の存在は重要：

- **場所**：峯神社（椿町明神山）の **南方・妙人山** に鎮座
- **祭神**：木花咲耶姫（同神を遥拝）
- **由緒記載**：「**奥には姉上の柏姫が祭祀**」と記載
- **意味**：峯神社（本社・木花咲耶姫）／津峯神社（姉・賀志波比売＝石長比売）／妙人山奥の院 という三層構造

これにより、阿波説における家族祭祀の地理配置は **「中心の峯神社、北の津峯、南の妙人山奥の院」** という三角形構造を成し、より複雑で組織的な古代祭祀ネットワークが描き出される。

## 🔮 阿波説における5つの理論的意義

### 1. 浅間神社系1300社の本源論
富士山本宮浅間大社を頂点とする **全国浅間神社（約1300社）** の祭神・木花咲耶姫の本源が阿波・峯神社にある、という命題は、**全国規模の祭祀ネットワーク** の本貫を阿波に求める阿波説の中核を成す。

### 2. 天孫降臨神話の阿波本舞台論
木花咲耶姫は **天孫瓊瓊杵尊の妃神**。彼女の本源が阿波にあるなら、天孫降臨神話の本舞台も阿波（橘湾周辺）であった可能性が高い。

### 3. 大山祇神社（大三島）との祭祀的対応
父神・大山祇神は大三島（伊予国一宮）に祀られるが、阿波説では **大三島の大山祇神社の元宮も阿波（阿讃山脈の大山）** とされる。
→ 関連：[[元宮ハブ_MOC]] 内「大山祇神社」項

### 4. 古代の太平洋海洋ネットワーク
ヘイアウ型神殿の存在は、**古代阿波が太平洋諸島と海洋的に繋がっていた** 可能性を示唆する。海人族の祭祀権が阿波を中心としていたという論への物証。

### 5. 賀志波比売＝天照大神論との接続
津峯神社の賀志波比売命を **天照大神の幼名期** と解釈する説と整合する。木花咲耶姫（妹）と天照大神（姉）が阿波で姉妹祭祀されていたという、皇祖神信仰の阿波本貫論。
